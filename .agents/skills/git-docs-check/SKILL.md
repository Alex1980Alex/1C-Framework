# Проверка Git и документации в Codex

Это инструкция явного раннего вызова, а не автоматический контроль каждой задачи.
`agents/openai.yaml` задаёт `allow_implicit_invocation: false`; поддержку этой настройки
целевой версией Codex проверяют отдельно, а не выводят из наличия файла.
Если пользователь запросил проверку перед правками, выполни её до изменения файлов.
Она не подключает UserPromptSubmit/Stop и не меняет существующие обработчики.

## Входные данные

Получи из запроса или текущего явно доверенного контекста задачи:

- `--package-root`: абсолютный путь уже принятой доверенной установки проверяющего пакета;
- `--root`: абсолютный путь выбранного Git-репозитория;
- `--base`: полный идентификатор исходного коммита, 40 или 64 шестнадцатеричных символа.

Если данных не хватает, кратко назови недостающие значения. Это запрос сведений,
а не повторного разрешения. Не подставляй ветку, предполагаемую базу или текущий каталог.
Не выводи доверие к пакету из проверяемого репозитория и не запускай скачанную копию
для подтверждения её же доверенности. Доверие к Python, стандартной библиотеке
и начальному запускаемому коду обеспечивает вызывающий.

`--head` необязателен: адаптер один раз закрепляет фактический HEAD выбранного
репозитория. При явном задании нужен полный идентификатор того же формата.
Проверяется весь объявленный диапазон зафиксированных изменений между base и head.
Не добавляй фильтры путей и исключения; результат не описывает индекс или рабочее дерево.

## Запуск

Используй фактически доступный Codex `exec_command`. Найди абсолютный путь адаптера
в репозитории этой инструкции: от каталога навыка `../../../scripts/git_docs_codex.py`.
Не ищи проверяющий код в `--root`. Передавай пути отдельными аргументами в кавычках;
для Windows используй UTF-8. Пример команды с заменяемыми значениями:

```text
python -X utf8 -I -B "<adapter-repository>/scripts/git_docs_codex.py" --package-root "<accepted-package>" --root "<selected-repository>" --base <full-base-SHA> --format json
```

При необходимости добавь `--head <full-head-SHA>` и `--timeout <seconds>`;
стандартный таймаут - 45 секунд. Не вставляй команды через обратные кавычки
и не включай секреты окружения в команду или отчёт.

## Чтение результата

Прочитай фактический JSON, а не только код завершения: справка тоже может дать rc0.
Коды результата: 0 PASS, 1 FAIL, 2 UNKNOWN. PASS требует свежего проверенного контекста;
FAIL требует подлинного отчёта, связанного с этим контекстом, и найденных нарушений.
Ошибка запуска, таймаут, недостающий путь, неверная схема или расхождение кода
и отчёта означают UNKNOWN. Отсутствие запуска не означает PASS.

Кратко сообщи по-русски статус, root/base/head, найденные нарушения или ошибки
адаптера и сведения правил из фактического отчёта. Внешняя оболочка содержит
контекст и статус адаптера; вложенный отчёт проверяющего кода сохраняется без правок.
Его `author: not_assessed` и `adapter_status: not_used` не доказывают авторство
и не заменяют статус внешнего адаптера. Не заявляй принадлежность изменений исполнителю.

Границы доверия и поставки: [git-docs-boundary.md](../../../docs/git-docs-boundary.md).
Обнаружение нового навыка проверяй в свежем Codex; наличие файла не доказывает
его загрузку текущей сессией. Общий каталог Claude Code этим навыком не изменяется.
