# Реализация задачи 1С

Выполни реализацию задачи по конфигурации 1С, используя **skill ** (6-этапный pipeline).

## Задача от пользователя:
$ARGUMENTS

---

## Инструкция

**Используй skill ** — единый источник методологии реализации.

Skill определяет:
- 6 последовательных этапов (Подготовка → BSL → XML → Верификация → Документация → Обучение+Git)
- Допущенные MCP-инструменты (Serena, ast-grep, bsl-platform-context, bsl-semantic-search)
- Правила BSL/XML модификаций
- Паттерны верификации и сохранения опыта

### Входные данные

Из  извлеки:
1. **ANALYSIS-REPORT.md** — файл отчёта анализа (из )
2. **Путь к src/** — корень исходников конфигурации
3. Дополнительные инструкции (если есть)

### Результат

- Внесённые BSL/XML изменения согласно плану
- Верификация через autoreview + cross-system impact
- Обновлённая документация (IMPLEMENTATION-PROGRESS.md)
- Git commit с описанием изменений
- Сохранённый опыт в память
