# 1c-config-knowledge — накопленное знание о конфигурации

Кэш фактов о конкретной конфигурации `УправлениеТранспортомНаПЛК`, собранных AutoResearch-циклом
1c-study и проверенных на тестовой базе `testdb1c_research`.

## Содержимое `cache/`

- `_index.json` — метаданные конфигурации (версия, статистика изученных объектов).
- `business_processes.md` — цепочки документов и бизнес-процессы.
- `document_register_map.md` — карта документ↔регистр.
- `documents/`, `registers/`, `catalogs/` — по-объектные заметки (заполняются по мере изучения).

## Использование

Перед работой с конкретным документом/регистром этой конфигурации — проверить `cache/documents/`
или `cache/registers/` на уже изученные факты (избегать повторного ресёрча). Пополнять кэш по ходу
изучения новых объектов через AutoResearch 1c-study.
