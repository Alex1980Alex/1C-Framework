## 1. Таблица компонентов (Структура эпика)

При планировании эпика создай таблицу компонентов:

| Тип | Имя | Синоним | Назначение | Что сделать | Вид изменения | Пояснение |
|-----|-----|---------|------------|-------------|---------------|-----------|
| Документ | гкс_ФактНабораПроб | Факт набора проб | Фиксация факта набора проб | Добавить реквизит "Статус" | Изменение | Для отслеживания состояния |
| РегистрСведений | гкс_СоответствиеФНП | Соответствие ФНП | Хранение связей | Создать с нуля | Новый | Связь ФНП и ЛабАнализ |

**Виды изменений:**
- **Новый** - создание с нуля
- **Изменение** - доработка существующего
- **Удаление** - удаление объекта/функционала

## 2. Методы оценки

### 2.1 Подробная (детальная) оценка

**Когда использовать:** Для точной оценки, когда есть чёткое ТЗ

**Алгоритм:**
1. Разбить раздел "Как сделать" на отдельные пункты
2. Оценить каждый пункт в часах
3. Суммировать

**Пример разбивки:**

```
Задача: Доработка документа "Заявка на отгрузку"

- Удалить ТЦ "РазнарядкиНаОтгрузку" ............... 2 часа (включая связанный код)
- Добавить реквизиты в шапку ...................... 1 час
- Изменить форму документа ....................... 2 часа
- Изменить движения документа .................... 4 часа
- Выполнить отладку работоспособности ............ 2 часа
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ИТОГО: 11 часов
```

### 2.2 Статистическая оценка

**Когда использовать:** Когда нет детального ТЗ или для быстрой предварительной оценки

**Базовые нормативы:**

| Операция | Время |
|----------|-------|
| Доработка документа (среднее) | 8 часов |
| Создание нового регистра сведений | 4-6 часов |
| Создание нового документа | 12-16 часов |
| Доработка формы | 2-4 часа |
| Изменение движений | 3-6 часов |
| Создание отчёта | 4-8 часов |
| Создание обработки | 6-12 часов |

### Работа с объектами метаданных

| Операция | Минимум | Среднее | Максимум |

|----------|---------|---------|----------|

## 4. Правило 16 часов

**КРИТИЧЕСКОЕ ПРАВИЛО:**

> Лимит затрат на исполнение одной задачи - **не более 16 часов**

**Если оценка > 16 часов:**
1. Выполнить декомпозицию на подзадачи
2. Каждая подзадача ≤ 16 часов
3. Оценка эпика = сумма оценок подзадач

**Пример декомпозиции:**

```
Эпик: Интеграция с внешней системой (32 часа)

├─ Задача 1: Создание HTTP-сервиса (8 часов)
├─ Задача 2: Реализация бизнес-логики (12 часов)
├─ Задача 3: Тестирование и отладка (8 часов)
└─ Задача 4: Документация (4 часа)
```

## 5. Коэффициенты сложности

Применяй коэффициенты к базовым оценкам:

|--------|-------------|
| Незнакомая подсистема | × 1.5 |
| Сложная бизнес-логика | × 1.3 |

## 7. Метрики спринта

**Расчёт план/факт:**
- Плановое время выполненных задач = Дней прошло × 8 ч/день
- Фактическое время = Сумма оценок выполненных задач

**Правило 3 задач:**
- Не более 3 задач одновременно в работе
- Завершать начатое перед взятием нового
