# Archived Skills

Skills moved here were identified as unused or harmful by the skill-health analyzer.

## Archive criteria

- **NEVER USED**: recommended 10+ times over 30 days, activated 0 times
- **HIGH WASTE**: recommended frequently (>5 times), waste_rate > 80%
- **Manual decision**: user explicitly archived after review

## Restore

To restore a skill, move its directory back to `.claude/skills/` and re-add to `skill-router-config.json`.
