# ADR-002: 3-tier структура знаний (cache + adr + skill)

**Дата:** 2026-02-14
**Статус:** accepted
**Исследование:** [cache/knowledge-organization-patterns.md](../cache/knowledge-organization-patterns.md)

---

## Контекст

Кеш-файл `haystack-vs-langchain-architecture.md` содержал одновременно объективные факты (бенчмарки, GitHub repos) и субъективные выводы ("Наше решение", "Связанные файлы"). Возник вопрос: должны ли выводы находиться в кеше или нужна отдельная структура?

## Решение

**Разделить knowledge artifacts на 3 уровня:**

```
.claude/skills/architecture-research/
├── cache/          # ФАКТЫ — объективные, переиспользуемые
├── adr/            # РЕШЕНИЯ — контекстные, версионируемые (ADR формат)
└── SKILL.md        # ПРОЦЕДУРА — как проводить исследование
```

### Обоснование

1. **Zettelkasten — принцип атомарности** [web]: 6 типов блоков знаний (concepts, arguments, counter-arguments, models, hypotheses, observations) — наблюдения и выводы должны быть отдельными атомарными заметками для переиспользуемости
2. **ADR (Architecture Decision Records)** [web: joelparkerhenderson/architecture-decision-record]: индустриальный стандарт, жизненный цикл Research → Evaluate → Decision → Implement → Sunset
3. **Google ADK Memory Architecture** [web]: 3 уровня — Memory (факты/preferences), Working Context (активные рассуждения), Artifacts (большие данные по имени+версии)
4. **Knowledge-Based Agent (KBA)** [web]: Knowledge Base (хранённые факты) vs Inference Engine (выведенные решения) — разделение позволяет менять выводы без потери фактов
5. **Claude Code Memory docs** [docs]: `.claude/rules/` — модульные правила по темам, каждый файл — одна тема

## Последствия

### Положительные
- Факты в кеше переиспользуемы — можно вынести другое решение на основе тех же данных
- ADR-записи имеют жизненный цикл (proposed → accepted → superseded)
- Решения связаны с исследованиями через поле `research`
- Чистое разделение ответственности: собирать ≠ решать ≠ процедурировать

### Отрицательные
- Дополнительный файл на каждое решение
- Нужна дисциплина: не смешивать выводы с фактами в кеше

## Альтернативы

1. **Единый файл (как было)** — отклонён: смешение фактов и выводов, невозможно переиспользовать факты для другого решения
2. **Отдельная папка `reports/`** — отклонён: ADR формат строже и включает жизненный цикл + альтернативы
3. **Только 2 уровня (cache + skill)** — отклонён: решения теряются или замусоривают кеш
