# ADR-007: Skill-Delegated Subagent — передача знаний через prompt

**Дата:** 2026-02-24
**Статус:** accepted
**Исследование:** [cache/skill-delegated-subagent-pattern.md](../cache/skill-delegated-subagent-pattern.md)

---

## Контекст

Подагенты Claude Code не наследуют навыки (skills) из родительского разговора [docs].
Если субагент вызывает `Skill()` самостоятельно:
- PostToolUse:Skill не срабатывает (баг #6305) — activated_skills не обновляется [web]
- Тратится 1 turn на активацию вместо работы [exp]
- Нет гарантии что субагент применит знания из скилла [exp]

Нужен надёжный способ делегировать задачи субагентам с передачей специализированных знаний.

## Решение

**Оркестратор сам читает SKILL.md и передаёт содержимое в prompt субагента.**

Workflow:
1. Оркестратор получает задачу
2. Определяет нужные скиллы (по триггерам из skill-router)
3. `Read(skills/X/SKILL.md)` — читает знания
4. `Read(skills/X/cache/topic.md)` — читает кешированные факты (если есть)
5. `Task(prompt=знания+задача, subagent_type="general-purpose")` — делегирует
6. Получает результат и интегрирует

### Обоснование

| Критерий | Skill() в субагенте | **Через prompt** |
|----------|--------------------|--------------------|
| Надёжность | ~80% (баг #6305) | **100%** [exp] |
| Overhead | 1 turn | **0 turns** [docs] |
| Гарантия знаний | Нет | **Да** [own] |
| Сложность | Низкая | Средняя (оркестрация) [own] |

## Последствия

### Положительные
- 100% надёжность передачи знаний субагенту [exp]
- 0 overhead на активацию скиллов [docs]
- Обход бага #6305 без костылей [own]
- Возможность параллельной делегации с разными скиллами [docs]
- Оркестратор контролирует объём передаваемых знаний (полный скилл или выжимка) [own]

### Отрицательные
- Увеличивает объём prompt субагента (токены) [own]
- Оркестратор должен знать какие скиллы нужны — нет автоматического routing в субагенте [own]
- Один уровень делегации (субагент не может делегировать дальше) [docs]

## Альтернативы

1. **`skills:` в frontmatter агента** — работает только для файловых агентов (.md в .claude/agents/), не для динамических Task() вызовов [docs]
2. **Субагент сам вызывает Skill()** — ненадёжно из-за #6305, тратит turn [web]
3. **Не использовать скиллы в субагентах** — потеря специализированных знаний [own]
4. **Хук SubagentStart для инъекции** — сложно, нет доступа к prompt субагента [docs]

## Связанные файлы

- `.claude/skills/*/SKILL.md` — скиллы для передачи
- `.claude/skills/*/cache/*.md` — кешированные знания
- `.claude/hooks/code-skill-enforcer.py` — enforcer который проверяет activated_skills
- `.claude/hooks/shared/session_state.py` — хранилище activated_skills
