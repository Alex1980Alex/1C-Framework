1С:Предприятие 8
Конфигурация "Библиотека интеграции с 1С:Документооборотом 8", редакция 1.1

Библиотека предоставляет набор механизмов для интеграции
с конфигурацией 1С:Документооборот через веб-сервис DMService.
=================================================================

1. Файлы поставки.
2. Важная информация.

Файлы поставки
-----------------------------------------------------------------
1. 1Cv8.cf - файл поставки библиотеки. Не предназначен для создания
  информационных баз по шаблону. Перед использованием необходимо
  ознакомиться с документацией.
2. 1Cv8.dt - демонстрационная база.
Файлы расположены в подкаталоге \1c\DMIL\1_1_12_2\
каталога шаблонов 1С:Предприятия 8.3.

3. Документация:
- файл "DocDMIL.html" описывает способы первичного внедрения,
обновления и пользовательскую документацию по библиотеке.
Файл расположен в подкаталоге \1c\DMIL\1_1_12_2\ExtFiles\
каталога шаблонов 1С:Предприятия 8.3.

4. Обработка расстановки фрагментов кода в формы объектов
- файл РасстановкаДобавленияИВызоваКомандИнтеграции.epf
расположен в подкаталоге \1c\DMIL\1_1_12_2\ExtFiles\
каталога шаблонов 1С:Предприятия 8.3.


Важная информация
-----------------------------------------------------------------
Внимание!
Данная версия конфигурации "Библиотека интеграции с 1С:Документооборотом 8"
предназначена для использования с платформой "1С:Предприятие 8.3" версии 8.3.12.
