# Быстрый старт

> Добро пожаловать в Claude Code!

Это руководство по быстрому старту позволит вам использовать помощь в кодировании на основе ИИ всего за несколько минут. К концу вы поймёте, как использовать Claude Code для типичных задач разработки.

## Перед началом

Убедитесь, что у вас есть:

* Открытый терминал или командная строка
* Проект кода для работы
* Учётная запись [Claude.ai](https://claude.ai) (рекомендуется) или [Claude Console](https://console.anthropic.com/)

## Шаг 1: Установите Claude Code

To install Claude Code, use one of the following methods:

<Tabs>
  <Tab title="Native Install (Recommended)">
    **macOS, Linux, WSL:**

    ```bash  theme={null}
    curl -fsSL https://claude.ai/install.sh | bash
    ```

    **Windows PowerShell:**

    ```powershell  theme={null}
    irm https://claude.ai/install.ps1 | iex
    ```

    **Windows CMD:**

    ```batch  theme={null}
    curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
    ```

    <Info>
      Native installations automatically update in the background to keep you on the latest version.
    </Info>
  </Tab>

  <Tab title="Homebrew">
    ```sh  theme={null}
    brew install --cask claude-code
    ```

    <Info>
      Homebrew installations do not auto-update. Run `brew upgrade claude-code` periodically to get the latest features and security fixes.
    </Info>
  </Tab>

  <Tab title="WinGet">
    ```powershell  theme={null}
    winget install Anthropic.ClaudeCode
    ```

    <Info>
      WinGet installations do not auto-update. Run `winget upgrade Anthropic.ClaudeCode` periodically to get the latest features and security fixes.
    </Info>
  </Tab>
</Tabs>

## Шаг 2: Войдите в свою учётную запись

Claude Code требует учётную запись для использования. Когда вы начнёте интерактивный сеанс с помощью команды `claude`, вам нужно будет войти:

```bash  theme={null}
claude
# При первом использовании вам будет предложено войти
```

```bash  theme={null}
/login
# Следуйте подсказкам для входа в свою учётную запись
```

Вы можете войти, используя любой тип учётной записи:

* [Claude.ai](https://claude.ai) (планы подписки - рекомендуется)
* [Claude Console](https://console.anthropic.com/) (доступ к API с предоплаченными кредитами)

После входа ваши учётные данные сохраняются, и вам не нужно будет входить снова.

<Note>
  Когда вы впервые аутентифицируете Claude Code с помощью своей учётной записи Claude Console, для вас автоматически создаётся рабочее пространство под названием "Claude Code". Это рабочее пространство обеспечивает централизованное отслеживание затрат и управление всем использованием Claude Code в вашей организации.
</Note>

<Note>
  Вы можете иметь оба типа учётных записей под одним адресом электронной почты. Если вам нужно войти снова или переключиться между учётными записями, используйте команду `/login` в Claude Code.
</Note>

## Шаг 3: Начните свой первый сеанс

Откройте терминал в любом каталоге проекта и запустите Claude Code:

```bash  theme={null}
cd /path/to/your/project
claude
```

Вы увидите экран приветствия Claude Code с информацией о вашем сеансе, недавними беседами и последними обновлениями. Введите `/help` для доступных команд или `/resume` для продолжения предыдущей беседы.

<Tip>
  После входа (Шаг 2) ваши учётные данные сохраняются на вашей системе. Узнайте больше в разделе [Управление учётными данными](/ru/iam#credential-management).
</Tip>

## Шаг 4: Задайте свой первый вопрос

Давайте начнём с понимания вашей кодовой базы. Попробуйте одну из этих команд:

```
> what does this project do?
```

Claude проанализирует ваши файлы и предоставит резюме. Вы также можете задать более конкретные вопросы:

```
> what technologies does this project use?
```

```
> where is the main entry point?
```

```
> explain the folder structure
```

Вы также можете спросить Claude о его собственных возможностях:

```
> what can Claude Code do?
```

```
> how do I use slash commands in Claude Code?
```

```
> can Claude Code work with Docker?
```

<Note>
  Claude Code читает ваши файлы по мере необходимости - вам не нужно вручную добавлять контекст. Claude также имеет доступ к собственной документации и может ответить на вопросы о его функциях и возможностях.
</Note>

## Шаг 5: Сделайте своё первое изменение кода

Теперь давайте заставим Claude Code выполнить некоторое реальное кодирование. Попробуйте простую задачу:

```
> add a hello world function to the main file
```

Claude Code будет:

1. Найти подходящий файл
2. Показать вам предложенные изменения
3. Попросить ваше одобрение
4. Сделать правку

<Note>
  Claude Code всегда запрашивает разрешение перед изменением файлов. Вы можете одобрить отдельные изменения или включить режим "Принять всё" для сеанса.
</Note>

## Шаг 6: Используйте Git с Claude Code

Claude Code делает операции Git разговорными:

```
> what files have I changed?
```

```
> commit my changes with a descriptive message
```

Вы также можете запросить более сложные операции Git:

```
> create a new branch called feature/quickstart
```

```
> show me the last 5 commits
```

```
> help me resolve merge conflicts
```

## Шаг 7: Исправьте ошибку или добавьте функцию

Claude хорошо разбирается в отладке и реализации функций.

Опишите то, что вы хотите, на естественном языке:

```
> add input validation to the user registration form
```

Или исправьте существующие проблемы:

```
> there's a bug where users can submit empty forms - fix it
```

Claude Code будет:

* Находить соответствующий код
* Понимать контекст
* Реализовать решение
* Запускать тесты, если они доступны

## Шаг 8: Попробуйте другие типичные рабочие процессы

Есть несколько способов работать с Claude:

**Рефакторинг кода**

```
> refactor the authentication module to use async/await instead of callbacks
```

**Написание тестов**

```
> write unit tests for the calculator functions
```

**Обновление документации**

```
> update the README with installation instructions
```

**Проверка кода**

```
> review my changes and suggest improvements
```

<Tip>
  **Помните**: Claude Code - это ваш помощник-программист на основе ИИ. Общайтесь с ним как с полезным коллегой - опишите, чего вы хотите достичь, и он поможет вам это сделать.
</Tip>

## Основные команды

Вот наиболее важные команды для ежедневного использования:

| Команда             | Что она делает                                       | Пример                              |
| ------------------- | ---------------------------------------------------- | ----------------------------------- |
| `claude`            | Запустить интерактивный режим                        | `claude`                            |
| `claude "task"`     | Выполнить одноразовую задачу                         | `claude "fix the build error"`      |
| `claude -p "query"` | Выполнить одноразовый запрос, затем выйти            | `claude -p "explain this function"` |
| `claude -c`         | Продолжить самую последнюю беседу в текущем каталоге | `claude -c`                         |
| `claude -r`         | Возобновить предыдущую беседу                        | `claude -r`                         |
| `claude commit`     | Создать коммит Git                                   | `claude commit`                     |
| `/clear`            | Очистить историю беседы                              | `> /clear`                          |
| `/help`             | Показать доступные команды                           | `> /help`                           |
| `exit` или Ctrl+C   | Выйти из Claude Code                                 | `> exit`                            |

Полный список команд см. в разделе [Справочник CLI](/ru/cli-reference).
