# Использование Claude Code с Chrome (бета)

> Подключите Claude Code к вашему браузеру для тестирования веб-приложений, отладки с помощью логов консоли и автоматизации задач браузера.

<Note>
  Интеграция с Chrome находится в бета-версии и в настоящее время работает только с Google Chrome. Она еще не поддерживается в Brave, Arc и других браузерах на основе Chromium. WSL (Windows Subsystem for Linux) также не поддерживается.
</Note>

Claude Code интегрируется с расширением Claude in Chrome для браузера, чтобы предоставить вам возможности автоматизации браузера прямо из вашего терминала. Разрабатывайте в терминале, а затем тестируйте и отлаживайте в браузере без переключения контекста.

## Что дает интеграция

С подключенным Chrome вы можете объединять действия браузера с командами терминала в единый рабочий процесс. Например: извлечь документацию с веб-сайта, проанализировать ее, создать код на основе полученной информации и зафиксировать результат.

Ключевые возможности включают:

* **Живая отладка**: Claude читает ошибки консоли и состояние DOM напрямую, а затем исправляет код, который их вызвал
* **Проверка дизайна**: Создайте пользовательский интерфейс на основе макета Figma, а затем попросите Claude открыть его в браузере и проверить соответствие
* **Тестирование веб-приложений**: Тестируйте валидацию форм, проверяйте визуальные регрессии или убедитесь, что пользовательские потоки работают правильно
* **Аутентифицированные веб-приложения**: Взаимодействуйте с Google Docs, Gmail, Notion или любым приложением, в которое вы вошли, без необходимости в коннекторах API
* **Извлечение данных**: Извлекайте структурированную информацию с веб-страниц и сохраняйте ее локально
* **Автоматизация задач**: Автоматизируйте повторяющиеся задачи браузера, такие как ввод данных, заполнение форм или многосайтовые рабочие процессы
* **Запись сеанса**: Записывайте взаимодействия браузера в виде GIF-файлов для документирования или обмена информацией о произошедшем

## Предварительные требования

Перед использованием Claude Code с Chrome вам потребуется:

* Браузер [Google Chrome](https://www.google.com/chrome/)
* Расширение [Claude in Chrome](https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn) версии 1.0.36 или выше
* [Claude Code CLI](/ru/quickstart#step-1:-install-claude-code) версии 2.0.73 или выше
* Платный план Claude (Pro, Team или Enterprise)

## Как работает интеграция

Claude Code взаимодействует с Chrome через расширение Claude in Chrome для браузера. Расширение использует [Native Messaging API](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging) Chrome для получения команд от Claude Code и их выполнения в вашем браузере. Эта архитектура позволяет Claude Code управлять вкладками браузера, читать содержимое страницы и выполнять действия, пока вы продолжаете работать в терминале.

Когда Claude встречает страницу входа, CAPTCHA или другое препятствие, он делает паузу и просит вас справиться с ним. Вы можете предоставить учетные данные для ввода Claude или войти вручную в браузер. После того как вы преодолеете препятствие, скажите Claude продолжить, и он продолжит с того же места.

Claude открывает новые вкладки для задач браузера, а не захватывает существующие. Однако он использует состояние входа вашего браузера, поэтому если вы уже вошли на сайт в Chrome, Claude может получить к нему доступ без повторной аутентификации.

<Note>
  Интеграция с Chrome требует видимого окна браузера. Когда Claude выполняет действия браузера, вы увидите, как Chrome открывается и переходит в реальном времени. Режима без интерфейса нет, так как интеграция зависит от вашего фактического сеанса браузера с его состоянием входа.
</Note>

## Настройка интеграции

<Steps>
  <Step title="Обновите Claude Code">
    Интеграция с Chrome требует последней версии Claude Code. Если вы установили с помощью [встроенного установщика](/ru/quickstart#step-1:-install-claude-code), обновления происходят автоматически. В противном случае выполните:

    ```bash  theme={null}
    claude update
    ```
  </Step>

  <Step title="Запустите Claude Code с включенным Chrome">
    Запустите Claude Code с флагом `--chrome`:

    ```bash  theme={null}
    claude --chrome
    ```
  </Step>

  <Step title="Проверьте соединение">
    Выполните `/chrome` для проверки статуса соединения и управления параметрами. Если расширение не обнаружено, вы увидите предупреждение со ссылкой на его установку.
  </Step>
</Steps>

Вы также можете включить интеграцию с Chrome из существующего сеанса, используя команду `/chrome`.

## Попробуйте

После подключения введите это в Claude, чтобы увидеть интеграцию в действии:

```
Go to code.claude.com/docs, click on the search box,
type "hooks", and tell me what results appear
```

Claude открывает страницу, нажимает на поле поиска, вводит запрос и сообщает результаты автодополнения. Это демонстрирует навигацию, нажатие и ввод текста в едином рабочем процессе.

## Примеры рабочих процессов

Claude может переходить по страницам, нажимать и печатать, заполнять формы, прокручивать, читать логи консоли и сетевые запросы, управлять вкладками, изменять размер окон и записывать GIF-файлы. Выполните `/mcp` и нажмите на `claude-in-chrome`, чтобы увидеть полный список доступных инструментов.

Следующие примеры показывают распространенные шаблоны для автоматизации браузера.

### Тестирование локального веб-приложения

При разработке веб-приложения попросите Claude проверить, что ваши изменения работают правильно:

```
I just updated the login form validation. Can you open localhost:3000,
try submitting the form with invalid data, and check if the error
messages appear correctly?
```

Claude переходит на ваш локальный сервер, взаимодействует с формой и сообщает о своих наблюдениях.

### Отладка с помощью логов консоли

Если в вашем приложении есть проблемы, Claude может читать вывод консоли для диагностики проблем:

```
Open the dashboard page and check the console for any errors when
the page loads.
```

Claude читает сообщения консоли и может фильтровать по определенным шаблонам или типам ошибок.

### Автоматизация заполнения форм

Ускорьте повторяющиеся задачи ввода данных:

```
I have a spreadsheet of customer contacts in contacts.csv. For each row,
go to our CRM at crm.example.com, click "Add Contact", and fill in the
name, email, and phone fields.
```

Claude читает ваш локальный файл, переходит к веб-интерфейсу и вводит данные для каждой записи.

### Создание контента в Google Docs

Используйте Claude для прямого написания в ваших документах без настройки API:

```
Draft a project update based on our recent commits and add it to my
Google Doc at docs.google.com/document/d/abc123
```

Claude открывает документ, нажимает в редактор и вводит содержимое. Это работает с любым веб-приложением, в которое вы вошли: Gmail, Notion, Sheets и другие.

### Извлечение данных с веб-страниц

Извлекайте структурированную информацию с веб-сайтов:

```
Go to the product listings page and extract the name, price, and
availability for each item. Save the results as a CSV file.
```

Claude переходит на страницу, читает содержимое и компилирует данные в структурированный формат.

### Запуск многосайтовых рабочих процессов

Координируйте задачи на нескольких веб-сайтах:

```
Check my calendar for meetings tomorrow, then for each meeting with
an external attendee, look up their company on LinkedIn and add a
note about what they do.
```

Claude работает на разных вкладках для сбора информации и завершения рабочего процесса.

### Запись демо-GIF

Создавайте общедоступные записи взаимодействий браузера:

```
Record a GIF showing how to complete the checkout flow, from adding
an item to the cart through to the confirmation page.
```

Claude записывает последовательность взаимодействий и сохраняет ее как GIF-файл.

## Лучшие практики

При использовании автоматизации браузера помните эти рекомендации:

* **Модальные диалоги могут прерывать поток**: JavaScript-предупреждения, подтверждения и подсказки блокируют события браузера и предотвращают получение Claude команд. Если появляется диалог, закройте его вручную и скажите Claude продолжить.
* **Используйте новые вкладки**: Claude создает новые вкладки для каждого сеанса. Если вкладка становится неответчивой, попросите Claude создать новую.
* **Фильтруйте вывод консоли**: Логи консоли могут быть многословными. При отладке скажите Claude, какие шаблоны искать, вместо того чтобы просить весь вывод консоли.

## Устранение неполадок

### Расширение не обнаружено

Если Claude Code показывает "Chrome extension not detected":

1. Убедитесь, что расширение Chrome (версия 1.0.36 или выше) установлено
2. Убедитесь, что Claude Code версии 2.0.73 или выше, выполнив `claude --version`
3. Проверьте, что Chrome запущен
4. Выполните `/chrome` и выберите "Reconnect extension" для переподключения
5. Если проблема сохраняется, перезагрузите Claude Code и Chrome

### Браузер не отвечает

Если команды браузера Claude перестают работать:

1. Проверьте, не блокирует ли страницу модальный диалог (alert, confirm, prompt)
2. Попросите Claude создать новую вкладку и попробуйте снова
3. Перезагрузите расширение Chrome, отключив и повторно включив его

### Первоначальная настройка

При первом использовании интеграции Claude Code устанавливает хост для собственного обмена сообщениями, который позволяет взаимодействие между CLI и Chrome. Если вы столкнулись с ошибками разрешений, вам может потребоваться перезагрузить Chrome, чтобы установка вступила в силу.

## Включение по умолчанию

Интеграция с Chrome требует флага `--chrome` каждый раз при запуске Claude Code. Чтобы включить его по умолчанию, выполните `/chrome` и выберите "Enabled by default".

<Note>
  Включение Chrome по умолчанию увеличивает использование контекста, так как инструменты браузера всегда загружены. Если вы заметили увеличение потребления контекста, отключите этот параметр и используйте `--chrome` только при необходимости.
</Note>

Разрешения на уровне сайта наследуются от расширения Chrome. Управляйте разрешениями в параметрах расширения Chrome, чтобы контролировать, какие сайты Claude может просматривать, нажимать и печатать. Выполните `/chrome`, чтобы увидеть текущие параметры разрешений.
