# Стили вывода

> Адаптируйте Claude Code для задач помимо разработки программного обеспечения.

Стили вывода позволяют использовать Claude Code как агента любого типа, сохраняя при этом его основные возможности: запуск локальных скриптов, чтение/запись файлов и отслеживание задач.

## Встроенные стили вывода

Стиль **Default** (по умолчанию) — это существующий системный промпт, разработанный для эффективного выполнения задач по разработке ПО.

Есть два дополнительных встроенных стиля, ориентированных на обучение:

- **Explanatory**: Предоставляет образовательные "Инсайты" между задачами. Помогает понять архитектурные решения и паттерны кодовой базы.

- **Learning**: Совместный режим обучения на практике. Claude не только делится инсайтами, но и предлагает вам самостоятельно написать небольшие стратегические фрагменты кода. Claude добавляет маркеры `TODO(human)` в код для вашей реализации.

## Как работают стили вывода

Стили вывода напрямую модифицируют системный промпт Claude Code:

- Все стили исключают инструкции для краткого вывода (например, отвечать лаконично)
- Пользовательские стили исключают инструкции для кода (проверка тестами), если `keep-coding-instructions` не `true`
- Все стили добавляют свои инструкции в конец системного промпта
- Все стили вызывают напоминания для Claude следовать инструкциям стиля

## Смена стиля вывода

Два способа:

- Запустите `/output-style` для доступа к меню выбора стиля (также доступно из `/config`)
- Запустите `/output-style [style]`, например `/output-style explanatory`

Изменения сохраняются на уровне локального проекта в `.claude/settings.local.json`. Вы также можете напрямую редактировать поле `outputStyle` в файле настроек.

## Создание пользовательского стиля

Пользовательские стили — это Markdown-файлы с frontmatter и текстом для системного промпта:

```markdown
---
name: My Custom Style
description:
  A brief description of what this style does
---

# Custom Style Instructions

You are an interactive CLI tool that helps users with software engineering
tasks. [Your custom instructions here...]

## Specific Behaviors

[Define how the assistant should behave in this style...]
```

Сохраняйте файлы на уровне пользователя (`~/.claude/output-styles`) или проекта (`.claude/output-styles`).

### Frontmatter

| Frontmatter                | Назначение                                                          | По умолчанию            |
| :------------------------- | :------------------------------------------------------------------ | :---------------------- |
| `name`                     | Название стиля вывода                                               | Наследуется от файла    |
| `description`              | Описание стиля. Используется в UI `/output-style`                   | Нет                     |
| `keep-coding-instructions` | Сохранять ли части промпта, связанные с кодированием                | false                   |

## Сравнение с другими функциями

### Output Styles vs. CLAUDE.md vs. --append-system-prompt

Стили вывода полностью "выключают" части системного промпта для разработки ПО. Ни CLAUDE.md, ни `--append-system-prompt` не редактируют системный промпт. CLAUDE.md добавляет содержимое как пользовательское сообщение *после* системного промпта. `--append-system-prompt` добавляет контент в конец системного промпта.

### Output Styles vs. Агенты

Стили напрямую влияют на основной цикл агента и затрагивают только системный промпт. Агенты вызываются для обработки конкретных задач и могут включать дополнительные настройки (модель, доступные инструменты, контекст использования).

### Output Styles vs. Навыки (Skills)

Стили модифицируют *как* Claude отвечает (форматирование, тон, структура) и всегда активны после выбора. Навыки — это промпты для конкретных задач, вызываемые через `/skill-name` или загружаемые Claude автоматически. Используйте стили для последовательных предпочтений форматирования; навыки — для переиспользуемых рабочих процессов.
