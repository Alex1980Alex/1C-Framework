# Аналитика

> Просмотрите подробные сведения об использовании и метрики производительности развертывания Claude Code вашей организации.

Claude Code предоставляет панель аналитики, которая помогает организациям понять закономерности использования разработчиками, отслеживать метрики производительности и оптимизировать внедрение Claude Code.

<Note>
  Аналитика в настоящее время доступна только для организаций, использующих Claude Code с Claude API через Claude Console.
</Note>

## Доступ к аналитике

Перейдите на панель аналитики по адресу [console.anthropic.com/claude-code](https://console.anthropic.com/claude-code).

### Требуемые роли

* **Primary Owner**
* **Owner**
* **Billing**
* **Admin**
* **Developer**

<Note>
  Пользователи с ролями **User**, **Claude Code User** или **Membership Admin** не могут получить доступ к аналитике.
</Note>

## Доступные метрики

### Принятые строки кода

Общее количество строк кода, написанного Claude Code, которые пользователи приняли в своих сеансах.

* Исключает отклоненные предложения кода
* Не отслеживает последующие удаления

### Процент принятия предложений

Процент случаев, когда пользователи принимают использование инструмента редактирования кода, включая:

* Edit
* Write
* NotebookEdit

### Активность

**users**: Количество активных пользователей в данный день (число на левой оси Y)

**sessions**: Количество активных сеансов в данный день (число на правой оси Y)

### Расходы

**users**: Количество активных пользователей в данный день (число на левой оси Y)

**spend**: Общая сумма в долларах, потраченная в данный день (число на правой оси Y)

### Аналитика команды

**Members**: Все пользователи, которые прошли аутентификацию в Claude Code

* Пользователи API key отображаются по **идентификатору API key**
* Пользователи OAuth отображаются по **адресу электронной почты**

**Spend this month:** Общие расходы на одного пользователя за текущий месяц.

**Lines this month:** Общее количество принятых строк кода на одного пользователя за текущий месяц.

## Эффективное использование аналитики

### Мониторинг внедрения

Отслеживайте статус членов команды, чтобы определить:

* Активных пользователей, которые могут поделиться лучшими практиками
* Общие тенденции внедрения в вашей организации

### Измерение производительности

Показатели принятия инструментов и метрики кода помогают вам:

* Понять удовлетворенность разработчиков предложениями Claude Code
* Отследить эффективность генерации кода
* Определить возможности для обучения или улучшения процессов
