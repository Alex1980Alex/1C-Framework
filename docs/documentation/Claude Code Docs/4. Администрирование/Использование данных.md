# Использование данных

> Узнайте о политике использования данных Anthropic для Claude

## Политики использования данных

### Политика обучения на данных

**Потребительские пользователи (планы Free, Pro и Max)**:
Мы даем вам возможность разрешить использование ваших данных для улучшения будущих моделей Claude. Мы будем обучать новые модели, используя данные из учетных записей Free, Pro и Max, когда этот параметр включен (включая случаи, когда вы используете Claude Code из этих учетных записей).

**Коммерческие пользователи**: (планы Team и Enterprise, API, платформы третьих сторон и Claude Gov) сохраняют существующие политики: Anthropic не обучает генеративные модели, используя код или подсказки, отправленные в Claude Code на коммерческих условиях, если только клиент не выбрал предоставить нам свои данные для улучшения модели (например, [Developer Partner Program](https://support.claude.com/en/articles/11174108-about-the-development-partner-program)).

### Development Partner Program

Если вы явно согласитесь на методы предоставления нам материалов для обучения, такие как [Development Partner Program](https://support.claude.com/en/articles/11174108-about-the-development-partner-program), мы можем использовать эти предоставленные материалы для обучения наших моделей. Администратор организации может явно согласиться на участие в Development Partner Program для своей организации. Обратите внимание, что эта программа доступна только для API Anthropic первой стороны и недоступна для пользователей Bedrock или Vertex.

### Обратная связь с использованием команды `/bug`

Если вы решите отправить нам отзыв о Claude Code с помощью команды `/bug`, мы можем использовать ваш отзыв для улучшения наших продуктов и услуг. Стенограммы, отправленные через `/bug`, сохраняются в течение 5 лет.

### Опросы о качестве сеанса

Когда вы видите подсказку "How is Claude doing this session?" в Claude Code, ответ на этот опрос (включая выбор "Dismiss") записывает только вашу числовую оценку (1, 2, 3 или dismiss). Мы не собираем и не сохраняем стенограммы разговоров, входные данные, выходные данные или другие данные сеанса как часть этого опроса. В отличие от отзывов с большим пальцем вверх/вниз или отчетов `/bug`, этот опрос о качестве сеанса является простой метрикой удовлетворенности продуктом. Ваши ответы на этот опрос не влияют на ваши предпочтения обучения данных и не могут использоваться для обучения наших моделей ИИ.

### Хранение данных

Anthropic сохраняет данные Claude Code на основе типа вашей учетной записи и предпочтений.

**Потребительские пользователи (планы Free, Pro и Max)**:

* Пользователи, которые разрешают использование данных для улучшения модели: период хранения 5 лет для поддержки разработки модели и улучшения безопасности
* Пользователи, которые не разрешают использование данных для улучшения модели: период хранения 30 дней
* Параметры конфиденциальности можно изменить в любое время на [claude.ai/settings/data-privacy-controls](https://claude.ai/settings/data-privacy-controls).

**Коммерческие пользователи (Team, Enterprise и API)**:

* Стандартное: период хранения 30 дней
* Нулевое хранение данных: доступно с надлежащим образом настроенными ключами API - Claude Code не будет сохранять стенограммы чатов на серверах
* Локальное кэширование: клиенты Claude Code могут сохранять сеансы локально до 30 дней для включения возобновления сеанса (настраивается)

Узнайте больше о практике хранения данных в нашем [Privacy Center](https://privacy.anthropic.com/).

Для получения полной информации, пожалуйста, ознакомьтесь с нашими [Commercial Terms of Service](https://www.anthropic.com/legal/commercial-terms) (для пользователей Team, Enterprise и API) или [Consumer Terms](https://www.anthropic.com/legal/consumer-terms) (для пользователей Free, Pro и Max) и [Privacy Policy](https://www.anthropic.com/legal/privacy).

## Доступ к данным

Для всех пользователей первой стороны вы можете узнать больше о том, какие данные регистрируются для [локального Claude Code](#local-claude-code-data-flow-and-dependencies) и [удаленного Claude Code](#cloud-execution-data-flow-and-dependencies). Обратите внимание, что для удаленного Claude Code Claude получает доступ к репозиторию, в котором вы инициируете сеанс Claude Code. Claude не получает доступ к репозиториям, которые вы подключили, но в которых не начали сеанс.

Claude Code устанавливается из [NPM](https://www.npmjs.com/package/@anthropic-ai/claude-code). Claude Code работает локально. Для взаимодействия с LLM Claude Code отправляет данные по сети. Эти данные включают все подсказки пользователя и выходные данные модели. Данные зашифрованы при передаче через TLS и не зашифрованы в состоянии покоя. Claude Code совместим с большинством популярных VPN и прокси LLM.

Claude Code построен на API Anthropic. Для получения подробной информации о средствах контроля безопасности нашего API, включая процедуры логирования API, пожалуйста, обратитесь к артефактам соответствия, предлагаемым в [Anthropic Trust Center](https://trust.anthropic.com).

### Cloud execution: поток данных и зависимости

При использовании [Claude Code в веб-версии](/ru/claude-code-on-the-web) сеансы работают на виртуальных машинах, управляемых Anthropic, вместо локального запуска. В облачных средах:

* **Хранилище кода и данных:** Ваш репозиторий клонируется на изолированную виртуальную машину. Код и данные сеанса подлежат политикам хранения и использования для вашего типа учетной записи (см. раздел Хранение данных выше)
* **Учетные данные:** Аутентификация GitHub обрабатывается через защищенный прокси; ваши учетные данные GitHub никогда не попадают в песочницу
* **Сетевой трафик:** Весь исходящий трафик проходит через прокси безопасности для логирования аудита и предотвращения злоупотреблений
* **Данные сеанса:** Подсказки, изменения кода и выходные данные следуют тем же политикам данных, что и локальное использование Claude Code

Для получения подробной информации о безопасности облачного выполнения см. [Security](/ru/security#cloud-execution-security).

## Сервисы телеметрии

Claude Code подключается с машин пользователей к сервису Statsig для логирования операционных метрик, таких как задержка, надежность и паттерны использования. Это логирование не включает никакой код или пути к файлам. Данные зашифрованы при передаче с использованием TLS и в состоянии покоя с использованием 256-битного шифрования AES. Прочитайте больше в [документации по безопасности Statsig](https://www.statsig.com/trust/security). Чтобы отказаться от телеметрии Statsig, установите переменную окружения `DISABLE_TELEMETRY`.

Claude Code подключается с машин пользователей к Sentry для логирования операционных ошибок. Данные зашифрованы при передаче с использованием TLS и в состоянии покоя с использованием 256-битного шифрования AES. Прочитайте больше в [документации по безопасности Sentry](https://sentry.io/security/). Чтобы отказаться от логирования ошибок, установите переменную окружения `DISABLE_ERROR_REPORTING`.

Когда пользователи выполняют команду `/bug`, копия их полной истории разговора, включая код, отправляется в Anthropic. Данные зашифрованы при передаче и в состоянии покоя. Опционально создается проблема Github в нашем публичном репозитории. Чтобы отказаться от отчетов об ошибках, установите переменную окружения `DISABLE_BUG_COMMAND`.

## Поведение по умолчанию по поставщикам API

По умолчанию мы отключаем весь несущественный трафик (включая отчеты об ошибках, телеметрию и функциональность отчетов об ошибках) при использовании Bedrock или Vertex. Вы также можете отказаться от всех этих функций сразу, установив переменную окружения `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`. Вот полное поведение по умолчанию:

| Сервис                          | Claude API                                                              | Vertex API                                                           | Bedrock API                                                           |
| ------------------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------- | --------------------------------------------------------------------- |
| **Statsig (Metrics)**           | По умолчанию включено.<br />`DISABLE_TELEMETRY=1` для отключения.       | По умолчанию отключено.<br />`CLAUDE_CODE_USE_VERTEX` должен быть 1. | По умолчанию отключено.<br />`CLAUDE_CODE_USE_BEDROCK` должен быть 1. |
| **Sentry (Errors)**             | По умолчанию включено.<br />`DISABLE_ERROR_REPORTING=1` для отключения. | По умолчанию отключено.<br />`CLAUDE_CODE_USE_VERTEX` должен быть 1. | По умолчанию отключено.<br />`CLAUDE_CODE_USE_BEDROCK` должен быть 1. |
| **Claude API (`/bug` reports)** | По умолчанию включено.<br />`DISABLE_BUG_COMMAND=1` для отключения.     | По умолчанию отключено.<br />`CLAUDE_CODE_USE_VERTEX` должен быть 1. | По умолчанию отключено.<br />`CLAUDE_CODE_USE_BEDROCK` должен быть 1. |

Все переменные окружения можно проверить в `settings.json` ([прочитайте больше](/ru/settings)).
