# Эффективное управление затратами

> Узнайте, как отслеживать и оптимизировать использование токенов и затраты при использовании Claude Code.

Claude Code потребляет токены для каждого взаимодействия. Средняя стоимость составляет \$6 на разработчика в день, при этом ежедневные затраты остаются ниже \$12 для 90% пользователей.

Для командного использования Claude Code взимается плата в зависимости от потребления токенов API. В среднем Claude Code стоит \~\$100-200/разработчик в месяц с Sonnet 4.5, хотя есть большая вариативность в зависимости от того, сколько экземпляров запускают пользователи и используют ли они его в автоматизации.

## Отслеживание затрат

### Использование команды `/cost`

<Note>
  Команда `/cost` не предназначена для подписчиков Claude Max и Pro.
</Note>

Команда `/cost` предоставляет подробную статистику использования токенов для вашей текущей сессии:

```
Total cost:            $0.55
Total duration (API):  6m 19.7s
Total duration (wall): 6h 33m 10.2s
Total code changes:    0 lines added, 0 lines removed
```

### Дополнительные варианты отслеживания

Проверьте [историческое использование](https://support.claude.com/ru/articles/9534590-cost-and-usage-reporting-in-console) в Claude Console (требуется роль Admin или Billing) и установите [лимиты расходов рабочей области](https://support.claude.com/ru/articles/9796807-creating-and-managing-workspaces) для рабочей области Claude Code (требуется роль Admin).

<Note>
  Когда вы впервые аутентифицируете Claude Code с помощью вашей учетной записи Claude Console, для вас автоматически создается рабочая область под названием "Claude Code". Эта рабочая область обеспечивает централизованное отслеживание и управление затратами для всего использования Claude Code в вашей организации. Вы не можете создавать ключи API для этой рабочей области - она предназначена исключительно для аутентификации и использования Claude Code.
</Note>

## Управление затратами для команд

При использовании Claude API вы можете ограничить общие расходы рабочей области Claude Code. Для настройки [следуйте этим инструкциям](https://support.claude.com/ru/articles/9796807-creating-and-managing-workspaces). Администраторы могут просматривать отчеты о затратах и использовании, [следуя этим инструкциям](https://support.claude.com/ru/articles/9534590-cost-and-usage-reporting-in-console).

На Bedrock и Vertex Claude Code не отправляет метрики из вашего облака. Чтобы получить метрики затрат, несколько крупных предприятий сообщили об использовании [LiteLLM](/ru/third-party-integrations#litellm), который является инструментом с открытым исходным кодом, помогающим компаниям [отслеживать расходы по ключу](https://docs.litellm.ai/docs/proxy/virtual_keys#tracking-spend). Этот проект не связан с Anthropic, и мы не проводили аудит его безопасности.

### Рекомендации по ограничению скорости

При настройке Claude Code для команд учитывайте эти рекомендации по количеству токенов в минуту (TPM) и запросов в минуту (RPM) на пользователя в зависимости от размера вашей организации:

| Размер команды        | TPM на пользователя | RPM на пользователя |
| --------------------- | ------------------- | ------------------- |
| 1-5 пользователей     | 200k-300k           | 5-7                 |
| 5-20 пользователей    | 100k-150k           | 2.5-3.5             |
| 20-50 пользователей   | 50k-75k             | 1.25-1.75           |
| 50-100 пользователей  | 25k-35k             | 0.62-0.87           |
| 100-500 пользователей | 15k-20k             | 0.37-0.47           |
| 500+ пользователей    | 10k-15k             | 0.25-0.35           |

Например, если у вас есть 200 пользователей, вы можете запросить 20k TPM для каждого пользователя, или 4 миллиона общего TPM (200\*20,000 = 4 миллиона).

TPM на пользователя уменьшается по мере роста размера команды, потому что мы ожидаем, что в более крупных организациях меньше пользователей будут использовать Claude Code одновременно. Эти ограничения скорости применяются на уровне организации, а не для отдельного пользователя, что означает, что отдельные пользователи могут временно потреблять больше, чем их рассчитанная доля, когда другие не активно используют сервис.

<Note>
  Если вы предполагаете сценарии с необычно высокой одновременной нагрузкой (например, живые тренинги с большими группами), вам может потребоваться более высокое распределение TPM на пользователя.
</Note>

## Снижение использования токенов

* **Компактные беседы:**

  * Claude использует автоматическое сжатие по умолчанию, когда контекст превышает 95% емкости
  * Переключение автоматического сжатия: запустите `/config` и перейдите к "Auto-compact enabled"
  * Используйте `/compact` вручную, когда контекст становится большим
  * Добавьте пользовательские инструкции: `/compact Focus on code samples and API usage`
  * Настройте сжатие, добавив в CLAUDE.md:

    ```markdown  theme={null}
    # Summary instructions

    When you are using compact, please focus on test output and code changes
    ```

* **Напишите конкретные запросы:** Избегайте неопределенных запросов, которые вызывают ненужное сканирование

* **Разбейте сложные задачи:** Разделите большие задачи на сосредоточенные взаимодействия

* **Очистите историю между задачами:** Используйте `/clear` для сброса контекста

Затраты могут значительно варьироваться в зависимости от:

* Размера анализируемой кодовой базы
* Сложности запросов
* Количества файлов, которые ищутся или изменяются
* Длины истории беседы
* Частоты сжатия беседы

## Использование токенов в фоновом режиме

Claude Code использует токены для некоторой фоновой функциональности даже в режиме ожидания:

* **Суммирование беседы**: Фоновые задания, которые суммируют предыдущие беседы для функции `claude --resume`
* **Обработка команд**: Некоторые команды, такие как `/cost`, могут генерировать запросы для проверки статуса

Эти фоновые процессы потребляют небольшое количество токенов (обычно менее \$0.04 за сессию) даже без активного взаимодействия.

## Отслеживание изменений версий и обновлений

### Информация о текущей версии

Чтобы проверить текущую версию Claude Code и детали установки:

```bash  theme={null}
claude doctor
```

Эта команда показывает вашу версию, тип установки и информацию о системе.

### Понимание изменений в поведении Claude Code

Claude Code регулярно получает обновления, которые могут изменить способ работы функций, включая отчеты о затратах:

* **Отслеживание версии**: Используйте `claude doctor` для просмотра текущей версии
* **Изменения поведения**: Функции, такие как `/cost`, могут отображать информацию по-разному в разных версиях
* **Доступ к документации**: Claude всегда имеет доступ к последней документации, которая может помочь объяснить текущее поведение функции

### Когда изменяется отчетность по затратам

Если вы заметили изменения в способе отображения затрат (например, команда `/cost` показывает другую информацию):

1. **Проверьте вашу версию**: Запустите `claude doctor` для подтверждения текущей версии
2. **Обратитесь к документации**: Спросите Claude напрямую о текущем поведении функции, так как он имеет доступ к актуальной документации
3. **Свяжитесь с поддержкой**: Для конкретных вопросов по выставлению счетов обратитесь в поддержку Anthropic через вашу учетную запись Console

<Note>
  Для развертывания команд мы рекомендуем начать с небольшой пилотной группы для
  установления моделей использования перед более широким развертыванием.
</Note>
