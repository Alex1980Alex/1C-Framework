# Быстрый старт

> Создайте своего первого агента глубокого анализа за считанные минуты

В этом руководстве вы найдете пошаговое руководство по созданию вашего первого глубокого агента с функциями планирования, файловой системы и возможностями суб-агентов. Вы создадите исследовательского агента, способного проводить исследования и писать отчеты.

## Предварительные условия

Прежде чем начать, убедитесь, что у вас есть ключ API от поставщика моделей (например, Anthropic, OpenAI).

<Примечание>
  Для работы Deep Agents требуется модель, поддерживающая [вызов инструментов](/oss/python/concepts/tool-calling). См. [настройка](/oss/python/deepagents/customization#model) для получения информации о настройке вашей модели.
</Примечание>

</Примечание>

### Шаг 2: Настройте свои API-ключи

```bash theme={null}
export ANTHROPIC_API_KEY="your-api-key"
export TAVILY_API_KEY="your-tavily-api-key"
```

### Шаг 3: Создайте инструмент поиска

```python theme={null}
импорт os
from typing import Literal
from tavily import TavilyClient
from deepagents import create_deep_agent

tavily_client = TavilyClient(api_key=os.environ["TAVILY_API_KEY"])

def internet_search(
    запрос: str,
    max_results: int = 5,
    тема: Буквальный ["общий", "новости", "финансы"] = "общий",
    include_raw_content: bool = False,
):
    """Выполнить поиск в интернете"""
    return tavily_client.search(
        запрос,
        max_results=max_results,
        include_raw_content=include_raw_content,
        тема=тема,
    )
```

### Шаг 4: Создайте глубокого агента

```python theme={null}
# Системное подсказка для направления агента в режим эксперта-исследователя
research_instructions = """Вы — опытный исследователь. Ваша задача — провести тщательное исследование, а затем написать безупречный отчет."

В качестве основного средства сбора информации вы используете поисковую систему в интернете.

## `поиск_в_интернете`

Используйте это для выполнения поиска в интернете по заданному запросу. Вы можете указать максимальное количество возвращаемых результатов, тему и необходимость включения исходного контента.
"""

agent = create_deep_agent(
    инструменты=[поиск в интернете],
    system_prompt=research_instructions
)
```

### Шаг 5: Запустите агента

```python theme={null}
result = agent.invoke({"messages": [{"role": "user", "content": "What is langgraph?"}]})

# Вывести ответ агента
print(result["messages"][-1].content)
```

## Что случилось?

Ваш глубокий агент автоматически:

1. **Запланирован подход**: Использован встроенный инструмент `write_todos` для разбивки исследовательской задачи на этапы.
2. **Проведено исследование**: Для сбора информации использован инструмент `internet_search`.
3. **Управляемый контекст**: Использовались инструменты файловой системы (`write_file`, `read_file`) для разгрузки больших результатов поиска.
4. **Создание субагентов** (при необходимости): Делегирование сложных подзадач специализированным субагентам.
5. **Составили краткий отчет**: Обобщили полученные данные в связный ответ.

## Следующие шаги

Теперь, когда вы создали своего первого глубокого агента:

* **Настройте своего агента**: Узнайте о [параметрах настройки](/oss/python/deepagents/customization), включая пользовательские системные подсказки, инструменты и субагентов.
* **Разберитесь с промежуточным ПО**: Изучите архитектуру промежуточного ПО, лежащую в основе работы глубоких агентов.
* **Добавить долговременную память**: Включить [постоянную память](/oss/python/deepagents/long-term-memory) между диалогами.
* **Развертывание в производственной среде**: Узнайте о [параметрах развертывания](/oss/python/langgraph/deploy) для приложений LangGraph.
