# Долговременная память

> Узнайте, как расширять возможности агентов с глубокой памятью, используя постоянную память в разных потоках.

Глубокие агенты поставляются с локальной файловой системой для разгрузки памяти. По умолчанию эта файловая система хранится в состоянии агента и является **временной для одного потока** — файлы теряются при завершении разговора.

Вы можете расширить функциональность агентов с поддержкой **долговременной памяти**, используя `CompositeBackend`, который направляет определенные пути к постоянному хранилищу. Это позволяет использовать гибридное хранилище, где некоторые файлы сохраняются между потоками, а другие остаются временными.

```тема русалки={null}
график LR
    Агент[Глубокий Агент] --> Маршрутизатор{Маршрутизатор Пути}

    Маршрутизатор --> |/memories/*| Магазин[Бэкенд магазина]
    Маршрутизатор --> |другое| Состояние[Состояние бэкенда]

    Store --> Persist[(Persistent<br/>across threads)]
    Состояние --> Эфемерное[(Эфемерное<br/>однопоточное)]
```

## Настраивать

Настройте долговременную память, используя `CompositeBackend`, который перенаправляет путь `/memories/` к `StoreBackend`:

```python theme={null}
from deepagents import create_deep_agent
from deepagents.backends import CompositeBackend, StateBackend, StoreBackend
from langgraph.store.memory import InMemoryStore
from langgraph.checkpoint.memory import MemorySaver

checkpointer = MemorySaver()

def make_backend(runtime):
    return CompositeBackend(
        default=StateBackend(runtime), # Временное хранилище
        маршруты={
            "/memories/": StoreBackend(runtime) # Постоянное хранилище
        }
    )

agent = create_deep_agent(
    store=InMemoryStore(), # Требуется для StoreBackend
    backend=make_backend,
    контрольная точка=контрольная точка
)
```

## Как это работает

При использовании `CompositeBackend` агенты глубокого доступа поддерживают **две отдельные файловые системы**:

### 1. Кратковременная (транзиентная) файловая система

* Сохраняется в состоянии агента (через `StateBackend`)
* Сохраняется только в пределах одной нити.
* Файлы теряются при завершении потока.
* Доступ осуществляется по стандартным путям: `/notes.txt`, `/workspace/draft.md`

### 2. Долгосрочная (постоянная) файловая система

* Хранится в хранилище LangGraph (через `StoreBackend`)
* Сохраняется во всех ветках обсуждений и диалогах.
* Сохраняет работоспособность после перезапуска агента
* Доступ осуществляется через пути, начинающиеся с `/memories/`: `/memories/preferences.txt`

### Маршрутизация

`CompositeBackend` выполняет файловые операции на основе префиксов путей:

* Файлы, пути к которым начинаются с `/memories/`, хранятся в хранилище (постоянно).
* Файлы без этого префикса остаются во временном состоянии
* Все инструменты файловой системы (`ls`, `read_file`, `write_file`, `edit_file`) работают с обоими вариантами.

```python theme={null}
# Временный файл (теряется после завершения потока)
agent.invoke({
    "messages": [{"role": "user", "content": "Write draft to /draft.txt"}]
})

# Постоянный файл (сохраняется в разных потоках)
agent.invoke({
    "messages": [{"role": "user", "content": "Сохранить итоговый отчет в /memories/report.txt"}]
})
```

## Межпотоковое сохранение данных

Доступ к файлам в `/memories/` возможен из любого потока:

```python theme={null}
импорт uuid

# Поток 1: Запись в долговременную память
config1 = {"configurable": {"thread_id": str(uuid.uuid4())}}
agent.invoke({
    "messages": [{"role": "user", "content": "Save my preferences to /memories/preferences.txt"}]
}, config=config1)

# Тема 2: Чтение из долговременной памяти (другой разговор!)
config2 = {"configurable": {"thread_id": str(uuid.uuid4())}}
agent.invoke({
    "messages": [{"role": "user", "content": "Какие у меня предпочтения?"}]
}, config=config2)
# Агент может читать файл /memories/preferences.txt из первого потока
```

## Варианты использования

### Пользовательские настройки

Сохранение пользовательских настроек, которые сохраняются между сессиями:

```python theme={null}
agent = create_deep_agent(
    store=InMemoryStore(),
    backend=lambda rt: CompositeBackend(
        default=StateBackend(rt),
        routes={"/memories/": StoreBackend(rt)}
    ),
    system_prompt="""Когда пользователи сообщают вам о своих предпочтениях, сохраните их в
    /memories/user_preferences.txt, чтобы вы помнили их в будущих разговорах."""
)
```

### Инструкции по самосовершенствованию

Агент может обновлять свои инструкции на основе полученных отзывов:

```python theme={null}
agent = create_deep_agent(
    store=InMemoryStore(),
    backend=lambda rt: CompositeBackend(
        default=StateBackend(rt),
        routes={"/memories/": StoreBackend(rt)}
    ),
    system_prompt="""У вас есть файл по адресу /memories/instructions.txt с дополнительной информацией."" ...
    инструкции и предпочтения.

    Ознакомьтесь с этим файлом в начале разговора, чтобы понять предпочтения пользователей.

    Когда пользователи оставляют отзывы типа «пожалуйста, всегда делайте X» или «я предпочитаю Y»,
    "Обновите файл /memories/instructions.txt с помощью инструмента edit_file.""
)
```

Со временем файл с инструкциями накапливает пользовательские предпочтения, помогая агенту совершенствоваться.

### База знаний

Накапливайте знания в ходе многочисленных бесед:

```python theme={null}
# Беседа 1: Узнайте о проекте
agent.invoke({
    "messages": [{"role": "user", "content": "Мы разрабатываем веб-приложение с использованием React. Сохраните заметки по проекту."}]
})

# Разговор 2: Используйте эти знания
agent.invoke({
    "messages": [{"role": "user", "content": "Какой фреймворк мы используем?"}]
})
# Агент читает файл /memories/project_notes.txt из предыдущего разговора
```

### Исследовательские проекты

Сохраняйте состояние исследования между сессиями:

```python theme={null}
research_agent = create_deep_agent(
    store=InMemoryStore(),
    backend=lambda rt: CompositeBackend(
        default=StateBackend(rt),
        routes={"/memories/": StoreBackend(rt)}
    ),
    system_prompt="""Вы являетесь научным ассистентом."

    Сохраняйте результаты своих исследований в папку /memories/research/:
    - /memories/research/sources.txt - Список найденных источников
    - /memories/research/notes.txt - Ключевые выводы и заметки
    - /memories/research/report.md - Окончательный вариант отчета

    Это позволяет продолжать исследования в течение нескольких сессий."""
)
```

## Реализации магазинов

Подойдет любая реализация `BaseStore` из LangGraph:

### InMemoryStore (разработка)

Подходит для тестирования и разработки, но данные теряются при перезапуске:

```python theme={null}
from langgraph.store.memory import InMemoryStore

store = InMemoryStore()
agent = create_deep_agent(
    магазин=магазин,
    backend=lambda rt: CompositeBackend(
        default=StateBackend(rt),
        routes={"/memories/": StoreBackend(rt)}
    )
)
```

### PostgresStore (production)

Для производственной среды используйте постоянное хранилище:

```python theme={null}
from langgraph.store.postgres import PostgresStore
импорт os

# Используйте PostgresStore.from_conn_string в качестве менеджера контекста
store_ctx = PostgresStore.from_conn_string(os.environ["DATABASE_URL"])
магазин = store_ctx.__enter__()
store.setup()

agent = create_deep_agent(
    магазин=магазин,
    backend=lambda rt: CompositeBackend(
        default=StateBackend(rt),
        routes={"/memories/": StoreBackend(rt)}
    )
)
```

## Передовые методы

### Используйте описательные пути

Организуйте постоянные файлы с помощью понятных путей:

```
/memories/user_preferences.txt
/memories/research/topic_a/sources.txt
/memories/research/topic_a/notes.txt
/memories/project/requirements.md
```

### Документирование структуры памяти

Укажите агенту, что и где хранится в вашей системной подсказке:

```
Структура вашей персистентной памяти:
- /memories/preferences.txt: Пользовательские настройки и параметры
- /memories/context/: Долгосрочный контекст о пользователе
- /воспоминания/знания/: Факты и информация, усвоенные с течением времени
```

### Удаление старых данных

Внедрите периодическую очистку устаревших постоянных файлов для поддержания управляемости хранилища.

### Выберите подходящее хранилище

* **Разработка**: Используйте `InMemoryStore` для быстрой итерации.
* **Производство**: Используйте `PostgresStore` или другие хранилища данных.
* **Многопользовательская архитектура**: Рассмотрите возможность использования пространств имен на основе `assistant_id` в вашем хранилище.
