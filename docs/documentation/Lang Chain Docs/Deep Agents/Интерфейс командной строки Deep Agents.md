# Интерфейс командной строки Deep Agents

> Интерактивный интерфейс командной строки для сборки с использованием Deep Agents

Deep Agents CLI — это помощник для программистов с открытым исходным кодом, который запускается в вашем терминале и сохраняет данные в постоянной памяти.
Ваши агенты командной строки поддерживают контекст между сессиями, изучают проектные соглашения, используют настраиваемые навыки и выполняют код с контролем авторизации.

Интерфейс командной строки Deep Agents обладает следующими встроенными возможностями:

* <Icon icon="file" size={16} /> **Операции с файлами** - чтение, запись и редактирование файлов в вашем проекте с помощью инструментов, позволяющих агентам управлять кодом и документацией и изменять их.
* <Icon icon="terminal" size={16} /> **Выполнение команд оболочки** - выполнение команд оболочки для запуска тестов, сборки проектов, управления зависимостями и взаимодействия с системами контроля версий.
* <Icon icon="magnifying-glass" size={16} /> **Поиск в интернете** - поиск в интернете актуальной информации и документации (требуется ключ API Tavily).
* <Icon icon="globe" size={16} /> **HTTP-запросы** - выполнение HTTP-запросов к API и внешним сервисам для получения данных и задач интеграции.
* <Icon icon="list-check" size={16} /> **Планирование и отслеживание задач** - разбейте сложные задачи на отдельные этапы и отслеживайте прогресс с помощью встроенной системы задач.
* <Icon icon="brain" size={16} /> **Хранение и извлечение информации из памяти** - хранение и извлечение информации между сессиями, позволяющее агентам запоминать проектные соглашения и изученные шаблоны.
* <Icon icon="head-side" size={16} /> **Участие человека** - требуется одобрение человека для выполнения конфиденциальных операций с инструментом.
* <Icon icon="puzzle-piece" size={16} /> **Навыки** - расширяют возможности агента за счет пользовательских знаний и инструкций, хранящихся в каталогах навыков.

## Трассировка с помощью LangSmith

Включите трассировку LangSmith, чтобы видеть операции агента на панели мониторинга LangSmith:

1. Включите трассировку LangSmith:

   ```bash theme={null}
   export LANGCHAIN_TRACING=true
   export LANGCHAIN_API_KEY="your-api-key"
   ```

2. Настройте трассировку агента для сложных операций с агентом, таких как вызовы инструментов и решения агента:

   ```bash theme={null}
   export DEEPAGENTS_LANGSMITH_PROJECT="my-deep-agent-execution"
   ```

3. Если вы разрабатываете приложение LangChain с глубокими агентами и хотите отделить трассировку агентов от трассировки вашего приложения, также настройте параметр `LANGSMITH_PROJECT`:

   ```bash theme={null}
   export LANGSMITH_PROJECT="my-app-calls-to-langchain"
   ```

После настройки интерфейс командной строки отображает следующее:

```sh theme={null}
✓ Трассировка LangSmith: 'my-project'
```

## Конфигурация

У каждого агента есть свой собственный каталог конфигурации по адресу `~/.deepagents/<agent_name>/`.
Имя агента по умолчанию — `agent`.
Если при запуске агента папка с именем агента отсутствует, она будет создана по пути `~/.deepagents/<new_agent>/`.

```bash theme={null}
# Список всех настроенных агентов
список deepagents

# Использовать определенную конфигурацию агента
deepagents --agent mybot

# Использовать конкретную модель (автоматическое определение поставщика)
deepagents --model claude-sonnet-4-5-20250929
deepagents --model gpt-4o

# Автоматическое одобрение использования инструмента (без запросов от человека)
deepagents --автоматическое одобрение

# Выполнение кода в удалённой песочнице
deepagents --sandbox modal # or runloop, daytona
deepagents --sandbox-id dbx_123 # повторное использование существующей песочницы
```

## Обучите своих агентов правилам работы с проектами

В процессе использования агент автоматически сохраняет информацию в `~/.deepagents/<agent_name>/memories/` в виде файлов Markdown, используя протокол приоритета памяти:

1. **Исследование**: Перед началом выполнения задач выполняет поиск в памяти соответствующего контекста.
2. **Ответ**: При возникновении неопределенности во время выполнения проверяет память.
3. **Обучение**: Автоматически сохраняет новую информацию для будущих сессий.

Агент организует свою память по темам, используя описательные имена файлов:

```
~/.deepagents/backend-dev/memories/
├── api-conventions.md
├── database-schema.md
└── deployment-process.md
```

Когда вы обучаете агентов правилам работы с агентами:

```bash theme={null}
uvx deepagents-cli --agent backend-dev
Наш API использует стиль snake_case и включает временные метки created_at/updated_at.
```

Программа запоминает информацию для будущих сессий:

```bash theme={null}
> Создайте конечную точку /users
# Применяет соглашения без запроса подтверждения
```

## Настройка вашего глубокого агента

Существует два основных способа настройки любого агента:

* **Память**: глобальные и специфичные для проекта файлы `AGENTS.md`, которые загружаются полностью при запуске сессии.
  Используйте память для определения общего стиля кодирования и ваших предпочтений.

* **Навыки**: Глобальный и специфический для проекта контекст, соглашения, руководящие принципы или инструкции.
  Используйте навыки в контексте, необходимом только при выполнении конкретных задач.

### Предоставьте контекст проекта или пользователя

Файлы [`AGENTS.md`](https://agents.md/) обеспечивают постоянную память, которая всегда загружается при запуске сессии.

Вы можете указать глобальную пользовательскую память для агента в файле `~/.deepagents/<agent_name>/AGENTS.md`.
Этот файл всегда загружается при запуске новой сессии глубокого агента.
Агент также может считывать свои файлы памяти при ответе на вопросы, касающиеся конкретного проекта, или когда вы ссылаетесь на прошлые работы или шаблоны.

Для управления памятью, специфичной для проекта, вы можете добавить контекст в файл `.deepagents/AGENTS.md` в корневой папке любого проекта, при условии, что проект использует Git.
При запуске CLI из любой папки проекта, CLI найдет корневую папку проекта, проверив наличие содержащейся в ней папки `.git`.

Глобальный и проектный файлы `AGENTS.md` загружаются одновременно и добавляются в командную строку системы при запуске.
Агент будет обновлять их по мере использования, предоставляя дополнительную информацию о том, как он должен себя вести, отзывы о своей работе или инструкции по запоминанию чего-либо.
Агент также будет обновлять свою память, если обнаружит закономерности или предпочтения в ваших взаимодействиях.

Если вы хотите явно указать своему глубокому агенту обновить навыки и память на основе текущего контекста из потока, используйте команду `/remember`, которая загружает пользовательскую инструкцию для проверки контекста и выполнения обновлений.

Для добавления более структурированной информации о проекте в дополнительные файлы памяти вы можете добавить их в `.deepagents/` и сослаться на них в файле `AGENTS.md`.
Для того чтобы агент знал об этих файлах, необходимо указать ссылки на дополнительные файлы в файле `AGENTS.md`.
Дополнительные файлы не будут считываться при запуске, но агент сможет ссылаться на них и обновлять их по мере необходимости.

<Заголовок аккордеона="Когда использовать глобальные, а когда проектные `AGENTS.md`">
  **Глобальный файл `AGENTS.md`** (`~/.deepagents/agent/AGENTS.md`)

  * Ваша личность, стиль и общие предпочтения в программировании
  * Общий тон и стиль общения
  * Универсальные параметры кодирования (форматирование, подсказки типов и т. д.)
  * Шаблоны использования инструментов, применимые повсюду
  * Рабочие процессы и методологии, которые не меняются от проекта к проекту

  **Проект `AGENTS.md`** (`.deepagents/AGENTS.md` в корне проекта)

  * Контекст и соглашения, специфичные для проекта
  * Архитектура проекта и шаблоны проектирования
  * Соглашения об условиях кодирования, специфичные для этой кодовой базы
  * Стратегии тестирования и процессы развертывания
  * Руководящие принципы работы команды и структура проекта
</Аккордеон>

## Использование удалённых песочниц

Выполнение кода в изолированных удаленных средах обеспечивает безопасность и гибкость. Удаленные песочницы предоставляют следующие преимущества:

* **Безопасность**: Защитите свой локальный компьютер от выполнения потенциально вредоносного кода.
* **Чистая среда**: Используйте определенные зависимости или конфигурации ОС без локальной настройки.
* **Параллельное выполнение**: Запуск нескольких агентов одновременно в изолированных средах.
* **Длительно выполняющиеся задачи**: Выполняйте ресурсоемкие операции, не блокируя работу компьютера.
* **Воспроизводимость**: Обеспечьте согласованную среду выполнения во всех командах.

Для использования удалённой песочницы выполните следующие действия:

1. Настройте поставщика тестовой среды ([Runloop](https://www.runloop.ai/), [Daytona](https://www.daytona.io/) или [Modal](https://modal.com/)):

   ```bash theme={null}
   # Runloop
   export RUNLOOP_API_KEY="your-key"

   # Дейтона
   export DAYTONA_API_KEY="your-key"

   # Модальное окно
   модальная настройка
   ```

2. Запустите CLI в изолированной среде:

   ```bash theme={null}
   uvx deepagents-cli --sandbox runloop --sandbox-setup ./setup.sh
   ```

   Агент работает локально, но все операции с кодом выполняются в удаленной песочнице. Дополнительные скрипты настройки позволяют конфигурировать переменные среды, клонировать репозитории и подготавливать зависимости.

3. (Необязательно) Создайте файл `setup.sh` для настройки вашей песочницы:

   ```bash theme={null}
   #!/bin/bash
   set -e

   # Клонирование репозитория с использованием токена GitHub
   git clone https://x-access-token:${GITHUB_TOKEN}@github.com/username/repo.git $HOME/workspace
   cd $HOME/workspace

   # Сделать переменные окружения постоянными
   cat >> ~/.bashrc <<'EOF'
   export GITHUB_TOKEN="${GITHUB_TOKEN}"
   экспортировать OPENAI_API_KEY="${OPENAI_API_KEY}"
   cd $HOME/workspace
   EOF

   источник ~/.bashrc
   ```

   Сохраните секреты в локальном файле `.env`, чтобы скрипт настройки мог получить к ним доступ.

<Предупреждение>
  Песочницы изолируют выполнение кода, но агенты остаются уязвимыми для внедрения запросов с использованием недоверенных входных данных. Используйте только подтверждение от человека, кратковременные секреты и доверенные скрипты настройки.

  Следует отметить, что API песочниц быстро развиваются, и мы ожидаем, что все больше поставщиков будут поддерживать прокси-серверы, которые помогут снизить риски внедрения запросов и проблем с управлением секретами.
</Предупреждение>

## Используйте навыки

Навыки — это многократно используемые возможности агентов, которые обеспечивают специализированные рабочие процессы и знания в предметной области.
Вы можете использовать [skills](/oss/python/deepagents/skills), чтобы наделить своего глубокого агента новыми возможностями и экспертными знаниями.
Глубокие навыки работы с агентами соответствуют [стандарту Agent Skills](https://agentskills.io/).
После добавления навыков ваш агент автоматически начнет их использовать и обновлять по мере вашего взаимодействия с ним, а также предоставлять ему дополнительную информацию.

Если вы хотите явно указать своему глубокому агенту обновить навыки и память на основе текущего контекста из потока, используйте команду `/remember`, которая загружает пользовательскую инструкцию для проверки контекста и выполнения обновлений.

### Добавить навыки

1. Начните с создания навыка:

   <Вкладки>
     <Tab title="Навыки пользователя">
       ```bash theme={null}
       Навыки deepagents создают навыки тестирования
       ```

       В результате в папке `~/.deepagents/<agent_name>` будут сгенерированы следующие файлы:
     </Tab>

     <Tab title="Навыки проекта">
       ```bash theme={null}
       deepagents skills create test-kill --project
       ```

       В результате в папке `~/{project}/.deepagents/skills` будут сгенерированы следующие файлы:
     </Tab>
   </Вкладки>

   ```plaintext theme={null}
   навыки/
   └── тест-навык
       └── SKILL.md
   ```

2. Откройте сгенерированный файл `SKILL.md` и отредактируйте его, добавив свои инструкции.

3. При желании можно добавить дополнительные скрипты или другие ресурсы в папку `test-skill`.
   Для получения дополнительной информации см. [Примеры](/oss/python/deepagents/skills#examples).

Если у вас уже есть папка с навыками, содержащая файлы навыков, вы также можете скопировать их непосредственно в папку агента:

```bash theme={null}
mkdir -p ~/.deepagents/<agent_name>/skills
cp -r examples/skills/web-research ~/.deepagents/<agent_name>/skills/
```

При запуске CLI сканирует каталоги `~/.deepagents/<agent_name>/skills/` и `.deepagents/skills/`.
Для навыков, специфичных для проекта, в корневой папке проекта должна быть папка `.git`.
При запуске CLI из любой папки проекта, CLI найдет корневую папку проекта, проверив наличие содержащейся в ней папки `.git`.

Для каждого навыка интерфейс командной строки считывает имя и описание из метаданных файла `SKILL.md`.
При использовании интерфейса командной строки, если задача соответствует описанию навыка, агент прочтет файл навыка и будет следовать его инструкциям.
