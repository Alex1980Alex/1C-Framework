# Навыки

> Узнайте, как расширить возможности вашего глубокого агента с помощью навыков.

Навыки — это многократно используемые возможности агентов, которые обеспечивают специализированные рабочие процессы и знания в предметной области.
Вы можете использовать [Agent Skills](https://agentskills.io/), чтобы наделить своего агента новыми возможностями и экспертными знаниями.
Глубокие навыки работы с агентами соответствуют [стандарту Agent Skills](https://agentskills.io/).

## Что такое навыки

Навыки представляют собой каталог папок, в каждой из которых находится один или несколько файлов, содержащих контекст, который может использовать агент:

* Файл `SKILL.md`, содержащий инструкции и метаданные о навыке.
* Дополнительные скрипты (необязательно)
* Дополнительная справочная информация, например, документы (необязательно)
* Дополнительные ресурсы, такие как шаблоны и другие материалы (необязательно)

## Как работают навыки

При создании агента с глубокими настройками вы можете передать список каталогов, содержащих навыки.
При запуске агент считывает вводную часть каждого файла `SKILL.md`.

Когда агент получает подсказку, он проверяет, может ли он использовать какие-либо навыки при выполнении этой подсказки.
Если система находит соответствующее сообщение, она затем просматривает остальные файлы навыков.
Такой подход, при котором информация о навыках проверяется только по мере необходимости, называется поэтапным раскрытием информации.

## Примеры

У вас может быть папка с навыками, содержащая навык использования сайта с документами определенным образом, а также другой навык для поиска в репозитории препринтов научных статей arXiv:

```plaintext theme={null}
    навыки/
    ├── langgraph-docs
    │ └── SKILL.md
    └── arxiv_search
        ├── SKILL.md
        └── arxiv_search.ts # код для поиска на arXiv
```

Файл `SKILL.md` всегда имеет один и тот же шаблон, начиная с метаданных в начале файла и заканчивая инструкциями для навыка.
В следующем примере показан навык, который дает инструкции о том, как предоставлять соответствующие документы Langgraph по запросу:

```md theme={null}
---
имя: langgraph-docs
Описание: Используйте этот навык для запросов, связанных с LangGraph, чтобы получить необходимую документацию и предоставить точные и актуальные рекомендации.
---

## Обзор

В этом разделе объясняется, как получить доступ к документации LangGraph Python, чтобы ответить на вопросы и получить рекомендации по реализации.

## Инструкции

### 1. Получите указатель документации

Воспользуйтесь инструментом fetch_url, чтобы прочитать следующий URL-адрес:
https://docs.langchain.com/llms.txt

Здесь представлен структурированный список всей доступной документации с описаниями.

### 2. Выберите соответствующую документацию

Исходя из вопроса, определите 2-4 наиболее релевантных URL-адреса документации из индекса. Расставьте приоритеты:

- Подробные пошаговые инструкции по вопросам внедрения.
- Страницы с основными понятиями для понимания вопросов
- Учебные пособия с примерами полного цикла реализации
- Справочная документация для получения подробной информации об API.

### 3. Получить выбранную документацию

Используйте инструмент fetch_url для чтения выбранных URL-адресов документации.

### 4. Предоставлять точные указания

После ознакомления с документацией выполните запрос пользователя.
```

<ParamField body="skills" type="list[str]" optional>
  Список путей к источникам навыков. Пути должны быть указаны с использованием косых черт и являются относительными по отношению к корневому каталогу бэкэнда.

  * При использовании StateBackend (по умолчанию) предоставьте файлы навыков с помощью `invoke(files={...})`.
  * При использовании FilesystemBackend навыки загружаются с диска относительно корневого каталога бэкенда.

  Более поздние источники имеют приоритет над более ранними для навыков с тем же названием (последний источник имеет приоритет).
</ParamField>

## Когда использовать навыки и инструменты

Вот несколько общих рекомендаций по использованию инструментов и навыков:

* Используйте навыки, когда контекст достаточно подробный, чтобы уменьшить количество токенов в системном запросе.
* Используйте навыки для объединения возможностей в более масштабные действия и предоставления дополнительного контекста, выходящего за рамки описания отдельных инструментов.
* Используйте дополнительные инструменты, если у агента нет доступа к файловой системе.
