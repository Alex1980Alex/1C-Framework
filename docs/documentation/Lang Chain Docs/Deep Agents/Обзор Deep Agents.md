# Обзор Deep Agents

> Создавайте агентов, способных планировать, использовать субагентов и применять файловые системы для решения сложных задач.

[`deepagents`](https://pypi.org/project/deepagents/) — это автономная библиотека для создания агентов, способных решать сложные многоэтапные задачи. Созданная на основе LangGraph и вдохновленная такими приложениями, как Claude Code, Deep Research и Manus, библиотека deep agents обладает возможностями планирования, файловыми системами для управления контекстом и возможностью создания подагентов.

## Когда использовать глубокие агенты

Используйте агентов с глубокими знаниями, когда вам нужны агенты, способные:

* **Выполнение сложных, многоэтапных задач**, требующих планирования и декомпозиции.
* **Управление большими объемами контекстной информации** с помощью инструментов файловой системы.
* **Делегировать работу** специализированным субагентам для изоляции контекста
* **Сохранение памяти** между разговорами и ветками обсуждений

Для более простых случаев использования рассмотрите возможность применения функции [`create_agent`](/oss/python/langchain/agents) в LangChain или создания собственного рабочего процесса [LangGraph](/oss/python/langgraph/overview).

## Основные возможности

<Card title="Планирование и декомпозиция задач" icon="timeline">
  В состав Deep Agents входит встроенный инструмент `write_todos`, позволяющий агентам разбивать сложные задачи на отдельные этапы, отслеживать прогресс и корректировать планы по мере появления новой информации.
</Карточка>

<Card title="Управление контекстом" icon="ножницы">
  Инструменты файловой системы (`ls`, `read_file`, `write_file`, `edit_file`) позволяют агентам выгружать большой контекст в память, предотвращая переполнение контекстного окна и обеспечивая работу с результатами инструментов переменной длины.
</Карточка>

<Card title="Появление субагента" icon="people-group">
  Встроенный инструмент `task` позволяет агентам создавать специализированных субагентов для изоляции контекста. Это позволяет сохранить контекст основного агента чистым, одновременно обеспечивая глубокое выполнение конкретных подзадач.
</Карточка>

<Card title="Долговременная память" icon="база данных">
  Расширяйте возможности агентов, используя постоянную память для работы в разных потоках с помощью хранилища LangGraph. Агенты могут сохранять и извлекать информацию из предыдущих разговоров.
</Карточка>

## Связь с экосистемой LangChain

Deep Agents построен на основе:

* [LangGraph](/oss/python/langgraph/overview) - Обеспечивает выполнение базового графа и управление состоянием.
* [LangChain](/oss/python/langchain/overview) - Инструменты и интеграция моделей беспрепятственно работают с глубокими агентами.
* [LangSmith](/langsmith/home) - Наблюдаемость, оценка и развертывание

Приложения Deep Agent можно развертывать с помощью [LangSmith Deployment](/langsmith/deployments) и отслеживать с помощью [LangSmith Observability](/langsmith/observability).
