# Быстрый старт

Этот краткий курс позволит вам всего за несколько минут перейти от простой настройки к полноценному агенту искусственного интеллекта.

<Совет>
  **Сервер LangChain Docs MCP**

  Если вы используете ИИ-помощника в программировании или IDE (например, Claude Code или Cursor), вам следует установить [сервер LangChain Docs MCP](/use-these-docs), чтобы максимально эффективно его использовать. Это гарантирует, что ваш агент будет иметь доступ к актуальной документации и примерам LangChain.
</Совет>

## Требования

Для этих примеров вам потребуется:

* [Установите](/oss/python/langchain/install) пакет LangChain
* Создайте учетную запись [Claude (Anthropic)](https://www.anthropic.com/) и получите ключ API.
* Установите переменную среды `ANTHROPIC_API_KEY` в терминале.

Хотя в этих примерах используется модель Claude, вы можете использовать [любую поддерживаемую модель](/oss/python/integrations/providers/overview), изменив имя модели в коде и указав соответствующий ключ API.

## Создание базового агента

Начните с создания простого агента, который сможет отвечать на вопросы и вызывать инструменты. Агент будет использовать модель языка Клода Соннета 4.5, базовую функцию прогноза погоды в качестве инструмента и простую подсказку для управления своим поведением.

```python theme={null}
from langchain.agents import create_agent

def get_weather(city: str) -> str:
    «Получите информацию о погоде для конкретного города».
    return f"В {городе} всегда солнечно!"

агент = create_agent(
    model="claude-sonnet-4-5-20250929",
    инструменты=[get_weather],
    system_prompt="Вы полезный помощник",
)

# Запуск агента
agent.invoke(
    {"messages": [{"role": "user", "content": "what is the weather in sf"}]}
)
```

<Совет>
  Чтобы узнать, как отслеживать действия вашего агента с помощью LangSmith, см. [документацию LangSmith](/langsmith/trace-with-langchain).
</Совет>

## Создайте реального агента

Далее, создайте практичного агента прогнозирования погоды, демонстрирующего ключевые производственные концепты:

1. **Подробные системные подсказки** для улучшения работы агента.
2. **Создать инструменты**, интегрирующиеся с внешними данными.
3. **Конфигурация модели** для обеспечения согласованных ответов
4. **Структурированный вывод** для предсказуемых результатов.
5. **Разговорная память** для общения в чате.
6. **Создайте и запустите агента**, чтобы протестировать его полную работоспособность.

Давайте рассмотрим каждый шаг:

<Шаги>
  <Заголовок шага="Определите системную подсказку">
    Системное сообщение определяет роль и поведение вашего агента. Будьте конкретны и предлагайте конкретные действия:

    ```python wrap theme={null}
    SYSTEM_PROMPT = """Вы — опытный синоптик, который любит каламбуры."

    Вам доступны два инструмента:

    - get_weather_for_location: используйте эту функцию, чтобы получить погоду для конкретного места.
    - get_user_location: используйте эту функцию для получения местоположения пользователя.

    Если пользователь спрашивает вас о погоде, убедитесь, что вы знаете его местоположение. Если из вопроса вы понимаете, что он имеет в виду место, где находится, используйте инструмент get_user_location, чтобы определить его местоположение.
    ```
  </Шаг>

  <Шаг title="Создать инструменты">
    [Инструменты](/oss/python/langchain/tools) позволяют модели взаимодействовать с внешними системами, вызывая определенные вами функции.
    Инструменты могут зависеть от [контекста среды выполнения](/oss/python/langchain/runtime), а также взаимодействовать с [памятью агента](/oss/python/langchain/short-term-memory).

    Обратите внимание, как инструмент `get_user_location` использует контекст времени выполнения:

    ```python theme={null}
    from dataclasses import dataclass
    from langchain.tools import tool, ToolRuntime

    @инструмент
    def get_weather_for_location(city: str) -> str:
        «Получите информацию о погоде для конкретного города».
        return f"В {городе} всегда солнечно!"

    @dataclass
    Контекст класса:
        «Настраиваемая схема контекста среды выполнения».
        user_id: str

    @инструмент
    def get_user_location(runtime: ToolRuntime[Context]) -> str:
        «Получение информации о пользователе на основе его идентификатора».
        user_id = runtime.context.user_id
        Возвращать "Florida", если user_id == "1", иначе "SF"
    ```

    <Совет>
      Инструменты должны быть хорошо документированы: их название, описание и имена аргументов становятся частью запроса модели.
      Декоратор ``@tool` из библиотеки LangChain добавляет метаданные и позволяет внедрять их во время выполнения с помощью параметра `ToolRuntime`.
    </Совет>
  </Шаг>

  <Шаг title="Настройте свою модель">
    Настройте свою [языковую модель](/oss/python/langchain/models) с правильными параметрами для вашего конкретного случая:

    ```python theme={null}
    from langchain.chat_models import init_chat_model

    модель = init_chat_model(
        "claude-sonnet-4-5-20250929",
        температура = 0,5,
        timeout=10,
        max_tokens=1000
    )
    ```

    В зависимости от выбранной модели и поставщика, параметры инициализации могут различаться; подробную информацию см. на соответствующих справочных страницах.
  </Шаг>

  <Заголовок шага="Определить формат ответа">
    При необходимости можно задать структурированный формат ответа, если требуется, чтобы ответы агента совпадали.
    конкретная схема.

    ```python theme={null}
    from dataclasses import dataclass

    # Здесь мы используем класс данных, но модели Pydantic также поддерживаются.
    @dataclass
    класс ResponseFormat:
        «Схема ответа для агента».
        # Ответ с игрой слов (всегда обязателен)
        punny_response: str
        # Любая интересная информация о погоде, если таковая имеется
        weather_conditions: str | None = None
    ```
  </Шаг>

  <Шаг title="Добавить память">
    Добавьте [память](/oss/python/langchain/short-term-memory) к вашему агенту, чтобы поддерживать состояние между взаимодействиями. Это позволяет
    Агент способен запоминать предыдущие разговоры и контекст.

    ```python theme={null}
    from langgraph.checkpoint.memory import InMemorySaver

    checkpointer = InMemorySaver()
    ```

    <Информация>
      В производственной среде используйте постоянный контрольный указатель, который сохраняет историю сообщений в базу данных.
      Дополнительные сведения см. в разделе [Добавление и управление памятью](/oss/python/langgraph/add-memory#manage-short-term-memory).
    </Info>
  </Шаг>

  <Шаг title="Создание и запуск агента">
    Теперь соберите свой агент со всеми компонентами и запустите его!

    ```python theme={null}
    from langchain.agents.structured_output import ToolStrategy

    агент = create_agent(
        модель=модель,
        system_prompt=SYSTEM_PROMPT,
        tools=[get_user_location, get_weather_for_location],
        context_schema=Context,
        response_format=ToolStrategy(ResponseFormat),
        контрольная точка=контрольная точка
    )

    # `thread_id` — это уникальный идентификатор для данной беседы.
    config = {"configurable": {"thread_id": "1"}}

    response = agent.invoke(
        {"messages": [{"role": "user", "content": "what is the weather outside?"}]},
        config=config,
        context=Context(user_id="1")
    )

    print(response['structured_response'])
    # ResponseFormat(

    #weather_conditions="Во Флориде всегда солнечно!"
    # )


    Обратите внимание, что мы можем продолжить разговор, используя тот же `thread_id`.

        config=config,
        context=Context(user_id="1")
    )

    print(response['structured_response'])
    ```
