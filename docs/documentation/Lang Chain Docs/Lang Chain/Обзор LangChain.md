# Обзор LangChain

LangChain — это фреймворк с открытым исходным кодом, имеющий готовую архитектуру агентов и интеграцию с любыми моделями или инструментами, что позволяет создавать агентов, которые адаптируются так же быстро, как и развивается экосистема.

LangChain — это самый простой способ начать создавать агентов и приложения на основе моделей обучения с ограниченным опытом (LLM). Всего за 10 строк кода вы можете подключиться к OpenAI, Anthropic, Google и [и многим другим](/oss/python/integrations/providers/overview). LangChain предоставляет готовую архитектуру агентов и интеграцию моделей, чтобы помочь вам быстро начать работу и беспрепятственно интегрировать LLM в ваши агенты и приложения.

Мы рекомендуем использовать LangChain, если вы хотите быстро создавать агентов и автономные приложения. Используйте [LangGraph](/oss/python/langgraph/overview), нашу низкоуровневую среду выполнения для оркестрации агентов, если у вас более сложные задачи, требующие сочетания детерминированных и агентных рабочих процессов, значительной кастомизации и тщательно контролируемой задержки.

Агенты LangChain (/oss/python/langchain/agents) построены на основе LangGraph и обеспечивают надежное выполнение, потоковую передачу данных, участие человека в процессе, сохранение данных и многое другое. Для базового использования агентов LangChain знание LangGraph не требуется.

## <Icon icon="wand-magic-sparkles" /> Создать агента

```python theme={null}
# pip install -qU langchain "langchain[anthropic]"
from langchain.agents import create_agent

def get_weather(city: str) -> str:
    «Получите информацию о погоде для конкретного города».
    return f"В {городе} всегда солнечно!"

агент = create_agent(
    model="claude-sonnet-4-5-20250929",
    инструменты=[get_weather],
    system_prompt="Вы полезный помощник",
)

# Запуск агента
agent.invoke(
    {"messages": [{"role": "user", "content": "what is the weather in sf"}]}
)
```

Чтобы начать создавать собственные агенты и приложения с помощью LangChain, ознакомьтесь с [инструкциями по установке](/oss/python/langchain/install) и [руководством по быстрому запуску](/oss/python/langchain/quickstart).
