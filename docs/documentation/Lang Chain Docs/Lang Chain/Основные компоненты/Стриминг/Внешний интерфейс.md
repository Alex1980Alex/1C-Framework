# Внешний интерфейс

> Создавайте генеративные пользовательские интерфейсы с потоковой передачей данных в реальном времени от агентов LangChain, графов LangGraph и пользовательских API.

React-хук `useStream` обеспечивает бесшовную интеграцию с возможностями потоковой обработки данных LangGraph. Он берет на себя все сложности потоковой обработки, управления состоянием и логики ветвления, позволяя вам сосредоточиться на создании превосходных генеративных пользовательских интерфейсов.

Основные характеристики:

* <Icon icon="messages" size={16} /> **Потоковая передача сообщений** — Обработка потока фрагментов сообщений для формирования полного сообщения
* <Icon icon="arrows-rotate" size={16} /> **Автоматическое управление состоянием** — для сообщений, прерываний, состояний загрузки и ошибок
* <Icon icon="code-branch" size={16} /> **Разветвление диалога** — Создавайте альтернативные пути диалога из любой точки истории чата
* <Icon icon="palette" size={16} /> **Дизайн, не зависящий от пользовательского интерфейса** — Используйте собственные компоненты и стили

## Основные правила использования

Хук `useStream` подключается к любому графу LangGraph, независимо от того, запущен ли он на вашей собственной конечной точке или развернут с помощью [развертываний LangSmith](/langsmith/deployments).

```tsx theme={null}
import { useStream } from "@langchain/langgraph-sdk/react";

функция Chat() {
  const stream = useStream({
    assistantId: "agent",
    // Локальная разработка
    apiUrl: "http://localhost:2024",
    // Развертывание в производственной среде (на сервере LangSmith)
    // apiUrl: "https://your-deployment.us.langgraph.app"
  });

  const handleSubmit = (message: string) => {
    stream.submit({
      сообщения: [
        { content: message, type: "human" }
      ],
    });
  };

  возвращаться (
    <div>
      {stream.messages.map((message, idx) => (
        <div key={message.id ?? idx}>
          {message.type}: {message.content}
        </div>
      ))}

      {stream.isLoading && <div>Загрузка...</div>}
      {stream.error && <div>Ошибка: {stream.error.message}</div>}
    </div>
  );
}
```

## Управление потоками

Отслеживайте ход обсуждений с помощью встроенной системы управления потоками. Вы можете получить доступ к идентификатору текущего потока и получать уведомления о создании новых потоков:

```tsx theme={null}
import { useState } from "react";
import { useStream } from "@langchain/langgraph-sdk/react";

функция Chat() {
  const [threadId, setThreadId] = useState<string | null>(null);

  const stream = useStream({
    apiUrl: "http://localhost:2024",
    assistantId: "agent",
    threadId: threadId,
    onThreadId: setThreadId,
  });

  // Идентификатор потока обновляется при создании нового потока
  // Сохраните это в параметрах URL или в localStorage для обеспечения постоянного хранения.
}
```

Мы рекомендуем сохранять `threadId`, чтобы пользователи могли возобновить беседу после обновления страницы.

### Возобновление после обновления страницы

Хук `useStream` может автоматически возобновлять текущий запуск после монтирования, установив параметр `reconnectOnMount: true`. Это полезно для продолжения потока после обновления страницы, гарантируя, что сообщения и события, сгенерированные во время простоя, не будут потеряны.

```tsx theme={null}
const stream = useStream({
  apiUrl: "http://localhost:2024",
  assistantId: "agent",
  reconnectOnMount: true,
});
```

По умолчанию идентификатор созданного запуска хранится в `window.sessionStorage`, который можно изменить, передав пользовательскую функцию хранения:

```tsx theme={null}
const stream = useStream({
  apiUrl: "http://localhost:2024",
  assistantId: "agent",
  reconnectOnMount: () => window.localStorage,
});
```

Для ручного управления процессом возобновления используйте функции обратного вызова run для сохранения метаданных и `joinStream` для возобновления работы:

```tsx theme={null}
import { useStream } from "@langchain/langgraph-sdk/react";
import { useEffect, useRef } from "react";

function Chat({ threadId }: { threadId: string | null }) {
  const stream = useStream({
    apiUrl: "http://localhost:2024",
    assistantId: "agent",
    threadId,
    onCreated: (run) => {
      // Сохранение идентификатора запуска при начале трансляции
      window.sessionStorage.setItem(`resume:${run.thread_id}`, run.run_id);
    },
    onFinish: (_, run) => {
      // Очистка ресурсов после завершения трансляции
      window.sessionStorage.removeItem(`resume:${run?.thread_id}`);
    },
  });

  // Возобновить потоковое воспроизведение при монтировании, если сохранен идентификатор запуска.
  const joinedThreadId = useRef<string | null>(null);
  useEffect(() => {
    if (!threadId) return;
    const runId = window.sessionStorage.getItem(`resume:${threadId}`);
    if (runId && joinedThreadId.current !== threadId) {
      stream.joinStream(runId);
      joinedThreadId.current = threadId;
    }
  }, [threadId]);

  const handleSubmit = (text: string) => {
    // Используйте streamResumable, чтобы гарантировать, что события не будут потеряны.
    stream.submit(
      { messages: [{ type: "human", content: text }] },
      { streamResumable: true }
    );
  };
}
```

## Оптимистичные обновления

Вы можете оптимистично обновить состояние клиента перед выполнением сетевого запроса, обеспечивая немедленную обратную связь с пользователем:

```tsx theme={null}
const stream = useStream({
  apiUrl: "http://localhost:2024",
  assistantId: "agent",
});

const handleSubmit = (text: string) => {
  const newMessage = { type: "human" as const, content: text };

  stream.submit(
    { messages: [newMessage] },
    {
      optimisticValues(prev) {
        const prevMessages = prev.messages ?? [];
        return { ...prev, messages: [...prevMessages, newMessage] };
      },
    }
  );
};
```

### Создание оптимистичного потока

Используйте параметр `threadId` в параметре `submit`, чтобы включить оптимистичные шаблоны пользовательского интерфейса, в которых идентификатор потока необходимо знать до его создания:

```tsx theme={null}
import { useState } from "react";
import { useStream } from "@langchain/langgraph-sdk/react";

функция Chat() {
  const [threadId, setThreadId] = useState<string | null>(null);
  const [optimisticThreadId] = useState(() => crypto.randomUUID());

  const stream = useStream({
    apiUrl: "http://localhost:2024",
    assistantId: "agent",
    threadId,
    onThreadId: setThreadId,
  });

  const handleSubmit = (text: string) => {
    // Переход к следующему потоку происходит немедленно, без ожидания его создания.
    window.history.pushState({}, "", `/threads/${optimisticThreadId}`);

    // Создать поток с заданным идентификатором
    stream.submit(
      { messages: [{ type: "human", content: text }] },
      { threadId: optimisticThreadId }
    );
  };
}
```

### Отображение кэшированного потока

Используйте параметр `initialValues`, чтобы отображать кэшированные данные потоков немедленно, пока история загружается с сервера:

```tsx theme={null}
function Chat({ threadId, cachedData }) {
  const stream = useStream({
    apiUrl: "http://localhost:2024",
    assistantId: "agent",

  });
```

Ветвление

Создавайте альтернативные пути диалога, редактируя предыдущие сообщения или генерируя ответы ИИ заново. Используйте `getMessagesMetadata()` для доступа к информации о контрольных точках для ветвления:

<CodeGroup>
  ```tsx Chat.tsx theme={null}
  import { useStream } from "@langchain/langgraph-sdk/react";
  import { BranchSwitcher } from "./BranchSwitcher";

  функция Chat() {
    const stream = useStream({
      apiUrl: "http://localhost:2024",
      assistantId: "agent",
    });

    возвращаться (
      <div>
        {stream.messages.map((message) => {
          const meta = stream.getMessagesMetadata(message);
          const parentCheckpoint = meta?.firstSeenState?.parent_checkpoint;

          возвращаться (
            <div key={message.id}>
              <div>{message.content as string}</div>

              {/* Редактировать сообщения, оставленные человеком */}
              {message.type === "human" && (
                <кнопка
                  onClick={() => {
                    const newContent = prompt("Редактировать сообщение:", message.content as string);
                    if (newContent) {
                      stream.submit(
                        { messages: [{ type: "human", content: newContent }] },
                        { checkpoint: parentCheckpoint }
                      );
                    }
                  }}
                >
                  Редактировать
                </button>
              )}

              {/* Восстанавливаем сообщения ИИ */}
              {message.type === "ai" && (
                <кнопка
                  onClick={() => stream.submit(undefined, { checkpoint: parentCheckpoint })}
                >
                  Регенерировать
                </button>
              )}

              {/* Переключение между ветвями */}
              <BranchSwitcher
                branch={meta?.branch}
                branchOptions={meta?.branchOptions}
                onSelect={(branch) => stream.setBranch(branch)}
              />
            </div>
          );
        })}
      </div>
    );
  }
  ```

  ```tsx BranchSwitcher.tsx theme={null}
  /**
   * Компонент для навигации между ветками диалога.
   * Отображает текущее положение ветви и позволяет переключаться между альтернативными вариантами.
   */
  export function BranchSwitcher({
    ветвь,
    branchOptions,
    onSelect,
  }: {
    ветвь: строка | неопределено;
    branchOptions: string[] | undefined;
    onSelect: (branch: string) => void;
  }) {
    if (!branchOptions || !branch) return null;
    const index = branchOptions.indexOf(branch);

    возвращаться (
      <div className="flex items-center gap-2">
        <кнопка
          type="button"
          disabled={index <= 0}
          onClick={() => onSelect(branchOptions[index - 1])}
        >
          ←
        </button>
        <span>{index + 1} / {branchOptions.length}</span>
        <кнопка
          type="button"
          disabled={index >= branchOptions.length - 1}
          onClick={() => onSelect(branchOptions[index + 1])}
        >
          →
        </button>
      </div>
    );
  }
  ```
</CodeGroup>

## Типобезопасная потоковая передача

Хук `useStream` поддерживает полный вывод типов при использовании с агентами, созданными с помощью `@\[`createAgent`], или графами, созданными с помощью ``StateGraph`](https://reference.langchain.com/python/langgraph/graphs/#langgraph.graph.state.StateGraph). Передайте `typeof agent` или `typeof graph` в качестве параметра типа для автоматического определения типов вызовов инструментов.

### С помощью `createAgent`

При использовании @\[`createAgent`] типы вызовов инструментов автоматически определяются на основе инструментов, которые вы регистрируете в своем агенте:

<CodeGroup>
  ```python agent.py theme={null}

      return "Погода в {местоположение}: Солнечно, 72°F"

  агент = create_agent(
      model="openai:gpt-4.1-mini",
      инструменты=[get_weather],
  )
  ```

  ```tsx Chat.tsx theme={null}
  import { useStream } from "@langchain/langgraph-sdk/react";
  ```

### С помощью `StateGraph`

Для пользовательских приложений на основе [`StateGraph`](https://reference.langchain.com/python/langgraph/graphs/#langgraph.graph.state.StateGraph) типы состояний определяются на основе аннотаций графа:

<CodeGroup>
  ```python graph.py theme={null}
  from langgraph.graph import StateGraph, START, END
  from langgraph.graph.message import add_messages
  from langchain_openai import ChatOpenAI
  ```

## Обработка событий

Хук `useStream` предоставляет параметры обратного вызова, позволяющие получать доступ к различным типам потоковых событий. Вам не нужно явно настраивать режимы потока — просто передайте параметры обратного вызова для тех типов событий, которые вы хотите обрабатывать:

### Доступные функции обратного вызова

| Обратный вызов    | Описание                                                               | Режим потоковой передачи |
| ----------------- | ---------------------------------------------------------------------- | ------------------------ |
| `onUpdateEvent`   | Вызывается при получении обновления состояния после каждого шага графа | `updates`                |
| `onCustomEvent`   | Вызывается при получении пользовательского события от вашего графа     | `custom`                 |
| `onMetadataEvent` | Вызывается с метаданными выполнения и потока                           | `metadata`               |
| `onError`         | Вызывается при возникновении ошибки                                    | -                        |
| `onFinish`        | Вызывается при завершении потока                                       | -                        |

## Многоагентная потоковая передача

## Модели рассуждений

<Предупреждение>
  Расширенная поддержка рассуждений/мышления в настоящее время находится на экспериментальной стадии. Интерфейс потоковой передачи токенов для рассуждений различается в зависимости от поставщика (OpenAI или Anthropic) и может измениться по мере разработки абстракций.
</Предупреждение>

При использовании моделей с расширенными возможностями рассуждения (таких как модели рассуждения OpenAI или расширенное мышление Anthropic) мыслительный процесс встроен в содержимое сообщения. Вам потребуется извлечь и отобразить его отдельно.

  ```typescript utils.ts theme={null}
  import type { Message, AIMessage } from "@langchain/langgraph-sdk";

  /**
   * Извлекает смысловую/логическую информацию из сообщения, полученного от ИИ.
   * Поддерживает как рассуждения OpenAI, так и расширенное антропическое мышление.
   */
  export function getReasoningFromMessage(message: Message): string | undefined {
    type MessageWithExtras = AIMessage & {
      additional_kwargs?: {
        обоснование?: {
          summary?: Array<{ type: string; text: string }>;
        };
      };
      contentBlocks?: Array<{ type: string; thinking?: string }>;
    };

    const msg = message as MessageWithExtras;

    // Проверьте наличие аргументации OpenAI в additional_kwargs
    if (msg.additional_kwargs?.reasoning?.summary) {
      const content = msg.additional_kwargs.reasoning.summary
        .filter((item) => item.type === "summary_text")
        .map((item) => item.text)
        .присоединиться("");
      if (content.trim()) return content;
    }

    // Проверка наличия антропического мышления в блоках контента
    if (msg.contentBlocks?.length) {
      const thinking = msg.contentBlocks
        .filter((b) => b.type === "thinking" && b.thinking)
        .map((b) => b.thinking)
        .join("\n");
      если (размышление) вернуть размышление;
    }

    // Проверка наличия мысли в массиве message.content
    if (Array.isArray(msg.content)) {
      const thinking = msg.content
        .filter((b): b is { type: "thinking"; thinking: string } =>
          typeof b === "object" && b?.type === "thinking" && "thinking" in b
        )
        .map((b) => b.thinking)
        .join("\n");
      если (размышление) вернуть размышление;
    }

    возвращаем неопределенное значение;
  }

  /**
   * Извлекает текстовое содержимое из сообщения.
   */
  export function getTextContent(message: Message): string {
    if (typeof message.content === "string") return message.content;
    if (Array.isArray(message.content)) {
      return message.content
        .filter((c): c is { type: "text"; text: string } => c.type === "text")
        .map((c) => c.text)
        .присоединиться("");
    }
    возвращаться "";
  }
  ```
