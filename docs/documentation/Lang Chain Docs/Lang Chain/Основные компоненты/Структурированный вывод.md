# Структурированный вывод

Структурированный вывод позволяет агентам возвращать данные в определенном, предсказуемом формате. Вместо анализа ответов на естественном языке вы получаете структурированные данные в виде объектов JSON, [моделей Pydantic](https://docs.pydantic.dev/latest/concepts/models/#basic-model-usage) или классов данных, которые ваше приложение может использовать напрямую.

Функция `create_agent` в LangChain автоматически обрабатывает структурированные выходные данные. Пользователь задает желаемую схему структурированных выходных данных, и когда модель генерирует эти данные, они захватываются, проверяются и возвращаются в ключе `structured_response` состояния агента.

```python theme={null}
def create_agent(
    ...
    response_format: Union[
        ToolStrategy[StructuredResponseT],
        ProviderStrategy[StructuredResponseT],
        тип[СтруктурированныйОтветT],
        Никто,
    ]
```

## Формат ответа

Используйте `response_format` для управления тем, как агент возвращает структурированные данные:

* **`ToolStrategy[StructuredResponseT]`**: Использует вызов инструмента для получения структурированного вывода
* **`ProviderStrategy[StructuredResponseT]`**: Использует структурированный вывод, встроенный в провайдер.
* **`type[StructuredResponseT]`**: Тип схемы - автоматически выбирает наилучшую стратегию на основе возможностей модели.
* **`Нет`**: Структурированный вывод не запрашивался явно

Если тип схемы указан напрямую, LangChain автоматически выбирает:

* `ProviderStrategy`, если выбранная модель и поставщик поддерживают собственный структурированный вывод (например, [OpenAI](/oss/python/integrations/providers/openai), [Anthropic (Claude)](/oss/python/integrations/providers/anthropic) или [xAI (Grok)](/oss/python/integrations/providers/xai)).
* `ToolStrategy` для всех остальных моделей.

<Примечание>
  Поддержка встроенных структурированных выходных данных считывается динамически из [данных профиля](/oss/python/langchain/models#model-profiles) модели при использовании `langchain>=1.1`. Если данные недоступны, используйте другое условие или укажите их вручную:

  ```python theme={null}
  custom_profile = {
      "structured_output": True,
      # ...
  }
  model = init_chat_model("...", profile=custom_profile)
  ```

  Если указаны инструменты, модель должна поддерживать одновременное использование инструментов и структурированного вывода.
</Примечание>

Структурированный ответ возвращается в ключе `structured_response` конечного состояния агента.

## Стратегия поставщика услуг

Некоторые поставщики моделей поддерживают структурированный вывод данных изначально через свои API (например, OpenAI, xAI (Grok), Gemini, Anthropic (Claude)). Это наиболее надежный метод, если он доступен.

Для использования этой стратегии настройте `ProviderStrategy`:

```python theme={null}
class ProviderStrategy(Generic[SchemaT]):
    схема: тип[SchemaT]
    strict: bool | None = None
```

<Информация>
  Параметр `strict` требует, чтобы `langchain>=1.2`.
</Info>

<ParamField path="schema" required>
  Схема, определяющая структурированный формат вывода. Поддерживается:

  * **Модели Pydantic**: подклассы `BaseModel` с проверкой полей. Возвращает проверенный экземпляр Pydantic.
  * **Dataclasses**: Классы данных Python с аннотациями типов. Возвращает словарь.
  * **TypedDict**: Типизированные классы словарей. Возвращает словарь.
  * **JSON Schema**: Словарь со спецификацией JSON-схемы. Возвращает словарь.
</ParamField>

<ParamField path="strict">
  Необязательный логический параметр для включения строгого соблюдения схемы. Поддерживается некоторыми поставщиками (например, [OpenAI](/oss/python/integrations/chat/openai) и [xAI](/oss/python/integrations/chat/xai)). По умолчанию — `None` (отключено).
</ParamField>

LangChain автоматически использует `ProviderStrategy`, когда вы передаете тип схемы непосредственно в [`create_agent.response_format`](https://reference.langchain.com/python/langchain/agents/#langchain.agents.create_agent\(response_format\)), и модель поддерживает собственный структурированный вывод:

<CodeGroup>
  ```python Pydantic Model theme={null}
  from pydantic import BaseModel, Field
  from langchain.agents import create_agent


  class ContactInfo(BaseModel):
      «Контактная информация человека».
      имя: str = Field(description="Имя человека")
      email: str = Field(description="Адрес электронной почты человека")
      телефон: str = Field(description="Номер телефона человека")

  агент = create_agent(
      model="gpt-5",
      response_format=ContactInfo # Автоматический выбор стратегии поставщика
  )

  результат = agent.invoke({
      "сообщения": [{"роль": "пользователь", "содержание": "Извлечь контактную информацию от: Джон Доу, john@example.com, (555) 123-4567"}]
  })

  print(result["structured_response"])
  # ContactInfo(name='John Doe', email='john@example.com', phone='(555) 123-4567')
  ```

<Примечание>
  Если поставщик изначально поддерживает структурированный вывод для выбранной вами модели, то функционально эквивалентно написать `response_format=ProductReview` вместо `response_format=ProviderStrategy(ProductReview)`.

  В любом случае, если структурированный вывод не поддерживается, агент переключится на стратегию вызова инструмента.
</Примечание>

## Стратегия вызова инструментов

Для моделей, не поддерживающих собственный структурированный вывод, LangChain использует вызов инструментов для достижения того же результата. Это работает со всеми моделями, поддерживающими вызов инструментов (большинством современных моделей).

Для использования этой стратегии настройте параметр `ToolStrategy`:

```python theme={null}
class ToolStrategy(Generic[SchemaT]):
    схема: тип[SchemaT]
    tool_message_content: str | None
    handle_errors: Union[
        логическое значение,
        стр.
        тип[Исключение],
        кортеж[тип[Исключение], ...],
        Callable[[Exception], str],
    ]
```

<ParamField path="schema" required>
  Схема, определяющая структурированный формат вывода. Поддерживается:

  * **Модели Pydantic**: подклассы `BaseModel` с проверкой полей. Возвращает проверенный экземпляр Pydantic.
  * **Dataclasses**: Классы данных Python с аннотациями типов. Возвращает словарь.
  * **TypedDict**: Типизированные классы словарей. Возвращает словарь.
  * **JSON Schema**: Словарь со спецификацией JSON-схемы. Возвращает словарь.
  * **Типы объединения**: Несколько вариантов схемы. Модель выберет наиболее подходящую схему в зависимости от контекста.
</ParamField>

<ParamField path="tool_message_content">
  Пользовательское содержимое для сообщения инструмента, возвращаемого при генерации структурированного вывода.
  Если параметр не указан, по умолчанию отображается сообщение со структурированными данными ответа.
</ParamField>

<ParamField path="handle_errors">
  Стратегия обработки ошибок при проверке структурированных выходных данных. По умолчанию — `True`.

  * **`True`**: Перехватывать все ошибки с помощью шаблона ошибок по умолчанию
  * **`str`**: Перехватывать все ошибки с помощью этого пользовательского сообщения
  * **`type[Exception]`**: Перехватывайте этот тип исключения только с сообщением по умолчанию.
  * **`tuple[type[Exception], ...]`**: Перехватывайте эти типы исключений только с сообщением по умолчанию.
  * **`Callable[[Exception], str]`**: Пользовательская функция, возвращающая сообщение об ошибке
  * **`Ложь`**: Повторная попытка не выполняется, исключения распространяются дальше.
</ParamField>

### Содержимое сообщений пользовательского инструмента

Параметр `tool_message_content` позволяет настроить сообщение, которое отображается в истории переписки при генерации структурированного вывода:

```python theme={null}
from pydantic import BaseModel, Field
from typing import Literal
from langchain.agents import create_agent
from langchain.agents.structured_output import ToolStrategy


class MeetingAction(BaseModel):
    «Пункты плана действий, извлеченные из стенограммы совещания».
    задача: str = Field(description="Конкретная задача, которую необходимо выполнить")
    Исполнитель: str = Field(description="Человек, ответственный за выполнение задачи")
    приоритет: Literal["низкий", "средний", "высокий"] = Field(description="Уровень приоритета")

агент = create_agent(
    model="gpt-5",
    инструменты=[],
    response_format=ToolStrategy(
        схема=MeetingAction,
        tool_message_content="Действие зафиксировано и добавлено в протокол совещания!"
    )
)

agent.invoke({
    "messages": [{"role": "user", "content": "Из нашей встречи: Саре необходимо как можно скорее обновить график проекта"}]
})
```


### Обработка ошибок

Модели могут допускать ошибки при генерации структурированного вывода с помощью вызова инструментов. LangChain предоставляет интеллектуальные механизмы повторной попытки для автоматической обработки этих ошибок.

#### Ошибка множественных структурированных выходных данных

Когда модель некорректно вызывает несколько структурированных инструментов вывода, агент предоставляет сообщение об ошибке в виде [`ToolMessage`](https://reference.langchain.com/python/langchain/messages/#langchain.messages.ToolMessage) и предлагает модели повторить попытку:

```python theme={null}
from pydantic import BaseModel, Field
из набора текста импорт Union
from langchain.agents import create_agent
from langchain.agents.structured_output import ToolStrategy


class ContactInfo(BaseModel):
    имя: str = Field(description="Имя человека")
    email: str = Field(description="Email address")

class EventDetails(BaseModel):
    event_name: str = Field(description="Название события")
    дата: str = Field(description="Дата события")

агент = create_agent(
    model="gpt-5",
    инструменты=[],
    response_format=ToolStrategy(Union[ContactInfo, EventDetails]) # По умолчанию: handle_errors=True
)

agent.invoke({
    "messages": [{"role": "user", "content": "Extract info: John Doe (john@email.com) is organizing the Tech Conference on March 15"}]
})
```

```python theme={null}
    model="gpt-5",
```

#### Стратегии обработки ошибок

Способ обработки ошибок можно настроить с помощью параметра `handle_errors`:

**Пользовательское сообщение об ошибке:**

```python theme={null}
ToolStrategy(
    схема=Рейтинг продукта,
    handle_errors="Пожалуйста, поставьте оценку от 1 до 5 и добавьте комментарий."
)
```

Если `handle_errors` — строка, агент *всегда* предложит модели повторить попытку с фиксированным сообщением об инструменте:

```
================================= Сообщение инструмента =================================
Имя: ProductRating

Пожалуйста, поставьте оценку от 1 до 5 и добавьте комментарий.
```

**Обрабатывайте только определенные исключения:**

```python theme={null}
ToolStrategy(
    схема=Рейтинг продукта,
    handle_errors=ValueError # Повторять попытку только при возникновении ValueError, в остальных случаях генерировать исключение
)
```

Если `handle_errors` имеет тип исключения, агент повторит попытку (используя сообщение об ошибке по умолчанию) только в том случае, если возникшее исключение имеет указанный тип. Во всех остальных случаях исключение будет сгенерировано.

**Обработка нескольких типов исключений:**

```python theme={null}
ToolStrategy(
    схема=Рейтинг продукта,
    handle_errors=(ValueError, TypeError) # Повторить попытку ValueError и TypeError
)
```

Если `handle_errors` представляет собой кортеж исключений, агент повторит попытку (используя сообщение об ошибке по умолчанию) только в том случае, если возникшее исключение относится к одному из указанных типов. Во всех остальных случаях исключение будет сгенерировано.

**Функция обработки пользовательских ошибок:**

```python theme={null}

from langchain.agents.structured_output import StructuredOutputValidationError
from langchain.agents.structured_output import MultipleStructuredOutputsError

def custom_error_handler(error: Exception) -> str:
    if isinstance(error, StructuredOutputValidationError):
        return "Возникла проблема с форматированием. Попробуйте еще раз."
    elif isinstance(error, MultipleStructuredOutputsError):
        Возвращается сообщение "Было получено несколько структурированных результатов. Выберите наиболее подходящий."
    еще:
        return f"Ошибка: {str(error)}"


агент = create_agent(
    model="gpt-5",
    инструменты=[],
    response_format=ToolStrategy(
                        схема=Union[ContactInfo, EventDetails],
                        handle_errors=custom_error_handler
                    ) # По умолчанию: handle_errors=True
)

результат = agent.invoke({
    "messages": [{"role": "user", "content": "Extract info: John Doe (john@email.com) is organizing the Tech Conference on March 15"}]
})

for msg in result['messages']:
    # Если сообщение на самом деле является объектом ToolMessage (а не словарем), проверьте имя его класса.
    if type(msg).__name__ == "ToolMessage":
        print(msg.content)
    # Если сообщение представляет собой словарь или вам нужен резервный вариант
    elif isinstance(msg, dict) and msg.get('tool_call_id'):
        print(msg['content'])

```
