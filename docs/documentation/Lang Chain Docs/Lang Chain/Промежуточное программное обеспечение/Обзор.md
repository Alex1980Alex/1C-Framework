# Обзор

> Контроль и настройка выполнения агента на каждом этапе

Промежуточное ПО (middleware) обеспечивает более строгий контроль над тем, что происходит внутри агента. Промежуточное ПО полезно в следующих случаях:

* Отслеживание поведения агентов с помощью логирования, аналитики и отладки.
* Преобразование подсказок, [выбор инструмента](/oss/python/langchain/middleware/built-in#llm-tool-selector) и форматирование вывода.
* Добавление [повторных попыток](/oss/python/langchain/middleware/built-in#tool-retry), [резервных вариантов](/oss/python/langchain/middleware/built-in#model-fallback) и логики досрочного завершения.
* Применение [ограничений скорости](/oss/python/langchain/middleware/built-in#model-call-limit), защитных механизмов и [обнаружения персональных данных](/oss/python/langchain/middleware/built-in#pii-detection).

Добавьте промежуточное ПО, передав его в функцию [`create_agent`](https://reference.langchain.com/python/langchain/agents/#langchain.agents.create_agent):

```python theme={null}
from langchain.agents import create_agent
from langchain.agents.middleware import SummarizationMiddleware, HumanInTheLoopMiddleware

агент = create_agent(
    model="gpt-4.1",
    инструменты=[...],
    промежуточное ПО=[
        SummarizationMiddleware(...),
        HumanInTheLoopMiddleware(...)
    ],
)
```
