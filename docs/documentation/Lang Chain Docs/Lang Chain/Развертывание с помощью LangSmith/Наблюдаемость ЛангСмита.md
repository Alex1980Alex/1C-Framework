# Наблюдаемость ЛангСмита

При создании и запуске агентов с LangChain вам необходимо понимать, как они себя ведут: какие [инструменты](/oss/python/langchain/tools) они вызывают, какие запросы генерируют и как принимают решения. Агенты LangChain, созданные с помощью [`create_agent`](https://reference.langchain.com/python/langchain/agents/#langchain.agents.create_agent), автоматически поддерживают трассировку через [LangSmith](/langsmith/home), платформу для захвата, отладки, оценки и мониторинга поведения приложений LLM.

[*Трассировки*](/langsmith/observability-concepts#traces) записывают каждый шаг выполнения вашего агента, от первоначального ввода данных пользователем до конечного ответа, включая все вызовы инструментов, взаимодействия с моделью и точки принятия решений. Эти данные о выполнении помогают отлаживать проблемы, оценивать производительность при различных входных данных и отслеживать модели использования в производственной среде.

В этом руководстве показано, как включить трассировку для ваших агентов LangChain и использовать LangSmith для анализа их выполнения.

## Предварительные условия

Прежде чем начать, убедитесь, что у вас есть следующее:

* **Учетная запись LangSmith**: Зарегистрируйтесь (бесплатно) или войдите в систему по адресу [smith.langchain.com](https://smith.langchain.com).
* **Ключ API LangSmith**: Следуйте инструкциям по созданию ключа API (/langsmith/create-account-api-key#create-an-api-key).

## Включить трассировку

Все агенты LangChain автоматически поддерживают трассировку LangSmith. Чтобы включить её, установите следующие переменные среды:

```bash theme={null}
export LANGSMITH_TRACING=true
export LANGSMITH_API_KEY=<ваш-ключ-API>
```

## Быстрый старт

Для отправки трассировки в LangSmith не требуется дополнительный код. Просто запустите код агента, как обычно:

```python theme={null}
from langchain.agents import create_agent


def send_email(to: str, subject: str, body: str):
    «Отправить электронное письмо получателю».
    # ... логика отправки электронных писем
    return f"Электронное письмо отправлено {кому}"

def search_web(query: str):
    «Ищите информацию в интернете».
    # ... логика веб-поиска
    return "Результаты поиска по запросу: {query}"

агент = create_agent(
    model="gpt-4.1",
    tools=[send_email, search_web],
    system_prompt="Вы — полезный помощник, который может отправлять электронные письма и осуществлять поиск в интернете."
)

# Запустите агент — все шаги будут отслеживаться автоматически.
response = agent.invoke({
    "messages": [{"role": "user", "content": "Найдите последние новости об ИИ и отправьте краткое изложение по электронной почте на адрес john@example.com"}]
})
```

По умолчанию трассировка будет записываться в проект с именем `default`. Чтобы настроить пользовательское имя проекта, см. [Запись в проект](#log-to-a-project).

## Выборочная трассировка

Вы можете отслеживать конкретные вызовы или части вашего приложения, используя менеджер контекста `tracing_context` в LangSmith:

```python theme={null}
import langsmith as ls

# Это будет отслежено
с помощью ls.tracing_context(enabled=True):
    agent.invoke({"messages": [{"role": "user", "content": "Отправить тестовое письмо на адрес alice@example.com"}]})

# Эта трассировка НЕ ​​будет выполняться (если параметр LANGSMITH_TRACING не задан)
agent.invoke({"messages": [{"role": "user", "content": "Отправить еще одно письмо"}]})
```

## Запись в проект

<Accordion title="Statically">
  Вы можете задать пользовательское имя проекта для всего вашего приложения, установив переменную среды `LANGSMITH_PROJECT`:

  ```bash theme={null}
  export LANGSMITH_PROJECT=my-agent-project
  ```
</Аккордеон>

<Заголовок аккордеона="Динамически">
  Для конкретных операций можно программно задать имя проекта:

  ```python theme={null}
  import langsmith as ls

  with ls.tracing_context(project_name="email-agent-test", enabled=True):
      response = agent.invoke({
          "messages": [{"role": "user", "content": "Send welcome email"}]
      })
  ```
</Аккордеон>

## Добавление метаданных к трассировкам

Вы можете добавлять к своим трассировкам пользовательские метаданные и теги:

```python theme={null}
response = agent.invoke(
    {"messages": [{"role": "user", "content": "Отправить приветственное письмо"}]},
    config={
        "теги": ["production", "email-assistant", "v1.0"],
        "метаданные": {
            "user_id": "user_123",
            "session_id": "session_456",
            «окружающая среда»: «производство»
        }
    }
)
```

Функция `tracing_context` также принимает теги и метаданные для более точного управления:

```python theme={null}
с помощью ls.tracing_context(
    project_name="email-agent-test",
    enabled=True,
    tags=["production", "email-assistant", "v1.0"],
    metadata={"user_id": "user_123", "session_id": "session_456", "environment": "production"}):
    response = agent.invoke(
        {"messages": [{"role": "user", "content": "Отправить приветственное письмо"}]}
    )
```

Эти пользовательские метаданные и теги будут прикреплены к трассировке в LangSmith.
