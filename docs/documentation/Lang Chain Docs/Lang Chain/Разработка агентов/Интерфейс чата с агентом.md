# Интерфейс чата агента

[Agent Chat UI](https://github.com/langchain-ai/agent-chat-ui) — это приложение Next.js, предоставляющее диалоговый интерфейс для взаимодействия с любым агентом LangChain. Оно поддерживает чат в реальном времени, визуализацию инструментов и расширенные функции, такие как отладка с возможностью перемещения во времени и разветвление состояний. Agent Chat UI бесперебойно работает с агентами, созданными с помощью [`create_agent`](../langchain/agents), и обеспечивает интерактивный опыт для ваших агентов с минимальной настройкой, независимо от того, работаете ли вы локально или в развернутом контексте (например, [LangSmith](/langsmith/home)).

Agent Chat UI — это программное обеспечение с открытым исходным кодом, которое можно адаптировать под нужды вашего приложения.

### Быстрый старт

Самый быстрый способ начать работу — использовать размещенную версию:

1. **Перейдите в [интерфейс чата с агентом](https://agentchat.vercel.app)**
2. **Подключите агента**, введя URL-адрес развертывания или адрес локального сервера.
3. **Начните общение** — пользовательский интерфейс автоматически обнаружит и отобразит вызовы инструментов и прерывания.

### Местное развитие

Для настройки или локальной разработки вы можете запустить Agent Chat UI локально:

<CodeGroup>
  ```bash Use npx theme={null}

  cd my-chat-ui

  # Установите зависимости и запустите
  ```

### Свяжитесь со своим агентом

Пользовательский интерфейс Agent Chat может подключаться как к [локальным](/oss/python/langchain/studio#setup-local-agent-server), так и к [развернутым агентам](/oss/python/langchain/deploy).

После запуска пользовательского интерфейса Agent Chat вам потребуется настроить его для подключения к вашему агенту:

1. **Идентификатор графа**: Введите название вашего графа (его можно найти в разделе `graphs` в файле `langgraph.json`).
2. **URL развертывания**: Конечная точка вашего сервера агента (например, `http://localhost:2024` для локальной разработки или URL развернутого агента)
3. **Ключ API LangSmith (необязательно)**: Добавьте свой ключ API LangSmith (не требуется, если вы используете локальный сервер агента).

После настройки пользовательский интерфейс Agent Chat автоматически будет получать и отображать все прерванные диалоги от вашего агента.

<Совет>
  В интерфейсе Agent Chat UI предусмотрена встроенная поддержка отображения вызовов инструментов и сообщений о результатах их работы. Чтобы настроить отображаемые сообщения, см. [Скрытие сообщений в чате](https://github.com/langchain-ai/agent-chat-ui?tab=readme-ov-file#hiding-messages-in-the-chat).
</Совет>
