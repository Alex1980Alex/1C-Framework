# Студия ЛангСмита

При локальной сборке агентов LangChain полезно визуализировать происходящее внутри агента, взаимодействовать с ним в режиме реального времени и отлаживать возникающие проблемы. **LangSmith Studio** — это бесплатный визуальный интерфейс для разработки и тестирования агентов LangChain на локальном компьютере.

Studio подключается к локально запущенному агенту, чтобы показать вам каждый шаг, который он выполняет: запросы, отправленные модели, вызовы инструментов и их результаты, а также конечный результат. Вы можете тестировать различные входные данные, проверять промежуточные состояния и итеративно улучшать поведение агента без дополнительного кода или развертывания.

На этой странице описано, как настроить Studio с локальным агентом LangChain.

## Предварительные условия

Прежде чем начать, убедитесь, что у вас есть следующее:

* **Учетная запись LangSmith**: Зарегистрируйтесь (бесплатно) или войдите в систему по адресу [smith.langchain.com](https://smith.langchain.com).
* **Ключ API LangSmith**: Следуйте инструкциям по созданию ключа API (/langsmith/create-account-api-key#create-an-api-key).
* Если вы не хотите, чтобы данные [отслеживались](/langsmith/observability-concepts#traces) в LangSmith, установите `LANGSMITH_TRACING=false` в файле `.env` вашего приложения. При отключенной трассировке данные не покидают ваш локальный сервер.

## Настройка локального сервера агента

### 1. Установите LangGraph CLI

Интерфейс командной строки LangGraph (LangGraph CLI) предоставляет локальный сервер разработки (также называемый сервером агента), который подключает ваш агент к Studio.

```shell theme={null}
# Требуется Python >= 3.11.
pip install --upgrade "langgraph-cli[inmem]"
```

### 2. Подготовьте своего агента

Если у вас уже есть агент LangChain, вы можете использовать его напрямую. В этом примере используется простой почтовый агент:

```python title="agent.py" theme={null}
from langchain.agents import create_agent

def send_email(to: str, subject: str, body: str):
    """Отправить электронное письмо"""
    email = {
        "к": к,
        "субъект": субъект,
        "тело": тело
    }
    # ... логика отправки электронных писем

    return f"Электронное письмо отправлено {кому}"

агент = create_agent(
    "gpt-4.1",
    инструменты=[отправить_электронную почту],
    system_prompt="Вы являетесь помощником по работе с электронной почтой. Всегда используйте инструмент send_email."
)
```

### 3. Переменные окружающей среды

Для подключения локального агента Studio требуется ключ API LangSmith. Создайте файл `.env` в корневой директории вашего проекта и добавьте свой ключ API из [LangSmith](https://smith.langchain.com/settings).

<Предупреждение>
  Убедитесь, что ваш файл `.env` не добавлен в систему контроля версий, например, Git.
</Предупреждение>

```bash .env theme={null}
LANGSMITH_API_KEY=lsv2...
```

### 4. Создайте конфигурационный файл LangGraph

Интерфейс командной строки LangGraph использует конфигурационный файл для поиска вашего агента и управления зависимостями. Создайте файл `langgraph.json` в каталоге вашего приложения:

```json title="langgraph.json" theme={null}
{
  "зависимости": ["."],
  "графики": {
    "agent": "./src/agent.py:agent"
  },
  "env": ".env"
}
```

Функция [`create_agent`](https://reference.langchain.com/python/langchain/agents/#langchain.agents.create_agent) автоматически возвращает скомпилированный граф LangGraph, что соответствует требованиям ключа `graphs` в конфигурационном файле.

<Информация>
  Для получения подробных пояснений к каждому ключу в JSON-объекте конфигурационного файла обратитесь к [справочнику по конфигурационным файлам LangGraph](/langsmith/cli#configuration-file).
</Info>

На данном этапе структура проекта будет выглядеть следующим образом:

```bash theme={null}
мое-приложение/
├── src
│ └── agent.py
├── .env
└── langgraph.json
```

### 5. Установите зависимости

Установите зависимости вашего проекта из корневого каталога:

<CodeGroup>
  ```shell pip theme={null}
  pip install langchain langchain-openai
  ```

  ```shell uv theme={null}
  uv add langchain langchain-openai
  ```
</CodeGroup>

### 6. Найдите своего агента в студии.

Запустите сервер разработки, чтобы подключить ваш агент к Studio:

```shell theme={null}
langgraph dev
```

<Предупреждение>
  Safari блокирует подключения к Studio через `localhost`. Чтобы обойти это ограничение, выполните указанную выше команду с параметром `--tunnel` для доступа к Studio через защищенный туннель.
</Предупреждение>

После запуска сервера ваш агент будет доступен как через API по адресу `http://127.0.0.1:2024`, так и через пользовательский интерфейс Studio по адресу `https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024`:

Подключив Studio к локальному агенту, вы можете быстро вносить изменения в его поведение. Запустите тестовый ввод, изучите полную трассировку выполнения, включая подсказки, аргументы инструмента, возвращаемые значения и метрики токена/задержки. Если что-то пойдет не так, Studio перехватит исключения вместе с окружающим состоянием, чтобы помочь вам понять, что произошло.

Сервер разработки поддерживает горячую перезагрузку — вносите изменения в подсказки или сигнатуры инструментов в своем коде, и Studio немедленно их отобразит. Повторно запускайте диалоги с любого шага, чтобы протестировать изменения, не начиная все заново. Этот рабочий процесс масштабируется от простых агентов с одним инструментом до сложных многоузловых графов.
