# Долговременная память

## Обзор

Агенты LangChain используют [LangGraph persistence](/oss/python/langgraph/persistence#memory-store) для обеспечения долговременной памяти. Это более сложная тема, для использования которой требуются знания LangGraph.

## Хранение данных в памяти

LangGraph хранит долговременную память в виде JSON-документов в хранилище [store](/oss/python/langgraph/persistence#memory-store).

Каждый объект памяти организован в рамках пользовательского пространства имен (подобно папке) и имеет уникальный ключ (например, имя файла). Пространства имен часто содержат идентификаторы пользователей или организаций, а также другие метки, упрощающие организацию информации.

Эта структура обеспечивает иерархическую организацию памяти. Поиск по пространствам имен поддерживается с помощью контентных фильтров.

```python theme={null}
from langgraph.store.memory import InMemoryStore


def embed(texts: list[str]) -> list[list[float]]:
    # Замените на фактическую функцию встраивания или объект встраивания LangChain
    return [[1.0, 2.0] * len(texts)]


# InMemoryStore сохраняет данные во встроенный в память словарь. В производственной среде используйте хранилище на основе базы данных.
store = InMemoryStore(index={"embed": embed, "dims": 2}) # [!code highlight]
user_id = "my-user"
application_context = "chitchat"
namespace = (user_id, application_context) # [!code highlight]
store.put( # [!выделение кода]
    пространство имён,
    "память",
    {
        "правила": [
            «Пользователям нравится короткий и прямой язык».
            Пользователь владеет только английским языком и языком Python.
        ],
        "my-key": "my-value",
    },
)
# получить "память" по идентификатору
item = store.get(namespace, "a-memory") # [!code highlight]
# Поиск "воспоминаний" в этом пространстве имен с фильтрацией по эквивалентности контента, отсортированный по сходству векторов.
items = store.search( # [!code highlight]
    namespace, filter={"my-key": "my-value"}, query="language preferences"
)
```

Для получения дополнительной информации о хранилище в памяти см. руководство [Persistence](/oss/python/langgraph/persistence#memory-store).

## Чтение долговременной памяти в инструментах

```python Инструмент, который агент может использовать для поиска информации о пользователе theme={null}
from dataclasses import dataclass

from langchain_core.runnables import RunnableConfig
from langchain.agents import create_agent
from langchain.tools import tool, ToolRuntime
from langgraph.store.memory import InMemoryStore


@dataclass
Контекст класса:
    user_id: str

# InMemoryStore сохраняет данные во встроенный в память словарь. В производственной среде используйте хранилище на основе базы данных.
store = InMemoryStore() # [!подсветка кода]

# Запись тестовых данных в хранилище с помощью метода put
store.put( # [!выделение кода]
    ("пользователи", # Пространство имен для группировки связанных данных (пространство имен users для пользовательских данных)
    "user_123", # Ключ в пространстве имен (идентификатор пользователя в качестве ключа)
    {
        "имя": "Джон Смит",
        "язык": "английский",
    } # Данные для хранения для данного пользователя
)

@инструмент
def get_user_info(runtime: ToolRuntime[Context]) -> str:
    «Поиск информации о пользователе».
    # Доступ к хранилищу — тот же, что и при вызове `create_agent`
    store = runtime.store # [!code highlight]
    user_id = runtime.context.user_id
    # Получение данных из хранилища - возвращает объект StoreValue со значением и метаданными
    user_info = store.get(("users",), user_id) # [!code highlight]
    return str(user_info.value) if user_info else "Неизвестный пользователь"

агент = create_agent(
    model="claude-sonnet-4-5-20250929",
    инструменты=[get_user_info],
    # Передача хранилища агенту — позволяет агенту получить доступ к хранилищу при запуске инструментов
    магазин=магазин, # [!подсветка кода]
    context_schema=Context
)

# Запуск агента
agent.invoke(
    {"messages": [{"role": "user", "content": "look up user information"}]},
    context=Context(user_id="user_123") # [!code highlight]
)
```

## Запись в долговременную память из инструментов

Пример инструмента на Python, обновляющего информацию о пользователе theme={null}
from dataclasses import dataclass
from typing_extensions import TypedDict

from langchain.agents import create_agent
from langchain.tools import tool, ToolRuntime
from langgraph.store.memory import InMemoryStore


# InMemoryStore сохраняет данные во встроенный в память словарь. В производственной среде используйте хранилище на основе базы данных.
store = InMemoryStore() # [!подсветка кода]

@dataclass
Контекст класса:
    user_id: str

# TypedDict определяет структуру пользовательской информации для программы LLM.
class UserInfo(TypedDict):
    имя: str

# Инструмент, позволяющий агенту обновлять информацию о пользователе (полезно для чат-приложений)
@инструмент
def save_user_info(user_info: UserInfo, runtime: ToolRuntime[Context]) -> str:
    """Сохранить информацию о пользователе."""
    # Доступ к хранилищу — тот же, что и при вызове `create_agent`
    store = runtime.store # [!code highlight]
    user_id = runtime.context.user_id # [!code highlight]
    # Хранение данных в хранилище (пространство имен, ключ, данные)
    store.put(("users",), user_id, user_info) # [!code highlight]
    return "Информация о пользователе успешно сохранена."

агент = create_agent(
    model="claude-sonnet-4-5-20250929",
    инструменты=[save_user_info],
    магазин=магазин, # [!подсветка кода]
    context_schema=Context
)

# Запуск агента
agent.invoke(
    {"messages": [{"role": "user", "content": "Меня зовут Джон Смит"}]},
    # Идентификатор пользователя (user_id) передается в контексте для определения того, чья информация обновляется.
    context=Context(user_id="user_123") # [!code highlight]
)

# Вы можете получить доступ к магазину напрямую, чтобы узнать значение.
store.get(("users",), "user_123").value
```
