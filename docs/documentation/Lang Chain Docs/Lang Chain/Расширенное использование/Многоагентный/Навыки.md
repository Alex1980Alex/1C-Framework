# Навыки

В архитектуре **навыков** специализированные возможности упаковываются в виде вызываемых «навыков», которые расширяют поведение [агента](/oss/python/langchain/agents). Навыки представляют собой, в основном, специализации, управляемые подсказками, которые агент может вызывать по запросу.
Для получения информации о встроенной поддержке навыков см. [Deep Agents](/oss/python/deepagents/skills).

<Совет>
  Этот шаблон концептуально идентичен шаблону [llms.txt](https://llmstxt.org/) (представленному Джереми Ховардом), который использует вызов инструментов для постепенного раскрытия документации. Шаблон навыков применяет тот же подход к специализированным запросам и знаниям предметной области, а не только к страницам документации.
</Совет>

## Ключевые характеристики

* Специализация, основанная на подсказках: навыки определяются в первую очередь специализированными подсказками.
* Постепенное раскрытие информации: навыки становятся доступными в зависимости от контекста или потребностей пользователя.
* Распределение по командам: Разные команды могут развивать и поддерживать навыки самостоятельно.
* Облегченная структура: навыки проще, чем у полноценных субагентов.

## Когда использовать

Используйте шаблон навыков, когда вам нужен один [агент](/oss/python/langchain/agents) с множеством возможных специализаций, когда вам не нужно устанавливать конкретные ограничения между навыками или когда разным командам необходимо разрабатывать возможности независимо друг от друга. Распространенные примеры включают помощников по программированию (навыки для разных языков или задач), базы знаний (навыки для разных областей) и творческих помощников (навыки для разных форматов).

## Базовая реализация

```python theme={null}
from langchain.tools import tool
from langchain.agents import create_agent

@инструмент
def load_skill(skill_name: str) -> str:
    """Загрузить подсказку для специализированного навыка."

    Доступные навыки:
    - write_sql: Эксперт по написанию SQL-запросов
    - review_legal_doc: Рецензент юридических документов

    Возвращает подсказку и контекст навыка.
    """
    # Загрузка содержимого навыков из файла/базы данных
    ...

агент = create_agent(
    model="gpt-4.1",
    инструменты=[load_skill],
    system_prompt=(
        «Вы — полезный помощник».
        «Вам доступны два навыка:»
        "write_sql and review_legal_doc."
        "Используйте load_skill для доступа к ним."
    ),
)
```

## Расширение шаблона

При написании пользовательских реализаций вы можете расширить базовый шаблон навыков несколькими способами:

* **Динамическая регистрация инструментов**: Сочетание поэтапного раскрытия информации с управлением состоянием позволяет регистрировать новые [инструменты](/oss/python/langchain/tools) при загрузке навыков. Например, загрузка навыка "database\_admin" может как добавить специализированный контекст, так и зарегистрировать инструменты, специфичные для базы данных (резервное копирование, восстановление, миграция). Здесь используются те же механизмы "инструмент-состояние", что и в многоагентных шаблонах — инструменты обновляют состояние для динамического изменения возможностей агента.

* **Иерархические навыки**: Навыки могут определять другие навыки в древовидной структуре, создавая вложенные специализации. Например, загрузка навыка «анализ данных» может сделать доступными такие поднавыки, как «эксперт по pandas», «визуализация» и «статистический анализ». Каждый поднавык может быть загружен независимо по мере необходимости, что позволяет постепенно раскрывать знания в предметной области с высокой степенью детализации. Такой иерархический подход помогает управлять большими базами знаний, организуя возможности в логические группы, которые можно обнаружить и загрузить по запросу.
