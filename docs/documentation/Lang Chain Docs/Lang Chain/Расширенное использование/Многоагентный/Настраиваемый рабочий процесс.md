# Пользовательский рабочий процесс

В архитектуре **пользовательского рабочего процесса** вы определяете собственный, уникальный поток выполнения с помощью [LangGraph](/oss/python/langgraph/overview). Вы имеете полный контроль над структурой графа, включая последовательные шаги, условные ветвления, циклы и параллельное выполнение.

```тема русалки={null}
график LR
    A([Вход]) --> B{{Условие}}
    B -->|path_a| C[Детерминированный шаг]
    B -->|path_b| D((Агентный шаг))
    C --> G([Выход])
    D --> G([Выход])
```

## Ключевые характеристики

* Полный контроль над структурой графа
* Сочетание детерминированной логики с агентным поведением
* Поддержка последовательных шагов, условных переходов, циклов и параллельного выполнения.
* Встраивайте другие шаблоны в качестве узлов в свой рабочий процесс.

## Когда использовать

Используйте пользовательские рабочие процессы, если стандартные шаблоны (субагенты, навыки и т. д.) не соответствуют вашим требованиям, вам необходимо сочетать детерминированную логику с агентным поведением или ваш сценарий использования требует сложной маршрутизации или многоэтапной обработки.

Каждый узел в вашем рабочем процессе может представлять собой простую функцию, вызов LLM или целый [агент](/oss/python/langchain/agents) с [инструментами](/oss/python/langchain/tools). Вы также можете создавать другие архитектуры в рамках пользовательского рабочего процесса — например, встраивать многоагентную систему в качестве одного узла.

Полный пример пользовательского рабочего процесса смотрите в приведенном ниже руководстве.

## Базовая реализация

Главная идея заключается в том, что вы можете вызывать агента LangChain непосредственно из любого узла LangGraph, сочетая гибкость пользовательских рабочих процессов с удобством готовых агентов:

```python theme={null}
from langchain.agents import create_agent
from langgraph.graph import StateGraph, START, END

agent = create_agent(model="openai:gpt-4.1", tools=[...])

def agent_node(state: State) -> dict:
    «Узел LangGraph, который вызывает агента LangChain».
    результат = agent.invoke({
        "messages": [{"role": "user", "content": state["query"]}]
    })
    return {"answer": result["messages"][-1].content}

# Создайте простой рабочий процесс
рабочий процесс = (
    StateGraph(State)
    .add_node("agent", agent_node)
    .add_edge(START, "agent")
    .add_edge("agent", END)
    .compile()
)
```

## Пример: конвейер RAG

Распространенный пример использования — это объединение [retrieval](/oss/python/langchain/retrieval) с агентом. В этом примере создан помощник по статистике WNBA, который извлекает данные из базы знаний и может получать новости в режиме реального времени.

<Accordion title="Пользовательский рабочий процесс RAG">
  В представленном рабочем процессе показаны три типа узлов:

  * **Узел модели** (Перезапись): Переписывает пользовательский запрос для более эффективного поиска с использованием [структурированного вывода](/oss/python/langchain/structured-output).
  * **Детерминированный узел** (Извлечение): Выполняет поиск векторного сходства — без участия LLM.
  * **Узел агента** (Агент): Обосновывает полученный контекст и может получать дополнительную информацию с помощью инструментов.

  ```тема русалки={null}
  график LR
      A([Запрос]) --> B{{Переписать}}
      B --> C[(Получить)]
      C --> D((Агент))
      D --> E([Ответ])
  ```

  <Совет>
    Вы можете использовать состояние LangGraph для передачи информации между этапами рабочего процесса. Это позволяет каждой части вашего рабочего процесса считывать и обновлять структурированные поля, что упрощает обмен данными и контекстом между узлами.
  </Совет>

  ```python theme={null}
  from typing import TypedDict
  from pydantic import BaseModel
  from langgraph.graph import StateGraph, START, END
  from langchain.agents import create_agent
  from langchain.tools import tool
  from langchain_openai import ChatOpenAI, OpenAIEmbeddings
  from langchain_core.vectorstores import InMemoryVectorStore

  class State(TypedDict):
      вопрос: стр.
      rewritten_query: str
      документы: список[str]
      ответ: стр.

  # База знаний WNBA с составами команд, результатами игр и статистикой игроков
  embeddings = OpenAIEmbeddings()
  vector_store = InMemoryVectorStore(embeddings)
  vector_store.add_texts([
      # Составы
      Состав команды «Нью-Йорк Либерти» на 2024 год: Брианна Стюарт, Сабрина Ионеску, Джонкель Джонс, Кортни Вандерслот.
      Состав команды Las Vegas Aces на 2024 год: Эйжа Уилсон, Келси Плам, Джеки Янг, Челси Грей.
      Состав команды Indiana Fever на 2024 год: Кейтлин Кларк, Алия Бостон, Келси Митчелл, НаЛисса Смит.
      # Результаты игры
      «Финал WNBA 2024: «Нью-Йорк Либерти» победили «Миннесота Линкс» со счетом 3-2 и завоевали чемпионский титул».
      15 июня 2024 года: «Индиана Фивер» — 85, «Чикаго Скай» — 79. Кейтлин Кларк набрала 23 очка и сделала 8 результативных передач.
      20 августа 2024 года: «Лас-Вегас Эйсес» — 92, «Финикс Меркьюри» — 84. Эйжа Уилсон набрала 35 очков.
      # Статистика игрока
      Статистика Эйджи Уилсон за сезон 2024 года: 26,9 очка за игру, 11,9 подбора за игру, 2,6 блок-шота за игру. Получила награду MVP.
      Статистика Кэйтлин Кларк за сезон 2024 года: 19,2 очка за игру, 8,4 передачи за игру, 5,7 подбора за игру. Выиграла награду «Новичок года».
      Статистика Брианны Стюарт за 2024 год: 20,4 очка за игру, 8,5 подбора за игру, 3,5 передачи за игру.
  ])
  retriever = vector_store.as_retriever(search_kwargs={"k": 5})

  @инструмент
  def get_latest_news(query: str) -> str:
      Получайте самые свежие новости и обновления WNBA.
      # Ваш API для новостей здесь
      "Последние новости: WNBA объявила о расширении формата плей-офф на 2025 год..."

  агент = create_agent(
      model="openai:gpt-4.1",
      инструменты=[get_latest_news],
  )

  model = ChatOpenAI(model="gpt-4.1")

  class RewrittenQuery(BaseModel):
      запрос: str

  def rewrite_query(state: State) -> dict:
      «Перепишите пользовательский запрос для более эффективного поиска».
      system_prompt = """Перепишите этот запрос, чтобы получить соответствующую информацию о WNBA."
  База знаний содержит: составы команд, результаты игр с указанием счета и статистику игроков (PPG, RPG, APG).
  Сосредоточьтесь на конкретных именах игроков, названиях команд или упомянутых статистических категориях."""
      response = model.with_structured_output(RewrittenQuery).invoke([
          {"role": "system", "content": system_prompt},
          {"role": "user", "content": state["question"]}
      ])
      return {"rewritten_query": response.query}

  def retrieve(state: State) -> dict:
      «Извлечение документов на основе переписанного запроса».
      docs = retriever.invoke(state["rewritten_query"])
      return {"documents": [doc.page_content for doc in docs]}

  def call_agent(state: State) -> dict:
      """Сгенерируйте ответ, используя полученный контекст."""
      контекст = "\n\n".join(state["documents"])
      prompt = f"Контекст:\n{контекст}\n\nВопрос: {state['question']}"
      response = agent.invoke({"messages": [{"role": "user", "content": prompt}]})
      return {"answer": response["messages"][-1].content_blocks}

  рабочий процесс = (
      StateGraph(State)
      .add_node("rewrite", rewrite_query)
      .add_node("retrieve", retrieve)
      .add_node("agent", call_agent)
      .add_edge(START, "rewrite")
      .add_edge("rewrite", "retrieve")
      .add_edge("retrieve", "agent")
      .add_edge("agent", END)
      .compile()
  )

  result = workflow.invoke({"question": "Кто выиграл чемпионат WNBA 2024 года?"})
  print(result["answer"])
  ```
</Аккордеон>
