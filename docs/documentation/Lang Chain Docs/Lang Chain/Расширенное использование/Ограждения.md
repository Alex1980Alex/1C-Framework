# Ограждения

> Внедрите проверки безопасности и фильтрацию контента для ваших агентов.

Системы контроля помогают создавать безопасные и соответствующие нормативным требованиям приложения на основе ИИ, проверяя и фильтруя контент в ключевых точках выполнения агента. Они могут обнаруживать конфиденциальную информацию, обеспечивать соблюдение политик в отношении контента, проверять результаты и предотвращать небезопасное поведение до того, как оно приведет к проблемам.

К типичным сценариям использования относятся:

* Предотвращение утечки персональных данных
* Выявление и блокировка атак с использованием мгновенной инъекции
* Блокировка неприемлемого или вредоносного контента
* Обеспечение соблюдения бизнес-правил и требований соответствия.
* Проверка качества и точности выходных данных

Вы можете реализовать механизмы контроля с помощью [промежуточного ПО](/oss/python/langchain/middleware), чтобы перехватывать выполнение в стратегически важных точках — до запуска агента, после его завершения или во время вызовов модели и инструментов.

## Встроенные ограждения

### Выявление персональных данных

LangChain предоставляет встроенное промежуточное программное обеспечение для обнаружения и обработки персональных данных (PII) в диалогах. Это ПО может обнаруживать распространенные типы персональных данных, такие как электронные письма, данные кредитных карт, IP-адреса и многое другое.

Промежуточное программное обеспечение для обнаружения персональных данных полезно в таких случаях, как приложения в сфере здравоохранения и финансов с требованиями к соблюдению нормативных требований, агенты службы поддержки клиентов, которым необходимо очищать журналы, и в целом любое приложение, обрабатывающее конфиденциальные данные пользователей.

Промежуточное программное обеспечение для обработки персональных данных поддерживает несколько стратегий обработки обнаруженных персональных данных:

| Стратегия | Описание                                      | Пример                |
| --------- | --------------------------------------------- | --------------------- |
| `redact`  | Заменить на `[REDACTED_{PII_TYPE}]`           | `[REDACTED_EMAIL]`    |
| `маска`   | Частично неясно (например, последние 4 цифры) | `****-****-****-1234` |
| `хеш`     | Заменить на детерминированный хеш             | `a8f5f167...`         |
| `block`   | Вызывает исключение при обнаружении           | Выбрасывается ошибка  |

```python theme={null}
from langchain.agents import create_agent
from langchain.agents.middleware import PIIMiddleware


агент = create_agent(
    model="gpt-4.1",
    tools=[customer_service_tool, email_tool],
    промежуточное ПО=[
        # Удаляйте адреса электронной почты из пользовательского ввода перед отправкой в ​​модель
        PIIMiddleware(
            "электронная почта",
            стратегия="редактировать",
            apply_to_input=True,
        ),
        # Маскировка данных кредитных карт во вводимых пользователем данных
        PIIMiddleware(
            "кредитная карта",
            стратегия="маска",
            apply_to_input=True,
        ),
        # Блокировка ключей API - выдача ошибки при обнаружении
        PIIMiddleware(
            "api_key",
            детектор=r"sk-[a-zA-Z0-9]{32}",
            стратегия="блок",
            apply_to_input=True,
        ),
    ],
)

# Когда пользователь предоставляет персональные данные, обработка будет производиться в соответствии со стратегией.
результат = agent.invoke({
    "messages": [{"role": "user", "content": "Мой адрес электронной почты: john.doe@example.com, номер карты: 5105-1051-0510-5100"}]
})
```

### Человек в процессе

LangChain предоставляет встроенное промежуточное программное обеспечение, позволяющее запрашивать одобрение человека перед выполнением важных операций. Это один из наиболее эффективных механизмов защиты при принятии решений, имеющих решающее значение.

Промежуточное программное обеспечение с участием человека полезно в таких случаях, как финансовые транзакции и переводы, удаление или изменение производственных данных, отправка сообщений внешним сторонам и любые операции, оказывающие существенное влияние на бизнес.

```python theme={null}
from langchain.agents import create_agent
from langchain.agents.middleware import HumanInTheLoopMiddleware
from langgraph.checkpoint.memory import InMemorySaver
from langgraph.types import Command


агент = create_agent(
    model="gpt-4.1",
    tools=[search_tool, send_email_tool, delete_database_tool],
    промежуточное ПО=[
        HumanInTheLoopMiddleware(
            interrupt_on={
                # Требуется согласование для проведения конфиденциальных операций
                "send_email": True,
                "delete_database": True,
                # Автоматическое подтверждение безопасных операций
                "поиск": Ложь,
            }
        ),
    ],
    # Сохранение состояния при прерываниях
    checkpointer=InMemorySaver(),
)

# Для обеспечения возможности сохранения данных при участии человека требуется идентификатор потока.
config = {"configurable": {"thread_id": "some_id"}}

# Агент приостановит выполнение и будет ждать подтверждения, прежде чем запускать конфиденциальные инструменты.
результат = agent.invoke(
    {"messages": [{"role": "user", "content": "Отправить электронное письмо команде"}]},
    config=config
)

результат = agent.invoke(
    Command(resume={"decisions": [{"type": "approve"}]}),
    config=config # Тот же идентификатор потока для возобновления приостановленного разговора
)
```

## Перила, изготовленные на заказ

Для более сложных механизмов защиты можно создать пользовательское промежуточное ПО, которое запускается до или после выполнения агента. Это дает полный контроль над логикой проверки, фильтрацией контента и проверками безопасности.

### До введения ограничений для агентов

Используйте обработчики событий «перед агентом», чтобы проверять запросы один раз в начале каждого вызова. Это полезно для проверок на уровне сессии, таких как аутентификация, ограничение скорости или блокировка неподходящих запросов до начала какой-либо обработки.

<CodeGroup>
  ```python title="Класс синтаксиса" theme={null}
  из набора текста импортировать Any

  from langchain.agents.middleware import AgentMiddleware, AgentState, hook_config
  from langgraph.runtime import Runtime

  класс ContentFilterMiddleware(AgentMiddleware):
      «Детерминированный механизм защиты: блокировка запросов, содержащих запрещенные ключевые слова».

      def __init__(self, banned_keywords: list[str]):
          super().__init__()
          self.banned_keywords = [kw.lower() for kw in banned_keywords]

      @hook_config(can_jump_to=["end"])
      def before_agent(self, state: AgentState, runtime: Runtime) -> dict[str, Any] | None:
          # Получить первое сообщение от пользователя
          если не state["messages"]:
              вернуть None

          first_message = state["messages"][0]
          если first_message.type != "human":
              вернуть None

          content = first_message.content.lower()

          # Проверка на наличие запрещенных ключевых слов
          for keyword in self.banned_keywords:
              если ключевое слово присутствует в содержимом:
                  # Блокировка выполнения перед любой обработкой
                  возвращаться {
                      "сообщения": [{
                          "роль": "ассистент",
                          «Содержание»: «Я не могу обрабатывать запросы, содержащие неприемлемый контент. Пожалуйста, переформулируйте свой запрос».
                      }],
                      "jump_to": "end"
                  }

          вернуть None

  # Использовать пользовательское ограждение
  from langchain.agents import create_agent

  агент = create_agent(
      model="gpt-4.1",
      инструменты=[инструмент поиска, инструмент калькулятора],
      промежуточное ПО=[
          ContentFilterMiddleware(
              banned_keywords=["hack", "exploit", "malware"]
          ),
      ],
  )

  # Этот запрос будет заблокирован до начала обработки
  результат = agent.invoke({
      "messages": [{"role": "user", "content": "How do I hack into database?"}]
  })
  ```

### После введения ограничений для агентов

Используйте обработчики событий "после агента", чтобы проверить окончательные результаты перед возвратом пользователю. Это полезно для проверок безопасности на основе моделей, проверки качества или окончательной проверки соответствия полному ответу агента.

<CodeGroup>
  ```python title="Класс синтаксиса" theme={null}
  from langchain.agents.middleware import AgentMiddleware, AgentState, hook_config
  from langgraph.runtime import Runtime
  из langchain.messages импортировать AIMessage
  from langchain.chat_models import init_chat_model
  из набора текста импортировать Any

  класс SafetyGuardrailMiddleware(AgentMiddleware):
      «Ограничительные меры на основе моделей: используйте модель LLM для оценки безопасности реагирования».

      def __init__(self):
          super().__init__()
          self.safety_model = init_chat_model("gpt-4.1-mini")

      @hook_config(can_jump_to=["end"])
      def after_agent(self, state: AgentState, runtime: Runtime) -> dict[str, Any] | None:
          # Получение окончательного ответа ИИ
          если не state["messages"]:
              вернуть None

          last_message = state["messages"][-1]
          if not isinstance(last_message, AIMessage):
              вернуть None

          # Используйте модель для оценки безопасности
          safety_prompt = f"""Оцените, является ли этот ответ безопасным и уместным.
          Отвечайте только словами «БЕЗОПАСНО» или «НЕБЕЗОПАСНО».

          Ответ: {last_message.content}"""

          result = self.safety_model.invoke([{"role": "user", "content": safety_prompt}])

          если "UNSAFE" в result.content:
              last_message.content = "Я не могу предоставить этот ответ. Пожалуйста, переформулируйте свой запрос."

          вернуть None

  # Используйте защитное ограждение
  from langchain.agents import create_agent

  агент = create_agent(
      model="gpt-4.1",
      инструменты=[инструмент поиска, инструмент калькулятора],
      промежуточное ПО=[SafetyGuardrailMiddleware()],
  )

  результат = agent.invoke({
      "messages": [{"role": "user", "content": "Как сделать взрывчатку?"}]
  })
  ```

### Объединение нескольких ограждений

Вы можете добавить несколько механизмов защиты в массив промежуточного ПО. Они выполняются последовательно, что позволяет создавать многоуровневую защиту:

```python theme={null}
from langchain.agents import create_agent
from langchain.agents.middleware import PIIMiddleware, HumanInTheLoopMiddleware

агент = create_agent(
    model="gpt-4.1",
    tools=[search_tool, send_email_tool],
    промежуточное ПО=[
        # Слой 1: Детерминированный входной фильтр (до агента)
        ContentFilterMiddleware(banned_keywords=["hack", "exploit"]),

        # Уровень 2: Защита персональных данных (модель до и после)
        PIIMiddleware("email", strategy="redact", apply_to_input=True),
        PIIMiddleware("email", strategy="redact", apply_to_output=True),

        # Уровень 3: Человеческий контроль за использованием конфиденциальных инструментов
        HumanInTheLoopMiddleware(interrupt_on={"send_email": True}),

        # Уровень 4: Проверка безопасности на основе модели (после агента)
        SafetyGuardrailMiddleware(),
    ],
)
```
