# Время выполнения

## Обзор

Функция [`create_agent`](https://reference.langchain.com/python/langchain/agents/#langchain.agents.create_agent) в LangChain работает на основе среды выполнения LangGraph.

LangGraph предоставляет объект [`Runtime`](https://reference.langchain.com/python/langgraph/runtime/#langgraph.runtime.Runtime) со следующей информацией:

1. **Контекст**: статическая информация, такая как идентификатор пользователя, подключения к базе данных или другие зависимости для вызова агента.
2. **Хранилище**: экземпляр [BaseStore](https://reference.langchain.com/python/langgraph/store/#langgraph.store.base.BaseStore), используемый для [долговременной памяти](/oss/python/langchain/long-term-memory)
3. **Потоковой записыватель**: объект, используемый для потоковой передачи информации в режиме «пользовательского» потока.

<Совет>
  Контекст среды выполнения обеспечивает **внедрение зависимостей** для ваших инструментов и промежуточного ПО. Вместо жесткого кодирования значений или использования глобального состояния вы можете внедрять зависимости среды выполнения (например, подключения к базе данных, идентификаторы пользователей или конфигурацию) при вызове вашего агента. Это делает ваши инструменты более тестируемыми, многократно используемыми и гибкими.
</Совет>

Вы можете получить доступ к информации о времени выполнения в [инструментах](#inside-tools) и [промежуточном ПО](#inside-middleware).

## Доступ

При создании агента с помощью [`create_agent`](https://reference.langchain.com/python/langchain/agents/#langchain.agents.create_agent) можно указать `context_schema`, чтобы определить структуру `context`, хранящегося в агенте [`Runtime`](https://reference.langchain.com/python/langgraph/runtime/#langgraph.runtime.Runtime).

При запуске агента передайте аргумент `context` с соответствующей конфигурацией для выполнения:

```python theme={null}
from dataclasses import dataclass

from langchain.agents import create_agent


@dataclass
Контекст класса:
    имя_пользователя: строка

агент = create_agent(
    model="gpt-5-nano",
    инструменты=[...],
    context_schema=Context # [!code highlight]
)

agent.invoke(
    {"messages": [{"role": "user", "content": "Как меня зовут?"}]},
    context=Context(user_name="John Smith") # [!code highlight]
)
```

### Внутренние инструменты

Вы можете получить доступ к информации о времени выполнения внутри инструментов, чтобы:

* Получите доступ к контексту
* Чтение или запись в долговременную память
* Запись в [пользовательский поток](/oss/python/langchain/streaming#custom-updates) (например, отслеживание прогресса работы инструмента / обновления)

Используйте параметр `ToolRuntime` для доступа к объекту [`Runtime`](https://reference.langchain.com/python/langgraph/runtime/#langgraph.runtime.Runtime) внутри инструмента.

```python theme={null}
from dataclasses import dataclass
from langchain.tools import tool, ToolRuntime # [!code highlight]

@dataclass
Контекст класса:
    user_id: str

@инструмент
def fetch_user_email_preferences(runtime: ToolRuntime[Context]) -> str: # [!code highlight]
    «Получить настройки электронной почты пользователя из хранилища».
    user_id = runtime.context.user_id # [!code highlight]

    preferences: str = "Пользователь предпочитает, чтобы вы написали короткое и вежливое электронное письмо."
    if runtime.store: # [!подсветка кода]
        if memory := runtime.store.get(("users",), user_id): # [!code highlight]
            preferences = memory.value["preferences"]

    предпочтения возврата
```

### Внутри промежуточного ПО

В промежуточном ПО можно получить доступ к информации, получаемой во время выполнения, для создания динамических подсказок, изменения сообщений или управления поведением агента в зависимости от контекста пользователя.

Для доступа к объекту [`Runtime`](https://reference.langchain.com/python/langgraph/runtime/#langgraph.runtime.Runtime) внутри [хуков в стиле узлов](/oss/python/langchain/middleware/custom#node-style-hooks). Для [хуков в стиле оберток](/oss/python/langchain/middleware/custom#wrap-style-hooks) объект `Runtime` доступен внутри параметра [`ModelRequest`](https://reference.langchain.com/python/langchain/middleware/#langchain.agents.middleware.ModelRequest).

```python theme={null}
from dataclasses import dataclass

from langchain.messages import AnyMessage
from langchain.agents import create_agent, AgentState
from langchain.agents.middleware import dynamic_prompt, ModelRequest, before_model, after_model
from langgraph.runtime import Runtime


@dataclass
Контекст класса:
    имя_пользователя: строка

# Динамические подсказки
@dynamic_prompt
def dynamic_system_prompt(request: ModelRequest) -> str:
    user_name = request.runtime.context.user_name # [!code highlight]
    system_prompt = f"Вы полезный помощник. Обращайтесь к пользователю как {user_name}."
    return system_prompt

# Перед хуком модели
@before_model
def log_before_model(state: AgentState, runtime: Runtime[Context]) -> dict | None: # [!code highlight]
    print(f"Обработка запроса для пользователя: {runtime.context.user_name}") # [!подсветка кода]
    вернуть None

# После модели хук
@after_model
def log_after_model(state: AgentState, runtime: Runtime[Context]) -> dict | None: # [!code highlight]
    print(f"Запрос выполнен для пользователя: {runtime.context.user_name}") # [!code highlight]
    вернуть None

агент = create_agent(
    model="gpt-5-nano",
    инструменты=[...],
    middleware=[dynamic_system_prompt, log_before_model, log_after_model], # [!code highlight]
    context_schema=Context
)

agent.invoke(
    {"messages": [{"role": "user", "content": "Как меня зовут?"}]},
    context=Context(user_name="John Smith")
)
```
