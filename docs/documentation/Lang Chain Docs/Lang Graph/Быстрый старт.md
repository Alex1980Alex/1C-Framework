# Быстрый старт

В этом кратком руководстве показано, как создать агента-калькулятора, используя API графов LangGraph или функциональный API.

* [Используйте Graph API](#use-the-graph-api), если вы предпочитаете определять своего агента как граф узлов и ребер.
* [Используйте функциональный API](#use-the-functional-api), если вы предпочитаете определять своего агента как единую функцию.

Для получения концептуальной информации см. [Обзор Graph API](/oss/python/langgraph/graph-api) и [Обзор функционального API](/oss/python/langgraph/functional-api).

<Информация>
  В этом примере вам потребуется создать учетную запись [Claude (Anthropic)](https://www.anthropic.com/) и получить ключ API. Затем установите переменную среды `ANTHROPIC_API_KEY` в терминале.
</Info>

    ## 2. Определите состояние

    Состояние графа используется для хранения сообщений и количества вызовов LLM.

    <Совет>
      Состояние в LangGraph сохраняется на протяжении всего выполнения агента.

      Тип `Annotated` с оператором `operator.add` гарантирует, что новые сообщения будут добавляться к существующему списку, а не заменять его.
    </Совет>

    ```python theme={null}
    from langchain.messages import AnyMessage
    from typing_extensions import TypedDict, Annotated
    импортный оператор


    class MessagesState(TypedDict):
        сообщения: Аннотированные[список[AnyMessage], оператор.add]
        llm_calls: int
    ```

    ## 3. Определение узла модели

    Узел модели используется для вызова LLM и принятия решения о том, следует ли вызывать инструмент или нет.

    ```python theme={null}
    from langchain.messages import SystemMessage


    def llm_call(state: dict):
        «LLM решает, называть ли инструмент или нет»

        возвращаться {
            "сообщения": [
                model_with_tools.invoke(
                    [
                        SystemMessage(
                            content="Вы — полезный помощник, которому поручено выполнять арифметические операции над набором входных данных."
                        )
                    ]
                    + state["messages"]
                )
            ],
            "llm_calls": state.get('llm_calls', 0) + 1
        }
    ```

    ## 4. Определение узла инструмента

    Узел инструмента используется для вызова инструментов и возврата результатов.

    ```python theme={null}
    from langchain.messages import ToolMessage


    def tool_node(state: dict):
        """Выполняет вызов инструмента"""

        результат = []
        for tool_call in state["messages"][-1].tool_calls:
            инструмент = tools_by_name[tool_call["name"]]
            observation = tool.invoke(tool_call["args"])
            result.append(ToolMessage(content=observation, tool_call_id=tool_call["id"]))
        return {"messages": result}
    ```

    ## 5. Определите логику завершения

    Функция условного ребра используется для маршрутизации к узлу инструмента или к конечной точке в зависимости от того, выполнил ли LLM вызов инструмента.

    ```python theme={null}
    from typing import Literal
    from langgraph.graph import StateGraph, START, END


    def should_continue(state: MessagesState) -> Literal["tool_node", END]:
        «Решите, следует ли нам продолжать цикл или остановиться, исходя из того, сделал ли LLM запрос на использование инструмента».

        сообщения = состояние["сообщения"]
        last_message = messages[-1]

        # Если LLM вызывает инструмент, выполните действие.
        if last_message.tool_calls:
            return "tool_node"

        # В противном случае мы останавливаемся (отправляем ответ пользователю)
    ```

    ## 6. Сборка и компиляция агента

    Агент создается с использованием класса [`StateGraph`](https://reference.langchain.com/python/langgraph/graphs/#langgraph.graph.state.StateGraph) и компилируется с помощью метода [`compile`](https://reference.langchain.com/python/langgraph/graphs/#langgraph.graph.state.StateGraph.compile).

    ```python theme={null}
    # Создание рабочего процесса
    agent_builder = StateGraph(MessagesState)

    # Добавить узлы
    agent_builder.add_node("llm_call", llm_call)
    agent_builder.add_node("tool_node", tool_node)

    # Добавить ребра для соединения узлов
    agent_builder.add_edge(START, "llm_call")
    agent_builder.add_conditional_edges(
        "llm_call",
        should_continue,
        ["tool_node", END]
    )
    agent_builder.add_edge("tool_node", "llm_call")

    # Компиляция агента
    agent = agent_builder.compile()

    # Показать агента
    from IPython.display import Image, display
    display(Image(agent.get_graph(xray=True).draw_mermaid_png()))

    # Вызов
    from langchain.messages import HumanMessage
    сообщения = [HumanMessage(content="Добавьте 3 и 4.")]
    messages = agent.invoke({"messages": messages})
    for m in messages["messages"]:
        m.pretty_print()
    ```

    <Совет>
      Чтобы узнать, как отслеживать действия вашего агента с помощью LangSmith, см. [документацию LangSmith](/langsmith/trace-with-langgraph).
    </Совет>

    ## 2. Определение узла модели

    Узел модели используется для вызова LLM и принятия решения о том, следует ли вызывать инструмент или нет.

    <Совет>
      Декоратор [`@task`](https://reference.langchain.com/python/langgraph/func/#langgraph.func.task) помечает функцию как задачу, которая может быть выполнена в рамках агента. Задачи могут вызываться синхронно или асинхронно внутри вашей функции точки входа.
    </Совет>

    ```python theme={null}
    @задача
    def call_llm(messages: list[BaseMessage]):
        «LLM решает, называть ли инструмент или нет»
        return model_with_tools.invoke(
            [
                SystemMessage(
                    content="Вы — полезный помощник, которому поручено выполнять арифметические операции над набором входных данных."
                )
            ]
            + сообщения
        )
    ```

    ## 3. Определение узла инструмента

    Узел инструмента используется для вызова инструментов и возврата результатов.

    ```python theme={null}
    @задача
    ```

    ## 4. Определение агента

    Агент создается с использованием функции [`@entrypoint`](https://reference.langchain.com/python/langgraph/func/#langgraph.func.entrypoint).

    <Примечание>
      В функциональном API вместо явного определения узлов и ребер вы пишете стандартную логику управления потоком выполнения (циклы, условные операторы) в рамках одной функции.
    </Примечание>

    ```python theme={null}
    @entrypoint()
    def agent(messages: list[BaseMessage]):
        model_response = call_llm(messages).result()

        пока истинно:
            if not model_response.tool_calls:
                перерыв

            # Выполнение инструментов
            tool_result_futures = [
                call_tool(tool_call) for tool_call in model_response.tool_calls
            ]
            tool_results = [fut.result() for fut in tool_result_futures]
            messages = add_messages(messages, [model_response, *tool_results])
            model_response = call_llm(messages).result()

        messages = add_messages(messages, model_response)
        возвращать сообщения

    # Вызов
    сообщения = [HumanMessage(content="Добавьте 3 и 4.")]
    for chunk in agent.stream(messages, stream_mode="updates"):
        print(chunk)
        print("\n")
    ```
