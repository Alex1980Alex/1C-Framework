# Использовать путешествие во времени

При работе с недетерминированными системами, принимающими решения на основе моделей (например, агентами, использующими модели с низкой степенью детерминации), может быть полезно детально изучить процесс принятия ими решений:

1. <Icon icon="lightbulb" size={16} /> **Понимание логики**: Проанализируйте шаги, которые привели к успешному результату.
2. <Icon icon="bug" size={16} /> **Отладка ошибок**: Определите, где и почему возникли ошибки.
3. <Icon icon="magnifying-glass" size={16} /> **Изучите альтернативы**: протестируйте разные пути, чтобы найти лучшие решения.

LangGraph предоставляет функциональность «путешествия во времени» для поддержки подобных сценариев использования. В частности, вы можете возобновить выполнение с предыдущей контрольной точки — либо воспроизведя то же состояние, либо изменив его для изучения альтернативных вариантов. Во всех случаях возобновление выполнения с прошлого создает новую ветку в истории.

Чтобы использовать функцию перемещения во времени в LangGraph:

1. [Запустите граф](#1-run-the-graph) с начальными входными данными, используя методы [`invoke`](https://reference.langchain.com/python/langgraph/graphs/#langgraph.graph.state.CompiledStateGraph.invoke) или [`stream`](https://reference.langchain.com/python/langgraph/graphs/#langgraph.graph.state.CompiledStateGraph.stream).
2. [Идентификация контрольной точки в существующем потоке](#2-identify-a-checkpoint): Используйте метод [`get_state_history`](https://reference.langchain.com/python/langgraph/graphs/#langgraph.graph.state.CompiledStateGraph.get_state_history), чтобы получить историю выполнения для конкретного `thread_id` и найти нужный `checkpoint_id`.
   В качестве альтернативы, установите прерывание ([interrupt](/oss/python/langgraph/interrupts)) перед узлом (узлами), где вы хотите приостановить выполнение. Затем вы сможете найти самую последнюю контрольную точку, записанную до этого прерывания.
3. [Обновление состояния графа (необязательно)](#3-update-the-state-optional): Используйте метод [`update_state`](https://reference.langchain.com/python/langgraph/graphs/#langgraph.graph.state.CompiledStateGraph.update_state), чтобы изменить состояние графа в контрольной точке и возобновить выполнение с альтернативного состояния.
4. [Возобновить выполнение с контрольной точки](#4-resume-execution-from-the-checkpoint): Используйте методы `invoke` или `stream` с входным параметром `None` и конфигурацией, содержащей соответствующие `thread_id` и `checkpoint_id`.

## В рабочем процессе

В этом примере создан простой рабочий процесс LangGraph, который генерирует тему для шутки и пишет шутку, используя LLM. Демонстрируется, как запустить граф, получить предыдущие контрольные точки выполнения, при необходимости изменить состояние и возобновить выполнение с выбранной контрольной точки для изучения альтернативных вариантов.

### Настраивать

Для построения этого рабочего процесса в данном примере необходимо настроить Anthropic LLM и установить необходимые зависимости:

1. Установите зависимости:

```bash theme={null}
pip install langchain_core langchain-anthropic langgraph
```

2. Инициализируйте LLM:

```python theme={null}
импорт os
импортировать getpass

from langchain_anthropic import ChatAnthropic

def _set_env(var: str):
    if not os.environ.get(var):
        os.environ[var] = getpass.getpass(f"{var}: ")


_set_env("ANTHROPIC_API_KEY")

llm = ChatAnthropic(model="claude-sonnet-4-5-20250929")
```

<Совет>
  Зарегистрируйтесь в [LangSmith](https://smith.langchain.com), чтобы быстро выявлять проблемы и улучшать производительность ваших проектов LangGraph. LangSmith позволяет использовать данные трассировки для отладки, тестирования и мониторинга ваших приложений LLM, созданных с помощью LangGraph. Вы также можете [получать трассировки из LangSmith](/langsmith/export-traces#fetch-a-single-run-by-id), чтобы воспроизводить и отлаживать проблемы в производственной среде локально.
</Совет>

3. Внедрить рабочий процесс
   Реализация рабочего процесса представляет собой простой граф с двумя узлами: один для генерации темы шутки, другой для написания самой шутки и состояние для хранения промежуточных значений.

```python theme={null}
импорт uuid

from typing_extensions import TypedDict, NotRequired
from langgraph.graph import StateGraph, START, END
from langchain.chat_models import init_chat_model
from langgraph.checkpoint.memory import InMemorySaver


class State(TypedDict):
    тема: NotRequired[str]
    шутка: NotRequired[str]


модель = init_chat_model(
    "claude-sonnet-4-5-20250929",
    температура = 0,
)


def generate_topic(state: State):
    «Приглашение от LLM придумать тему для шутки»
    msg = model.invoke("Придумайте забавную тему для шутки")
    return {"topic": msg.content}


def write_joke(state: State):
    «Лаборатория права предлагает написать шутку на заданную тему»
    msg = model.invoke(f"Напишите короткую шутку о {state['topic']}")
    return {"joke": msg.content}


# Создание рабочего процесса
рабочий процесс = StateGraph(State)

# Добавить узлы
workflow.add_node("generate_topic", generate_topic)
workflow.add_node("write_joke", write_joke)

# Добавить ребра для соединения узлов
workflow.add_edge(START, "generate_topic")
workflow.add_edge("generate_topic", "write_joke")
workflow.add_edge("write_joke", END)

# Компиляция
checkpointer = InMemorySaver()
graph = workflow.compile(checkpointer=checkpointer)
график
```

### 1. Запустите график

Для запуска рабочего процесса вызывается метод [`invoke`](https://reference.langchain.com/python/langgraph/graphs/#langgraph.graph.state.CompiledStateGraph.invoke) без каких-либо входных данных. Обратите внимание на `thread_id`, чтобы отслеживать это выполнение и получать контрольные точки позже.

```python theme={null}
config = {
    "настраиваемый": {
        "thread_id": uuid.uuid4(),
    }
}
state = graph.invoke({}, config)

print(state["topic"])
print()
print(state["joke"])
```

**Выход:**

```
Как насчет «Тайной жизни носков в сушилке»? Ну, знаете, исследовать загадочное явление, когда носки попадают в стирку парами, а выходят поодиночке. Куда они деваются? Начинают ли они новую жизнь где-то еще? Существует ли некий рай для носков, о котором мы не знаем? В этой повседневной загадке, которая объединяет нас всех, таится огромный комедийный потенциал!

# Тайная жизнь носков в сушилке

Я наконец-то обнаружила, куда деваются все мои пропавшие носки после сушки в сушилке. Оказалось, они вовсе не пропали — они просто сбежали с чужими носками из прачечной, чтобы начать новую жизнь вместе.

Моя синяя ромбовидная туфля теперь живет на Бермудах с красной в горошек, выкладывает фотографии с отдыха в Sockstagram и присылает мне ворсинки в качестве алиментов.
```

### 2. Определите контрольную точку

Чтобы продолжить выполнение с предыдущего момента в графе, используйте [`get_state_history`](https://reference.langchain.com/python/langgraph/graphs/#langgraph.graph.state.CompiledStateGraph.get_state_history), чтобы получить все состояния и выбрать то, с которого вы хотите возобновить выполнение.

```python theme={null}
# Штаты возвращаются в обратном хронологическом порядке.
states = list(graph.get_state_history(config))

для штата в штатах:
    print(state.next)
    print(state.config["configurable"]["checkpoint_id"])
    print()
```

**Выход:**

```
()
1f02ac4a-ec9f-6524-8002-8f7b0bbeed0e

('write_joke',)
1f02ac4a-ce2a-6494-8001-cb2e2d651227

('generate_topic',)
1f02ac4a-a4e0-630d-8000-b73c254ba748

('__начинать__',)
1f02ac4a-a4dd-665e-bfff-e6c8c44315d9
```

```python theme={null}
# Это предпоследний штат (штаты перечислены в хронологическом порядке)
selected_state = states[1]
print(selected_state.next)
print(selected_state.values)
```

**Выход:**


<a id="optional" />

### 3. Обновить состояние (необязательно)

Функция `update_state`(https://reference.langchain.com/python/langgraph/graphs/#langgraph.graph.state.CompiledStateGraph.update_state) создаст новую контрольную точку. Новая контрольная точка будет связана с тем же потоком, но с новым идентификатором.

```python theme={null}
new_config = graph.update_state(selected_state.config, values={"topic": "chickens"})
print(new_config)
```

**Выход:**

```
{'configurable': {'thread_id': 'c62e2e03-c27b-4cb6-8cea-ea9bfedae006', 'checkpoint_ns': '', 'checkpoint_id': '1f02ac4a-ecee-600b-8002-a1d21df32e4c'}}
```

### 4. Возобновить выполнение с контрольной точки

Для возобновления выполнения с выбранной контрольной точки вызовите [`invoke`](https://reference.langchain.com/python/langgraph/graphs/#langgraph.graph.state.CompiledStateGraph.invoke) с конфигурацией, указывающей на новую контрольную точку.

```python theme={null}
graph.invoke(None, new_config)
```

**Выход:**

```python theme={null}
{'topic': 'chickens',
 «Шутка»: «Почему курица присоединилась к музыкальной группе?\n\nПотому что у неё были отличные куриные ножки!»
```
