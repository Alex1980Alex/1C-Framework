# Запустить локальный сервер

В этом руководстве показано, как запустить приложение LangGraph локально.

## Предварительные условия

Прежде чем начать, убедитесь, что у вас есть следующее:

* API-ключ для [LangSmith](https://smith.langchain.com/settings) — регистрация бесплатна.

## 1. Установите LangGraph CLI

<CodeGroup>
  ```bash pip theme={null}
  # Требуется Python >= 3.11.
  pip install -U "langgraph-cli[inmem]"
  ```

  ```bash uv theme={null}
  # Требуется Python >= 3.11.
  uv add "langgraph-cli[inmem]"
  ```
</CodeGroup>

## 2. Создайте приложение LangGraph

Создайте новое приложение, используя [шаблон `new-langgraph-project-python`](https://github.com/langchain-ai/new-langgraph-project). Этот шаблон демонстрирует одноузловое приложение, которое вы можете расширить собственной логикой.

```shell theme={null}
langgraph new path/to/your/app --template new-langgraph-project-python
```

<Совет>
  **Дополнительные шаблоны**
  Если вы используете команду `langgraph new` без указания шаблона, вам будет показано интерактивное меню, позволяющее выбрать один из доступных шаблонов.
</Совет>

## 3. Установка зависимостей

В корневой директории вашего нового приложения LangGraph установите зависимости в режиме `edit`, чтобы ваши локальные изменения использовались сервером:

<CodeGroup>
  ```bash pip theme={null}
  cd path/to/your/app
  pip install -e .
  ```

  ```bash uv theme={null}
  cd path/to/your/app
  uv sync
  ```
</CodeGroup>

## 4. Создайте файл `.env`

В корневой директории вашего нового приложения LangGraph вы найдете файл `.env.example`. Создайте файл `.env` в корневой директории вашего нового приложения LangGraph и скопируйте в него содержимое файла `.env.example`, указав необходимые ключи API:

```bash theme={null}
LANGSMITH_API_KEY=lsv2...
```

## 5. Запуск сервера агента

Запустите сервер LangGraph API локально:

```shell theme={null}
langgraph dev
```

Пример выходных данных:

```
ИНФО:langgraph_api.cli:

        Добро пожаловать в

╦ ┌─┐┌┐┌┌─┐╔═╗┬─┐┌─┐┌─┐┬ ┬
║ ├─┤││││ ┬║ ╦├┬┘├─┤├─┘├─┤
╩═╝┴ ┴┘└┘└─┘╚═╝┴└─┴ ┴┴ ┴ ┴

- 🚀 API: http://127.0.0.1:2024
- 🎨 Пользовательский интерфейс студии: https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024
- 📚 Документы API: http://127.0.0.1:2024/docs

Этот сервер, работающий в оперативной памяти, предназначен для разработки и тестирования.
Для использования в производственной среде, пожалуйста, используйте LangSmith Deployment.
```

Команда `langgraph dev` запускает Agent Server в режиме работы в оперативной памяти. Этот режим подходит для разработки и тестирования. Для использования в производственной среде разверните Agent Server с доступом к постоянному хранилищу. Для получения дополнительной информации см. [Обзор настройки платформы](/langsmith/platform-setup).

## 6. Протестируйте свое приложение в Studio

[Studio](/langsmith/studio) — это специализированный пользовательский интерфейс, позволяющий подключаться к API-серверу LangGraph для визуализации, взаимодействия и отладки вашего приложения локально. Протестируйте свой граф в Studio, перейдя по URL-адресу, указанному в выводе команды `langgraph dev`:

```
> - Веб-интерфейс LangGraph Studio: https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024
```

Для сервера-агента, работающего на пользовательском хосте/порту, обновите параметр запроса `baseUrl` в URL-адресе. Например, если ваш сервер работает по адресу `http://myhost:3000`:

```
https://smith.langchain.com/studio/?baseUrl=http://myhost:3000
```

<Accordion title="Совместимость с Safari">
  Используйте флаг `--tunnel` в своей команде, чтобы создать защищенный туннель, поскольку Safari имеет ограничения при подключении к серверам localhost:

  ```shell theme={null}
  langgraph dev --tunnel
  ```
</Аккордеон>

## 7. Тестирование API

<Вкладки>
  <Tab title="Python SDK (async)">
    1. Установите LangGraph Python SDK:
       ```shell theme={null}
       pip install langgraph-sdk
       ```
    2. Отправить сообщение помощнику (беспоточный режим выполнения):
       ```python theme={null}
       from langgraph_sdk import get_client
       import asyncio

       client = get_client(url="http://localhost:2024")

       async def main():
           async for chunk in client.runs.stream(
               Нет, # Беспотоковая версия
               "agent", # Имя ассистента. Определено в langgraph.json.
               ввод={
               "сообщения": [{
                   "роль": "человек",
                   «Содержание»: «Что такое LangGraph?»
                   }],
               },
           ):
               print(f"Получение нового события типа: {chunk.event}...")
               print(chunk.data)
               print("\n\n")

       asyncio.run(main())
       ```
  </Tab>

  <Tab title="Python SDK (sync)">
    1. Установите LangGraph Python SDK:
       ```shell theme={null}
       pip install langgraph-sdk
       ```
    2. Отправить сообщение помощнику (беспоточный режим выполнения):
       ```python theme={null}
       from langgraph_sdk import get_sync_client

       client = get_sync_client(url="http://localhost:2024")

       for chunk in client.runs.stream(
           Нет, # Беспотоковая версия
           "agent", # Имя ассистента. Определено в langgraph.json.
           ввод={
               "сообщения": [{
                   "роль": "человек",
                   «Содержание»: «Что такое LangGraph?»
               }],
           },
           stream_mode="messages-tuple",
       ):
           print(f"Получение нового события типа: {chunk.event}...")
           print(chunk.data)
           print("\n\n")
       ```
  </Tab>

  <Tab title="REST API">
    ```bash theme={null}
    curl -s --request POST \
        --url "http://localhost:2024/runs/stream" \
        --header 'Content-Type: application/json' \
        --данные "{
            \"assistant_id\": \"agent\",
            \"вход\": {
                \"сообщения\": [
                    {
                        «роль»: «человек»,
                        «Содержание»: «Что такое LangGraph?»
                    }
                ]
            },
            \"stream_mode\": \"messages-tuple\"
        }"
    ```
  </Tab>
</Вкладки>
