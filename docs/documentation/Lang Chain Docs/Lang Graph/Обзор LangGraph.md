# Обзор LangGraph

Получите полный контроль над разработкой агентов с помощью LangGraph, которые надежно справляются со сложными задачами.

LangGraph — это низкоуровневая платформа оркестрации и среда выполнения для создания, управления и развертывания долго работающими агентами с сохранением состояния, которой доверяют компании, формирующие будущее агентов, включая Klarna, Replit, Elastic и другие.

LangGraph — это очень низкоуровневый инструмент, полностью ориентированный на **оркестрацию** агентов. Перед использованием LangGraph мы рекомендуем ознакомиться с некоторыми компонентами, используемыми для создания агентов, начиная с [models](/oss/python/langchain/models) и [tools](/oss/python/langchain/tools).

В документации мы будем часто использовать компоненты [LangChain](/oss/python/langchain/overview) для интеграции моделей и инструментов, но вам не обязательно использовать LangChain для работы с LangGraph. Если вы только начинаете работать с агентами или хотите использовать более высокий уровень абстракции, мы рекомендуем использовать [агенты](/oss/python/langchain/agents) из LangChain, которые предоставляют готовые архитектуры для распространенных циклов LLM и вызова инструментов.

LangGraph ориентирован на базовые возможности, важные для оркестрации агентов: стабильное выполнение, потоковая передача данных, участие человека и многое другое.

## <Icon icon="download" size={20} /> Установить

<CodeGroup>
  ```bash pip theme={null}
  pip install -U langgraph
  ```

  ```bash uv theme={null}
  uv add langgraph
  ```
</CodeGroup>

Затем создайте простой пример "Hello World":

```python theme={null}
from langgraph.graph import StateGraph, MessagesState, START, END

def mock_llm(state: MessagesState):
    return {"messages": [{"role": "ai", "content": "hello world"}]}

graph = StateGraph(MessagesState)
graph.add_node(mock_llm)
graph.add_edge(START, "mock_llm")
graph.add_edge("mock_llm", END)
graph = graph.compile()

graph.invoke({"messages": [{"role": "user", "content": "hi!"}]})
```

Основные преимущества

LangGraph предоставляет низкоуровневую вспомогательную инфраструктуру для *любого* длительно работающего рабочего процесса или агента с сохранением состояния. LangGraph не абстрагирует подсказки или архитектуру и предоставляет следующие основные преимущества:

* [Устойчивое выполнение](/oss/python/langgraph/durable-execution): Создание агентов, которые сохраняют работоспособность после сбоев и могут работать в течение длительного времени, возобновляя выполнение с того места, где остановились.
* [Human-in-the-loop](/oss/python/langgraph/interrupts): Обеспечивает контроль со стороны человека путем проверки и изменения состояния агента в любой момент времени.
* [Комплексная память](/oss/python/concepts/memory): Создание агентов с сохранением состояния, обладающих как кратковременной рабочей памятью для текущих рассуждений, так и долговременной памятью между сессиями.
* [Отладка с помощью LangSmith](/langsmith/home): Получите глубокое понимание сложного поведения агентов с помощью инструментов визуализации, которые отслеживают пути выполнения, фиксируют переходы состояний и предоставляют подробные метрики во время выполнения.
* [Готовое к использованию развертывание](/langsmith/deployments): Уверенно развертывайте сложные агентские системы с помощью масштабируемой инфраструктуры, разработанной для решения уникальных задач, связанных с длительными рабочими процессами с сохранением состояния.

## Экосистема LangGraph

Хотя LangGraph можно использовать автономно, он также легко интегрируется с любым продуктом LangChain, предоставляя разработчикам полный набор инструментов для создания агентов. Для улучшения разработки приложений LLM используйте LangGraph в паре со следующими компонентами:
