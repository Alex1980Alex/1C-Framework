# Развертывание LangSmith

В этом руководстве показано, как развернуть агента в **[LangSmith Cloud](/langsmith/deploy-to-cloud)**, полностью управляемой платформе хостинга, разработанной для рабочих нагрузок агентов. Благодаря облачному развертыванию вы можете развертывать агента непосредственно из своего репозитория GitHub — LangSmith берет на себя инфраструктурные, масштабируемые и операционные вопросы.

Традиционные хостинговые платформы созданы для веб-приложений без сохранения состояния и с коротким сроком жизни. LangSmith Cloud **специально разработан для агентов с сохранением состояния и длительным сроком работы**, которым требуется постоянное состояние и фоновое выполнение.

<Совет>
  LangSmith предлагает несколько вариантов развертывания, помимо облачных решений, включая развертывание с использованием [управляющей плоскости (гибридной/самостоятельно размещенной)](/langsmith/deploy-with-control-plane) или в виде [автономных серверов](/langsmith/deploy-standalone-server). Для получения дополнительной информации см. [Обзор развертывания](/langsmith/deployments).
</Совет>

## Предварительные условия

Прежде чем начать, убедитесь, что у вас есть следующее:

* Аккаунт GitHub (https://github.com/)
* Аккаунт LangSmith (https://smith.langchain.com/) (регистрация бесплатна)

## Разверните своего агента

### 1. Создайте репозиторий на GitHub

Для развертывания в LangSmith код вашего приложения должен находиться в репозитории GitHub. Поддерживаются как публичные, так и частные репозитории. Для этого краткого руководства сначала убедитесь, что ваше приложение совместимо с LangGraph, следуя [руководству по настройке локального сервера](/oss/python/langgraph/studio#setup-local-agent-server). Затем загрузите свой код в репозиторий.

### 2. Развертывание в LangSmith

<Шаги>
  <Заголовок шага="Переход к развертыванию LangSmith">
    Войдите в [LangSmith](https://smith.langchain.com/). В левой боковой панели выберите **Развертывания**.
  </Шаг>

  <Шаг title="Создать новое развертывание">
    Нажмите кнопку **+ Новое развертывание**. Откроется панель, где вы сможете заполнить необходимые поля.
  </Шаг>

  <Step title="Ссылка на репозиторий">
    Если вы впервые используете GitHub или добавляете частный репозиторий, который ранее не был подключен, нажмите кнопку **Добавить новую учетную запись** и следуйте инструкциям для подключения вашей учетной записи GitHub.
  </Шаг>

  <Шаг title="Развернуть репозиторий">
    Выберите репозиторий вашего приложения. Нажмите **Отправить** для развертывания. Процесс может занять около 15 минут. Вы можете проверить статус в разделе **Подробности развертывания**.
  </Шаг>
</Шаги>

### 3. Протестируйте свое приложение в Studio

После развертывания вашего приложения:

1. Выберите только что созданное развертывание, чтобы просмотреть более подробную информацию.
2. Нажмите кнопку **Студия** в правом верхнем углу. Откроется Студия, где отобразится ваш график.

### 4. Получите URL-адрес API для вашего развертывания

1. В окне **Сведения о развертывании** в LangGraph щелкните **URL-адрес API**, чтобы скопировать его в буфер обмена.
2. Щелкните по URL-адресу, чтобы скопировать его в буфер обмена.

### 5. Тестирование API

Теперь вы можете протестировать API:

<Вкладки>
  <Tab title="Python">
    1. Установите LangGraph SDK:

    ```shell theme={null}
    pip install langgraph-sdk
    ```

    2. Отправьте сообщение агенту:

    ```python theme={null}
    from langgraph_sdk import get_sync_client # или get_client для асинхронного режима

    client = get_sync_client(url="your-deployment-url", api_key="your-langsmith-api-key")

    for chunk in client.runs.stream(
        Нет, # Беспотоковая версия
        "agent", # Имя агента. Определено в langgraph.json.
        ввод={
            "сообщения": [{
                "роль": "человек",
                «Содержание»: «Что такое LangGraph?»
            }],
        },
        stream_mode="updates",
    ):
        print(f"Получение нового события типа: {chunk.event}...")
        print(chunk.data)
        print("\n\n")
    ```
  </Tab>

  <Tab title="REST API">
    ```bash theme={null}
    curl -s --request POST \
        --url <DEPLOYMENT_URL>/runs/stream \
        --header 'Content-Type: application/json' \
        --header "X-Api-Key: <ключ API LANGSMITH> \
        --данные "{
            \"assistant_id\": \"agent\", `# Имя агента. Определено в langgraph.json.`
            \"вход\": {
                \"сообщения\": [
                    {
                        «роль»: «человек»,
                        «Содержание»: «Что такое LangGraph?»
                    }
                ]
            },
            \"stream_mode\": \"updates\"
        }"
    ```
  </Tab>
</Вкладки>
