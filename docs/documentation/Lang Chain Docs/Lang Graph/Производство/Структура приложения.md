# Структура приложения

Приложение LangGraph состоит из одного или нескольких графов, файла конфигурации (`langgraph.json`), файла, определяющего зависимости, и необязательного файла `.env`, определяющего переменные окружения.

В этом руководстве показана типичная структура приложения и описано, как указать необходимую конфигурацию для развертывания приложения с помощью [LangSmith Deployment](/langsmith/deployments).

<Информация>
  LangSmith Deployment — это управляемая платформа хостинга для развертывания и масштабирования агентов LangGraph. Она берет на себя инфраструктурные, масштабируемые и операционные вопросы, позволяя развертывать агенты с сохранением состояния и длительным временем работы непосредственно из вашего репозитория. Подробнее см. в [документации по развертыванию](/langsmith/deployments).
</Info>

## Ключевые понятия

Для развертывания с использованием LangSmith необходимо предоставить следующую информацию:

1. [Конфигурационный файл LangGraph](#configuration-file-concepts) (`langgraph.json`), определяющий зависимости, графы и переменные среды, используемые для приложения.
2. Графы, реализующие логику приложения.
3. Файл, определяющий [зависимости](#зависимости), необходимые для запуска приложения.
4. [Переменные среды](#environment-variables), необходимые для работы приложения.

  </Tab>

## Файл конфигурации

Файл `langgraph.json` представляет собой JSON-файл, в котором указываются зависимости, графы, переменные среды и другие параметры, необходимые для развертывания приложения LangGraph.

Подробную информацию обо всех поддерживаемых ключах в JSON-файле см. в [справочнике по конфигурационному файлу LangGraph](/langsmith/cli#configuration-file).

<Совет>
  В интерфейсе командной строки LangGraph (/langsmith/cli) по умолчанию используется конфигурационный файл `langgraph.json`, расположенный в текущем каталоге.
</Совет>

### Примеры

* Зависимости включают пользовательский локальный пакет и пакет `langchain_openai`.
* Один граф будет загружен из файла `./your_package/your_file.py` с переменной `variable`.
* Переменные среды загружаются из файла `.env`.

```json theme={null}
{
  "dependencies": ["langchain_openai", "./your_package"],
  "графики": {
    "my_agent": "./your_package/your_file.py:agent"
  },
  "env": "./.env"
}
```

## Зависимости

Приложение LangGraph может зависеть от других пакетов Python.

Как правило, для корректной настройки зависимостей вам потребуется указать следующую информацию:

1. Файл в каталоге, определяющий зависимости (например, `requirements.txt`, `pyproject.toml` или `package.json`).

2. Ключ `dependencies` в [файле конфигурации LangGraph](#configuration-file-concepts), указывающий зависимости, необходимые для запуска приложения LangGraph.

3. Любые дополнительные исполняемые файлы или системные библиотеки можно указать с помощью ключа `dockerfile_lines` в [файле конфигурации LangGraph](#configuration-file-concepts).

## Графики

Используйте ключ `graphs` в [файле конфигурации LangGraph](#configuration-file-concepts), чтобы указать, какие графы будут доступны в развернутом приложении LangGraph.

В файле конфигурации можно указать один или несколько графов. Каждый граф идентифицируется именем (которое должно быть уникальным) и путем либо к: (1) скомпилированному графу, либо (2) к определенной функции, которая создает граф.

## Переменные среды

Если вы работаете с развернутым локально приложением LangGraph, вы можете настроить переменные среды в ключе `env` файла конфигурации LangGraph (#configuration-file-concepts).

Для развертывания в производственной среде обычно требуется настроить переменные среды в самой среде развертывания.
