# Тест

После создания прототипа агента LangGraph естественным следующим шагом будет добавление тестов. В этом руководстве описаны некоторые полезные шаблоны, которые можно использовать при написании модульных тестов.

Обратите внимание, что это руководство относится к LangGraph и охватывает сценарии с графами, имеющими пользовательскую структуру. Если вы только начинаете, ознакомьтесь с [этим разделом](/oss/python/langchain/test/), в котором используется встроенная функция LangChain [`create_agent`](https://reference.langchain.com/python/langchain/agents/#langchain.agents.create_agent).

## Предварительные условия

Во-первых, убедитесь, что у вас установлен [`pytest`](https://docs.pytest.org/):

```bash theme={null}
$ pip install -U pytest
```

## Начиная

Поскольку многие агенты LangGraph зависят от состояния, полезным подходом является создание графа перед каждым тестом, в котором он используется, а затем компиляция его внутри тестов с новым экземпляром контрольной точки.

Приведенный ниже пример демонстрирует работу этого механизма на простом линейном графе, который проходит через `node1` и `node2`. Каждый узел обновляет единственный ключ состояния `my_key`:

```python theme={null}
импортировать pytest

from typing_extensions import TypedDict
from langgraph.graph import StateGraph, START, END
from langgraph.checkpoint.memory import MemorySaver

def create_graph() -> StateGraph:
    class MyState(TypedDict):
        мой_ключ: str

    graph = StateGraph(MyState)
    graph.add_node("node1", lambda state: {"my_key": "hello from node1"})
    graph.add_node("node2", lambda state: {"my_key": "hello from node2"})
    graph.add_edge(START, "node1")
    graph.add_edge("node1", "node2")
    graph.add_edge("node2", END)
    график возврата

def test_basic_agent_execution() -> None:
    checkpointer = MemorySaver()
    graph = create_graph()
    compiled_graph = graph.compile(checkpointer=checkpointer)
    результат = compiled_graph.invoke(
        {"my_key": "initial_value"},
        config={"configurable": {"thread_id": "1"}}
    )
    assert result["my_key"] == "hello from node2"
```

## Тестирование отдельных узлов и ребер

Скомпилированные агенты LangGraph предоставляют ссылки на каждый отдельный узел в виде `graph.nodes`. Вы можете использовать это для тестирования отдельных узлов внутри вашего агента. Обратите внимание, что это позволит обойти любые контрольные точки, передаваемые при компиляции графа:

```python theme={null}
импортировать pytest

from typing_extensions import TypedDict
from langgraph.graph import StateGraph, START, END
from langgraph.checkpoint.memory import MemorySaver

def create_graph() -> StateGraph:
    class MyState(TypedDict):
        мой_ключ: str

    graph = StateGraph(MyState)
    graph.add_node("node1", lambda state: {"my_key": "hello from node1"})
    graph.add_node("node2", lambda state: {"my_key": "hello from node2"})
    graph.add_edge(START, "node1")
    graph.add_edge("node1", "node2")
    graph.add_edge("node2", END)
    график возврата

def test_individual_node_execution() -> None:
    # В этом примере будет проигнорировано
    checkpointer = MemorySaver()
    graph = create_graph()
    compiled_graph = graph.compile(checkpointer=checkpointer)
    # Вызывать только узел 1
    result = compiled_graph.nodes["node1"].invoke(
        {"my_key": "initial_value"},
    )
    assert result["my_key"] == "hello from node1"
```

## Частичное выполнение

Для агентов, состоящих из больших графов, может потребоваться тестирование отдельных путей выполнения внутри агента, а не всего потока от начала до конца. В некоторых случаях может быть целесообразно [преобразовать эти разделы в подграфы](/oss/python/langgraph/use-subgraphs), которые можно вызывать отдельно, как обычно.

Однако, если вы не хотите вносить изменения в общую структуру графа агентов, вы можете использовать механизмы сохранения состояния LangGraph для имитации состояния, в котором ваш агент приостановлен непосредственно перед началом нужного участка и снова приостановится в конце этого участка. Шаги следующие:

1. Скомпилируйте свой агент с контрольной точкой (для тестирования подойдет контрольная точка в памяти [`InMemorySaver`](https://reference.langchain.com/python/langgraph/checkpoints/#langgraph.checkpoint.memory.InMemorySaver)).
2. Вызовите метод [`update_state`](/oss/python/langgraph/use-time-travel) вашего агента с параметром [`as_node`](/oss/python/langgraph/persistence#as-node), установленным на имя узла *перед* тем, с которого вы хотите начать тестирование.
3. Запустите агента, используя тот же `thread_id`, что и для обновления состояния, и параметр `interrupt_after`, установленный на имя узла, на котором вы хотите остановиться.

Вот пример, в котором выполняются операции только со вторым и третьим узлами линейного графа:

```python theme={null}
импортировать pytest

from typing_extensions import TypedDict
from langgraph.graph import StateGraph, START, END
from langgraph.checkpoint.memory import MemorySaver

def create_graph() -> StateGraph:
    class MyState(TypedDict):
        мой_ключ: str

    graph = StateGraph(MyState)
    graph.add_node("node1", lambda state: {"my_key": "hello from node1"})
    graph.add_node("node2", lambda state: {"my_key": "hello from node2"})
    graph.add_node("node3", lambda state: {"my_key": "hello from node3"})
    graph.add_node("node4", lambda state: {"my_key": "hello from node4"})
    graph.add_edge(START, "node1")
    graph.add_edge("node1", "node2")
    graph.add_edge("node2", "node3")
    graph.add_edge("node3", "node4")
    graph.add_edge("node4", END)
    график возврата

def test_partial_execution_from_node2_to_node3() -> None:
    checkpointer = MemorySaver()
    graph = create_graph()
    compiled_graph = graph.compile(checkpointer=checkpointer)
    compiled_graph.update_state(
        config={
          "настраиваемый": {
            "thread_id": "1"
          }
        },
        # Состояние передано в узел 2 — моделирование состояния в
        # конец узла 1
        значения={"my_key": "initial_value"},
        # Обновить сохраненное состояние так, как если бы оно поступило с узла 1
        # Выполнение возобновится на узле 2
        as_node="node1",
    )
    результат = compiled_graph.invoke(
        # Возобновить выполнение, передав None
        Никто,
        config={"configurable": {"thread_id": "1"}},
        # Остановить выполнение после узла 3, чтобы узел 4 не запускался
        interrupt_after="node3",
    )
    assert result["my_key"] == "hello from node3"
```
