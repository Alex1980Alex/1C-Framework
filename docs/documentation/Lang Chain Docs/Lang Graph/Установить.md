# Установка LangGraph

Для установки базового пакета LangGraph:

<CodeGroup>
  ```bash pip theme={null}
  pip install -U langgraph
  ```

  ```bash uv theme={null}
  uv add langgraph
  ```
</CodeGroup>

Для использования LangGraph обычно требуется доступ к LLM-модулям и определение инструментов.
Вы можете сделать это так, как сочтете нужным.

Один из способов сделать это (который мы будем использовать в документации) — это использовать [LangChain](/oss/python/langchain/overview).

Установите LangChain с помощью:

<CodeGroup>
  ```bash pip theme={null}
  pip install -U langchain
  # Требуется Python 3.10+
  ```

  ```bash uv theme={null}
  uv add langchain
  # Требуется Python 3.10+
  ```
</CodeGroup>

Для работы со специальными пакетами поставщика LLM вам потребуется установить их отдельно.

Инструкции по установке для конкретного поставщика см. на странице [интеграции](/oss/python/integrations/providers/overview).
