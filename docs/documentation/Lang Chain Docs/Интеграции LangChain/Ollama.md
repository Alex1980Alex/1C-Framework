#Оллама

На этой странице представлена ​​информация обо всех интеграциях LangChain с [Ollama](https://ollama.com/).

Ollama позволяет запускать модели с открытым исходным кодом (например, [`gpt-oss`](https://ollama.com/library/gpt-oss)) локально.

Полный список поддерживаемых моделей и вариантов см. в [библиотеке моделей Ollama](https://ollama.ai/library).
