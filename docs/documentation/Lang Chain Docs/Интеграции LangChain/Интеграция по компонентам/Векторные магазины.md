# Магазины Vector

## Обзор

В векторном хранилище хранятся [встроенные](/oss/python/integrations/text_embedding) данные и выполняется поиск по сходству.

```тема русалки={null}
блок-схема LR

    подграф "📥 Этап индексации (хранение)"
        A[📄 Документы] --> B[🔢 Модель встраивания]
        B --> C[🔘 Векторы встраивания]
        C --> D[(Векторное хранилище)]
    конец

    подграф "📤 Этап запроса (извлечение)"
        E[❓ Текст запроса] --> F[🔢 Модель встраивания]
        F --> G[🔘 Вектор запроса]
        G --> H[🔍 Поиск сходства]
        H --> D
        D --> I[📄 Результаты Top-k]
    конец
```

### Интерфейс

LangChain предоставляет единый интерфейс для хранилищ векторной графики, позволяющий:

* `add_documents` - Добавить документы в хранилище.
* `delete` — Удалить сохраненные документы по идентификатору.
* `similarity_search` — Запрос на поиск семантически похожих документов.

Эта абстракция позволяет переключаться между различными реализациями без изменения логики вашего приложения.

### Инициализация

Для инициализации хранилища векторов необходимо предоставить ему модель встраивания:

```python theme={null}
from langchain_core.vectorstores import InMemoryVectorStore
vector_store = InMemoryVectorStore(embedding=SomeEmbeddingModel())
```

### Добавление документов

Добавьте объекты [`Document`](https://reference.langchain.com/python/langchain_core/documents/#langchain_core.documents.base.Document) (содержащие `page_content` и необязательные метаданные) следующим образом:

```python theme={null}
vector_store.add_documents(documents=[doc1, doc2], ids=["id1", "id2"])
```

### Удаление документов

Удаление путем указания идентификаторов:

```python theme={null}
vector_store.delete(ids=["id1"])
```

### Поиск сходства

Выполните семантический запрос с помощью `similarity_search`, который вернет наиболее близкие встроенные документы:

```python theme={null}
similar_docs = vector_store.similarity_search("Ваш запрос здесь")
```

Многие векторные хранилища поддерживают такие параметры, как:

* `k` — количество результатов для возврата
* `filter` — условная фильтрация на основе метаданных

### Метрики сходства и индексирование

Сходство встраивания может быть вычислено с помощью следующих методов:

* **Косинусное подобие**
* **Евклидово расстояние**
* **Точечный продукт**

Для эффективного поиска часто используются методы индексирования, такие как HNSW (Hierarchical Navigable Small World), хотя конкретные методы зависят от используемого векторного хранилища.

### Фильтрация метаданных

Фильтрация по метаданным (например, источник, дата) может уточнить результаты поиска:

```python theme={null}
vector_store.similarity_search(
  "запрос",
  k=3,
  filter={"source": "tweets"}
)
```

<важно>
  Поддержка фильтрации на основе метаданных различается в зависимости от реализации.
  Для получения более подробной информации обратитесь к документации выбранного вами магазина векторной графики.
</важно>
