# Встраивание моделей

## Обзор

<Примечание>
  В данном обзоре рассматриваются **текстовые модели встраивания**. LangChain в настоящее время не поддерживает мультимодальные модели встраивания.

  См. [лучшие модели встраивания](#top-integrations).
</Примечание>

Модели встраивания преобразуют исходный текст — например, предложение, абзац или твит — в вектор чисел фиксированной длины, отражающий его **семантическое значение**. Эти векторы позволяют машинам сравнивать и искать текст на основе смысла, а не конкретных слов.

На практике это означает, что тексты со схожими идеями располагаются близко друг к другу в векторном пространстве. Например, вместо сопоставления только фразы «машинное обучение» (*), векторные представления могут выявлять документы, в которых обсуждаются связанные понятия, даже если используется разная формулировка.

### Как это работает

1. **Векторизация** — Модель кодирует каждую входную строку в виде многомерного вектора.
2. **Оценка сходства** — Векторы сравниваются с использованием математических метрик для измерения степени родства исходных текстов.

### Метрики сходства

Для сравнения эмбеддингов обычно используется несколько метрик:

* **Косинусное подобие** — измеряет угол между двумя векторами.
* **Евклидово расстояние** — измеряет расстояние по прямой между точками.
* Скалярное произведение** — измеряет, насколько один вектор проецируется на другой.

Вот пример вычисления косинусного сходства между двумя векторами:

```python theme={null}
import numpy as np

def cosine_similarity(vec1, vec2):
    dot = np.dot(vec1, vec2)
    return dot / (np.linalg.norm(vec1) * np.linalg.norm(vec2))

similarity = cosine_similarity(query_embedding, document_embedding)
print("Косинусное сходство:", similarity)
```

## Интерфейс

LangChain предоставляет стандартный интерфейс для моделей встраивания текста (например, OpenAI, Cohere, Hugging Face) через интерфейс [Embeddings](https://reference.langchain.com/python/langchain_core/embeddings/#langchain_core.embeddings.embeddings.Embeddings).

Доступны два основных метода:

* `embed_documents(texts: List[str]) → List[List[float]]`: Встраивает список документов.
* `embed_query(text: str) → List[float]`: Встраивает один запрос.

<Примечание>
  Интерфейс позволяет встраивать запросы и документы с использованием различных стратегий, хотя на практике большинство поставщиков обрабатывают их одинаково.
</Примечание>

## Кэширование

Эмбеддинги могут храниться или временно кэшироваться, чтобы избежать необходимости их повторного вычисления.

Кэширование эмбеддингов можно осуществить с помощью `CacheBackedEmbeddings`. Этот оберточный модуль хранит эмбеддинги в хранилище типа «ключ-значение», где текст хешируется, и этот хеш используется в качестве ключа в кэше.

Основной поддерживаемый способ инициализации `CacheBackedEmbeddings` — это `from_bytes_store`. Он принимает следующие параметры:

* **`underlying_embedder`**: Эмбеддер, используемый для встраивания.
* **`document_embedding_cache`**: Любой [`ByteStore`](/oss/python/integrations/stores/) для кэширования встраивания документов.
* **`batch_size`**: (необязательно, по умолчанию `None`) Количество документов, которые будут встраиваться между обновлениями хранилища.
* **`пространство имен`**: (необязательно, по умолчанию `""`) Пространство имен, используемое для кэша документов. Помогает избежать конфликтов (например, установить его в качестве имени модели встраивания).
* **`query_embedding_cache`**: (необязательно, по умолчанию `None`) Хранилище байтов [`ByteStore`](/oss/python/integrations/stores/) для кэширования встраивания запросов или `True` для повторного использования того же хранилища, что и `document_embedding_cache`.

<Важно>
  — Всегда устанавливайте параметр `namespace`, чтобы избежать конфликтов при использовании разных моделей встраивания.
  — Параметр `CacheBackedEmbeddings` по умолчанию не кэширует векторные представления запросов. Чтобы включить эту функцию, укажите параметр `query_embedding_cache`.
</Важно>

```python theme={null}
время импорта
from langchain_classic.embeddings import CacheBackedEmbeddings # [!code highlight]
from langchain_classic.storage import LocalFileStore # [!code highlight]
from langchain_core.vectorstores import InMemoryVectorStore

# Создайте базовую модель эмбеддингов
underlying_embeddings = ... # например, OpenAIEmbeddings(), HuggingFaceEmbeddings() и т. д.

# Хранилище сохраняет встраивания в локальную файловую систему
# Это не для использования в производственных целях, но полезно для локального применения.
store = LocalFileStore("./cache/") # [!подсветка кода]

cached_embedder = CacheBackedEmbeddings.from_bytes_store(
    underlying_embeddings,
    магазин,
    namespace=underlying_embeddings.model
)

# Пример: кэширование встраивания запроса
tic = time.time()
print(cached_embedder.embed_query("Hello, world!"))
print(f"Первый вызов занял: {time.time() - tic:.2f} секунд")

# Последующие вызовы используют кэш
tic = time.time()
print(cached_embedder.embed_query("Hello, world!"))
print(f"Второй вызов занял: {time.time() - tic:.2f} секунд")
```

В производственной среде обычно используется более надежное постоянное хранилище, такое как база данных или облачное хранилище. Дополнительные варианты см. в разделе [интеграции со хранилищами](/oss/python/integrations/stores/).
