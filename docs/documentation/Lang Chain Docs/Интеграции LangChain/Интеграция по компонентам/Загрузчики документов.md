# нулевой

Загрузчики документов предоставляют **стандартный интерфейс** для чтения данных из различных источников (таких как Slack, Notion или Google Drive) в формат [Document](https://reference.langchain.com/python/langchain_core/documents/#langchain_core.documents.base.Document) LangChain.
Это гарантирует единообразную обработку данных независимо от их источника.

Все загрузчики документов реализуют интерфейс [`BaseLoader`](https://reference.langchain.com/python/langchain_core/document_loaders/#langchain_core.document_loaders.BaseLoader).

## Интерфейс

Каждый загрузчик документов может определять свои собственные параметры, но они используют общий API:

* `load()` – Загружает все документы одновременно.
* `lazy_load()` – Лениво загружает документы, что полезно для больших наборов данных.

```python theme={null}
from langchain_community.document_loaders.csv_loader import CSVLoader

загрузчик = CSVLoader(
    ... # Здесь указаны параметры, специфичные для интеграции
)

# Загрузить все документы
документы = loader.load()

# Для больших наборов данных используйте отложенную загрузку документов.
for document in loader.lazy_load():
    print(document)
```
