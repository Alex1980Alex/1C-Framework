# Инструменты и наборы инструментов

[Инструменты](/oss/python/langchain/tools) — это утилиты, предназначенные для вызова моделями: их входные данные предназначены для генерации моделями, а выходные данные — для передачи обратно моделям.

Набор инструментов — это совокупность инструментов, предназначенных для совместного использования.
