# Модели чата

Модели чата (Chat models) — это языковые модели, которые используют последовательность сообщений (messages) в качестве входных данных и возвращают сообщения в качестве выходных данных. <Подсказка: Более старые модели, которые не следуют интерфейсу модели чата и вместо этого используют интерфейс, который принимает строку в качестве входных данных и возвращает строку в качестве выходных данных. Эти модели обычно не включают префикс «Chat» в свое имя или суффикс «LLM».">(в отличие от традиционных текстовых моделей чата)</Подсказка>.

## API завершения чата

Некоторые поставщики моделей предлагают конечные точки, совместимые с устаревшим API завершения чата OpenAI ([Chat Completions API](https://platform.openai.com/docs/guides/completions)). В таком случае вы можете использовать [`ChatOpenAI`](/oss/python/integrations/chat/openai) с пользовательским `base_url` для подключения к этим конечным точкам. Обратите внимание, что функции, построенные на основе API завершения чата, могут не полностью поддерживаться `ChatOpenAI`; в таких случаях рассмотрите возможность использования класса, специфичного для поставщика, если таковой имеется (например, [`ChatLiteLLM`](https://github.com/Akshay-Dongare/langchain-litellm/) (поддерживаемый сообществом) для [LiteLLM](https://litellm.ai/)).

<Accordion title="Пример: OpenRouter">
  Для использования OpenRouter вам потребуется зарегистрировать учетную запись и получить [ключ API](https://openrouter.ai/docs/api-reference/authentication).

  ```python theme={null}
  from langchain_openai import ChatOpenAI

  модель = ChatOpenAI(
      model="...", # Укажите модель, доступную в OpenRouter
      api_key="OPENROUTER_API_KEY",
      base_url="https://openrouter.ai/api/v1",
  )
  ```

  Для получения более подробной информации обратитесь к документации OpenRouter по адресу [https://openrouter.ai/docs/quickstart].

  <Примечание>
    Для получения [токенов обоснования](https://openrouter.ai/docs/use-cases/reasoning-tokens),

    1. Переключите импорт с `langchain_openai` на `langchain_deepseek`.
    2. Используйте `ChatDeepSeek` вместо `ChatOpenAI`. Вам потребуется изменить параметр `base_url` на `api_base`.
    3. При необходимости скорректируйте параметры рассуждений в разделе `extra_body`, например:

    ```python theme={null}
    модель = ChatDeepSeek(
        модель="...",
        api_key="...",
        api_base="https://openrouter.ai/api/v1",
        extra_body={"reasoning": {"enabled": True}},
    )
    ```

    Это известное ограничение `ChatOpenAI`, которое будет устранено в будущей версии.
  </Примечание>
</Аккордеон>
