# Разделители текста

<CodeGroup>
  ```bash pip theme={null}
  pip install -U langchain-text-splitters
  ```

  ```bash uv theme={null}
  uv add langchain-text-splitters
  ```
</CodeGroup>

**Разделители текста** разбивают большие документы на более мелкие фрагменты, которые можно будет извлекать по отдельности и которые будут помещаться в пределах окна контекста модели.

Существует несколько стратегий разделения документов, каждая из которых имеет свои преимущества.

<Совет>
  В большинстве случаев начните с [`RecursiveCharacterTextSplitter`](/oss/python/integrations/splitters/recursive_text_splitter). Он обеспечивает хороший баланс между сохранением контекста и управлением размером фрагмента. Эта стратегия по умолчанию хорошо работает «из коробки», и вам следует рассматривать возможность ее изменения только в том случае, если вам необходимо точно настроить производительность для вашего конкретного приложения.
</Совет>

## На основе структуры текста

Текст по своей природе организован в иерархические единицы, такие как абзацы, предложения и слова. Мы можем использовать эту присущую структуре для формирования стратегии разделения текста, создавая фрагменты, которые сохраняют естественный ход речи, поддерживают семантическую связность внутри фрагмента и адаптируются к различным уровням детализации текста. `RecursiveCharacterTextSplitter` из библиотеки LangChain реализует эту концепцию:

* Функция [`RecursiveCharacterTextSplitter`](/oss/python/integrations/splitters/recursive_text_splitter) пытается сохранить целостность более крупных единиц текста (например, абзацев).
* Если единица превышает размер блока, она переходит на следующий уровень (например, предложения).
* При необходимости этот процесс продолжается до уровня отдельных слов.

Пример использования:

```python theme={null}
from langchain_text_splitters import RecursiveCharacterTextSplitter

text_splitter = RecursiveCharacterTextSplitter(chunk_size=100, chunk_overlap=0)
тексты = text_splitter.split_text(document)
```

## На основе длины

Интуитивно понятная стратегия заключается в разделении документов по длине. Этот простой, но эффективный подход гарантирует, что каждый фрагмент не превысит заданный лимит размера. Ключевые преимущества разделения по длине:

* Простая реализация
* Постоянные размеры блоков
* Легко адаптируется к различным требованиям модели.

Типы разделения по длине:

* На основе токенов: разделяет текст в зависимости от количества токенов, что полезно при работе с языковыми моделями.
* Разделение по символам: разделяет текст в зависимости от количества символов, что обеспечивает более единообразный подход для разных типов текста.

Пример реализации с использованием `CharacterTextSplitter` из библиотеки LangChain с разделением текста на основе токенов:

```python theme={null}
from langchain_text_splitters import CharacterTextSplitter

text_splitter = CharacterTextSplitter.from_tiktoken_encoder(
    encoding_name="cl100k_base", chunk_size=100, chunk_overlap=0
)
тексты = text_splitter.split_text(document)
```

## Структура документа

Некоторые документы имеют заданную структуру, например, файлы HTML, Markdown или JSON. В таких случаях целесообразно разделять документ на основе его структуры, поскольку это часто естественным образом группирует семантически связанный текст. Ключевые преимущества разделения на основе структуры:

* Сохраняет логическую структуру документа
* Сохраняет контекст внутри каждого фрагмента
* Может быть более эффективен для последующих задач, таких как поиск или обобщение информации.

Примеры расщепления на основе структуры:

* Markdown: Разделение по заголовкам (например, `#`, `##`, `###`)
* HTML: Разделение с помощью тегов
* JSON: Разделение по элементам объекта или массива
* Код: Разделен на функции, классы или логические блоки
