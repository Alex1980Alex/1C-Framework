# Ретриверы

[Retriever](/oss/python/langchain/retrieval#building-blocks) — это интерфейс, который возвращает документы на основе неструктурированного запроса.
Это более универсальный инструмент, чем хранилище векторных данных.
Для того чтобы получить документы, пользователю не обязательно уметь их хранить, достаточно лишь возвращать (или извлекать) их.
Системы ретриверов могут создаваться из векторных хранилищ, но их понятие достаточно широкое, чтобы включать в себя [поиск в Википедии](/oss/python/integrations/retrievers/wikipedia/) и [Amazon Kendra](/oss/python/integrations/retrievers/amazon_kendra_retriever/).

Обработчики запросов принимают строковый запрос в качестве входных данных и возвращают список объектов [`Document`](https://reference.langchain.com/python/langchain_core/documents/#langchain_core.documents.base.Document) в качестве выходных данных.

Обратите внимание, что все [хранилища векторов](/oss/python/integrations/vectorstores) могут быть преобразованы в объекты-получатели. Для получения информации о доступных хранилищах векторов обратитесь к [документации по интеграции](/oss/python/integrations/vectorstores/).
На этой странице перечислены пользовательские средства получения данных, реализованные путем наследования от класса BaseRetriever.
