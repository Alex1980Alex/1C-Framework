# Архитектура компонентов

Сила LangChain заключается в том, как его компоненты взаимодействуют друг с другом, создавая сложные приложения искусственного интеллекта. На этой странице представлены диаграммы, демонстрирующие взаимосвязи между различными компонентами.

## Экосистема основных компонентов

На приведенной ниже диаграмме показано, как основные компоненты LangChain соединяются для формирования полноценных приложений искусственного интеллекта:

```тема русалки={null}
график TD
    %% Обработка входных данных
    подграф "📥 Обработка входных данных"
        A[Ввод текста] --> B[Загрузчики документов]
        B --> C[Разделители текста]
        C --> D[Документы]
    конец

    %% Встраивание и хранение
    подграф "🔢 Встраивание и хранение"
        D --> E[Встраивание моделей]
        E --> F[Векторы]
        F --> G[(Векторные хранилища)]
    конец

    %% Получение
    подграф "🔍 Извлечение"
        H[Пользовательский запрос] --> I[Встраивание моделей]
        I --> J[Вектор запроса]
        J --> K[Ретриверы]
        К --> Г
        Г --> Л[Соответствующий контекст]
    конец

    %% Поколение
    подграф "🤖 Поколение"
        M[Модели чата] --> N[Инструменты]
        N --> O[Результаты работы инструмента]
        О --> М
        Л --> М
        М --> П[Ответ ИИ]
    конец

    %% Оркестрация
    подграф "🎯 Оркестровка"
        Q[Агенты] --> M
        Q --> N
        Q --> K
        Q --> R[Память]
    конец
```

### Как соединяются компоненты

Каждый последующий слой компонентов строится на основе предыдущих:

1. **Обработка входных данных** – Преобразование исходных данных в структурированные документы.
2. **Встраивание и хранение** – Преобразование текста в векторные представления, доступные для поиска.
3. **Поиск** – Нахождение релевантной информации на основе запросов пользователей.
4. **Генерация** – Используйте модели ИИ для создания ответов, при необходимости с помощью инструментов.
5. **Оркестровка** – Координация всего с помощью агентов и систем памяти.

## Категории компонентов

LangChain разделяет компоненты на следующие основные категории:

| Категория | Назначение | Ключевые компоненты | Варианты использования |
| -------------------------------------------------------------------- | --------------------------- | ----------------------------------- | -------------------------------------------------- |
| **[Модели](/oss/python/langchain/models)** | Рассуждения и генерация ИИ | Модели чатов, LLM, модели встраивания | Генерация текста, рассуждения, семантическое понимание |
| **[Инструменты](/oss/python/langchain/tools)** | Внешние возможности | API, базы данных и т. д. | Веб-поиск, доступ к данным, вычисления |
| **[Агенты](/oss/python/langchain/agents)** | Оркестрация и рассуждения | Агенты ReAct, агенты вызова инструментов | Недетерминированные рабочие процессы, принятие решений |
| **[Память](/oss/python/langchain/short-term-memory)** | Сохранение контекста | История сообщений, пользовательское состояние | Диалоги, взаимодействие с сохранением состояния |
| **[Поисковые системы](/oss/python/integrations/retrievers)** | Доступ к информации | Векторные поисковые системы, веб-поисковые системы | RAG, поиск по базе знаний |
| **[Обработка документов](/oss/python/integrations/document_loaders)** | Ввод данных | Загрузчики, разделители, преобразователи | Обработка PDF, веб-скрейпинг |
| **[Векторные хранилища](/oss/python/integrations/vectorstores)** | Семантический поиск | Chroma, Pinecone, FAISS | Поиск сходства, хранение эмбеддингов |

## Распространенные шаблоны

### RAG (Retrieval-Augmented generation)

```тема русалки={null}
график LR
    A[Вопрос пользователя] --> B[Получатель]
    B --> C [Соответствующие документы]
    C --> D[Модель чата]
    А --> Д
    D --> E [Информированный ответ]
```

### Агент с инструментами

```тема русалки={null}
график LR
    A[Запрос пользователя] --> B[Агент]
    B --> C{Нужен инструмент?}
    C -->|Да| D[Вызов инструмента]
    D --> E[Результат работы инструмента]
    Е --> Б
    C -->|Нет| F[Окончательный ответ]
```

### Многоагентная система

```тема русалки={null}
график LR
    A[Сложная задача] --> B[Агент-супервизор]
    B --> C [Специалист-агент 1]
    B --> D[Специалист-агент 2]
    C --> E[Результаты]
    Д --> Е
    Е --> Б
    B --> F [Скоординированный ответ]
```
