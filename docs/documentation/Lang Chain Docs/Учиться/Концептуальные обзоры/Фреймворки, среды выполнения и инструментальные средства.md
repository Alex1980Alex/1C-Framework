# Фреймворки, среды выполнения и инструментальные среды

> Разберитесь в различиях между LangChain, LangGraph и DeepAgents и узнайте, когда следует использовать каждый из них.

LangChain поддерживает несколько пакетов с открытым исходным кодом, которые помогут вам создавать агентов. Каждый из них служит разным целям в стеке разработки агентов. Понимание различий между [фреймворками для агентов](#agent-frameworks-like-langchain), [средами выполнения агентов](#agent-runtimes-like-langgraph) и [настройками для агентов](#agent-harnesses-like-the-deep-agents-sdk) поможет вам выбрать подходящий инструмент для ваших нужд.

## Фреймворки для агентов (например, LangChain)

Фреймворки для агентов предоставляют абстракции, которые упрощают начало работы при создании приложений с использованием LLM.

[LangChain](/oss/python/langchain/overview) — это фреймворк для работы с агентами, предоставляющий такие абстракции, как структурированные блоки контента, цикл работы агента и промежуточное программное обеспечение.

Абстракции LangChain разработаны таким образом, чтобы с ними было легко начать работу, и в то же время они обеспечивают гибкость, необходимую для решения сложных задач.

Хотя LangChain построен на основе [LangGraph](/oss/python/langgraph/overview), вам не нужно знать LangGraph, чтобы использовать LangChain.

Другие примеры фреймворков для работы с агентами включают [SDK для ИИ от Vercel](https://ai-sdk.dev/docs/introduction), [CrewAI](https://www.crewai.com/), [SDK для агентов OpenAI](https://openai.github.io/openai-agents-python/), [ADK от Google](https://google.github.io/adk-docs/), [LlamaIndex](https://www.llamaindex.ai/) и многие другие.

### Когда использовать LangChain

Используйте LangChain, когда:

* Вы хотите быстро создавать агентов и автономные приложения.
* Для моделей, инструментов и циклов взаимодействия агентов необходимы стандартные абстракции.
* Вам нужна простая в использовании платформа, которая при этом обеспечивает гибкость.
* Вы создаёте простые агентские приложения, не требующие сложной оркестровки.

## Среды выполнения агентов (например, LangGraph)

Среды выполнения агентов предоставляют инструменты для запуска агентов в производственной среде.
К числу поддерживаемых инструментов могут относиться:

* **Устойчивое выполнение**: Агенты продолжают работу даже при сбоях и могут работать в течение длительного времени, возобновляя выполнение с того места, где остановились.
* **Потоковая передача**: Поддержка потоковых рабочих процессов и ответов.
* **Участие человека в процессе**: Включение человеческого контроля путем проверки и изменения состояния агента.
* **Сохранение состояния**: Сохранение состояния на уровне потоков и между потоками для управления состоянием.
* **Низкоуровневое управление**: Прямое управление оркестровкой агентов без высокоуровневых абстракций.

[LangGraph](/oss/python/langgraph/overview) — это низкоуровневая среда оркестрации и выполнения для создания, управления и развертывания долго работающих агентов с сохранением состояния.

Агентские фреймворки, как правило, имеют более высокий уровень и работают на основе среды выполнения агентов.
Например, LangChain 1.0 построен на основе LangGraph.

Другие примеры сред выполнения агентов включают [Temporal](https://temporal.io/), [Inngest](https://www.inngest.com/) и другие механизмы надежного выполнения.

### Когда использовать LangGraph

Используйте LangGraph, когда:

* Вам необходим детальный, низкоуровневый контроль над управлением агентами.
* Для длительно работающих агентов с сохранением состояния требуется надежное выполнение.
* Вы создаёте сложные рабочие процессы, сочетающие детерминированные и агентные этапы.
* Для развертывания агентов необходима готовая к использованию в производственной среде инфраструктура.

## Инструменты для работы с агентами (например, SDK Deep Agents)

Агентские фреймворки — это специализированные платформы для создания агентов, в которые уже встроены инструменты и возможности, упрощающие разработку сложных и долгосрочно работающих агентов.
К числу поддерживаемых инструментов могут относиться:

* **Возможности планирования**: Отслеживайте выполнение нескольких задач с помощью списка дел.
* **Делегирование задач**: Делегируйте работу и поддерживайте четкий контекст взаимодействия с субагентами.
* **Файловая система**: доступ на чтение и запись к файлам на различных подключаемых хранилищах.
* **Управление токенами**: Сводка истории переписки и удаление результатов из больших наборов инструментов.

[Deep Agents SDK](/oss/python/deepagents/overview) основан на LangGraph и добавляет возможности планирования, файловые системы для управления контекстом, возможность запуска субагентов и многое другое.
DeepAgents разработан для сложных многоэтапных задач, требующих планирования и декомпозиции.

Другие примеры инструментов для работы с агентами включают [Claude Agent SDK](https://platform.claude.com/docs/en/agent-sdk/overview), [Manus](https://manus.im/) и другие CLI-интерфейсы для программирования.

### Когда использовать SDK Deep Agents

Используйте [Deep Agents SDK](/oss/python/deepagents/overview), когда:

* Вы создаёте агентов, которые работают в течение длительных периодов времени.
* Вы создаёте агентов, которым необходимо выполнять сложные, многоэтапные задачи.
* Вы хотите использовать предопределенные инструменты, такие как операции с файловой системой, выполнение команд bash и автоматическое формирование контекста.
* Вы хотите использовать предопределенные подсказки и субагентов.

| ----------------- | ----------------------------------------------------------------------- | --------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Кратковременная память | [Кратковременная память](/oss/python/langchain/short-term-memory) | [Кратковременная память](/oss/python/langgraph/add-memory#add-short-term-memory) | [`StateBackend`](/oss/python/deepagents/backends#statebackend-ephemeral) |
| Долговременная память | [Долговременная память](/oss/python/langchain/long-term-memory) | [Долговременная память](/oss/python/langgraph/add-memory#add-long-term-memory) | [Долговременная память](/oss/python/deepagents/long-term-memory) |
| Навыки | [Навыки для работы с несколькими агентами](/oss/python/langchain/multi-agent/skills) | - | [Навыки](/oss/python/deepagents/skills) |
| Субагенты | [Многоагентные субагенты](/oss/python/langchain/multi-agent/subagents) | [Подграфы](/oss/python/langgraph/use-subgraphs) | [Субагенты](/oss/python/deepagents/subagents) |
| Человек в цикле | [Промежуточное ПО для человека в цикле](/oss/python/langchain/human-in-the-loop) | [Прерывания](/oss/python/langgraph/interrupts) | [параметр `interrupt_on`](/oss/python/deepagents/harness#human-in-the-loop) |
