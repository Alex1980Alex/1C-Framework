### LangGraph

В реализациях [агентов](/oss/python/langchain/agents) LangChain используются примитивы [LangGraph](/oss/python/langgraph/overview).
Если требуется более глубокая настройка, агентов можно реализовать непосредственно в LangGraph.

<Card title="Custom RAG Agent" icon="user-magnifying-glass" href="/oss/python/langgraph/agentic-rag" horizontal>
