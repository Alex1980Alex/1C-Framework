
Что такое протокол языкового сервера?
Добавление таких функций, как автозаполнение, переход к определению или документация при наведении курсора на текст в языке программирования, требует значительных усилий. Традиционно эту работу приходилось повторять для каждого инструмента разработки, поскольку каждый инструмент предоставляет разные API для реализации одной и той же функции.

Языковой сервер предназначен для предоставления специфических для языка функций и взаимодействия с инструментами разработки по протоколу, обеспечивающему межпроцессное взаимодействие.

Идея протокола Language Server Protocol (LSP) заключается в стандартизации протокола взаимодействия таких серверов и инструментов разработки. Таким образом, один и тот же сервер языка может быть повторно использован в нескольких инструментах разработки, что, в свою очередь, позволит поддерживать несколько языков с минимальными усилиями.

LSP выгоден как поставщикам языковых решений, так и разработчикам инструментов!
