# Версионирование

Протокол контекста модели использует строковые идентификаторы версий, соответствующие следующему формату:
`ГГГГ-ММ-ДД` — для обозначения последней даты внесения обратно несовместимых изменений.

<Информация>
  Версия протокола *не* будет увеличиваться при...
  Протокол обновляется при условии сохранения обратной совместимости изменений. Это позволяет
  для постепенных улучшений при сохранении совместимости.
</Info>

## Изменения

Изменения могут быть отмечены следующим образом:

* **Черновик**: разрабатываемые технические условия, еще не готовые к использованию.
* **Текущий**: текущая версия протокола, готовая к использованию и которая может продолжать использоваться.
  получать обратно совместимые изменения.
* **Окончательная версия**: прежние, полные технические характеристики, которые не будут изменены.

Текущая версия протокола: [**2025-11-25**](/specification/2025-11-25/).

## Переговоры

Согласование версий происходит во время
[инициализация](/specification/latest/basic/lifecycle#initialization). Клиенты и
Серверы **МОГУТ** поддерживать несколько версий протокола одновременно, но они **ОБЯЗАНЫ**.
Согласовать единую версию для использования на протяжении всей сессии.

Протокол предусматривает надлежащую обработку ошибок в случае сбоя согласования версий, что позволяет
клиенты должны корректно завершать соединения, если не удается найти совместимую версию.
с сервером.
