# SDK

> Официальные SDK для сборки с использованием протокола контекста модели

Создавайте MCP-серверы и клиенты, используя наши официальные SDK. Все SDK предоставляют одинаковую базовую функциональность и полную поддержку протоколов.

## Начиная

Каждый SDK предоставляет одинаковую функциональность, но следует идиомам и передовым практикам своего языка. Все SDK поддерживают:

* Создание MCP-серверов, предоставляющих доступ к инструментам, ресурсам и подсказкам.
* Создание MCP-клиентов, способных подключаться к любому MCP-серверу.
* Протоколы локальной и удаленной передачи данных
* Соответствие протоколу безопасности типа

Посетите страницу SDK для выбранного вами языка, чтобы найти инструкции по установке, документацию и примеры.
