Протокол контекста модели (MCP) поддерживает постраничную обработку операций со списками, которые могут возвращать
Большие наборы результатов. Пагинация позволяет серверам выдавать результаты меньшими порциями, а не большими.

Пагинация особенно важна при подключении к внешним сервисам через
Интернет, но также полезен для локальной интеграции, чтобы избежать проблем с производительностью при работе с большими объемами данных.

## Модель пагинации

В MCP используется постраничная навигация с помощью непрозрачного курсора, а не нумерация страниц.

* Курсор представляет собой непрозрачный строковый токен, обозначающий позицию в результирующем наборе.
* Размер страницы определяется сервером, и клиенты **НЕ ДОЛЖНЫ** предполагать наличие фиксированной страницы.
  размер

## Формат ответа

Пагинация запускается, когда сервер отправляет **ответ**, который включает в себя:

* Текущая страница результатов
* Необязательное поле `nextCursor`, если есть несколько результатов.

```json theme={null}
{
  "jsonrpc": "2.0",
  "id": "123",
  "результат": {
    "ресурсы": [...],
    "nextCursor": "eyJwYWdlIjogM30="
  }
}
```

## Формат запроса

После получения курсора клиент может *продолжить* постраничную навигацию, отправив соответствующий запрос.
включая этот курсор:

```json theme={null}
{
  "jsonrpc": "2.0",
  "id": "124",
  "метод": "ресурсы/список",
  "параметры": {
    "cursor": "eyJwYWdlIjogMn0="
  }
}
```

## Операции, поддерживающие пагинацию

Следующие операции MCP поддерживают постраничную навигацию:

* `resources/list` - Список доступных ресурсов
* `resources/templates/list` - Список шаблонов ресурсов
* `prompts/list` - Список доступных подсказок
* `tools/list` - Список доступных инструментов

## Руководство по внедрению

1. Серверы **ДОЛЖНЫ**:
   * Обеспечивает стабильные курсоры
   * Корректная обработка недопустимых курсоров

2. Клиенты **должны**:
   * Отсутствие `nextCursor` следует рассматривать как конец результатов.
   * Поддерживаются как постраничные, так и непостраничные потоки.

3. Клиенты **ОБЯЗАНЫ** рассматривать курсоры как непрозрачные токены:
   * Не делайте предположений о формате курсора.
   * Не пытайтесь анализировать или изменять курсоры.
   * Не сохранять курсоры между сессиями

## Обработка ошибок

Недопустимые курсоры **ДОЛЖНЫ** приводить к ошибке с кодом -32602 (Недопустимые параметры).
