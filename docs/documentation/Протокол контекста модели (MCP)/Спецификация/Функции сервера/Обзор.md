# Обзор

<Информация>**Ревизия протокола**: 2025-11-25</Информация>

Серверы предоставляют основные строительные блоки для добавления контекста к языковым моделям посредством
MCP. Эти примитивы обеспечивают расширенное взаимодействие между клиентами, серверами и языком программирования.
модели:

* **Подсказки**: Предварительно определенные шаблоны или инструкции, которые определяют языковую модель.
  взаимодействия
* **Ресурсы**: Структурированные данные или контент, предоставляющие дополнительный контекст для модели.
* **Инструменты**: Исполняемые функции, позволяющие моделям выполнять действия или получать данные.
  информация

Каждый примитив можно обобщить в следующей иерархии управления:

| Примитив    | Управление                | Описание                                                 | Пример                              |
| ----------- | ------------------------- | -------------------------------------------------------- | ----------------------------------- |
| Подсказки   | Управляемые пользователем | Интерактивные шаблоны, вызываемые по выбору пользователя | Команды с косой чертой, пункты меню |
| Ресурсы     | Управляется приложением   | Контекстные данные, прикрепленные и управляемые клиентом | Содержимое файлов, история Git      |
| Инструменты | Управление моделью        | Функции, доступные для LLM для выполнения действий       | POST-запросы к API, запись файлов   |
