# PDF Vector & Graph Framework — Документация

> Полное руководство по фреймворку. **Структура организована по 9 слоям обвязки агента (Harness):**
> LLM — ядро, вокруг 9 слоёв. Каталоги физически сгруппированы по слоям и пронумерованы `слой.глава`.

**Точка входа:** [Карта Harness](0_ВВЕДЕНИЕ/0.3_HARNESS_MAP/49.1_Harness_Map.md) — что такое 9 слоёв и как всё связано.
