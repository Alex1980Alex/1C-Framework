# 01.1 Введение

## Что такое PDF Vector & Graph Framework

PDF Vector & Graph Framework — это платформа для интеллектуальной обработки PDF-документов, объединяющая семантический поиск (Vector), графы знаний (Graph) и RAG-агентов (Retrieval-Augmented Generation) для получения точных и полных ответов на вопросы по содержимому документов.

## Основные возможности

### Интеллектуальный поиск

- **14 стратегий поиска** — от быстрого BM25 (5 мс) до глубокого GraphRAG
- **Hybrid Search** — комбинация семантического, лексического и графового поиска с RRF fusion
- **Section-First Search** — двухуровневый поиск: сначала раздел, затем точные фрагменты
- **Автоматический выбор стратегии** — Adaptive RAG анализирует запрос и выбирает оптимальный подход

### RAG-агенты

- **Self-RAG** — самокорректирующийся агент: оценка релевантности, переписка запроса, проверка галлюцинаций
- **Deep Research** — декомпозиция сложных вопросов на подзадачи, итеративный поиск, синтез ответа
- **Adaptive RAG** — классификация запроса и маршрутизация к оптимальной стратегии
- **Conversational RAG** — многошаговый диалог с сохранением контекста и streaming

### Обработка документов

- **Hybrid Loader** — PyMuPDF4LLM + fitz таблицы + Docling + Vision OCR (сканированные страницы)
- **Image Understanding** — Claude Vision описывает изображения, 81.5% конвертируются в markdown-таблицы
- **Граф знаний** — автоматическое извлечение сущностей и связей, community detection
- **Инкрементальная индексация** — delta updates, версионирование, file watcher

### Множество интерфейсов

- **Web UI** — Gradio интерфейс с 5 вкладками (Chat, Search, Documents, Graph, Settings)
- **REST API** — FastAPI с 40+ эндпоинтами
- **CLI** — командная строка для всех операций
- **MCP Server** — 14 инструментов для интеграции с Claude Code
- **OpenAI-Compatible API** — совместимость с OpenAI Python SDK
- **Python API** — QuickRAG в 3 строки кода

## Ключевые отличия

1. **Section-First Search** — уникальный двухуровневый поиск по структуре документа
2. **Ralph Wiggum** — паттерн самокоррекции LLM-вызовов (11 точек интеграции)
3. **Hybrid Loader** — 4-уровневая загрузка PDF с гарантией 100% покрытия страниц
4. **Turbo Pipeline** — каскадный пайплайн с 31x ускорением для простых запросов
5. **LLM Reranker** — Claude через Z.AI для осмысленного ранжирования (12-24x быстрее CrossEncoder)
