| Adaptive RAG | Классификация запроса → маршрутизация | Claude Haiku 4.5 (classify) |
| Deep Research | Декомпозиция → итеративный поиск → синтез | Claude Opus 4.6 |

| Multi-Agent | Оркестрация нескольких агентов | Claude Opus 4.6 |
| Routing | Маршрутизация к специализированным агентам | Claude Haiku 4.5 |

### 3. Слой поиска

14 стратегий поиска с унифицированным SearchManager:

```
SearchManager
├── VectorSearchStrategy      (семантический, E5-large 1024d)
├── BM25SearchStrategy         (лексический, FTS5 + pymorphy3)
├── HybridSearchStrategy       (vector + BM25 + graph, RRF)
├── GraphSearchStrategy        (поиск по графу знаний)
├── MMRSearchStrategy          (diversity через MMR)
├── TwoStageSearchStrategy     (recall → reranking)
├── SelfRAGSearchStrategy      (с grading и rewrite)
├── AdaptiveSearchStrategy     (автоклассификация)
├── GraphRAGLocalStrategy      (local community search)
├── GraphRAGGlobalStrategy     (global map-reduce)
├── AutoMergeSearchStrategy    (parent-child retrieval)
├── RaptorSearchStrategy       (иерархические суммаризации)
├── SectionFirstPipeline       (BM25 по заголовкам → scoped hybrid)
├── VisualSearchStrategy       (ColPali visual embeddings)
└── WebSearchStrategy          (внешний веб-поиск)
```

## Потоки данных

### Поток индексации

```
PDF файл
  → Hybrid Loader (PyMuPDF + fitz + Docling + Vision OCR)
    → Pipeline (split, metadata, context)
      → Embedding (E5-large, 1024d)
        → Qdrant (dense + BM25 sparse vectors)
        → FTS5 (лемматизированный BM25)
        → NetworkX/Neo4j (entities, relations)
        → Parent Store (parent-child hierarchy)
```

### Поток поиска

```
Запрос пользователя
  → Turbo Classifier (rule-based, 0ms)
    → simple: BM25 (5ms) → ответ
    → moderate: Hybrid Search (vector + BM25 + graph) → Reranker → ответ
    → complex: Adaptive RAG → Decomposition → Multi-step search → Synthesis
```

### Поток RAG

```
Вопрос
  → Self-RAG Agent
    → Поиск контекста (SearchManager)
      → Grading релевантности (параллельный, asyncio.gather)
        → relevance < threshold? → Rewrite запроса → повторный поиск
        → Генерация ответа (Claude Opus 4.6)
          → Hallucination Check
            → grounded? → Ответ пользователю
            → not grounded? → Regeneration
```

### Unified Memory System (Phase 49)

4 подсистемы памяти (`src/memory/`), объединённые через Memory Orchestrator:

| Подсистема | Тип | Backend | MCP Tools |
|-----------|-----|---------|-----------|
| Memory AI | Episodic | SQLite (`data/memory_ai.db`) | 5 (get/save/search/delete/categories) |
| Vector Memory | Semantic | Qdrant (`learned_patterns`, 1024d) | 7 (save/search/apply/get/delete/decay/health) |
| Skill Learning | Learning | JSONL (`data/skill_learning/`) | 7 (capture/batch/pending/confirm/reject/stats/health) |
| Memory Orchestrator | Router | — | UnifiedID + LinkRegistry + FederatedSearch |

UnifiedID формат: `{memory_type}:{source}:{identifier}` (episodic/semantic/docs/learning).
LinkRegistry: SQLite-backed граф связей (6 типов, BFS traversal, batch ops).
FederatedSearch: параллельный async поиск по всем подсистемам с score normalization и dedup.

Подробности: скилл `hooks-skills-mcp-triad`, конфигурация `.claude/skills/skill-router-config.json`.
