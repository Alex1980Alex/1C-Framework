# 01.3 Технологический стек

> **Phase 8 + 9.1 production state (2026-04-30):** retrieval мигрирован на TEI + Qwen3-Embedding-8B 4096d (10 коллекций). Подробности: [chapter 31](../31_QWEN3_RETRIEVAL_PRODUCTION/31.1_Обзор.md).

## Основные технологии

| Компонент | Технология | Версия / Модель | Назначение |
|-----------|------------|----------------|-----------|
| **Язык** | Python | 3.11+ | Основной язык разработки |
| **Main LLM** | Claude Opus 4.6 | claude-opus-4-6 | Генерация ответов, агенты, анализ |
| **Fast LLM** | Claude Sonnet 4.5 | claude-sonnet-4-5-20250929 | Grading, rewriting, hallucination check |
| **Vision** | Claude Sonnet 4.5 | claude-sonnet-4-5-20250929 | Описание изображений из PDF |
| **Embedding** | Qwen3-Embedding-8B (production) | Qwen/Qwen3-Embedding-8B | 4096 dims, last-token pooling, instruction prefix для query |
| **Embedding backend** | TEI Docker | ghcr.io/huggingface/text-embeddings-inference:1.7.2 (Ampere) | FA2, continuous batching, MAX_CLIENT_BATCH_SIZE=32 |
| **Vector Store** | Qdrant | v1.17.1 (Docker) | Dense 4096d cosine; BM25 via SQLite FTS5 (production) |
| **Graph Store** | NetworkX / Neo4j | — | Графы знаний, entity extraction |
| **BM25** | SQLite FTS5 + pymorphy3 | — | Лексический поиск, русская лемматизация |
| **Web Framework** | FastAPI | — | REST API, OpenAI-compatible endpoints |
| **UI** | Gradio | — | Web интерфейс с 5 вкладками |
| **Agent Framework** | LangGraph | — | Оркестрация RAG-агентов |
| **Chains** | LangChain | — | LLM интеграция, tools, chains |
| **CLI** | Typer | — | Командная строка |
| **MCP** | FastMCP | — | Model Context Protocol server |

## Embedding-провайдеры

### Production default (Phase 8)

| Провайдер | Модель | Размерность | Backend | Когда использовать |
|-----------|--------|------------|---------|-------------------|
| **TEI (Qwen3)** | Qwen/Qwen3-Embedding-8B | 4096 | Docker `pdf-rag-tei`, FA2 + continuous batching | **PRODUCTION DEFAULT.** SOTA code+text (MTEB-Code 80.68, Multilingual 70.58), 32K context, last-token pooling + instruction prefix для query |

### Legacy / alternative providers (для справки)

| Провайдер | Модель | Размерность | Языки | Статус / Когда использовать |
|-----------|--------|------------|-------|-----------------------------|
| **Local (E5)** | intfloat/multilingual-e5-large | 1024 | 100+ | Legacy default до Phase 8 (2026-04-30). Может использоваться через `EMBEDDING__PROVIDER=local` |
| **Jina v3** | jina-embeddings-v3 | 1024 | 100+ | Late Chunking, API-based, Matryoshka dimensions |
| **BGE-M3** | BAAI/bge-m3 | 1024 | 100+ | Multilingual fallback, Dense + Sparse + ColBERT |
| **GIGA** | ai-sage/Giga-Embeddings-instruct | 1024 | RU+EN | Path D alternative (SOTA RU 69.1 ruMTEB), не выбрано над Qwen3 |
| **ColPali** | vidore/colpali-v1.3 | multi-vector | Multi | Visual page retrieval (future, см. roadmap §32.6) |
| **MiniLM** | sentence-transformers/all-MiniLM-L6-v2 | 384 | EN+ | Lightweight chunk-boundary detector в `SemanticSplitter` (НЕ retrieval) |

## Vector Store провайдеры

| Провайдер | Тип | Особенности |
|-----------|-----|-------------|
| **Qdrant** (primary) | Docker | Named vectors (dense + sparse), server-side RRF, IDF modifier |
| **ChromaDB** | Embedded | Лёгкий, для разработки |
| **pgvector** | PostgreSQL | SQL-интеграция, транзакции |

## Reranker-ы

| Reranker | Тип | Скорость | Качество | Когда использовать |
|----------|-----|----------|----------|-------------------|
| **LLM Reranker** | Claude via Z.AI | ~5 сек | Высокое | По умолчанию, русский текст |
| **CrossEncoder** | BAAI/bge-reranker-v2-m3 | 60-120 сек (CPU) | Высокое | Без GPU |
| **ColBERT** | colbert-v2 | Быстрый | Среднее | Batch reranking |
| **FlashRank** | ms-marco-MiniLM-L-6-v2 | Быстрый | Среднее | Two-Stage Pipeline |

## Ключевые зависимости

### Основные библиотеки

```
langchain          — LLM интеграция, chains, tools
langgraph          — Agent orchestration, state management
sentence-transformers — Local embedding models
qdrant-client      — Qdrant vector store
fastapi            — REST API
gradio             — Web UI
typer              — CLI
pydantic-settings  — Configuration management
```

### PDF обработка

```
pymupdf4llm        — Основной PDF → Markdown конвертер
pymupdf (fitz)     — Извлечение таблиц и изображений
docling             — Структурный парсинг PDF
```

### Поиск и NLP

```
pymorphy3           — Русская лемматизация для BM25
flashrank           — Лёгкий reranker
networkx            — Граф знаний (in-memory)
neo4j               — Граф знаний (production)
```

### Мониторинг и качество

```
langfuse            — LLM observability
prometheus-client   — Метрики
ragas               — RAG evaluation framework
arq                 — Background job processing
```
