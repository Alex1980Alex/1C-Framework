# 02.1 Установка

## Системные требования

| Требование | Минимум | Рекомендуется |
|-----------|---------|---------------|
| **Python** | 3.11 | 3.11+ |
| **RAM** | 8 GB | 16+ GB |
| **Диск** | 5 GB | 20+ GB (для моделей и индексов) |
| **Docker** | Docker Desktop | Docker Desktop + Docker Compose |
| **GPU** | Не обязательно | NVIDIA GPU (CUDA) для ускорения embeddings |
| **ОС** | Windows 10+, Linux, macOS | Windows 11, Ubuntu 22.04+ |

## Шаг 1: Клонирование репозитория

```bash
git clone <repository-url> 1C-Framework
cd 1C-Framework
```

## Шаг 2: Создание виртуального окружения

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate
```

## Шаг 3: Установка зависимостей

```bash
# Основные зависимости
pip install -e ".[all]"

# Или через Makefile
make install
```

### Установка по группам (опционально)

```bash
# Только ядро (без UI, без evaluation)
pip install -e .

# С поддержкой GPU
pip install -e ".[gpu]"

# С evaluation framework
pip install -e ".[eval]"

# С production зависимостями
pip install -e ".[prod]"
```

## Шаг 4: Запуск Qdrant (Docker)

Qdrant — основное векторное хранилище. Требуется Docker.

```bash
# Запуск Qdrant
docker run -d --name qdrant \
    -p 6333:6333 -p 6334:6334 \
    -v $(pwd)/data/qdrant_storage:/qdrant/storage \
    qdrant/qdrant:v1.15.5

# Проверка
curl http://localhost:6333/healthz
```

### Альтернатива: Docker Compose

```bash
# Запуск всего стека (Qdrant + API + UI)
docker compose -f docker/docker-compose.yml up -d
```

## Шаг 5: Настройка API-ключей

```bash
# Скопировать пример конфигурации
cp .env.example .env

# Обязательно указать:
# ANTHROPIC__API_KEY=your-anthropic-api-key
```

Подробная настройка всех параметров — в [02.2 Конфигурация](02.2_Конфигурация.md).

## Шаг 6: Проверка установки

```bash
# Health check API
python -m src.api.app &
curl http://localhost:8000/health

# Или через CLI
python -m src.cli.main --help
```

## Быстрый старт с Docker Compose

Если вы хотите запустить весь стек одной командой:

```bash
# 1. Настроить .env
cp .env.example .env
# Отредактировать .env — указать ANTHROPIC__API_KEY

# 2. Запустить стек
docker compose -f docker/docker-compose.yml up -d

# 3. Открыть UI
# http://localhost:7860
```

Docker Compose запустит:
- Qdrant (порт 6333)
- API сервер (порт 8000)
- Web UI (порт 7860)

## Возможные проблемы при установке

| Проблема | Решение |
|----------|---------|
| `pip install` падает на `sentence-transformers` | `pip install torch` отдельно, затем повторить |
| Docker не запускается | Убедитесь, что Docker Desktop запущен |
| `CUDA not available` | Установите `pip install torch --index-url https://download.pytorch.org/whl/cu121` |
| Qdrant недоступен | `docker ps` — проверить, что контейнер запущен |
| `ModuleNotFoundError` | Убедитесь, что venv активирован |
