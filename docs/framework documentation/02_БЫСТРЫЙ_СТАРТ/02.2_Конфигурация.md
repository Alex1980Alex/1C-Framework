# 02.2 Конфигурация

Все параметры настраиваются через файл `.env` в корне проекта.

## Обязательные параметры

```env
# API-ключ Anthropic (Claude)
ANTHROPIC__API_KEY=your-anthropic-api-key

# URL Qdrant (если не Docker Compose)
VECTOR_STORE__QDRANT_URL=http://localhost:6333
```
