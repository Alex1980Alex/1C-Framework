# 02.3 Первый запуск

## Пошаговое руководство

### 1. Убедитесь, что всё готово

```bash
# Qdrant запущен
curl http://localhost:6333/healthz
# {"title":"qdrant - vectorass engine","version":"1.15.5"}

# API ключ настроен
grep ANTHROPIC__API_KEY .env
# ANTHROPIC__API_KEY=sk-ant-...
```

### 2. Запустите API сервер

```bash
# Запуск сервера
python -m src.api.app

# Или через Makefile
make serve

# Проверка
curl http://localhost:8000/health
```

### 3. Проиндексируйте первый PDF

```bash
# Через CLI
python -m src.cli.main index "data/pdfs/your-document.pdf" --graph

# Или загрузите через Web UI (см. ниже)
```

При индексации происходит:
1. PDF загружается через Hybrid Loader (PyMuPDF + Docling + Vision OCR)
2. Текст разбивается на чанки (~500-800 символов)
3. Для каждого чанка генерируется embedding (E5-large, 1024d)
4. Чанки сохраняются в Qdrant (dense + BM25 sparse vectors)
5. Строится BM25 FTS5 индекс с русской лемматизацией
6. (При `--graph`) Извлекаются сущности и связи для графа знаний

### 4. Запустите Web UI

```bash
# В отдельном терминале
python -m src.ui.app

# Или через Makefile
make ui
```

Откройте http://localhost:7860

### 5. Попробуйте поиск

#### Через Web UI

1. Перейдите на вкладку **Search**
2. Введите запрос, например: `"конфигуратор"`
3. Выберите стратегию (по умолчанию — vector)
4. Нажмите **Поиск**

#### Через CLI

```bash
# Простой поиск
python -m src.cli.main search "конфигуратор"

# Hybrid (лучшее качество)
python -m src.cli.main search "конфигуратор" --strategy hybrid

# BM25 (самый быстрый, 5 мс)
python -m src.cli.main search "конфигуратор" --strategy bm25
```

#### Через API

```bash
curl -X POST http://localhost:8000/search/ \
    -H "Content-Type: application/json" \
    -d '{"query": "конфигуратор", "strategy": "hybrid", "k": 5}'
```

### 6. Задайте вопрос

#### Через Web UI

1. Перейдите на вкладку **Chat**
2. Введите вопрос: `"Что такое конфигуратор?"`
3. Получите ответ с источниками

#### Через CLI

```bash
python -m src.cli.main ask "Что такое конфигуратор?"

# С streaming
python -m src.cli.main ask "Что такое конфигуратор?" --stream
```

#### Через API

```bash
curl -X POST http://localhost:8000/search/ask \
    -H "Content-Type: application/json" \
    -d '{"query": "Что такое конфигуратор?", "strategy": "hybrid"}'
```

## QuickRAG — 3 строки кода

Самый быстрый способ начать работу из Python:

```python
from src.pdf_framework import QuickRAG

rag = QuickRAG()
rag.add("data/pdfs/your-document.pdf")
answer = rag.ask("Что такое конфигуратор?")
print(answer)
```

Async-версия:

```python
import asyncio
from src.pdf_framework import QuickRAG

async def main():
    rag = QuickRAG()
    await rag.aadd("data/pdfs/your-document.pdf")
    answer = await rag.aask("Что такое конфигуратор?")
    print(answer)

asyncio.run(main())
```
