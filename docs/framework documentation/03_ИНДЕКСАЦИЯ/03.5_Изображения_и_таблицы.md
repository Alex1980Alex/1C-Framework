# 03.5 Изображения и таблицы

## Image Understanding

### Как работает

1. **Извлечение** — PyMuPDF сканирует PDF и извлекает изображения (min 50x50 px)
2. **Claude Vision** — Claude Sonnet 4.5 описывает каждое изображение как OCR-транскриптор
3. **Markdown таблицы** — система распознаёт таблицы в изображениях и конвертирует в markdown (81.5%)
4. **Chunking** — описания становятся отдельными чанками с привязкой к `page_number`
5. **Индексация** — image chunks индексируются вместе с текстовыми (dense + BM25)

### CLI

```bash
# Индексация с извлечением изображений
python -m src.cli.main index "document.pdf" --extract-images

# Комбо: текст + изображения + граф
python -m src.cli.main index "document.pdf" --extract-images --graph
```

### Настройка

```env
VISION__MODEL=claude-sonnet-4-5-20250929
VISION__MAX_TOKENS=2048
VISION__MIN_IMAGE_SIZE=50
```

### Python API

```python
from src.pdf_framework.processing.image_extractor import ImageExtractor

extractor = ImageExtractor(settings=components.settings.vision)

# Извлечь и описать изображения
image_chunks = await extractor.extract_and_describe(
    pdf_path="path/to/document.pdf",
)

for chunk in image_chunks:
    print(f"Page {chunk.metadata.get('page_number')}: {chunk.content[:100]}...")
```

### Результаты (на примере Глава 5)

| Метрика | Значение |
|---------|----------|
| Image chunks | 119 |
| Средняя длина описания | 1237 символов |
| Markdown таблицы | 97/119 (81.5%) |
| Формат таблиц | `|` markdown |

## Извлечение таблиц

### Три источника таблиц

| Источник | Когда используется | Качество |
|----------|-------------------|----------|
| **fitz tables** | Всегда (primary) | Высокое для простых таблиц |
| **Docling** | Fallback для сложных layout | Высокое для структурных |
| **Vision OCR** | Для таблиц в изображениях | Высокое (81.5% → markdown) |

### fitz tables

```python
# PyMuPDF автоматически извлекает таблицы
import fitz

doc = fitz.open("document.pdf")
for page in doc:
    tables = page.find_tables()
    for table in tables:
        markdown = table.to_markdown()
```

### Docling tables

Docling парсит структурные элементы PDF и извлекает таблицы с сохранением:
- Заголовков столбцов
- Объединённых ячеек (merged cells)
- Форматирования

### Vision OCR таблицы

Claude Vision + специальный system prompt + few-shot пример для конвертации табличных изображений в markdown-формат:

```markdown
| Колонка 1 | Колонка 2 | Колонка 3 |
|-----------|-----------|-----------|
| Значение  | Значение  | Значение  |
```

## Section Inheritance для изображений

Изображения наследуют секцию ближайшего текстового чанка:

```
Чанк #155 (текст): section_title = "5.8 Справочники"
Чанк #156 (image): section_title = "5.8 Справочники"  ← наследовано
Чанк #157 (текст): section_title = "5.8 Справочники"
```

Это позволяет Section-First Search находить изображения в контексте правильного раздела.
