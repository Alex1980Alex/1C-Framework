# 04.2 Hybrid Search

## Обзор

Hybrid Search — рекомендуемая стратегия поиска, объединяющая три подхода:

1. **Vector Search** — семантический поиск через E5-large embeddings (1024d)
2. **BM25 Search** — лексический поиск через Qdrant sparse vectors + FTS5
3. **Graph Search** — поиск по графу знаний (entities + relations)

Результаты объединяются через **Reciprocal Rank Fusion (RRF)**.

## Как работает

### Server-side RRF (Qdrant Native)

```
Запрос: "роли и права доступа"

Step 1: Prefetch Dense
  → E5-large embedding → Qdrant dense search → Top 50

Step 2: Prefetch BM25
  → Qdrant sparse vectors (IDF modifier) → Top 50

Step 3: RRF Fusion (server-side)
  → score(d) = SUM 1/(k + rank_i(d)), k=60

Step 4: Graph Merge
  → Результаты из графа знаний → merge с RRF

Step 5: Reranking (LLM)
  → Claude Sonnet 4.5 → финальный top-k
```

### Формула RRF

```
score(d) = Σ 1/(k + rank_i(d))
```

где `k=60` — константа сглаживания, `rank_i(d)` — ранг документа в i-ой подсистеме.

## CLI

```bash
# Hybrid search (по умолчанию — лучшее качество)
python -m src.cli.main search "роли и права доступа" --strategy hybrid

# С увеличенным количеством результатов
python -m src.cli.main search "PostgreSQL СУБД" --strategy hybrid -k 10

# С фильтрацией
python -m src.cli.main search "установка" --strategy hybrid --language ru
```

## Python API

```python
response = await components.search_manager.search(
    query="роли и права доступа",
    strategy="hybrid",
    k=10,
    rerank=True,
)

for result in response.results:
    print(f"Score: {result.score:.4f}")
    print(f"Section: {result.chunk.metadata.get('section_title')}")
    print(f"Page: {result.chunk.metadata.get('page_number')}")
    print(f"Content: {result.chunk.content[:150]}...")
    print()
```

## API

## Настройка весов

```env
# Для концептуальных вопросов ("что такое", "как работает")
SEARCH__HYBRID_VECTOR_WEIGHT=0.7
SEARCH__HYBRID_GRAPH_WEIGHT=0.3

# Для фактических вопросов ("версия", "имя файла")
SEARCH__HYBRID_VECTOR_WEIGHT=0.4
SEARCH__HYBRID_GRAPH_WEIGHT=0.6

# Универсальные (default)
SEARCH__HYBRID_VECTOR_WEIGHT=0.6
SEARCH__HYBRID_GRAPH_WEIGHT=0.4

# RRF константа
SEARCH__HYBRID_RRF_K=60
```

## Производительность

| Этап | Время |
|------|-------|
| Dense search | 415-475 мс |
| BM25 search | 5-14 мс |
| RRF fusion | <1 мс |
| Graph merge | 10-50 мс |
| LLM reranking | ~5 с |
| **Итого без reranking** | **~500 мс** |
| **Итого с LLM reranking** | **~5.5 с** |
