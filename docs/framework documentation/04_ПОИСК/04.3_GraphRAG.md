# 04.3 GraphRAG

## Обзор

GraphRAG использует граф знаний для поиска информации через сущности и их связи. Доступны 4 режима:

| Режим | Стратегия | Описание |
|-------|-----------|----------|
| **Local** | `graphrag_local` | Поиск по ближайшим сущностям и community summaries |
| **Global** | `graphrag_global` | Map-reduce по ВСЕМ communities для обзорных ответов |
| **LightRAG** | `graph` | Dual-level: entity vectors + relation vectors |
| **Auto** | `adaptive` | Автоматический выбор Local vs Global по типу запроса |

## Local Search

Находит ближайшие сущности в графе и собирает контекст из их окружения.

```bash
python -m src.cli.main search "конфигуратор" --strategy graphrag_local --top-k 5
```

**Алгоритм:**
1. Поиск entity по запросу (через entity embeddings)
2. Обход соседних entities (1-2 hop)
3. Сбор community summaries
4. Сбор связанных чанков
5. Генерация ответа на основе собранного контекста

**Лучше всего для:** конкретных вопросов об объектах, терминах, связях.

## Global Search

Map-reduce по всем community summaries для высокоуровневых обзоров.

```bash
python -m src.cli.main search "архитектура платформы 1С" --strategy graphrag_global
```

**Алгоритм:**
1. **Map** — для каждой community генерируется промежуточный ответ (Claude Haiku)
2. **Reduce** — промежуточные ответы объединяются в финальный (Claude Sonnet)

**Лучше всего для:** обзорных вопросов, "расскажи об архитектуре", "какие бывают типы...".

## Настройка

```env
# Community Detection (при индексации)
GRAPH_RAG__COMMUNITY_DETECTION=true
GRAPH_RAG__COMMUNITY_ALGORITHM=leiden

# Local Search
GRAPH_RAG__LOCAL_SEARCH_K=10

# Global Search (модели)
GRAPH_RAG__GLOBAL_MAP_LLM=claude-haiku-4-5-20251001
GRAPH_RAG__GLOBAL_REDUCE_LLM=claude-sonnet-4-5-20250929
```

## Python API

```python
# Local GraphRAG
response = await components.search_manager.search(
    query="конфигуратор",
    strategy="graphrag_local",
    k=5,
)

# Global GraphRAG
response = await components.search_manager.search(
    query="архитектура платформы",
    strategy="graphrag_global",
    k=5,
)
```

## Требования

GraphRAG требует предварительной индексации с графом:

```bash
python -m src.cli.main index "document.pdf" --graph --communities
```

Без `--communities` Local Search будет работать (через entities), но Global Search требует community summaries.
