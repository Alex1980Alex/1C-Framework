# 04.4 BM25 Lexical Search

## Обзор

BM25 — полнотекстовый лексический поиск. Самая быстрая стратегия: **5-14 мс** (в 50-60x быстрее vector search).

## Два backend-а

| Backend | Технология | Особенности |
|---------|------------|-------------|
| **Qdrant Native** | Sparse vectors + IDF modifier | Server-side, интегрирован с Hybrid |
| **FTS5** | SQLite FTS5 + pymorphy3 lemmatization | Standalone, русская морфология |

### Настройка

```env
# Выбор backend
SEARCH__BM25_BACKEND=qdrant
# Варианты: "qdrant" | "fts5" | "both"
```

## Русская лемматизация (pymorphy3)

BM25 с pymorphy3 корректно обрабатывает русские словоформы:

```
"регистром" → "регистр"
"накопления" → "накопление"
"справочников" → "справочник"
"объектами конфигурации" → "объект конфигурация"
```

Результат на бенчмарке RusBEIR: **NDCG@10 = 52.16**

## CLI

```bash
# BM25 поиск (5-14 мс)
python -m src.cli.main search "модуль внешнего соединения" --strategy bm25

# BM25 с фильтрацией
python -m src.cli.main search "регистр накопления" --strategy bm25 --language ru
```

## Multi-column FTS5

FTS5 индекс использует мульти-колоночную схему с бустом заголовков:

```sql
-- title получает 10x вес, body — 1x
CREATE VIRTUAL TABLE chunks_fts USING fts5(
    chunk_id, title, body,
    tokenize='unicode61'
);
```

При поиске:
1. **Title-only search** — поиск только по заголовкам (section_title)
2. **Body-only search** — поиск по тексту чанков
3. **Two-pass RRF** — слияние результатов title + body через RRF(k=60)

## Пересборка BM25 индекса

Если BM25 возвращает 0 результатов или данные рассинхронизировались:

```bash
# Через скрипт
python build_bm25_index.py

# Через API
curl -X POST http://localhost:8000/documents/rebuild-bm25

# Через Web UI — кнопка «Пересобрать BM25» на вкладке Documents
```

## Python API

```python
# BM25 поиск
response = await components.search_manager.search(
    query="модуль внешнего соединения",
    strategy="bm25",
    k=10,
)

# Qdrant native hybrid (vector + BM25)
response = await components.search_manager.search(
    query="роли и права доступа",
    strategy="hybrid",
    k=10,
)
```

## Производительность

| Операция | Время |
|----------|-------|
| BM25 FTS5 search | 5-14 мс |
| BM25 Qdrant sparse | 10-20 мс |
| Vector search | 415-475 мс |
| **Ускорение BM25 vs Vector** | **50-60x** |
