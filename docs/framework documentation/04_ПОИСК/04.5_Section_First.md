# 04.5 Section-First Search

## Обзор

Section-First Search — уникальная двухуровневая стратегия поиска:

1. **Определение раздела** — BM25 по заголовкам (title=10x) находит доминирующий раздел
2. **Scoped Hybrid** — Hybrid search ограничен найденным разделом

## Как работает

```
Запрос: "справочники"

Step 1: BM25 Two-Pass
  → Title-only: "5.8 Справочники" (score: 0.95)
  → Body-only: chunks из разных разделов
  → RRF merge → dominant section = "5.8" (>50% результатов)

Step 2: Scoped Hybrid Search
  → Vector + BM25 + Graph, ограничено section_prefix = "5.8"
  → Результаты только из раздела "5.8 Справочники"
```

### Результаты

```
"справочники"            → раздел 5.8
"регистры накопления"    → раздел 5.14
"формы"                  → раздел 5.8.1
"модули объектов"        → раздел 5.3
```

## CLI

```bash
# Section-First поиск
python -m src.cli.main search "справочники" --strategy section_first
```

## ToC API

Framework предоставляет API для навигации по структуре документа:

```bash
# Получить оглавление
curl http://localhost:8000/toc/{document_id}

# Получить конкретный раздел
curl http://localhost:8000/toc/{document_id}/section/5.8

# Генерация суммаризаций разделов
curl -X POST http://localhost:8000/toc/{document_id}/generate-summaries
```

## Breadcrumb в результатах

Каждый чанк содержит breadcrumb-навигацию:

```
Раздел: Глава 5 > 5.8 Справочники > 5.8.1 Формы справочника
```

Breadcrumb включается в контекст RAG-агента для лучшего понимания структуры.

## Metadata чанков

| Поле | Описание | Пример |
|------|----------|--------|
| `section_title` | Заголовок раздела | `"5.8 Справочники"` |
| `section_number` | Номер раздела | `"5.8"` |
| `breadcrumb` | Полный путь | `"Глава 5 > 5.8 Справочники > 5.8.1"` |
| `level` | Уровень вложенности | `2` |
| `parent_section` | Родительский раздел | `"5"` |

## Настройка

```env
# Section-First использует BM25 multi-column
# Title получает 10x boost
# Dominant section = >50% результатов в одном разделе
```
