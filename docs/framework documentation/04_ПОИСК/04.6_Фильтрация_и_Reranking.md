# 04.6 Фильтрация и Reranking

## Metadata фильтрация

### Доступные фильтры

| Фильтр | Описание | Значения |
|--------|----------|----------|
| `language` | Язык документа | `ru`, `en` |
| `document_type` | Тип документа | `documentation`, `user_manual`, `developer_guide`, `admin_guide`, `api_reference`, `tutorial`, `introduction` |
| `version` | Версия документа | `8.3`, `8.3.26`, `8.3.27` |

### CLI

```bash
# Фильтр по языку
python -m src.cli.main search "руководство" --language ru

# Фильтр по типу документа
python -m src.cli.main search "установка" --doc-type user_manual

# Фильтр по версии
python -m src.cli.main search "конфигуратор" --version 8.3

# Комбинированные фильтры
python -m src.cli.main search "PostgreSQL" \
    --strategy hybrid \
    --language ru \
    --doc-type documentation \
    --version 8.3
```

### Python API

```python
response = await components.search_manager.search(
    query="конфигуратор",
    strategy="hybrid",
    k=10,
    filter={
        "language": "ru",
        "document_type": "documentation",
        "version": "8.3",
    },
)
```

## Reranking

### 4 типа reranker-ов

| Reranker | Тип | Скорость | Качество | Когда |
|----------|-----|----------|----------|-------|
| **LLM** | Claude via Z.AI | ~5 с | Высокое | По умолчанию |
| **CrossEncoder** | BAAI/bge-reranker-v2-m3 | 60-120 с (CPU) | Высокое | Без API |
| **FlashRank** | ms-marco-MiniLM-L-6-v2 | Быстро | Среднее | Two-Stage |
| **ColBERT** | colbert-v2 | Быстро | Среднее | Batch |

### LLM Reranker (рекомендуется)

Использует Claude Sonnet 4.5 через Z.AI API для осмысленной оценки релевантности на русском языке:

```env
AGENT__RERANKER_TYPE=llm
```

Преимущества:
- Понимает русский текст на уровне LLM
- 12-24x быстрее CrossEncoder
- Осмысленные оценки 0.0-1.0

### CrossEncoder

```env
AGENT__RERANKER_TYPE=cross_encoder
AGENT__RERANKER_MODEL=BAAI/bge-reranker-v2-m3
```

Альтернативные модели:
- `BAAI/bge-reranker-v2-m3` — multilingual (рекомендуется)
- `BAAI/bge-reranker-large` — самая точная
- `ms-marco-MiniLM-L-6-v2` — быстрая (English)

### Отключение reranking

```bash
# CLI
python -m src.cli.main search "быстрый запрос" --no-rerank

# Python API
response = await components.search_manager.search(
    query="быстрый запрос",
    strategy="vector",
    rerank=False,
)
```
