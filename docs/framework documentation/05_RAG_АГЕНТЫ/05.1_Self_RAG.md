## Обзор

Self-RAG — самокорректирующийся RAG-агент на базе LangGraph. Автоматически контролирует качество поиска и генерации ответа через три механизма:

1. **Document Grading** — оценка релевантности каждого найденного документа
2. **Query Rewriting** — автоматическая переписка запроса при низкой релевантности
3. **Hallucination Check** — проверка ответа на соответствие контексту

## Как работает

```
Вопрос
  → Поиск контекста (SearchManager)
    → Document Grading (параллельно, asyncio.gather)
      ├── relevant (score > threshold) → в контекст
      └── irrelevant → отбрасывается
    → Достаточно релевантных? (relevance ratio)
      ├── Да → Генерация ответа (Claude Opus 4.6)
      │         → Hallucination Check
      │           ├── grounded → Ответ пользователю
      │           └── not grounded → Regeneration (до 2 попыток)
      └── Нет → Query Rewriting (Ralph Wiggum)
                → Повторный поиск (до 2 попыток)
```

## Ralph Wiggum — самокоррекция

Self-RAG использует паттерн Ralph Wiggum: при неудаче LLM-вызова, **причина отказа** передаётся в следующую попытку (не слепой retry):

```
Попытка 1: "Ответ слишком короткий (15 символов, требуется >20)"
Попытка 2: (включает feedback) → более полный ответ
```

Точки интеграции Ralph Wiggum в Self-RAG:
- `generate_answer` — длина >20 символов, русский язык
- `_grade_one` — ответ начинается с yes/no/да/нет
- `check_hallucination` — grounded/not_grounded формат
- `_rewrite_via_llm` — не идентичен оригиналу, очистка префиксов

## Python API

```python
from src.api.dependencies.components import Components

async def ask_with_self_rag():
    components = Components()
    await components.initialize()

    # Поиск контекста
    search_response = await components.search_manager.search(
        query="Что такое конфигуратор?",
        strategy="hybrid",
        k=5,
    )

    # RAG ответ (Self-RAG включён автоматически)
    from src.pdf_framework.chains.qa.retrieval_qa import RetrievalQAChain

    chain = RetrievalQAChain(
        settings=components.settings.agent,
        api_key=components.settings.anthropic_api_key,
    )

    answer = await chain.answer(
        question="Что такое конфигуратор?",
        search_response=search_response,
    )
    print(answer)
```

## LLM Rotation (дешёвый LLM)

Компоненты Self-RAG поддерживают CheapLLM fallback через LLM Rotation Service. При включении (`LLM_ROTATION_ENABLED=true`) grader, hallucination_checker и rewriter сначала пробуют дешёвый LLM (GLM-5 и др.), при неудаче — Claude. Конфигурация: `LLM_ROTATION_COMPONENTS` в `.env`. Подробнее: skill `llm-rotation`.
