# 05.2 Adaptive RAG

## Обзор

Adaptive RAG автоматически анализирует запрос и выбирает оптимальную стратегию поиска.

## Как работает

```
Запрос → Classifier (rule-based 90% / LLM 10%)
  → factual + simple   → vector search
  → factual + moderate → hybrid search + reranking
  → conceptual         → graphrag_local
  → overview           → graphrag_global
  → complex            → decomposition → multi-step search
  → comparison         → decomposition → parallel search → synthesis
```

### Rule-based Classifier (Turbo, 0 мс)

90% запросов классифицируются через правила без LLM:

| Паттерн | Тип | Стратегия |
|---------|-----|-----------|
| "что такое X" | factual | vector |
| "как работает X" | conceptual | hybrid |
| "сравните X и Y" | comparison | decomposition |
| "расскажите о X" | overview | graphrag_global |
| "какие бывают X" | exploratory | graphrag_local |
| Сложный вопрос | complex | decomposition |

### LLM Classifier (для неопределённых)

Оставшиеся 10% классифицируются через Claude Haiku.

## CLI

```bash
# Adaptive RAG
python -m src.cli.main search "Что такое модуль?" --strategy adaptive --verbose

# Verbose покажет классификацию
# [CLASSIFY] Query type: factual
# [CLASSIFY] Complexity: simple
# [ROUTE] Selected strategy: vector
```

## Query Decomposition

Для сложных запросов Adaptive RAG автоматически разбивает вопрос на подвопросы:

```bash
python -m src.cli.main search "Сравните конфигуратор и пользовательский режим" \
    --strategy adaptive --verbose
```

```
[DECOMPOSE] Sub-questions:
  1. Что такое конфигуратор?
  2. Что такое пользовательский режим?
  3. В чем различия между ними?
[SEARCH] Sub-question 1... (5 results)
[SEARCH] Sub-question 2... (5 results)
[SEARCH] Sub-question 3... (3 results)
[SYNTHESIS] Combining results...
```

## Force Route

Принудительный выбор стратегии:

```bash
python -m src.cli.main search "архитектура" \
    --strategy adaptive \
    --force-route graphrag_global
```

## Настройка

```env
ADAPTIVE__ROUTING_ENABLED=true
ADAPTIVE__CLASSIFIER_MODEL=claude-haiku-4-5-20251001
ADAPTIVE__DECOMPOSE_THRESHOLD=complex
```
