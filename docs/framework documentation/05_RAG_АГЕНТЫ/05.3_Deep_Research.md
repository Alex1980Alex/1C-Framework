# 05.3 Deep Research Agent

## Обзор

Deep Research Agent предназначен для сложных исследовательских вопросов. Декомпозирует вопрос на подзадачи и проводит итеративный многошаговый поиск.

## Как работает

```
Вопрос: "Сравните все типы модулей в 1С и их области применения"

Step 1: Research Planner
  → Декомпозиция на 3-5 подвопросов:
    1. Какие типы модулей существуют?
    2. Каково назначение каждого типа?
    3. В каких случаях используется каждый тип?

Step 2: Multi-Step Retrieval (LangGraph)
  → Для каждого подвопроса:
    → Поиск (vector + BM25 + graph)
      → Проверка полноты
        → Недостаточно? → Уточнённый поиск

Step 3: Quality Checker
  → Coverage check: все ли аспекты покрыты?
  → Groundedness check: все ли факты подтверждены?

Step 4: Synthesizer
  → Синтез финального ответа
  → Citation chains (ссылки на источники)
```

## CLI

```bash
# Deep Research (многошаговый поиск)
python -m src.cli.main research "Сравните все типы модулей в 1С и их области применения"
```

## Python API

```python
from src.pdf_framework.agents.deep.research_agent import DeepResearchAgent

agent = DeepResearchAgent(
    search_manager=components.search_manager,
    settings=components.settings,
)

result = await agent.research(
    question="Сравните все типы модулей в 1С",
    max_steps=5,
)

print(result.answer)
print(f"Sources: {len(result.sources)}")
print(f"Sub-questions: {result.sub_questions}")
```

## Компоненты

| Компонент | Назначение |
|-----------|-----------|
| **ResearchPlanner** | Декомпозиция на 2-4 подвопроса |
| **Multi-Step Retriever** | Итеративный поиск с углублением |
| **CrossDocumentSynthesizer** | Синтез из нескольких источников |
| **ResearchQualityChecker** | Проверка coverage + groundedness |

## Когда использовать

- Сравнительные вопросы ("сравните X и Y")
- Обзорные вопросы ("расскажите обо всех типах...")
- Аналитические вопросы ("какие преимущества и недостатки...")
- Вопросы, требующие информации из нескольких разделов
