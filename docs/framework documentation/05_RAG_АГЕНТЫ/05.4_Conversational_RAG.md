# 05.4 Conversational RAG

## Обзор

Conversational RAG обеспечивает многошаговый диалог с сохранением контекста, переписью запросов с учётом истории и потоковым выводом ответов.

## Interactive Chat

### CLI

```bash
# Запуск интерактивного чата
pdf-framework chat --strategy hybrid
```

### Команды чата

```
> Что такое конфигуратор?
(ответ)

> А какие у него функции?
(ответ с учётом контекста — агент помнит, что речь о конфигураторе)

> /history        — показать историю диалога
> /clear          — очистить историю
> /strategy vector — сменить стратегию
> /quit           — выход
```

## Query Reformulation

Каждый новый вопрос автоматически переписывается с учётом истории:

```
History:
  User: "Что такое конфигуратор?"
  AI: "Конфигуратор — это средство разработки..."

User: "А какие у него функции?"
Reformulated: "Какие функции у конфигуратора в 1С:Предприятие?"
```

## Streaming Responses

```bash
# CLI с streaming
python -m src.cli.main ask "Опишите архитектуру 1С:Предприятие" --stream

# API с SSE
curl -X POST http://localhost:8000/search/ask/stream \
    -H "Content-Type: application/json" \
    -d '{"query": "Опишите архитектуру 1С:Предприятие"}'
```

## Thread Management

Сохранение и продолжение сессий:

```bash
# Чат с именованной сессией
pdf-framework chat --thread session-1 --strategy adaptive

# Продолжение предыдущей сессии
pdf-framework chat --thread session-1
```

## Настройка

```env
CONVERSATION__MAX_HISTORY=10
CONVERSATION__STORAGE=sqlite
CONVERSATION__DB_PATH=data/conversations.db
```

## Web UI Chat

На вкладке **Chat** в Web UI:
- Ввод вопроса в текстовое поле
- Streaming ответ с визуальным индикатором
- Источники (чанки) отображаются под ответом
- Кнопки feedback (thumbs up/down)
- История диалога сохраняется в рамках сессии
