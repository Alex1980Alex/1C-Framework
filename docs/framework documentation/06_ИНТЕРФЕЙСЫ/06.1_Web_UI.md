# 06.1 Web UI (Gradio)

## Запуск

```bash
# Запуск backend (API)
python -m src.api.app
# → http://localhost:8000

# Запуск UI (в отдельном терминале)
python -m src.ui.app
# → http://localhost:7860
```

Или через Makefile:
```bash
make serve   # API на :8000
make ui      # UI на :7860
```

## 5 вкладок

### Chat — Диалог с AI

- Ввод вопроса в текстовое поле
- Streaming ответ с визуальным индикатором
- Источники (чанки) под ответом с номерами страниц
- Кнопки обратной связи (thumbs up/down)
- История диалога в рамках сессии
- Кнопка "Сбросить всё" для очистки

### Search — Поиск с фильтрами

- Поисковая строка
- Выбор стратегии (vector, hybrid, bm25, graphrag_local, graphrag_global, и др.)
- Количество результатов (top-k)
- Фильтры: язык, тип документа, версия
- Результаты с score, section_title, page_number
- Breadcrumb навигация

### Documents — Управление документами

- Загрузка PDF файлов (drag & drop)
- Список проиндексированных документов
- Удаление документов (каскадное из всех хранилищ)
- Кнопка "Пересобрать BM25" для синхронизации FTS5
- Статистика: количество чанков, страниц, entities

### Graph — Визуализация графа

- Интерактивная визуализация сущностей и связей
- Фильтрация по типу сущности
- Поиск entity по имени
- Просмотр связей для выбранной сущности
- Статистика графа (entities, edges, communities)

### Settings — Настройки и статистика

- Текущая конфигурация (модели, провайдеры)
- Статистика кэша (hit rate, entries)
- Статистика индекса (чанки, документы)
- Кнопка "Сбросить всё" (очистка кэша + настроек)

## Hook & Skill Dashboard (Streamlit)

Отдельная страница для мониторинга хуков и скиллов:

```bash
streamlit run src/ui/pages/hook_dashboard.py
```

### Возможности

- **Real-time метрики** — auto-refresh, 5 KPI-карточек
- **Hook invocation timeline** — график вызовов за выбранный период
- **Skill activation rate** — gauge + breakdown по скиллам + Source колонка (prompt-detection / post-tool-use)
- **Latency analysis** — p95, распределение по хукам
- **Error log viewer** — фильтрация ошибок
- **Session history** — scatter plot сессий

### Data source

Dashboard читает данные из SQLite (`HookMetricsDB`), который инжестит из JSONL-логов:
- `data/hook-invocations.jsonl` — invocations всех хуков
- `data/logs/skill-router.log` — рекомендации скиллов
- `data/logs/skill-usage.log` — фактические активации

**Файлы:** `src/ui/pages/hook_dashboard.py`, `src/pdf_framework/observability/hook_metrics_db.py`

## Настройка UI

```bash
# Указать порт и API URL
python -m src.ui.app --port 7860 --api-url http://localhost:8000

# Поделиться через Gradio share
python -m src.ui.app --share
```
