# 06.2 REST API

## Запуск

```bash
python -m src.api.app
# → http://localhost:8000
# → Swagger UI: http://localhost:8000/docs
```

### Поиск

| Method | Endpoint | Описание |
|--------|----------|----------|
| `POST` | `/search/` | Поиск по документам |
| `POST` | `/search/ask` | RAG question-answering |
| `POST` | `/search/ask/stream` | RAG с SSE streaming |
| `POST` | `/search/suggest` | Предложения запросов |
| `POST` | `/search/analyze` | Analyze |
| `POST` | `/search/research` | Research |
| `POST` | `/search/multi-agent` | Multi Agent |
| `POST` | `/search/visual` | Visual |
| `POST` | `/search/plan-execute` | Plan Execute |

```bash
# Поиск
curl -X POST http://localhost:8000/search/ \
    -H "Content-Type: application/json" \
    -d '{
        "query": "конфигуратор",
        "strategy": "hybrid",
        "k": 5,
        "rerank": true,
        "filter": {"language": "ru"}
    }'

# RAG (вопрос-ответ)
curl -X POST http://localhost:8000/search/ask \
    -H "Content-Type: application/json" \
    -d '{
        "query": "Что такое конфигуратор?",
        "strategy": "hybrid"
    }'
```

### Документы

| Method | Endpoint | Описание |
|--------|----------|----------|
| `POST` | `/documents/index` | Индексация PDF |
| `GET` | `/documents/` | Список документов |
| `GET` | `/documents/{id}` | Информация о документе |
| `DELETE` | `/documents/{id}` | Удаление документа (каскадное) |
| `POST` | `/documents/rebuild-bm25` | Пересборка BM25 индекса |
| `POST` | `/documents/upload` | Upload |
| `POST` | `/documents/index/stream` | Stream |
| `POST` | `/documents/index/batch/stream` | Stream |
| `GET` | `/documents/files` | Files |
| `GET` | `/documents/registry` | Registry |
| `PATCH` | `/documents/registry/{document_id}` | Registry |
| `GET` | `/documents/stats` | Stats |
| `DELETE` | `/documents/clear` | Clear |
| `POST` | `/documents/rebuild-sparse` | Rebuild Sparse |
| `POST` | `/documents/index/delta` | Delta |
| `GET` | `/documents/index/delta/stats` | Stats |
| `POST` | `/documents/index/delta/clear` | Clear |
| `POST` | `/documents/index-async` | Index Async |

```bash
# Индексация PDF
curl -X POST http://localhost:8000/documents/index \
    -F "file=@document.pdf" \
    -F "options={\"graph\": true}"

# Список документов
curl http://localhost:8000/documents/

# Удаление (каскадное из 9 хранилищ)
curl -X DELETE http://localhost:8000/documents/{document_id}

# Пересборка BM25
curl -X POST http://localhost:8000/documents/rebuild-bm25
```
