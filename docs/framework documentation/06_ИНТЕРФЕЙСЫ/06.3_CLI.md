# 06.3 CLI (Командная строка)

## Запуск

```bash
python -m src.cli.main --help
```

## Основные команды

### search — Поиск

```bash
python -m src.cli.main search "ЗАПРОС" [ОПЦИИ]
```

| Опция | Описание | Default |
|-------|----------|---------|
| `--strategy`, `-s` | Стратегия поиска | `vector` |
| `--top-k`, `-k` | Количество результатов | `5` |
| `--no-rerank` | Отключить reranking | `false` |
| `--language` | Фильтр по языку | — |
| `--doc-type` | Фильтр по типу | — |
| `--version` | Фильтр по версии | — |
| `--diversity` | MMR diversity (0.0-1.0) | `0.3` |
| `--expand-query` | HyDE расширение | `false` |
| `--verbose`, `-v` | Подробный вывод | `false` |
| `--tenant` | Tenant ID | `default` |
| `--force-route` | Принудительная стратегия | — |

```bash
# Примеры
python -m src.cli.main search "конфигуратор" --strategy hybrid
python -m src.cli.main search "регистр" --strategy bm25 --language ru
python -m src.cli.main search "архитектура" --strategy adaptive --verbose
python -m src.cli.main search "настройка" --strategy mmr --diversity 0.7 -k 10
```

### ask — Вопрос с RAG-ответом

```bash
python -m src.cli.main ask "ВОПРОС" [ОПЦИИ]
```

| Опция | Описание | Default |
|-------|----------|---------|
| `--strategy`, `-s` | Стратегия поиска | `hybrid` |
| `--no-self-rag` | Отключить Self-RAG | `false` |
| `--stream` | Потоковый вывод | `false` |
| `--verbose`, `-v` | Подробный вывод | `false` |

```bash
python -m src.cli.main ask "Что такое конфигуратор?" --stream
python -m src.cli.main ask "Сравните регистры" --strategy adaptive --verbose
```

### index — Индексация PDF

```bash
python -m src.cli.main index "ПУТЬ" [ОПЦИИ]
```

| Опция | Описание |
|-------|----------|
| `--graph` | Извлечь граф знаний |
| `--communities` | Community detection |
| `--parent-child` | Parent-child hierarchy |
| `--raptor` | RAPTOR tree |
| `--summarize` | Summary index |
| `--layout-aware` | Layout-aware parsing |
| `--extract-images` | Image extraction + Vision |
| `--extract-tables` | Table extraction |
| `--contextual` | Contextual Retrieval |
| `--recursive` | Рекурсивная обработка директории |
| `--full-reindex` | Полная переиндексация |
| `--tenant` | Tenant ID |
| `ui` | Ui |
| `feedback` | Feedback |

```bash
python -m src.cli.main index "document.pdf" --graph --communities
python -m src.cli.main index "docs/" --recursive --graph
```

### dashboard — Дашборд метрик

Открывает HTML-дашборд с автоматическим запуском всей цепочки зависимостей:
1. **Docker Desktop** — если не запущен
2. **Qdrant** — контейнер создаётся или перезапускается
3. **API-сервер** — uvicorn в фоне
4. **Браузер** — открывает дашборд

```bash
python -m src.cli.main dashboard [ОПЦИИ]
```

| Опция | Описание | Default |
|-------|----------|---------|
| `--port` | Порт API-сервера | `8000` |
| `--host` | Хост API-сервера | `127.0.0.1` |
| `--page` | Страница для открытия | `metrics/html` |
| `--no-browser` | Не открывать браузер | `false` |
| `--no-docker` | Пропустить запуск Docker/Qdrant | `false` |

```bash
# Полный автозапуск (Docker → Qdrant → API → Браузер)
python -m src.cli.main dashboard

# Без Docker (только API-сервер в degraded mode)
python -m src.cli.main dashboard --no-docker

# На другом порту
python -m src.cli.main dashboard --port 9000

# Без открытия браузера
python -m src.cli.main dashboard --no-browser
```
