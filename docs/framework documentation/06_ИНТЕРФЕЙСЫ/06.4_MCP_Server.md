# 06.4 MCP Server

## Обзор

MCP (Model Context Protocol) Server предоставляет 24 инструментов для интеграции с Claude Code и другими MCP-совместимыми клиентами.

## Запуск

```bash
# Запуск MCP сервера
python -m src.mcp_server.server
```

## 14 инструментов

| # | Инструмент | Описание |
|---|-----------|----------|
| 1 | `search_documents` | Поиск по проиндексированным документам |
| 2 | `ask_question` | RAG question-answering |
| 3 | `index_pdf` | Индексация PDF файла |
| 4 | `list_documents` | Список проиндексированных документов |
| 5 | `delete_document` | Удаление документа |
| 6 | `get_document_info` | Информация о документе |
| 7 | `search_graph` | Поиск по графу знаний |
| 8 | `get_graph_stats` | Статистика графа |
| 9 | `get_cache_stats` | Статистика кэша |
| 10 | `clear_cache` | Очистка кэша |
| 11 | `rebuild_bm25` | Пересборка BM25 индекса |
| 12 | `get_toc` | Получить оглавление документа |
| 13 | `submit_feedback` | Отправить обратную связь |
| 14 | `get_metrics` | Получить метрики |
| 15 | `graph_query` | Graph Query |
| 16 | `analyze` | Analyze |
| 17 | `research` | Research |
| 18 | `web_search` | Web Search |
| 19 | `search_with_fallback` | Search With Fallback |
| 20 | `list_collections` | List Collections |
| 21 | `get_stats` | Get Stats |
| 22 | `visual_search` | Visual Search |
| 23 | `visual_hybrid_search` | Visual Hybrid Search |
| 24 | `plan_execute` | Plan Execute |

## Примеры использования

### Поиск

```
search_documents(
    query="конфигуратор",
    strategy="hybrid",
    k=5,
    language="ru"
)
```

### RAG ответ

```
ask_question(
    query="Что такое конфигуратор?",
    strategy="hybrid"
)
```

### Индексация

```
index_pdf(
    path="data/pdfs/document.pdf",
    graph=true,
    communities=true
)
```

## Настройка в Claude Code

Добавить в `.claude/settings.local.json`:

```json
{
    "mcpServers": {
        "pdf-framework": {
            "command": "python",
            "args": ["-m", "src.mcp_server.server"],
            "cwd": "/path/to/1C-Framework"
        }
    }
}
```

## Дополнительные MCP серверы

Помимо основного PDF Framework MCP сервера, проект включает специализированные серверы:

| Сервер | Модуль | Назначение |
|--------|--------|------------|
| `bsl-semantic-search` | `src.bsl.semantic_search.mcp` | Семантический поиск по BSL коду |
| `bsl-platform-context` | Java JAR | API платформы 1С:Предприятие |
| `memory-ai` | `src.memory.ai_memory.server` | Эпизодическая память (5 tools) |
| `vector-memory` | `src.memory.vector_memory.server` | Семантические паттерны (7 tools) |
| `skill-learning` | `src.memory.skill_learning.server` | Обучение на паттернах (7 tools) |

Конфигурация всех серверов: `.mcp.json` в корне проекта.
