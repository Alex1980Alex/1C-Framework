# 06.6 OpenAI-Compatible API

## Обзор

Framework предоставляет OpenAI-совместимый endpoint `/v1/chat/completions`, позволяющий использовать OpenAI Python SDK для работы с RAG.

## Endpoint

```
POST /v1/chat/completions
```

## Использование через curl

```bash
curl -X POST http://localhost:8000/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{
        "model": "pdf-rag",
        "messages": [
            {"role": "user", "content": "Что такое конфигуратор?"}
        ]
    }'
```

## Использование через OpenAI Python SDK

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="not-needed",  # API ключ не требуется для локального сервера
)

response = client.chat.completions.create(
    model="pdf-rag",
    messages=[
        {"role": "user", "content": "Что такое конфигуратор?"}
    ],
)

print(response.choices[0].message.content)
```

## Streaming

```python
stream = client.chat.completions.create(
    model="pdf-rag",
    messages=[
        {"role": "user", "content": "Расскажите об архитектуре 1С"}
    ],
    stream=True,
)

for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")
```

## Совместимость

Поддерживаемые параметры:
- `model` — `"pdf-rag"` (единственная модель)
- `messages` — массив сообщений
- `stream` — потоковый вывод
- `temperature` — не используется (игнорируется)
- `max_tokens` — не используется (игнорируется)

## Когда использовать

- Интеграция с приложениями, использующими OpenAI SDK
- Замена OpenAI API на локальный RAG без изменения кода
- Тестирование через инструменты, совместимые с OpenAI API
