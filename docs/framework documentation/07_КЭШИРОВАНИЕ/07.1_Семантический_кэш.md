# 07.1 Семантический кэш

## Обзор

Семантический кэш сохраняет результаты поиска и возвращает их для похожих запросов без повторного вычисления. Если новый запрос >= 0.95 похож на кэшированный — мгновенный ответ из кэша.

## Как работает

```
Запрос: "конфигуратор в 1С Предприятие"

Step 1: Вычислить embedding запроса
Step 2: Сравнить с кэшированными запросами (cosine similarity)
Step 3: Найден кэш: "конфигуратор 1С" (similarity = 0.97 > 0.95)
Step 4: Возврат кэшированного результата (< 1 мс)
```

## Производительность

| Сценарий | Время |
|----------|-------|
| Первый запрос (embedding + поиск + LLM) | ~5-30 с |
| Повторный/похожий запрос (из кэша) | < 1 мс |

## CLI

```bash
# Первый запрос: ~5 секунд
python -m src.cli.main search "конфигуратор 1С"

# Повторный/похожий: < 1 секунды
python -m src.cli.main search "конфигуратор в 1С Предприятие"
```

## Управление

```bash
# Статистика кэша
curl http://localhost:8000/cache/stats

# Очистка кэша
curl -X DELETE http://localhost:8000/cache/clear
```

## Настройка

```env
CACHE__SEMANTIC_ENABLED=true
CACHE__SEMANTIC_THRESHOLD=0.95    # Cosine similarity порог
CACHE__SEMANTIC_TTL=3600          # TTL в секундах (1 час)
```

## Автоматическая инвалидация

Кэш автоматически очищается при:
- Переиндексации документа
- Удалении документа
- Ручной очистке через API/UI

## Python API

```python
from src.pdf_framework.search.semantic_cache import SemanticCache

cache = SemanticCache(threshold=0.95, ttl=3600)

# Проверить кэш
cached = await cache.get(query="конфигуратор 1С", strategy="hybrid")
if cached:
    return cached  # < 1 мс

# Сохранить в кэш
await cache.put(
    query="конфигуратор 1С",
    strategy="hybrid",
    response=search_response,
)
```
