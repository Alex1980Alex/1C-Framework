# 07.2 Embedding кэш

## Обзор

LRU кэш эмбеддингов запросов. Повторные запросы не требуют вычисления embedding через модель — используется кэшированное значение.

## Как работает

```
Запрос → embedding model → 1024d vector (415-475 мс)
Повторный запрос → LRU cache hit → 1024d vector (< 1 мс)
```

## Настройка

```env
CACHE__EMBEDDING_ENABLED=true
```

## Статистика

