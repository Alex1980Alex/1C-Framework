# 07.3 LLM кэш

## Обзор

Кэш ответов LLM. Сохраняет сгенерированные ответы с привязкой к запросу и стратегии поиска.

## Как работает

```
Ключ кэша = hash(query + strategy + context_hash)
  → Есть в кэше? → Возврат мгновенно
  → Нет? → LLM генерация → Сохранение в кэш
```

## Настройка

```env
CACHE__LLM_ENABLED=true
```

## Управление кэшем

```bash
# Статистика
pdf-framework cache stats

# Очистить только LLM кэш
pdf-framework cache clear --type llm

# Очистить только embedding кэш
pdf-framework cache clear --type embedding

# Очистить весь кэш
pdf-framework cache clear --type all
```

## Через API

```bash
curl http://localhost:8000/cache/stats
curl -X DELETE http://localhost:8000/cache/clear
```
