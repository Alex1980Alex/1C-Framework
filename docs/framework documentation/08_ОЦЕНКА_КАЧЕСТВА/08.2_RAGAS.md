# 08.2 RAGAS Integration

## Обзор

Интеграция с RAGAS (Retrieval Augmented Generation Assessment) framework для стандартизированной оценки качества RAG.

## Метрики RAGAS

| Метрика | Описание |
|---------|----------|
| **Context Precision** | Доля релевантных чанков в найденном контексте |
| **Context Recall** | Покрытие ground truth найденным контекстом |
| **Faithfulness** | Соответствие ответа найденному контексту |
| **Answer Relevancy** | Релевантность ответа вопросу |

## CLI

```bash
# RAGAS оценка
python -m src.cli.main eval --dataset "data/eval/benchmark.json" --evaluator ragas

# Regression testing
python -m src.cli.main eval --dataset "data/eval/benchmark.json" \
    --evaluator ragas --compare-with "reports/prev_eval.json"
```

## Python API

```python
from src.pdf_framework.evaluation.ragas_adapter import RAGASAdapter

adapter = RAGASAdapter(settings=components.settings)

result = await adapter.evaluate(
    questions=["Что такое конфигуратор?"],
    answers=["Конфигуратор — это..."],
    contexts=[retrieved_contexts],
    ground_truths=["Конфигуратор — средство разработки..."],
)

print(f"Faithfulness: {result.faithfulness:.2f}")
print(f"Answer Relevancy: {result.answer_relevancy:.2f}")
print(f"Context Precision: {result.context_precision:.2f}")
```

## Regression Testing

Отслеживание деградации качества между версиями:

```python
from src.pdf_framework.evaluation.regression import RegressionTester

tester = RegressionTester()

# Quick test (30 секунд)
result = await tester.run(mode="quick", dataset="data/eval/benchmark.json")

# Full test (5-10 минут)
result = await tester.run(mode="full", dataset="data/eval/benchmark.json")

# Сравнение
if result.degraded:
    print(f"DEGRADATION: {result.metric} dropped from {result.prev} to {result.current}")
```

## Synthetic Test Generation

Автоматическая генерация тестовых вопросов из чанков:

```python
from src.pdf_framework.evaluation.synthetic import (
    GoldenDatasetGenerator,
    SyntheticQuestionGenerator,
)

# Только синтетические вопросы (LLM-generated)
gen = SyntheticQuestionGenerator(api_key="...", model="claude-haiku-4-5-20251001")
dataset = gen.generate_from_chunks(chunks, questions_per_chunk=2, max_total_questions=50)

# Смешанный датасет: синтетические + human-curated из JSONL
golden_gen = GoldenDatasetGenerator(api_key="...")
dataset = golden_gen.create_golden_dataset(
    chunks=indexed_chunks,
    include_synthetic=True,
    synthetic_ratio=0.5,   # 50% synthetic, остальное из JSONL
    max_total=100,
    human_questions_file="data/eval/human_qs.jsonl",  # §6.3.3 — опционально
)
```

**Формат JSONL для `human_questions_file`** (добавлен §6.3.3, 2026-05-01):
```json
{"question": "Как настроить Qdrant?", "answer": "...", "context": "...", "difficulty": "medium"}
{"question": "Какой тип индекса использовать?", "question_type": "factual"}
```
Обязательное поле: `question`. Остальные (`answer`, `context`, `question_type`, `difficulty`) — опциональны.

## Заметки по реализации

**Безопасное извлечение текста из ответа LLM-судьи (2026-05-28).** `RAGASEvaluator`
читает оценку из ответа Anthropic SDK через внутренний helper `_first_text(response)`,
который выбирает **первый блок с `type == "text"`** (`next((b.text for b in
response.content if b.type == "text"), "")`), а не `response.content[0].text`.
Причина: `response.content` — это union типов блоков (`TextBlock | ThinkingBlock |
ToolUseBlock | …`), и `.text` есть только у `TextBlock`. При обычных eval-вызовах
(без extended thinking и tools) первый блок всегда текстовый, поэтому поведение не
изменилось; но при не-текстовом первом блоке helper отдаёт `""` (→ `_parse_score`
вернёт нейтральные 0.5) вместо runtime `AttributeError`/`IndexError`. Публичный API
`RAGASEvaluator` не менялся.
