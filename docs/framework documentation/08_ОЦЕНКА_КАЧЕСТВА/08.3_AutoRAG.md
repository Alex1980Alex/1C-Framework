# 08.3 AutoRAG — Автоматическая оптимизация

## Обзор

AutoRAG автоматически подбирает оптимальные параметры RAG через grid search.

## Что оптимизируется

| Параметр | Значения |
|----------|----------|
| **strategy** | vector, hybrid, bm25, mmr, two_stage, graphrag_local |
| **k** (top-k) | 3, 5, 10, 15 |
| **rerank** | true, false |
| **diversity** (MMR) | 0.1, 0.3, 0.5, 0.7 |
| **weights** (hybrid) | vector:0.4-0.8, graph:0.2-0.6 |

## CLI

```bash
# Grid search
python -m src.cli.main autorag --dataset "data/eval/benchmark.json"

# С ограничением
python -m src.cli.main autorag --dataset "data/eval/benchmark.json" \
    --strategies vector,hybrid,bm25 \
    --k-values 3,5,10
```

## Python API

```python
from src.pdf_framework.evaluation.autorag import AutoRAGRunner, ParameterGrid

grid = ParameterGrid(
    strategies=["vector", "hybrid", "bm25", "mmr"],
    k_values=[3, 5, 10],
    rerank=[True, False],
)

runner = AutoRAGRunner(
    search_manager=components.search_manager,
    grid=grid,
)

results = await runner.run(dataset_path="data/eval/benchmark.json")

# Лучшая конфигурация
best = results.best_config()
print(f"Best: strategy={best.strategy}, k={best.k}, rerank={best.rerank}")
print(f"Score: {best.score:.4f}")
```

## Smart Grid

Вместо полного перебора — интеллектуальный выбор комбинаций:

```python
from src.pdf_framework.evaluation.autorag import SmartGrid

grid = SmartGrid(budget=20)  # Максимум 20 экспериментов
# SmartGrid выберет наиболее информативные комбинации
```

## Экспорт оптимальной конфигурации

```python
# Экспорт в .env формат
best_config = results.best_config()
best_config.export_env("optimized.env")
```
