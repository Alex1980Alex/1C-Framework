# 08.4 Обратная связь (Self-Learning Feedback)

## Обзор

Система обратной связи позволяет пользователям оценивать ответы. Положительные оценки используются для улучшения качества.

## Как работает

```
Пользователь оценивает ответ (1-5 stars)
  → Feedback Store (SQLite)
    → Few-Shot: лучшие примеры (5 stars) → в промпты
    → Score Boost: документы с позитивным фидбеком → boost при поиске
    → Strategy Tuning: статистика → адаптация параметров
```

## Три компонента

| Компонент | Назначение |
|-----------|-----------|
| **Feedback Store** | Хранение оценок пользователей (1-5 stars) |
| **Few-Shot Provider** | Лучшие примеры (5 stars) как few-shot в промптах |
| **Score Booster** | Boost score документов с позитивным фидбеком |

## Отправка feedback

### Через API

```bash
curl -X POST http://localhost:8000/feedback/ \
    -H "Content-Type: application/json" \
    -d '{
        "query": "конфигуратор",
        "result_id": "chunk_123",
        "score": 5,
        "comment": "Точный ответ"
    }'
```

### Через Web UI

На вкладке Chat — кнопки thumbs up / thumbs down под каждым ответом.

### Python API

```python
from src.pdf_framework.feedback.store import FeedbackStore

store = FeedbackStore()

await store.add(
    query="конфигуратор",
    chunk_id="chunk_123",
    score=5,
    comment="Отличный ответ",
)

# Получить лучшие примеры для few-shot
examples = await store.get_best_examples(query="конфигуратор", top_k=3)
```
