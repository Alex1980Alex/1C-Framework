# 09.3 Rate Limiting

## Обзор

Ограничение частоты запросов через slowapi для защиты от перегрузки.

## Лимиты по умолчанию

| Endpoint | Лимит |
|----------|-------|
| `POST /search/` | 30 запросов/минуту |
| `POST /search/ask` | 10 запросов/минуту |
| `POST /documents/index` | 5 запросов/минуту |
| Остальные | 60 запросов/минуту |

## Настройка

```env
RATE_LIMIT__ENABLED=true
RATE_LIMIT__REQUESTS_PER_MINUTE=60
RATE_LIMIT__BURST=10
```

## Ответ при превышении лимита

```json
{
    "detail": "Rate limit exceeded. Try again in 30 seconds.",
    "retry_after": 30
}
```

HTTP статус: `429 Too Many Requests`

## Отключение

```env
RATE_LIMIT__ENABLED=false
```
