# 09.4 Мониторинг

## Observability Stack

| Компонент | Назначение | Тип |
|-----------|-----------|-----|
| **JSON Tracing** | Логирование всех операций | Файловый |
| **Langfuse** | LLM observability (traces, costs) | SaaS/Self-hosted |
| **Prometheus** | Метрики (latency, throughput) | Metrics |
| **HTML Dashboard** | Визуальный дашборд метрик | Web |

## JSON Tracing

Все операции логируются в JSON формате:

```env
OBSERVABILITY__TRACER=jsonfile
OBSERVABILITY__TRACE_DIR=data/traces
```

```bash
# Поиск с verbose
python -m src.cli.main search "конфигуратор" --verbose
# → Trace сохраняется в data/traces/
```

## Langfuse

Полноценный LLM observability:
- Traces всех LLM-вызовов
- Стоимость (tokens, cost)
- Latency по шагам
- Качество (scores)

```env
LANGFUSE__ENABLED=true
LANGFUSE__PUBLIC_KEY=your-public-key
LANGFUSE__SECRET_KEY=your-secret-key
LANGFUSE__HOST=https://cloud.langfuse.com
```

## Prometheus Metrics

```bash
# Получить метрики
curl http://localhost:8000/metrics/

# HTML дашборд
# http://localhost:8000/metrics/html
```

### Доступные метрики

| Метрика | Тип | Описание |
|---------|-----|----------|
| `search_requests_total` | Counter | Общее число поисковых запросов |
| `search_latency_seconds` | Histogram | Задержка поиска |
| `index_chunks_total` | Counter | Проиндексированных чанков |
| `cache_hits_total` | Counter | Попаданий в кэш |
| `cache_misses_total` | Counter | Промахов кэша |
| `llm_tokens_total` | Counter | Использованных токенов LLM |

## Analytics

```bash
# Аналитика использования
curl http://localhost:8000/metrics/analytics
```

Включает:
- Топ запросов
- Распределение по стратегиям
- Средняя задержка по стратегиям
- Hit rate кэша
