# 09.4 Мониторинг

## Observability Stack

| Компонент | Назначение | Тип |
|-----------|-----------|-----|
| **JSON Tracing** | Логирование всех операций | Файловый |
| **Langfuse** | LLM observability (traces, costs) | SaaS/Self-hosted |
| **Prometheus** | Метрики (latency, throughput) | Metrics |
| **HTML Dashboard** | Визуальный дашборд метрик | Web |
| **Hook Metrics DB** | SQLite инжест hook invocations | SQLite |

| **OTLP Exporter** | OpenTelemetry для хуков | OTLP |

## JSON Tracing

Все операции логируются в JSON формате:

```env
OBSERVABILITY__TRACER=jsonfile
OBSERVABILITY__TRACE_DIR=data/traces
```

```bash
# Поиск с verbose
python -m src.cli.main search "конфигуратор" --verbose
# → Trace сохраняется в data/traces/
```

## Langfuse

Полноценный LLM observability:
- Traces всех LLM-вызовов
- Стоимость (tokens, cost)
- Latency по шагам
- Качество (scores)

```env
LANGFUSE__ENABLED=true
LANGFUSE__PUBLIC_KEY=your-public-key
LANGFUSE__SECRET_KEY=your-secret-key
LANGFUSE__HOST=https://cloud.langfuse.com
```

## Предварительное условие: запуск REST API

HTML Dashboard, Prometheus и Analytics — эндпоинты FastAPI. Они доступны **только при запущенном API-сервере**:

```bash
# Запуск API-сервера
python -m uvicorn src.api.app:create_app --factory --host 0.0.0.0 --port 8000

# Или через CLI
python -m src.cli.main serve --port 8000
```

После запуска все `/metrics/*` эндпоинты становятся доступны по адресу `http://localhost:8000`.

**Файл:** `src/api/app.py` (фабрика `create_app`), `src/api/routes/metrics.py` (эндпоинты)

## HTML Dashboard

Визуальный дашборд системных метрик в браузере с автообновлением каждые 30 секунд.

**URL:** `http://localhost:8000/metrics/html`

### Секции дашборда

| Секция | Содержимое |
|--------|-----------|
| **Key Metrics** | 6 карточек: Total Queries, Queries Today, Avg Latency, P95 Latency, Cache Hit Rate, Error Rate |
| **Cache Statistics** | Таблица: Embedding Cache, LLM Response Cache, Document Cache (hits, misses, hit rate с progress bar) |
| **Search Strategy Usage** | Таблица стратегий поиска с долей использования (%) |

### Как работает

1. `GET /metrics/html` вызывает `get_metrics()` — сбор метрик из 4 источников:
   - `MetricsCollector` — общие метрики (queries, latency, errors)
   - `EmbeddingCache` — кеш эмбеддингов (hits/misses)
   - `LLMCache` — кеш LLM-ответов (hits/misses)
   - `DocumentCache` — кеш документов (hits/stale)
2. Значения подставляются в HTML-шаблон через `string.Template`
3. JavaScript автоматически перезагружает страницу каждые 30 секунд

### Цветовая индикация

| Метрика | Зелёный | Жёлтый | Красный |
|---------|---------|--------|---------|
| Cache Hit Rate | > 50% | 20-50% | < 20% |
| Error Rate | < 1% | 1-5% | > 5% |

## Prometheus Metrics

```bash
# JSON метрики
curl http://localhost:8000/metrics/

# Prometheus exposition format (для scraping)
curl http://localhost:8000/metrics/prometheus

# HTML дашборд (в браузере)
http://localhost:8000/metrics/html
```

### Доступные метрики

| Метрика | Тип | Описание |
|---------|-----|----------|
| `search_requests_total` | Counter | Общее число поисковых запросов |
| `search_latency_seconds` | Histogram | Задержка поиска |
| `index_chunks_total` | Counter | Проиндексированных чанков |
| `cache_hits_total` | Counter | Попаданий в кэш |
| `cache_misses_total` | Counter | Промахов кэша |
| `llm_tokens_total` | Counter | Использованных токенов LLM |

## Hook Observability

Мониторинг хуков Claude Code (invocations, skill activations, latency):

### Hook Metrics DB

SQLite pipeline для инжеста JSONL-логов хуков в базу данных:

```python
from src.pdf_framework.observability.hook_metrics_db import HookMetricsDB

db = HookMetricsDB()
db.ingest_from_logs()

recent = db.get_recent_invocations(limit=100)
metrics = db.get_hook_metrics(hours=24)
skills = db.get_skill_metrics(hours=24)
```

**Файл:** `src/pdf_framework/observability/hook_metrics_db.py`

### OpenTelemetry Tracing для хуков

```python
from src.pdf_framework.observability.tracer import HookTracer

tracer = HookTracer()
with tracer.span("hook_execution", hook="SkillRouter"):
    # hook logic
    pass
```

Поддерживаемые backends: JsonFile, LangSmith, Langfuse, OpenTelemetry.

**Файл:** `src/pdf_framework/observability/tracer.py`

### CLI Dashboard

```bash
python scripts/hook-dashboard.py              # Текстовый отчёт
python scripts/hook-dashboard.py --period 7d  # За 7 дней
python scripts/hook-dashboard.py --json       # JSON для CI
```

### Streamlit Dashboard

5 вкладок: metrics, timeline, skill activation, latency, errors. Подробнее: [06.1 Web UI](../06_ИНТЕРФЕЙСЫ/06.1_Web_UI.md#hook--skill-dashboard-streamlit).

**Файл:** `scripts/test-hooks-e2e.py`

```bash
python scripts/eval-hooks.py --list-suites   # Доступные suites
python scripts/eval-hooks.py --suite ide-filtering  # Один suite
python scripts/eval-hooks.py --json           # JSON для CI
```

5 suites: skill-activation (20 тестов), stop-hook-safety (3), ide-filtering (10), git-commit-enforcement (2), docs-change-enforcement (3).

**Файлы:** `scripts/eval-hooks.py`, `tests/eval/hook_prompts.json`
