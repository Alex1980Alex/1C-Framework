# 09.5 Docker

## Быстрый запуск

```bash
# Запуск всего стека
docker compose -f docker/docker-compose.yml up -d
```

Запускаются:
- **Qdrant** (порт 6333) — векторное хранилище
- **API** (порт 8000) — REST API
- **UI** (порт 7860) — Gradio Web UI

## Docker Compose (базовый)

```yaml
services:
  qdrant:
    image: qdrant/qdrant:v1.15.5
    ports:
      - "6333:6333"
      - "6334:6334"
    volumes:
      - ./data/qdrant_storage:/qdrant/storage

  api:
    build: .
    ports:
      - "8000:8000"
    environment:
      - VECTOR_STORE__QDRANT_URL=http://qdrant:6333
    depends_on:
      - qdrant

  ui:
    build: .
    command: python -m src.ui.app
    ports:
      - "7860:7860"
    depends_on:
      - api
```

## GPU Docker

Для ускорения embedding на GPU:

```bash
docker compose -f docker/docker-compose.gpu.yml up -d
```

Требуется:
- NVIDIA Docker Runtime
- CUDA-совместимый GPU

## Standalone Qdrant

```bash
docker run -d --name qdrant \
    -p 6333:6333 -p 6334:6334 \
    -v $(pwd)/data/qdrant_storage:/qdrant/storage \
    qdrant/qdrant:v1.15.5

# Проверка
curl http://localhost:6333/healthz
```

## Production Deploy

### Nginx reverse proxy

```nginx
upstream api {
    server localhost:8000;
}

server {
    listen 443 ssl;
    server_name your-domain.com;

    location /api/ {
        proxy_pass http://api/;
    }

    location / {
        proxy_pass http://localhost:7860;
    }
}
```

### Health checks

```bash
# API
curl http://localhost:8000/health

# Qdrant
curl http://localhost:6333/healthz

# UI
curl http://localhost:7860
```

## Переменные окружения для Docker

```bash
# .env для Docker
ANTHROPIC__API_KEY=sk-ant-...
VECTOR_STORE__PROVIDER=qdrant
VECTOR_STORE__QDRANT_URL=http://qdrant:6333
EMBEDDING__MODEL=intfloat/multilingual-e5-large
```
