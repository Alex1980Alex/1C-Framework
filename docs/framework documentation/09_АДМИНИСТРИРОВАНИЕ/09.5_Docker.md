# 09.5 Docker

## Быстрый запуск

```bash
# Запуск всего стека
docker compose -f docker/docker-compose.yml up -d
```

Запускаются:
- **Qdrant** (порт 6333) — векторное хранилище
- **API** (порт 8000) — REST API
- **UI** (порт 7860) — Gradio Web UI

## Docker Compose (базовый)

```yaml
services:
  qdrant:
    image: qdrant/qdrant:v1.15.5
    ports:
      - "6333:6333"
      - "6334:6334"
    volumes:
      - ./data/qdrant_storage:/qdrant/storage

  api:
    build: .
    ports:
      - "8000:8000"
    environment:
      - VECTOR_STORE__QDRANT_URL=http://qdrant:6333
    depends_on:
      - qdrant

  ui:
    build: .
    command: python -m src.ui.app
    ports:
      - "7860:7860"
    depends_on:
      - api
```

## GPU Docker

Для ускорения embedding на GPU:

```bash
docker compose -f docker/docker-compose.gpu.yml up -d
```

Требуется:
- NVIDIA Docker Runtime
- CUDA-совместимый GPU

### TEI — text-embeddings-inference (Phase 8.12.6, opt-in)

Альтернативный backend для Qwen3-Embedding-8B через HTTP-сервер
(Rust runtime: continuous batching + token-based dynamic batching +
FlashAttention 2). Используется скриптом `scripts/reindex_bsl_qwen3.py`
с флагом `--embedder qwen3-tei`.

Сервис добавлен в `docker/docker-compose.gpu.yml` под opt-in профилем
`tei` (по умолчанию не стартует):

```bash
docker compose -f docker/docker-compose.yml \
  -f docker/docker-compose.gpu.yml --profile tei up -d tei

# Smoke-check
curl -s http://localhost:8080/health
curl -s http://localhost:8080/info | jq .model_id
```

Параметры (в `docker-compose.gpu.yml`):

| Env | Значение | Зачем |
|---|---|---|
| `MODEL_ID` | `Qwen/Qwen3-Embedding-8B` | Pinned per Phase 8 roadmap |
| `MAX_INPUT_LENGTH` | `4096` | Совпадает с `Qwen3STEmbedder.max_seq_length` (Phase 8.12 C5) |
| `MAX_BATCH_TOKENS` | `16384` | Conservative для 24 GB VRAM, тюнится после 8.12.3 baseline |
| `DTYPE` | `bfloat16` | Native для Qwen3; fallback `float32` если регрессирует TEI [issue #675](https://github.com/huggingface/text-embeddings-inference/issues/675) (Qwen3 + ORT FP16) |

Image tag — `ghcr.io/huggingface/text-embeddings-inference:1.7.2`
(Ampere base для RTX 3090 sm_86; **не `turing-1.5`** — тот для sm_75
и идёт по медленному code-path на Ampere).

## Standalone Qdrant

```bash
docker run -d --name qdrant \
    -p 6333:6333 -p 6334:6334 \
    -v $(pwd)/data/qdrant_storage:/qdrant/storage \
    qdrant/qdrant:v1.15.5

# Проверка
curl http://localhost:6333/healthz
```

## Production Deploy

### Nginx reverse proxy

```nginx
upstream api {
    server localhost:8000;
}

server {
    listen 443 ssl;
    server_name your-domain.com;

    location /api/ {
        proxy_pass http://api/;
    }

    location / {
        proxy_pass http://localhost:7860;
    }
}
```

### Health checks

```bash
# API
curl http://localhost:8000/health

# Qdrant
curl http://localhost:6333/healthz

# UI
curl http://localhost:7860
```

## Переменные окружения для Docker

```bash
# .env для Docker
ANTHROPIC__API_KEY=sk-ant-...
VECTOR_STORE__PROVIDER=qdrant
VECTOR_STORE__QDRANT_URL=http://qdrant:6333
EMBEDDING__MODEL=intfloat/multilingual-e5-large
```
