## Потоки данных

### Поток индексации

```
PDF файл
  → Hybrid Loader (PyMuPDF + fitz + Docling + Vision OCR)
    → Pipeline (split, metadata, context)
      → Embedding (TEI + Qwen3-Embedding-8B, 4096d)
        → Qdrant (dense 4096d)
        → FTS5 (лемматизированный BM25)
        → NetworkX/Neo4j (entities, relations)
        → Parent Store (parent-child hierarchy)
```

### Поток поиска

```
Запрос пользователя
  → Turbo Classifier (rule-based, 0ms)
    → simple: BM25 (5ms) → ответ
    → moderate: Hybrid Search (vector + BM25 + graph) → Reranker → ответ
    → complex: Adaptive RAG → Decomposition → Multi-step search → Synthesis
```

### Поток RAG

```
Вопрос
  → Self-RAG Agent
    → Поиск контекста (SearchManager)
      → Grading релевантности (параллельный, asyncio.gather)
        → relevance < threshold? → Rewrite запроса → повторный поиск
        → Генерация ответа (Claude Opus 4.6)
          → Hallucination Check
            → grounded? → Ответ пользователю
            → not grounded? → Regeneration
```

История: изначально (2026-05-04) хук был на UPS с regex-парсингом prompt'а; затем переключили на `UserPromptExpansion` ([официальный Claude Code 2.x event](https://code.claude.com/docs/en/hooks) со структурированным `command_name`); затем **2026-05-05 эмпирически на Windows** подтверждено что UPE для `/cmd` платформой **не эмитится** — ноль hook entries при валидной регистрации в settings.json (session `10108f33-...`), тогда как UPS стреляет надёжно. Вернулись на UPS-primary, UPE-обработчик оставили как forward-compat: если платформа починит событие — заработает без правок, дублирующий run_id защищён `get_run`-guard'ом. UPS-парсинг: двухступенчатый — `<command-name>NAME</command-name>` тэг (post-expansion form) приоритетнее, fallback `^\s*/NAME` (raw CLI). Перед raw-regex'ом стрипается leading backtick/quote noise (Claude Code v2.1.126+ оборачивает real CLI prompts в `` `/cmd args ``, см. commit `fbdf1b720`; live-регрессия пойманная в session `2800d2fd-...` 2026-05-05 — backtick-strip случайно удалили при UPE→UPS rewrite, восстановили). UPE-fallback по-прежнему фильтрует `expansion_type=="slash_command"`, отсекая MCP-prompts с собственной observability через `mcp-invocation-logger`), `logging-status-banner.py` (SessionStart → выводит status-баннер `[mcp/slash logging: ACTIVE]` с количеством slash_run/mcp_call за последние 24ч; способ верифицировать что хуки активны после рестарта Claude Code). Все записи идут в общий `data/hook-invocations.jsonl` с полями `category` (`hook` / `mcp_call` / `slash_run`) и `run_id` (сквозной trace slash-run → MCP-вызовы → end). Расширение схемы — в `shared/invocation_logger.py` (поля `category`, `run_id`, обратно совместимы). `shared/run_context.py` использует Windows `msvcrt.locking` (POSIX `fcntl.flock` fallback) для защиты от lost-update при concurrent Claude-сессиях, плюс GC orphan `.tmp` файлов старше часа. ### Unified Memory System (Phase 49, Hermes Phase 0)

4 подсистемы памяти (`src/memory/`), объединённые через Memory Orchestrator:

| Подсистема | Тип | Backend | MCP Tools |
|-----------|-----|---------|-----------|
| Memory AI | Episodic | SQLite (`data/memory_ai.db`) | 5 (get/save/search/delete/categories) |
| Vector Memory | Semantic | Qdrant (`learned_patterns`, 4096d Qwen3) | 7 (save/search/apply/get/delete/decay/health) |
| Skill Learning | Learning | JSONL (`data/skill_learning/`) | 7 (capture/batch/pending/confirm/reject/stats/health) |
| Memory Orchestrator | Router | — | UnifiedID + LinkRegistry + FederatedSearch |

UnifiedID формат: `{memory_type}:{source}:{identifier}` (episodic/semantic/docs/learning/**wiki/graph**).
LinkRegistry: SQLite-backed граф связей (**10 типов**: based_on, supports, contradicts, extends, derives_from, session_context, **promoted_to, superseded_by, mirrors, graph_node**; BFS traversal, batch ops).
FederatedSearch: параллельный async поиск по всем подсистемам с score normalization и dedup. `AiMemorySearchAdapter` использует tokenized LIKE matching (split query → OR-join на токен ≥ 3 символов) + Python-side rerank по `0.5 × match_ratio + 0.5 × importance` — находит многословные запросы в кириллическом content. Timeout-resilience: per-adapter `asyncio.wait_for(timeout_ms)` + outer hard-ceiling `asyncio.timeout(timeout_ms × 1.5)` вокруг цикла сбора результатов — гарантирует возврат tool call за ≤ 7.5 s даже при деградации thread pool / event loop в долгоживущей MCP-сессии.

MemoryCube wiki serialization: `to_wiki_page()` (YAML frontmatter + markdown sections) / `from_wiki_page()` round-trip. Wiki drafts saved to `docs/wiki/drafts/<slug>.md`.
memory-first-hook v3: 4-layer RRF (SQLite 0.30, Qdrant 0.35, .md 0.15, Wiki 0.20).
