# Совместимость embedding SDK

Путь `BSL_EMBEDDER=st` передаёт `tokenizer_kwargs={"padding_side": "left"}` в конструктор SentenceTransformer. Этот параметр есть в проверенных колёсах 3.0.0, 5.1.2 и 5.3.0; начиная с проверенной версии 5.4.0 конструктор его не принимает. Ограничение зависимости следует этому контракту; переход на новый API требует отдельной проверки. Первичный источник: [SentenceTransformers на PyPI](https://pypi.org/project/sentence-transformers/).

Проверка сигнатур не загружает модели и не доказывает качество векторов. Перед сменой модели или backend сравните результаты с эталонным пространством коллекции. Для Qwen3 необходимо сохранить левое дополнение tokenizer, инструкции запроса и размерность вектора.

Провайдеры `local` и `giga` передают список текстов в `encode` с его стандартными float32 NumPy sentence embeddings. После `tolist()` ожидается список списков float; аннотация этого результата не меняет значения и не выполняет преобразования.

Claude Vision принимает MIME-типы `image/jpeg`, `image/png`, `image/gif`, `image/webp`. При отсутствии попадания в кэш другой `image_format` возвращает существующий ответ `success=False` до сетевого вызова. Допустимый формат передаётся без конвертации содержимого.

CI устанавливает зависимости из `pyproject.toml`. Сводка границ проверки: [CI compatibility](../../../ci-compatibility.md).
