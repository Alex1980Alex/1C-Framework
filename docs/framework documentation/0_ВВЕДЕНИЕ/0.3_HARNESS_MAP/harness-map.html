9 слоёв harness → компоненты фреймворка

Сама LLM — только ядро. Всё, что делает её рабочим агентом, — «обвязка» (harness) из девяти слоёв вокруг модели. Ниже: каждый слой из схемы-образа и то, чем он уже реализован в этом проекте.

LLM
Модель = ядро. Она генерирует текст и запросы к инструментам. Harness — 9 слоёв вокруг — превращает генерацию в автономного агента: даёт контекст, инструменты, память, проверку и оркестрацию.
слой harness — концепция из схемы

7

Слой «Проверка» у этого фреймворка глубже схемы-первоисточника: это не один блок, а целый слой fail-closed Stop-энфорсеров и композируемых политик (evaluate_gates), которых в исходной инфографике нет.

Блоки Feedback Loop / Scheduled Automation / Session Persistence / Orchestrator из второй схемы тоже сопоставлены: skill-learning + pattern-reinforce · cron/CI-autopilot · session-memory-save + HMR .active.json · memory-orchestrator + gate-orchestrator.
