# 10.1 Частые ошибки

## Qdrant не доступен

**Симптом:** `ConnectionError: Cannot connect to Qdrant at localhost:6333`

**Поведение API-сервера:** Если Qdrant (или Neo4j) недоступен при старте, сервер запускается в **degraded mode** — эндпоинты метрик (`/metrics/`, `/metrics/html`) и health (`/health`) работают, а search/index/chat возвращают 500. В логах:
```
WARNING: Failed to initialize components (Qdrant/Neo4j may be offline): ...
         Server will start in degraded mode — metrics and health endpoints remain available.
```

**Решение — запустить Qdrant:**
```bash
# Проверить контейнер
docker ps | grep qdrant

# Запустить, если не запущен
docker run -d --name qdrant -p 6333:6333 -p 6334:6334 \
    -v $(pwd)/data/qdrant_storage:/qdrant/storage \
    qdrant/qdrant:v1.15.5

# Проверить здоровье
curl http://localhost:6333/healthz

# Перезапустить API-сервер для полной инициализации
```

## BM25 возвращает 0 результатов

**Симптом:** Стратегия `bm25` не находит ничего.

**Решение:**
```bash
# Пересобрать FTS5 индекс
python build_bm25_index.py

# Или через API
curl -X POST http://localhost:8000/documents/rebuild-bm25

# Проверить количество записей
python -c "
from src.pdf_framework.search.bm25_store import BM25Store
import asyncio

async def check():
    store = BM25Store()
    await store.initialize()
    count = await store.count()
    print(f'BM25 chunks: {count}')

asyncio.run(check())
"
```

## Embedding dimension mismatch

**Симптом:** `ValueError: Expected dimension 1024, got 384`

**Решение:**
```env
# Убедиться, что .env соответствует модели
EMBEDDING__MODEL=intfloat/multilingual-e5-large
EMBEDDING__DIMENSIONS=1024
```

При смене модели — полная переиндексация:
```bash
python -m src.cli.main index "document.pdf" --full-reindex
```

## Reranker не загружается

**Симптом:** `ModuleNotFoundError: sentence_transformers`

**Решение:**
```bash
pip install --upgrade sentence-transformers

# Или использовать LLM reranker (не требует sentence-transformers)
# В .env:
AGENT__RERANKER_TYPE=llm
```

## Image descriptions не генерируются

**Симптом:** Image chunks пустые или отсутствуют.

**Решение:**
```env
# Проверить настройки Vision
VISION__MODEL=claude-sonnet-4-5-20250929
VISION__MAX_TOKENS=2048
VISION__MIN_IMAGE_SIZE=50
```

Убедитесь, что API-ключ Anthropic имеет доступ к Vision моделям.

## Фильтры не работают

**Симптом:** Фильтрация по language/doc_type/version не даёт результатов.

**Решение:**
```bash
# Переиндексировать с metadata enrichment
python -m src.cli.main index "document.pdf" --full-reindex
```

## ModuleNotFoundError

**Симптом:** `ModuleNotFoundError: No module named 'arq'` (или другой модуль)

**Решение:**
```bash
# Установить недостающие зависимости
pip install arq prometheus_client plotly

# Или полная установка
pip install -e ".[all]"
```

## API не запускается

**Симптом:** Ошибка при `python -m src.api.app`

**Решение:**
1. Проверить `.env` файл — все обязательные параметры заполнены
2. Проверить Qdrant — `curl http://localhost:6333/healthz`
3. Проверить зависимости — `pip install -e ".[all]"`

## GraphRAG не работает

**Симптом:** `graphrag_local` или `graphrag_global` возвращает пустой результат.

**Решение:**
```bash
# GraphRAG требует индексации с графом
python -m src.cli.main index "document.pdf" --graph --communities

# Проверить граф
curl http://localhost:8000/graph/stats
```
