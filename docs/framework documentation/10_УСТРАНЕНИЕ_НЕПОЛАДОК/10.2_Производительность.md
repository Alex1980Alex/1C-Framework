# 10.2 Производительность

## Latency по стратегиям

| Стратегия | Без reranking | С LLM reranking |
|-----------|--------------|-----------------|
| `bm25` | 5-14 мс | ~5 с |
| `vector` | 415-475 мс | ~5.5 с |
| `hybrid` | ~500 мс | ~5.5 с |
| `section_first` | 50-100 мс | ~5 с |
| `graphrag_local` | 1-3 с | ~8 с |
| `graphrag_global` | 5-15 с | — |
| `adaptive` (simple) | 125 мс | — |
| `deep_research` | 10-30 с | — |

## Turbo Pipeline

Автоматическая оптимизация для простых запросов:

```
simple (90%):   BM25 early termination → 125 мс (было 3878 мс, 31x ускорение)
moderate:       Hybrid + Reranking → 3-5 с
complex:        Decomposition + Multi-step → 10-30 с
```

Turbo Pipeline включён по умолчанию и работает автоматически.

## Оптимизация скорости

### 1. Используйте BM25 для быстрых запросов

```bash
python -m src.cli.main search "точный запрос" --strategy bm25
# 5-14 мс
```

### 2. Отключите reranking

```bash
python -m src.cli.main search "запрос" --no-rerank
# Экономит ~5 секунд
```

### 3. Уменьшите top-k

```bash
python -m src.cli.main search "запрос" -k 3
# Меньше чанков → быстрее grading
```

### 4. Используйте семантический кэш

```env
CACHE__SEMANTIC_ENABLED=true
CACHE__SEMANTIC_THRESHOLD=0.95
```

Повторные запросы: < 1 мс.

### 5. GPU для embeddings

```bash
# Установить PyTorch с CUDA
pip install torch --index-url https://download.pytorch.org/whl/cu121
```

GPU ускоряет embedding в 5-10x.

### 6. FlashRank вместо LLM reranker

```env
AGENT__RERANKER_TYPE=flashrank
# ~100 мс вместо ~5 с
```

## Оптимизация качества

### 1. Hybrid search (лучшее качество)

```bash
python -m src.cli.main search "запрос" --strategy hybrid
```

### 2. LLM reranker (осмысленное ранжирование)

```env
AGENT__RERANKER_TYPE=llm
```

### 3. AutoRAG (подбор оптимальных параметров)

```bash
python -m src.cli.main autorag --dataset "data/eval/benchmark.json"
```

### 4. Индексация с графом и communities

```bash
python -m src.cli.main index "document.pdf" --graph --communities
```
