# 12.1 Обзор декомпозиции задач

> Декомпозиция задач — механизм, который гарантирует что Claude Code
> не начнёт писать код до тех пор, пока задача не классифицирована,
> разбита на подзадачи (если нужно) и проверена на наличие скиллов.

---

## Проблема

Без контроля Claude Code склонен:

- Сразу начинать писать код, не разобравшись в задаче
- Пропускать существующие скиллы с проверенными паттернами
- Решать сложную задачу одним монолитным изменением
- Не разбивать работу на отслеживаемые подзадачи

## Решение: Phase Machine + 4 хука

Система декомпозиции реализована через **фазовый автомат** (phase machine),
координируемый 4 хуками. Write/Edit **физически заблокированы** до тех пор,
пока Claude не пройдёт все обязательные фазы.

```
                        ФАЗОВЫЙ АВТОМАТ

idle ──────> classified ──────> decomposed ──────> skill_checked
  │              │                   │                    │
  │  UserPrompt  │   TaskCreate()    │    Skill()         │
  │  Submit      │   (наблюдатель)   │    (наблюдатель)   │
  │              │                   │                    │
  └──────────────┴───────────────────┴────────────────────┘
                                                 │
                                          ТОЛЬКО ЭТА ФАЗА
                                          РАЗРЕШАЕТ Write/Edit
```

| Фаза | Кто устанавливает | Write/Edit |
|------|------------------|------------|
| `idle` | Начало (reset) | BLOCKED |
| `classified` | `skill-eval-enforcer-shell.py` | BLOCKED |
| `decomposed` | `task-protocol-observer.py` при TaskCreate | BLOCKED |
| `skill_checked` | `task-protocol-observer.py` при Skill() | **ALLOWED** |

## Два независимых слоя блокировки

Write/Edit проходят через **два** enforcement-хука последовательно:

```
Write/Edit запрос
    │
    ▼
┌─────────────────────────────┐
│  task-protocol-enforcer.py  │  Слой 1: фаза протокола
│  phase != skill_checked?    │
│  → BLOCK                    │
└─────────────┬───────────────┘
              │ (если фаза OK)
              ▼
┌─────────────────────────────┐
│  code-skill-enforcer.py     │  Слой 2: паттерны контента
│  Level B → Level A → A.1 → C│
│  → BLOCK если нет скилла    │
└─────────────┬───────────────┘
              │ (если всё OK)
              ▼
         Write/Edit
         ВЫПОЛНЯЕТСЯ
```

Если первый хук блокирует — второй не выполняется. Claude видит причину
блокировки и корректирует действие (вызывает Skill(), делает TaskCreate и т.д.).

## 4 хука системы

| Хук | Событие | Роль |
|-----|---------|------|
| [skill-eval-enforcer-shell.py](../../../.claude/hooks/skill-eval-enforcer-shell.py) | UserPromptSubmit | Reset + классификация + инструкция |
| [task-protocol-observer.py](../../../.claude/hooks/task-protocol-observer.py) | PostToolUse:TaskCreate\|Skill | Записывает фазы decomposed/skill_checked |
| [task-protocol-enforcer.py](../../../.claude/hooks/task-protocol-enforcer.py) | PreToolUse:Write\|Edit | Блокирует если phase != skill_checked |
| [code-skill-enforcer.py](../../../.claude/hooks/code-skill-enforcer.py) | PreToolUse + PostToolUse | 6 уровней A-F: контент, директории, bash |

## Ключевой принцип: ИНСТРУКТИРУЕМАЯ декомпозиция

Хуки **не выполняют** декомпозицию автоматически. Они **инструктируют** Claude
что делать и **блокируют** если он не выполнил шаги:

1. `skill-eval-enforcer-shell` **инструктирует**: "CLASSIFY, DECOMPOSE, SKILL CHECK"
2. Claude **сам решает** вызвать TaskCreate (создать подзадачи)
3. `task-protocol-observer` **наблюдает** за TaskCreate — записывает phase=decomposed
4. Claude **сам решает** вызвать Skill() (проверить скиллы)
5. `task-protocol-observer` **наблюдает** за Skill() — записывает phase=skill_checked
6. `task-protocol-enforcer` **разрешает** Write/Edit

```
Инструктирование (stdout)     Наблюдение (PostToolUse)     Блокировка (PreToolUse)
────────────────────────       ─────────────────────────    ────────────────────────
skill-eval-enforcer-shell      task-protocol-observer       task-protocol-enforcer
   │                              │                            │
   │  "CLASSIFY, DECOMPOSE,       │  TaskCreate → decomposed   │  phase != skill_checked?
   │   SKILL CHECK"               │  Skill()   → skill_checked │  → BLOCK
   │                              │                            │
   └──────────────────────────────┴────────────────────────────┘
```
