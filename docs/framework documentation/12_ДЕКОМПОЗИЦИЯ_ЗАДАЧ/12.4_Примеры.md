# 12.4 Примеры декомпозиции

> Полные сценарии: от промпта пользователя до завершения задачи.
> Каждый шаг с указанием какой хук срабатывает и что происходит в SessionState.

---

## Пример 1: Trivial задача

**Промпт:** "Fix typo in README"

```
ШАГИ                                    ХУКИ                          SESSION STATE
─────                                   ────                          ─────────────
1. Пользователь: "Fix typo in README"
                                        skill-router.py               router_fired_at = now
                                        → нет рекомендаций
                                        (README не матчит бандлы)

                                        skill-eval-enforcer-shell.py  phase = classified
                                        → complexity = trivial        complexity = trivial
                                        → stdout: TASK PROTOCOL

2. Claude: нет релевантного скилла
   → активирует learning-loop
                                        task-protocol-observer.py     phase = skill_checked
                                        → PostToolUse:Skill

3. Claude: Edit(README.md, fix typo)
                                        task-protocol-enforcer.py     ← reads phase
                                        → phase == skill_checked      = skill_checked → OK
                                        → ALLOW

                                        code-skill-enforcer.py        (no pattern match)
                                        → .md файл, нет паттернов
                                        → ALLOW

4. Edit выполняется ✓
```

**Итого**: 1 промпт → 1 skill activation → 1 Write/Edit. Минимальный путь.

## Пример 2: Medium задача

**Промпт:** "Добавь валидацию в SearchQuery модель и обнови search endpoint"

```
ШАГИ                                    ХУКИ                          SESSION STATE
─────                                   ────                          ─────────────
1. Пользователь: промпт (10 слов + маркер "и")
                                        skill-router.py               router_fired_at = now
                                        → рекомендует pdf-knowledge

                                        skill-eval-enforcer-shell.py  phase = classified
                                        → complexity = trivial (10 слов, complexity = trivial
                                          нет multi-file маркеров,
                                          "и" — не маркер)
                                        → router fired → skip stdout

2. Claude классифицирует как medium
   (2 файла: модель + endpoint)
   Claude: TaskCreate("Add SearchQuery validation")
                                        task-protocol-observer.py     phase = decomposed
                                        → PostToolUse:TaskCreate      subtask_count = 1

   Claude: TaskCreate("Update search endpoint")
                                        task-protocol-observer.py     subtask_count = 2
                                        → PostToolUse:TaskCreate

3. Claude: активирует pdf-knowledge
                                        task-protocol-observer.py     phase = skill_checked
                                        → PostToolUse:Skill

4. Claude: TaskUpdate(task1, in_progress)
   Claude: Write(schemas/search.py)
                                        task-protocol-enforcer.py     → skill_checked → OK
                                        code-skill-enforcer.py        → нет паттернов → OK

5. Write выполняется ✓
   Claude: TaskUpdate(task1, completed)

6. Claude: TaskUpdate(task2, in_progress)
   Claude: Edit(api/search.py)
                                        task-protocol-enforcer.py     → skill_checked → OK
                                        code-skill-enforcer.py        → нет паттернов → OK

7. Edit выполняется ✓
   Claude: TaskUpdate(task2, completed)

8. Claude: верификация кода
```

**Итого**: 1 промпт → 2 TaskCreate → 1 skill → 2 Write/Edit → verify.

## Пример 3: Complex задача

**Промпт:** "Implement multi-tenant support across all vector store providers.
Each tenant should have isolated collections, separate rate limits..."
(120+ слов, маркер "across all")

```
ШАГИ                                    ХУКИ                          SESSION STATE
─────                                   ────                          ─────────────
1. Пользователь: промпт (120+ слов)
                                        skill-router.py               router_fired_at = now
                                        → рекомендует pdf-knowledge,
                                          architecture-research

                                        skill-eval-enforcer-shell.py  phase = classified
                                        → complexity = complex        complexity = complex
                                        → router fired → skip stdout

2. Claude: полная декомпозиция
   TaskCreate("Add tenant_id to base vector store")
                                        observer → decomposed         phase = decomposed
   TaskCreate("Update Qdrant provider")                               subtask_count = 1
                                        observer → count++            subtask_count = 2
   TaskCreate("Update ChromaDB provider")
                                        observer → count++            subtask_count = 3
   TaskCreate("Add tenant middleware")
                                        observer → count++            subtask_count = 4
   TaskCreate("Update API endpoints")
                                        observer → count++            subtask_count = 5
   TaskCreate("Add integration tests")
                                        observer → count++            subtask_count = 6

3. Claude: активирует pdf-knowledge
                                        observer → skill_checked      phase = skill_checked

4-9. FOR EACH subtask:
     TaskUpdate(in_progress)
     Write/Edit (ALLOWED — phase OK)
     TaskUpdate(completed)

10. Claude: верификация кода
```

**Итого**: 1 промпт → 6 TaskCreate → 1 skill → N Write/Edit → verify.

## Пример 4: Блокировка — попытка Write без Skill

**Промпт:** "Add logging to the search module"

```
ШАГИ                                    ХУКИ                          SESSION STATE
─────                                   ────                          ─────────────
1. Пользователь: промпт
                                        skill-eval-enforcer-shell.py  phase = classified

2. Claude СРАЗУ пробует Write (без skill):
   Write(search/logger.py)
                                        task-protocol-enforcer.py     ← reads phase
                                        → phase == classified         = classified
                                        → BLOCK!                      ≠ skill_checked

   Claude видит:
   "TASK PROTOCOL: Check skills before writing code.
    Skills not checked yet!
    1. Search available skills for this task
    2. Activate via Skill() — or learning-loop if none found
    3. Then retry Write/Edit."

3. Claude: активирует скилл
                                        observer → skill_checked      phase = skill_checked

4. Claude: RETRY Write(search/logger.py)
                                        task-protocol-enforcer.py     → skill_checked → OK
                                        → ALLOW

5. Write выполняется ✓
```

**Итого**: блокировка научила Claude следовать протоколу.

## Пример 5: Двойная блокировка — Level A после protocol

**Промпт:** "Добавь граф агентов" (затрагивает LangGraph паттерны)

```
ШАГИ                                    ХУКИ                          SESSION STATE
─────                                   ────                          ─────────────
1. Пользователь: промпт
                                        skill-router.py               рекомендует
                                        → langgraph-core              langgraph-core

                                        skill-eval-enforcer-shell.py  phase = classified

2. Claude: активирует langgraph-core
                                        observer → skill_checked      phase = skill_checked
                                                                      activated: [langgraph-core]

3. Claude: Write(agents/graph.py)
   содержимое включает StateGraph
                                        task-protocol-enforcer.py     → skill_checked → OK

                                        code-skill-enforcer.py
                                        → Level A: StateGraph → langgraph-core
                                        → is_skill_activated("langgraph-core")? YES
                                        → ALLOW

4. Write выполняется ✓
```

Если бы Claude **не активировал** langgraph-core, Level A заблокировал бы на шаге 3.

## Пример 6: Level A.1 — LEARN цикл

**Промпт:** "Добавь кеширование через Redis"

```
ШАГИ                                    ХУКИ                          SESSION STATE
─────                                   ────                          ─────────────
1. Пользователь: промпт
                                        skill-router.py               (нет бандла для Redis)
                                        → нет рекомендаций

                                        skill-eval-enforcer-shell.py  phase = classified

2. Claude: активирует learning-loop
                                        observer → skill_checked      phase = skill_checked

3. Claude: Write(cache/redis_cache.py)
   содержимое включает Redis паттерны
                                        task-protocol-enforcer.py     → skill_checked → OK

                                        code-skill-enforcer.py
                                        → Level A.1: research_protocol
                                        → Redis detected, нет скилла
                                        → add_activated("learn:redis-caching")
                                        → BLOCK: "Run learning-loop"

   Claude видит блокировку и запускает
   learning-loop: SEARCH → FETCH → EXECUTE → VERIFY → CREATE

4. Claude: RETRY Write(cache/redis_cache.py)
                                        code-skill-enforcer.py
                                        → Level A.1: Redis detected
                                        → is_activated("learn:redis-caching")? YES
                                        → пропуск (dedup)
                                        → ALLOW

5. Write выполняется ✓
```

**Итого**: Level A.1 заставил Claude создать скилл для Redis перед написанием кода.

## Сводная таблица: что блокирует что

| Сценарий | Слой 1 (protocol) | Слой 2 (content) | Результат |
|----------|-------------------|-------------------|-----------|
| skill активирован, нет паттернов | ALLOW | ALLOW | Write OK |
| skill активирован, паттерн совпал | ALLOW | ALLOW (skill activated) | Write OK |
| skill НЕ активирован | BLOCK | — | Сначала активируй |
| skill активирован, паттерн без скилла | ALLOW | BLOCK (Level A) | Активируй нужный скилл |
| skill активирован, research protocol | ALLOW | BLOCK (Level A.1) | Запусти learning-loop |
