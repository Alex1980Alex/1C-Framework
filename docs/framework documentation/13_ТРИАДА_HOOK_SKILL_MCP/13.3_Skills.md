# 13.3 Skills — процедурное знание (КАК)

> Скиллы — Markdown-файлы с инструкциями для Claude Code. Содержат процедуры,
> шаблоны, кеши знаний и антипаттерны. Загружаются через `Skill()` tool.

---

## Формат SKILL.md

Каждый скилл — файл `SKILL.md` в директории `.claude/skills/<name>/`:

```
.claude/skills/<skill-name>/
├── SKILL.md              ← Основной файл (≤ 500 строк)
├── references/           ← Детали, шаблоны, API
│   ├── advanced-usage.md
│   └── templates.md
└── cache/                ← Накопленные знания (для Domain-скиллов)
    ├── _index.json
    ├── _topic_template.md
    └── <topic>.md
```

### YAML frontmatter

```yaml
---
name: skill-name
description: "Краткое описание. Триггеры: 'keyword1', 'keyword2', 'keyword3'.
  НЕ для X — используй skill-Y."
---
```

| Поле | Назначение |
|------|-----------|
| `name` | Уникальный идентификатор (совпадает с названием директории) |
| `description` | ≤ 300 символов: что делает + триггерные фразы + НЕ-redirects |

**Триггеры** — ключевые слова, по которым Skill Router рекомендует скилл.
**НЕ-redirect** — перенаправление на правильный скилл при пересечении доменов.

## 4 типа скиллов

| Тип | Характеристика | Пример |
|-----|---------------|--------|
| **Domain** | 5-фазный research + cache | `1c-doc-research`, `tech-research`, `architecture-research` |
| **Procedural** | Шаблон + чеклист | `create-hook`, `doc-to-skill`, `doc-to-cache` |
| **Program** | Алгоритм (Q1-Q6 → ШАГ 1-5) | `triad-factory` |
| **Classifier** | Маршрутизация по типу задачи | `task-evaluation` |

### Domain-скиллы (5-фазный цикл)

```
Фаза 0: Проверить кеш (_index.json) → hit? → вернуть из кеша
Фаза 1: Поиск в локальных данных (MCP tool: search_documents)
Фаза 2: Дополнительный веб-поиск (WebSearch)
Фаза 3: Верификация (факты, терминология)
Фаза 4: Атрибуция (каждый факт с источником: [docs/web/exp/own])
Фаза 5: Сохранение в кеш
```

### Procedural-скиллы

Содержат готовый шаблон с плейсхолдерами и чеклист. Claude следует шаблону
при создании нового артефакта (хук, скилл, конфиг).

### Program-скиллы

Содержат алгоритм — последовательность шагов с условиями. Пример: Фабрика
триады (Q1-Q6 классификация → формула → генерация → связывание → верификация).

## Skill Router

Skill Router ([`.claude/hooks/skill-router.py`](../../../.claude/hooks/skill-router.py)) —
хук `UserPromptSubmit`, который анализирует каждый промпт и рекомендует скиллы.

```
Промпт пользователя
  │
  ▼
Layer A: Keyword matching ──── точное совпадение фраз
  │
  ▼
Layer B: Fuzzy matching ────── fuzz.partial_ratio (thefuzz)
  │
  ▼
Layer C: TF-IDF scoring ────── семантическая близость (numpy-only)
  │
  ▼
Результат: systemMessage с рекомендациями
```

Конфигурация роутера: [`.claude/skills/skill-router-config.json`](../../../.claude/skills/skill-router-config.json)
— 28 бандлов, сгруппированных по 6 доменам:

| Домен | Кол-во бандлов | Примеры |
|-------|:--------------:|---------|
| framework | 9 | framework-api, framework-cli, indexing-pipeline |
| claude-code | 6 | claude-code-settings, claude-code-cli, claude-code-hooks-bugs |
| langchain | 2 | langchain-core, langgraph-core |
| research | 3 | 1c-doc-research, tech-research, architecture-research |
| tools | 4 | create-hook, doc-to-skill, triad-factory |
| 1c | 1 | 1c-doc-research |

Каждый бандл содержит `keywords`, `skills` (обязательные) и `optional` (по контексту).

Подробнее: [11.3 Skill Router](../11_СИСТЕМА_СКИЛЛОВ/11.3_Skill_Router.md)

## Cache layer

Domain-скиллы хранят исследованные темы в `cache/`:

```
.claude/skills/tech-research/cache/
├── _index.json           ← Реестр: {keyword, file, last_verified, category}
├── _topic_template.md    ← Шаблон для новых тем (N категорий)
├── colbert-reranking.md  ← Исследованная тема
├── qdrant-sparse.md      ← Исследованная тема
└── ...
```

**_index.json** — центральный реестр:
```json
{
  "topics": [
    {
      "keyword": "colbert-reranking",
      "file": "colbert-reranking.md",
      "category": "reranking",
      "last_verified": "2026-02-15",
      "sources": ["arxiv", "sbert.net"]
    }
  ]
}
```

**Категории** зависят от домена:

| Домен | Кол-во категорий | Примеры |
|-------|:----------------:|---------|
| 1c-doc-research | 8 | объекты, механизмы, язык, права, UI, интеграция |
| tech-research | 7 | embeddings, search, reranking, chunking, agents |
| architecture-research | — | cache/ (факты) + adr/ (решения в ADR-формате) |

**TTL:** 30 дней по умолчанию. После истечения — повторная верификация.

**Фаза 0** (проверка кеша) при попадании возвращает тему из файла без
повторного исследования, экономя время и API-запросы.

## Enforcement

Система принуждения обеспечивает обязательное использование скиллов через
6 уровней (A-F):

| Уровень | Фаза | Событие | Действие |
|---------|------|---------|----------|
| A | PRE | PreToolUse:Write\|Edit | BLOCK если скилл не активирован |
| A.1 | PRE | PreToolUse:Write\|Edit | BLOCK + рекомендация `learning-loop` |
| B | PRE | PreToolUse:Write\|Edit | Проверка task-protocol |
| C | PRE | PreToolUse:Write\|Edit | Специфичные паттерны кода |
| D | POST | PostToolUse:WebSearch | Research cache reminder |
| E | POST | PostToolUse:Write\|Edit | Post-verification (must_contain / must_not_contain) |
| F | POST | PostToolUse:Write\|Edit | LEARN advisory (создание нового скилла) |

Подробнее: [11.4 Skill Enforcement](../11_СИСТЕМА_СКИЛЛОВ/11.4_Skill_Enforcement.md)
