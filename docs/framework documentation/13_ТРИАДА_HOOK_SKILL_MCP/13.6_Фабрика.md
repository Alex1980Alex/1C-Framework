# 13.6 Фабрика триады

> Фабрика — порождающий паттерн (Abstract Factory + Builder), который превращает
> решение из чата в работающую автоматизацию. Классификация Q1-Q6 определяет
> формулу — какие компоненты нужно создать.

---

## Мотивация

Решения, принятые в чате, теряются между сессиями. Фабрика обеспечивает
преобразование решений в артефакты:

```
Без фабрики:  Решение → ответ в чате → потеряно
С фабрикой:   Решение → Q1-Q6 → формула → артефакты → автоматизация
```

## ШАГ 1: Классификация (Q1-Q6)

Ответь на 6 вопросов (да/нет):

| # | Вопрос | Если ДА → компонент |
|---|--------|---------------------|
| Q1 | Это должно срабатывать **автоматически** на событие? | → **Hook** нужен |
| Q2 | Есть **процедура/знание** которое нужно описать? | → **Skill** нужен |
| Q3 | Нужен **внешний инструмент** (API, DB, поиск)? | → **MCP Tool** нужен |
| Q4 | Нужно **накапливать знания** по теме? | → **Cache** нужен |
| Q5 | Нужно **принудительно** выполнять (не пропускать)? | → **Enforcer** нужен |
| Q6 | Нужно **фиксировать решения** (не только факты)? | → **ADR** нужен |

**Примеры:**

```
"Исследование новой технологии"
  Q1=Да → Hook   Q2=Да → Skill   Q3=Да → MCP
  Q4=Да → Cache  Q5=Да → Enforcer  Q6=Нет
  ФОРМУЛА: Hook + Skill + MCP + Cache + Enforcer

"Шаблон создания хуков"
  Q1=Нет  Q2=Да → Skill   Q3=Нет  Q4=Нет  Q5=Нет  Q6=Нет
  ФОРМУЛА: Skill-only

"Оптимизация параметров поиска"
  Q1=Да → Hook   Q2=Нет  Q3=Нет  Q4=Нет  Q5=Нет  Q6=Нет
  ФОРМУЛА: Hook-only

"Архитектурное решение по фреймворку"
  Q1=Да → Hook   Q2=Да → Skill   Q3=Да → MCP
  Q4=Да → Cache  Q5=Да → Enforcer  Q6=Да → ADR
  ФОРМУЛА: Hook + Skill + MCP + Cache + Enforcer + ADR
```

## ШАГ 2: Формула

По ответам на Q1-Q6 определяется комбинация компонентов:

| Формула | Когда | Создаваемые файлы |
|---------|-------|--------------------|
| Hook + Skill + MCP + Cache + ADR + Enforcer | Домен знаний + решения | skill/, cache/, adr/, detector, reminder, MCP tool |
| Hook + Skill + MCP + Cache + Enforcer | Домен знаний (только факты) | skill/, cache/, detector, reminder |
| Skill + Cache + ADR | Решения по запросу (без автоматики) | SKILL.md, cache/, adr/ |
| Hook + Skill + MCP | Автоматизация + инструмент | hook.py, SKILL.md, MCP tool |
| Hook + Skill | Автоматизация workflow | hook.py, SKILL.md |
| Skill + MCP | Инструмент по запросу | SKILL.md, MCP tool |
| Skill + Cache | Доменное знание без решений | SKILL.md, cache/ |
| Skill-only | Процедура / шаблон | SKILL.md |
| Hook-only | Простой триггер / валидация | hook.py |
| MEMORY-only | Баг / workaround / факт | MEMORY.md запись |

**Правило 3-tier Knowledge:**
- Q4=Да + Q6=Нет → `cache/` only (факты)
- Q4=Да + Q6=Да → `cache/` + `adr/` (факты отделены от решений)
- Q6=Да без Q4 → не бывает (решение основано на исследовании → нужен cache)

## ШАГ 3: Генерация

Для каждого компонента в формуле — создать файлы по шаблону.

### Hook (если Q1=Да)

| Подтип | Event | Назначение |
|--------|-------|-----------|
| Детектор | UserPromptSubmit | Keyword scoring → systemMessage |
| Напоминание | PostToolUse | Проверка результата → add_task() |
| Валидатор | PreToolUse | Проверка параметров → block() |
| Блокировщик | Stop | Проверка pending tasks → exit(2) |

Файл: `.claude/hooks/<name>.py` — наследует `BaseHook`.
Подробнее: skill `create-hook`.

### Skill (если Q2=Да)

| Подтип | Содержимое |
|--------|-----------|
| Доменный | 5 фаз, source hierarchy, шаблон кеша |
| Процедурный | Шаблон, чеклист, антипаттерны |
| Мета | Архитектура, диаграммы, связи |

Файл: `.claude/skills/<name>/SKILL.md` — с YAML frontmatter.
Подробнее: skill `doc-to-skill`.

### Cache (если Q4=Да)

```
.claude/skills/<domain>-research/cache/
├── _topic_template.md    ← Шаблон темы (N категорий)
├── _index.json           ← Реестр: {keyword, file, last_verified}
└── <topic>.md            ← Исследованная тема
```

### ADR (если Q6=Да)

```
.claude/skills/<domain>-research/adr/
├── _index.json           ← Реестр: {id, title, status, date, research}
└── NNN-<название>.md     ← ADR-файл
```

Шаблон ADR:

```markdown
# ADR-NNN: [Название решения]

**Дата:** YYYY-MM-DD
**Статус:** proposed | accepted | superseded | deprecated

## Контекст
[Почему возник вопрос]

## Решение
[Что решили + обоснование с атрибуцией]

## Последствия
### Положительные / Отрицательные

## Альтернативы
[Что рассматривали и почему отклонили]
```

### MCP Tool (если Q3=Да)

Файл: `src/mcp_server/server.py` — `@server.tool()` декоратор.
Обновить `.vscode/mcp.json`.

### Enforcer (если Q5=Да)

Связка двух хуков:
1. PostToolUse хук → `add_task()` → `hook-todos.json`
2. Stop хук `task-enforcer.py` → проверка pending → BLOCK/ALLOW

## ШАГ 4: Связывание

Подключить артефакты к существующей системе:

| Артефакт | Подключение |
|----------|-------------|
| Hook | Добавить в `.claude/settings.json` → `hooks` → EventName |
| Skill | Авто-подхват Claude Code по triggers в frontmatter |
| Skill | Добавить bundle в `skill-router-config.json` |
| MCP Tool | `@server.tool()` в `server.py` |
| Cache | Инициализировать `_index.json`, связать с Фазой 0 в SKILL.md |
| ADR | Инициализировать `adr/_index.json`, связать с cache через `research` |
| Enforcer | add_task() в PostToolUse хуке → task-enforcer читает на Stop |

**Обновить реестры:**
- Таблица Hooks/Skills в skill `hooks-skills-mcp-triad`
- `CLAUDE.md` → Knowledge Cache / Active Skills (если новый домен)
- `MEMORY.md` → краткая запись

## ШАГ 5: Верификация

| Компонент | Тест |
|-----------|------|
| Hook | `echo '{"prompt":"тест"}' \| python hook.py` → проверить stdout JSON |
| Skill | Новая сессия → вопрос по triggers → скилл подхватился? |
| MCP Tool | `curl localhost:8000/...` или MCP client call |
| Cache | `_index.json` обновился после исследования? |
| ADR | `adr/_index.json` содержит запись? ADR ссылается на cache? |
| Enforcer | Создать pending task → Stop → BLOCK? |
| Связка | Полный pipeline: вопрос → detector → skill → reminder → enforcer |

## Чеклист нового домена

- [ ] Skill: `skills/<domain>-research/SKILL.md` создан (5-6 фаз)
- [ ] Cache: `cache/_topic_template.md` создан (категории)
- [ ] Cache: `cache/_index.json` создан (пустой)
- [ ] Q6: если Да → `adr/_index.json` создан, Фаза 6 в SKILL.md
- [ ] Hook: `DOMAIN_TERMS` добавлен в `research-task-detector.py`
- [ ] Hook: `DOMAIN_SIGNALS` добавлен в `knowledge-cache-reminder.py`
- [ ] Router: bundle добавлен в `skill-router-config.json`
- [ ] Реестр: обновлена таблица в skill `hooks-skills-mcp-triad`
- [ ] `CLAUDE.md`: обновлён раздел Knowledge Cache
- [ ] `MEMORY.md`: добавлена запись о новом домене
- [ ] Тест: echo + hook → stdout корректен

## Антипаттерны

| Плохо | Почему | Как правильно |
|-------|--------|---------------|
| Решение без артефакта | Потеряется в следующей сессии | Минимум MEMORY-only |
| Ad-hoc компонент без Фабрики | Не связан с реестром, не верифицирован | Через Q1-Q6 → ШАГ 1-5 |
| Выводы в cache-файле | Нельзя переиспользовать факты | Факты в cache/, решения в adr/ |
| Тяжёлые вычисления в хуке | Timeout 3-5s | Только keyword matching, file read |
| Относительные пути в settings.json | bash съедает `\` | Абсолютные пути |
