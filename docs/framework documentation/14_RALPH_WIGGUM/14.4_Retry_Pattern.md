# 14.4 Retry Pattern

> Self-correcting retry: вместо слепого повтора LLM-вызова, система передаёт
> причину ошибки в следующую попытку через `CORRECTION:` message.

---

## Паттерн

Стандартный retry повторяет вызов без изменений — и получает тот же результат.
Ralph Wiggum retry **добавляет feedback** с описанием проблемы:

```
Обычный retry:              Ralph Wiggum retry:

LLM("вопрос")              LLM("вопрос")
  → невалидный ответ          → невалидный ответ
LLM("вопрос")              LLM("вопрос" + "CORRECTION: ожидал yes/no, получил 'maybe'")
  → тот же ответ               → валидный ответ
```

## Шаблон кода

```python
# Ralph Wiggum: self-correcting retry
max_rw_retries = 2
rw_feedback = ""

for rw_attempt in range(1, max_rw_retries + 1):
    try:
        messages = list(base_messages)
        if rw_feedback:
            messages.append(HumanMessage(content=f"CORRECTION: {rw_feedback}"))

        response = await llm.ainvoke(messages)
        result = parse_response(response)

        # Валидация результата
        if not is_valid(result):
            rw_feedback = f"Validation failed: {reason}. Please fix."
            continue  # Повтор С обратной связью

        return result  # Успех

    except Exception as e:
        rw_feedback = f"Previous call failed: {e}."

# Все попытки исчерпаны — graceful degradation
return fallback_value
```

## Ключевые принципы

| Принцип | Описание |
|---------|---------|
| **Max 2 попытки** | Контроль стоимости, предотвращение бесконечных циклов |
| **Feedback-driven** | Передача конкретной причины ошибки, а не слепой retry |
| **Валидаторы** | Проверка длины, языка, формата, JSON-структуры |
| **Graceful degradation** | Всегда возврат fallback при полном провале |

## Пример: Grader

```python
# grader.py — Ralph Wiggum self-correcting loop
rw_feedback = ""
for rw_attempt in range(1, 3):
    messages = [SystemMessage(content=GRADING_PROMPT), HumanMessage(...)]
    if rw_feedback:
        messages.append(HumanMessage(content=f"CORRECTION: {rw_feedback}"))

    response = await llm.ainvoke(messages)
    text = response.content.strip().lower()

    if text.startswith(("yes", "relevant", "да")):
        return True
    elif text.startswith(("no", "not", "нет")):
        return False
    else:
        rw_feedback = (
            f"Expected 'yes' or 'no', got: '{text[:50]}'. "
            "Answer with exactly 'yes' or 'no'."
        )

# Fallback: consider not relevant
return False
```

## Пример: Entity Extractor

```python
# entity_extractor.py — JSON validation retry
rw_feedback = ""
for rw_attempt in range(1, 3):
    messages = [SystemMessage(content=EXTRACTION_PROMPT), HumanMessage(content=text)]
    if rw_feedback:
        messages.append(HumanMessage(content=f"CORRECTION: {rw_feedback}"))

    response = await llm.ainvoke(messages)

    try:
        entities = json.loads(response.content)
        if isinstance(entities, list):
            return entities
        rw_feedback = "Response must be a JSON array, got dict."
    except json.JSONDecodeError as e:
        rw_feedback = f"Invalid JSON: {e}. Return a valid JSON array."

# Fallback: empty list
return []
```

## Graceful Degradation

Каждая интеграция определяет свой fallback:

| Компонент | Fallback при исчерпании попыток |
|-----------|---------------------------------|
| Grader | `False` (документ не релевантен) |
| Hallucination checker | `True` (считаем ответ обоснованным) |
| Rewriter | Оригинальный запрос без изменений |
| Query expansion | Оригинальный запрос (1 вариант) |
| HyDE | Оригинальный запрос (без гипотезы) |
| Entity extractor | `[]` (пустой список) |
| Summarizer | Первые N символов текста |
| Context generator | Пустая строка |

## Связь с async

Все retry-циклы используют `async`/`await` и `llm.ainvoke()`:

```python
# Async retry вписывается в async pipeline
async def grade_document(llm, question, document):
    rw_feedback = ""
    for rw_attempt in range(1, 3):
        messages = [...]
        if rw_feedback:
            messages.append(HumanMessage(content=f"CORRECTION: {rw_feedback}"))
        response = await llm.ainvoke(messages)  # async LLM call
        ...
```

Это позволяет запускать несколько retry-циклов параллельно (например, grading
нескольких документов одновременно через `asyncio.gather()`).
