# 16.2 COM-подключение (V83.COMConnector)

Руководство по программному взаимодействию с серверной базой 1С:Предприятие 8.3 через Python и `pywin32`.

## 1. Установка

```bash
pip install pywin32
```

> **Важно:** Разрядность Python должна совпадать с разрядностью 1С. Если 1С 64-битная — Python тоже 64-бит.

Если COM-компонент не находится, зарегистрируйте вручную (от администратора):
```bash
regsvr32 "C:\Program Files\1cv8\8.3.27.1859\bin\comcntr.dll"
```

## 2. Базовое подключение

```python
import win32com.client

# Создание коннектора
connector = win32com.client.Dispatch("V83.COMConnector")

# Подключение к серверной базе
conn = connector.Connect('Srvr="localhost";Ref="TestDB";Usr="a.terletskiy@sodrugestvo.ru";Pwd="1980"')

print(f"Подключено: {conn.Metadata.Name} v{conn.Metadata.Version}")
```

## 3. Параметры строки подключения

| Параметр | Описание | Пример |
| :--- | :--- | :--- |
| **Srvr** | Адрес сервера 1С (кластера) | `Srvr="localhost"` |
| **Ref** | Имя информационной базы | `Ref="TestDB"` |
| **Usr** | Имя пользователя 1С | `Usr="Admin"` |
| **Pwd** | Пароль пользователя | `Pwd="123"` |
| **File** | Путь к файловой базе (вместо Srvr+Ref) | `File="C:\\Bases\\MyBase"` |

## 4. Чтение метаданных конфигурации

### Общая информация
```python
meta = conn.Metadata
print(f"Конфигурация: {meta.Name}")
print(f"Синоним: {meta.Synonym}")
print(f"Версия: {meta.Version}")
```

### Обход коллекций метаданных

```python
# Список всех справочников
catalogs = meta.Catalogs
for i in range(catalogs.Count()):
    cat = catalogs.Get(i)
    print(f"  {cat.Name} | {cat.Synonym}")
```

**Основные коллекции:**

| Коллекция | Описание |
|-----------|----------|
| `Catalogs` | Справочники |
| `Documents` | Документы |
| `InformationRegisters` | Регистры сведений |
| `AccumulationRegisters` | Регистры накопления |
| `AccountingRegisters` | Регистры бухгалтерии |
| `Enums` | Перечисления |
| `Reports` | Отчёты |
| `DataProcessors` | Обработки |
| `Constants` | Константы |
| `ChartsOfAccounts` | Планы счетов |
| `ExchangePlans` | Планы обмена |

### Реквизиты и табличные части

```python
# Метаданные конкретного справочника
cat_meta = meta.Catalogs.Find("Номенклатура")

# Реквизиты
for i in range(cat_meta.Attributes.Count()):
    attr = cat_meta.Attributes.Get(i)
    print(f"  Реквизит: {attr.Name} ({attr.Synonym})")

# Табличные части
for i in range(cat_meta.TabularSections.Count()):
    ts = cat_meta.TabularSections.Get(i)
    print(f"  Табличная часть: {ts.Name}")
```

## 5. Выполнение запросов

```python
query = conn.NewObject("Query")
query.Text = """
    SELECT
        Ref.Code AS Code,
        Ref.Description AS Name
    FROM
        Catalog.Номенклатура AS Ref
    WHERE
        Ref.DeletionMark = FALSE
"""

result = query.Execute().Unload()

for i in range(result.Count()):
    row = result.Get(i)
    print(f"  {row.Code}: {row.Name}")
```

### Параметризованные запросы

```python
query = conn.NewObject("Query")
query.Text = """
    SELECT Description FROM Catalog.Номенклатура
    WHERE Code = &TargetCode
"""
query.SetParameter("TargetCode", "00001")
result = query.Execute().Unload()
```

## 6. CRUD операции

### Создание элемента справочника

```python
new_item = conn.Catalogs.Номенклатура.CreateItem()
new_item.Code = "PY-001"
new_item.Description = "Товар из Python"
new_item.Write()
print(f"Создан: {new_item.Ref}")
```

### Изменение

```python
ref = conn.Catalogs.Номенклатура.FindByCode("00001")
if not ref.IsEmpty():
    obj = ref.GetObject()
    obj.Description = "Новое название"
    obj.Write()
```

### Пометка удаления

```python
ref = conn.Catalogs.Номенклатура.FindByCode("PY-001")
if not ref.IsEmpty():
    obj = ref.GetObject()
    obj.DeletionMark = True
    obj.Write()
```

### Проведение документа

```python
doc_ref = conn.Documents.ПриемкаТоваров.FindByNumber("00005")
if not doc_ref.IsEmpty():
    doc_obj = doc_ref.GetObject()
    doc_obj.Write(conn.DocumentWriteMode.Posting)
```

## 8. Обработка ошибок

```python
import win32com.client
import pywintypes

try:
    connector = win32com.client.Dispatch("V83.COMConnector")
    conn = connector.Connect(conn_string)
except pywintypes.com_error as e:
    hr, msg, exc, _ = e.args
    if exc:
        print(f"1C Error: {exc[2]}")
    else:
        print(f"COM Error: {msg} (HRESULT: {hr})")
```

**Типичные ошибки:**

| HRESULT | Описание | Решение |
|---------|----------|---------|
| `-2147467259` | Неверное имя пользователя или пароль | Проверьте Usr/Pwd |
| `-2147221005` | COM-объект не зарегистрирован | `regsvr32 comcntr.dll` |
| `-2147024891` | Отказано в доступе | Запустите от администратора |

## 9. Закрытие соединения

```python
import gc

# Удаляем ссылки на COM-объекты
del conn
del connector
gc.collect()  # Принудительная сборка мусора для освобождения COM
```

> Каждое COM-соединение занимает лицензию 1С. Всегда закрывайте соединение после использования.
