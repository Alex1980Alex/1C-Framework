# 16.4 Настройка сервера 1С

Пошаговое руководство по развертыванию сервера 1С:Предприятие 8.3 на Windows.

## 1. Системные требования

| Компонент | Требование |
| :--- | :--- |
| ОС | Windows 10/11, Windows Server 2016/2019/2022 |
| Платформа 1С | 8.3.27+ (64-бит) |
| СУБД | MS SQL Server 2019+ или PostgreSQL 14+ |
| Python | 3.11+ (64-бит, для COM-подключения) |

## 2. Установка компонентов 1С

Запустите установщик и отметьте:

1. **Сервер 1С:Предприятие** — основной сервис (ragent, rmngr, rphost)
2. **Администрирование сервера** — MMC-оснастка (radmin.dll)
3. **Толстый клиент** — необходим для COM-подключений

Путь по умолчанию: C:\Program Files\1cv8\8.3.27.1859\

## 3. Настройка службы агента

### Учетная запись

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| LocalSystem | Не требует пароля, всегда работает | Полные права на машине |
| USR1CV8 | Изоляция прав, рекомендация 1С | Нужно следить за паролем |

Переключение на LocalSystem:
```bash
sc.exe config "1C:Enterprise 8.3 Server Agent (x86-64)" obj= "LocalSystem" password= ""
```

### Порты

| Порт | Назначение |
|------|-----------|
| 1540 | Агент сервера (ragent) |
| 1541 | Менеджер кластера (rmngr) |
| 1545 | RAS — сервер администрирования |
| 1560-1591 | Рабочие процессы (rphost) |

### Изменение параметров службы

```bash
sc.exe config "1C:Enterprise 8.3 Server Agent (x86-64)" binPath= "\"C:\Program Files\1cv8\8.3.27.1859\bin\ragent.exe\" -srvc -agent -regport 1541 -port 1540 -range 1560:1591 -d \"C:\Program Files\1cv8\srvinfo\""
```

## 4. Настройка MS SQL Server

### Включение Mixed Authentication
1. SQL Server Management Studio -> ПКМ по серверу -> Properties -> Security
2. Выбрать SQL Server and Windows Authentication mode
3. Перезапустить службу SQL Server

### Создание логина для 1С

```sql
CREATE LOGIN [usr1cv8] WITH PASSWORD = '1980', CHECK_POLICY = OFF;
ALTER SERVER ROLE sysadmin ADD MEMBER [usr1cv8];
```

## 5. Создание информационной базы

### Вариант А: Через MMC-консоль

1. Откройте C:\Program Files\1cv8\common\1CV8 Servers (x86-64).msc
2. Добавьте центральный сервер: localhost, порт 1540
3. Кластеры -> Локальный кластер -> Информационные базы -> Создать
4. Укажите: Имя, Тип СУБД (MSSQLServer), Сервер БД, База данных, Пользователь

### Вариант Б: Через RAC

```bash
ras.exe cluster --port=1545 localhost:1540
rac cluster list localhost:1545
rac infobase create --cluster=<UUID> --create-database --name="TestDB" --dbms=MSSQLServer --db-server=localhost --db-name=testdb1c --db-user=usr1cv8 --db-pwd="1980" --locale=ru localhost:1545
```

### Добавление в стартер 1С

Файл %APPDATA%\1C\1CEStart\ibases.v8i:
```ini
[TestDB]
Connect=Srvr="localhost";Ref="TestDB";
ID=69122529-8378-41fa-af35-0e7d011a436f
OrderInList=0
Folder=/
OrderInTree=0
External=0
ClientConnectionSpeed=Normal
App=Auto
WA=1
Version=8.3
```

## 6. Проверка подключения

### Из Python
```python
import win32com.client
connector = win32com.client.Dispatch("V83.COMConnector")
conn = connector.Connect('Srvr="localhost";Ref="TestDB";Usr="user";Pwd="pass"')
print(f"OK: {conn.Metadata.Name} v{conn.Metadata.Version}")
```

### Из RAC
```bash
rac infobase summary list --cluster=<UUID> localhost:1545
```

## 7. Типичные проблемы

| Проблема | Причина | Решение |
| :--- | :--- | :--- |
| MMC не может создать оснастку | Не зарегистрирована radmin.dll | regsvr32 radmin.dll |
| Ошибка 1069 при старте службы | Неверный пароль учетной записи | Сбросить пароль или LocalSystem |
| Несовпадение версий 32/64 бит | Служба запускает старую версию | Проверить binPath через sc.exe qc |
| Ошибка входа SQL | SQL Auth отключен | Включить Mixed Mode |
| Соединение не установлено (RAC) | RAS не запущен | Запустить ras.exe |
| COM: объект не зарегистрирован | comcntr.dll не зарегистрирован | regsvr32 comcntr.dll |
