## Анализ рисков

### Безопасные действия (0 риск)

| Действие | Почему безопасно |
|----------|------------------|
| YAML frontmatter к скиллам | Добавление, не изменение |
| Eval промпты | Только измерение |
| type + last_verified в YAML | Метаданные, не влияют на логику |
| autoresearch.md, JSONL логи | Новые файлы |
| skill-quality-monitor (только логи) | Никаких блокировок, graceful degradation |

### Рискованные действия (нужна защита)

| Действие | Риск | Защита |
|----------|------|--------|
| Pushy descriptions | Скилл начнёт триггериться когда не надо | Eval ДО и ПОСЛЕ, один скилл за раз, revert при F1↓ |
| Новые хуки-датчики | +200-500ms на промпт | Только логирование, timeout 2s |
| Ночной AutoResearch | Executor сломал скилл | Отдельная git ветка, ручной review |
| Ultrathink | +$0.05-0.10 на вызов | Только 2-3 скилла, замер cost/quality |
