# 19.1 Обзор системы индексации

## Зачем нужна индексация

Индексация позволяет Claude Code и MCP-серверам **семантически искать** по коду и документации проекта. Без индексации поиск возможен только по точным совпадениям (grep/ripgrep). С индексацией -- по смыслу: "найди процедуру проведения документа" вернёт `ОбработкаПроведения`, даже если эти слова не совпадают буквально.

## Два уровня индексации

```
Уровень 1: 1c-docs-rag                     Уровень 2: bsl-semantic-search
────────────────────────                    ──────────────────────────────
Что:   BSL + JS + TS + Python + Markdown    Что:   только BSL файлы
Как:   sentence-transformers (MiniLM)       Как:   Ollama (nomic-embed-text, 768d)
Где:   SQLite (hybrid_search.db)            Где:   JSON (bsl_index_full.json)
MCP:   mcp__1c-docs-rag__*                  MCP:   mcp__bsl-semantic-search__*
Зав-ти: Python + sentence-transformers      Зав-ти: Python + Ollama
```

| Характеристика | 1c-docs-rag | bsl-semantic-search |
|---|---|---|
| Языки | BSL, JS, TS, Python, Markdown | Только BSL |
| Модель эмбеддингов | paraphrase-multilingual-MiniLM-L12-v2 | nomic-embed-text:latest (Ollama) |
| Размерность | 384 | 768 |
| Хранилище | SQLite FTS5 + векторы | JSON файл |
| Парсинг BSL | текстовый + AST (опционально) | BSLParser (функции, переменные, типы модулей) |
| Инкрементальность | да (по hash файла) | нет (полная каждый раз) |
| Скорость | ~10 файлов/сек | ~0.4 файла/сек (Ollama) |
| Зависимости | Python | Python + Ollama |

## Третий уровень: reindex_bsl.bat (полная 3-фазная)

Для глубокого анализа BSL кода существует расширенная индексация из 3 фаз:

```
Фаза 1: FTS5          SQLite полнотекстовый поиск (smart_index_bsl.py --ast)
Фаза 2: Qdrant         Векторный поиск E5-large 1024d (reindex_bsl_qwen3.py)
Фаза 3: Call Graph     Граф вызовов BSL (build_call_graph.py)
```

Требует: Qdrant (Docker), E5-large модель, дополнительные скрипты.

## Какой инструмент выбрать

```
Вопрос: что индексировать?
  │
  ├── Весь проект (BSL + документация + JS/Python)
  │     └── index-folder.bat "проект"
  │
  ├── Только BSL для семантического поиска
  │     └── index-folder.bat "проект" --bsl-only
  │
  ├── Только документацию (MD файлы)
  │     └── index-folder.bat "проект" --docs-only
  │
  ├── Глубокий BSL анализ (FTS5 + Qdrant + Call Graph)
  │     └── reindex_bsl.bat "проект"
  │
  └── Из Claude Code (интерактивно)
        └── /index-folder или /index-project
```

## Расположение файлов

| Файл | Путь | Назначение |
|---|---|---|
| `index-folder.bat` | `scripts/index-folder.bat` | Основная команда (2 фазы) |
| `reindex_bsl.bat` | `reindex_bsl.bat` | Полная BSL индексация (3 фазы) |
| `smart_index_bsl.py` | `scripts/docs-mcp/smart_index_bsl.py` | Python: 1c-docs-rag индексатор |
| `bsl_indexer_async.py` | `D:\1C-Enterprise_Framework\bsl-semantic-search\scripts\indexing\bsl_indexer_async.py` | Python: BSL эмбеддинги через Ollama |
| `hybrid_search.db` | `cache/docs-mcp/hybrid_search.db` | Результат: SQLite БД 1c-docs-rag |
| `bsl_index_full.json` | `D:\1C-Enterprise_Framework\bsl-semantic-search\data\index\bsl_index_full.json` | Результат: BSL эмбеддинги JSON |

## Slash-команды Claude Code

| Команда | Что делает |
|---|---|
| `/index-folder` | Индексация проекта без Serena (docs + BSL) |
| `/index-project` | Индексация проекта с Serena |
| `/index-all` | Полная индексация всех типов файлов |
