# 19.2 index-folder.bat -- основная команда индексации

## Синтаксис

```cmd
scripts\index-folder.bat <путь_или_проект> [опции]
```

## Аргументы

| Аргумент | Описание | Пример |
|---|---|---|
| Имя проекта | Ищет в `src/projects/configuration/` | `"260304_GKSTCPLK-2182"` |
| Полный путь | Индексирует указанную папку | `"D:\Projects\src"` |
| `--list` | Показать список доступных проектов | |
| `--help` | Справка | |

## Опции

| Опция | Описание |
|---|---|
| `--docs-only` | Только 1c-docs-rag (этап 1). Не требует Ollama |
| `--bsl-only` | Только bsl-semantic-search (этап 2). Требует Ollama |
| `--full` | Полная индексация всех файлов (не только изменённых) |
| `--force` | Принудительная переиндексация (игнорирует hash) |
| `--background` | Запуск в фоновом режиме (лог в `logs/`) |
| `--languages bsl,js,py` | Указать конкретные языки |

Опции можно комбинировать: `--full --force`

## Примеры использования

### Индексация проекта 1С по имени

```cmd
cd D:\1С-Framework
scripts\index-folder.bat "260304_GKSTCPLK-2182"
```

Скрипт автоматически:
1. Найдёт папку `src/projects/configuration/260304_GKSTCPLK-2182/src/`
2. Проиндексирует через 1c-docs-rag (BSL + Markdown)
3. Запустит Ollama (если не запущен)
4. Проиндексирует BSL через bsl-semantic-search

### Только документация (быстро, без Ollama)

```cmd
scripts\index-folder.bat "260304_GKSTCPLK-2182" --docs-only
```

Занимает ~30-60 сек для проекта из 2000 BSL файлов.

### Полная принудительная переиндексация

```cmd
scripts\index-folder.bat "260304_GKSTCPLK-2182" --full --force
```

Игнорирует hash-кеш, переиндексирует все файлы заново. Полезно после обновления модели эмбеддингов или структурных изменений в парсере.

### Индексация произвольной папки

```cmd
scripts\index-folder.bat "D:\Projects\MyProject\src" --languages bsl,py
```

### Фоновая индексация

```cmd
scripts\index-folder.bat "260304_GKSTCPLK-2182" --background
```

Запускается в фоне, лог записывается в `logs/index-YYYYMMDD_HHMM.log`.

### Список проектов

```cmd
scripts\index-folder.bat --list
```

Выводит все проекты в `src/projects/configuration/`.

## Как работает

### Этап 1: 1c-docs-rag (smart_index_bsl.py)

```
Вход: папка с файлами (BSL, JS, TS, Python, Markdown)
  |
  v
Сканирование файлов по расширениям
  |
  v
Для каждого файла:
  1. Чтение содержимого
  2. Чанкинг (smart: по процедурам для BSL, по секциям для MD)
  3. Вычисление hash (для инкрементальности)
  4. Создание эмбеддинга (MiniLM, 384d)
  5. Запись в SQLite FTS5 (полнотекст + вектор)
  |
  v
Выход: cache/docs-mcp/hybrid_search.db
```

**Модель:** `paraphrase-multilingual-MiniLM-L12-v2` -- загружается автоматически через sentence-transformers. Не требует Ollama.

**Инкрементальность:** при повторном запуске индексируются только изменённые файлы (по hash). Флаг `--force` отключает это поведение.

**MCP сервер:** `1c-docs-rag` автоматически перезапускается и подхватывает обновлённую БД.

### Этап 2: bsl-semantic-search (bsl_indexer_async.py)

```
Вход: папка с BSL файлами
  |
  v
BSLParser: парсинг каждого .bsl файла
  - Тип модуля (ОбъектМодуль, МенеджерМодуль, ФормаМодуль)
  - Список функций/процедур
  - Список переменных
  - Извлечение searchable_text
  |
  v
Ollama API: создание эмбеддинга (nomic-embed-text, 768d)
  - Async batch processing
  - Retry logic (3 попытки)
  - Circuit breaker
  - Graceful degradation (индексация без эмбеддинга)
  |
  v
Выход: bsl-semantic-search/data/index/bsl_index_full.json
```

**Ollama:** скрипт автоматически находит Ollama (`PATH`, `%LOCALAPPDATA%\Programs\Ollama`, `Program Files`) и запускает если не работает.

**Скорость:** ~0.4 файла/сек (ограничена Ollama API). Проект из 2000 BSL файлов -- ~80 минут.

**MCP сервер:** `bsl-semantic-search` загружает индекс при старте.

## Типичные ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| `[ERROR] Папка не найдена` | Неправильное имя проекта | `--list` для списка |
| `[ERROR] Ollama не установлен` | Ollama не найден | Установить: https://ollama.com/download |
| `[ERROR] Ollama не запустился` | Порт 11434 занят или таймаут | Проверить `netstat -an \| findstr 11434` |
| `[ERROR] Скрипт не найден: smart_index_bsl.py` | Нет `scripts/docs-mcp/` | Убедиться что фреймворк полный |
| `UnicodeEncodeError` | cp1251 консоль | Запускать через `chcp 65001` (bat уже делает это) |
