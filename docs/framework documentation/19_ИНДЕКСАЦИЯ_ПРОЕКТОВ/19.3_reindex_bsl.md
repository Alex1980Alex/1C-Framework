# 19.3 reindex_bsl.bat -- полная 3-фазная BSL индексация

## Когда использовать

`reindex_bsl.bat` -- расширенная версия для **глубокого анализа BSL кода**. В отличие от `index-folder.bat`, добавляет Qdrant векторный поиск и граф вызовов.

```
index-folder.bat          reindex_bsl.bat
  FTS5 + MiniLM             FTS5 + AST parsing
  Ollama nomic-embed         Qdrant E5-large (1024d)
  ---                        Call Graph (SQLite)
  Быстрый, лёгкий            Мощный, тяжёлый
```

## Синтаксис

```cmd
reindex_bsl.bat [имя_проекта] [--full] [--force] [--list] [--help]
```

Без аргументов -- ищет первый проект в `src/projects/configuration/` автоматически.

## 3 фазы индексации

### Фаза 1: FTS5 (SQLite полнотекстовый поиск)

```cmd
python scripts/docs-mcp/smart_index_bsl.py --path "PROJECT" --ast
```

- Парсинг BSL через AST (процедуры, функции, параметры)
- SQLite FTS5 для полнотекстового поиска
- Инкрементальный (по hash)
- Результат: `cache/docs-mcp/hybrid_search.db`

### Фаза 2: Qdrant (векторный поиск E5-large)

```cmd
python scripts/reindex_bsl_qwen3.py --project "PROJECT" --embedder e5 --batch-size 50
```

- Модель E5-large (1024 dimensions)
- Загрузка в Qdrant (требуется Docker)
- Коллекция: `bsl_code_v3`
- Batch processing (50 файлов за раз)

**Требования:**
- Docker Desktop запущен
- Qdrant контейнер: `docker run -d -p 6333:6333 qdrant/qdrant`
- E5-large модель (~1.3 GB)

### Фаза 3: Call Graph (граф вызовов BSL)

```cmd
python scripts/build_call_graph.py --project "PROJECT"
```

- Строит граф вызовов между процедурами/функциями
- Зависимости между модулями
- Результат: `cache/bsl_call_graph.db`
- Используется для навигации: "кто вызывает эту функцию?"

## Примеры

### Стандартная индексация

```cmd
reindex_bsl.bat "260304_GKSTCPLK-2182"
```

### Полная принудительная

```cmd
reindex_bsl.bat "260304_GKSTCPLK-2182" --full --force
```

### Авто-поиск проекта

```cmd
reindex_bsl.bat
```

Найдёт первый проект с подпапкой `src/` и проиндексирует его.

## Выходные данные

| Хранилище | Путь | Поиск через |
|---|---|---|
| FTS5 | `cache/docs-mcp/hybrid_search.db` | `mcp__1c-docs-rag__search_docs` |
| Qdrant | `localhost:6333`, коллекция `bsl_code_v3` | `mcp__bsl-semantic-search__bsl_search` |
| Call Graph | `cache/bsl_call_graph.db` | `mcp__code-graph__get_dependencies` |

## Сравнение с index-folder.bat

| | index-folder.bat | reindex_bsl.bat |
|---|---|---|
| **Назначение** | Ежедневная индексация | Полный анализ проекта |
| **Языки** | BSL, JS, TS, Python, MD | Только BSL |
| **Зависимости** | Python + Ollama | Python + Ollama + Docker + Qdrant |
| **Время (2000 BSL)** | ~80 мин | ~2-3 часа |
| **Граф вызовов** | Нет | Да |
| **Qdrant** | Нет | Да (E5-large, 1024d) |
| **Инкрементальность** | Да (FTS5) | Частичная |
| **Когда запускать** | После каждого изменения | При первой настройке проекта |
