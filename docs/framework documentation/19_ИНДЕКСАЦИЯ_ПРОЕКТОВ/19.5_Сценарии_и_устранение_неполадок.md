# 19.5 Сценарии использования и устранение неполадок

## Типичные сценарии

### Сценарий 1: Новый проект 1С

Получили новый проект, нужно проиндексировать для семантического поиска.

```cmd
:: 1. Проверить что проект на месте
scripts\index-folder.bat --list

:: 2. Полная индексация (документация + BSL эмбеддинги)
scripts\index-folder.bat "260304_GKSTCPLK-2182" --full

:: 3. Проверить результат
:: В Claude Code:
mcp__1c-docs-rag__search_docs("ОбработкаПроведения документ")
mcp__bsl-semantic-search__bsl_search("создание документа")
```

### Сценарий 2: Обновился код проекта

Получили новую версию конфигурации, нужно обновить индекс.

```cmd
:: Инкрементальная индексация (только изменённые файлы)
scripts\index-folder.bat "260304_GKSTCPLK-2182"
```

Без `--force` скрипт проиндексирует только файлы с изменённым hash.

### Сценарий 3: Быстрая индексация (только документация)

Ollama не запущен, не хочется ждать. Нужен только поиск по документации.

```cmd
scripts\index-folder.bat "260304_GKSTCPLK-2182" --docs-only
```

Занимает ~30-60 сек. Не требует Ollama.

### Сценарий 4: Индексация фреймворка (навыки, хуки, скрипты)

```cmd
:: Индексация скиллов
scripts\index-folder.bat "D:\1С-Framework\.claude\skills" --docs-only --languages markdown

:: Индексация документации
scripts\index-folder.bat "D:\1С-Framework\docs" --docs-only --languages markdown
```

### Сценарий 5: Большой проект в фоне

Проект содержит 5000+ BSL файлов. Индексация займёт часы.

```cmd
scripts\index-folder.bat "МойПроект" --full --background
```

Лог записывается в `logs/index-YYYYMMDD_HHMM.log`. Можно продолжить работу.

### Сценарий 6: Глубокий анализ BSL (Qdrant + Call Graph)

```cmd
:: Запустить Qdrant
docker run -d -p 6333:6333 qdrant/qdrant

:: 3-фазная индексация
reindex_bsl.bat "260304_GKSTCPLK-2182" --full
```

После этого доступен граф вызовов и E5-large векторный поиск (1024d).

### Сценарий 7: Из Claude Code (slash-команда)

```
> /index-folder
> 260304_GKSTCPLK-2182
```

Claude Code запустит индексацию интерактивно.

## Устранение неполадок

### Ollama не запускается

**Симптом:** `[ERROR] Ollama не запустился за 30 секунд`

**Проверка:**
```cmd
:: Занят ли порт?
netstat -an | findstr 11434

:: Ручной запуск
"%LOCALAPPDATA%\Programs\Ollama\ollama.exe" serve

:: Есть ли нужная модель?
curl http://localhost:11434/api/tags
:: Должна быть nomic-embed-text:latest
```

**Если модели нет:**
```cmd
ollama pull nomic-embed-text
```

### Индексация прерывается на середине

**Симптом:** Часть файлов проиндексирована, часть нет.

**Решение:** Запустить повторно без `--force`. Инкрементальность подхватит с места остановки (для 1c-docs-rag). Для bsl-semantic-search -- запустить заново.

### MCP сервер не видит новый индекс

**Симптом:** `search_docs` возвращает старые результаты.

**Решение:**
```cmd
:: 1c-docs-rag: перезапустится автоматически при следующем вызове
:: Если не помогло -- убить процесс вручную:
powershell "Get-Process python | Where-Object {$_.CommandLine -like '*mcp_server*'} | Stop-Process"
```

### Ошибка "Скрипт не найден"

| Скрипт | Причина | Решение |
|---|---|---|
| `smart_index_bsl.py` | Нет `scripts/docs-mcp/` | Проверить целостность фреймворка |
| `bsl_indexer_async.py` | Нет `1C-Enterprise_Framework/bsl-semantic-search/` | Клонировать репозиторий |
| `reindex_bsl_qwen3.py` | Нет скрипта Qdrant | Только для `reindex_bsl.bat` |
| `build_call_graph.py` | Нет скрипта Call Graph | Только для `reindex_bsl.bat` |

### Ошибка кодировки (UnicodeEncodeError)

**Симптом:** `'charmap' codec can't encode character`

**Решение:** Убедиться что bat-файл запускается через `cmd.exe` (не PowerShell). bat-файл вызывает `chcp 65001` автоматически.

Если проблема в Python скрипте:
```cmd
set PYTHONIOENCODING=utf-8
scripts\index-folder.bat ...
```

### Медленная индексация BSL

**Типичная скорость:** ~0.4 файла/сек через Ollama.

**Способы ускорения:**
- Увеличить `--batch-size` (default: 10)
- Увеличить `--max-workers` (default: 4)
- Использовать GPU для Ollama: `set OLLAMA_GPU_LAYERS=35`
- Для первого раза: `--max-files 100` для проверки, потом полная

### Большой размер bsl_index_full.json

Проект из 2000 BSL файлов создаёт JSON ~50-100 MB (из-за эмбеддингов).

**Не является проблемой:** файл загружается один раз при старте MCP-сервера.
