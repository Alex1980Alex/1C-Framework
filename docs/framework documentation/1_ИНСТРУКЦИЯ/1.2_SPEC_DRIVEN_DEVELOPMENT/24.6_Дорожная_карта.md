## Метрики успеха

| Метрика | Текущее | Целевое |
|---------|---------|---------|
| Архитектурные ошибки AI в коде 1С | Частые | Снижение на 70% |
| Отклонения на Code Review | ~40% | < 15% |
| Задачи через полный цикл SDD | 0% | > 80% |
| Объем контекста при доработке типовых | 100% | 40-50% (Delta-specs) |
| Время обнаружения Gap-ошибок | Тестирование (дни) | Генерация (минуты) |

## Когда НЕ использовать SDD

Полный цикл SDD нецелесообразен для тривиальных задач:

- Косметические исправления UI (видимость, группировки)
- Исправление мелких багов (опечатки, замена знака)
- Рефакторинг формата кода
- Простые отчеты на СКД
- Обновление документации

**Правило:** Если задача не требует создания новых объектов метаданных или изменения бизнес-логики — SDD-конвейер можно безопасно обойти через `implement-1c-task`.
