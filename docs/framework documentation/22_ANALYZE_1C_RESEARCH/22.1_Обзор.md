# 22.1 Обзор

Система Analyze-1C-Research представляет собой эволюцию метода анализа задач 1С, переходящую от однопроходной схемы к итеративному процессу с объективной оценкой качества.

## Проблематика

Текущая реализация `analyze-1c-task-v2` имеет ряд ограничений: анализ выполняется в один проход без возможности итеративного улучшения, отсутствует объективная метрика качества результата, нет механизма персистентности для сохранения промежуточных состояний. Это приводит к нестабильному качеству выходных отчётов и невозможности систематической оптимизации.

## Решение

Трёхагентная архитектура итеративного анализа. Executor выполняет первичный анализ по фазам 1-4, Reviewer проводит критическую оценку на фазе 5 с присвоением числового скоринга, Comparator выполняет слепое сравнение A/B вариантов. Цикл продолжается до достижения целевого показателя качества или обнаружения плато.

## Архитектура системы

**Level 1: Loop Manager**
Управляющий слой: `ralph.bat --template 1c-analysis`, `analyze-1c-research.ps1`, команда `/analyze-1c-task:research`. Отвечает за оркестрацию итераций и обработку сигналов завершения.

**Level 2: Three-Agent Engine**
Исполнительный слой с разделением ответственности. Executor генерирует отчёт, Reviewer оценивает по критериям полноты и точности, Comparator выбирает лучший вариант без контекста итерации.

**Level 3: MCP Infrastructure**
Инструментальный слой: `bsl-semantic-search` для семантического поиска, `1c-mcp-toolkit` для работы с метаданными, `bsl-platform-context` для контекста платформы, `pdf-vector-graph` для работы с документацией.

## Отличия от AutoResearch v2

| Аспект | AutoResearch (код) | Analyze-1C-Research |
|--------|-------------------|---------------------|
| Метрика | ruff errors, F1 | Quality score (0-100) |
| REVERT | git revert кода | Откат отчёта к предыдущей версии |
| Plateau | 5 итераций | 3 итерации |
| Типичный цикл | 10-20 итераций | 3-7 итераций |
| MCP tools | Минимально | Активно (get_metadata, execute_query, bsl_search) |
| Dead Ends | Кодовые подходы | Неверные гипотезы об архитектуре задачи |
