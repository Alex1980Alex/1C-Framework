# 22.5 Eval и калибровка

## Eval Dataset

Файл `data/eval/1c-analysis/eval_dataset.json` содержит 16 реальных ANALYSIS-REPORTs с human scores (60-95). Каждая запись включает path к отчёту, human overall score и expected gaps.

## Запуск оценки

```bash
python scripts/eval-analysis-scorer.py         # таблица + summary
python scripts/eval-analysis-scorer.py --json   # JSON output
```

## Текущие метрики

| Metric | Value | Target | Status |
|--------|-------|--------|--------|
| Gap F1 | 89.2% | > 70% | PASS |
| MAE (all) | 29.8 | < 10 | FAIL |
| MAE (marked) | 8.3 | < 10 | PASS |
| Pearson R | 0.36 | > 0.8 | FAIL |

## Интерпретация

Scorer измеряет **marker compliance** (соответствие маркерам), а не субъективное качество анализа. Это осознанное решение: scorer стимулирует использование маркеров `✓ get_metadata`, `✓ pattern`, `[REQ-N]`.

- **Отчёты с маркерами** (3 из 16): MAE = 8.3 — в пределах target
- **Legacy отчёты без маркеров** (13 из 16): auto score 27-58 при human 60-88 — scorer занижает, потому что маркеров нет

По мере перехода на `/analyze-1c-task:research` (который генерирует маркеры автоматически) доля marked-отчётов будет расти, и общий MAE будет снижаться.

## Калибровка весов

Текущие веса (30/25/20/15/10) — экспертная оценка. При накоплении 10+ отчётов с маркерами можно оптимизировать:

```python
from scipy.optimize import minimize

def calibrate(dataset):
    def objective(weights):
        auto = [compute_score(task, weights) for task in dataset]
        human = [task["human_scores"]["overall"] for task in dataset]
        return -pearsonr(auto, human)

    return minimize(objective, x0=[30, 25, 20, 15, 10],
                   bounds=[(0,50)]*5,
                   constraints={"type": "eq", "fun": lambda w: sum(w) - 100})
```

## Как добавить отчёт в dataset

1. Прогнать scorer: `python scripts/score-analysis-report.py path/to/report.md`
2. Оценить отчёт вручную (overall 0-100)
3. Добавить запись в `eval_dataset.json`:
   ```json
   {
     "id": "GKSTCPLK-XXXX",
     "report_path": "relative/path/to/report.md",
     "human_scores": {"overall": 85},
     "expected_gaps": [{"type": "pattern_missing"}],
     "notes": "description"
   }
   ```
4. Запустить `python scripts/eval-analysis-scorer.py` — проверить влияние на метрики
