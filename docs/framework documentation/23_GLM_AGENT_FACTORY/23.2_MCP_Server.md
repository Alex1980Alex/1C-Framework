# 23.2 MCP Server (Plan B)

> Явный вызов GLM-агентов через MCP tools. Стабильный, не зависит от hook bugs.

---

## Назначение

MCP Server `glm-agent` предоставляет 6 инструментов для Claude Code, каждый из которых делегирует задачу GLM-5.1 через Z.AI API. В отличие от HTTP Proxy (Plan C), требует явного вызова `mcp__glm-agent__*`.

## Инструменты

| Tool | Описание | Параметры |
|------|----------|-----------|
| `analyze` | Анализ кода: паттерны, smells, complexity | `prompt` (req), `files` (opt) |
| `review` | Code review: баги, security, maintainability | `prompt` (req), `files` (opt) |
| `generate` | Генерация кода по спецификации | `prompt` (req) |
| `research` | Исследование и сравнение технологий | `prompt` (req) |
| `architect` | Проектирование архитектуры, ADR | `prompt` (req) |
| `write` | Документация, README, комментарии | `prompt` (req), `files` (opt) |

## Конфигурация

Регистрация в `.claude/mcp-servers.json`:

```json
{
  "glm-agent": {
    "command": "python",
    "args": ["scripts/claude-backend/glm-mcp/server.py"],
    "cwd": "D:\\1C-Enterprise_Framework",
    "env": {
      "PYTHONPATH": "D:\\1C-Enterprise_Framework\\scripts\\claude-backend",
      "GLM_API_URL": "https://api.z.ai/api/anthropic",
      "GLM_API_KEY": "<your-key>"
    },
    "disabled": false
  }
}
```

## Как работает

```
Claude Code вызывает mcp__glm-agent__analyze(prompt="...", files=["a.py"])
       |
       v
  MCP Server (stdio JSON-RPC)
       |
       +-- 1. Загружает system prompt из .claude/agents/glm-analyst.md
       +-- 2. Читает содержимое файлов с диска (max 50KB, max 20 файлов)
       +-- 3. Собирает messages: system + user (prompt + file content)
       +-- 4. Вызывает GLM-5.1 API через GLMClient
       +-- 5. Извлекает текст из ответа
       +-- 6. Возвращает как MCP tool result
```

## File Content Injection

При передаче `files` сервер автоматически:
- Читает содержимое каждого файла с диска
- Добавляет его в prompt с заголовком `--- File: path ---`
- Ограничивает общий объем 50 KB
- Обрабатывает до 20 файлов за вызов
- При ошибке чтения добавляет `[File not found]` / `[Error reading]`

## Agent Prompt Loader

System prompt загружается из `.claude/agents/glm-{type}.md`:

```
analyze -> .claude/agents/glm-analyst.md
review  -> .claude/agents/glm-reviewer.md
generate -> .claude/agents/glm-coder.md
research -> .claude/agents/glm-researcher.md
architect -> .claude/agents/glm-architect.md
write    -> .claude/agents/glm-writer.md
```

Если файл не найден, используется fallback prompt.

## Примеры использования

### Анализ Python файла

```
mcp__glm-agent__analyze(
  prompt="Find code smells and complexity issues",
  files=["src/parser.py", "src/validator.py"]
)
```

### Code review

```
mcp__glm-agent__review(
  prompt="Review for security vulnerabilities",
  files=["api/routes.js"]
)
```

### Генерация кода

```
mcp__glm-agent__generate(
  prompt="Write a TypeScript LRU cache class with generics and TTL support"
)
```

### Исследование

```
mcp__glm-agent__research(
  prompt="Compare WebSocket vs SSE vs Long Polling for real-time updates"
)
```

## Протокол

MCP Server использует stdio JSON-RPC 2.0:

| Method | Описание |
|--------|----------|
| `initialize` | Возвращает capabilities и server info |
| `tools/list` | Возвращает список 6 tools с inputSchema |
| `tools/call` | Вызывает tool, возвращает `{content: [{type: "text", text: "..."}]}` |
| `notifications/*` | Игнорируются |

## Обработка ошибок

При ошибке GLM API возвращается текстовое сообщение:

```
[GLM Agent Error: Connection timeout]

Fallback: Use Claude Agent instead.
```

Claude Code может перенаправить задачу на Claude Agent на основании этого сообщения.
