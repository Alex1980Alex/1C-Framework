# 23.4 Agent Definitions

> System prompts для 6 GLM-агентов. Определяют поведение, scope и output format каждого агента.

---

## Формат определения

Каждый агент описан в файле `.claude/agents/glm-{type}.md` с YAML frontmatter:

```markdown
---
name: glm-analyst
description: Code analysis agent powered by GLM-5.1. NOT for BSL/1C code.
model: haiku
tools: Read
---

# GLM Analyst Agent

You are a code analysis specialist...

## Capabilities
...

## Scope
- Universal code: Python, JavaScript, TypeScript, Go, etc.
- NOT for BSL/1C code

## Output Format
...

## Rules
...
```

### Frontmatter поля

| Поле | Назначение | Значение |
|------|------------|----------|
| `name` | Идентификатор агента | `glm-analyst`, `glm-reviewer`, etc. |
| `description` | Описание для Claude Code | Отображается в Agent tool |
| `model` | Маркер для routing | `haiku` (перехватывается proxy/hook) |
| `tools` | Доступные инструменты | Определяет sandbox подагента |

## Агенты

### glm-analyst

**Файл:** `.claude/agents/glm-analyst.md`

**Модель:** glm-5.1

**Специализация:** Глубокий анализ кода --- паттерны, anti-patterns, code smells, complexity.

**Capabilities:**
- Pattern detection
- Cyclomatic complexity analysis
- Dependency mapping
- Performance profiling hints
- Security audit (OWASP)

**Output format:**

```markdown
## Analysis: [file/module name]

### Summary
[1-2 sentence overview]

### Findings
| # | Severity | Category | Location | Description |
|---|----------|----------|----------|-------------|

### Metrics
- Total lines, functions, max complexity, coupling score

### Recommendations
1. [Ordered by impact with code examples]
```

**Benchmark:** 96/100 avg score, 32.5s avg latency.

## Выбор модели

| Agent type | Модель | Причина |
|-----------|--------|---------|
| analyst, reviewer, coder, architect | glm-5.1 | Требуется глубокий анализ кода |
| researcher, writer | glm-4.5-air | Текстовые задачи, не требуют code reasoning |

Логика в `GLMClient`:
```python
model = self.model_lite if agent_type in ("researcher", "writer") else self.model
```
