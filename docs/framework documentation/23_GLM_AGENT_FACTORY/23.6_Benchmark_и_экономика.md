## Quality Benchmark

### Методология

10 задач покрывают все 6 типов агентов:

| # | Агент | Задача |
|---|-------|--------|
| 1 | analyst | Анализ Python функции: code smells, complexity |
| 2 | reviewer | Security review JavaScript кода (SQL injection) |
| 3 | coder | Генерация LRU cache на Python с type hints |
| 4 | researcher | Сравнение WebSocket vs SSE |
| 5 | architect | Event-driven архитектура для order processing |
| 6 | writer | API документация для REST endpoint |
| 7 | analyst | Анализ Go кода: performance issues (O(n^3)) |
| 8 | reviewer | Review TypeScript кода: any type, error handling |
| 9 | coder | Deep merge TypeScript с generics |
| 10 | architect | Caching strategy для read-heavy API |

### Scoring

Heuristic scoring по 3 критериям (composite = weighted sum):

| Критерий | Вес | Как считается |
|----------|-----|---------------|
| Keyword presence | 40% | Ожидаемые ключевые слова в ответе |
| Length adequacy | 30% | 200--2000 chars = 100, < 50 = 10, > 4000 = 80 |
| Structure | 30% | Наличие headers, lists, code blocks, paragraphs |
