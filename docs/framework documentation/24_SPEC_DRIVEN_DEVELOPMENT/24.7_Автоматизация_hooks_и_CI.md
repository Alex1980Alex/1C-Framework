## Обзор

Глава описывает четыре уровня автоматизации OpenSpec в фреймворке: hooks (4 шт), CI workflow, pre-commit lint, smoke-preflight. Все компоненты введены в sprint 2026-05-20 ([roadmap §B/C/D/E/F/Q](../../roadmap/260520_ROADMAP_OPENSPEC_INTEGRATION_V2.md)).

```
┌──────────────────────────────────────────────────────────────────┐
│  Слои автоматизации OpenSpec в 1С-Framework                      │
└──────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────┐
  │ L1 — PreToolUse hook (live, блокирующий)                    │
  │   approval-gate.py                                          │
  │   • Skill('implement-1c-task') без approved → BLOCK         │
  │   • Skill('opsx:apply') без approved → BLOCK                │
  └────────────────────────────┬────────────────────────────────┘
                               │
  ┌────────────────────────────▼────────────────────────────────┐
  │ L2 — PostToolUse hook (live, info-only)                     │
  │   openspec-change-coverage.py                               │
  │   • Edit/Write в Конфигурация/ с JIRA-токеном в пути        │
  │   • Нет active change для этой JIRA → systemMessage         │
  └────────────────────────────┬────────────────────────────────┘
                               │
  ┌────────────────────────────▼────────────────────────────────┐
  │ L3 — Stop hooks (session-end, info-only)                    │
  │   opsx-apply-postvalidate.py                                │
  │   • Был /opsx:apply без brownfield-validate → напоминание   │
  │   openspec-task-progress.py                                 │
  │   • Git diff → heuristic candidate-completed tasks          │
  └────────────────────────────┬────────────────────────────────┘
                               │
  ┌────────────────────────────▼────────────────────────────────┐
  │ L4 — CI/PR gate (remote)                                    │
  │   .github/workflows/openspec.yml                            │
  │   • PR → scripts/openspec_lint_ci.py --mode structural      │
  │   • PR → scripts/openspec_lint_ci.py --mode coverage        │
  │   • Comment summary на PR                                   │
  └─────────────────────────────────────────────────────────────┘
```
