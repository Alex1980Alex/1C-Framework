# 25. Learning Loop — самообучающийся пайплайн

## 25.1 Обзор

**Learning Loop** — механизм самообучения Claude Code, который активируется, когда для выполнения задачи не хватает существующих навыков (skills). Система не просто ищет информацию — она преобразует полученные знания в формализованный, повторно используемый skill.

**Ключевое свойство — самоусиление:** каждый успешный прогон пайплайна создаёт новый skill. Будущие задачи по этой теме выполняются мгновенно, без повторного поиска. База знаний растёт с каждой итерацией.

**Реализация:**
- Субагент: `.claude/agents/learning-loop.md`
- Модель: `opus` (требуется сложное рассуждение для синтеза знаний)
- Триггер: `code-skill-enforcer` Level A.1 — блокирует `Write`, когда в `.claude/skills/` отсутствует skill для текущей технологии
- Скилл-инструкция: `.claude/skills/learning-loop/SKILL.md`

**Пайплайн:**

```
SEARCH → FETCH → EXECUTE → VERIFY → CREATE
  ↑                                    │
  └────── skill создан ◄──────────────┘
```
