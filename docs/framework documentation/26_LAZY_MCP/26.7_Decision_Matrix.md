# 26.7 MCP Servers Decision Matrix

> Roadmap reference: [260509_ROADMAP_CONSOLIDATED_BACKLOG.md §4.8](../../../docs/roadmap/260509_ROADMAP_CONSOLIDATED_BACKLOG.md). Closed 2026-05-09.

Decision matrix per active MCP server в проекте: **keep** / replace / remove с обоснованием.

## Audit findings (2026-05-09)

Roadmap §4.8 называл 5 кандидатов на decision (claude-hud, codebase-memory-mcp, parry, sonar-bsl, bsl-language-server). Реальный inventory `.mcp.json`:

- **0** из 5 кандидатов roadmap присутствуют — никогда не landed
- **20** active MCP servers фактически работают
- **27** дополнительных on-demand серверов через lazy-mcp proxy (см. [26.3 Реестр серверов](26.3_Реестр_серверов.md))

Roadmap candidate list был aspirational и outdated к моменту аудита. Текущая matrix — на actual production set.

## Lazy-MCP on-demand servers (27)

Серверы через [26.3 Реестр серверов](26.3_Реестр_серверов.md) активируются по mention pattern. Их decision = **keep all** by virtue of zero startup cost (loaded on demand). Audit таких — отдельный scope.

## Когда пересмотреть

| Триггер | Действие |
|---|---|
| Server не использовался > 60 дней | Проверить через `data/hook-invocations.jsonl` (category=mcp_call), candidate на retirement |
| Дубликат функционала | Сравнить tools, удалить менее mature |
| Новый external tool появился | Добавить в matrix с initial decision |
| Production incident | Pause server (`mcpServers.{name}.enabled=false` если поддерживается), root-cause analysis |

## Проверка use-rate (опционально)

```bash
# Топ MCP-серверов по использованию за 7 дней
sqlite3 data/hook-metrics.db <<EOF
SELECT
    SUBSTR(tool, 1, INSTR(tool || '__', '__') - 1) AS server,
    COUNT(*) AS calls,
    AVG(elapsed_ms) AS avg_ms
FROM invocations
WHERE category = 'mcp_call'
  AND timestamp > datetime('now', '-7 days')
GROUP BY server
ORDER BY calls DESC;
EOF
```
