# 27.10 Memory Surfacing Quality — semantic + confidence-weighted + hybrid (§24)

> **Статус:** P0–P2 + execution-cache + epoch-invalidation DONE (2026-05-31, ADR-D6 accepted). Research (3 агента, ~11 GitHub-репозиториев source-level) + дизайн: [roadmap 260523 §24](../../roadmap/260523_ROADMAP_FULL_DEV_LIFECYCLE_ANALYSIS.md).

## Проблема (verified live)

`memory-first-hook` всплывал `learned_patterns` грубым **token-overlap** (`len(overlap)/len(query)`), хотя эмбеддинги — настоящие TEI Qwen3 4096d (semantic был возможен, но `learned_patterns` не входил в `SEMANTIC_COLLECTIONS`). Вдобавок **§22 `effective_confidence` не применялся к surfacing** (использовался только в MCP `handle_search_patterns`) — то есть достоверность паттерна никак не влияла на то, что инжектится в контекст модели.

Цель: semantic recall + confidence-weighting + hybrid robustness.

## Research summary (ключевые выводы)

1. **Composite ranking — production rankers ADDITIVE/RRF, НЕ multiply.** generative_agents (min-max → weighted sum), mem0 (semantic+bm25+entity, adaptive норм), crewAI (`0.5·sim+0.3·decay+0.2·importance`), LangChain TimeWeighted (additive). YourMemory **явно отвергает** `cosine×strength` для ранжирования → это рефайнит наивный `score *= confidence`.
2. **Hybrid + RRF.** Rank-based **RRF `1/(k+rank)`, k=60** (Cormack SIGIR2009; LangChain `EnsembleRetriever c=60`, LlamaIndex `k=60`) корректно мёржит **scale-mismatched** сигналы (cosine vs overlap) без нормализации. Для Cyrillic/BSL (dense recall 45-65%) — **lexical ≥ dense** (вес ~0.7/0.3).
3. **Confidence/staleness gating.** Консенсус trusted-knowledge: **гибрид** — hard floor (kill noise) + soft в live-band. Archived/`expired_at` → **EXCLUDE** (не downweight): `×0.5` рискован (sim 0.95×0.5=0.475 обгоняет live 0.45×0.9=0.405).

## ADR-D6 — финальный дизайн surfacing `learned_patterns`

### P0 — Semantic surfacing + confidence-gating (`6906210c9`)

- `("learned_patterns", "pattern")` добавлен в `SEMANTIC_COLLECTIONS` (TEI 4096d, эмбеддинги уже настоящие — reindex НЕ нужен).
- `_pattern_score_gate(payload, base_score)` (§24.2.3):
  - **archived hard-exclude:** `expired_at` set → drop (opt `MEMORY_INCLUDE_ARCHIVED=1`);
  - **hard noise floor:** `effective_confidence < MIN_SURFACE_CONF (0.15)` → drop;
  - **floored-multiply (soft):** `final = rrf_score × max(CONF_FLOOR (0.3), eff)` — gating «relevant AND trusted», но new-pattern с prior 0.70 не давится, discredited→0.1 сильно подавлен. Raw `×confidence` — анти-паттерн per research.

### P1 — Hybrid RRF (`74a4aa761`)

`search_qdrant` строит per-source arms и мёржит client-side RRF k=60:

| Arm | Источник | Вес (`SURFACE_RRF_WEIGHTS`) |
|---|---|---|
| `skill` | `skill_library` semantic | 0.5 |
| `experience` | `experience_embeddings` semantic | 0.5 |
| `conversation` | `conversation_memory` semantic | 0.5 |
| `pattern_dense` | `learned_patterns` semantic (gated) | 0.3 |
| `pattern_lexical` | `learned_patterns` token-overlap — **ALWAYS-ON** (не fallback) | 0.7 |

- Lexical 0.7 > dense 0.3 для BSL (CamelCase/Cyrillic dense recall-collapse).
- RRF dedup по content-hash: паттерн в обоих arm'ах фьюзится → boosted rank (корректно).
- **Graceful degradation:** TEI down → dense arms пусты, `pattern_lexical` всё ещё populated → lexical-only RRF, никогда не ломает surfacing.
- Side-fix: §22 P3 `handle_search_patterns` archived `×0.5` → hard-exclude.

### P2 — Optional LLM rerank (off by default)

`_rerank_results()` post-fusion reorder top-N через Ollama `qwen2.5-coder:7b` (зеркалит BSL `_llm_rerank`: numbered prompt → CSV-индексы → reorder). **OFF by default** (`MEMORY_RERANK=1`): эмпирически ~2.5s warm / ~6.5s cold > hot-path budget (3s) и 5s hard-kill хука → enable требует поднять `settings.json` timeout ≥10s. Skippable: fail/timeout/no-budget → fused-порядок. Omitted-кандидаты дописываются (no silent drop).

## Execution cache (2026-05-31)

`memory-first-hook` hash-memoize'ит весь pipeline по `hash(query_tokens)` на диске (`.claude/cache/memory-first-surfacing-cache.json`, TTL `MEMORY_SURFACE_CACHE_TTL=300s`, FIFO 200, opt-out `MEMORY_SURFACE_CACHE_DISABLE=1`). Hit пропускает TEI+Qdrant+RRF+rerank (~2s); reinforcement реплеится на hit (§22 P1 продолжает считать surfaced-паттерны).

### Epoch-keyed invalidation

`cache_key` включает **confidence-epoch** — [`src/memory/vector_memory/epoch.py`](../../../src/memory/vector_memory/epoch.py): `bump()` атомарно пишет `time.time()` в `.claude/cache/confidence-epoch.txt`, `read()` — дешёвый локальный read **без Qdrant-roundtrip**, fail-soft→0.0. Любая confidence/archive-мутация (`reinforce_pattern` + server.py `apply`/`decay`/`save`/`delete`) бампает эпоху → мгновенный cache-miss. Закрывает 5-минутное stale-окно между §22 confidence и §24 surfacing. Server.py-бампы требуют `/mcp reconnect`; reinforce + hook-reader спавнятся свежими (effective сразу).

## Surfacing trace logging (§24.4)

`memory-first-hook` пишет per-invocation JSONL в `.claude/cache/memory-first-surfacing.log` (`_surface_log()` + module-global `_TRACE`): стадии `cache` (hit/miss), `tei` (ok/down/no_embedding + error), `arms` (hit-counts по 5 плечам), `gate` (archived/below_floor/passed), `layers`, `rrf_fused`, `rerank` (off/too_few/no_budget/error/no_ranking/parse_error/applied), `reinforced_pids`, `duration_ms`, terminal `outcome` (injected/injected-cached/no-results/cached-empty). Fail-soft, atomic size-rotation 2MB, opt-out `MEMORY_SURFACE_LOG_DISABLE=1`, без prompt-контента/тел паттернов.

Закрывает «слепоту» fail-soft pipeline (раньше `except: pass` молчал). Анализ: `tail` + построчный `json.loads`.

## cp1251 stdout hotfix

Surfacing-вывод через `_emit_stdout()` (UTF-8-байты via `sys.stdout.buffer`, как `HookOutput.emit()`) — `print()` с кириллицей на cp1251-pipe ронял `UnicodeEncodeError` и молча терял всю инъекцию.

## Acceptance

- ✅ learned_patterns всплывают **семантически** (парафраз без word-overlap) при живом TEI; token-overlap при TEI-down.
- ✅ `effective_confidence` влияет на ранг; conf<0.15 не всплывает; archived не всплывает (без флага).
- ✅ RRF k=60, lexical-вес > dense; TEI-down → lexical-only (no crash).

## §25 B1 — self-tuning hook-in (2026-06-01)

Константы fusion (`SURFACE_RRF_WEIGHTS`, `MIN_SURFACE_CONF`, `CONF_FLOOR`, `SURFACE_RRF_K`, `SURFACE_CACHE_TTL`) больше не только hardcoded: `memory-first-hook.py::_load_surfacing_tuning()` при импорте оверлеит [`data/memory/surfacing_tuning.json`](../../../data/memory/surfacing_tuning.json), clamped к `clamp_ranges`. Fail-soft → defaults на missing/malformed; удалить файл = вернуть defaults; opt-out `MEMORY_SURFACE_TUNING_DISABLE=1`; явный `MEMORY_SURFACE_CACHE_TTL` env побеждает файл. Файл переписывает **только** gated promotion ([`scripts/tune_memory_surfacing.py`](../../../scripts/tune_memory_surfacing.py), B2) при улучшении held-out метрики без регрессии. Измерение качества — golden-set harness [`scripts/memory_golden_harness.py`](../../../scripts/memory_golden_harness.py) (B0, 43 query, content-hash labels).
