# 28.4 Индексация проектов

> **Версия:** 3.0 | **Дата:** 2026-05-04

---

## Принцип

BSL Semantic Search работает ТОЛЬКО по проиндексированным данным. Если проект не проиндексирован — все запросы вернут пустой результат.

Индексация создаёт:
- **Эмбеддинги** функций/процедур через **TEI + Qwen3-Embedding-8B 4096d** (Late Chunking pooling) → Qdrant `bsl_code_v4_late`
- **Граф зависимостей** модулей → Neo4j (graph database)
- **Метаданные** объектов → Qdrant (RRF-коллекция)

### Payload schema (Phase 8)

| Поле | Содержимое | Примечание |
|------|-----------|-----------|
| `module_path` | Полный путь к BSL-файлу | Phase 8 переименовал из `file_path` |
| `content` | Текст процедуры/функции + контекст вокруг | Phase 8 переименовал из `searchable_text` |
| `module_type` | `CommonModule` / `ObjectModule` / `FormModule` / `ManagerModule` | Используется для фильтра `module_types` |
| `function_name`, `region`, `dependencies` | Метаинформация для рендера и графа | — |

> Если код-клиент после Phase 8 продолжает читать `file_path` / `searchable_text` — он молча получит пустые строки. См. фикс [`bsl_search` 2026-05-04](../../../src/bsl/semantic_search/services/search.py).

## Способы индексации

### Через slash-команду

```
/index-project
```

Интерактивная команда: запрашивает путь к проекту, тип индексации.

### Через MCP (1c-docs-rag)

```python
# BSL файлы
mcp__1c-docs-rag__index_bsl_project(
    project_path="D:/1C-Enterprise_Framework/src/projects/configuration/PROJECT/src",
    project_name="PROJECT"
)

# XML метаданные (формы, подсистемы, права)
mcp__1c-docs-rag__index_xml_project(
    project_path="D:/1C-Enterprise_Framework/src/projects/configuration/PROJECT/src",
    project_name="PROJECT"
)

# Инкрементальная (только изменённые файлы)
mcp__1c-docs-rag__index_incremental(
    directory="D:/1C-Enterprise_Framework/src/projects/configuration/PROJECT"
)
```

### Через Python-скрипты

```bash
# Полная индексация BSL
python bsl-semantic-search/scripts/indexing/bsl_indexer.py \
    --project-path "src/projects/configuration/PROJECT/src" \
    --project-name "PROJECT"

# Индексация метаданных (из MCP_Сервер)
python bsl-semantic-search/scripts/indexing/metadata_indexer.py \
    --mcp-url "http://KOMPUTER/TestDB/hs/mcp/rpc"

# Граф зависимостей
python bsl-semantic-search/scripts/neo4j/bsl_dependency_analyzer.py \
    --project-path "src/projects/configuration/PROJECT/src"
```

## Проверка индексации

```python
# Список проиндексированных проектов
mcp__1c-docs-rag__get_indexed_projects()

# Статистика индекса
mcp__1c-docs-rag__get_stats()
```

## Qdrant коллекции (Phase 8 + 9.1, актуально на 2026-05-04)

| Коллекция | Точек | Содержимое | Модель / dim |
|-----------|------|-----------|--------------|
| **`bsl_code_v4_late`** (production) | 54 752 | Функции/процедуры BSL с **Late Chunking** pooling | Qwen3-Embedding-8B / 4096d |
| `bsl_code_v4` (research baseline) | 24 455 | Функции/процедуры BSL, std pooling | Qwen3-Embedding-8B / 4096d |
| `framework_code_v1` | 21 277+ | Self framework код (`src/`, `scripts/`, `.claude/`, `docs/`) | Qwen3 / 4096d, auto-reindex on commit |
| `wiki_pages_v1` | 3 073 | `docs/wiki/entities/*.md` | Qwen3 / 4096d |
| `graph_embeddings` | 6 694 | KG entities | Qwen3 / 4096d |

Текущее число точек в production-коллекции возвращает `bsl_stats` MCP-tool (см. [28.3 §5](28.3_Инструменты.md#5-bsl_stats--статистика-индекса)).

**Reindex command (Phase 8):**
```bash
python scripts/reindex_bsl_qwen3.py --pooling-mode late-chunking --embedder qwen3-st --collection bsl_code_v4_late
```

**Dropped 2026-04-30 (legacy):** `bsl_code_v2` (768d nomic), `bsl_code_v3` (1024d E5), `metadata_rrf`/`docs_rag` (концепты, не реализованы под Phase 8). Подробности: [chapter 31 Qwen3 Retrieval Production](../31_QWEN3_RETRIEVAL_PRODUCTION/31.1_Обзор.md), [roadmap Phase 8](../../roadmap/260426_ROADMAP_PHASE_8_QWEN3_EMBEDDING_REINDEX.md).

## Рекомендации

- Индексировать **после каждого крупного изменения** конфигурации
- Использовать **инкрементальную** индексацию для ежедневных обновлений
- Первичная полная индексация ~5000 BSL файлов: ~10-20 минут
- Инкрементальная: ~30 сек (только дельта)
