# 28.4 Индексация проектов

> **Версия:** 2.0 | **Дата:** 2026-04-07

---

## Принцип

BSL Semantic Search работает ТОЛЬКО по проиндексированным данным. Если проект не проиндексирован — все запросы вернут пустой результат.

Индексация создаёт:
- **Эмбеддинги** функций/процедур → Qdrant (vector store)
- **Граф зависимостей** модулей → Neo4j (graph database)
- **Метаданные** объектов → Qdrant (RRF-коллекция)

## Способы индексации

### Через slash-команду

```
/index-project
```

Интерактивная команда: запрашивает путь к проекту, тип индексации.

### Через MCP (1c-docs-rag)

```python
# BSL файлы
mcp__1c-docs-rag__index_bsl_project(
    project_path="D:/1C-Enterprise_Framework/src/projects/configuration/PROJECT/src",
    project_name="PROJECT"
)

# XML метаданные (формы, подсистемы, права)
mcp__1c-docs-rag__index_xml_project(
    project_path="D:/1C-Enterprise_Framework/src/projects/configuration/PROJECT/src",
    project_name="PROJECT"
)

# Инкрементальная (только изменённые файлы)
mcp__1c-docs-rag__index_incremental(
    directory="D:/1C-Enterprise_Framework/src/projects/configuration/PROJECT"
)
```

### Через Python-скрипты

```bash
# Полная индексация BSL
python bsl-semantic-search/scripts/indexing/bsl_indexer.py \
    --project-path "src/projects/configuration/PROJECT/src" \
    --project-name "PROJECT"

# Индексация метаданных (из MCP_Сервер)
python bsl-semantic-search/scripts/indexing/metadata_indexer.py \
    --mcp-url "http://KOMPUTER/TestDB/hs/mcp/rpc"

# Граф зависимостей
python bsl-semantic-search/scripts/neo4j/bsl_dependency_analyzer.py \
    --project-path "src/projects/configuration/PROJECT/src"
```

## Проверка индексации

```python
# Список проиндексированных проектов
mcp__1c-docs-rag__get_indexed_projects()

# Статистика индекса
mcp__1c-docs-rag__get_stats()
```

## Qdrant коллекции

| Коллекция | Содержимое | Модель эмбеддинга |
|-----------|-----------|-------------------|
| `bsl_code_v2` | Функции/процедуры BSL | nomic-embed-text |
| `metadata_rrf` | Объекты метаданных (3 вектора) | nomic-embed-text |
| `docs_rag` | Документация фреймворка | nomic-embed-text |

## Рекомендации

- Индексировать **после каждого крупного изменения** конфигурации
- Использовать **инкрементальную** индексацию для ежедневных обновлений
- Первичная полная индексация ~5000 BSL файлов: ~10-20 минут
- Инкрементальная: ~30 сек (только дельта)
