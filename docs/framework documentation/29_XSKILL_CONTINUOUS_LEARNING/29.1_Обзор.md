# 29.1 XSkill Continuous Learning -- Обзор

> Двухпоточная архитектура непрерывного обучения агента без обновления весов модели.
> Основана на XSkill (arXiv: 2603.12056).

## Что это

XSkill Continuous Learning -- система из 8 фаз, которая позволяет Claude Code агенту:

1. **Запоминать** что сработало и что провалилось при работе с инструментами
2. **Обобщать** тактические инсайты из сырых логов (Experience Bank)
3. **Подсказывать** релевантный опыт при похожих задачах (семантический retrieval)
4. **Оценивать** эффективность знаний и skills по реальным outcomes
5. **Обновлять** SKILL.md файлы автоматически на основе накопленного опыта

## Отличие от Learning Loop (глава 25)

| | Learning Loop (гл. 25) | XSkill (гл. 29) |
|--|------------------------|------------------|
| Фокус | Создание новых skills | Непрерывное улучшение всех знаний |
| Триггер | Блокировка агента | Каждое действие агента |
| Цикл | SEARCH-FETCH-EXECUTE-VERIFY-CREATE | Accumulate-Consolidate-Retrieve-Evaluate |
| Хранение | SKILL.md | Experience Bank (JSONL) + Qdrant + SKILL.md |
| Отрицательные примеры | Нет | Failure capture + contrastive analysis |
| Cross-model | Нет | Per-model confidence, affinity matrix |
| Visual | Нет | Screenshot grounding (SigLIP) |

## 8 фаз

| Фаза | Название | Что делает |
|------|----------|-----------|
| 1 | Experience Distillation | Сырые логи -> структурированные инсайты |
| 2 | Failure Capture | Ошибки, retry, switch -> отрицательные примеры |
| 3 | Hierarchical Consolidation | Dedup, merge, eviction, auto-promotion в SKILL.md |
| 4 | Semantic Skill Retrieval | Qdrant + TF-IDF гибридный поиск skills и experiences |
| 5 | Continuous Learning Loop | Outcome tracking, confidence scoring, auto-deprecation |
| 6 | Cross-Model Profiling | Per-model effectiveness, affinity matrix, transfer tracking |
| 7 | Observability | Метрики, 5 slash commands, dashboard |
| 8 | Visual Grounding | Screenshot capture, SigLIP embeddings, visual search |

## Файловая структура

```
scripts/hooks/learning/
  experience-distiller.py          # Phase 1: batch distillation
  micro-experience-capture.py      # Phase 1: real-time micro-capture
  failure-capture.py               # Phase 2: error/retry/switch detection
  contrastive-analyzer.py          # Phase 2: success vs failure analysis
  experience-consolidator.py       # Phase 3: dedup, merge, eviction
  skill-promoter.py                # Phase 3: experience -> SKILL.md
  consolidation-scheduler.py       # Phase 3: auto-trigger every 5 sessions
  experience_search.py             # Phase 4: semantic search API
  experience-embedder.py           # Phase 4: Qdrant indexing
  index-skills-to-qdrant.py        # Phase 4: skill embeddings
  outcome-tracker.py               # Phase 5: implicit/explicit feedback
  knowledge-scorer.py              # Phase 5: EMA confidence update
  skill-health-checker.py          # Phase 5: health scores, auto-deprecation
  model-profiler.py                # Phase 6: per-model scoring
  model-transfer-tracker.py        # Phase 6: cross-model transfer
  xskill-metrics.py                # Phase 7: metrics collection
  visual_grounding_capture.py      # Phase 8: screenshot capture hook
  visual_embedder.py               # Phase 8: SigLIP/pHash embeddings
  visual_grounding_eval.py         # Phase 8: PoC evaluation

cache/experience-bank/
  experiences.jsonl                # Experience records
  failures.jsonl                   # Failure records
  outcomes.jsonl                   # Outcome tracking
  meta.json                        # Aggregate stats
  metrics.json                     # Observability metrics
  schema.json                      # JSON Schema for records
  visual-captures.jsonl            # Screenshot captures
  screenshots/                     # Stored screenshots
  archive/                         # Evicted records

Qdrant collections:
  skill_library      (75 points, 768d, nomic-embed-text)
  experience_embeddings (768d, nomic-embed-text)
  visual_grounding   (768d, SigLIP)
```
