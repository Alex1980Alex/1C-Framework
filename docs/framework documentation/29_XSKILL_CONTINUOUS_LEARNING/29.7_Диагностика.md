## Частые проблемы

### Experience Bank пуст (0 records)

**Причина:** хуки не зарегистрированы или отключены.

**Проверка:**
```bash
# Проверить hooks в settings.json
grep -c "learning" .claude/settings.json

# Проверить env-переменные
echo $FAILURE_CAPTURE_ENABLED
echo $MICRO_CAPTURE_ENABLED
```

**Решение:** убедиться что хуки прописаны в `.claude/settings.json` под `PostToolUse`, `PreCompact`, `Stop`.

### Qdrant collection пуста

**Причина:** embedder не запускался.

```bash
# Проверить Ollama
curl http://localhost:11434/api/tags

# Проверить Qdrant
curl http://localhost:6333/collections

# Запустить индексацию
python scripts/hooks/learning/experience-embedder.py --full
python scripts/hooks/learning/index-skills-to-qdrant.py
```

### Semantic search возвращает пусто

**Причина (Phase 9.1+):** TEI Docker (`pdf-rag-tei`) не запущен → fallback на token overlap → мало текстовых совпадений.

**Решение:** запустить TEI Docker:
```bash
docker compose --profile tei up -d
docker ps --filter "name=pdf-rag-tei"  # Status должен быть Up + healthy
curl -s http://localhost:8080/health    # 200 OK
```

**Legacy причина (до Phase 9.1, 2026-04-30):** Ollama не запущен → fallback на TF-IDF. Решение было `ollama pull nomic-embed-text:latest && ollama serve`. После миграции на TEI Qwen3 4096d Ollama embedding больше не используется.

### Consolidation не срабатывает

**Причина:** counter < 5 сессий.

```bash
python scripts/hooks/learning/consolidation-scheduler.py --status
# sessions_since_consolidation: 2, threshold: 5

# Принудительный запуск
python scripts/hooks/learning/consolidation-scheduler.py --force
```

### Visual embedder: "SigLIP load failed"

**Причина:** нет `sentencepiece` или `torch`.

```bash
pip install transformers torch sentencepiece Pillow
```

Или использовать pHash fallback:
```bash
pip install imagehash Pillow
python scripts/hooks/learning/visual_embedder.py --full --backend phash
```

### Skill health = 0.42 для всех skills

**Нормально** на старте. Health score = 0.42 -- базовый score для skills без outcome данных. После накопления outcomes (2-3 недели) scores дифференцируются.

## Мониторинг в production

| Что мониторить | Как | Нормальное значение |
|---------------|-----|-------------------|
| Experiences growth | `/xskill-status` -> growth_7d | >= 3/week |
| Failure rate | `/xskill-status` -> failure_rate | < 50% |
| Consolidation recency | meta.json -> last_consolidation | < 2 weeks |
| Qdrant health | `curl localhost:6333/collections` | status=green |
| Hook latency | PostToolUse hooks | < 15ms |
| Stale ratio | experiences with last_observed > 30d | < 30% |

## Зависимости

| Компонент | Обязательный | Для чего |
|-----------|-------------|---------|
| Python 3.11+ | Да | Все хуки |
| numpy | Да | TF-IDF, scoring |
| requests | Да | Ollama API |
| Qdrant (Docker) | Нет* | Semantic search (fallback: TF-IDF) |
| Ollama + nomic-embed-text (legacy, до Phase 9.1) | Нет* | Embeddings (fallback: TF-IDF) |
| transformers + torch | Нет | Phase 8: SigLIP visual embeddings |
| imagehash + Pillow | Нет | Phase 8: pHash fallback |
| sentencepiece | Нет | Phase 8: SigLIP text tokenizer |

*Система работает без Qdrant/Ollama через TF-IDF fallback, но с пониженным качеством retrieval.
