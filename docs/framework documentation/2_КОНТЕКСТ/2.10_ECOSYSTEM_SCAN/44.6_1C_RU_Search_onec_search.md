## Назначение

Стек поиска для **русскоязычного/1С-домена** (интернет + Infostart) с максимальной релевантностью —
ответ на то, что [ecosystem_scan](44.4_V2_Ecosystem_Scan.md) англоязычен и на 1С-теме даёт пусто.
Всё **free / self-host, без платных API** (ADR-040). Переиспользует приём [`engagement_rank`](44.2_Engagement_Ranking.md).
Два контура:
- **Интернет/Infostart** — `scripts/onec_search.py` (Фазы 1-4);
- **Локальный индекс 1С-доков** — усиление `POST /search/ask` через Contextual Retrieval (Фаза 5).

## Конвейер (Фазы 1-4, onec_search)

```
запрос (RU/1С)
  -> Ф3 RAG-Fusion: expand_queries (multi-query, БЕЗ LLM) -> N вариантов
  -> Ф1 SearXNG (free meta-search, Yandex+Google+Bing+DDG) на каждый вариант
  -> RRF-слияние (k=60, дедуп по url)
  -> Ф2 TEI rerank (bge-reranker-v2-m3, GPU) по ОРИГ. запросу -> top
  -> [Ф4 --engagement] Scrapling рендер Infostart -> Просмотры -> blend relevance x engagement
  -> authority×recency: final = relevance × trust(домен) × (1 + recency) [по умолчанию ВКЛ, --no-rank]
  -> Markdown / JSON бриф
```
Чистое ядро (`_rrf_fuse` / `rerank_tei`-слияние / `_parse_infostart_views` / `to_markdown`) — без сети,
юнит-тестируемо; сеть/браузер изолированы и graceful (любой источник упал -> деградация, не краш).

## Фазы

| Ф | Что | Реализация | Прирост / эффект |
|---|---|---|---|
| **1** | **SearXNG** (free RU web) | self-host meta-search, JSON API, движок **Yandex** | заменил сломанный DuckDuckGo; бесплатный RU-веб |
| **2** | **TEI reranker** | `bge-reranker-v2-m3` cross-encoder через TEI **GPU** (candle CUDA) | reranking — крупнейший единичный прирост релевантности |
| **3** | **RAG-Fusion** | `expand_queries` (reuse, БЕЗ LLM) + RRF k=60 | +19% nDCG@10, +18% MRR [arxiv 2402.03367] |
| **4** | **engagement-blend** (opt-in `--engagement`) | Scrapling DynamicFetcher рендерит Infostart (JS) -> Просмотры -> `engagement_rank.blended_score` | relevance x engagement для Infostart; ~37с/стр (рендер), top_k=5 |
| **5** | **Contextual Retrieval** (локальный индекс) | существующий `ContextGenerator` на **free-LLM**: LLM-контекст на чанк -> `contextual_content` для embedding/BM25 | -49…67% failed retrieval [anthropic]; `index --contextual` |

## Инфраструктура

**`docker/docker-compose.search.yml`** (free / self-host):
| Сервис | Порт | Назначение |
|---|---|---|
| `onec-searxng` | 8888 | SearXNG meta-search (JSON, Yandex), `searxng/settings.yml` (limiter off, formats+json) |
| `onec-tei-reranker` | 8082 | TEI **GPU** + `bge-reranker-v2-m3` (candle CUDA, БЕЗ Intel-MKL) |
| `pdf-rag-tei` (gpu.yml, profile `tei`) | 8080 | TEI-эмбеддер Qwen3-8B (для локального поиска) |

**GPU-бюджет:** эмбеддер ~16GB + reranker ~2GB = **~18GB < 24GB** — оба serving-модели уживаются.
Indexing (qwen3-st) держит весь GPU -> не совмещать с serving (остановить перед обслуживанием).

**Зависимости Ф4** (Scrapling, main venv): `pip install "scrapling[fetchers]"` (база `pip install scrapling`
неполна — нужны extras: curl_cffi/msgspec/browserforge/patchright) + `python -m playwright install chromium`.

**Запуск инфры:**
```bash
docker compose -f docker/docker-compose.search.yml up -d
docker compose -f docker/docker-compose.yml -f docker/docker-compose.gpu.yml --profile tei up -d tei
```

## Использование

```bash
python scripts/onec_search.py "направление на разгрузку заблокированных ТС" --top 10
python scripts/onec_search.py "печать ТТН снятие с хранения" --site infostart.ru --engagement
python scripts/onec_search.py "тема" --no-fusion --json
python -m src.cli index <doc> --contextual
```
Env: `SEARXNG_URL` (default `http://localhost:8888`), `TEI_RERANK_URL` (`http://localhost:8082`).

## Ключевые решения и подводные камни (live-выявлено)

- **TEI cpu-образ крэшит на AMD** (`Intel MKL SGEMM Parameter 13` на Ryzen) -> reranker на **GPU-образе** (candle CUDA). [[feedback-tei-cpu-amd-mkl-crash]]
- **Infostart engagement JS-рендерится** (нет в статичном HTML / SSR-hydration / JSON-LD / сниппетах) -> Ф4 только через браузерный рендер (Scrapling). Internal-API путь **верифицирован отсутствующим** (network-capture: 0 stats-XHR; engagement = Bitrix SSR).
- **Contextual Retrieval на free-LLM:** `ContextGenerator` уже был — включён без платного Anthropic (`context_generator` Cat-1 в llm_rotation + no-key-robust конструктор). Полный ре-индекс корпуса = операционный.
- **DuckDuckGo free-скрейп сломан** (anti-bot) -> SearXNG вместо него; web-плечо в ecosystem_scan отклонено.
