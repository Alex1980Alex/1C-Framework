# 05.6 Sandbox исполнения agent-generated кода

> **Статус (2026-05-15):** ✅ **Hermes Ф5 COMPLETE** — все 3 backend готовы (DryRun + LangSmith + E2B), 38/38 tests pass, `select_backend()` env-driven helper, skill `sandbox-execution` обновлён.

## Зачем

Когда research-агенты (`architecture-research`, `tech-research`) генерируют
прототип кода, его НЕЛЬЗЯ запускать в основном процессе — это `eval()` в
production. Sandbox изолирует:

- Файловая система (write только в `/tmp` песочницы)
- Зависимости (отдельный pip env)
- Сеть (запрещена; explicit allowlist для paid backends)
- CPU/memory (timeout 30s, soft RAM limit)

## Архитектура

```
SandboxBackend (ABC)
  ├─ DryRunBackend          ✅ zero-dep CI/no-key fallback (50-call quota)
  ├─ LangSmithBackend        ✅ Firecracker microVM (GA May 2026, langsmith[sandbox])
  └─ E2BBackend              ✅ Stateful Jupyter (e2b-code-interpreter, ~$0.10/h vCPU)
```

**Auto-selector** (`src.pdf_framework.sandbox.select_backend`):
1. `prefer="auto"` (default) → LangSmith (если `LANGSMITH_API_KEY`) → E2B (если `E2B_API_KEY`) → DryRun fallback
2. Явный выбор: `select_backend("langsmith")` / `"e2b"` / `"dryrun"`

**Уникальные фичи backends:**
- **LangSmith:** snapshots + copy-on-write forks (10 parallel branches ≈ стоимость одного), Auth Proxy (секреты не доходят до runtime), blueprints (cold-start reduction)
- **E2B:** stateful Jupyter Kernel — переменные/импорты persist между `execute` вызовами в рамках одного sandbox; pause-resume preserves state до 30 дней при $0 compute

## Когда использовать

| Use case | Backend |
|---|---|
| CI / no API key | DryRun (zero cost) |
| Local development | DryRun (zero cost) |
| Production research agent | LangSmith (когда landed) или E2B |
| Mock в unit-тестах высокоуровневого кода | DryRun |

## Quick start

```python
from src.pdf_framework.sandbox import DryRunBackend

backend = DryRunBackend()
result = await backend.execute("print('hello')")
# SandboxResult(stdout="[dry-run] code not executed", exit_code=0, ...)

# Records all calls for introspection
backend.calls  # [{"method": "execute", "args": {...}}]
```
