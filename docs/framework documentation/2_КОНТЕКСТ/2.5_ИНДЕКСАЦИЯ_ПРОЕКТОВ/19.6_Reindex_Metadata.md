## Обзор

**reindex_metadata.py** — конвейер для автоматической индексации метаданных конфигурации 1С:Предприятие в Qdrant. Экспортирует структуру объектов (справочники, документы, регистры), преобразует в эмбеддинги и сохраняет для семантического поиска.

## Архитектура конвейера

### Этап 1: Экспорт метаданных

Метаданные экспортируются через HTTP API **1c-mcp-server** (расширение MCP_Сервер):

```
POST /mcp → tools/call → get_metadata(path="/")
```

Возвращает полное дерево: справочники, документы, регистры с реквизитами и табличными частями.

### Этап 2: Парсинг в плоскую структуру

Древовидная структура преобразуется в набор **MetadataRecord**:

| Поле | Пример |
|------|--------|
| `full_path` | `Справочник.Контрагенты` |
| `object_type` | `Справочник` |
| `object_name` | `Контрагенты` |
| `synonym` | `Контрагенты` |
| `attributes` | `["ИНН", "КПП", "Наименование"]` |
| `table_parts` | `["КонтактнаяИнформация"]` |
| `description` | Автогенерация для эмбеддинга |
| `content_hash` | SHA-256 хеш записи |

### Этап 3: Инкрементальное обновление

Кеш хешей в `cache/metadata_hashes.json`:
- Вычисляется SHA-256 каждого MetadataRecord
- Сравнивается с предыдущим запуском
- Upsert только изменённых записей
- Delete удалённых объектов

### Этап 4: Загрузка в Qdrant

| Параметр | Значение |
|----------|----------|
| Коллекция | `metadata_1c` |
| Размерность | 768 |
| Метрика | Cosine |
| Модель эмбеддингов | nomic-embed-text (Ollama) |

## Использование

```bash
# Инкрементальное обновление (по умолчанию)
python scripts/reindex_metadata.py

# Полное переиндексирование
python scripts/reindex_metadata.py --full

# Превью изменений без записи
python scripts/reindex_metadata.py --dry-run
```

### Опции

| Флаг | Default | Описание |
|------|---------|----------|
| `--mcp-url` | `http://KOMPUTER/TestDB/hs/mcp/rpc` | URL MCP_Сервер |
| `--qdrant-host` | `localhost` | Хост Qdrant |
| `--qdrant-port` | `6333` | Порт Qdrant |
| `--ollama-url` | `http://localhost:11434` | URL Ollama |
| `--cache-dir` | `cache` | Директория кеша |
