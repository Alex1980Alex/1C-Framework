# 28_1.1 Auto-Reports — обзор

После каждой индексации Qdrant-коллекции или сборки графа (BSL call graph / Neo4j / graph_embeddings) фреймворк автоматически генерирует **глубокий аналитический отчёт** и складывает в `data/reports/`. Цель — нулевая ручная работа: запустил индексер → через 10-30с лежит markdown-отчёт с метриками, аномалиями и diff против прошлого ран'а.

## Когда срабатывает

Триггер — Stop-хук [`post-indexing-analyzer.py`](../../../../.claude/hooks/post-indexing-analyzer.py). На каждый Claude Code Stop он читает tail `data/indexing-progress.jsonl`, находит все новые `run_end` события (с `run_id`, отсутствующим в `.claude/cache/post-indexing-analyzer-state.json`), и спавнит [`scripts/analyze_run.py`](../../../../scripts/analyze_run.py) как **detached subprocess** для каждого нового ран'а.

Хук **не блокирует** Stop — `Popen` запускает анализатор и возвращает за <2с. Отчёт появляется через 10-30с (зависит от размера коллекции).

## Что попадает в отчёт

| Раздел | Indexing | Graph |
|--------|:--------:|:-----:|
| Run identity (PID, CLI flags) | ✓ | ✓ |
| Run end summary (files/chunks/symbols) | ✓ | ✓ |
| Stages & timing table | ✓ | ✓ |
| Discrete events log | ✓ | ✓ |
| Heartbeat gaps (idle detection) | ✓ | ✓ |
| Qdrant collection state | ✓ | partial |
| L2 norm probes | ✓ | ✓ |
| Self recall@1 sanity probe | ✓ | — |
| Dimension consistency | ✓ | — |
| Entity types distribution | — | ✓ (qdrant_graph) |
| Top-N nodes by degree | — | ✓ (neo4j/sqlite) |
| Schema integrity (orphans, dangling) | — | ✓ |
| Diff vs previous report | ✓ | ✓ |
| Auto-detected anomalies | ✓ | ✓ |

## Файлы

```
data/reports/
  indexing/
    framework_code_v1_20260522_001553.md      # основной отчёт
    framework_code_v1_20260522_001553.json    # sidecar для diff vs prev
    _latest_framework_code_v1.md              # копия последнего
  graph/
    bsl_call_graph_*.md
    neo4j_call_graph_*.md
    graph_embeddings_*.md
  index.jsonl                                  # append-only реестр всех ран'ов
  _analyzer.log                                # stdout/stderr detached subprocess'ов
```
