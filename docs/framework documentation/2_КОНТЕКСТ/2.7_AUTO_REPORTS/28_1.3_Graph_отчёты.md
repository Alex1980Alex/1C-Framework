# 38.3 Graph-отчёты

Графовый pipeline в фреймворке трёхступенчатый:

```
[build_call_graph.py]  -->  cache/bsl_call_graph.db   (SQLite, source of truth)
                                    |
                  +-----------------+------------------+
                  v                                    v
   [load_graph_to_neo4j.py]                  [build_graph_embeddings.py]
                  |                                    |
                  v                                    v
            Neo4j (bolt:7687)                  Qdrant graph_embeddings
            Module/Symbol/Object                 (entity+relation vectors)
```

Каждый артефакт может быть проанализирован независимо через [`scripts/analyze_run.py`](../../../../scripts/analyze_run.py) с флагом `--source`. Три значения: `sqlite`, `neo4j`, `qdrant_graph`.

## Sub-source: `sqlite`

Источник: `cache/bsl_call_graph.db` (выход `build_call_graph.py`). Таблицы: `module_metadata` (2 080 строк), `symbols` (33 771), `calls` (79 999).

**Метрики**:
- Counts по 4 таблицам в виде Markdown-таблицы
- **Symbols by `symbol_type`** — distribution functions/procedures/variables (top вверху)
- **Top-15 symbols by incoming call count** — наиболее часто вызываемые. Surface дубли (одинаковое имя в разных модулях)
- **Top-15 modules by symbol count** — density modules (где сконцентрирована логика)
- **Schema integrity**:
  - `modules с 0 symbols` — orphan modules (пустые или parse errors)
  - `calls с broken endpoints` — callee_name не найден в `symbols.name`. Обычно высокий (32+k) — внешние API (`УстановитьСтрокуВыборки`, `Сообщить` BSL stdlib), либо typos. Surface через `dangling_calls` anomaly

**Запуск**:
```bash
.venv\Scripts\python.exe scripts/analyze_run.py --mode graph \
  --source sqlite --db-path cache/bsl_call_graph.db
```

Если есть `--run-id <build_call_graph-...>` — добавляется секция Run identity с PID/timing.

## Sub-source: `neo4j`

Источник: `bolt://localhost:7687` (default credentials `neo4j` / `<NEO4J_PASSWORD>` — те же что в [`load_graph_to_neo4j.py`](../../../../scripts/load_graph_to_neo4j.py)).

**Метрики**:
- **Neo4j overview**: total nodes / total relationships / edges/node ratio / orphan nodes (degree=0)
- **Nodes by label**: `Symbol` (91.9%), `Module` (5.6%), `Object` (2.2%), `Community` (0.2%) — community-detection из Leiden
- **Relationships by type**: `CALLS` (79.8%), `BELONGS_TO` (10.2%), `DECLARES` (9.5%), `CONTAINS` (0.5%)
- **Top-15 nodes by degree**: hubs — `Community-0`, BSL stdlib `Добавить`, `ПодставитьПараметрыВСтроку`. Surface дубли в графе (одинаковое имя × разный elementId)
- **Orphan nodes** — анализируется отдельно (degree=0 = изоляты), surface через anomaly

**Запуск**:
```bash
.venv\Scripts\python.exe scripts/analyze_run.py --mode graph --source neo4j \
  --neo4j-uri bolt://localhost:7687 \
  --neo4j-user neo4j --neo4j-password <NEO4J_PASSWORD>
```

Cypher-запросы внутри (Neo4j 5+ syntax — `elementId(n)` вместо deprecated `id(n)`):
- `CALL db.labels()` / `CALL db.relationshipTypes()`
- `MATCH (n:<label>) RETURN count(n)`
- `MATCH (n) WITH n, size([(n)--() | 1]) AS deg ORDER BY deg DESC LIMIT 15`
- `MATCH (n) WHERE NOT (n)--() RETURN count(n)`

## Sub-source: `qdrant_graph`

Источник: Qdrant collection `graph_embeddings` (4096d Qwen3, 36 590 точек по состоянию на 2026-05-22 — entity-embeddings + relation-embeddings).

**Метрики**:
- **Collection state**: alias-aware physical name, points_count, dimension, status
- **Entity types distribution** (top-20) — по payload `entity_type` или `type`. Выявляет dominant entity categories
- **Entity vs relation split** — по payload `kind` или derived из наличия `relation_type`
- **Top sources distribution** (top-15) — откуда entity извлечены (source / source_doc)
- **L2 norm summary** — mean/std/min/max

**Запуск**:
```bash
.venv\Scripts\python.exe scripts/analyze_run.py --mode graph \
  --source qdrant_graph --qdrant-collection graph_embeddings \
  --sample-size 500
```

## Diff vs previous run

Универсальный — работает для всех трёх sub-источников. Поля diff'а:

| sub-source | Diff поля |
|-----------|-----------|
| sqlite | Δ modules, Δ symbols, Δ calls, Δ module_metadata (count + %) |
| neo4j | Δ total_nodes, Δ total_rels, Δ orphan_count |
| qdrant_graph | Δ points_count, Δ dimension, Δ L2 norm mean |

L2 norm drift >25% → autopopulated в anomalies (вероятный model swap).

## Anomalies

| Аномалия | Sub-source | Что значит |
|----------|-----------|------------|
| `N calls без matching symbol` | sqlite | Dangling endpoints — внешние API / typo. Нормально для BSL (stdlib calls не в `symbols`) |
| `N orphan nodes — изолированные модули/символы` | neo4j | Модули без связей — пустые или мёртвый код |
| `Neo4j connect error` / `Cypher error` | neo4j | Бот down / wrong credentials / schema mismatch |
| `Qdrant scroll error` | qdrant_graph | Collection corrupted / wrong dim |
| `L2 norm изменился на N%` | all qdrant | Model swap |
