# 30.1 Обзор: Эффективность команд, скиллов и MCP

Основа эффективности проекта — триада Hooks + Skills + MCP, где хуки контролируют соблюдение процессов, скиллы предоставляют проверенные решения, а MCP-серверы дают доступ к внешним данным. Кросс-обзор того, как настроена максимальная отдача от этого взаимодействия, приведен ниже. Подробное описание архитектуры триады: [13.1 Обзор триады](../13_ТРИАДА_HOOK_SKILL_MCP/13.1_Обзор.md)

## 1. Маршрутизация промптов (4 слоя подбора)

Основной роутер `skill-router.py` (событие `UserPromptSubmit`) использует каскад из 4 слоев для определения подходящего скилла:

- **Layer A**: keyword matching (32 bundles, weighted_keywords)
- **Layer B**: fuzzy matching (pymorphy3 + rapidfuzz, threshold 78)
- **Layer C**: TF-IDF scoring (numpy-only, `shared/tfidf_scorer.py`)
- **Layer D**: semantic search через Qdrant `skill_library` (768d nomic, 75 скиллов) + Ollama nomic-embed-text

Конфигурация маршрутизации хранится в `skill-router-config.json`. Скиллы распределены по 8 доменам: 1c, framework, claude-code, langchain, research, memory, llm, tools. Переменная окружения `SKILL_ROUTER_NO_SEMANTIC=1` отключает Layer D. Логирование решений Layer A/B ведется в `data/skill-router.log`.

Дополнительные роутеры `UserPromptSubmit`:
- `research-task-detector.py` — классификация задач на Architecture / 1С / Tech / Hybrid
- `decision-to-triad.py` — маршрутизация решений и идей в Фабрику триады (Q1–Q5)
- `document-persistence.py` — перехват roadmap/plan/analysis для сохранения в docs/

Подробнее: [11.3 Skill Router](../11_СИСТЕМА_СКИЛЛОВ/11.3_Skill_Router.md)

## 2. Принуждение к качеству (Enforcers)

Система Enforcers блокирует выполнение действий, не соответствующих стандартам проекта.

| Хук | Событие | Что блокирует |
|---|---|---|
| `code-skill-enforcer.py` | PreToolUse Write\|Edit\|Bash | Write/Edit без активации Skill() |
| `approval-gate.py` | PreToolUse Skill | `/implement-1c-task` без одобренного `.openspec.yaml` |
| `root-clutter-guard.py` | PreToolUse Write | `test_*`/`temp_*`/`debug_*` в корне |
| `z-ai-write-guard.py` | PreToolUse Write\|Edit | Write >15 строк кода без `llm_complete` в сессии |
| `bulk-action-guard.py` | PreToolUse Bash | bulk rm (5+ файлов) / деструктивные команды |
| `task-enforcer.py` | Stop | Stop с pending tasks в `hook-todos.json` |
| `git-commit-enforcer.py` | Stop | Stop с незакоммиченными изменениями |
| `docs-change-enforcer.py` | Stop | Код изменён без обновления docs (есть `SKIP_PATTERNS`) |

Подробнее: [09.8 Skill-First Enforcement](../09_АДМИНИСТРИРОВАНИЕ/09.8_Skill_First_Enforcement.md)

## 3. Метрики и самообучение

Для оценки и повышения точности маршрутизации собираются метрики:

- `data/skill-accuracy.jsonl` — per-prompt корреляция recommend↔activate через `prompt_id` (md5). Два источника: PostToolUse Skill и prompt-detection (workaround бага #6305 — парсинг `<command-name>` из предыдущего turn)
- `data/skill-usage.log` — логирование всех активаций скиллов
- SQLite `hook_metrics_db.py` — таблицы `hook_metrics`, `skill_activations`, `skill_accuracy` с колонкой `source`
- Dashboards: CLI `scripts/hook-dashboard.py`, HTML `/metrics/html`, Streamlit `src/ui/pages/hook_dashboard.py`

**DelegationBandit** (LinUCB) — автономная маршрутизация Z.AI-делегирования. Использует 4 arm (Soft/Medium/Hard/Never), 6-dim features, реализован на pure numpy. Состояние бандита сохраняется в `data/delegation-bandit.pkl`.

Подробнее: [11.7 Мониторинг и метрики](../11_СИСТЕМА_СКИЛЛОВ/11.7_Мониторинг_и_метрики.md)

## 4. Token Economy (делегирование на Z.AI)

Действует правило «>15 строк → делегируй», контролируемое тремя компонентами:

- `z-ai-delegation-enforcer.py` (UserPromptSubmit) — сигналит Medium/Hard для делегируемых задач
- `delegation-outcome-tracker.py` (PreToolUse Write) — записывает outcome в `delegation-outcomes.jsonl` (TensorZero формат)
- `z-ai-write-guard.py` — блокирует Write/Edit >15 строк кода без `llm_complete` в сессии

**LLM Rotation v2.0** управляет пулом из 5 провайдеров (zai-glm5, gemini, openrouter, ollama-local, ollama-cloud). Включает Circuit Breaker, AdaptiveScorer и BudgetTracker для оптимизации расходов.

Базовое правило разделения труда: **Opus = Planner/Reviewer, Z.AI = Coder**.

Ссылки: [15.1 Token Economy](../15_TOKEN_ECONOMY/15.1_Обзор.md), [21.1 LLM Rotation](../21_LLM_ROTATION/21.1_Обзор.md)

## 5. MCP-экосистема

MCP-серверы активируются через профили в `.mcp/`: `pdf.json`, `bsl.json`, `full.json`, `lazy-mcp.json`.

Ключевые серверы:
- `pdf-vector-graph` — 14 tools (search, index, graph, research)
- `1c-mcp-crud` (ACTIVE) — 17 tools через IIS `/hs/mcp/rpc` (требует публикацию базы + расширение MCP_Сервер)
- `bsl-semantic-search` — 6 tools (hybrid_search, call_graph, impact_analysis, dead_code, coding_context, object_info)
- `serena` — LSP-навигация, symbol tools, project memories
- `memory-orchestrator` — федеративный поиск (AI Memory + Vector Memory + Skill Learning)
- `openspec-mcp` (v0.4.2) — SDD workflow (propose/approve/apply)
- `lazy-mcp` — прокси для 27 on-demand серверов (11 категорий)

Ссылки: [06.4 MCP Server](../06_ИНТЕРФЕЙСЫ/06.4_MCP_Server.md), [16.5 MCP-серверы для 1С](../16_ПОДКЛЮЧЕНИЕ_1С/16.5_MCP_серверы_для_1С.md), [26. Lazy MCP](../26_LAZY_MCP/)

## 6. Межхуковая коммуникация

Взаимодействие между хуками обеспечивается через общие структуры данных:

- Общий файл `.claude/cache/hook-todos.json` (atomic writes, file lock Windows msvcrt / Unix fcntl)
- reminder-хуки добавляют tasks → Stop-enforcers читают и блокируют завершение сессии
- `SessionState` (`.claude/data/session-skills.json`) — хранит activated skills, prompt_id, LLM delegation flag, dedup
- Shared utilities: `shared/core_paths.py`, `shared/fuzzy_match.py` (pymorphy3 + rapidfuzz), `shared/semantic_search.py`, `shared/tfidf_scorer.py`

Подробнее: [13.5 Взаимодействие триады](../13_ТРИАДА_HOOK_SKILL_MCP/13.5_Взаимодействие.md)

## 7. Итог — формула эффективности

- **Маршрутизация**: 4-слойный router (keyword + fuzzy + TF-IDF + semantic) → правильный скилл с первого раза
- **Принуждение**: PreToolUse-gate'ы + Stop-enforcers → невозможно уйти без качества (skill, commit, docs)
- **Измерение**: accuracy JSONL + SQLite + 3 dashboard → полная видимость эффективности
- **Самообучение**: DelegationBandit + skill_library Qdrant → автономная адаптация системы
- **Делегирование**: Z.AI Coder + Opus Reviewer → экономия токенов без потери качества
- **Экосистема**: 21+ MCP сервер в 4 профилях → специализированные инструменты под задачу
