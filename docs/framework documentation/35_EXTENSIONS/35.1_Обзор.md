# 35.1 Extensions — Расширения и плагины

> **Статус:** Зарезервировано. Директория `src/extensions/` существует как placeholder для будущих расширений. Активного кода нет — фреймворк не импортирует из этого модуля.

## Назначение

`src/extensions/` предназначен для project-specific расширений и интеграций, которые не входят в ядро фреймворка:
- Кастомные провайдеры эмбеддингов / vector store
- Интеграции с внешними системами
- 1С-специфичные расширения

## Текущее содержимое

```
src/extensions/
└── гкс_MCPToolkit/   # git submodule — MCP инструментарий (project-specific)
```

`гкс_MCPToolkit` — submodule для 1С-проекта. Управляется через `.gitmodules`.

## Создание расширения

До реализации API расширений — используйте прямой импорт и регистрацию через `src/api/app.py`:

```python
# src/extensions/my_extension/__init__.py
from src.pdf_framework.vector_store.base import BaseVectorStore

class MyCustomStore(BaseVectorStore):
    """Custom vector store implementation."""
    ...
```

```python
# src/api/app.py — регистрация
from src.extensions.my_extension import MyCustomStore
app.state.custom_store = MyCustomStore()
```
