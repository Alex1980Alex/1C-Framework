## Назначение

Расширенный набор feature'ов wrapper'а, закрывающих implementation gap'ы выявленные после GKSTCPLK-2468 ОПЭ + research лидирующих debug-протоколов. Каждый feature шипится одновременно как:
1. Подмодуль-helper (`bp_conditions.py` / `logpoints.py` / `system_stops.py`) в `tools/bsl-debug-server/`
2. Новый MCP tool или расширение существующего
3. Unit-тесты + direct Python E2E с моками клиента
4. Live verification на ИБTransportManagementDevelop (где это архитектурно достижимо)
