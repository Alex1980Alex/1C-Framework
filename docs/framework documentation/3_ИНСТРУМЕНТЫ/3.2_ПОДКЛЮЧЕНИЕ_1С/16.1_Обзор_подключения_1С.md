# 16.1 Подключение к 1С:Предприятие — Обзор

## Назначение

Фреймворк поддерживает прямое подключение к серверным базам **1С:Предприятие 8.3** через COM-интерфейс (V83.COMConnector). Это позволяет читать метаданные конфигурации, выполнять запросы, управлять данными и анализировать структуру базы программно из Python.

## 1. Способы подключения

| Метод | Протокол | Назначение | Производительность |
| :--- | :--- | :--- | :--- |
| **COM (Основной)** | V83.COMConnector | Прямой доступ к метаданным, выполнение запросов, CRUD | Высокая (внутри LAN) |
| **RAC/RAS CLI** | TCP/IP (порт 1545) | Администрирование кластера, сессии, блокировки | Средняя (shell) |
| **REST HTTP** | OData / HTTP-сервисы 1С | Чтение данных через веб-сервер, внешние интеграции | Средняя |

## 2. Системные требования

- **ОС:** Windows 10/11 или Windows Server 2016+
- **Python:** 3.11+ (разрядность должна совпадать с 1С — 64-бит)
- **Библиотеки:** pywin32 (pip install pywin32)
- **Платформа 1С:** 8.3.27+ (установлен толстый клиент)

## 3. Архитектура подключения

```
Python Script
    |
    +-- win32com.client.Dispatch("V83.COMConnector")
    |       |
    |       +-- .Connect(conn_string)
    |       |       |
    |       |       +-- 1C Server (ragent:1540 -> rmngr:1541 -> rphost)
    |       |               |
    |       |               +-- MS SQL / PostgreSQL
    |       |
    |       +-- .ConnectAgent(host) -- для администрирования
    |
    +-- RAC CLI (rac.exe -> ras:1545 -> ragent:1540)
```

## 4. Возможности COM-подключения

### Чтение метаданных
- Структура конфигурации: справочники, документы, регистры, перечисления
- Реквизиты объектов, табличные части, типы данных
- Подсистемы, роли, общие модули

### Работа с данными
- Запросы на языке запросов 1С (SELECT, JOIN, GROUP BY)
- CRUD: создание, изменение, удаление элементов справочников и документов
- Проведение/отмена проведения документов
- Вызов экспортных процедур общих модулей

### Пример

```python
import win32com.client

connector = win32com.client.Dispatch("V83.COMConnector")
conn = connector.Connect('Srvr="localhost";Ref="TestDB";Usr="admin";Pwd="pass"')

meta = conn.Metadata
print(f"Конфигурация: {meta.Name}, версия {meta.Version}")
```

## 5. Ограничения

| Ограничение | Описание |
|-------------|----------|
| Только Windows | COM работает только на Windows |
| Разрядность | Python x64 <-> 1С x64. Смешивание 32/64 бит вызовет ошибку |
| Однопоточность | COM-объекты 1С не потокобезопасны |
| Нет UI | Доступ только к серверному контексту |
| Лицензия | Каждое COM-соединение занимает лицензию 1С |
