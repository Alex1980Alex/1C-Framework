# 16.3 Администрирование через RAC/RAS

Утилиты `rac` (клиент) и `ras` (сервер) позволяют автоматизировать администрирование кластера серверов 1С без графической консоли.

## 1. Архитектура

| Компонент | Файл | Порт | Назначение |
| :--- | :--- | :--- | :--- |
| **Агент сервера** | `ragent.exe` | 1540 | Корневой процесс, управляет менеджерами кластера |
| **Менеджер кластера** | `rmngr.exe` | 1541 | Управляет рабочими процессами, лицензиями, клиентами |
| **Сервер администрирования** | `ras.exe` | 1545 | Принимает команды от `rac`, транслирует в API кластера |
| **Клиент администрирования** | `rac.exe` | — | Консольная утилита для отправки команд |

> `rac` подключается к `ras` (порт 1545), который общается с `ragent` (порт 1540).

## 2. Запуск RAS

### Интерактивный режим
```bash
"C:\Program Files\1cv8\8.3.27.1859\bin\ras.exe" cluster --port=1545 localhost:1540
```

### Установка как служба Windows
```bash
sc create "1C:Enterprise RAS" binPath= "\"C:\Program Files\1cv8\8.3.27.1859\bin\ras.exe\" cluster --port=1545 localhost:1540" start= auto
sc start "1C:Enterprise RAS"
```

## 3. Команды RAC

Общий формат: `rac.exe <команда> [параметры] localhost:1545`

### Кластеры
```bash
# Список кластеров (получаем cluster UUID)
rac cluster list localhost:1545
```

### Информационные базы

```bash
# Список баз
rac infobase summary list --cluster=<UUID> localhost:1545

# Создание базы (MS SQL)
rac infobase create --cluster=<UUID> ^
  --create-database ^
  --name="MyDB" ^
  --dbms=MSSQLServer ^
  --db-server=localhost ^
  --db-name=mydb1c ^
  --db-user=usr1cv8 ^
  --db-pwd="1980" ^
  --locale=ru ^
  localhost:1545

# Обновление параметров базы
rac infobase update --cluster=<UUID> --infobase=<IB_UUID> ^
  --db-user=usr1cv8 --db-pwd="new_pass" ^
  localhost:1545

# Блокировка сеансов
rac infobase update --cluster=<UUID> --infobase=<IB_UUID> ^
  --sessions-deny=on --denied-message="Техработы" ^
  localhost:1545
```

### Сессии

```bash
# Список активных сессий
rac session list --cluster=<UUID> localhost:1545

# Сессии конкретной базы
rac session list --cluster=<UUID> --infobase=<IB_UUID> localhost:1545

# Завершение сессии
rac session terminate --cluster=<UUID> --session=<SID> localhost:1545
```

### Соединения

```bash
# Список соединений
rac connection list --cluster=<UUID> localhost:1545

# Отключение соединения
rac connection disconnect --cluster=<UUID> --connection=<CID> localhost:1545
```

## 4. Примеры автоматизации

### PowerShell: подсчёт активных сессий

```powershell
$rac = "C:\Program Files\1cv8\8.3.27.1859\bin\rac.exe"
$cluster = (& $rac cluster list localhost:1545 | Select-String "cluster" | ForEach-Object {
    ($_ -split ": ")[1].Trim()
})

$sessions = & $rac session list --cluster=$cluster localhost:1545
$count = ($sessions | Select-String "session :").Count
Write-Host "Активных сессий: $count"
```

### Bash: список баз

```bash
RAC="C:/Program Files/1cv8/8.3.27.1859/bin/rac.exe"
CLUSTER=$("$RAC" cluster list localhost:1545 | grep "cluster" | awk -F': ' '{print $2}')
"$RAC" infobase summary list --cluster=$CLUSTER localhost:1545
```

## 5. Мониторинг

| Команда | Что показывает |
|---------|---------------|
| `session list` | Активные пользователи, время начала, приложение |
| `lock list` | Блокировки объектов (кем, что, когда) |
| `process list` | Рабочие процессы rphost: память, CPU, порт |
| `connection list` | Сетевые соединения к кластеру |
