# 26.1. Lazy-MCP — Обзор

## Назначение

**Lazy-MCP** — это прокси-сервер для динамической загрузки MCP-инструментов по требованию. Решает ключевую проблему масштабирования: вместо загрузки всех MCP-серверов одновременно (100k+ токенов описаний инструментов), экспонирует Claude Code всего **3 мета-инструмента** и запускает реальные серверы только при обращении.

**Результат: ~100k токенов → ~5k токенов (экономия 95%)**

## Расположение

```
infra/lazy-mcp/
├── src/
│   ├── server.py              # Точка входа MCP-сервера
│   ├── registry.py            # Реестр серверов и категорий
│   ├── loader.py              # Динамический загрузчик (LRU pool)
│   ├── tool_interceptor.py    # Маршрутизация A/B/C через Z.AI
│   ├── server_wrapper.py      # Debug-обёртка с логированием
│   └── __init__.py
├── config/
│   └── registry.yaml          # Конфигурация 22 серверов в 10 категориях
├── .venv/                     # Изолированное Python-окружение
├── requirements.txt           # mcp>=1.0.0, pyyaml>=6.0
├── start-lazy-mcp.bat         # Startup-скрипт
├── README.md
└── ROADMAP.md
```

## Три мета-инструмента

| Инструмент | Назначение | Пример |
|---|---|---|
| `recommend_tools(task_description)` | Умная рекомендация на основе описания задачи | `"найди процедуры в BSL"` → `/1c-development/ast-grep-mcp` |
| `get_tools_in_category(path)` | Иерархическая навигация по каталогу | `/1c-development` → список серверов |
| `execute_tool(tool_path, arguments)` | Динамическое выполнение любого инструмента | `/1c-development/ast-grep-mcp/ast_grep` с аргументами |

## Ключевые характеристики

| Метрика | Значение |
|---|---|
| Экономия токенов | ~95% (100k → 5k) |
| Активных серверов в пуле | max 5 (LRU eviction) |
| Задержка первого вызова | 1-3 секунды (запуск сервера) |
| Задержка последующих | <500мс (из пула) |
| Зарегистрировано серверов | 22 в 10 категориях |
| Протокол | JSON-RPC 2.0 over stdio |

## Подключение

Lazy-MCP подключается к Claude Code через MCP-профиль `.mcp/lazy-mcp.json`:

```json
{
  "mcpServers": {
    "lazy-mcp": {
      "command": "C:\\1С-Framework\\infra\\lazy-mcp\\.venv\\Scripts\\python.exe",
      "args": ["src/server.py"],
      "cwd": "C:\\1С-Framework\\infra\\lazy-mcp",
      "env": {
        "PYTHONIOENCODING": "utf-8",
        "LAZY_MCP_CONFIG": "C:\\1С-Framework\\infra\\lazy-mcp\\config\\registry.yaml"
      },
      "timeout": 30000
    }
  }
}
```

Запуск с профилем:

```bash
claude --mcp-config .mcp/lazy-mcp.json
```
