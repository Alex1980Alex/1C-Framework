# 26.4. Lazy-MCP — Tool Interceptor

## Назначение

**Tool Interceptor** (`src/tool_interceptor.py`) — система автоматической маршрутизации MCP tool calls. Классифицирует каждый инструмент по категории A/B/C и направляет вызов через оптимальный провайдер (Z.AI или прямое выполнение).

## Категории инструментов

| Категория | Маршрутизация | Описание | Примеры |
|---|---|---|---|
| **A** (100% Z.AI) | `ZAI_ONLY` | Детерминированные операции, результат не требует проверки | AST-анализ, поиск в памяти, файловый grep |
| **B** (70-90% Z.AI) | `ZAI_WITH_VALIDATION` | Требуют проверки результата Claude | RAG-ответы, генерация документации |
| **C** (0% Z.AI) | `CLAUDE_ONLY` | Сложный reasoning, архитектура — только Claude | Sequential thinking, MCTS, code review |

## Алгоритм маршрутизации

```
intercept(server_name, tool_name, args)
    │
    ├─ 1. Классификация: classify_tool() → ToolCategory
    │     ├─ server ∈ CATEGORY_A_SERVERS? → A
    │     ├─ server ∈ CATEGORY_C_SERVERS? → C
    │     ├─ tool ∈ TOOL_CLASSIFICATION[server]? → explicit
    │     ├─ "*" wildcard? → default for server
    │     └─ default → A (большинство MCP ops детерминированные)
    │
    ├─ 2. Проверка кэша (Category A only)
    │     cache_key = f"{server}:{tool}:{sorted_args}"
    │     if cached && TTL valid → return (provider: "cache")
    │
    ├─ 3. Category C → не перехватываем
    │     return InterceptResult(intercepted=False, provider="claude")
    │
    ├─ 4. Попытка Z.AI
    │     ├─ Z.AI доступен? → execute via Z.AI
    │     │   ├─ Category A → return result + cache
    │     │   └─ Category B → return zai_result + needs_validation
    │     └─ Z.AI недоступен? → fallback to direct execution
    │
    └─ 5. Direct fallback
          loader.execute_tool(server, tool, args)
          return result (provider: "direct_fallback")
```

## InterceptResult

```python
@dataclass
class InterceptResult:
    intercepted: bool        # Успешно ли перехвачен
    category: ToolCategory   # A/B/C
    decision: RoutingDecision  # ZAI_ONLY/ZAI_WITH_VALIDATION/CLAUDE_ONLY
    result: Any              # Результат выполнения
    error: Optional[str]     # Ошибка если есть
    latency_ms: int          # Задержка в мс
    provider: str            # zai | cache | direct_fallback | claude
```

## Кеширование

| Параметр | Значение |
|---|---|
| Стратегия | In-memory TTL cache |
| TTL | 300 секунд (5 минут) |
| Область | Только Category A |
| Ключ | `server:tool:sorted_json_args` |
| Hit rate | ~30% (типичные повторные запросы) |
