# 26.5. Lazy-MCP — Использование

## Быстрый старт

### Запуск с профилем

```bash
claude --mcp-config .mcp/lazy-mcp.json
```

### Ручной запуск (для отладки)

```bash
cd C:\1С-Framework\infra\lazy-mcp
.venv\Scripts\python.exe src\server.py
```

Или через startup-скрипт:

```cmd
start-lazy-mcp.bat
```

## Паттерны использования

### Паттерн 1: Автоматический (рекомендуемый)

Claude вызывает `recommend_tools` с описанием задачи → получает рекомендацию → вызывает `execute_tool`.

```
User: "Найди все процедуры в BSL коде"

Claude:
1. recommend_tools("найди все процедуры в BSL коде")
   → {
       "recommendations": [{
         "category": "1c-development",
         "score": 4,
         "matched_keywords": ["BSL", "процедура"],
         "suggested_tool": {
           "path": "/1c-development/ast-grep-mcp/ast_grep",
           "hint": "pattern='Процедура $NAME($$$PARAMS)', language='bsl'"
         }
       }],
       "quick_action": {
         "message": "🎯 Рекомендую категорию '1c-development'",
         "tool_path": "/1c-development/ast-grep-mcp/ast_grep"
       }
     }

2. execute_tool("/1c-development/ast-grep-mcp/ast_grep", {
     "pattern": "Процедура $NAME($$$PARAMS)",
     "language": "bsl"
   })
   → {результаты AST-поиска}
```

### Паттерн 2: Навигация по каталогу (ручной)

Пошаговое исследование доступных инструментов.

```
# Шаг 1: Список категорий
get_tools_in_category("/")
→ ["1c-development", "documentation", "memory", "learning",
   "file-operations", "reasoning", "web", "browser", "utils"]

# Шаг 2: Серверы в категории
get_tools_in_category("/1c-development")
→ ["ast-grep-mcp", "bsl-platform-context", "bsl-semantic-search",
   "bsl-debugger", "bsl-semantic-diff"]

# Шаг 3: Инструменты сервера (запускает сервер!)
get_tools_in_category("/1c-development/ast-grep-mcp")
→ [
     {"name": "ast_grep", "description": "...", "full_path": "/1c-development/ast-grep-mcp/ast_grep"},
     {"name": "get_module_ast", "description": "...", "full_path": "..."}
   ]

# Шаг 4: Выполнение
execute_tool("/1c-development/ast-grep-mcp/ast_grep", { ... })
```

### Паттерн 3: Прямой вызов (если путь известен)

Если вы знаете полный путь к инструменту — вызывайте напрямую.

```
execute_tool("/memory/memory-ai/save_important_message", {
  "content": "Важная заметка",
  "importance": 0.8,
  "category": "project"
})
```

## Рекомендации по категориям

### 1c-development

**Ключевые слова:** BSL, 1С, 1C, процедура, функция, модуль, конфигурация, справочник, документ, регистр

**Типичные задачи:**
- AST-анализ BSL кода → `/1c-development/ast-grep-mcp/ast_grep`
- API платформы 1С → `/1c-development/bsl-platform-context/search`
- Семантический поиск по коду → `/1c-development/bsl-semantic-search/bsl_hybrid_search`

### documentation

**Ключевые слова:** документация, docs, RAG, autodocument, best practices

**Типичные задачи:**
- Поиск в документации → `/documentation/1c-docs-rag/search_docs`

### memory

**Ключевые слова:** память, memory, контекст, запомни, вспомни, knowledge graph

**Типичные задачи:**
- Сохранить контекст → `/memory/unified-memory/save_memory`
- Поиск в памяти → `/memory/memory-ai/search_messages`

### file-operations

**Ключевые слова:** файл, grep, search, read, write, директория

**Типичные задачи:**
- Regex-поиск → `/file-operations/ripgrep/search`
- Файловые операции → `/file-operations/filesystem/read_file`

### reasoning

**Ключевые слова:** думай, think, step by step, сложная задача

**Типичные задачи:**
- Пошаговый анализ → `/reasoning/sequential-thinking/sequentialthinking`
- MCTS-рассуждения → `/reasoning/reasoner/mcts_search`

### web

**Ключевые слова:** веб, HTTP, API, браузер, fetch, scrape

**Типичные задачи:**
- Веб-поиск → `/web/brave/brave_web_search`
- Браузер → `/web/puppeteer/navigate`

## LRU Pool

### Поведение пула

| Параметр | Значение |
|---|---|
| Максимум активных серверов | 5 |
| Стратегия вытеснения | LRU (Least Recently Used) |
| Проверка здоровья | `process.poll()` при каждом обращении |
| Перезапуск мёртвых | Автоматический |

### Пример LRU-цикла

```
Вызовы:
1. ast-grep-mcp      → старт, pool: [ast-grep]
2. ast-grep-mcp      → из пула, pool: [ast-grep] (move_to_end)
3. 1c-docs-rag       → старт, pool: [ast-grep, 1c-docs-rag]
4. memory-ai         → старт, pool: [ast-grep, 1c-docs-rag, memory-ai]
5. brave             → старт, pool: [ast-grep, 1c-docs-rag, memory-ai, brave]
6. serena            → старт, pool: [ast-grep, 1c-docs-rag, memory-ai, brave, serena]
7. ast-grep-mcp      → из пула (move_to_end), pool: [1c-docs-rag, memory-ai, brave, serena, ast-grep]
8. ripgrep           → LRU evict 1c-docs-rag → старт, pool: [memory-ai, brave, serena, ast-grep, ripgrep]
```

## Настройка окружения

### Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `LAZY_MCP_CONFIG` | `config/registry.yaml` | Путь к конфигурации реестра |
| `LAZY_MCP_METRICS_PATH` | `cache/metrics/lazy-mcp-routing.json` | Путь к файлу метрик |
| `PYTHONIOENCODING` | `utf-8` | Кодировка I/O |
| `PYTHONUNBUFFERED` | `1` | Отключение буферизации stdout |

### Требования к системе

| Компонент | Версия | Примечание |
|---|---|---|
| Python | 3.10+ | Для lazy-mcp сервера |
| Node.js / NPX | 18+ | Для npx-серверов |
| Java | 17+ (Zulu) | Для bsl-platform-context |
| Docker | 20+ | Опционально, для docker-mcp |
