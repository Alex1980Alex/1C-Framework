# 35.1 Extensions — Расширения и плагины

> **Статус (проверено аудитом 2026-07-04):** концептуальная глава-задел. Каталога
> `src/extensions/` в репозитории **нет**, формализованного plugin-API тоже нет —
> кастомные расширения сейчас регистрируются прямым импортом (см. ниже). Раздел
> сохранён как описание намеченной точки расширения.

## Назначение

Точка расширения для project-specific интеграций, которые не входят в ядро фреймворка:
- Кастомные провайдеры эмбеддингов / vector store
- Интеграции с внешними системами
- 1С-специфичные расширения

## Текущее содержимое

Каталога `src/extensions/` **нет** (и записи в `.gitmodules` для него нет).
Ранее здесь предполагался submodule `гкс_MCPToolkit` — этот путь **отменён**:
инструментарий MCPToolkit **deprecated** и полностью заменён расширением
`MCP_Сервер` (сервер `1c-mcp-crud`), исходники которого живут в
[`src/bsl/mcp_integration/`](../../../../src/bsl/mcp_integration/README.md) —
см. [16.5 MCP-серверы для 1С](../3.2_ПОДКЛЮЧЕНИЕ_1С/16.5_MCP_серверы_для_1С.md).

## Создание расширения

До реализации API расширений — используйте прямой импорт и регистрацию через `src/api/app.py`:

```python
# src/extensions/my_extension/__init__.py
from src.pdf_framework.vector_store.base import BaseVectorStore

class MyCustomStore(BaseVectorStore):
    """Custom vector store implementation."""
    ...
```

```python
# src/api/app.py — регистрация
from src.extensions.my_extension import MyCustomStore
app.state.custom_store = MyCustomStore()
```
