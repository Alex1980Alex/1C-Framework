## Назначение

Локальная транскрибация (ASR) аудио/видео в текст — записи встреч (Яндекс Телемост / Zoom), голосовые
заметки, видео-демонстрации. Русский + multi-язык, **полностью на машине** (приватно — для внутренних встреч),
бесплатно, с GPU-ускорением. Модель — **Whisper large-v3** (или `large-v3-turbo`).

**Триггеры:** «транскрибируй», «расшифруй запись/встречу», «speech-to-text», «whisper», «субтитры из видео»,
«текст из mp3/webm».

НЕ для раскадровки видео по кадрам (→ [гл.47 scene-detect](../3.6_SCENE_DETECT_MCP/47.1_Обзор.md)). НЕ для
эмбеддингов/поиска (→ [гл.31](../../2_КОНТЕКСТ/2.8_QWEN3_RETRIEVAL_PRODUCTION/31.1_Обзор.md)).

## Два движка (выбор)

| | **whisper.cpp** (установлено) | **faster-whisper** |
|---|---|---|
| GPU | **Vulkan** (NVIDIA/AMD/Intel, prebuilt, без CUDA SDK) | CUDA (нужны cuBLAS+cuDNN) |
| Формат модели | **GGML** (`ggerganov/whisper.cpp`) | CTranslate2 (`Systran/faster-whisper-*`) |
| Поставка | как **MCP-сервер** (звать из чата) | Python-библиотека (скрипт) |
| Когда | постоянный инструмент, любой GPU, минимум CUDA-возни | Python-пайплайн, NVIDIA, max-скорость |

В этом фреймворке выбран и установлен **whisper.cpp + Vulkan как MCP** (приватность + один инструмент из чата +
GPU без CUDA-зависимостей). faster-whisper описан ниже как альтернатива.

## Установленный вариант — `whisper` MCP (whisper.cpp Vulkan)

Компоненты (Windows, RTX 3090):
- **npm-пакет** `whisper-windows-mcp@2.3.0` (глобально; Node ≥18). Бинарь НЕ несёт.
- **Бинарь Vulkan** (release v1.4.0 `whisper-vulkan-win-x64.zip`) → `C:\whisper\Release\` (`whisper-cli.exe`,
  `ggml-vulkan.dll` 57 МБ, `whisper.dll`, `ggml*.dll`). Видит RTX 3090 (device 0, fp16, NV_coopmat2).
- **Модели** `C:\whisper\models\`: `ggml-large-v3-turbo.bin` (1.6 ГБ, дефолт) + `ggml-large-v3.bin` (2.9 ГБ,
  макс. качество). Источник — `huggingface.co/ggerganov/whisper.cpp`.
- **ffmpeg** (Gyan.FFmpeg, `winget install`) в user PATH — для видео/не-(wav/mp3/flac/ogg).

Запись в [`.mcp.json`](../../../../.mcp.json) (`.mcp.json` локальный, в git не версионируется):
```json
"whisper": {
  "command": "npx",
  "args": ["-y", "whisper-windows-mcp"],
  "env": {
    "WHISPER_CLI_PATH": "C:\\whisper\\Release\\whisper-cli.exe",
    "WHISPER_MODEL": "C:\\whisper\\models\\ggml-large-v3-turbo.bin",
    "WHISPER_CONSENT_ACKNOWLEDGED": "true"
  },
  "timeout": 120000
}
```
> После правки `.mcp.json` — **полный рестарт Claude Code** (не `/mcp reconnect` — он не перечитывает конфиг серверов).

**Privacy-гейт сервера (важно, 2026-07-25).** `whisper-windows-mcp` перед КАЖДЫМ возвратом текста
требует явного подтверждения пользователя (аудио остаётся локально всегда; вопрос — про передачу
транскрипта в API). Управление:
- `WHISPER_CONSENT_ACKNOWLEDGED=true` в env (выше) — постоянное согласие для нечувствительного контента;
- `privacy_mode=true` per-call — транскрипт только в локальный файл, в API не уходит (подтверждение
  при этом всё равно запрашивается, если не снято env-переменной);
- для регулируемых записей (медицина/юр./перс. данные) гейт снимать НЕ следует.

**MCP-инструменты:** `transcribe_audio` (по пути к файлу), `start_batch`/`transcribe_batch` (пачкой),
`generate_subtitles` (SRT/VTT), `check_system` (GPU/Vulkan), `list_models`/`switch_model`/`download_model`,
`check_progress`. GPU (Vulkan, device 0) и модель из `WHISPER_MODEL` берутся автоматически.

## Производительность (замеры на RTX 3090, аудио ~5:06 / 306 с)

| Движок / модель | Устройство | Время |
|---|---|---|
| faster-whisper int8 | CPU | 209 с |
| whisper.cpp large-v3 | RTX 3090 (Vulkan) | 37.9 с |
| **whisper.cpp large-v3-turbo** | **RTX 3090 (Vulkan)** | **6.8 с** (~45× realtime) |

Качество turbo ≈ full large-v3 (на реальной RU-встрече текст совпал). Дефолт — turbo; для максимума качества
переключиться на large-v3 (`switch_model` или env `WHISPER_MODEL`).

## Форматы и видео
- Аудио **wav/mp3/flac/ogg** — нативно, **без ffmpeg**.
- Видео (**.webm/.mp4/.mkv…**) и прочее аудио — авто-конверт через **ffmpeg** (в PATH).
- Совет: если рядом с видео есть готовая `.mp3`-дорожка — скармливать её (быстрее, без конверта).

## Альтернатива — faster-whisper на CUDA (Python)

Если нужен Python-пайплайн на NVIDIA. Драйвер NVIDIA НЕ содержит cuBLAS/cuDNN — ставятся pip-колёсами (toolkit
не нужен; ct2 4.x = CUDA 12 / cuDNN 9):
```
pip install faster-whisper nvidia-cublas-cu12 "nvidia-cudnn-cu12==9.*"
```
**Windows-нюанс:** Python 3.8+ не ищет зависимые DLL в PATH → перед `from faster_whisper import WhisperModel`:
```python
import os, glob, sys
for d in glob.glob(os.path.join(sys.prefix, "Lib", "site-packages", "nvidia", "*", "bin")):
    os.add_dll_directory(d)
```
Затем `WhisperModel("large-v3", device="cuda", compute_type="float16")`; fallback `device="cpu", compute_type="int8"`.

## Диагностика (живые грабли)

| Симптом | Причина | Решение |
|---|---|---|
| HF-загрузчик `huggingface_hub` виснет на 0 байт (большой blob) | Xet/hf_transfer backend; мелкие конфиги качаются, модель — нет | качать модель **через curl** (`-L -C - --retry`); сеть здорова (~4 МБ/с) |
| `cublas64_12.dll not found` при `device=cuda` (faster-whisper) | нет cuBLAS/cuDNN (их нет в драйвере) | pip-колёса + `os.add_dll_directory` (см. выше) |
| `nvidia-smi` «CUDA Version 13.2», а CUDA «нет» | это max версия драйвера, НЕ установленный toolkit | toolkit не нужен — pip-колёса CUDA 12 |
| MCP `whisper` не появился после правки `.mcp.json` | `/mcp reconnect` не перечитывает конфиг | **полный рестарт Claude Code** |
| Видео не транскрибируется | нет ffmpeg в PATH | `winget install Gyan.FFmpeg` (рестарт shell) или env `FFMPEG_PATH` |

GGML (whisper.cpp) и CTranslate2 (faster-whisper) — **разные форматы**, не взаимозаменяемы; качать под свой движок.
