# 40.1 PR Automation — обзор

> Sister-документ к [39_LANGFUSE](../39_LANGFUSE/39.1_Обзор.md). См. cache: [`github-pr-automation-2026.md`](../../../.claude/skills/architecture-research/cache/github-pr-automation-2026.md).

## Что это

Группа Claude Code hooks + pre-commit + `gh` CLI, которые автоматизируют **полный git-workflow**: от inline auto-save до per-task branch + push + PR + auto-merge. Состоит из 3 уровней:

1. **Edit-time** — `auto-git-save.py` коммитит каждые N файлов
2. **Stop-time** — `git-commit-enforcer.py` блокирует Stop при uncommitted changes
3. **Task-time** — `post-task-push-pr.py` (новейший, opt-in) — на TaskUpdate(completed) детачит branch + push + `gh pr create` + опц. auto-merge

Все 12 файлов в `.claude/hooks/` упоминают git/commit. Среди них основные:

| Файл | Уровень | Назначение |
|------|---------|------------|
| [`auto-git-save.py`](../../../.claude/hooks/auto-git-save.py) | Edit-time | PostToolUse Write/Edit/Bash: трекает изменённые файлы, sync commit при threshold |
| [`auto-git-save-prompt.py`](../../../.claude/hooks/auto-git-save-prompt.py) | UserPromptSubmit | Прерывает спам auto-save при множественных user prompts |
| [`posttooluse-auto-git-save.py`](../../../.claude/hooks/posttooluse-auto-git-save.py) | PostToolUse | Альтернативный trigger вариант |
| [`shared/auto_save_core.py`](../../../.claude/hooks/shared/auto_save_core.py) | Shared | Core logic для всех auto-git-save вариантов |
| [`git-commit-enforcer.py`](../../../.claude/hooks/git-commit-enforcer.py) | Stop | Блокирует Stop event если есть uncommitted в watched paths |
| [`post-task-push-pr.py`](../../../.claude/hooks/post-task-push-pr.py) | PostToolUse:TaskUpdate | **NEW** (2026-05-22) — branch + push + PR + optional auto-merge |
| [`docs-change-enforcer.py`](../../../.claude/hooks/docs-change-enforcer.py) | Stop | Блокирует Stop если код изменён без обновления docs (CODE_TO_DOMAIN mapping) |
| [`docs-change-tracker.py`](../../../.claude/hooks/docs-change-tracker.py) | PostToolUse | Трекинг docs-need для enforcer'а |
| [`task-enforcer.py`](../../../.claude/hooks/task-enforcer.py) | Stop | Блокирует Stop если pending mandatory tasks |
| [`shared/task_master.py`](../../../.claude/hooks/shared/task_master.py) | Shared | Task tracking primitives для всех enforcer'ов |

Плюс **pre-commit gates** (`.pre-commit-config.yaml`): ruff lint/format, mypy, gitleaks, markdownlint, kb-lint — все запускаются перед commit (включая auto-saves).

## Use cases

- **Никогда не теряем работу**: каждые 3 изменения = sync commit. Crash безопасен.
- **Чистая история**: pre-commit gates режут broken code на этапе commit, не push.
- **No "забыл закоммитить"**: git-commit-enforcer = Stop block.
- **Per-task workflow** (новое): task done → автоматический branch + PR. Reviewer видит per-feature diff, можно selective merge.
- **Docs всегда в sync с кодом**: docs-change-enforcer maps code paths → doc chapters → блок Stop если drift.

## Архитектура (high-level)

```
┌─ Edit-time (Write/Edit) ──────────────────────────────────────┐
│ auto-git-save.py                                              │
│   ├─ track changed file in .claude/cache/auto-git-save.json   │
│   ├─ threshold (3 files default) reached?                     │
│   │    YES → git add + git commit -m "chore: auto-save ..."   │
│   │    NO  → create mandatory task in hook-todos.json         │
│   └─ pre-commit hooks run on commit (ruff/mypy/gitleaks/...)  │
└────────────────────────────────────────────────────────────────┘

┌─ Task-time (TaskUpdate completed) ───── opt-in via AUTO_PR_ENABLED ─┐
│ post-task-push-pr.py (PostToolUse:TaskUpdate)                       │
│   ├─ check AUTO_PR_ENABLED=1 + commits_ahead(base) >= threshold     │
│   ├─ run pre-push tests (shlex + shell=False)                       │
│   ├─ git branch -f task/<id>-<slug> HEAD     (no checkout)          │
│   ├─ git push -u origin task/...                                    │
│   ├─ gh pr create --base $AUTO_PR_BASE --head task/... --title ... │
│   ├─ if AUTO_PR_AUTO_MERGE=1 → gh pr merge --squash --delete-branch │
│   └─ emit systemMessage с PR URL                                    │
└──────────────────────────────────────────────────────────────────────┘

┌─ Stop-time (Claude attempts Stop) ───────────────────────────┐
│ git-commit-enforcer.py                                       │
│   └─ if uncommitted in src/ docs/ tests/ .claude/{skills,hooks}/ │
│         → exit 2 (BLOCK STOP)                                │
│ docs-change-enforcer.py                                      │
│   └─ if code changed but docs not (per CODE_TO_DOMAIN map)   │
│         → systemMessage "обнови docs/N_DOMAIN/"              │
│ task-enforcer.py                                             │
│   └─ if pending mandatory tasks → systemMessage              │
└───────────────────────────────────────────────────────────────┘
```

## Когда работает

Все хуки активны по умолчанию (зарегистрированы в `.claude/settings.json`). `post-task-push-pr.py` — единственный **opt-in** через env var `AUTO_PR_ENABLED=1`. Остальные включены always.
