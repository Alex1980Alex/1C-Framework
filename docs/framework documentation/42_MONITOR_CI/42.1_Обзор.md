# 42.1 Monitor CI — Обзор

Realtime watcher состояния CI / PR / bot reviews / Security advisories через `Monitor` background tool.

## Зачем

Без Monitor пользователь должен **руками** проверять `gh pr view`, открывать GitHub Notifications, читать почту. Monitor делает это **автоматически** и оповещает Claude в чате на каждое значимое изменение (push, CI completion, bot review, security alert).

## Что покрывается

| Источник | Метод | Cadence |
|---|---|---|
| CI gates на open PRs (priority-tagged P0-P3) | `gh pr list --json statusCheckRollup` + jq tag | 20s |
| Workflow RUN-FAIL all branches | `gh run list --status failure --limit 8` | 20s |
| Bot reviews (gemini-code-assist) | `gh pr view --comments` | 20s |
| Dependabot PR'ы | `gh pr list --label dependencies` | 20s |
| Security advisories (CodeQL severity=error) | `gh api .../code-scanning/alerts` | 20s |
| Cost Baseline weekly run | `gh run list --workflow "Cost Baseline (weekly)"` | 45s |

**Priority badges** (added 2026-05-26 Phase 1): `[P0-master]` для master CI fails / `[P1-PR]` для open PR events / `[P2-dependabot]` для Dependabot workflows / `[P3-security]` для CodeQL alerts. Easier triage в шумном stream.

**Auto-cache integration** (Phase 1): на каждый `RUN-FAIL[...]` Monitor автоматически invokes `python scripts/ci_failure_cache.py --run-id N` → JSONL append + Qdrant upsert + auto-issue на N≥3 recurrences. См. [42.4 Failure Caching](42.4_Failure_Caching.md).

**SessionStart auto-summary** (Phase 2): при старте Claude сессии hook [`gh-notif-intake-on-start.py`](../../../.claude/hooks/gh-notif-intake-on-start.py) emit'ит сводку unread GH notifications (`[GH-NOTIF] N unread (cat=X, ...)`). См. [42.5 GitHub Notifications Intake](42.5_GH_Notifications_Intake.md).

**`claude.yml` workflow disabled** (2026-05-26, PR #57): Anthropic API account credit exhausted, файл переименован в `claude.yml.disabled`. Бот-ревью покрывает gemini-code-assist (бесплатно). Reversibility: rename back + rotate API key.

## Архитектура

Monitor — это long-running bash `while true` loop, который:
1. Запрашивает текущее состояние из gh CLI / gh api
2. Сравнивает с предыдущим snapshot через `comm -13`
3. Emit'ит ТОЛЬКО **delta** (новые / изменённые events) в stdout
4. Claude получает notification по каждой stdout строке

См. [42.2 Архитектура](42.2_Архитектура.md).
