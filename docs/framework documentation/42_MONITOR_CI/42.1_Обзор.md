# 42.1 Monitor CI — Обзор

Realtime watcher состояния CI / PR / bot reviews / Security advisories через `Monitor` background tool.

## Зачем

Без Monitor пользователь должен **руками** проверять `gh pr view`, открывать GitHub Notifications, читать почту. Monitor делает это **автоматически** и оповещает Claude в чате на каждое значимое изменение (push, CI completion, bot review, security alert).

## Что покрывается

| Источник | Метод | Cadence |
|---|---|---|
| CI gates на open PRs | `gh pr list --json statusCheckRollup` | 15s |
| Workflow runs all branches | `gh run list --limit 8` | 15s |
| Bot reviews (gemini, claude.yml) | `gh pr view --comments` | 15s |
| Dependabot PR'ы | `gh pr list --label dependencies` | 15s |
| Security advisories (CodeQL) | `gh api .../code-scanning/alerts` | 15s |
| Cost Baseline weekly run | `gh run list --workflow "Cost Baseline (weekly)"` | 45s |

## Архитектура

Monitor — это long-running bash `while true` loop, который:
1. Запрашивает текущее состояние из gh CLI / gh api
2. Сравнивает с предыдущим snapshot через `comm -13`
3. Emit'ит ТОЛЬКО **delta** (новые / изменённые events) в stdout
4. Claude получает notification по каждой stdout строке

См. [42.2 Архитектура](42.2_Архитектура.md).
