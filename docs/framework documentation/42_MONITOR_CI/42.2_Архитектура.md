# 42.2 Архитектура Monitor

Polling loop + delta-detection + stdout notification.

## Pipeline

```
[bash while loop]
   │
   ├─► gh pr list ─► statusCheckRollup (JSON) ─┐
   ├─► gh run list ─► workflowName/conclusion ─┤
   ├─► gh api code-scanning/alerts ────────────┤
   └─► gh pr view --comments ──────────────────┤
                                               ▼
                                        [merge + sort -u]
                                               │
                                               ▼
                                          /tmp/cur.txt
                                               │
                                       comm -13 prev cur
                                               │
                                               ▼
                                    [NEW events only]
                                               │
                                               ▼
                                          stdout
                                               │
                                               ▼
                                  Claude Code notification
                                               │
                                               ▼
                                       prev = cur, sleep 15
```

## Ключевые свойства

| Property | Implementation |
|---|---|
| **Delta-only emission** | `comm -13 prev cur` показывает строки в cur которые НЕ в prev |
| **Stateless restart** | Restart Monitor = первый снапшот эмитится полностью, далее только delta |
| **Multi-source merge** | `sort -u` дедуплицирует через все источники |
| **Persistent mode** | `persistent: true` → живёт всю сессию (TaskStop останавливает) |
| **Timeout-mode** | `timeout_ms` для one-shot ожидания (до 60 min) |
| **Filter pre-existing noise** | Regex exclude `YAxUnit\|BSL Static\|BDD Tests` (1С CI forever QUEUED, см. 41.x) |
| **Priority badges** (2026-05-26) | jq if/elif/else chain: `[P0-master]` (headBranch=master) / `[P2-dependabot]` (workflowName matches Dependabot) / `[P3-security]` (CodeQL) / `[P1-PR]` (fallback). Order matters — CI fail on master takes precedence over source workflow. |
| **Auto-cache feedback loop** (Phase 1) | На каждый emit'нутый `RUN-FAIL[...]` line spawns `python scripts/ci_failure_cache.py --run-id N` → JSONL append → Qdrant upsert → potential issue creation. См. [42.4](42.4_Failure_Caching.md). |
