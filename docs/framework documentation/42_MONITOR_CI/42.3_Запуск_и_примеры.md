# 42.3 Запуск Monitor и примеры

Examples и cookbook для типовых watch-сценариев.

## Comprehensive CI watcher (active в текущей сессии — `bhlaxqp3s`)

```bash
prev="" ; while true ; do {
  gh pr list --state open --json number,title,statusCheckRollup \
    --jq '.[] | . as $pr | (.statusCheckRollup[]? |
      select(.conclusion != "" and .conclusion != "SKIPPED" and
             (.name | test("YAxUnit|BSL Static|BDD Tests") | not)) |
      "PR#\($pr.number) \($pr.title[:35]) :: \(.name|gsub(" *\\\\(.*\\\\)";""))=\(.conclusion)")' ;
  gh run list --limit 8 --json databaseId,workflowName,headBranch,conclusion,status \
    --jq '.[] | select(.conclusion != "" and .conclusion != "skipped") |
      "RUN[\(.workflowName)] \(.headBranch[:25]) → \(.conclusion)"' ;
  gh pr list --state open --label "dependencies" --json number,title \
    --jq '.[] | "DEPENDABOT PR#\(.number) \(.title[:50])"' ;
  gh api repos/Alex1980Alex/1C-Framework/code-scanning/alerts \
    --jq '.[]? | select(.state == "open") |
      "SEC-ALERT \(.rule.severity) \(.rule.id) — \(.most_recent_instance.location.path)"' | head -5 ;
} | sort -u > /tmp/cur.txt 2>/dev/null ;
  new=$(comm -13 <(echo "$prev") /tmp/cur.txt | grep -vE "^$|node-version|cannot iterate" || true) ;
  if [ -n "$new" ]; then echo "$new" ; fi ;
  prev=$(cat /tmp/cur.txt) ;
  sleep 15 ;
done
```

## Простой PR-watcher (one PR)

```bash
prev="" ; while true ; do
  cur=$(gh pr view $PR --json statusCheckRollup --jq '.statusCheckRollup[] | "\(.name)=\(.conclusion)"' | sort -u) ;
  comm -13 <(echo "$prev") <(echo "$cur") ;
  prev="$cur" ;
  remain=$(echo "$cur" | grep -c "=$") ;
  [ "$remain" = "0" ] && echo "GATES COMPLETE" && break ;
  sleep 30 ;
done
```
