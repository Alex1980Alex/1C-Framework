# 42.4 Failure Caching + Analysis

Multi-layer кэш и анализ ошибок CI через [`scripts/ci_failure_cache.py`](../../../scripts/ci_failure_cache.py).

## Pipeline

```
FAILURE event (Monitor) → ci_failure_cache.py:
  1. gh run view --log-failed → fetch raw log
  2. extract_first_error() → first meaningful error line (skip runner noise)
  3. SHA256[:16] hash → dedup key
  4. JSONL append → .claude/cache/ci-failures.jsonl
  5. TEI embed (Qwen3, 4096d) → MRL truncate → 1024d
  6. Qdrant upsert → ci_failures collection
  7. Qdrant search top-3 similar past failures (score >= 0.7)
  8. Count occurrences of same hash:
     - if >= 3 AND no existing issue → gh issue create
     - tag in .claude/cache/ci-failure-issues.json
```

## Storage layers

| Layer | Path | What | Retention |
|---|---|---|---|
| JSONL log | `.claude/cache/ci-failures.jsonl` | Все failures с metadata | Unlimited (append-only) |
| Issue tags | `.claude/cache/ci-failure-issues.json` | hash → issue URL mapping | Persistent (manual cleanup) |
| Qdrant `ci_failures` | localhost:6333 collection | 1024d Qwen3 embeddings + payload | Survives до collection delete |
| GitHub Issues | Labels `ci-failure,automated` | Auto-created на 3+ recurrences | Manual close |

## CLI

```bash
# Анализ конкретного fail
python scripts/ci_failure_cache.py --pr 19 --job "Pre-commit Hooks"

# Stats
python scripts/ci_failure_cache.py --stats

# Text search past failures
python scripts/ci_failure_cache.py --search "ConnectionRefusedError"
```

## Monitor integration

Monitor `bkozphbx9` (CI watcher + auto-cache):
- На каждый FAILURE event парсит `PR#N\tjob_name\ttitle`
- Если новый (не в prev) → вызывает `ci_failure_cache.py --pr N --job <name>`
- Emit в чат: `FAIL PR#N job=<name> title="..." occ=<count>[ issue_url=...]`
- `occ=1` = новая ошибка, `occ>=3` = recurring + issue URL

## Зачем нужны 4 слоя

| Слой | Use case |
|---|---|
| JSONL | grep/tail для quick lookup, persistent across sessions |
| Issue tags | Дедупликация issue creation (не создаём дубликаты) |
| Qdrant | Semantic similarity (новая ошибка похожа на старую с другим текстом) |
| GitHub Issues | Tracking + visibility for team (recurring failures) |
