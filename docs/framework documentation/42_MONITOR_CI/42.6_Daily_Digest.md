# 42.6 Daily Digest CLI

Markdown summary of last 24h CI activity для self-serve health check.

## Quick start

```bash
python scripts/ci_digest.py                       # stdout markdown, 24h window
python scripts/ci_digest.py --since 48h           # 48h window
python scripts/ci_digest.py --save docs/reports/ci-2026-05-26.md
```

## Sections

| Section | Source | What |
|---|---|---|
| CI Failures | `.claude/cache/ci-failures.jsonl` | top-10 grouped by `error_hash` (post-Phase-1 normalization) |
| Open PRs | `gh pr list --state open` | failing required gates count (excludes noisy YAxUnit/BSL Static/BDD/Claude Code Review) |
| Recently Merged | `gh pr list --state merged --search "merged:>=YYYY-MM-DD"` | up to 30 PRs |
| Auto-Issues | `gh issue list --label ci-failure,automated` | open auto-created issues |
| GitHub Notifications | `gh api notifications` | unread, grouped by `.reason` + top-5 subjects |

## CLI

```
python scripts/ci_digest.py [--since WINDOW] [--save PATH]

  --since WINDOW   "24h" / "7d" / "2w" / "1m" (default: 24h)
                   "m" approximates 30 days. Negative/zero → 24h fallback.
  --save PATH      Write to file (mkdir -p parents). Always prints to stdout.
```

## Architecture

Plain Python CLI, no async — `subprocess` for `gh` invocations, `json` parsing, `datetime` arithmetic. No external deps beyond stdlib + `gh` binary on PATH.

Timestamp handling: parses ISO with `Z`/`+HH:MM` suffixes, coerces naive → UTC defensively (fix from code-verify subagent `aac7e35e5ca3f47e2`).

## Limitations

- GH search `merged:>=YYYY-MM-DD` only supports date granularity — `--since 6h` shows same merged list as `--since 1d`.
- No JSON output mode (only markdown). Future: `--json` flag if needed for downstream parsing.
- Doesn't fetch failures since last `ci-failures.jsonl` write — relies on existing cache state. Run `python scripts/ci_failure_cache.py --catchup` first for fresh data.
