# 42.7 Полная цепочка: Push → CI → PR-анализ → Уведомления → Intake

> Сквозная карта конвейера доставки кода (зафиксирована 2026-06-12 по итогам
> живого аудита; в тот же день закрыты дыры H1-H4 — см. §6). Каждый этап
> ссылается на профильную главу с деталями.

## 0. Схема

```
ЛОКАЛЬНО                GITHUB                        ОБРАТНЫЙ ВВОД (intake)
────────                ──────                        ──────────────────────
Write/Edit
  │ auto-save трио       push/PR
  │ (amend-absorb)         │
  ▼                        ▼
git commit ──► git push ──► GitHub Actions ──► PR-анализ ──► Уведомления
            ▲              │ ci.yml (гейты)    │ gemini bot   │ email (человеку)
   pre-push │              │ codeql.yml        │ CodeQL       │ gh api notifications
   гейт     │              │ ci-1c.yml (gate)  │ review-      ▼
   (ruff+   │              │ openspec.yml      │ протокол   SessionStart: [GH-NOTIF] баннер
   compile) │              ▼                   ▼            SessionStart+Stop: ci-catchup
            │            checks rollup ──► merge (ручной) ──► post-merge auto-revert*
            │                                                 ci_digest (по запросу)
            └── PREPUSH_SKIP=1 / --no-verify (bypass)         (* за гейтом AUTO_PR_ENABLED)
```

## 1. Локальный слой (до push)

| Механизм | Когда | Что делает | Глава |
|---|---|---|---|
| auto-save трио (`auto-git-save.py`, `posttooluse-*`, `*-prompt.py`) | каждый Write/Edit | авто-коммит `chore: auto-save`; **amend-absorb**: незапушенные auto-save'ы одного prefix'а схлопываются в один коммит, поглощаемый осмысленным `git commit --amend` | skill `auto-git-save` §1.5 |
| `pre-push` (`scripts/git_hooks/pre-push`) | `git push` | ruff check + compileall **только** по py-файлам, уходящим в push; bypass `PREPUSH_SKIP=1` или `--no-verify` | этот файл |
| `git-commit-enforcer` / `task-enforcer` / `docs-change-enforcer` | Stop | блокируют завершение сессии при незакоммиченном / pending-задачах / непокрытой доке | [01.2](../01_ОБЗОР/01.2_Архитектура.md) |

⚠ **Commit-время намеренно не гейтится**: `core.hooksPath=scripts/git_hooks`
перекрывает `.git/hooks`, pre-commit framework локально не срабатывает (он
гоняется в CI job'е Pre-commit Hooks), а auto-save коммитит свободно — гейт
качества стоит на **публикации** (pre-push), не на сохранении.

## 2. GitHub Actions (что проходит push/PR)

`ci.yml` триггерится push'ем только в `master`/`main`/`dev-master`; для рабочих
веток всё исполняется через **pull_request-событие открытого PR**.

**Гейтящие джобы (красное = PR не мержится):**

| Джоб | Проверяет |
|---|---|
| Lint & Format (3.11/3.12) | `ruff check src/ scripts/ .claude/hooks/` + `ruff format --check src/` + compile-smoke + TOC-валидация (`validate_toc.py`) + roadmap §18 lint |
| Type Check (mypy-baseline ratchet) | новые mypy-ошибки сверх `mypy-baseline.txt`; resync-команда — в комментарии джоба, **exclude обязан совпадать с filter-шагом** (рассинхрон чинился 2026-06-12) |
| Pre-commit Hooks | `pre-commit run --all-files` (та самая проверка, которой нет локально) |
| Unit Tests (3.11/3.12) | `pytest -m "unit and not slow"` + Codecov (tokenless OIDC); окружение = `.[dev,morphology]` — **без qdrant**, тесты с qdrant-зависимыми импортами обязаны `pytest.importorskip("qdrant_client")` |

**Advisory (красное ≠ блок):** mypy strict, Integration Tests (Qdrant-сервис),
pip-audit (schedule), Skill Router eval (F1≥0.75).

**Параллельные workflow:** CodeQL (python+JS, PR + weekly), OpenSpec (по путям),
Cost Baseline (weekly), **CI 1C** — см. §5.

## 4. Уведомления и почта

**Письма GitHub → почтовый ящик владельца — дубль для человека; автоматика
ящик НЕ парсит.** Первоисточник для машины — GitHub API, три контура intake:

| Контур | Когда | Что делает | Глава |
|---|---|---|---|
| `gh-notif-intake-on-start.py` | SessionStart | `gh api notifications` → классификатор (`security=P0`, `ci-fail`/`pr-review`=P1, `dependabot`=P2, `merged`=P3, first-match-wins) → баннер `[GH-NOTIF] N unread (...)` | [42.5](42.5_GH_Notifications_Intake.md) |
| `ci-catchup-on-start.py` + **`ci-catchup-on-stop.py`** | SessionStart + Stop (cooldown 15м) | detached `ci_failure_cache.py --catchup 20` → нормализованный `error_hash` в `ci-failures.jsonl`; count≥3 → авто-issue. Stop-вариант добавлен 2026-06-12: провалы **во время** сессии больше не ждут следующей | [42.4](42.4_Failure_Caching.md) |
| `ci_digest.py --since 24h` | по запросу | markdown-сводка: top-10 failures, PRs, авто-issues, notifications | [42.6](42.6_Daily_Digest.md) |

**Исходящая почта**: `shared/pr_notifier.py` (SMTP/STARTTLS) шлёт письма о
PR-событиях — выключен, пока не задан `AUTO_PR_SMTP_HOST`. Monitor
(критические события в реальном времени) — session-bound, [42.1](42.1_Обзор.md).

## 5. CI 1C и self-hosted runner

Все 5 джобов `ci-1c.yml` (BSL Static Analysis, сборка, YAxUnit, BDD) требуют
runner `[self-hosted, windows-11, 1c]`. **Runner-гейт (2026-06-12):** в репо
0 зарегистрированных runner'ов → без гейта джобы висели QUEUED вечно на каждом
PR (у `pull_request` не было даже paths-фильтра). Теперь: paths-фильтр у
pull_request + `if: vars.CI_1C_RUNNER_ONLINE == '1'` на каждом джобе — пока
runner не зарегистрирован, джобы мгновенно SKIPPED (нейтрально для rollup).

**Оживление**: зарегистрировать runner (Settings → Actions → Runners → New
self-hosted, метки `windows-11`, `1c`), обновить устаревшие env-пути
(`D:\1C-FW` → `C:\1С-Framework`), затем `gh variable set CI_1C_RUNNER_ONLINE --body 1`.
