# 43.5.3 · Блок РАЗВИЛКА — `confidence ≥ 0.7`?

> **Блок 3/6** детектор-каскада. Обзор — [43.5 Сквозная карта](43.5_СКВОЗНАЯ_КАРТА.md) (§0.3, §0.5).
> Стрелка между «поймали 1С» и «что с этим делать». Развилка читает **уверенность**
> (`confident_1c`), а не сам факт `is_1c`. Код:
> [`route_1c_task`](../../../.claude/hooks/shared/pipeline_1c_bridge.py#L398).

## Схема

```
┌─ РАЗВИЛКА · уверены? (confidence ≥ 0.7) ───────────────────────────────────┐
│                                                                            │
│   classify_1c_task.confidence ∈ {0.0 · 0.5 · 0.7 · 0.9 · 1.0}              │
│   confident_1c = (confidence ≥ 0.7) = bool(JIRA) ∨ _1C_STRONG              │
│                                                                            │
│        ├─ да   →  ③ ОЦЕНКА СЛОЖНОСТИ → РЕЖИМ   (будет прогон)              │
│        └─ нет  →  ② ДОСМОТР ПО СМЫСЛУ          (чаще → ask_1c)             │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
```

## Подробно

Блок ① дал два разных ответа из одной строки: **`is_1c`** (это вообще 1С?) и **`confident_1c`**
(уверены ли настолько, чтобы запускать прогон?). Развилка ветвится по **второму**:

```
confident_1c = bool(jira) ∨ _1C_STRONG.search(prompt)
```

— «уверены» = есть **JIRA-код** ИЛИ **сильный 1С-маркер** (`гкс_`, `configuration/`, `Объект.точка`,
CamelCase-кириллица). Калиброванный `confidence` ∈ {0.0·0.5·0.7·0.9·1.0}; `confident_1c =
confidence ≥ 0.7` (behavior-preserving обёртка над тем же предикатом).

- **Уверены (≥0.7)** → вход минует семантику, идёт прямо в [③ ОЦЕНКА СЛОЖНОСТИ](43.5.5_ОЦЕНКА_СЛОЖНОСТИ.md)
  → РЕЖИМ: прогон (auto / ask_flow / gated по сложности).
- **Не уверены (<0.7)** → вход проваливается в [② ДОСМОТР ПО СМЫСЛУ](43.5.4_ДОСМОТР_ПО_СМЫСЛУ.md).
  Вердикт ② **мягкий** — максимум поднимает до `ask_1c` (вопрос), никогда сразу в прогон.

**Инвариант безопасности.** Матч без сильного маркера → `confident_1c=False` → ветка «нет» →
вопрос, **не слепой прогон**. Высокий recall ① компенсируется тем, что неуверенное **деградирует
в вопрос**. Финальное решение — за Claude ([[feedback-1c-detection-judgment-mine]]).

## Кратко (TL;DR)

- Развилка читает **`confident_1c`** (= `bool(JIRA) ∨ _1C_STRONG`), не сам `is_1c`.
- **да (≥0.7)** → прямо в оценку сложности → прогон; **нет (<0.7)** → семантический досмотр ②.
- Инвариант: неуверенный матч деградирует в **вопрос**, не в авто-прогон.

## Реальный пример

**Трасса A (уверены):** `GKSTCPLK-2182 Доработать…` → есть JIRA → `confident_1c=True` → ветка
**«да»** → сразу ③ сложность (points=4 → medium) → РЕЖИМ `ask_flow`. Семантика ② **не зовётся**.

**Трасса B (не уверены):** `Добавить реквизит в справочник контрагентов` → `is_1c=True` (термин
«справочник» + глагол «добав»), но JIRA нет и `_1C_STRONG` нет → `confident_1c=False` → ветка
**«нет»** → ② ДОСМОТР. Сложность считается (medium), но **не влияет** — выход будет `ask_1c`.
