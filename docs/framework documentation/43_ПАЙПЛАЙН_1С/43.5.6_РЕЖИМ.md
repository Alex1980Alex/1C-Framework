# 43.5.6 · Блок РЕЖИМ — `flow` (рекомендация маршрута)

> **Блок 6/6** (финальный) детектор-каскада. Обзор — [43.5 Сквозная карта](43.5_СКВОЗНАЯ_КАРТА.md) (§0.5).
> Объединяет детект (①/②) + сложность (③) в **режим** `flow ∈ {none, ask_1c, auto, ask_flow, ask_action, gated}`
> и инъектит рекомендацию в `systemMessage`. Это **подсказка** — решение за пользователем/Claude.
> Код: [`route_1c_task`](../../../.claude/hooks/shared/pipeline_1c_bridge.py).

## Схема

```
┌─ РЕЖИМ (flow) · рекомендация хука; решение — за пользователем ─────────────┐
│   none       →  молчит (не 1С)                                             │
│   ask_1c     →  «это 1С? новая / доработка?»  + V.6 (папка ТЗ)             │
│   auto       →  /run-1c-task                      (простая)                │
│   ask_flow   →  СПРОСИ: AUTO или гейт?            (средняя)                │
│   ask_action →  СПРОСИ: что нужно сделать?        (confident+simple, но    │
│                                                    действие НЕ названо)    │
│   gated      →  /analyze → ревью → /implement     (сложная)                │
└────────────────────────────────────────────────────────────────────────────┘
```

## Подробно

Финальный блок собирает результаты предыдущих в одно из **шести** значений `flow`. Ключевой
предохранитель — `confident_1c` (см. [43.5.3 РАЗВИЛКА](43.5.3_РАЗВИЛКА.md)): он решает **раньше**
сложности.

| `flow` | Условие | Рекомендация хука (инъекция в `systemMessage`) |
|---|---|---|
| **`none`** | не 1С (`is_1c=False`) | молчит (`return None`) |
| **`ask_1c`** | 1С, но `confident_1c=False` | **ПОДТВЕРДИ:** это 1С? новая / доработка / багфикс? + V.6 (папка) |
| **`auto`** | confident ∧ `simple` ∧ есть действие | запусти **`/run-1c-task`** (AUTO: analyze→approve→implement→test) |
| **`ask_flow`** | confident ∧ `medium` | **СПРОСИ:** AUTO (`/run-1c-task`) или гейтованный поток? |
| **`ask_action`** | confident ∧ `simple` ∧ нет таск-глагола ∧ нет work-сигналов (`actionless`) | **СПРОСИ:** что нужно сделать? (AUTO **не запускается** — действие не названо) |
| **`gated`** | confident ∧ `complex` | **`/analyze-1c-task`** → ревью ANALYSIS-REPORT → **`/implement-1c-task`** |

**Инвариант безопасности.** Матч без сильного маркера → `confident_1c=False` → `ask_1c`, **не
авто-маршрут**. Recall высокий, но ложные срабатывания **деградируют в вопрос**, не в слепой прогон.

**Решение — за Claude/пользователем.** Хук **advisory**: финальное «это 1С / каким потоком» — за
Claude; при сомнении (1С/не-1С, AUTO/гейт) — спросить ([[feedback-1c-detection-judgment-mine]]).
К `ask_1c` хук добавляет точечные V.6-ноты по `ttype` (T2 bugfix / T3 «не учтено» / папка ТЗ).

## Кратко (TL;DR)

- **6 режимов:** `none` / `ask_1c` / `auto` / `ask_flow` / `ask_action` / `gated` — по паре (`confident_1c` × банда + наличие действия).
- `confident_1c` решает **раньше** сложности: неуверенный 1С → всегда `ask_1c`.
- `ask_flow` = **только средняя сложность** («AUTO или гейт?»); `ask_action` = confident+simple, но **действие не названо** («что сделать?»). Потребитель различает по значению `flow` — доп-ключ `actionless` более не обязателен.
- Рекомендация **advisory** (инъекция в `systemMessage`); финальное решение — за Claude/пользователем.

## Реальный пример

| Чат-сообщение | `is_1c` | `confident` | банда | `flow` → действие |
|---|---|---|---|---|
| `GKSTCPLK-2182 Доработать создание Направления…` | ✓ | ✓ (JIRA) | medium | **`ask_flow`** — спросить AUTO/гейт |
| `Создать регистр накопления гкс_УчётРазгрузки…` | ✓ | ✓ (`гкс_`) | complex | **`gated`** — `/analyze`→ревью→`/implement` |
| `GKSTCPLK-2182` (один JIRA без глагола/сигналов) | ✓ | ✓ (JIRA) | simple | **`ask_action`** — confident, simple, но действие не названо → «что нужно сделать?» |
| `Добавить реквизит в справочник контрагентов` | ✓ | **✗** | (не влияет) | **`ask_1c`** — `confident=✗` решает раньше → подтвердить + V.6 |
| `Отрефактори search manager на httpx` | ✗ | — | — | **`none`** — молчит (не 1С) |

Третья строка — суть инварианта: термин («справочник») + глагол («добавить») дают `is_1c=True`, но
без сильного маркера система **не угадывает режим, а спрашивает**.
