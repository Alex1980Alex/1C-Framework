# 43.7 Аудит консистентности слоёв пайплайна

> Честный снимок согласованности между тремя слоями пайплайна 1С (команда → скилл → хук, см.
> [43.6](43.6_АНАТОМИЯ_КОМАНД.md)). Источник — сквозной разбор всех 5 команд, 4 скиллов и 8 хуков +
> `settings.json` (2026-06-16). Каждый пункт — с `file:line`. Классификация: ✅ исправлено · 🔵 by-design ·
> ⚠ осталось.

## Методика

Три параллельных чтения исходников (не по памяти): (1) все `.claude/commands/*1c*.md`; (2) скиллы
`analyze-1c-task-v2`, `implement-1c-task`, `run-1c-task`, `va-bdd-testing`; (3) хуки пайплайна + регистрация
в `settings.json`. Сверялись: `allowed-tools` команды vs инструменты, упомянутые в скилле; версии frontmatter
vs тело; имена MCP-серверов; наличие frontmatter/`commands:`.

**Сводка:** найдено ~22 расхождения. **Исправлено 10** (этой сессией), **by-design 4** (разъяснено),
**осталось 4** (требуют решения владельца / отдельной задачи).

## 🔵 By-design (разъяснено — не дефект)

| Наблюдение | Где | Почему так задумано |
|---|---|---|
| Имя команды ≠ имя скилла (`/analyze-1c-task` → `analyze-1c-task-v2`) | `commands/analyze-1c-task.md:2` | Методика версионируется независимо; одна методика может обслуживать несколько команд |
| `/run-1c-task`, `/write-1c-tests`, `/run-1c-tests` без `allowed-tools` | `commands/run-1c-task.md`, `write-1c-tests.md`, `run-1c-tests.md` | Оркестратор и тест-команды **наследуют** инструменты делегируемого скилла (`va-bdd-testing` несёт свой `allowed-tools`) |
| Хардкод путей `D:\va-test\...` | `commands/run-1c-tests.md:249`, `write-1c-tests.md:503` | Реальное расположение VA-харнесса (память [[reference_va_debug_attach]]) — не баг среды |
| «4 основных MCP-сервера», хотя инструменты от 8 серверов | `commands/implement-1c-task.md:78,84` | «4 основных» (EDT-MCP, 1c-mcp-crud, bsl-debug-server, 1c-debug-hmr) + вспомогательные — терминологическое сокращение |

## Инвариант поддержки

Перечень — **снимок на 2026-06-16**. Чтобы аудит не устаревал: при правке команды/скилла сверять три
слоя (`allowed-tools` команды ↔ инструменты скилла ↔ хуки состояния), держать `version`/`commands:` в
frontmatter скилла актуальными, а имена MCP-серверов — едиными (`1c-mcp-crud`, не `1c-mcp-server`).
