# 43.9.6 Формы, СКД, макеты

> **Тип:** UI-артефакты — формы, схемы компоновки данных (СКД), макеты табличных документов (`.mxl`/`.mxlx`):
> чтение структуры и offline-правка. Глава каталога [43.9](43.9_ИНСТРУМЕНТЫ_ПО_ТИПАМ.md). Этапы: **1-2**
> (структура), **3** (правка). Запись BSL модулей форм — в [43.9.5](43.9.5_ЗАПИСЬ_И_РЕФАКТОРИНГ.md);
> рендер печати для verify — в [43.9.2](43.9.2_ДАННЫЕ_И_RUNTIME.md).

## Назначение
Понять и изменить визуальные/отчётные артефакты: дерево элементов формы, наборы/поля/параметры СКД, области/
ячейки/merge макета. Ключевая боль — эти артефакты не редактируются обычным BSL-путём (нужны спец-инструменты).

## Инструменты

| Функция | Сервер / CLI | Что делает | Подводный камень |
|---|---|---|---|
| `inspect_form_layout` | codepilot1c | дерево формы (элементы/команды) — **отлично** | хост плагина (`-32000` если выкл.) |
| `get_form_structure` | 1c-mcp-crud | элементы формы + DataPath/видимость (для VA BDD) | — |
| `get_form_layout_snapshot` | edt-mcp | снапшот раскладки с bounds | bounds только при `nativeFormLayoutRender=FALSE` ([[feedback-edt-mcp-form-bounds-render-flag]]) |
| `get_form_screenshot` 🔒 | edt-mcp | визуальный скрин формы **без запуска** клиента | 🔒 advisory-кандидат в обязательные (ADR-035) — сюрфейсится `•` в onec-task-gate |
| `dcs_manage` | codepilot1c | структура/правка СКД | **read сломан** (датасеты=0); `validate_query(dcsMode)` работает ([[reference-codepilot1c-form-template-dcs-tools]]) |
| `inspect_template` | codepilot1c | макет (табличный документ) | **не читает `.mxlx`** (хардкодит `.mxl`) |
| `form-info` / `skd-info` / `mxl-info` | cc-1c-skills (offline) | дерево формы / наборы СКД / области-ячейки макета | per-object процесс |
| `mxl-compile` / `mxl-decompile` | cc-1c-skills (offline) | **round-trip правки `.mxl`/`.mxlx`** | единственный надёжный offline-редактор (ADR-031) |
| `skd-edit` (25 ops) | cc-1c-skills (offline) | правка СКД (`.dcs`) | — |

## Выбор среди альтернатив

- **Структура формы (read)** → `inspect_form_layout` (codepilot) / `get_form_layout_snapshot` (edt) /
  `get_form_structure` (crud, для тестов). Визуальная проверка вёрстки **без клиента** → `get_form_screenshot`.
- **Структура СКД/макета (read)** → cc-1c-skills `skd-info`/`mxl-info` (у codepilot `dcs_manage` read сломан,
  `inspect_template` не видит `.mxlx`).
- **ПРАВКА `.mxl`/`.mxlx`/`.dcs` (write)** → **только cc-1c-skills** (`mxl-compile`/`decompile` round-trip,
  `skd-edit`). ⚠ EDT-MCP `.mxlx` **не компилирует** ([[feedback-edt-mcp-mxlx-not-compiled]]) — правка макета
  идёт GUI ИЛИ cc-1c-skills.
- **Verify печатной формы** → `execute_code` → PDF → Read ([43.9.2](43.9.2_ДАННЫЕ_И_RUNTIME.md), [[reference-1c-printform-render-verify]]).

## Когда применять
Планирование/Дизайн — дерево формы/СКД/макета перед правкой. Кодирование — offline-правка артефакта +
рендер-verify результата.
