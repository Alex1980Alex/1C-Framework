## Назначение

Opt-in CLI «что в экосистеме за N дней» по теме. Опрашивает **free public API** (без cookies/платных
ключей/скрапинга), ранжирует через [`engagement_rank`](44.2_Engagement_Ranking.md), схлопывает кросс-
источниковые дубли и печатает Markdown-бриф. Ускоритель Фазы 2 `architecture-research`/`tech-research`
и discovery для tooling-adoption (ADR-012..015).

## Запуск

```bash
python scripts/ecosystem_scan.py "RAG embeddings reranking 2026" --days 30 --top 10
python scripts/ecosystem_scan.py "claude code mcp" --out data/reports/ecosystem/mcp.md
python scripts/ecosystem_scan.py "langgraph" --json     # машинный JSON
```

| Флаг | Назначение | Дефолт |
|---|---|---|
| `query` (поз.) | тема скана | — |
| `--days N` | окно в днях | 30 |
| `--top N` | сколько результатов | 10 |
| `--out FILE` | сохранить Markdown в файл (иначе stdout) | — |
| `--json` | машинный JSON вместо Markdown | off |

## Источники (free, zero-config)

| Источник | API | engagement | Auth |
|---|---|---|---|
| **Hacker News** | Algolia `search_by_date` (HTTPS) | points + comments | нет |
| **StackOverflow** | StackExchange `search/advanced?sort=votes` | score | нет (free, без ключа; ~300 req/день) |
| **GitHub** | `search/repositories?sort=stars` | stars | `GITHUB_TOKEN` из env **опционально** (выше rate-limit) |

Окно дней → HN `created_at_i > ts`, SO `fromdate=ts`, GitHub `pushed:>date`.

> **Reddit убран (2026):** unauth `.json` → 403 c 2026-05-30, OAuth закрыт (data-licensing-сделки Reddit). Заменён на StackOverflow (free-text `q`, score-engagement, плоский JSON без ключа).

## Конвейер

```
query → fetch_hn + fetch_reddit + fetch_github   (сеть, graceful per-source)
      → _relevance (rapidfuzz token_set_ratio по expand_queries, иначе token-overlap)
      → filter (relevance ≥ min_relevance=0.5)
      → per-source min-max нормировка engagement в [0,1] (топ каждого источника → 1.0)
      → rank_items (blended = 0.7·relevance + 0.3·log-norm(eng_norm); источники конкурируют честно)
      → dedup_by_entity (нормализованный title)
      → top-N → to_markdown / json
```

**Чистое ядро** (`build_ranked` / `to_markdown` / `_relevance`) — без сети → юнит-тестируемо.
Сеть только в `fetch_*` / `scan`.

## Калибровка порога

`min_relevance=0.5` подобран эмпирически: `rapidfuzz.token_set_ratio` на **несвязанных** заголовках
шумит ~0.42 (напр. «unrelated cooking recipes» против «langgraph orchestration» = 0.417), релевантные =
1.0. Порог 0.5 чисто разделяет сигнал и шум.

## Безопасность и устойчивость

- **Нет секретов/cookies/скрапинга**; только публичные эндпоинты. `GITHUB_TOKEN` читается из env, не
  хардкодится, не обязателен. Согласуется с [[feedback-no-paid-anthropic-api]] и ремедиацией утечки секретов.
- **Graceful per-source:** `_http_json` с timeout, любая ошибка → `None` → источник даёт `[]` (остальные
  работают). CLI не падает стектрейсом при недоступной сети.
- **URL-инъекции:** query кодируется через `urllib.parse.quote`.
- **Windows/UTF-8:** stdout reconfigure; `--out` пишет UTF-8.

## Живой пример

`ecosystem_scan.py "retrieval augmented generation reranking" --days 60 --top 6` →

```
1. [GitHub] DataScienceUIBK/Rankify — Comprehensive Toolkit for Retrieval, Re-Ranking, RAG
   (engagement=677, score=0.9)   https://github.com/DataScienceUIBK/Rankify
2. [GitHub] DoniaGabal/Advanced_Rag_system ... (engagement=1, score=0.632)
...
```

`Rankify` (677★) ранжирован **#1** благодаря engagement×relevance, несмотря на равную релевантность
с менее популярными репо. HN/StackOverflow — graceful, если за окно нет хитов. Per-source нормировка позволяет топ-элементу HN/SO конкурировать с GitHub по релевантности, а не тонуть под звёздами (live-проверено: SO всплывает в выдаче по Q&A-запросам).

## Когда использовать

- Перед adopt/skip-решением по новому инструменту (что говорит сообщество за 30 дней).
- При research новой техники (RAG/embeddings/MCP/Claude Code) — свежие, ранжированные по engagement сигналы.
- **НЕ** для 1С-домена (источники англоязычны; 1С-контент — its.1c.ru/infostart, см. `1c-doc-research`).
