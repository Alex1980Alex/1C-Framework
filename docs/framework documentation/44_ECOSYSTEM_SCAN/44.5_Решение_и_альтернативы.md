## Контекст

Оценивался open-source [`last30days-skill`](https://github.com/mvanhorn/last30days-skill) (46.2k★, MIT)
на предмет интеграции. Это **social-trend research** (НЕ git/changelog, как можно подумать по названию):
опрашивает Reddit/X/YouTube/HN/Polymarket/TikTok/Instagram/Bluesky + web, ранжирует по engagement,
синтезирует бриф с цитатами.

## Решение: ADAPT частично (не full-adopt)

**Полный инструмент НЕ принят.** Причины:

| # | Риск | Серьёзность |
|---|---|---|
| 1 | **Доменный промах:** ядро фреймворка — 1С BSL (RU, источники its.1c.ru/infostart) + PDF RAG (self-search), а не англоязычные соцсети. ~90% работы — нулевая польза | ВЫСОКАЯ |
| 2 | **Дублирование:** уже есть `tech-research`, `architecture-research` Фаза 2, `autoresearch`, хуки `prework-github-bp/stackoverflow` | ВЫСОКАЯ |
| 3 | **Cookies/токены X/Bluesky/YouTube в PUBLIC-репо** — после ремедиации утечки секретов недопустимый attack-surface | ВЫСОКАЯ |
| 4 | **Платные API** (ScrapeCreators/Perplexity/Brave/XAI) для полной мощи — против cost-conscious-политики | СРЕДНЯЯ |
| 5 | ToS/legal-серость скрапинга TikTok/Instagram; 11 платформ = большая поверхность поломок | СРЕДНЯЯ |

**Принято выборочно:** извлечь полезное ядро — engagement-ранкинг + multi-query expansion + entity-dedup
— в безопасный модуль без скрапинга/cookies/платных API. Реализовано двумя путями:

- **V1** — [`engagement_rank`](44.2_Engagement_Ranking.md) встроен в авто-хук
  [`prework-github-bp`](44.3_V1_Prework.md) (блендинг вместо relevance-only).
- **V2** — [`ecosystem_scan.py`](44.4_V2_Ecosystem_Scan.md) (on-demand free HN/StackOverflow/GitHub скан; Reddit убран 2026 — API мёртв, заменён SO; per-source нормировка engagement).

## Честная оценка ROI

- **Высокая** польза для ~10% работы = «скан экосистемы RAG/Claude-Code/MCP за 30 дней».
- **~0** для ~90% = 1С BSL-разработка (не те источники/язык) + внутренняя PDF-RAG работа (self-search).
- Перекрытие с существующими research-механиками → чистый ROI full-adopt'а маргинальный; ADAPT снимает
  риски, сохраняя полезное ядро.

## Альтернативы (отклонены)

| Альтернатива | Почему отклонена |
|---|---|
| **Full-adopt** (marketplace + cookies + платные ключи) | доменный промах + секрет-риск public-репо + дублирование + платные зависимости |
| **Статус-кво** (только текущие research-скиллы/WebSearch) | приемлемо; но recency + engagement-ранкинг даёт реальный прирост для ecosystem-скана — извлекли дёшево |
| **Только V1** или **только V2** | оба дёшевы и переиспользуют один модуль → сделаны вместе, без дублирования |

## Доп. источники — GitHub/web research (2026-06-24)

Анализ free engagement-bearing источников для расширения скана (проверено live через urllib):

| Источник | API | engagement | free-text `q`? | Вердикт |
|---|---|---|---|---|
| Hacker News | Algolia `search_by_date` | points + comments | да | ✅ в проде |
| GitHub | `search/repositories` | stars | да | ✅ в проде |
| **StackOverflow** | StackExchange `search/advanced` | score / views | да | ✅ **в проде (заменил Reddit)** |
| ~~Reddit~~ | public `.json` | ups | да | ❌ **МЁРТВ 2026** (403 c 2026-05-30, OAuth закрыт — data-licensing) |
| **Lobsters** | `/t/<tag>.json` | score + comments | **нет (тег-based)** | ✅ **в проде V3** (query→tag-маппинг) |
| **Dev.to (forem)** | `/articles?tag=` | reactions | **нет (тег-based)** | ✅ **в проде V3** (query→tag-маппинг) |
| Web (Brave/Perplexity) | — | **нет engagement** | да | ⛔ пропущен — free DDG live сломан + relevance-only |

**Вывод research:** связка «free-text + engagement-метрика + zero-key» = только **HN / SO / GitHub** (все реализованы).
Lobsters/Dev.to несут engagement, но тег-based (не free-text) → требуют отображения запрос→тег.
Web-плечо (DuckDuckGo/Brave) даёт recall, но **без engagement** → блендинг вырождается в relevance-only
(для веба нет естественного сигнала популярности). Источники [web]: [Reddit API dead 2026](https://medium.com/@alex_79882/reddits-api-is-officially-dead-in-2026-here-s-what-i-use-instead-f88ee5b809c8), [HN blocks JSON](https://news.ycombinator.com/item?id=48329557).

## Будущее (опционально)

- **V3 РЕАЛИЗОВАН (2026-06-24):** query-adaptive веса + кеш сканов (`data/reports/ecosystem/`, TTL,
  `--no-cache`) + Lobsters/Dev.to через query→tag-маппинг. См. [44.4 §V3](44.4_V2_Ecosystem_Scan.md).
- **Остаётся (опц.):** интеграция вывода в Фазу 2 `architecture-research` как автоисточник; ещё
  free-источники (arXiv) через тот же `engagement_rank`; web-плечо — пропущено (free DDG live сломан).
- **Реверсивность:** V1 — graceful-fallback на relevance-only (удалить импорт); V2 — отдельный скрипт
  (удалить файл); `engagement_rank` — изолированный модуль. Откат тривиален.
