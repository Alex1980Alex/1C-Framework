## Назначение

Получение **дословного** контента из-за пейвола **ИТС (its.1c.ru)** — v8std-стандарты, расширения, БСП,
руководства — под пользовательской подпиской. Это **deep-fetch слой поверх onec_search (44.6)**:
onec_search/WebSearch находит ИТС-страницы (its.1c.ru = trust 1.0), `its_fetch` тянет полный текст топ-хитов.
Эталон 8.3.27 (`/search/`) остаётся приоритетом 1; ИТС = приоритет 2 (вендор).

## Конвейер

```
тема -> WebSearch "site:its.1c.ru <тема>"  (FIND: /db/<db>/content/N/hdoc — JS-дерево не парсится напрямую)
     -> its_fetch.py <URL>  (Playwright storageState под сессией ИТС)
     -> контент-фрейм w_metadata_doc_frame -> trafilatura -> markdown  (правила/таблицы/код сохранены)
     -> атрибуция [its.1c.ru, content/N, #stdNNN]
```

## Авторизация (Playwright storageState)

Реальный SSO-поток 1С (разведан live): `its.1c.ru/user/auth` → cookie «Принимаю» → «Войти через Портал
1С:ИТС» (`#login_portal`) → **login.1c.ru** (`#username`/`#password`/`#loginButton`) → редирект на
`its.1c.ru/personal/`. Сессия → `playwright/.auth/its.json` (**gitignored**), живёт недели.

| Команда | Действие |
|---|---|
| `its_fetch.py --login` | видимый браузер; env-креды авто-заполняются, иначе ручной вход (капча/2FA) |
| `its_fetch.py --auto-login` | **headless** авто-вход по env-кредам (re-login при истечении, без человека) |
| `its_fetch.py <URL>` | fetch под сессией → markdown (stdout / `--out`) |
| `its_fetch.py --check` | жива ли сессия |

## Извлечение контента (trafilatura)

Тело статьи ИТС лежит в **iframe `w_metadata_doc_frame`** (не в `body`). `_extract_content` берёт HTML фрейма →
**trafilatura** `extract(output_format="markdown", include_tables=True)` → чистый markdown с сохранением
нумерованных правил, **таблиц**, кода «Правильно/Неправильно». Graceful: нет trafilatura → текст фрейма → body.
Выбор trafilatura — лучшая практика с GitHub (F1=0.966), найдена через **`ecosystem_scan`** (см. ниже).

## Безопасность (хард)

- Креды — только в **`.env.its`** (gitignored) / env / окне браузера. **Никогда не в чат/код/git**
  (см. ремедиацию утечки секретов проекта). Сессия `playwright/.auth/` gitignored.
- Low-volume self-use под своей подпиской (не массовый скрейп; ToS).

## Установка

`pip install -e ".[its]"` (`playwright>=1.40` + `trafilatura>=2.0`) + `python -m playwright install chromium`.

## GitHub-поиск — обязательно через ecosystem_scan

С 2026-06-24 GitHub-поиск **принудительно** идёт через [`ecosystem_scan`](44.4_V2_Ecosystem_Scan.md) (engagement×relevance),
не через голый WebSearch. Хард-энфорсер [`github-search-via-ecosystem-scan.py`](../../../.claude/hooks/github-search-via-ecosystem-scan.py)
(PreToolUse:WebSearch блокирует GitHub-намеренный запрос → требует `ecosystem_scan`; opt-out `GITHUB_ECOSYSTEM_SCAN_DISABLE=1`).
Именно так был найден trafilatura для извлечения выше — догфудинг гл.44.
