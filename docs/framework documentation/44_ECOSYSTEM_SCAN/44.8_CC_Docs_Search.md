## Назначение

Семантический поиск по **документации Claude Code** (code.claude.com/docs) — CLI/SDK/хуки/субагенты/
настройки/permissions/MCP/плагины/интеграции. Внешние **публичные** доки индексируются в Qdrant и ищутся
семантически. **НЕ путать:** `/pdf-search` — локальные PDF/BSL/wiki/skill; `onec_search` (44.6) — web 1С/RU;
`its_fetch` (44.7) — ИТС за подпиской. `cc_docs_search` — публичные доки CC, индексированные.

## Конвейер

```
index:  sitemap (EN) + <lastmod> -> urllib GET -> trafilatura -> markdown -> chunk(## +1500)
        -> TEI embed (Qwen3-Embedding-8B 4096d, batch<=32) -> Qdrant `cc_docs` (Cosine, lastmod в payload)
search: query -> TEI (Qwen3 query-instruct) -> Qdrant top-k -> url + heading + snippet + score
```
Публичные доки → **без браузера** (urllib + trafilatura). Идемпотентно (`_pid=md5(url#idx)` → upsert).
~150 EN-страниц.

## Freshness — доки обновляются (ключевое)

sitemap несёт `<lastmod>` на каждую страницу → три режима:
| Команда | Что делает |
|---|---|
| `cc_docs_search.py check` | сколько страниц **обновилось/добавилось** с последней индексации (сравнение lastmod) |
| `cc_docs_search.py index --incremental` | ре-индекс **только изменённых/новых** (дёшево) |
| `cc_docs_search.py index` | полный ре-индекс (idempotent) |

**Правило:** перед ответом, чувствительным к актуальности → `check`; изменилось → `index --incremental`.
Зашито в скилл `cc-docs` и команду `/cc-docs`.

## Использование

```bash
python scripts/cc_docs_search.py search "permission modes" --top 8
python scripts/cc_docs_search.py check                 # что обновилось
python scripts/cc_docs_search.py index --incremental   # подтянуть изменённое
```
`/cc-docs <запрос>` — поиск + синтез ответа с цитатами `[code.claude.com/.../page]`, авто-проверка свежести.

## Инфраструктура

Reuse: **TEI** (`pdf-rag-tei`, :8080, Qwen3-8B 4096d) + **Qdrant** (:6333, коллекция `cc_docs`) + **trafilatura**
(`pip install -e ".[its]"` — общая зависимость с ИТС deep-fetch). Reversible: удалить коллекцию `cc_docs` = откат.

## Тесты / верификация

LIVE: index 150 EN-страниц → `cc_docs` (4096d); search «permission modes» → sandboxing 0.646 / glossary;
«create a custom hook» → hooks 0.64; `check` корректно парсит lastmod (150 стр.). code-verify PASS (graceful,
idempotent, batch≤32, query-instruct асимметрия). Зарегистрирован в skill-router (домен `claude-code`).
