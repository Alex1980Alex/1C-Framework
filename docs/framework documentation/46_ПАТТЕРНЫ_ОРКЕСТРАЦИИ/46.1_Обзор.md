# 46.1 Обзор — паттерны мульти-агентной оркестрации

> **Версия:** 1.0 | **Дата:** 2026-06-25 | **Статус:** ACTIVE
> **Контекст:** 6 паттернов оркестрации агентов и их реализация в Claude Code (субагенты + Workflow + hooks + agent-loop).

---

## Что это

Шесть переиспользуемых **паттернов оркестрации** нескольких агентов (субагентов) для решения задач, которые
один проход не вытягивает — нужны охват (декомпозиция+параллель), уверенность (независимые перспективы +
состязательная проверка) или масштаб (одна задача не помещается в контекст).

| # | Паттерн | Суть | Глава |
|---|---|---|---|
| 1 | **Classify-And-Act** | классифицировать вход → роутить к специализированному агенту | [46.2](46.2_Classify_And_Act.md) |
| 2 | **Fanout-And-Synthesize** | веер параллельных агентов → синтез | [46.3](46.3_Fanout_And_Synthesize.md) |
| 3 | **Adversarial Verification** | находку проверяют агенты-скептики (опровергнуть) | [46.4](46.4_Adversarial_Verification.md) |
| 4 | **Generate-And-Filter** | сгенерировать много кандидатов → отфильтровать | [46.5](46.5_Generate_And_Filter.md) |
| 5 | **Tournament** | N независимых попыток → судьи → победитель | [46.6](46.6_Tournament.md) |
| 6 | **Loop Until Done** | итеративный цикл агента до терминального условия | [46.7](46.7_Loop_Until_Done.md) |

## 4 примитива Claude Code (на чём всё строится)

| Примитив | Роль | Где |
|---|---|---|
| **Субагент** | рабочая единица (свой контекст, инструменты, модель) | Agent tool / Agent SDK `AgentDefinition`; `SubagentStart`-хук ловит спавн [code.claude.com/docs/en/hooks] |
| **Workflow** | детерминированный оркестратор (parallel / pipeline / циклы / условия) | Workflow tool; «custom subagents — the worker primitive workflows orchestrate» [code.claude.com/docs/en/workflows] |
| **Hooks** | гейты/верификация: callback → decision (`{}`=allow, deny=блок) | [code.claude.com/docs/en/agent-sdk/claude-code-features] |
| **Agent-loop** | условие останова цикла (`max_turns`/`max_budget_usd`) | [code.claude.com/docs/en/agent-sdk/agent-loop] |

## Как читать главу
Каждая подглава: **схема** (как на видео) → **когда применять** → **реализация в Claude Code** →
**Workflow-пример** (исполнимый JS) → **реальный пример в нашем фреймворке** → **подводные камни**.

Большинство паттернов **уже применяются** в проекте (примеры в подглавах; 4 из 6 — вживую в одной сессии:
fanout-synthesize, adversarial-verify, generate-filter, loop-until-done).
