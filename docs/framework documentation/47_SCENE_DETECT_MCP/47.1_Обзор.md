## Назначение

MCP-сервер `scene-detect` извлекает **один репрезентативный кадр на каждую смену сцены** в видеофайле.
Под капотом — [PySceneDetect](https://www.scenedetect.com/) `ContentDetector` (детект склеек по HSV-взвешенной
разнице между соседними кадрами). Это **точнее ffmpeg-фильтра** `select=gt(scene,X)`: кадр берётся не по
таймкоду и не по I-frame'ам, а по фактической визуальной смене плана.

Типовой результат — «storyboard» видео: по кадру на каждый план/сегмент между склейками, с таймкодами начала
и конца каждой сцены.

## Когда использовать (и когда нет)

**Триггеры скилла:** `раскадровка видео`, `смена сцены`, `кадр при смене сцены`, `scene detection`,
`извлечь ключевые кадры`, `PySceneDetect`, `scene-detect MCP`, `storyboard frames`, `видео на кадры по сценам`,
`detect scene changes`.

| Задача | Инструмент |
|---|---|
| Кадр **на каждую визуальную смену плана** | **этот MCP** (`ContentDetector`) |
| Кадры по **таймкоду / фиксированному интервалу** (каждые N сек) | ffmpeg `-vf fps=N` |
| Метаданные / транскрипт YouTube-ролика | `youtube-mcp` |

## Инструмент `extract_scene_frames`

```text
mcp__scene-detect__extract_scene_frames(
    video_path: str,
    threshold: float = 27.0,
    output_dir: str = "",
    num_images: int = 1,
) -> dict
```

**Параметры:**

| Параметр | По умолчанию | Описание |
|---|---|---|
| `video_path` | — (обязательный) | Путь к входному видеофайлу. Если файл не найден → `{ok: False, error}`. |
| `threshold` | `27.0` | Чувствительность `ContentDetector`. **НИЖЕ = больше склеек** (типичный диапазон 20–35). Выше — требуется бо́льшая разница контента. |
| `output_dir` | `""` | Куда писать кадры. Пусто → `<папка видео>/scene_frames` (создаётся автоматически). |
| `num_images` | `1` | Сколько кадров извлекать на каждую сцену. |

**Возвращает `dict`:**

```jsonc
{
  "ok": true,                       // false при ошибке (+ ключ "error")
  "count": 5,                       // число обнаруженных сцен; 0 = склеек нет (один непрерывный план)
  "scenes": [                       // метаданные по каждой сцене
    { "n": 1, "start": "00:00:00.000", "end": "00:00:03.480",
      "start_sec": 0.0, "end_sec": 3.48 }
  ],
  "images": ["<абсолютные пути к кадрам>"],
  "output_dir": "<абсолютный путь к папке вывода>"
}
```

`count = 0` означает, что склейки не обнаружены — это валидный ответ (видео = один непрерывный план),
а не ошибка. Кадры в этом случае не сохраняются (`images: []`).

## Под капотом (Source: PySceneDetect v0.7)

```text
detect(video_path, ContentDetector(threshold))   ->  scenes  (список пар FrameTimecode: start, end)
        |                                              |
        |                                              +-> scene_rows: n / start / end / start_sec / end_sec
        v
open_video(video_path) -> save_images(scenes, video, num_images, output_dir) -> файлы кадров
        v
нормализация вывода save_images (dict {scene_num: [файлы]}  ИЛИ  list [файлы])  -> абсолютные пути
```

Ключевые детали реализации ([`scene_detect_mcp.py`](../../../tools/scene-detect-mcp/scene_detect_mcp.py)):

- **Version-robust импорт `save_images`:** сначала `scenedetect.output` (v0.7), при `ImportError` — fallback на
  `scenedetect.scene_manager` (v0.6). Сервер работает на обеих линейках PySceneDetect.
- **Нормализация путей кадров:** `save_images` в разных версиях возвращает то `dict` (`{scene_num: [имена]}`),
  то `list` (`[имя, …]`). Сервер разбирает оба формата и приводит относительные имена к абсолютным путям через
  `output_dir`.
- **Обработка ошибок:** отсутствующий файл и любое исключение детекции возвращаются как
  `{ok: False, error: "..."}` — сервер не падает, а отдаёт диагностируемый ответ.

## Установка и регистрация

Код и виртуальное окружение — в [`tools/scene-detect-mcp/`](../../../tools/scene-detect-mcp/):

```bash
# из tools/scene-detect-mcp/
.venv\Scripts\python.exe -m venv .venv        # см. антипаттерн про голый python
.venv\Scripts\python -m pip install -r requirements.txt
```

Зависимости ([`requirements.txt`](../../../tools/scene-detect-mcp/requirements.txt)):
`mcp>=1.0.0`, `scenedetect>=0.6.4`, `opencv-python-headless>=4.9.0`, `numpy>=1.24`.

Регистрация в [`.mcp.json`](../../../.mcp.json):

```json
"scene-detect": {
  "command": "C:\\1С-Framework\\tools\\scene-detect-mcp\\.venv\\Scripts\\python.exe",
  "args": ["C:\\1С-Framework\\tools\\scene-detect-mcp\\scene_detect_mcp.py"],
  "timeout": 120000
}
```

> **Важно:** после правки `.mcp.json` нужен **полный рестарт Claude Code**, а не `/mcp reconnect`
> (reconnect не перечитывает конфигурацию серверов).

## Параметр `threshold` — настройка чувствительности

`threshold` управляет порогом `ContentDetector`: насколько сильным должно быть изменение содержимого кадра,
чтобы считаться склейкой.

- **Меньше порог (например 20)** → детектор чувствительнее → **больше** обнаруженных сцен (ловит мягкие
  переходы, плавные смены).
- **Больше порог (35+)** → детектор строже → **меньше** сцен (только резкие склейки).
- Дефолт `27.0` — баланс для большинства реальных видео.

Если на реальном видео часть переходов «потерялась» — снижайте порог. Если сцен слишком много (ложные
срабатывания на дрожании камеры/освещении) — повышайте.

## Примеры

**Раскадровка с дефолтами** (кадры → `<папка видео>/scene_frames`):

```text
extract_scene_frames(video_path="D:/clips/demo.mp4")
-> { ok: true, count: 7, scenes: [...7...], images: ["D:/clips/scene_frames/...", ...], ... }
```

**Повышенная чувствительность + своя папка + 2 кадра на сцену:**

```text
extract_scene_frames(
    video_path="D:/clips/demo.mp4",
    threshold=20.0,
    output_dir="D:/clips/storyboard",
    num_images=2,
)
```

**Непрерывный план (склеек нет):**

```text
extract_scene_frames(video_path="D:/clips/single_take.mp4")
-> { ok: true, count: 0, scenes: [], images: [], output_dir: "..." }
```

## Антипаттерны

| Плохо | Почему | Правильно |
|---|---|---|
| Кадр по таймкоду для «смены сцены» | интервал / I-frame ≠ визуальная смена плана | `ContentDetector` (этот MCP) |
| Тест на solid-цветах (заливках) | мягкие переходы недоловлены (smoke нашёл 1 из 2 склеек) | реальное видео ИЛИ снизить `threshold` (≈20) |
| `/mcp reconnect` после правки `.mcp.json` | не перечитывает конфигурацию серверов | полный рестарт Claude Code |
| Голый `python -m venv` | Store-alias python на Windows (exit 49) | `.venv\Scripts\python.exe -m venv …` |
