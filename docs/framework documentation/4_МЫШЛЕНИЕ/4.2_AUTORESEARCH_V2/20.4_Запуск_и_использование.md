# 20.4 Запуск и использование

AutoResearch v2 запускается тремя способами: PowerShell скрипт (Windows), Bash скрипт (Linux/Mac), шаблон Ralph Wiggum. Все варианты реализуют трёхагентный движок (Executor + Reviewer + Comparator).

## Быстрый старт

Три команды для начала работы:

```powershell
# Улучшить F1 skill router
.\scripts\autoresearch.ps1 -Domain skills -MaxIterations 15

# Убрать все ошибки ruff
.\scripts\autoresearch.ps1 -Domain python-quality -Target 0

# Через шаблон Ralph Wiggum
scripts\ralph.bat --template autoresearch --max-iterations 20
```

---

## autoresearch.ps1 — основной скрипт (Windows)

Основной интерфейс для запуска циклов AutoResearch в среде Windows с полной поддержкой persistence и метрик.

### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `-Domain` | string | ОБЯЗАТЕЛЬНЫЙ (если нет `-IdeaDir`). Значения: `skills`, `skill-health`, `python-quality`, `bsl`, `docs`, `hooks`, `security`, `tests` |
| `-IdeaDir` | string | Путь к custom рецепту, созданному через `/autoresearch:plan` |
| `-MaxIterations` | int | Максимальное количество итераций (по умолчанию 10) |
| `-Target` | string | Целевая метрика. Останов при достижении |
| `-CompareEvery` | int | Частота запуска Comparator (по умолчанию 5) |

### Настройки среды

Скрипт автоматически устанавливает:
- `chcp 65001` — кодировка UTF-8 в консоли
- `PYTHONIOENCODING=utf-8` — кодировка Python
- `RALPH_ENABLED=1` — флаг активации Ralph Wiggum

---

## autoresearch.sh — Bash эквивалент (Linux/Mac)

Полнофункциональный аналог для Unix-систем с использованием getopt для парсинга аргументов.

### Параметры

| Флаг | Аргумент | Описание |
|------|----------|----------|
| `-d` | domain | Домен (обязателен если нет `-i`) |
| `-n` | int | Max iterations (default 10) |
| `-t` | value | Target metric |
| `-c` | int | Compare every (default 5) |
| `-i` | path | Custom idea directory |
| `-h` | — | Справка |

### Примеры

```bash
./scripts/autoresearch.sh -d skills -n 15 -t 0.85
./scripts/autoresearch.sh -d python-quality -t 0
```

---

## ralph.bat — шаблонный запуск

Упрощённый запуск через систему шаблонов Ralph Wiggum. Подходит для разовых задач без необходимости отслеживания метрик.

### Шаблон autoresearch

```batch
scripts\ralph.bat --template autoresearch --max-iterations 20
```

### Другие доступные шаблоны

- `skill-health` — диагностика состояния скиллов
- `quality` — проверка качества Python кода
- `1c-study` — изучение конфигурации 1С:Предприятие

## Практические сценарии

### Сценарий 1: Первый запуск — диагностика

Рекомендуется начать с диагностики текущего состояния системы.

```powershell
.\scripts\autoresearch.ps1 -Domain skill-health -MaxIterations 3
```

**Результат:** health report покажет проблемные скиллы с приоритетами: HIGH WASTE, ROUTER MISS, NEVER USED.

---

### Сценарий 2: Довести F1 до 0.85

Целевой режим с автоматической остановкой при достижении метрики.

```powershell
.\scripts\autoresearch.ps1 -Domain skills -MaxIterations 30 -Target 0.85
```

Система остановится раньше, если F1 достигнет 0.85, или при обнаружении плато (5 итераций без улучшений).

---

### Сценарий 3: Ноль ошибок ruff

Полное исправление lint-ошибок в Python-коде.

```powershell
.\scripts\autoresearch.ps1 -Domain python-quality -Target 0
```

За каждую итерацию Claude исправит одну категорию ошибок (F401, E501, W291...). При `-Target 0` остановится когда ошибок не останется.

---

### Сценарий 4: Custom идея через wizard

Создание собственного рецепта через интерактивный планировщик.

```
> /autoresearch:plan   (в Claude Code)
# ... прохождение 5 gates ...
# Создана директория: data/autoresearch/api-speed-20260320/

.\scripts\autoresearch.ps1 -IdeaDir data/autoresearch/api-speed-20260320
```

---

### Сценарий 5: Продолжение прерванного цикла

autoresearch.ps1 сохраняет состояние в файл `autoresearch.md` после каждой итерации. При повторном запуске с тем же доменом система продолжит с прерванной итерации:

```powershell
# Первый запуск: дошли до итерации 7
.\scripts\autoresearch.ps1 -Domain skill-health -MaxIterations 15

# Второй запуск: продолжит с итерации 8
.\scripts\autoresearch.ps1 -Domain skill-health -MaxIterations 15
```

---

### Сценарий 6: Ночной цикл безопасности

Автоматический аудит безопасности. Каждая итерация — один attack vector по STRIDE.

```powershell
.\scripts\autoresearch.ps1 -Domain security -MaxIterations 20
```

## Разница autoresearch.ps1 vs ralph.bat

| Характеристика | autoresearch.ps1 | ralph.bat |
|----------------|------------------|-----------|
| **Домены** | 8 фиксированных рецептов | 8 шаблонов + произвольный промпт |
| **Persistence** | Да (autoresearch.md) | Нет |
| **Парсинг метрики** | `METRIC:`, `F1:`, `VERDICT:` | `RALPH_DONE` маркер |
| **Плато-детекция** | 5 iter без улучшений → стоп | Нет |
| **Target** | `-Target` → стоп при достижении | Нет |
| **JSONL лог** | autoresearch.jsonl | Нет |
| **Когда использовать** | Длинные циклы с метрикой | Разовые задачи |

### Рекомендации по выбору

- **autoresearch.ps1** — для многократных циклов улучшения с отслеживанием прогресса
- **ralph.bat** — для быстрого запуска без необходимости сохранения состояния
