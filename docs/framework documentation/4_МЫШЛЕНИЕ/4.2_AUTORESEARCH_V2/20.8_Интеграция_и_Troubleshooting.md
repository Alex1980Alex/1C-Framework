# 20.8 Интеграция с Ralph Wiggum и Troubleshooting

## Интеграция с Ralph Wiggum

Система AutoResearch v2 интегрирована в экосистему Ralph Wiggum как отдельный Tier, что позволяет активировать автономные итеративные циклы через ключевые фразы в промптах.

### ralph_activator.py — Tier 1.5

AutoResearch добавлен как промежуточный уровень (Tier 1.5) между Simple и Brainstorm режимами. Это обеспечивает приоритет активации выше, чем у обычных исследовательских задач, но ниже, чем у критических операций.

**Порядок проверки тиеров в ralph_activator:**

1. **Tier 0: Simple** (NEVER activate) — fix, typo, git status, commit
2. **Tier 3: Factory** (12 iter) — новый хук, new skill
3. **Tier 1.5: AutoResearch** (20 iter) — autoresearch, автономный цикл, улучши метрику
4. **Tier 4: Phase** (15 iter) — новая фаза, new pipeline
5. **Tier 2.5: Brainstorm** (10 iter) — придумай, предложи
6. **Tier 2: Research** (8 iter) — исследуй, сравни подходы
7. **Tier 5: Multi-step** (10 iter) — нумерованные списки

**Сигналы активации AUTORESEARCH_SIGNALS:**

```python
AUTORESEARCH_SIGNALS = [
    "autoresearch", "автоисследование", "автономный цикл",
    "улучши метрику", "improve metric", "reduce errors",
    "уменьши ошибки", "повысь покрытие", "increase coverage",
    "optimize", "оптимизируй итеративно",
    "measure and improve", "keep/revert",
    "автономное улучшение",
]
```

**Criteria при активации:**

- `all listed items completed`
- `MEMORY.md updated`

Максимальное количество итераций: 20.

---

### ralph_wiggum_stop.py — маркеры завершения

Stop hook проверяет специфические маркеры в транскрипте для определения момента завершения цикла.

**Поддерживаемые маркеры завершения:**

- `RALPH_DONE`
- `TASK_COMPLETE_OK`
- `ALL_DONE`
- `AUTORESEARCH_DONE` (добавлено в v2)

**Расширенное сопоставление критериев в CRITERIA_SIGNAL_MAP:**

```python
"target metric reached": [
    "target reached", "цель достигнута",
    "autoresearch_done", "metric target", "target met"
],
"autoresearch complete": [
    "autoresearch_done", "autoresearch complete",
    "autoresearch завершён", "all iterations", "plateau"
]
```

### Поток: Ralph + AutoResearch

```
scripts\ralph.bat --template autoresearch --max-iterations 20
  │
  ▼ RALPH_ENABLED=1
  │
  ▼ ralph_activator.py
  │   └── detects "autoresearch" → activates Ralph (max 20 iter)
  │
  ▼ claude -p "запусти AutoResearch v2 цикл"
  │   └── Claude вызывает Skill('autoresearch')
  │   └── Запускает autoresearch.ps1 или работает итеративно
  │
  ▼ На каждом Stop:
  │   ralph_wiggum_stop.py проверяет:
  │   - AUTORESEARCH_DONE в transcript?
  │   - "target metric reached" criteria?
  │   - Если нет → блокирует остановку
  │
  ▼ Когда AUTORESEARCH_DONE найден → allow stop
```

**Ключевые моменты:**

- Переменная окружения `RALPH_ENABLED=1` устанавливается автоматически при запуске через ralph.bat
- Stop hook блокирует преждевременную остановку до достижения критериев
- Цикл продолжается до явного маркера завершения или исчерпания лимита итераций

## Troubleshooting

### Метрика всегда null в autoresearch.jsonl

**Причина:** Claude выводит метрику в нестандартном формате, например `F1: 0.72` вместо ожидаемого `METRIC: 0.72`.

**Решение:** Скрипт autoresearch.ps1 поддерживает три формата парсинга:

1. `METRIC:\s*([\d.]+)` — каноничный формат
2. `"metric_after":\s*([\d.]+)` — JSON формат
3. `F1[\s:=]+([\d.]+)` — альтернативный формат

---

### Executor не делает коммит

**Причина:** Изменения выходят за пределы scope или обнаружен повтор Dead End.

**Решение:** Скрипт детектирует ситуацию через проверку `(commitBefore == commitAfter)`. В этом случае:

- Записывается `SKIP` в лог
- Инкрементируется счётчик `plateauCount`
- Цикл продолжается со следующей гипотезой

---

### Claude галлюцинирует результаты

**Симптом:** Claude отчитывается об изменениях, которых нет в git истории.

**Решение:**

1. Проверяйте git log после прогона: `git log --oneline -5`
2. Используйте меньше итераций (5-10 вместо 20+)
3. Длинные сессии в headless mode теряют контекст

---

### Плато после 2-3 итераций

**Причина:** Все лёгкие улучшения уже сделаны, система достигла локального оптимума.

**Решение:**

1. Переключитесь на другой домен улучшений
2. Запустите `/autoresearch` в интерактивном режиме для ручного управления
3. Пересмотрите подход — возможно нужны более глубокие изменения

---

### ralph_activator ложно активирует на обычные задачи

**Причина:** Простой промпт случайно содержит trigger keyword из AUTORESEARCH_SIGNALS.

**Решение:** Реализован guard через `RALPH_ENABLED`:

- В интерактивном режиме (без env var) Ralph никогда не активируется
- Активация происходит только в headless режиме через ralph.bat
- Проверка: `echo $env:RALPH_ENABLED`

---

### UTF-8 проблемы на Windows

**Симптом:** Кириллица в выводе Claude отображается некорректно.

**Решение:** Скрипт autoresearch.ps1 автоматически настраивает кодировку:

```powershell
chcp 65001
$env:PYTHONIOENCODING = "utf-8"
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```

---

### Dashboard показывает [No data]

**Причина:** Dashboard ищет файл autoresearch.jsonl не в той директории.

**Решение:** Укажите путь явно:

```bash
python scripts/autoresearch-dashboard.py data/autoresearch/
```

Проверьте существование файла: `ls data/autoresearch/autoresearch.jsonl`
