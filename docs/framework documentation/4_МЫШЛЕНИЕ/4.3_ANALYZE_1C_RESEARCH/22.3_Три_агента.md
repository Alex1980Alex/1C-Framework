# 22.3 Три агента

Система состоит из трёх специализированных агентов с чётким разделением обязанностей.

## Executor

Отвечает за фазы 1-4 анализа.

- **Итерация 1:** Полный 5-фазный анализ, создание `analysis-report.md`
- **Итерация N>1:** Читает `reviewer_feedback.json`, исправляет ровно ONE gap
- **Инструменты MCP:** `bsl_search`, `bsl_hybrid_search`, `get_metadata`, `execute_query`
- **Правила:**
  - Одно изменение за итерацию (атомарное, объяснимое в 1 предложении)
  - Не оценивает свою работу
  - Commit перед review
  - Не повторяет Dead Ends из `autoresearch.md`
- **Маркеры:** Добавляет `✓ get_metadata`, `✓ pattern`, `✓ execute_query`, `[REQ-N]` при каждом изменении

## Reviewer

Отвечает за фазу 5, скоринг и контроль качества.

- Запускает scorer: `python scripts/score-analysis-report.py`
- Верифицирует до 3 полей через `get_metadata`
- Валидирует до 2 SQL через `execute_query`
- Max 3 MCP calls per iteration (cost control)
- **Verdict:**
  - `KEEP` — score улучшился, gaps уменьшились
  - `IMPROVE` — score улучшился, но gaps остались
  - `REVERT` — score упал или не изменился
- Формирует `reviewer_feedback.json` с конкретным списком gaps
- Обновляет `autoresearch.md`: History table, Dead Ends

## Comparator

Слепое A/B сравнение каждые 3 итерации.

- Читает текущий отчёт (Version B) и baseline через `git show` (Version A)
- Оценивает обе версии по 5 критериям (1-10):
  - Completeness — все требования имеют точки модификации
  - Correctness — имена полей, SQL запросы точны
  - Patterns — использованы образцы из конфигурации
  - Actionability — план достаточно детален для реализации
  - Test coverage — тест-план покрывает edge cases
- Output: JSON с winner и scores
- Цель: поймать падение качества, которое пропустил scorer

## Разделение обязанностей

| Агент | Пишет | Читает | MCP | Verdict |
|-------|-------|--------|-----|---------|
| Executor | `analysis-report.md` | feedback, dead ends | Да (любые) | Нет |
| Reviewer | `feedback.json`, `autoresearch.md` | report, scorer output | Да (verify only) | Да |
| Comparator | `autoresearch.md` | report A, report B | Нет | Winner A/B |
