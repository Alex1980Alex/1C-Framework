# 22.4 Запуск и использование

Система поддерживает три режима работы.

## Интерактивный (Claude Code)

Запуск через чат-интерфейс с полным контролем процесса:

```
/analyze-1c-task:research
GKSTCPLK-1234: Добавить расчёт НДС
```

- **Executor** работает в главном контексте (полный доступ к MCP)
- **Reviewer** и **Comparator** запускаются как Agent subagents
- Пользователь видит прогресс: `Score: 78/100. 2 gaps. IMPROVE.`
- Можно вмешиваться: "сфокусируйся на SQL", "этот вопрос пропусти", "достаточно, score 78 хватит"

## Headless (PowerShell)

Автоматизированный запуск через CLI:

/analyze-1c-research

```powershell
# Базовый запуск
.\scripts\analyze-1c-research.ps1 -TaskFile docs/tasks/GKSTCPLK-1234.md

# С параметрами
.\scripts\analyze-1c-research.ps1 -TaskFile task.md -TargetScore 90 -MaxIterations 10

# Возобновление сессии
.\scripts\analyze-1c-research.ps1 -SessionDir data/analyze-1c-research/GKSTCPLK-1234

  # 1. Авто-определение — скрипт найдёт где остановился
  .\scripts\analyze-1c-research.ps1 -SessionDir "data/analyze-1c-research/GKSTCPLK-2262" -ResumeFrom auto

  # 2. Конкретная фаза — пропустить до P4
  .\scripts\analyze-1c-research.ps1 -SessionDir "data/analyze-1c-research/GKSTCPLK-2262" -ResumeFrom EXEC-P4

  # 3. С Reviewer — пропустить Executor
  .\scripts\analyze-1c-research.ps1 -SessionDir "data/analyze-1c-research/GKSTCPLK-2262" -ResumeFrom REV-S1
```

**Параметры:**

| Параметр         | По умолчанию | Описание                         |
| ---------------- | :----------: | -------------------------------- |
| `-TaskFile`      |      --      | Путь к файлу с описанием задачи  |
| `-SessionDir`    |      --      | Путь к папке сессии (для resume) |
| `-TargetScore`   |      85      | Целевой балл качества            |
| `-MaxIterations` |      7       | Максимум итераций                |
| `-CompareEvery`  |      3       | Частота Comparator               |

## Автономный (Ralph Wiggum)

Полностью автоматический режим:

```bash
scripts\ralph.bat --template 1c-analysis --task docs/tasks/GKSTCPLK-1234.md --max-iterations 7
```

## Структура сессии

```
data/analyze-1c-research/{task-id}/
  task.md                    # Исходное ТЗ
  analysis-report.md         # Живой отчёт (обновляется каждую итерацию)
  autoresearch.md            # Состояние: iteration, bestMetric, plateau, dead ends
  reviewer_feedback.json     # Текущие gaps для Executor
  autoresearch.jsonl         # Журнал итераций (JSON Lines)
  logs/
    executor_N.txt           # Вывод Executor итерации N
    reviewer_N.txt           # Вывод Reviewer итерации N
    comparator_N.txt         # Вывод Comparator (каждые 3 итерации)
```

## Условия завершения

| Условие                       | Действие                           |
| ----------------------------- | ---------------------------------- |
| `score >= target` (85)        | SUCCESS: цель достигнута           |
| 3 итерации без улучшения      | PLATEAU: требуется ручной review   |
| `MaxIterations` достигнут (7) | TIMEOUT: лучший результат сохранён |
| Маркер `AUTORESEARCH_DONE`    | Ранняя остановка                   |

## Resume

При запуске с `-SessionDir` скрипт считывает из `autoresearch.md` текущую итерацию, лучший балл и счётчик плато, и продолжает с прерванного места.
