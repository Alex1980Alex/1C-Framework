# 43.9.11 Деплой и управление конфигурацией/ИБ

> **Тип:** применение изменений конфигурации в информационную базу + управление проектами/ИБ/выгрузкой. Глава
> каталога [43.9](43.9_ИНСТРУМЕНТЫ_ПО_ТИПАМ.md). Этапы: **3-4** (применить правки → тестировать). Сама правка
> кода/метаданных — в [43.9.5](43.9.5_ЗАПИСЬ_И_РЕФАКТОРИНГ.md).

## Назначение
Довести записанные правки до работающей ИБ (обновление конфигурации БД), а также создать/удалить ИБ/проект,
выгрузить/загрузить конфигурацию из XML, управлять конфигурациями запуска.

## Инструменты

| Функция | Сервер / CLI | Что делает | Подводный камень |
|---|---|---|---|
| `update_database` ⭐ | edt-mcp | применить конфигурацию в ИБ (INCREMENTAL/FULL, **preview→confirm**) | НЕ обновляет **поставляемые профили** БСП; hard-timeout при монопольном доступе |
| `get_applications` / `list_configurations` | edt-mcp | приложения (ИБ) + конфигурации запуска (для target `update_database`) | applicationId/launchConfigurationName |
| `create_infobase` / `delete_infobase` | edt-mcp | создать/удалить ИБ | dev-ИБ паттерны — [[reference-dev-infobases]] |
| `create_project` / `delete_project` | edt-mcp | создать/удалить EDT-проект | — |
| `import_configuration_from_xml` / `export_configuration_to_xml` | edt-mcp | загрузка/выгрузка конфы из XML | — |
| `create_launch_config` / `delete_launch_config` | edt-mcp | конфигурации запуска клиента | — |
| Конфигуратор (`1cv8 DESIGNER … /UpdateDBCfg`) | CLI | пакетное обновление БД/расширения вне EDT | для `.cfe`/расширений ([[reference-1c-mcp-crud-extension-restore]]) |
| `ibcmd` | CLI | headless управление ИБ/конфигурацией | CI/масштаб |
| cc-1c-skills `db-*` (`db-create`/`db-load-cf`/`db-load-dt`/`db-dump-cf`/`db-update`/`db-list`/`db-run`…) | offline (скрипты) | headless жизненный цикл ИБ: создать/загрузить/выгрузить/обновить/прогнать | скриптуемо в батч/CI (без EDT/живой ИБ) |
| cc-1c-skills `cfe-*` (`cfe-init`/`cfe-borrow`/`cfe-patch-method`/`cfe-diff`/`cfe-validate`) | offline (скрипты) | инициализация/патч/диф/валидация **расширений** (`.cfe`) | offline round-trip расширения |
| cc-1c-skills `epf-*` (`epf-init`/`epf-build`/`epf-dump`/`epf-validate`) | offline (скрипты) | сборка/разборка/валидация **внешних обработок** (`.epf`) | offline build (ADR-031) |

## Выбор среди альтернатив

- **Применить правки конфигурации в dev-ИБ** → **`update_database`** (edt; preview без `confirm`, затем
  `confirm=true`). Target — `launchConfigurationName` (предпочт.) или `projectName`+`applicationId`.
- **После правки ПРАВ (профилей)** → `update_database` **+ обязательно** обновить поставляемые профили:
  `execute_code` → `Справочники.ПрофилиГруппДоступа.ОбновитьПоставляемыеПрофилиПоИзменениямКонфигурации()`
  (EDT-update сам их не обновляет — прецедент GKSTCPLK-2521 T3).
- **Расширения/`.cfe` вне EDT, CI, пакетно** → Конфигуратор (`DESIGNER /UpdateDBCfg -Extension`) / `ibcmd`.
- **Перенос конфы между средами** → `export/import_configuration_from_xml`.

## Когда применять
Кодирование — `update_database` после записи (+ revalidate/errors из [43.9.9](43.9.9_СТАТАНАЛИЗ_И_КАЧЕСТВО.md)
перед этим). Тестирование — обновить TestDB перед прогоном. Управление ИБ/проектами — операционные задачи.
