# 43.9.5 Запись и рефакторинг кода/метаданных

> **Тип:** изменение конфигурации — запись BSL, создание/правка метаданных, рефакторинг символов. Глава
> каталога [43.9](43.9_ИНСТРУМЕНТЫ_ПО_ТИПАМ.md). Этап: **3 Кодирование**. Основной write-path — **`edt-mcp`**.
> Применение записанного в ИБ (`update_database`) — в [43.9.11](43.9.11_ДЕПЛОЙ_И_ИБ.md); правка форм/СКД/макетов
> — в [43.9.6](43.9.6_ФОРМЫ_СКД_МАКЕТЫ.md).

## Назначение
Внести правки в код и метаданные конфигурации: тело методов, новые реквизиты/объекты, переименование символов,
точечная правка `.bsl`. После записи — валидация (`revalidate_objects`/`get_project_errors` из
[43.9.9](43.9.9_СТАТАНАЛИЗ_И_КАЧЕСТВО.md)).

## Инструменты

| Функция | Сервер / тул | Что пишет | Подводный камень |
|---|---|---|---|
| `write_module_source` ⭐ | edt-mcp | BSL-модуль/метод | снапшот EDT может затереть чужие правки — verify git diff перед commit ([[feedback-edt-mcp-stale-snapshot]]) |
| `create_metadata` | edt-mcp | новый объект/реквизит (FQN с `.Attribute.<Имя>`) | роли **не создаёт** — файлами (.mdo+Rights.rights+Configuration.mdo, [[project-1c-bsp-roles-workflow]]) |
| `modify_metadata` | edt-mcp | свойства существующего объекта | — |
| `rename_metadata_object` / `adopt_metadata_object` / `delete_metadata` | edt-mcp | переименование/принятие/удаление объекта | — |
| `get_content_assist` | edt-mcp | автодополнение при написании | — |
| `revalidate_objects` | edt-mcp | пере-валидация после правки | парный с `get_project_errors` ([43.9.9](43.9.9_СТАТАНАЛИЗ_И_КАЧЕСТВО.md)) |
| `resync_to_disk` | edt-mcp | синхронизация модели EDT с диском (детектор dangling-ссылок) | при коллизии диск/снапшот |
| `Edit` / `Write` | нативный | точечная правка `.bsl` на диске | потом `revalidate`/`update_database`; точное совпадение строки (табы!) |
| `bsl_rename_symbol` | bsl-semantic-search | rename символа cross-file | путь `[REFACTOR]` |
| `bsl-symbol-editing` (skill) | native Edit | замена тела метода / safe-delete | `bsl_replace_method_body`/`bsl_safe_delete_symbol` сервером **не экспонируются** |

## Выбор среди альтернатив

- **BSL/метаданные** → `edt-mcp` (`write_module_source`/`create_metadata`/`modify_metadata`) — дефолт
  (модель EDT остаётся консистентной + `update_database`).
- **Точечная правка `.bsl`**, когда EDT-write неудобен → нативный `Edit` (точное совпадение, табы) → затем
  `revalidate_objects`. ⚠ при коллизии снапшота — `checkout` + повтор Edit ([[feedback-edt-mcp-stale-snapshot]]).
- **Рефакторинг символа:** rename → `bsl_rename_symbol`; замена тела/удаление → skill `bsl-symbol-editing`
  (native Edit). Перед удалением — полнота через `find_callers` ([43.9.4](43.9.4_ГРАФ_И_IMPACT.md)).
- **Роли** → создание/структуру роли — **файлами** (EDT-MCP роли не создаёт); правку **прав внутри роли** умеет
  codepilot1c (`inspect_role_rights` / `mutate_role_rights`, через хост плагина) — но каноничный путь остаётся
  файловый (.mdo+Rights.rights+Configuration.mdo). Правка прав в **профилях** — программно в
  `гкс_УправлениеДоступом` ([[project-1c-bsp-roles-workflow]], [[project-1c-referenced-catalog-read-rights]]).
