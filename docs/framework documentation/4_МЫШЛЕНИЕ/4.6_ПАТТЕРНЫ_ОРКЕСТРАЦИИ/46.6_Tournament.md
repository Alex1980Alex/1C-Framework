# 46.6 Tournament

> **Статус:** актуально на 2026-07-05 (аудит 260704). Методологическая глава; проверяй датированные ссылки при использовании.

> Гл. [46 Паттерны оркестрации](46.1_Обзор.md)

## Схема
```
prompt ─┬─ попытка_1 (угол A) ─┐
        ├─ попытка_2 (угол B) ─┼─ [судьи: оценка] → победитель (+ лучшее из проигравших)
        └─ попытка_3 (угол C) ─┘
```

## Суть и когда
**N независимых попыток** с разных углов → **судьи** оценивают → берётся победитель (а лучшие идеи
проигравших — графтятся). Применять, когда пространство решений широкое и «одна попытка + итерации» хуже,
чем «несколько разных попыток + выбор». Даёт разнообразие подходов и устойчивый выбор.

## Реализация в Claude Code
- Генерация N попыток **разными промптами/углами** (MVP-first / risk-first / user-first).
- **Параллельные судьи** оценивают по критериям → синтез из победителя.
- **Workflow judge-panel:** `parallel(attempts)` → `parallel(judges)` → выбрать max-score.

## Workflow-пример
```js
const angles = ['MVP-first','risk-first','user-first']
const attempts = await parallel(angles.map(a => () => agent(`Реши задачу, угол ${a}: ${args.task}`)))
const scores = await parallel(attempts.map(t => () => agent(`Оцени решение 1-10 по полноте+риску: ${t}`, {schema: SCORE})))
const win = attempts[scores.indexOf(Math.max(...scores.map(s => s.score)))]
return agent(`Синтезируй финал из победителя, добавив лучшее из остальных: ${win} | ${attempts}`)
```

## Реальный пример в нашем фреймворке
- **`task-evaluation`** (скилл, brainstorm-режим): генерирует **3-5 вариантов** → **evaluation matrix** (оценка по
  критериям) → рекомендация + основа для ADR. Это турнир вариантов с судейством по матрице.
- **Применяется реже** остальных (большинство задач — single-attempt + adversarial-verify); турнир оправдан на
  широких дизайн-развилках (выбор подхода, где ошибка дорогая) — фиксируется через ADR (`architecture-research`).

## Подводные камни
- Дорого (N попыток + судьи) — применять выборочно, на действительно широких развилках.
- Попытки должны быть **разными по углу** (иначе турнир вырождается); судьям дать явные критерии.
