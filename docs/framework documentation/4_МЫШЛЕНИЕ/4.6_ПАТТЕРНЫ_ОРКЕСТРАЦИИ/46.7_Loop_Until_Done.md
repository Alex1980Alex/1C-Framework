# 46.7 Loop Until Done

> **Статус:** актуально на 2026-07-05 (аудит 260704). Методологическая глава; проверяй датированные ссылки при использовании.

> Гл. [46 Паттерны оркестрации](46.1_Обзор.md)

## Схема
```
prompt → agent → [проверка] ──не готово──┐
            ↑__________________________________|
                       готово → ■ (терминал)
```

## Суть и когда
Итеративный цикл агента **до терминального условия** (счётчик / «всё найдено» / бюджет / verify-PASS).
Применять, когда размер результата заранее неизвестен (открытый поиск багов/находок) или нужна доводка до
прохождения проверки. Простой `count < N` пропускает «хвост» — лучше «K пустых раундов подряд».

## Реализация в Claude Code
- **Agent-loop:** `max_turns` / `max_budget_usd` — встроенное условие останова [code.claude.com/docs/en/agent-sdk/agent-loop].
- **Stop-хук** как гейт: блокирует завершение, пока условие не выполнено (decision=deny).
- **Workflow `while(cond){ await agent() }`** — loop-until-dry / loop-until-count / loop-until-budget.

## Workflow-пример
```js
const found = []; let dry = 0
while (dry < 2) {                                   // 2 пустых раунда подряд = стоп
  const r = await agent('Найди ещё баги в модуле', {schema: BUGS})
  const fresh = r.bugs.filter(b => !found.some(f => f.id === b.id))
  if (!fresh.length) { dry++; continue }
  dry = 0; found.push(...fresh)
}
return found
```

## Реальный пример в нашем фреймворке
- **Ralph-Wiggum в `code-verify`**: при FAIL — итеративный retry с фидбеком ревьюера, **≤3 итераций** до PASS,
  потом «manual review» (термин-гард). Применялся на момент написания (см. штамп).
- **`pipeline-protocol-stop`** (ADR-018): Stop-хук **блокирует** завершение, пока пайплайн задачи не доведён
  (decision=deny) — «loop until pipeline done».
- **Loop-until-budget** (Workflow): `while (budget.remaining() > 50k) { agent() }` — масштаб под `+Nk`-директиву.

## Подводные камни
- **Обязателен термин-гард** (max итераций / бюджет) — иначе бесконечный цикл. Дедуп против **всех виденных**
  (не только подтверждённых), иначе отклонённое возвращается каждый раунд и цикл не сходится.
