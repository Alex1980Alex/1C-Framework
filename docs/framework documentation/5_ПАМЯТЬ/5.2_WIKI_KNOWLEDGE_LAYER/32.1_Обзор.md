# 32. Wiki Knowledge Layer — слой канонических знаний

## 32.1 Обзор

**Wiki Knowledge Layer** — это **L3-слой памяти** фреймворка: канонический long-lived storage для high-confidence знаний, синхронизируемый bidirectionally с Knowledge Graph (L2-вектор + графовая сущность) и накапливаемый через promotion из vector memory `learned_patterns`. Файлы хранятся как plain markdown с YAML frontmatter в [`docs/wiki/`](../../../wiki/), индексируются в отдельную Qdrant коллекцию `wiki_pages_v1`, и доступны через `[[wiki-link]]` cross-references как из других wiki-страниц, так и из docstrings BSL/Python кода.

Каноническая ссылка на skill — [`wiki-pipeline`](../../../../.claude/skills/wiki-pipeline/SKILL.md). Spec формальных требований (MUST/SHALL/SHOULD) — [`openspec/changes/hermes-llm-wiki/specs/wiki-export-pipeline/spec.md`](../../../openspec/changes/hermes-llm-wiki/specs/wiki-export-pipeline/spec.md) (766 строк).

### Ключевая идея

- **Plain markdown + YAML frontmatter** — human-editable, git-friendly, Obsidian-совместимый. Никаких proprietary форматов.
- **Bidirectional sync с Graph** — изменения в графе автоматически экспортируются в wiki (forward sync); изменения в markdown файлах автоматически отражаются в графе (reverse sync через watchdog).
- **L2 → L5 promotion** — паттерны из `learned_patterns` Qdrant коллекции, накопившие достаточное `application_count` + `confidence`, автоматически продвигаются в `docs/wiki/drafts/` для review и финальной канонизации в `docs/wiki/entities/`.
- **5-layer memory model** — wiki = L3 (canonical) + L5 (drafts), сочетается с L1 SQLite episodic, L2 Qdrant semantic, L4 user `.md` memory через memory-first-hook v3 RRF (см. [chapter 27.3](../5.1_UNIFIED_MEMORY/27.3_Memory_First_Hook.md)).
- **kb-lint quality gate** — pre-commit hook валидирует frontmatter, naming conventions, wiki-link integrity. Workaround для двух багов upstream kb-lint 0.1.1 на Windows + Cyrillic (см. [chapter 32.8](32.8_Pre_commit_и_качество.md)).

### 5-layer retrieval model

Полное описание — [`docs/wiki/SCHEMA.md`](../../../wiki/SCHEMA.md). Краткая таблица:

| Layer | Storage | Content | Retrieval weight |
|---|---|---|---|
| **L1** | SQLite (`data/memory_ai.db`) | Session summaries, volatile context, важные сообщения | 0.30 |
| **L2** | Qdrant `learned_patterns` (4096d Qwen3) | Learned patterns с confidence, skills, experiences | 0.35 |
| **L3** | **`docs/wiki/`** (markdown + frontmatter) | **Promoted high-confidence knowledge, canonical** | **0.20** |
| **L4** | User memory (`MEMORY.md`, `.md` files) | User-facing notes, persistent across sessions | 0.15 |
| **L5** | **`docs/wiki/drafts/`** | **Pending promotion candidates** | **0.20** (shared с L3 во время active session) |

L3 и L5 — это два суб-слоя одного хранилища (`docs/wiki/`), разделённые по lifecycle: drafts требуют review/promote-to-entities, entities считаются canonical.

```
                  │ reverse sync          │ index             │ retrieval
          ┌───────┴───────┐       ┌───────┴───────┐    ┌──────┴─────────┐
          │ ReverseSync   │       │WikiSearchIndexer│  │memory-first-   │

          └───────┬───────┘       └───────┬───────┘    └──────┬─────────┘
                  │                       │                    │
                  ▼                       ▼                    ▼
          GraphStore.add_       Qdrant wiki_pages_v1   4-layer fusion
          relation(...)         (3 073 points × 4096d)  L1+L2+L3+L4
                                                        weighted RRF
                                                        ▼
                                                  systemMessage
                                                  → Claude context
```

Плюс L2 → L5 promotion отдельным циклом:

```
MCP apply_pattern (success=true)
   │
   ▼
vector_memory.handle_apply_pattern
   application_count++, confidence += 0.02
   │
   ▼ (next Stop event)
session-memory-save.try_promote_patterns
   │
   ▼ (subprocess timeout 4s)
WikiPromoter.scan_and_promote
   filter: confidence ≥ 0.8 AND application_count ≥ 5
   dedup: cosine ≥ 0.85
   │
   ▼
docs/wiki/drafts/<slug>.md + log.md entry
```
