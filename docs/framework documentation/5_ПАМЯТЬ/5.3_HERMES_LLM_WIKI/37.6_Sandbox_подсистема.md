## Архитектура

```

  │
  ├─ DryRunBackend          ✅ zero-dep CI fallback (50-call quota, records calls)
  ├─ LangSmithBackend       ✅ Firecracker microVM (GA May 2026, langsmith[sandbox])

```

```
                         → elif E2B_API_KEY: E2B
                         → else: DryRun
prefer="langsmith"      → LangSmithBackend (raises if no key)
prefer="e2b"            → E2BBackend (raises if no key)
prefer="dryrun"         → DryRunBackend (always works)
```

## Контракт ABC

[`src/pdf_framework/sandbox/base.py`](../../../../src/pdf_framework/sandbox/base.py):

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass
from pathlib import Path


@dataclass
class SandboxResult:
    stdout: str
    stderr: str
    exit_code: int
    duration_seconds: float
    truncated: bool = False  # True if output > ~100 KB


class SandboxQuotaExceeded(Exception):
    """Raised on 51st execute() call (daily quota)."""


class SandboxBackend(ABC):
    @abstractmethod
    async def execute(self, code: str, language: str = "python", timeout: float = 30.0) -> SandboxResult: ...

    @abstractmethod
    async def install(self, packages: list[str]) -> None: ...

    @abstractmethod
    async def upload(self, local_path: Path, remote_path: str) -> None: ...

    @abstractmethod
    async def download(self, remote_path: str, local_path: Path) -> None: ...

    @abstractmethod
    async def close(self) -> None: ...
```

### Internal: command building

```python
# langsmith_backend.py:_build_cmd
@staticmethod
def _build_cmd(code: str, language: str) -> str:
    """Build shell command. Assumes POSIX shell (sh/bash) receiver."""
    if language == "python":
        # POSIX safe escape: ' → '\''
        escaped = code.replace("'", "'\\''")
        return f"python -c '{escaped}'"
    if language == "bash":
        return code
    raise ValueError(f"Unsupported language: {language}")
```

**Security note:** Escape pattern `'\''` — textbook POSIX safe quote-break-out. Assumes sh/bash receiver (default для `python-sandbox` template). Если LangSmith когда-то ship'нет cmd.exe template — escape breaks silently, update before switching.

```python
execution = await asyncio.to_thread(self._sandbox.run_code, code, timeout=int(timeout))

stdout = "\n".join(execution.logs.stdout)
stderr = "\n".join(execution.logs.stderr)
exit_code = 0

err = getattr(execution, "error", None)

    name = getattr(err, "name", "Error")           # "NameError"
```

## Selector helper

[`__init__.py:select_backend()`](../../../../src/pdf_framework/sandbox/__init__.py):

```python
def select_backend(prefer: str = "auto") -> SandboxBackend:
    """Select sandbox backend by env keys + preference.

    Order: prefer → LANGSMITH_API_KEY → E2B_API_KEY → DryRun fallback.
    """
    if prefer == "dryrun":
        return DryRunBackend()

    if prefer == "langsmith" or (prefer == "auto" and os.getenv("LANGSMITH_API_KEY")):
        from .langsmith_backend import LangSmithBackend
        return LangSmithBackend()

    if prefer == "e2b" or (prefer == "auto" and os.getenv("E2B_API_KEY")):
        from .e2b_backend import E2BBackend
        return E2BBackend()

    return DryRunBackend()
```

## Security architecture

### Что sandbox защищает

1. **Filesystem** — write только в `/tmp` песочницы, нет доступа к host filesystem (кроме `upload`/`download` API)
2. **Network** — outbound по default запрещён (E2B), explicit allowlist для paid backends (LangSmith via Auth Proxy)
3. **CPU/Memory** — soft RAM limit, timeout 30s default, daily quota 50 execute() calls
4. **Secrets** — LangSmith Auth Proxy keeps credentials off the sandbox; E2B requires explicit env var injection

### Threat model

| Угроза | Mitigation |
|---|---|
| Agent generates `rm -rf /` | Sandbox filesystem isolation — кроме `/tmp` ничего не достижимо |
| Agent generates `import os; os.system(...)` | Same — bare metal недоступен |
| Agent leaks API keys через `print(os.environ)` | LangSmith Auth Proxy — keys not in env; E2B — каждый user manages own keys |
| Resource exhaustion (mining cryptocurrency) | Daily quota 50 + per-execute timeout 30s + sandbox lifetime 24h max |
| Stateful kernel pollution between sessions | Каждый `SandboxBackend` instance = own sandbox; closing releases |
| Network exfil to attacker-controlled host | E2B default deny outbound; LangSmith Auth Proxy gate-keeps |

### Что НЕ защищается

- **Кодовая логика agent-generated кода** — sandbox не понимает intent. Если agent просит execute "calculate x" но малишесный input — sandbox executes obediently. Защита от такого уровня — guardrails / input validation на уровне agent prompt, не sandbox.
