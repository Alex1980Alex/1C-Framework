# 15.1 Token Economy — экономия токенов и контроль качества

> Делегирование генерации контента на дешёвые LLM (Z.AI, Gemini, Llama) с обязательным ревью Opus.
> Mandatory Code Review после каждого изменения кода — независимо от источника.

---

## Обзор

Token Economy — система из двух взаимодополняющих компонентов:

1. **Z.AI Delegation Protocol** — делегирование генерации контента на дешёвые модели через LLM Rotation. Opus декомпозирует и ревьюит, Z.AI генерирует черновики. Экономия ~85% output-токенов.

2. **Code Review Enforcer** — PostToolUse хук, принуждающий Opus к самопроверке после КАЖДОГО изменения кода. Ловит ошибки как в собственном коде, так и в ревью черновиков Z.AI.

```
Пользователь: "Сгенерируй 10 файлов документации"
    │
    ▼
z-ai-delegation-enforcer.py (UserPromptSubmit)
    │ Детектирует: "сгенерируй" + "10 файлов" → ORCHESTRATOR (MEDIUM)
    │
    ▼
Opus: DECOMPOSE → 10 подзадач
    │
    ▼
Z.AI: llm_complete() × 10  ← дешёвая генерация
    │
    ▼
Opus: REVIEW каждый результат
    │
    ▼
Write() файлы → code-review-enforcer.py (PostToolUse)
                 │ Если .py/.ts/.bsl → обязательный self-review
                 │ Если .md/.json → пропуск (не код)
```

**Связь компонентов:** Z.AI генерирует дёшево, Code Review Enforcer гарантирует качество. Вместе: дешёвая генерация + обязательный контроль.

## Компоненты системы

| Компонент | Тип | Файл | Событие |
|-----------|-----|------|---------|
| Z.AI Delegation Enforcer | Hook | `.claude/hooks/z-ai-delegation-enforcer.py` | UserPromptSubmit |
| Code Review Enforcer | Hook | `.claude/hooks/code-review-enforcer.py` | PostToolUse (Write\|Edit) |
| Z.AI Delegation Protocol | Skill | `.claude/skills/z-ai-delegation/SKILL.md` | По запросу |
| LLM Rotation | MCP | `mcp__llm-rotation__llm_complete()` | Программный вызов |
