# 21.4 Adaptive Routing и Budget

> Автоматический выбор лучшего провайдера по метрикам качества, скорости и стоимости с контролем дневного бюджета.

## AdaptiveScorer

Скоринг провайдеров на основе скользящего окна последних запросов. Модуль: `src/shared/llm_rotation/adaptive.py`.

### Формула составного скоринга

```
score = 0.4 * quality + 0.3 * latency_score + 0.3 * cost_score
```

| Компонент | Формула |
|-----------|---------|
| latency_score | `max(0, 1 - avg_latency / 30.0)` |
| cost_score | `max(0, 1 - avg_cost / 0.01)` |
| quality | `length_score - error_penalty` |

**Эвристика качества:**
- `length_score = min(1, len(response) / 100)`
- `error_penalty = 0.5` при наличии подстрок `"error"`, `"sorry"`, `"i cannot"`

### Параметры

| Параметр | Default | Описание |
|----------|---------|----------|
| window_size | 20 | Размер скользящего окна |
| min_samples | 5 | Минимум записей для валидного скоринга |
| default_score | 0.5 | Значение при недостатке данных |
| quality_weight | 0.4 | Вес качества |
| latency_weight | 0.3 | Вес скорости |
| cost_weight | 0.3 | Вес стоимости |

### Методы

```python
record(provider: str, latency: float, tokens: int, quality: float) -> None
score(provider: str) -> float
get_stats(provider: str) -> dict  # samples, score, avg_quality, avg_latency, avg_cost, total_cost, total_tokens
save(path: str | Path) -> None    # JSON, последние window_size записей
load(path: str | Path) -> None
```

## BudgetTracker

Контроль дневного бюджета с автоматическим сбросом при смене даты.

### Параметры

| Параметр | Default | Описание |
|----------|---------|----------|
| daily_budget | 1.0 | Бюджет в долларах |
| alert_threshold | 0.8 | Порог предупреждения (80%) |

### Логика

- `record_cost(provider, cost)` -- фиксирует расход, проверяет порог
- `check_daily_reset()` -- автосброс при смене даты
- Alert генерируется при достижении `alert_threshold` (однократно)

### Properties

| Property | Описание |
|----------|----------|
| `total_spent` | Потрачено за день ($) |
| `budget_remaining` | Остаток бюджета ($) |
| `is_over_budget` | Превышен ли бюджет |

### Цены за 1000 токенов (PRICE_PER_1K_TOKENS)

| Провайдер | Цена ($) |
|-----------|----------|
| zai-glm5 | 0.002 |
| zhipu | 0.001 |
| gemini | 0.0 |
| openrouter | 0.0 |
| mistral | 0.001 |
| ollama-local | 0.0 |
| ollama-cloud | 0.0 |

Persistence: `save()`/`load()` сохраняют `spending` и `reset_date` в JSON.

## Выбор провайдера (get_best_provider)

Алгоритм `LLMRotationService.get_best_provider()`:

1. **Фильтрация:** `is_available() == True` и API-ключ задан (если требуется)
2. **Сортировка** по кортежу (ascending):
   ```
   (0 if HEALTHY else 1, -adaptive_score, consecutive_errors, priority, avg_response_time)
   ```
3. **Результат:** первый элемент отсортированного списка

При `adaptive_routing=False` -- adaptive_score всегда 0.5, выбор по priority.
