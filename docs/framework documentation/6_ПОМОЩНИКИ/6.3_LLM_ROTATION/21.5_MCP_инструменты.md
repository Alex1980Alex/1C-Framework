# 21.5 MCP-инструменты

> 5 MCP-инструментов для генерации текста, мониторинга и управления провайдерами LLM Rotation.

---

## Обзор инструментов

| Инструмент | Описание |
|------------|----------|
| `llm_complete` | Отправка промпта с автоматической ротацией провайдеров |
| `llm_get_stats` | Статистика всех провайдеров |
| `llm_reset_provider` | Сброс провайдера в HEALTHY |
| `llm_test_providers` | Тест доступности всех провайдеров |
| `llm_list_providers` | Список конфигураций провайдеров |

Реализация: `src/shared/llm_rotation/mcp.py`.

---

## llm_complete

Основной инструмент для генерации текста с автоматической ротацией провайдеров.

### Параметры

| Параметр | Тип | Required | Default | Описание |
|----------|-----|----------|---------|----------|
| prompt | string | Да | -- | Текст промпта |
| system_prompt | string | Нет | null | Системный промпт |
| model | string | Нет | null | Конкретная модель (например `glm-5`) |
| preferred_provider | string | Нет | null | Предпочтительный провайдер |
| temperature | number | Нет | 0.7 | Температура (0.0-2.0) |
| max_tokens | integer | Нет | 2048 | Максимум токенов |
| timeout | integer | Нет | auto | Таймаут в секундах (auto: 60/90/180) |

### Формат ответа

```json
{
  "provider": "zai-glm5",
  "model": "glm-5",
  "text": "...",
  "response_time": 2.345,
  "usage": {"prompt_tokens": 100, "completion_tokens": 200},
  "attempt": 1
}
```

### Примеры использования

Простой вызов:

```
mcp__llm-rotation__llm_complete(prompt="Напиши функцию сортировки на Python")
```

С системным промптом и увеличенным лимитом:

```
mcp__llm-rotation__llm_complete(
    prompt="Объясни декораторы",
    system_prompt="Ты Python-разработчик",
    max_tokens=4096
)
```

С предпочтительным провайдером:

```
mcp__llm-rotation__llm_complete(
    prompt="Переведи на английский: ...",
    preferred_provider="gemini"
)
```

## llm_get_stats

Мониторинг состояния всех провайдеров.

**Параметры:** нет.

**Возвращает по каждому провайдеру:**

| Поле | Описание |
|------|----------|
| status | healthy / degraded / cooldown / unavailable |
| circuit_breaker | closed / open / half_open |
| cb_fail_count | Текущий счётчик ошибок CB |
| priority | Приоритет провайдера |
| requests | Общее количество запросов |
| errors | Общее количество ошибок |
| avg_response_time | Среднее время ответа (сек) |
| available | Доступен ли для запросов |

При `adaptive_routing=True` дополнительно:
- adaptive score, samples, avg_quality, avg_cost

При `rate_limiting_enabled=True` дополнительно:
- rpm, available tokens, capacity

## llm_reset_provider

Восстановление провайдера после сбоев.

| Параметр | Тип | Required | Описание |
|----------|-----|----------|----------|
| provider | string | Да | Имя провайдера (например `zai-glm5`) |

**Сбрасывает:**
- Circuit Breaker -> CLOSED
- consecutive_errors -> 0
- status -> HEALTHY

**Когда использовать:**
- После исправления проблемы с провайдером
- При застревании провайдера в статусе COOLDOWN
- После восстановления API-ключа

---

## llm_test_providers

Проверка доступности всех провайдеров.

**Параметры:** нет.

**Действие:** отправляет `"Say 'OK'"` каждому доступному провайдеру с `max_tokens=10`.

**Результат:** список провайдеров со статусом (OK / ошибка) и временем ответа.

---

## llm_list_providers

Просмотр конфигурации провайдеров.

**Параметры:** нет.

**Показывает по каждому провайдеру:**
- Имя и приоритет
- Base URL
- Модель по умолчанию
- Формат API (openai / anthropic / ollama)
- Наличие API-ключа
- Лимиты (RPM, daily)

## Конфигурация MCP-сервера

Для подключения добавьте в `.mcp.json`:

```json
{
  "llm-rotation": {
    "command": "python",
    "args": ["-m", "src.shared.llm_rotation.mcp"],
    "cwd": "D:/1C-Framework"
  }
}
```

Сервер инициализирует `LLMRotationService` при первом вызове инструмента (lazy-init).
