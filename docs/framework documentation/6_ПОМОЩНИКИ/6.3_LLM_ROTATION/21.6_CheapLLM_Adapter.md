# 21.6 CheapLLM Adapter

> Адаптер для замены дорогого Claude на дешёвые LLM в компонентах фреймворка через LLM Rotation.

---

## Назначение

Компоненты фреймворка (grader, rewriter, hyde и др.) по умолчанию используют ChatAnthropic. Часть задач не требует качества Claude и может выполняться дешёвыми моделями.

Адаптер предоставляет `cheap_llm_call()` как drop-in замену для таких вызовов.

**Механизм fallback:** LLM Rotation не отвечает -> пустая строка -> вызывающий код использует Claude.

Реализация: `src/shared/llm_rotation/adapter.py`.

## Реестр компонентов (COMPONENT_REGISTRY)

| Компонент | Категория | max_tokens | temperature | Описание |
|-----------|-----------|------------|-------------|----------|
| grader | 1 | 50 | 0.0 | Бинарная оценка релевантности (yes/no) |
| hallucination_checker | 1 | 100 | 0.0 | Проверка заземлённости (grounded/not_grounded) |
| rewriter | 1 | 200 | 0.7 | Переписывание запроса |
| query_expansion | 1 | 300 | 0.7 | Расширение запроса |
| hyde | 1 | 512 | 0.3 | Гипотетический документ (HyDE) |
| search_classifier | 1 | 100 | 0.0 | Классификация сложности запроса |
| section_summary | 2 | 300 | 0.3 | Саммари секции |
| context_generator | 2 | 200 | 0.0 | Контекст для чанка |
| entity_extractor | 2 | 4096 | 0.0 | Извлечение сущностей (JSON) |
| community_summarizer | 2 | 1024 | 0.0 | Тематическое саммари |

**Категории:**
- **Категория 1** -- идеальные кандидаты, включены по умолчанию
- **Категория 2** -- возможные кандидаты, включаются через переменную окружения

## API

### is_cheap_llm_enabled

```python
def is_cheap_llm_enabled(component: str) -> bool
```

Проверяет, включён ли дешёвый LLM для указанного компонента. Учитывает глобальный флаг `LLM_ROTATION_ENABLED` и список включённых компонентов.

### cheap_llm_call

```python
async def cheap_llm_call(
    prompt: str,
    system_prompt: str | None = None,
    component: str = "unknown",
    max_tokens: int | None = None,
    temperature: float | None = None,
) -> str
```

Вызывает дешёвую LLM через LLM Rotation.

| Параметр | Описание |
|----------|----------|
| prompt | Текст промпта |
| system_prompt | Системный промпт (опционально) |
| component | Имя компонента для выбора параметров из реестра |
| max_tokens | Переопределение лимита (default из реестра) |
| temperature | Переопределение температуры (default из реестра) |

**Возвращает:** строку с ответом модели или пустую строку при ошибке.

### evaluate_response

```python
def evaluate_response(
    component: str,
    response: str,
    original_input: str = "",
) -> dict[str, Any]
```

Оценивает качество ответа по критериям компонента. Возвращает `{"passed": bool, "metric": str, "reason": str}`.

### discover_unregistered_components

```python
def discover_unregistered_components() -> list[dict[str, str]]
```

Сканирует `src/` на наличие `ChatAnthropic()`, `Anthropic()`, `.ainvoke()` в файлах, не покрытых COMPONENT_REGISTRY. Возвращает список кандидатов для интеграции с CheapLLM.

## Критерии качества (QUALITY_CRITERIA)

| Компонент | Метрика | Ожидаемый формат |
|-----------|---------|------------------|
| grader | exact_match | `yes` или `no` |
| hallucination_checker | exact_match | `grounded` или `not_grounded` |
| rewriter | different_from_input | Отличается от входного запроса |
| query_expansion | contains_keywords | Расширенный запрос с доп. терминами |
| hyde | min_length >= 30 | Гипотетический документ |
| search_classifier | valid_classification | `complexity type confidence` (regex) |
| entity_extractor | valid_json | JSON с entities/relations |
| section_summary | min_length >= 20 | 2-3 предложения |
| context_generator | min_length >= 10 | 1-2 предложения |
| community_summarizer | min_length >= 30 | Тематическое саммари |

## Использование в компонентах

```python
from src.shared.llm_rotation.adapter import cheap_llm_call, is_cheap_llm_enabled

async def grade_document(query: str, document: str) -> str:
    prompt = f"Is this document relevant?\nQuery: {query}\nDocument: {document}"

    if is_cheap_llm_enabled("grader"):
        result = await cheap_llm_call(prompt, component="grader")
        if result:  # непустой ответ от дешёвой модели
            return result

    # Fallback to Claude
    return await claude_call(prompt)
```

## Конфигурация

| Переменная | Default | Описание |
|------------|---------|----------|
| `LLM_ROTATION_ENABLED` | `true` | Глобальный выключатель |
| `LLM_ROTATION_COMPONENTS` | все Category 1 | Список компонентов через запятую |

**Файл метрик:** `data/llm-rotation-metrics.jsonl`

Формат записи:
```json
{"ts": "2026-03-21T10:30:00+00:00", "component": "grader", "provider": "zai-glm5", "response_time_s": 1.5, "success": true, "fallback": false, "text_len": 3}
```
