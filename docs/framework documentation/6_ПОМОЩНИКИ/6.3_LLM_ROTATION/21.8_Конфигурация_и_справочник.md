# 21.8 Конфигурация и справочник

> Полный справочник настроек, переменных окружения и файлов данных LLM Rotation Service.

---

## Переменные окружения

Все переменные конфигурации используют префикс `LLM_ROTATION_`. Класс: `LLMRotationSettings` (pydantic-settings), файл: `src/shared/llm_rotation/config.py`.

### Основные настройки

| Переменная | Тип | Default | Описание |
|------------|-----|---------|----------|
| `LLM_ROTATION_PRIMARY_PROVIDER` | str | `claude-cli-haiku` | Основной провайдер (в этом репо `.mcp.json` переопределяет на `zai-glm5` — деплой-конфиг, НЕ дефолт кода; `zai-glm5` не входит в `DEFAULT_PROVIDERS`) |
| `LLM_ROTATION_MAX_RETRIES` | int | `3` | Максимум попыток fallback |
| `LLM_ROTATION_TIMEOUT` | int | `90` | Таймаут для коротких запросов (сек) |
| `LLM_ROTATION_TIMEOUT_GENERATION` | int | `120` | Таймаут для генерации (max_tokens 1024-3000) |
| `LLM_ROTATION_TIMEOUT_HEAVY` | int | `240` | Таймаут для тяжёлых задач (max_tokens > 3000) |
| `LLM_ROTATION_COOLDOWN_SECONDS` | int | `300` | Cooldown провайдера при ошибках (сек) |
| `LLM_ROTATION_RATE_LIMIT_COOLDOWN` | int | `60` | Cooldown при HTTP 429 (сек) |

### Force-Primary Mode

| Переменная | Тип | Default | Описание |
|------------|-----|---------|----------|
| `LLM_ROTATION_FORCE_PRIMARY` | bool | `true` | Сначала пытаться primary |
| `LLM_ROTATION_PRIMARY_MAX_RETRIES` | int | `2` | Повторы primary перед fallback |
| `LLM_ROTATION_PRIMARY_RETRY_DELAY` | float | `3.0` | Задержка между primary retry (сек) |
| `LLM_ROTATION_PRIMARY_COOLDOWN_SECONDS` | int | `30` | Cooldown primary провайдера (сек) |

### Circuit Breaker

| Переменная | Тип | Default | Описание |
|------------|-----|---------|----------|
| `LLM_ROTATION_CB_FAIL_THRESHOLD` | int | `3` | Порог ошибок для перехода в OPEN |
| `LLM_ROTATION_CB_SUCCESS_THRESHOLD` | int | `1` | Успешных probe для CLOSED |
| `LLM_ROTATION_CB_RESET_TIMEOUT` | float | `60.0` | Таймаут OPEN состояния (сек) |

### Backoff Strategy

| Переменная | Тип | Default | Описание |
|------------|-----|---------|----------|
| `LLM_ROTATION_BACKOFF_BASE_DELAY` | float | `1.0` | Базовая задержка (сек) |
| `LLM_ROTATION_BACKOFF_MAX_DELAY` | float | `30.0` | Максимальная задержка (сек) |
| `LLM_ROTATION_BACKOFF_JITTER` | float | `1.0` | Jitter [0..value] |
| `LLM_ROTATION_BACKOFF_MULTIPLIER` | float | `2.0` | Множитель экспоненты |

### Функции

| Переменная | Тип | Default | Описание |
|------------|-----|---------|----------|
| `LLM_ROTATION_HEALTH_CHECK_ENABLED` | bool | `true` | Фоновые health-check |
| `LLM_ROTATION_HEALTH_CHECK_INTERVAL` | int | `120` | Интервал проверок (сек) |
| `LLM_ROTATION_RATE_LIMITING_ENABLED` | bool | `true` | Token Bucket rate limiter |
| `LLM_ROTATION_ADAPTIVE_ROUTING` | bool | `true` | Adaptive scoring |

### Бюджет и Persistence

| Переменная | Тип | Default | Описание |
|------------|-----|---------|----------|
| `LLM_ROTATION_DAILY_BUDGET` | float | `1.0` | Дневной бюджет ($) |
| `LLM_ROTATION_BUDGET_ALERT_THRESHOLD` | float | `0.8` | Порог предупреждения (доля) |
| `LLM_ROTATION_PERSIST_ADAPTIVE` | bool | `true` | Сохранять adaptive данные |
| `LLM_ROTATION_ADAPTIVE_DATA_PATH` | str | `data/llm-rotation-adaptive.json` | Файл скоринга |
| `LLM_ROTATION_BUDGET_DATA_PATH` | str | `data/llm-rotation-budget.json` | Файл бюджета |

### API-ключи

| Переменная | Используется | Описание |
|------------|--------------|----------|
| `ANTHROPIC_API_KEY` | `anthropic-sonnet` (в `DEFAULT_PROVIDERS`) | Включает paid-API escape-hatch провайдер; без ключа `anthropic-sonnet` молча пропускается |
| `ZAI_API_KEY` | `zai_proxy.py` (отдельный компонент, НЕ `DEFAULT_PROVIDERS`) | Ключ для Z.AI OpenAI→Anthropic proxy |
| `ZHIPU_API_KEY` / `GEMINI_API_KEY` / `OPENROUTER_API_KEY` / `MISTRAL_API_KEY` | не используются | Legacy-поля `LLMRotationSettings` — провайдеры удалены из `DEFAULT_PROVIDERS` cleanup 2026-05-16, поля в `config.py` не вычищены |

### Ollama

| Переменная | Default | Описание |
|------------|---------|----------|
| `LLM_ROTATION_OLLAMA_URL` | `http://localhost:11434` | URL локального Ollama |
| `LLM_ROTATION_OLLAMA_CLOUD_URL` | `http://localhost:11434` | URL облачного Ollama |

## Файлы данных

| Файл | Описание |
|------|----------|
| `data/llm-rotation-completions.jsonl` | Лог всех запросов (провайдер, модель, время, токены) |

## Добавление нового провайдера

1. **Создать ProviderConfig** в `DEFAULT_PROVIDERS` (`service.py`):

   ```python
   ProviderConfig(
       name="new-provider",
       base_url="https://api.example.com/v1",
       api_key_env="NEW_PROVIDER_API_KEY",
       default_model="model-name",
       models=["model-name", "model-v2"],
       format="openai",  # "openai" | "anthropic" | "ollama"
       priority=7,
       rate_limit_rpm=30,
   )
   ```

2. **Добавить цену** в `PRICE_PER_1K_TOKENS` (`adaptive.py`):

   ```python
   PRICE_PER_1K_TOKENS["new-provider"] = 0.001
   ```

3. **Задать API-ключ** в `.env`:

   ```env
   NEW_PROVIDER_API_KEY=your-key
   ```

4. **Проверить** через MCP:

   ```
   mcp__llm-rotation__llm_test_providers()
   ```

## Публичный API

Экспорт из `src.shared.llm_rotation` (`__init__.py`, версия 2.0.0):

**Сервис и конфигурация:**
- `LLMRotationService` -- основной класс сервиса
- `ProviderConfig` -- конфигурация провайдера
- `ProviderState` -- runtime-состояние провайдера
- `ProviderStatus` -- enum (HEALTHY, DEGRADED, UNAVAILABLE, COOLDOWN)
- `DEFAULT_PROVIDERS` -- список провайдеров по умолчанию
- `get_service()` -- singleton-фабрика

**Circuit Breaker:**
- `CircuitBreaker` -- реализация паттерна
- `CircuitState` -- enum (CLOSED, OPEN, HALF_OPEN)

**Backoff и ошибки:**
- `BackoffStrategy` -- экспоненциальный backoff с jitter
- `RateLimitError` -- исключение при HTTP 429

**Scoring и бюджет:**
- `AdaptiveScorer` -- адаптивный скоринг провайдеров
- `BudgetTracker` -- трекер дневного бюджета
- `PRICE_PER_1K_TOKENS` -- словарь цен

**Rate Limiting:**
- `ProviderRateLimiter` -- менеджер rate limit
- `TokenBucket` -- алгоритм token bucket

**CheapLLM Adapter:**
- `cheap_llm_call()` -- дешёвый LLM-вызов
- `is_cheap_llm_enabled()` -- проверка включения
- `evaluate_response()` -- оценка качества ответа
- `discover_unregistered_components()` -- сканер незарегистрированных компонентов
- `COMPONENT_REGISTRY` -- реестр компонентов
- `QUALITY_CRITERIA` -- критерии качества
