## Концепция

**GLM Agent Factory** — система маршрутизации вызовов Claude Code `Agent()` на GLM-5.1 для задач, не связанных с BSL/1С. Это позволяет снизить затраты на API (переход с платных моделей Sonnet/Opus на бюджетный Z.AI) без потери качества результатов.

Система работает как **абстрактный уровень** между Claude Code и Claude API: для BSL-задач используется стандартный API, для универсального кода — GLM-5.1.

## Архитектура

GLM Agent Factory реализована в двух вариантах:

### План B: MCP Server (явные инструменты)

```
Claude Code Agent()
       |
mcp__glm-agent__{tool}()
       |
GLM-5.1 MCP Server (glm-mcp/server.py)
       |
GLM-5.1 API (Z.AI)
```

**Характеристики:**
- Явные MCP инструменты для каждого агента
- Полный контроль над маршрутизацией
- Требует явного вызова `mcp__glm-agent__{tool}()`

### План C: HTTP Proxy (прозрачная интерцепция)

```
Claude Code Agent()
       |
ANTHROPIC_BASE_URL=http://localhost:4000
       |
Router (glm-proxy/router.py)
  +-- BSL/1C --> Claude API
  +-- Universal --> GLM-5.1 API
       |
GLM-5.1 API (Z.AI) / Claude API
```

**Характеристики:**
- Прозрачная интерцепция через HTTP proxy
- Автоматический роутинг по типу кода
- Не требует изменений в коде Claude

## Критическое правило: BSL != GLM

```
+--------------------------------------+
|  BSL/1C код  -->  ВСЕГДА Claude      |
|  Универсальный код  -->  GLM-5.1     |
+--------------------------------------+
```

**GLM агенты НЕ понимают:**
- Синтаксис BSL (Процедура, Функция)
- Типы 1С (СправочникМенеджер, Запрос)
- Стандарты фреймворка 1C:Enterprise
- BSL-специфичные инструменты (ast-grep с `language="bsl"`)

Для анализа BSL всегда используйте Claude Agent с моделью `sonnet` или `opus`.

## Автоматическое отключение при ошибках

Встроенный **circuit breaker**:

- 3+ последовательных ошибки GLM API --> auto-disable
- Все запросы автоматически маршрутизируются на Claude API
- Re-enable: `GET /health?reset_glm=true` или restart proxy

## Интеграция с Claude Code

### Plan B (MCP инструменты)

```python
mcp__glm-agent__analyze(prompt="Analyze this module", files=["src/parser.py"])
mcp__glm-agent__review(prompt="Code review", files=["api/routes.js"])
mcp__glm-agent__research(prompt="Compare WebSocket vs SSE")
mcp__glm-agent__architect(prompt="Design event-driven system")
mcp__glm-agent__generate(prompt="Write LRU cache class")
mcp__glm-agent__write(prompt="Write API documentation")
```

### Plan C (прозрачное перенаправление)

```python
Agent(subagent_type="glm-analyst", model="haiku", prompt="...")  # --> GLM-5.1
Agent(subagent_type="Explore", model="sonnet", prompt="...")      # --> Claude API
```

### Fallback логика

```
GLM timeout/error --> Fallback to Claude API --> Полный результат
```
