## Назначение

HTTP Proxy перехватывает **все** API-вызовы Claude Code (включая Agent() и подагентов) на transport layer. Запросы с маркером `glm-*` направляются на GLM-5.1, остальные проходят к Anthropic API.

Преимущества перед MCP Server (Plan B):
- Прозрачный --- Claude Code не знает о подмене
- Перехватывает Agent() включая nested subagents
- Не зависит от hook bugs (#26923, #39814, #21460)

## Routing Engine

Три правила, оцениваются последовательно:

| # | Правило | Триггер | Пример |
|---|---------|---------|--------|
| 1 | MatchSubagentType | `metadata.subagent_type = "glm-*"` | `Agent(subagent_type="glm-analyst")` |
| 2 | MatchDescription | `glm-*` в description / первом user message | `"Use glm-coder to generate..."` |
| 3 | MatchSystemPrompt | `name: glm-*` в system prompt | Agent definition frontmatter |
| - | DefaultPassthrough | Ничего не совпало | Все остальные запросы |

Реализация: `glm-proxy/router.py`.

## Конфигурация

### Переменные окружения

| Переменная | Default | Описание |
|------------|---------|----------|
| `GLM_API_URL` | из zai-config.json | URL API GLM-5.1 |
| `GLM_API_KEY` | из zai-config.json | API ключ |
| `GLM_PROXY_PORT` | `4000` | Порт прокси |
| `GLM_MOCK_ENABLED` | `false` | Mock режим (без реальных API вызовов) |
| `GLM_FALLBACK_ANTHROPIC` | `true` | Fallback на Anthropic при ошибке GLM |
| `ANTHROPIC_BASE_URL_REAL` | из zai-config.json | Реальный Anthropic URL для passthrough |

### Config file

Прокси автоматически загружает `scripts/claude-backend/zai-config.json`:

```json
{
  "ANTHROPIC_DEFAULT_OPUS_MODEL": "glm-5.1",
  "ANTHROPIC_DEFAULT_SONNET_MODEL": "glm-5.1",
  "ANTHROPIC_AUTH_TOKEN": "<key>",
  "ANTHROPIC_BASE_URL": "https://api.z.ai/api/anthropic",
  "ANTHROPIC_DEFAULT_HAIKU_MODEL": "glm-4.5-air"
}
```

## Запуск

```bash
cd scripts/claude-backend/glm-proxy
python start_proxy.py
```

Вывод:
```
GLM Agent Factory Proxy
  Port: 4000
  Upstream: https://api.z.ai/api/anthropic
  GLM API: https://api.z.ai/api/anthropic
  Mock mode: False
  Agents: ['analyst', 'reviewer', 'coder', 'researcher', 'architect', 'writer']

  Set: ANTHROPIC_BASE_URL=http://localhost:4000
```

Затем запустить Claude Code с:
```bash
ANTHROPIC_BASE_URL=http://localhost:4000 claude
```

## Endpoints

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/v1/messages` | Основной endpoint --- routing + passthrough |
| GET | `/health` | Health check + статус auto-disable |
| GET | `/health?reset_glm=true` | Re-enable GLM после auto-disable |
| GET | `/metrics` | Последние 100 метрик запросов |

## Auto-Disable Logic

При 3+ consecutive ошибках GLM подряд прокси автоматически отключает маршрутизацию на GLM:

```
GLM error #1 -> fallback to Anthropic, counter=1
GLM error #2 -> fallback to Anthropic, counter=2
GLM error #3 -> AUTO-DISABLE, все запросы passthrough

GLM success (после re-enable) -> counter=0, auto-re-enabled
```

Конфигурация:
- `max_consecutive_errors`: порог (default: 3)
- `auto_disable_on_errors`: вкл/выкл (default: true)

Re-enable:
- `GET /health?reset_glm=true` --- ручной сброс
- Restart proxy --- автоматический сброс

Статус виден в `/health`:
```json
{
  "glm_auto_disabled": false,
  "consecutive_glm_errors": 0
}
```

## Streaming

Прокси поддерживает streaming для обоих направлений:

- **GLM streaming**: SSE passthrough от GLM API к Claude Code
- **Anthropic streaming**: прямой forward SSE от Anthropic к Claude Code

При ошибке GLM streaming --- fallback на Anthropic (non-streaming).
