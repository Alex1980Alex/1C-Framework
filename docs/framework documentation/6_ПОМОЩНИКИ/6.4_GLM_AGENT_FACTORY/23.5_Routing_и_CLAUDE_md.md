## Decision Flow

```
1. Можно ли сделать напрямую (Read/Edit/Grep)?   -> ДА -> ДЕЛАЙ, без Agent()
2. BSL/1C задача?                                -> ДА -> Claude Agent (sonnet/opus)
3. Universal code + GLM доступен?                -> ДА -> mcp__glm-agent__{tool}
4. Нужно параллельно в нескольких местах?        -> ДА -> Agent(model="sonnet")
5. Сложная архитектурная задача?                 -> ДА -> Agent(model="opus")
6. Простой lookup в фоне?                        -> ДА -> Agent(model="haiku")
```

## GLM Routing Table

| Тип задачи | Роутинг | Обоснование |
|-----------|---------|-------------|
| Анализ universal code | `mcp__glm-agent__analyze` | Не требует BSL контекст |
| Code review (Python/JS/etc) | `mcp__glm-agent__review` | Не требует BSL контекст |
| Генерация кода по spec | `mcp__glm-agent__generate` | Стандартные языки |
| Исследование | `mcp__glm-agent__research` | Knowledge-based |
| Архитектура (общая) | `mcp__glm-agent__architect` | Не зависит от языка |
| Документация | `mcp__glm-agent__write` | Текстовая задача |
| **Анализ BSL кода** | **Claude** (sonnet) | BSL специфика |
| **Multi-file рефакторинг** | **Claude** (sonnet) | Нужны Edit/Bash |
| **Параллельный поиск** | **Claude** (haiku) | Нужны Grep/Glob |
| **Критичная архитектура** | **Claude** (opus) | Макс. качество |

## Правило fallback

```
GLM timeout/error -> Claude Agent с той же моделью
```

При ошибке GLM:
1. MCP tool возвращает `[GLM Agent Error: ...]`
2. Claude видит ошибку и может переключиться на Claude Agent
3. HTTP Proxy автоматически делает passthrough к Anthropic

## Orchestrator Mode --- GLM Mixed Parallelism

Claude agents и GLM MCP tools можно вызывать параллельно:

```python
# OK: Claude Agent + GLM MCP tool в одном сообщении
Agent(model="sonnet", prompt="Analyze BSL module X")
mcp__glm-agent__analyze(prompt="Analyze Python module Y", files=["y.py"])
```

## Ограничения

- GLM-агенты **не имеют доступа** к файловой системе, Git, Bash --- только текст в prompt
- Для `analyze` и `review` файлы читаются MCP Server и вкладываются в prompt (max 50 KB)
- GLM-агенты **не понимают BSL** --- это design decision, не техническое ограничение
- Latency GLM-5.1 через Z.AI: 5--36s (зависит от output length)
