## Quick Rollback

### Plan C (HTTP Proxy)

```bash
# 1. Остановить proxy
taskkill /F /PID <pid>
# или найти процесс:
netstat -ano | findstr :4000

# 2. Убрать ANTHROPIC_BASE_URL
set ANTHROPIC_BASE_URL=
# или удалить из .env / shell profile

# 3. Перезапустить Claude Code
```

**Время:** < 2 минуты.

### Plan B (MCP Server)

```json
// .claude/mcp-servers.json
{
  "glm-agent": {
    "disabled": true
  }
}
```

**Время:** < 1 минута (+ restart Claude Code).

## Feature Flags

### Полное отключение

| Способ | Как |
|--------|-----|
| Proxy | Остановить процесс + убрать `ANTHROPIC_BASE_URL` |
| MCP | `"disabled": true` в mcp-servers.json |
| Config | `routing_enabled: false` в GLMConfig |

### Per-agent отключение

В `config.py` через env или код:

```python
config.agents_enabled = ["coder", "researcher"]
# analyst, reviewer, architect, writer -- отключены
# -> их запросы пойдут в Anthropic passthrough
```

### Mock режим

```bash
GLM_MOCK_ENABLED=true python start_proxy.py
```

Proxy возвращает mock-ответы без реальных API вызовов. Полезно для тестирования routing.

## Auto-Disable

При 3+ consecutive GLM ошибках:

```
[WARNING] GLM AUTO-DISABLED after 3 consecutive errors.
All requests will passthrough to Anthropic.
Reset via GET /health?reset_glm=true or restart proxy.
```

### Re-enable

```bash
# Вариант 1: HTTP reset
curl http://localhost:4000/health?reset_glm=true

# Вариант 2: Restart proxy
python start_proxy.py
```

## Troubleshooting

### GLM API timeout

**Симптом:** Задачи на analyst/architect занимают > 30s.

**Причина:** GLM-5.1 генерирует длинные ответы (1000--2000 tokens).

**Решение:**
- Ограничить `max_tokens` в запросе (default: 4096)
- Использовать `glm-4.5-air` для менее критичных задач
- Timeout configurable: `glm_timeout: 60` (в секундах)

### MCP Server не запускается

**Симптом:** `glm-agent` tools не появляются в Claude Code.

**Проверить:**
1. `PYTHONPATH` включает `scripts/claude-backend`
2. `aiohttp` установлен: `pip install aiohttp`
3. Логи: `scripts/claude-backend/glm-mcp/mcp-server.log`

### Proxy не перехватывает Agent()

**Симптом:** Agent() идет напрямую к Anthropic.

**Проверить:**
1. `ANTHROPIC_BASE_URL=http://localhost:4000` установлен
2. Proxy запущен: `curl http://localhost:4000/health`
3. Routing rules: проверить логи proxy

### Ошибка "attempted relative import"

**Симптом:** `ImportError: attempted relative import with no known parent package`

**Причина:** Запуск файла напрямую вместо как модуль.

**Решение:**
```bash
# Правильно:
cd scripts/claude-backend
python -m glm_proxy.proxy_server

# Или через start_proxy.py:
python glm-proxy/start_proxy.py
```

### Quality ниже ожидаемого

**Симптом:** GLM ответы неструктурированные или поверхностные.

**Проверить:**
1. System prompt загружается: проверить `.claude/agents/glm-{type}.md`
2. Правильный agent type: в логах `agent=analyst` vs `agent=coder`
3. Файлы вкладываются: в логах `files=N`

## Мониторинг

### Health check

```bash
curl http://localhost:4000/health
```

```json
{
  "status": "ok",
  "proxy_port": 4000,
  "glm_auto_disabled": false,
  "consecutive_glm_errors": 0,
  "requests_processed": 42,
  "agents_enabled": ["analyst", "reviewer", "coder", "researcher", "architect", "writer"]

```

```bash
curl http://localhost:4000/metrics
```

Возвращает последние 100 запросов с routing decision, latency, status.
