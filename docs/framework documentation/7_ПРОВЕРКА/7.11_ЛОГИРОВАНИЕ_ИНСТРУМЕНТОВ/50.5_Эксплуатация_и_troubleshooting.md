# 50.5 Эксплуатация и troubleshooting

Справочник CLI, переменных окружения, карта файлов и типовые проблемы контура логирования.

## CLI-команды

```bash
# Анализ здоровья инструментов (пишет data/reports/tools/_latest.{md,json})
.venv/Scripts/python.exe scripts/analyze_tool_health.py --window-days 14
.venv/Scripts/python.exe scripts/analyze_tool_health.py --reset-baseline [TOOL ...]  # выход из degraded-навсегда

# Cross-check native OTel ↔ hook (главная ценность тяжёлого пути)
.venv/Scripts/python.exe scripts/otel_crosscheck.py                 # markdown-секция
.venv/Scripts/python.exe scripts/otel_crosscheck.py --json --since-days 14

# Отчёт по вызовам (по run/session)
.venv/Scripts/python.exe scripts/tool_usage_report.py --run-id <id>
.venv/Scripts/python.exe scripts/tool_usage_report.py --rollup

# DuckDB SQL над логом
.venv/Scripts/python.exe scripts/audit_query.py --view latency-p95
.venv/Scripts/python.exe scripts/audit_query.py --view causation-chain --correlation-id <id>
.venv/Scripts/python.exe scripts/audit_query.py --sql "SELECT tool, count(*) FROM logs WHERE category='tool_call' GROUP BY 1"

# История вердиктов (повтор broken, healed, тренд)
.venv/Scripts/python.exe scripts/tool_verdict_history.py

# Health-probe зависимостей MCP
.venv/Scripts/python.exe scripts/probe_mcp_health.py

# LLM-judge на сэмпле (требует content-источник)
.venv/Scripts/python.exe scripts/tool_llm_judge.py --source <judge-items.jsonl> --langfuse

# Тяжёлый путь: нативный OTel + Langfuse
.venv/Scripts/python.exe scripts/otel/enable_claude_otel.py --console   # проверка эмиссии (zero-infra)
.venv/Scripts/python.exe scripts/otel/enable_claude_otel.py --otlp http://localhost:4318
.venv/Scripts/python.exe scripts/otel/enable_claude_otel.py --status
.venv/Scripts/python.exe scripts/otel/enable_claude_otel.py --disable
.venv/Scripts/python.exe scripts/otel/langfuse_up.py {up|status|down [--volumes]}
```

## Переменные окружения (opt-out / тюнинг)

| Переменная | Эффект |
|---|---|
| `TOOL_HEALTH_ANALYZER_DISABLE=1` | не запускать detached-анализ на Stop |
| `TOOL_HEALTH_BANNER_DISABLE=1` | не сюрфейсить alerts на SessionStart |
| `MCP_HEALTH_PROBE_DISABLE=1` | не пробить зависимости на SessionStart |
| `MCP_PROBE_1C_DISABLE=1` | не пробить 1С-инстансы |
| `MCP_PROBE_LANGFUSE_DISABLE=1` | не пробить Langfuse (даже при `.env.otel`) |
| `MCP_CALL_LOG_DISABLE=1` | отключить внутренний per-call лог MCP-серверов |
| `HOOK_LOG_ARCHIVES=N` | число ротированных архивов лога (default 12 ≈ 14 дней) |
| `TOOL_LOGGER_DEBUG_DUMP=1` | захват реальной формы payload → tool-response-shapes.jsonl |
| `CLAUDE_LOG_VALIDATE=1` | JSON-Schema валидация строк лога (advisory) |
| `CLAUDE_LOG_NO_CRYPTO=1` | не шифровать поле `error` |
| `DEGRADED_MIN_CALLS=N` | минимум вызовов для вердикта degraded (default 3) |

Тяжёлый путь (в `settings.local.json`, ставит `enable_claude_otel.py`): `CLAUDE_CODE_ENABLE_TELEMETRY`, `CLAUDE_CODE_ENHANCED_TELEMETRY_BETA`, `OTEL_{METRICS,LOGS,TRACES}_EXPORTER`, `OTEL_EXPORTER_OTLP_*`. Контент (PII): `OTEL_LOG_TOOL_CONTENT`/`_USER_PROMPTS`/`_TOOL_DETAILS` — **OFF по умолчанию**.

## Карта файлов

| Путь | Содержимое |
|---|---|
| `data/hook-invocations.jsonl` (+ `.1..N`) | основной лог событий/вызовов (gitignored) |
| `data/reports/tools/_latest.{md,json}` | отчёт здоровья инструментов (gitignored) |
| `data/reports/tools/verdicts.jsonl` | история вердиктов |
| `data/reports/tools/baseline.json` | ratchet-baseline p95/error-rate |
| `data/reports/tools/llm-judge.jsonl` | оценки LLM-judge |
| `data/mcp-health.jsonl` + `_mcp_health.json` | результаты health-probe |
| `data/otel/claude-otel-{logs,traces}.jsonl` | нативный OTLP-сырец (gitignored) |
| `.claude/cache/mcp-<server>-calls.jsonl` | per-call логи MCP-серверов |
| `.claude/cache/tool-response-shapes.jsonl` | дамп формы payload (диагностика) |
| `.env.otel` | секреты Langfuse (gitignored; шаблон `.env.otel.example`) |

## Troubleshooting

| Симптом | Причина / решение |
|---|---|
| Все инструменты success=100%, 0 ошибок | Ждёшь ошибку из Post — её нет (платформа не шлёт Post на провал built-in). Смотри `incomplete` (непарные Pre) в `_latest.md`, не error-rate. |
| Латентность тула ~20мс на всё | Смотришь `elapsed_ms` (время хука), а не `duration_ms`/пару. Реальная латентность — в `duration_ms`. |
| «Окно неполное» в отчёте | Ротация срезала хвост 14д. Подними `HOOK_LOG_ARCHIVES` или дай логу накопить архивы. |
| Множество degraded по p95 | Content-variable тулы (Bash/Grep) — латентность от контента; проверь, что они в списке исключений p95. |
| `mcp_call` строк нет для сервера | Правки MCP-серверного кода не применились — нужен `/mcp reconnect` (stdio держит старый код). |
| Native cross-check: все провалы как успех | OTLP `success`/`duration_ms` пришли как `stringValue` — нужен коэрсинг (`_coerce_bool`/`_coerce_int`); проверь версию `otel_crosscheck.py`. |
| Langfuse-web health 500 «Invalid env» | Проверь `.env.otel`: `LANGFUSE_INIT_USER_EMAIL` требует домен, `ENCRYPTION_KEY` = ровно 64 hex. |
| ClickHouse не стартует (port 9000) | Порт занят SonarQube — в compose ремап `127.0.0.1:9010:9000`. |
| Баннер молчит при явных проблемах | Проверь opt-out env (`*_DISABLE=1`) и cooldown (анализ 24ч, probe каждую сессию). |
