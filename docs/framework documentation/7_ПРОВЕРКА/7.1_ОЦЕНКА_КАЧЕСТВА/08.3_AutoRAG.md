# 08.3 AutoRAG — Автоматическая оптимизация

> **§3.4 GEPA migration (2026-05-16, roadmap 260509):** `DSPyOptimizer.optimize()` мигрирован с deprecated `dspy.MIPROv2` на `dspy.GEPA` (Generative Evolutionary Prompt Adaptation, DSPy ≥3.0). Reflection-based optimization c explicit feedback metric. Адаптер `_gepa_metric` оборачивает существующий `CompositeMetric` (2-arg) в `GEPAFeedbackMetric` Protocol (5-arg: gold, pred, trace, pred_name, pred_trace). `reflection_lm` переиспользует уже configured `dspy.LM`. API совместимость сохранена: `max_trials` параметр маппится на `max_full_evals` GEPA. **§3.4.3-§3.4.5 (compile + benchmark + default flip) deferred** до dedicated сессии с Anthropic API budget — POST /optimize endpoint code-ready.

> **§6.3.1 (2026-05-01):** `DSPyOptimizer.add_pairs_from_feedback(feedback_store)` реализован как async (был stub, возвращал 0). Вызывает `await feedback_store.get_positive(limit=100)`, добавляет `EvaluationPair` из позитивного фидбека. `AttributeError` (нет метода `get_positive`) — re-raise; прочие ошибки — warn + return 0.

> **Phase 8 default (2026-05-01, §2.1.3):** `RAGConfig.embedding_model` default изменён с `intfloat/multilingual-e5-large` (1024d) на `Qwen/Qwen3-Embedding-8B` (4096d). При запуске AutoRAG eval datasets, построенные под E5 1024d коллекции, требуют recreate Qdrant collection на 4096d. Подробности: [chapter 31](../../2_КОНТЕКСТ/2.8_QWEN3_RETRIEVAL_PRODUCTION/31.1_Обзор.md).

## Обзор

AutoRAG автоматически подбирает оптимальные параметры RAG через grid search.

## Что оптимизируется

| Параметр | Значения |
|----------|----------|
| **strategy** | vector, hybrid, bm25, mmr, two_stage, graphrag_local |
| **k** (top-k) | 3, 5, 10, 15 |
| **rerank** | true, false |
| **diversity** (MMR) | 0.1, 0.3, 0.5, 0.7 |
| **weights** (hybrid) | vector:0.4-0.8, graph:0.2-0.6 |

## CLI

```bash
# Grid search
python -m src.cli.main autorag --dataset "data/eval/benchmark.json"

# С ограничением
python -m src.cli.main autorag --dataset "data/eval/benchmark.json" \
    --strategies vector,hybrid,bm25 \
    --k-values 3,5,10
```

## Python API

```python
from src.pdf_framework.evaluation.autorag import AutoRAGRunner, ParameterGrid

grid = ParameterGrid(
    strategies=["vector", "hybrid", "bm25", "mmr"],
    k_values=[3, 5, 10],
    rerank=[True, False],
)

runner = AutoRAGRunner(
    search_manager=components.search_manager,
    grid=grid,
)

results = await runner.run(dataset_path="data/eval/benchmark.json")

# Лучшая конфигурация
best = results.best_config()
print(f"Best: strategy={best.strategy}, k={best.k}, rerank={best.rerank}")
print(f"Score: {best.score:.4f}")
```

## Smart Grid

Вместо полного перебора — интеллектуальный выбор комбинаций:

```python
from src.pdf_framework.evaluation.autorag import SmartGrid

grid = SmartGrid(budget=20)  # Максимум 20 экспериментов
# SmartGrid выберет наиболее информативные комбинации
```

## Экспорт оптимальной конфигурации

```python
# Экспорт в .env формат
best_config = results.best_config()
best_config.export_env("optimized.env")
```
