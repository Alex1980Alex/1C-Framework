# 08.6 Unit / Import-Smoke / Behavioral тесты

> Три тира Python-тестов фреймворка, бегущие в CI-джобе `test-unit` (тот же job, что и [08.5 Smoke Gate](08.5_Smoke_Gate.md)). Покрывают orphan-классы `src/pdf_framework/processing/`, которые раньше только импортировались, но не исполнялись.

## Зачем

До 2026-05-29 модули `src/pdf_framework/processing/` имели нулевое поведенческое покрытие: тесты их не инстанцировали (side-effects — mkdir, БД, сеть), поэтому метод-level баги (AttributeError на `self._format`, missing-await, None-client разыменования) проходили в CI незамеченными. Тир закрывает обе границы: импортируемость (smoke) и исполнимость (behavioral).

## Три тира

| Тир | Файл | Marker | Что проверяет |
|-----|------|--------|---------------|
| **Import-smoke** | [`tests/unit/test_import_smoke.py`](../../../../tests/unit/test_import_smoke.py) | `unit` | Авто-discovery всех `src.pdf_framework` модулей, каждый импортируется без ошибок (ловит broken imports, syntax errors) |
| **Behavioral** | [`tests/unit/test_processing_behavior.py`](../../../../tests/unit/test_processing_behavior.py) | `unit` | 14 тестов, исполняющих методы: ФС → `tmp_path`, Anthropic/embedder/LLM → моки, PDF → in-memory fitz. Ноль записи в cwd |
| **Retrieval smoke gate** | [`tests/eval/test_smoke_gate.py`](../../../../tests/eval/test_smoke_gate.py) | — | См. [08.5](08.5_Smoke_Gate.md) (отдельный, про NDCG@10, не про unit-логику) |

Оба unit-тира помечены marker `unit` → CI-джоб `test-unit` запускает их автоматически (вместе с retrieval smoke gate из 08.5).

## Какие баги ловит behavioral-тир

| Тест | Класс бага | Сайт |
|------|-----------|------|
| `test_page_renderer_save_pages` | метод-level AttributeError | `save_pages` дереференсит `self._config.format` (регрессия `self._format` → тест падает, подтверждено эмпирически) |
| `test_image_processor_awaits_embedding` | missing-await | coroutine vs list при embedding |
| proposition path | `.content` list-вариант | обработка списочного `.content` |
| `section_summary` / `image_extractor` | None-client guard | вызов без сконфигурированного клиента |

## Достигнутое покрытие

Форма CI (`--cov=src`), снимок 2026-05-29:

| Модуль | Coverage | Заметка |
|--------|----------|---------|
| `versioning.py` | 82% | + ветка concurrency-guard |
| `page_renderer.py` | 75% | вкл. `save_pages` — баг-сайт |
| `cache.py` | 74% | round-trip + stale |
| `image_processor.py` | 49% | await-путь покрыт |
| `section_summary.py` | 45% | CRUD + guard |
| `image_extractor.py` | 26% | guard + helpers |
| `table_extractor.py` | 15% | to_json |

## Честно про «полное»

Bug-prone/stateful логика (`versioning`/`page_renderer`/`cache`, 74–82%) покрыта хорошо. Extraction-модули (`image_extractor` 26%, `table_extractor` 15%) покрыты частично: пути `extract_from_pdf` / `tables_to_markdown_chunks` требуют реальных PDF с картинками/таблицами + моков Vision/pdfplumber — большой объём ради низкой баг-ценности (эти пути менее баг-склонны, чем покрытые). 100% line-coverage всех методов — отдельная крупная итерация.

## Запуск локально

```bash
# только unit-тир
.venv/Scripts/python.exe -m pytest tests/unit -m unit -v

# с покрытием (форма CI)
.venv/Scripts/python.exe -m pytest tests/unit -m unit --cov=src --cov-report=term-missing
```
