# 09.1 Мультитенантность

## Обзор

Multi-tenancy обеспечивает изоляцию данных между тенантами. Каждый тенант имеет собственные коллекции документов, индексы и настройки.

## Управление тенантами

### CLI

```bash
# Создать тенант
pdf-framework tenant create --id company-a

# Список тенантов
pdf-framework tenant list

# Удалить тенант
pdf-framework tenant delete --id company-a
```

### API

```bash
# Создать
curl -X POST http://localhost:8000/tenants/ \
    -H "Content-Type: application/json" \
    -d '{"id": "company-a", "name": "Company A"}'

# Список
curl http://localhost:8000/tenants/

# Удалить
curl -X DELETE http://localhost:8000/tenants/company-a
```

## Работа с тенантом

### Индексация

```bash
# Индексация для конкретного тенанта
python -m src.cli.main index "document.pdf" --tenant company-a
```

### Поиск

```bash
# Поиск в тенанте
python -m src.cli.main search "конфигуратор" --tenant company-a
```

### API

```bash
# Поиск с указанием тенанта
curl -X POST http://localhost:8000/search/ \
    -H "Content-Type: application/json" \
    -H "X-Tenant-ID: company-a" \
    -d '{"query": "конфигуратор"}'
```

## Изоляция данных

| Компонент | Изоляция |
|-----------|----------|
| Qdrant | Отдельная коллекция per tenant |
| BM25 FTS5 | Фильтр по tenant_id |
| Graph Store | Отдельный граф per tenant |
| Cache | Ключ включает tenant_id |

## Реализация в коде

| Компонент | Файл | Что делает |
|-----------|------|------------|
| `TenantMetadata` (Pydantic) | [`tenant_store.py`](../../../../src/pdf_framework/multitenancy/tenant_store.py) | Модель метаданных тенанта: `tenant_id`, `collection_name`, `created_at`, `document_count`, `storage_bytes`, `last_activity` |
| `TenantVectorStoreManager` | [`tenant_store.py`](../../../../src/pdf_framework/multitenancy/tenant_store.py) | Изолированные ChromaDB-хранилища по тенантам + SQLite-реестр метаданных и квот |
| `get_tenant_store_manager()` | [`tenant_store.py`](../../../../src/pdf_framework/multitenancy/tenant_store.py) | Фабрика global singleton-экземпляра менеджера |
| `TenantGraphStore(BaseGraphStore)` | [`tenant_graph.py`](../../../../src/pdf_framework/multitenancy/tenant_graph.py) | Обёртка над графовым хранилищем: фильтрует CRUD/query по `tenant_id`, отдельный JSON-файл на тенанта |
| `TenantGraphManager` | [`tenant_graph.py`](../../../../src/pdf_framework/multitenancy/tenant_graph.py) | Кэширует `TenantGraphStore` по тенантам, управляет их созданием/удалением |
| `get_tenant_graph_manager()` | [`tenant_graph.py`](../../../../src/pdf_framework/multitenancy/tenant_graph.py) | Фабрика global singleton-экземпляра графового менеджера |
| `_sanitize_tenant_id()` | оба файла | Санитизация `tenant_id` (`[a-zA-Z0-9_-]`, до 63 символов) для имени коллекции/файла |
