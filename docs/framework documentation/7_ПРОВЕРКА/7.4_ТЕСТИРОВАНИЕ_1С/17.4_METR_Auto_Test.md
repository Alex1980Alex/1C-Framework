# 17.4 METR и автоматическое тестирование после записи

## Обзор METR

**METR** (mcp-onec-test-runner v0.5.1) — Java-based MCP сервер для автоматизации тестирования 1С приложений. Интегрирует IBCMD, синтаксическую проверку и YaXUnit runner в единый workflow.

**Расположение:** `tools/mcp-jars/mcp-yaxunit-runner-0.5.1.jar`
**Конфигурация:** `tools/mcp-jars/application-testdb.yml`

### Основные возможности

- **Headless сборка** — IBCMD без интерфейса конфигуратора
- **Синтаксическая проверка** — валидация BSL модулей
- **YaXUnit runner** — запуск unit-тестов с фильтрацией и таймаутом
- **Incremental dump** — сохранение дампа конфигурации с SHA-256

## Конфигурация application-testdb.yml

```yaml
app:
  id: testdb
  format: DESIGNER
  base-path: "D:\\1С-Framework\\src\\bsl"

  source-set:
    - path: "."
      name: testdb
      type: "CONFIGURATION"
      purpose: [ "MAIN" ]
    - path: "exts/YAXUNIT"
      name: YAXUNIT
      type: "EXTENSION"
      purpose: [ "YAXUNIT" ]
    - path: "exts/Smoke"
      name: Smoke
      type: "EXTENSION"
      purpose: [ "TESTS" ]

  connection:
    connection-string: 'Srvr="KOMPUTER";Ref="TestDB";'
    user: "user@domain"
    password: "password"

  platform-version: "8.3.27.1859"

  tools:
    builder: DESIGNER
    enterprise:
      additional-launch-keys:
        - "/TESTMANAGER"

  dump:
    type: INCREMENTAL
    path: "D:\\1С-Framework\\build\\dumps"
    checksum-algorithm: SHA-256
```

**Важно:** В `purpose` допустимые значения: `MAIN`, `TESTS`, `YAXUNIT`. Значение `TESTING` вызывает ошибку `No enum constant SourceSetPurpose.TESTING`.

## Skill: auto-test-after-write

**Расположение:** `.claude/skills/auto-test-after-write/SKILL.md`

Навык срабатывает **автоматически после записи BSL модуля** через `write_module_source` и выполняет цепочку проверок:

### Workflow

**Шаг 1: Синтаксическая проверка**

```
mcp__metr__check_syntax_designer_config(
  config_path: "./src/configuration",
  target_module: "{module_name}"
)
```

Если ошибки — STOP, показать ошибки, ждать исправления.

**Шаг 2: Поиск связанных тестов**

Система ищет модули `{ModuleName}Test`:
- Написали `ОбработкаДанных.bsl` → ищет `ОбработкаДанныхTest.bsl`

**Шаг 3: Запуск отфильтрованных тестов**

```
mcp__metr__run_tests(
  test_framework: "YaXUnit",
  filter: { include_modules: ["{ModuleName}Test"] },
  timeout_per_test_sec: 30
)
```

**Шаг 4: Вывод результатов**

```
AUTO-TEST: ОбработкаДанных
[OK] Синтаксис: 0 ошибок (0.25s)
[OK] Тесты: 5/5 (1.2s)
Статус: READY FOR COMMIT
```

### Ограничения

- **Только BSL** — не работает для Python/JS
- **Требует YaXUnit** — расширение должно быть в sourceSets
- **Требует METR** — jar файл и YAML конфигурация
