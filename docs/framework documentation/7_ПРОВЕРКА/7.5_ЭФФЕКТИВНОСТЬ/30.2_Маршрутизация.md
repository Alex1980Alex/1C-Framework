# 30.2 Маршрутизация промптов

> 4-слойный skill-router + три дополнительных роутера на `UserPromptSubmit`.
> Определяют контекст промпта и рекомендуют релевантные скиллы,
> документы или триаду.

---

## 4 слоя skill-router.py

```
UserPrompt
    │
    ▼
┌─────────────────────────────────────────┐
│ Layer A: keyword matching               │
│ 32 bundles, weighted_keywords, +N score │
├─────────────────────────────────────────┤
│ Layer B: fuzzy matching                 │
│ pymorphy3 + rapidfuzz, threshold 78%    │
├─────────────────────────────────────────┤
│ Layer C: TF-IDF scoring                 │
│ char n-grams, cosine, top_k=2           │
├─────────────────────────────────────────┤
│ Layer D: semantic search                │
│ Qdrant 4096d Qwen3-8B TEI, ~80 skills   │
└─────────────────────────────────────────┘
    │
    ▼
Recommendations → SessionState
```

**Layer A**: keyword matching. 32 bundles содержат `weighted_keywords`. При совпадении слова из промпта с ключевым словом bundle получает +N баллов.

```json
{
  "name": "bsl-dev",
  "keywords": ["bsl", "1c", "oscript", "configator"],
  "weighted_keywords": {
    "bsl": 3,
    "конфигуратор": 5,
    "обработка": 2
  }
}
```

**Layer B**: fuzzy matching. Лемматизация через pymorphy3, сравнение через rapidfuzz Levenshtein. Порог 78%, обрабатываются только single words.

**Layer C**: TF-IDF scoring. Char n-grams, cosine similarity, чистый numpy. Реализация в `shared/tfidf_scorer.py`, возвращает top_k=2.

**Layer D**: semantic search. Qdrant коллекция `skill_library` — после Phase 9.1 (commit `ac91c4b7`, 2026-04-30): **4096d Qwen3-Embedding-8B через TEI**, 80/82 skills populated. Legacy (до Phase 9.1): 75 точек × 768d nomic-embed-text через Ollama. Env `SKILL_ROUTER_NO_SEMANTIC=1` отключает слой. См. [chapter 31.5](../../2_КОНТЕКСТ/2.8_QWEN3_RETRIEVAL_PRODUCTION/31.5_Миграция_и_итоги.md).

## Dedup и session state

SessionState хранит активации в `.claude/data/session-skills.json`.

Методы:
- `record_recommendation()` — сохраняет рекомендованный bundle
- `get_already_activated()` — возвращает список для дедупликации
- `set_prompt_id()` / `get_prompt_id()` — связывает recommend ↔ activate

Идентификатор промпта: `prompt_id = md5(ts + prompt[:80])[:8]`. Гарантирует уникальность без хранения полного текста.

## Дополнительные роутеры UserPromptSubmit

**`research-task-detector.py`**: классифицирует вопросы пользователя по категориям — Architecture / 1С / Tech / Hybrid. Вставляет системную подсказку с нужным скиллом-исследователем.

**`decision-to-triad.py`**: детектит решения и идеи в промпте («давай создадим», «предлагаю реализовать»). Перенаправляет в Фабрику триады с вопросами Q1–Q5 для структурирования.

**`document-persistence.py`**: перехватывает roadmap, plan, analysis. Добавляет systemMessage «сохрани в `docs/`» для предотвращения потери артефактов.

## A/B логирование

Лог маршрутизации: `data/skill-router.log`.

Каждая запись содержит поле `matched_by` со значением:
- `keyword` — Layer A
- `fuzzy` — Layer B
- `tfidf` — Layer C
- `semantic` — Layer D

Позволяет анализировать эффективность слоёв и отключать неработающие.
