# 39.1 Langfuse Observability — обзор

Phase 46 framework integration, version 1.3.0 в [tracer.py:11](../../../../src/pdf_framework/observability/tracer.py#L11). См. cache: [`langfuse-llm-observability-2026.md`](../../../../.claude/skills/architecture-research/cache/langfuse-llm-observability-2026.md).

## Что это и зачем

**Langfuse** — open-source LLM engineering platform (YC W23). В PDF Framework используется для **observability LLM-вызовов**: каждый запрос к Claude/GPT/Mistral, каждый прогон LangChain-агента, каждый tool-call попадает в trace tree с латентностью, токенами, cost, status и input/output.

Use cases:
- **Debug multi-step агентов** — Adaptive RAG, Self-RAG, Deep Research имеют 5-15 узлов на ран; trace tree показывает где «упало»
- **Cost tracking** — суммарные tokens × price per model per session, breakdown по компонентам
- **Latency analysis** — p50/p95/p99 per node; bottleneck detection
- **Quality scoring** — `client.score()` привязывает RAGAS-метрики к конкретным traces
- **Prompt versioning** (опц.) — управление промптами как артефактами

## Когда используется

Активно при `OBSERVABILITY__LANGFUSE_ENABLED=true` в `.env`. При false — все callbacks no-op (graceful skip).

## Архитектура (high-level)

```
ObservabilitySettings (.env / pydantic)
        ↓
build_langfuse_callback(user_id, session_id)
   (singleton-cached)
        ↓
Credentials resolution: explicit args → settings → env → disabled
        ↓
Langfuse() client init
        ↓
LangfuseCallbackHandler (LangChain BaseCallbackHandler)
   ├─ on_llm_start/end/error    → client.generation(...)
   ├─ on_chain_start/end/error  → client.span(...)
   └─ on_tool_start/end/error   → client.span(name="tool:...")
        ↓
Injected into: llm.callbacks, agent.callbacks, tool.callbacks
        ↓
Background queue + auto-flush → Langfuse Cloud / self-hosted backend
        ↓
Web UI: traces tree, latency p95, cost breakdown, scoring
```

```bash
OBSERVABILITY__LANGFUSE_SECRET_KEY=sk-lf-xyz789...
OBSERVABILITY__LANGFUSE_HOST=https://cloud.langfuse.com
OBSERVABILITY__LANGFUSE_PROJECT_NAME=pdf-framework

pip install langfuse>=4.0
```
