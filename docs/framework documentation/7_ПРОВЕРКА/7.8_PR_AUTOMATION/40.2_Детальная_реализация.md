# 40.2 PR Automation — детальная реализация

## auto-git-save.py (Edit-time commit)

[`.claude/hooks/auto-git-save.py`](../../../../.claude/hooks/auto-git-save.py) — PostToolUse hook на matchers `Write|Edit|Bash`.

### Flow

1. **Write/Edit detected** → track filename в `.claude/cache/auto-git-save.json`
2. **Threshold reached** (default 3 files):
   - `git add <files>`
   - `git commit -m "chore: auto-save <slug>"` (синхронно)
   - Complete mandatory task
3. **Below threshold**:
   - Create/update mandatory task в `hook-todos.json`
   - Emit `systemMessage` "будет auto-save после еще N файлов"
4. **Bash "git commit" detected**:
   - Validate cache (detect external commits)
   - Complete task if working tree clean
5. **Every call**: `sync_pending_tasks_with_git()` cleans zombie tasks

### Ported features

Из `1C-Enterprise_Framework git-commit-reminder.py v2.16`:
- Sync commit at threshold
- Zombie task prevention (sync с git status)
- Validate cache (external commits detection)
- Adaptive timeout (по file count)
- Adaptive cooldown (prevent rapid re-creation)
- File tracking в task metadata (single source of truth)
- Diagnostic logging → `.claude/cache/auto-git-save-debug.log`

### Pattern

Sync Commit + Enforcer. Не блокирует tool calls, но генерирует mandatory tasks которые блокируют Stop.

## git-commit-enforcer.py (Stop block)

[`.claude/hooks/git-commit-enforcer.py`](../../../../.claude/hooks/git-commit-enforcer.py) — Stop hook.

### Logic

```python
WATCHED_PATHS = ["src/", "docs/", "tests/", ".claude/skills/", ".claude/hooks/"]
CHANGE_STATUSES = {"M", "A", "D", "R", "C", "U", "T"}  # не untracked!

if uncommitted_in_watched():
    print(f"[GIT-COMMIT-ENFORCER] Обнаружены ...")
    sys.exit(2)  # block Stop
```

### Особенности

- `--porcelain` parsing с `core.quotepath=false` для кириллицы
- Игнорирует untracked (только tracked changes)
- Exit code 2 = HARD block Stop (не information advisory)
- Timeout 5s

## docs-change-enforcer.py (Stop advisory)

[`.claude/hooks/docs-change-enforcer.py`](../../../../.claude/hooks/docs-change-enforcer.py).

### CODE_TO_DOMAIN mapping

Список `(code_prefix, docs_subdir, skill)` tuples. Specific overrides ДО general prefixes (first-match-wins):

```python
CODE_TO_DOMAIN = [
    # Specific overrides
    ("src/pdf_framework/callbacks/langfuse/", "7_ПРОВЕРКА/7.2_АДМИНИСТРИРОВАНИЕ", "deployment"),
    ("src/pdf_framework/indexing/wiki_exporter.py", "5_ПАМЯТЬ/5.2_WIKI_KNOWLEDGE_LAYER", "wiki-pipeline"),
    ("scripts/analyzers/", "2_КОНТЕКСТ/2.7_AUTO_REPORTS", "post-indexing-analysis"),
    # General prefixes
    ("src/pdf_framework/search/", "2_КОНТЕКСТ/2.2_ПОИСК", "search-pipeline-debug"),
    ...
]
```

### Flow

1. На Stop читает changed files из последнего auto-save commit'а
2. Для каждого file находит matching domain (specific → general)
3. Если домен docs не обновлён в pair'е с code → advisory `systemMessage`
4. SKIP_PATTERNS для инфра-файлов (`.gitignore`, `tests/`, `scripts/`, etc.)

## post-task-push-pr.py (Task-time branch + PR)

[`.claude/hooks/post-task-push-pr.py`](../../../../.claude/hooks/post-task-push-pr.py) — PostToolUse:TaskUpdate, opt-in via `AUTO_PR_ENABLED=1`.

### Env vars

| Var | Default | Назначение |
|-----|---------|-----------|
| `AUTO_PR_ENABLED` | `0` | Master switch (`1` = on) |
| `AUTO_PR_BASE` | `master` | Base branch (для этого repo: `dev-master`) |
| `AUTO_PR_MIN_COMMITS` | `3` | Минимум commits ahead для триггера |
| `AUTO_PR_AUTO_MERGE` | `0` | `1` = auto-squash-merge после create |
| `AUTO_PR_WAIT_FOR_CHECKS` | `0` | `1` = `gh pr checks` poll до merge (gating) |
| `AUTO_PR_CHECKS_TIMEOUT` | `300` | Секунд на ожидание CI; после — merge SKIP |
| `AUTO_PR_NO_TESTS` | `0` | `1` = skip pre-push tests |
| `AUTO_PR_TEST_CMD` | `pre-commit run --all-files` | Pre-push gate (parsed через `shlex.split`, `shell=False`) |
| `AUTO_PR_TEST_TIMEOUT` | `600` | Секунд на pre-push gate (с 2026-05-22; раньше hard-coded 120) |
| `AUTO_PR_AUTO_REBASE` | `0` | `1` = auto-rebase HEAD на `origin/<base>` при drift |
| `AUTO_PR_CHERRY_PICK` | `0` | `1` = cherry-pick `start_sha..HEAD` в новую ветку (DEFERRED — `pr_helpers.cherry_pick_range_to_branch` ещё не реализован; hook ругается и падает на fallback вместо `AttributeError` с 2026-05-22) |
| `AUTO_PR_MERGE_QUEUE` | `0` | `1` = `gh pr merge --merge-queue` вместо `--squash` (требует GitHub merge queue в branch protection) |
| `AUTO_PR_REVIEWERS` | unset | CSV логинов — fallback если CODEOWNERS пуст |
| `AUTO_PR_REQUIRE_LABEL` | unset | Срабатывает только если task несёт этот label |
| `AUTO_PR_DRY_RUN` | `0` | `1` = вся валидация без push/PR/merge |
| `MEMORY_HOOK_NO_LANGFUSE` | unset | Skip Langfuse если случайно активен |
| `ANALYZER_GH_REPO` | unset | (для anomaly_tracker.py, не для этого хука) |

**Hook timeout в `.claude/settings.json` должен быть ≥ `AUTO_PR_TEST_TIMEOUT + AUTO_PR_CHECKS_TIMEOUT + 120s` slack**, иначе harness прибьёт subprocess до merge. С 2026-05-22 hook timeout поднят до `1320s` (для дефолтов 600+600+120).

### Flow (per TaskUpdate completed)

1. Check `AUTO_PR_ENABLED=1` (silent no-op otherwise)
2. Check `tool_input.status == "completed"`
3. Verify base branch exists locally (`git rev-parse --verify $AUTO_PR_BASE`)
4. Compute `commits_ahead = git rev-list --count $AUTO_PR_BASE..HEAD`
5. Skip if `commits_ahead < AUTO_PR_MIN_COMMITS`
6. Check idempotency state (`.claude/cache/post-task-push-pr-state.json`) — skip если `head_sha` уже обработан
7. Verify `gh --version` доступен
8. Pre-push tests: `shlex.split($AUTO_PR_TEST_CMD)` → `subprocess.run(shell=False)`. Skip if `AUTO_PR_NO_TESTS=1`
9. `git branch -f task/<taskId>-<slug> HEAD` (creates ref, no checkout)
10. `git push -u origin task/...`
11. `gh pr create --base $AUTO_PR_BASE --head task/... --title "[Task #N] subject" --body ...`
12. Optional: `gh pr merge $PR_URL --squash --delete-branch`
13. Update state file (atomic `os.replace`)
14. Emit systemMessage с PR URL

### Security improvements (post code-verify)

- `shlex.split` + `shell=False` для AUTO_PR_TEST_CMD — closes command injection vector (defence-in-depth)
- `_safe_int()` helper для AUTO_PR_MIN_COMMITS — never crashes on bad env
- Removed dead code в subject-extract
- Idempotent via head_sha check
- Never force-push, never reset, never checkout (stays on current branch)

## pre-commit config (gate layer)

[`.pre-commit-config.yaml`](../../../../.pre-commit-config.yaml) — запускается **автоматически** при каждом `git commit` (включая auto-saves):

| Gate | Tool | Что |
|------|------|-----|
| Ruff Lint | `astral-sh/ruff-pre-commit` | Linting (UP038, ERA, etc.) |
| Ruff Format | same | Auto-formatting |
| Type Check (mypy) | `mirrors-mypy` | Static types. Exclude: `tests/`, `docs/`, `scripts/`, `.claude/hooks/`, `quick.py` |
| Markdown Lint (wiki) | `markdownlint-cli2` | Format check для `docs/wiki/*.md` |
| KB Lint (wiki) | `scripts/kb_lint_ci.py` | Local Python wrapper |
| Gitleaks | secret scan | API keys leakage |
| Large Files | builtin | Block >1MB files |
| No Direct Commits to Main | builtin | Defensive guard |
| Hermes Eval Smoke | local | Phase 4 smoke test |
| MCP Servers Smoke | local | MCP availability |

Pre-commit modifications (ruff reformat) → блокируют commit → developer re-stages → retry.

## Trade-offs

| Решение | Pro | Con |
|---------|-----|-----|
| auto-commit при threshold | никогда не теряем работу | dirty history (`chore: auto-save X.py` × N) |
| Squash через soft-reset (memory pattern) | clean named commits | manual step + risk of accidental reset |
| Stop block on uncommitted | forces clean state | can be annoying при exploratory sessions |
| Pre-commit gates run on auto-save too | catch lint errors early | auto-save может зайти в loop при ruff reformat |
| `post-task-push-pr` opt-in default off | safe by default | требует ручной активации |
