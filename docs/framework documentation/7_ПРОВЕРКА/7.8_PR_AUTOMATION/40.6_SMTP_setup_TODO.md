## Пример env (в `settings.local.json` НЕ активировано по умолчанию)

> Значения ниже — **пример** для активации SMTP-уведомлений. В актуальном `.claude/settings.local.json` этих `AUTO_PR_SMTP_*` env **нет** (и `AUTO_PR_ENABLED=0` по умолчанию → весь PR-automation хук no-op). Чтобы включить — добавить их вручную.

- `AUTO_PR_SMTP_HOST=smtp.gmail.com`
- `AUTO_PR_SMTP_PORT=587`
- `AUTO_PR_SMTP_USER=alexterletskii80@gmail.com`
- `AUTO_PR_SMTP_TLS=1`
- `AUTO_PR_NOTIFY_TO=alexterletskii80@gmail.com`
- `AUTO_PR_NOTIFY_FROM=alexterletskii80@gmail.com`

## Missing: `AUTO_PR_SMTP_PASS`

Gmail требует app-password (не обычный пароль). 5 минут:

1. https://myaccount.google.com/apppasswords (нужна включённая 2FA)
2. Create password label "claude-code-pr-automation" → копировать 16 символов
3. Добавить в `.claude/settings.local.json` env: `"AUTO_PR_SMTP_PASS": "abcd efgh ijkl mnop"`

## Notification triggers (откуда приходят письма)

| Trigger | Source | Содержание |
|---|---|---|
| `pr_creation_failed` | `post-task-push-pr.py` | PR create failed |
| `pr_merge_failed` | `post-task-push-pr.py` | wait-for-checks timeout / red CI |
| `post_merge_revert` | `pr_check_post_merge.py` | Post-merge CI red → revert PR создан |

Alternatives: Yandex SMTP (`smtp.yandex.ru:465` + TLS=ssl), SendGrid (API key), Slack webhook (rewrite pr_notifier).
