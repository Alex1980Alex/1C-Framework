# 40.7 Gmail filter setup — `claude-watching` label

Status: pending user action — Gmail API scope insufficient для programmatic filter create.

See [40.6](40.6_SMTP_setup_TODO.md), [40.4](40.4_Дорожная_карта.md).

## Setup (5 минут)

1. Открыть https://mail.google.com/mail/u/0/#settings/filters
2. Click "Create a new filter"
3. **From:** `notifications@github.com`
4. **Has the words:** `Alex1980Alex/1C-Framework`
5. Click "Create filter" → checkboxes:
   - ☑ Apply the label → New label → `claude-watching`
   - ☑ Skip the Inbox (опционально — если не хочешь mailbox noise)
   - ☑ Mark as read (опционально)
   - ☑ Also apply filter to matching conversations

## Что мониторит Claude после применения filter'а

После применения label, мой Monitor `b2g2kdlrc` (Gmail watcher, 45s poll) видит:

- gemini-code-assist[bot] reviews на каждом PR
- claude.yml auto-reviews (если в `claude.yml` workflow срабатывает)
- Cost Baseline weekly failures
- Любые workflow run failures с label `claude-watching`

Дополнительный Monitor `b5iu4193n` (15s poll) видит statusCheckRollup всех open PRs + recent workflow runs.

## Известное ограничение

Gmail MCP scope (на 2026-05-24) — read-only. Programmatic label create/apply
не работает (`Request had insufficient authentication scopes`). Filter setup
ОБЯЗАТЕЛЬНО через UI Settings.

После UI filter setup, Claude может читать `label:claude-watching is:unread`
queries без write permission — этого достаточно для мониторинга.
