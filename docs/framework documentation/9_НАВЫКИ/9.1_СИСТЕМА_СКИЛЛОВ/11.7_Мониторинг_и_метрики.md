## Лог-файлы

Система скиллов генерирует 4 лог-файла:

| Файл | Формат | Кто пишет | Содержимое |
|------|--------|-----------|-----------|
| `data/skill-router.log` | Text | skill-router.py | `timestamp \| bundles=X \| skills=Y \| prompt=Z` |
| `data/skill-accuracy.jsonl` | JSONL | skill-router.py | `{type: recommend\|activate, prompt_id, skills}` |
| `data/skill-usage.log` | Text | skill-router.py | `timestamp \| skill=X \| session=Y \| source=prompt-detection` |
| `data/hook-invocations.jsonl` | JSONL | BaseHook (все хуки) | `{hook, event, tool, elapsed_ms, outcome, session_id}` |

### skill-router.log

Текстовый лог каждой рекомендации:
```
2026-03-03 10:15:00 | bundles=langchain-core,langchain-infra | skills=langchain-core,langgraph-core | prompt=создай agent с stategraph
```

### skill-accuracy.jsonl

JSONL для корреляции recommend ↔ activate:
```json
{"ts": "2026-03-03T10:15:00", "type": "recommend", "prompt_id": "abc12345", "skills": ["langchain-core", "langgraph-core"], "prompt": "создай agent с stategraph"}
{"ts": "2026-03-03T10:15:30", "type": "activate", "prompt_id": "abc12345", "skill": "langchain-core", "source": "prompt-detection"}
```

### skill-usage.log

Лог активаций скиллов:
```
2026-03-03 10:15:30 | skill=langchain-core | session=a1b2c3d4e5f6 | source=prompt-detection
```

### hook-invocations.jsonl

Лог всех вызовов хуков (записывается `BaseHook.run()` через `invocation_logger`):
```json
{"ts": "2026-03-03T10:15:00", "hook": "SkillRouter", "event": "UserPromptSubmit", "tool": null, "elapsed_ms": 45, "outcome": "message", "session_id": "abc123"}
```

## Prompt ID Correlation

Механизм связи рекомендаций с активациями:

```
1. Router генерирует prompt_id = MD5(timestamp + prompt[:80])[:8]
2. Router записывает {type: "recommend", prompt_id, skills} в skill-accuracy.jsonl
3. Router сохраняет prompt_id в SessionState.current_prompt_id
4. При следующем промпте: Router детектит <command-name>skill</command-name> теги
5. Для каждого активированного скилла: записывает {type: "activate", prompt_id}
6. Correlation: recommend.prompt_id == activate.prompt_id → конверсия
```

**Метрика activation rate:** % рекомендаций, после которых скилл был активирован.

## Evaluation: eval-skill-router.py

Файл: [scripts/eval-skill-router.py](../../../../scripts/eval-skill-router.py)

Офлайн-оценка качества маршрутизации.

### Ground Truth

Файл: `data/skill-router-ground-truth.jsonl`

Формат:
```json
{"prompt": "создай agent с StateGraph и checkpointer", "expected_skills": ["langgraph-core"], "expected_bundles": ["langchain-infra"]}
{"prompt": "как сделать движения по документу 1С", "expected_skills": ["1c-doc-research"], "expected_bundles": ["research-1c"]}
```

### Алгоритм evaluation

```
Для каждого ground truth промпта:
  1. Запуск skill-router.py с prompt через subprocess
  2. Парсинг stdout → extracted_skills, extracted_bundles
  3. Сравнение с expected_skills → precision, recall
  4. Агрегация по всем промптам → macro F1
```

### Запуск

```bash
python scripts/eval-skill-router.py              # Полный отчёт
python scripts/eval-skill-router.py --verbose     # С деталями каждого промпта
python scripts/eval-skill-router.py --json        # JSON для CI
```

### Метрики

`--json` выводит и legacy padded macro-F1 (Precision/Recall/F1, историческая метрика,
искажена silence-padding), и **честные** `honest_metrics` (см.
[11.3 Honest evaluation](11.3_Skill_Router.md#honest-evaluation-260613)):
`action_f1` (pooled, гейт), `silence_accuracy` (отдельно), `--split`/`--cv` breakdown.
CI-гейт (`skill-router-eval`, advisory) читает **`action_f1`**, не legacy F1 — см.
секцию «CI Gate» выше. Текущее honest-значение: pooled `action_f1` = **0.7708**
(CV k=5 mean 0.779), порог 0.75.

### Интерпретация (для honest action_f1)

- action_f1 > 0.80 — хорошо, система работает
- action_f1 0.75-0.80 — приемлемо (текущее состояние), возможна доработка бандлов
- action_f1 < 0.75 — CI-джоб печатает `::error::` (advisory, не блокирует merge)

## CI Gate

Файл: [`.github/workflows/ci.yml`](../../../../.github/workflows/ci.yml). Два раздельных job'а:

### `skill-router-gt-lint` (BLOCKING)

Прогоняет [`scripts/lint_skill_router_gt.py`](../../../../scripts/lint_skill_router_gt.py)
на `data/skill-router-ground-truth.jsonl` — проверяет схему (все поля/допустимые
значения `intent`/`source`/`split`) и **инвариант «no leakage»** (`source ==
transcript-router` ⇒ `split == quarantine`, никогда train/test). Блокирует merge
**независимо** от eval-джоба ниже — это гейт про качество разметки, не про F1.
Pure stdlib, без внешних зависимостей.

### `skill-router-eval` (ADVISORY, `continue-on-error: true`)

```bash
python scripts/eval-skill-router.py --json > eval-result.json
```

Порог — **pooled `action_f1` >= 0.75** (не старая padded macro-F1). Job печатает
`::error::` и завершается с exit 1 при провале, но `continue-on-error: true` не
блокирует merge — **осознанно advisory**: GT мал (95 строк) и эволюционирует
(honest-eval 260613, Фазы B/C тюнинга весов). Текущее значение: **pooled action_f1
= 0.7708** (CV k=5 mean 0.779), достигнуто после Фазы C. Промоушен в hard-блокировку
— одна строка (убрать `continue-on-error`) после стабилизации GT.

Старая формулировка «blocking F1 >= 0.70 macro-F1» из ранних версий этого документа
— **устаревшая метрика** (padded macro-F1 маскировала silence-примерами реальный
recall/precision); актуальная метрика и её честная методология — см.
[11.3 Honest evaluation](11.3_Skill_Router.md#honest-evaluation-260613).

## Метрики системы

### Operational Metrics

| Метрика | Источник | Описание |
|---------|---------|----------|
| Activation Rate | skill-accuracy.jsonl | % рекомендаций → активация |
| Block Rate | hook-invocations.jsonl | % PreToolUse → block |
| Latency P50/P95 | hook-invocations.jsonl | Время выполнения хуков (ms) |
| Error Rate | hook-invocations.jsonl | % вызовов с outcome=error |

### Quality Metrics

| Метрика | Источник | Описание |
|---------|---------|----------|
| Precision | eval-skill-router.py | Точность рекомендаций |
| Recall | eval-skill-router.py | Полнота рекомендаций |
| F1 | eval-skill-router.py | Balanced measure |
| Bundle F1 | eval-skill-router.py | F1 по бандлам (не скиллам) |

### Trend Metrics

| Метрика | Описание |
|---------|----------|
| Daily Activation Rate | Тренд конверсии по дням |
| Skill Frequency | Какие скиллы чаще активируются |
| Bundle Distribution | Распределение по бандлам |
| Intent Accuracy | Точность по system/informational/action |
