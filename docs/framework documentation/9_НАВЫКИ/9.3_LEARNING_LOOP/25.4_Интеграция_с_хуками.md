# 25.4 Интеграция с хуками

## Цепочка хуков

Пайплайн Learning Loop поддерживается хуками на всех этапах жизненного цикла:

### UserPromptSubmit
| Хук | Роль |
|-----|------|
| `skill-router.py` | Рекомендует `learning-loop` по ключевым словам |
| `research-task-detector.py` | Классифицирует тип задачи (research/brainstorm/hybrid) |

### PreToolUse
| Хук | Роль |
|-----|------|
| `code-skill-enforcer.py` Level A.1 | **BLOCKS** Write когда нет skill → `Skill('learning-loop')` |
| `code-skill-enforcer.py` Level F | Advisory backup через `pending_learn` |

### PostToolUse
| Хук | Роль |
|-----|------|
| `knowledge-cache-reminder.py` | Напоминает кешировать результаты FETCH |
| `posttooluse-web-cache.py` | Трекает вызовы WebSearch/WebFetch |
| `code-verify-reminder.py` | Создаёт mandatory task для VERIFY |
| `task-protocol-observer.py` | Фиксирует активацию skill в SessionState |

### Stop
| Хук | Роль |
|-----|------|
| `task-enforcer.py` | Блокирует завершение, если cache task pending |

## Диаграмма потока

```
UserPromptSubmit
  └── skill-router → рекомендует learning-loop
                          │
PreToolUse                │
  └── code-skill-enforcer Level A.1
        │ НЕТ skill для темы?
        │ → BLOCK Write ❌
        │ → "Activate Skill('learning-loop')"
        │
        ▼
Claude: Agent(subagent_type="learning-loop", prompt="...")
        │
        ▼
┌── learning-loop субагент ─────────────────────────────┐
│  SEARCH (Grep) → FETCH (WebSearch x3) → EXECUTE (Write)│
│  → VERIFY (Grep markers) → CREATE (Write SKILL.md)     │
└── returns summary ────────────────────────────────────┘
        │
PostToolUse
  ├── knowledge-cache-reminder → "сохрани KB в cache"
  ├── code-verify-reminder → mandatory task [CODE-VERIFY-PASS]
  └── task-protocol-observer → skill_checked
        │
Stop    │
  └── task-enforcer → cache task выполнена? → разрешает stop
```

## SessionState координация

| Поле | Когда записывается | Кто читает |
|------|--------------------|------------|
| `pending_learn` | Level A.1 (при блокировке) | Level F (advisory backup) |
| `activated_skills["learn:redis"]` | Level A.1 (при активации) | Level F (skip если уже triggered) |
| `skill_checked` | task-protocol-observer | code-skill-enforcer (разрешает Write) |
