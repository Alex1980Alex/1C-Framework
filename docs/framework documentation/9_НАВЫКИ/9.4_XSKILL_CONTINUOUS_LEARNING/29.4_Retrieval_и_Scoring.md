### Search API

```python
from experience_search import search_skills, search_experiences, search_visual_captures

# Поиск skills
results = search_skills("BSL structural code analysis", limit=5)
# -> [SkillSearchResult(skill_name="code-analysis-pipeline", score=0.72, ...)]

# Поиск experiences
results = search_experiences("ast-grep BSL pattern matching", limit=5)
# -> [ExperienceSearchResult(experience_id="exp-...", score=0.82,
#      tool_preference="mcp__ast-grep-mcp__ast_grep", ...)]

# Поиск по скриншотам (text -> image, cross-modal)
results = search_visual_captures("1C document form with table", limit=3)
# -> [VisualSearchResult(capture_id="vis-...", form_type="document_form", ...)]
```

### TF-IDF Fallback

Когда Ollama/Qdrant недоступны, search автоматически переключается на TF-IDF:
- Токенизация русский + английский
- L2-нормализация
- Cosine similarity
- Работает offline, ~5ms

### Индексация

```bash
# Skills -> Qdrant
python scripts/hooks/learning/index-skills-to-qdrant.py

# Experiences -> Qdrant
python scripts/hooks/learning/experience-embedder.py --full

# Visual captures -> Qdrant (SigLIP)
python scripts/hooks/learning/visual_embedder.py --full
```

Инкрементальная: повторный запуск проиндексирует только новые записи (по hash/ID).

## Phase 5: Continuous Learning Loop

### Outcome Tracking

**Файл:** `outcome-tracker.py` -- PostToolUse + UserPromptSubmit hook

Отслеживает результат применения знаний:

| Сигнал | Outcome | Score |
|--------|---------|-------|
| Пользователь продолжил без коррекции | `implicit_success` | +0.7 |
| Пользователь сказал "correct", "yes" | `explicit_success` | +1.0 |
| Пользователь сказал "no", "wrong" | `explicit_failure` | -1.0 |
| Retry того же инструмента | `implicit_failure` | -0.5 |

Записывает в `outcomes.jsonl` и `knowledge-usage.jsonl`.

### Knowledge Scoring (EMA)

**Файл:** `knowledge-scorer.py`

Пересчитывает confidence для каждого experience на основе outcomes:

```
new_confidence = old_confidence * decay + outcome_score * learning_rate
```

- **Decay:** records без использования >14 дней теряют 5%/неделю
- **Learning rate:** 0.3 (30% влияние нового outcome)
- **EMA smoothing:** экспоненциальное скользящее среднее

Пороги:
| Confidence | Действие |
|-----------|----------|
| >= 0.9 | Кандидат на promotion в SKILL.md |
| 0.4 - 0.9 | Активный, инжектируется при запросе |
| 0.3 - 0.4 | `needs_review=true` |
| < 0.2 за 30 дней | Auto-deprecation |

### Skill Health

**Файл:** `skill-health-checker.py`

Рассчитывает health score для каждого из 49 skills:

```
health = base_weight * existence_score
       + outcome_weight * (positive_outcomes / total_outcomes)
       + experience_weight * linked_experience_confidence
```

```bash
/skill-health
# ============================================================
#   SKILL HEALTH DASHBOARD
# ============================================================
#   [+] code-analysis-pipeline       health=0.85  outcomes=12  exp=3
#   [~] 1c-forms                     health=0.42  outcomes=0   exp=0
#   [!] deprecated-skill             health=0.18  outcomes=0   exp=0
```

### Auto-deprecation

Skill с health < 0.2 за 30 дней:
1. `deprecated: true` добавляется в YAML frontmatter
2. Запись в `skills-needing-revision.json`
3. Уведомление при старте сессии через `skill-health-notifier.py`
