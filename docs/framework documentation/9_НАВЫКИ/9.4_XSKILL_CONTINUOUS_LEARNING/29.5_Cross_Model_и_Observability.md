## Phase 6: Cross-Model Knowledge Profiling

### Зачем

Разные модели (Opus, Sonnet, Haiku, GLM) по-разному используют одни и те же знания. Experience "используй ast-grep для BSL" может быть полезен для Opus (который понимает BSL), но бесполезен для GLM (который не знает BSL).

### Model-Aware Scoring

**Файл:** `model-profiler.py`

Каждый experience хранит per-model confidence:

```json
{
  "per_model_confidence": {
    "claude-opus": 0.92,
    "claude-sonnet": 0.85,
    "claude-haiku": 0.60,
    "glm": 0.30
  }
}
```

### Affinity Matrix

Матрица `model x category -> effectiveness`:

```
Category              claude-haiku  claude-opus  claude-sonnet  glm
----------------------------------------------------------------------
parameter_tuning           0.000        0.000        0.000    0.000
tool_selection             0.670        0.670        0.670    0.670
workflow_order             0.890        0.890        0.890    0.890
```

Хранится в `cache/experience-bank/model-affinity-matrix.json`.

### Conditional Injection

При retrieval проверяется effectiveness для текущей модели:

```python
if model_affinity[current_model][experience.category] < 0.3:
    skip_injection()  # не инжектировать бесполезный experience
```

### Transfer Tracking

**Файл:** `model-transfer-tracker.py`

Отслеживает cross-model transfer: experience создан Claude Opus, использован GLM.

```bash
/model-knowledge-fit
# MODEL-KNOWLEDGE FIT DASHBOARD
# claude-opus   avg=0.520  best=workflow_order(0.89)
# claude-sonnet avg=0.520  best=workflow_order(0.89)
# glm           avg=0.520  best=workflow_order(0.89)
```

## Phase 7: Observability & Metrics

### Metrics Collection

**Файл:** `xskill-metrics.py`

Собирает 5 категорий метрик:

| Категория | Метрики |
|-----------|---------|
| Experience Bank | total, by_category, by_status, avg_confidence, growth_rate_7d/30d |
| Failure Tracking | total, by_type, by_severity, by_tool, failure_rate |
| Consolidation | last_run, sessions_till_next, total_archived |
| Retrieval | keyword_hit_rate, semantic_hit_rate, overall_hit_rate, promotions |
| Velocity | avg_distillation_hours, avg_promotion_hours |

```bash
# Полный dashboard
python scripts/hooks/learning/xskill-metrics.py

# JSON вывод
python scripts/hooks/learning/xskill-metrics.py --json

# Одна секция
python scripts/hooks/learning/xskill-metrics.py --json --section bank
```

### Slash Commands

| Команда | Что показывает |
|---------|---------------|
| `/xskill-status` | Общий статус: кол-во experiences, failures, last consolidation |
| `/xskill-experiences` | Топ-10 experiences по confidence с фильтрами |
| `/xskill-failures` | Топ-10 failure patterns, рекомендации |
| `/xskill-health` | Комплексный health dashboard |
| `/xskill-consolidate` | Ручной запуск consolidation pipeline |

```json

  "experiences_added": +4,
  "previous_collection": "2026-04-08T20:00:00Z"
}
```
