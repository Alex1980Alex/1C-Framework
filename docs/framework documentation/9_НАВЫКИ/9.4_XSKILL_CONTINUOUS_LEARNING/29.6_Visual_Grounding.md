## Идея

Текстовые experience records не захватывают визуальную информацию: как выглядит форма 1С, расположение полей, таблица товаров. Visual grounding привязывает experience к скриншотам форм для:

- **Visual retrieval:** "покажи experience для формы, похожей на этот скриншот"
- **Form-aware guidance:** "в прошлый раз на такой форме мы использовали подход X"
- **Cross-modal search:** текстовый запрос "invoice form with table" -> скриншот

## Screenshot Capture Hook

**Файл:** `visual_grounding_capture.py` -- PostToolUse hook

Детектирует три типа визуальных взаимодействий:

| Источник | Детекция |
|----------|---------|
| `Read(*.png/jpg)` | tool_name=Read + image extension |
| `clipboard_get_image` | MCP clipboard tool |
| Screenshot keywords | "screenshot", "скриншот" в tool result |

### Form Type Detection

Автоматическая классификация по пути файла:

| Паттерн в пути | Form type |
|----------------|-----------|
| `Documents/`, `Документы/` | `document_form` |
| `Catalogs/`, `Справочники/` | `catalog_form` |
| `Reports/`, `Отчёты/` | `report_form` |
| `ListForm`, `ФормаСписка` | `list_form` |
| `error`, `dialog` | `dialog` |
| `debug` | `debugger` |

### Deduplication

По MD5 hash файла. Повторный capture того же скриншота не создает дубликат.

## Image Embedding

**Файл:** `visual_embedder.py`

Два backend-а:

### SigLIP (primary)

- **Модель:** `google/siglip-base-patch16-224`
- **Размерность:** 768 (совпадает с nomic-embed-text — legacy reference, см. DROPPED banner вверху)
- **Text-image alignment:** да (shared embedding space)
- **Cross-modal search:** текстовый запрос против image embeddings
- **Зависимости:** `transformers`, `torch`, `sentencepiece`, `Pillow`

### pHash (fallback)

- **Библиотека:** `imagehash` + `Pillow`
- **Размерность:** 256 (padded до 768 для Qdrant)
- **Семантика:** нет (только визуальное сходство)
- **Cross-modal:** нет
- **Зависимости:** `imagehash`, `Pillow` (~1MB)

```bash
# Индексация всех captures
python visual_embedder.py --full --backend siglip

# Только новые
python visual_embedder.py --new

# Cross-modal поиск (текст -> изображение)
python visual_embedder.py --query "invoice form with goods table"

# Visual similarity (изображение -> изображение)
python visual_embedder.py --query-image cache/screenshot.png
```

## PoC Results

Тестирование на 5 реальных скриншотах из cache/:

| Метрика | Результат | Цель |
|---------|-----------|------|
| Self-match rate | **100%** | - |
| Same-type Precision@3 | **100%** | >= 60% |
| Cross-modal hit rate | 0% | >= 40% |
| Embedding latency | ~10s cold / ~200ms warm | < 200ms |

**Вердикт:** visual similarity работает. Cross-modal требует скриншотов реальных форм 1С с правильными form_type метками.
