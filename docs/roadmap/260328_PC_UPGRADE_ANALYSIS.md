## 2. ПЕРЕНОСИМ — детали по каждому компоненту

### Процессор: AMD Ryzen 7 5700G

- **Что делать:** Снять со старой платы HP, установить на Gigabyte B550
- **Нюансы переноса:**
  - Старая термопаста прилипает — НЕ дёргать кулер вверх, покрутить
  - Не трогать ножки процессора пальцами
  - Совместить золотой треугольник с меткой на сокете
  - Процессор вставляется БЕЗ усилия
- **Ограничение:** Поддерживает только PCIe 3.0 (аппаратное ограничение APU Cezanne). GPU и SSD будут работать, но медленнее чем могли бы на PCIe 4.0

### Оперативная память: 2x 16GB DDR4

| Слот | Модуль | Макс. частота | Реальная частота |
| :--- | :--- | :--- | :--- |
| Channel A | SK Hynix HMAA2GU6CJR8N-XN | 3200 MHz | **2667 MHz** |
| Channel B | A-DATA AX4U320016G16A-CBK20 | 2667 MHz | **2667 MHz** |

- **Что делать:** Переставить в слоты 2 и 4 новой платы (для двухканала)
- **Нюанс:** Обе работают на 2667 MHz (по медленной). В BIOS новой платы можно попробовать вручную выставить 2933 MHz — может работать стабильно
- **После установки дискретной GPU:** Встроенная Vega 8 простаивает, RAM больше не делится с iGPU — вся память доступна системе

### Накопители

| Диск | Тип | Размер | Куда ставим | Назначение |
| :--- | :--- | :--- | :--- | :--- |
| ADATA Legend 960 | NVMe M.2 2280 | 2 TB | M.2 #1 (от CPU) | Система, софт, рабочие файлы |
| Kioxia KBG40ZNV256G | NVMe M.2 **2230** | 256 GB | M.2 #2 (от чипсета) | Кэш, файл подкачки |
| Seagate ST2000DM005 | SATA HDD | 2 TB | SATA порт #1 | Архивы, бэкапы |
| Seagate ST2000DM005 | SATA HDD | 2 TB | SATA порт #2 | Архивы, бэкапы |

- **ВНИМАНИЕ — Kioxia 2230:** Это укороченный форм-фактор (30mm вместо стандартных 80mm). На B550 AORUS Elite V2 слоты M.2 имеют стойку под 2280. Нужно проверить, есть ли дополнительная стойка под 2230, или купить переходник 2230→2280
- **HDD:** Для подключения нужны SATA-кабели (Data). В комплекте с материнской платой обычно идут 2 штуки. Питание SATA берётся от нового БП

| **Кулер CPU HP** | Проприетарное крепление, не совместим со стандартным AM4 backplate |

## 5. Нюансы и предупреждения

### Критические

- [ ] **Kioxia SSD форм-фактор 2230:** Укороченный (30mm вместо 80mm). Стандартные M.2 слоты рассчитаны на 2280. Проверить наличие крепёжной стойки под 2230 на B550 AORUS Elite V2. Если нет — купить переходник 2230-to-2280 (~300-500 руб)
- [ ] **WiFi отсутствует на новой плате:** B550 AORUS Elite V2 не имеет WiFi. Обязательно перенести Realtek RTL8821CE из старого ПК или купить USB WiFi адаптер
- [ ] **Лицензия Windows 11 IoT Enterprise:** Скорее всего привязана к материнской плате HP (OEM-активация). При переносе SSD на новую плату потребуется повторная активация — ключ может не сработать
- [ ] **RTX 3090 TDP 350W:** БП HP не потянет. Новый БП 850W — обязателен, не опционален

### Важные

- [ ] **PCIe 3.0 ограничение:** Ryzen 5700G (APU) поддерживает только PCIe 3.0. GPU работает на PCIe 3.0 x16 (потеря ~3-5% в играх, минимальна для LLM). SSD работают на ~3500 MB/s вместо ~7000 MB/s
- [ ] **Зазор GPU и NVMe адаптер:** RTX 3090 занимает 2.7 слота. Между PCIe x16 #1 (GPU) и PCIe x16 #2 (адаптер) должен быть зазор. На B550 AORUS Elite V2 расстояние обычно достаточно, но проверить визуально после установки GPU
- [ ] **Длина GPU ~300mm:** При выборе корпуса убедиться, что поддержка GPU > 320mm (запас). Корзина HDD не должна мешать
- [ ] **SATA кабели для HDD:** В комплекте с мат. платой обычно 2 SATA кабеля — хватит для 2 HDD. Питание SATA от нового БП
- [ ] **LHR на RTX 3090:** Ограничение майнинга — абсолютно не влияет на LLM inference

### Рекомендательные

- [ ] **RAM разные частоты:** Обе планки работают на 2667 MHz. В BIOS можно попробовать вручную выставить 2933 MHz — может работать стабильно. Идеально — заменить на одинаковый комплект 2x16GB DDR4-3200
- [ ] **RTX 3090 нагрев:** Hotspot может достигать 100+C. Корпус должен иметь хороший продув — минимум 3 вентилятора (2 вдув фронт, 1 выдув зад)

## 6. Опциональные улучшения (в будущем)

- [ ] **Замена RAM:** Продать текущие 2 планки, купить комплект 2x16GB или 2x32GB DDR4-3200. Для LLM больше RAM = лучше (кэширование моделей в системной памяти)
- [ ] **WiFi 6:** Старый адаптер Realtek — WiFi 5 (802.11ac). Для большей скорости можно купить Intel AX200/AX210 (WiFi 6/6E) — PCIe M.2 Key-E модуль
- [ ] **Доп. охлаждение корпуса:** 2-3 дополнительных вентилятора 120/140mm для отвода тепла от RTX 3090
- [ ] **UPS:** Блок бесперебойного питания 1000VA+ для защиты от скачков (RTX 3090 чувствительна к качеству питания)
