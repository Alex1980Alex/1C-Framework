## Этап 1: Аудит и подготовка (КРИТИЧЕСКИ ВАЖНО)

Перед покупкой компонентов необходимо убедиться в физической совместимости новых частей со старым корпусом и блоком питания HP.

### Чек-лист совместимости:
- [ ] **Проверка корпуса (Form Factor):**
    - Измерьте внутреннее пространство. Материнская плата **Gigabyte B550 AORUS Elite V2** имеет форм-фактор **ATX** (305mm x 244mm).
    - *Риск:* Корпуса HP часто бывают формата Micro-ATX или имеют нестандартные монтажные отверстия/перегородки. Если корпус узкий — плата не влезет.
- [ ] **Проверка блока питания (PSU):**
    - Откройте крышку и посмотрите на разъёмы материнской платы.
    - **Стандарт:** 24-pin (широкий) + 8-pin (CPU).
    - **HP OEM:** Часто встречаются нестандартные 6-pin или комбинированные разъёмы.
    - *Решение:* Если разъёмы нестандартные, БП придётся менять на стандартный ATX (дополнительный бюджет ~5000-8000 руб).
- [ ] **Проверка питания GPU:**
    - Мощные карты для LLM (RTX 3090/4090) требуют 2-3 коннектора 8-pin (6+2) или новый стандарт 12VHPWR. Старый БП HP (обычно 400-500W) их не потянет ни по мощности, ни по коннекторам.

## Этап 3: Сборка и перенос

### 3.1. Ограничения Ryzen 7 5700G (ВАЖНО ЗНАТЬ)

> **ВНИМАНИЕ:** Ryzen 5700G — это APU серии Cezanne. Аппаратное ограничение: поддерживает **ТОЛЬКО PCIe 3.0** (НЕ 4.0), даже на платах B550/X570, которые умеют PCIe 4.0.

- PCIe 4.0 SSD будут работать, но на скоростях PCIe 3.0 (~3500 MB/s вместо ~7000 MB/s)
- GPU тоже будет работать на PCIe 3.0 x16 — для LLM inference это НЕ критично (узкое место — VRAM, а не шина)
- Всего 24 линии PCIe 3.0

### 3.2. Перенос процессора

**Демонтаж со старой платы HP:**

1. Отключить все провода от платы (питание, USB, вентиляторы)
2. Снять кулер (обычно 4 винта или защёлки)
   - **НЮАНС:** Старая термопаста "приклеивает" кулер. **НЕ ДЁРГАТЬ вверх!** Покрутите кулер плавно из стороны в сторону, чтобы разрушить слой пасты, затем снимите
3. Поднять рычажок сокета AM4
4. Аккуратно достать процессор (за края, **НЕ трогать ножки снизу**)

**Установка на новую плату:**

1. Поднять рычаг сокета
2. Найти **золотой треугольник** в углу процессора — совместить с треугольником на сокете платы
3. Положить процессор — он **сам упадёт** в сокет без усилий. Если не идёт — проверьте ориентацию. **НИКОГДА не давить!**
4. Опустить рычаг и зафиксировать
5. Нанести термопасту — капля размером с горошину по центру крышки
6. Установить новый кулер, затягивая винты по диагонали (крест-накрест) для равномерного прижима

### 3.3. Схема подключения устройств

| Слот на плате | Устройство | Линии PCIe | Назначение |
| :--- | :--- | :--- | :--- |
| **M.2 #1 (верхний, от CPU)** | ADATA Legend 960 2TB | PCIe 3.0 x4 | Система, софт, рабочие файлы |
| **M.2 #2 (нижний, от чипсета)** | Kioxia 256GB | PCIe 3.0 x4 | Кэш / файл подкачки |
| **PCIe x16 #1 (верхний)** | Дискретная GPU (RTX) | PCIe 3.0 x16 | LLM inference |
| **PCIe x16 #2 (нижний)** | NVMe адаптер + 3-й SSD | PCIe 3.0 x4 | Хранилище моделей LLM |
| **SATA порты (6 шт)** | 2x Seagate 2TB HDD | SATA III | Архивы, бэкапы |

### 3.4. RAM — несогласованность частот

Текущая ситуация: 2 планки DDR4 разной частоты (3200 + 2667 MHz). Обе работают на **2667 MHz** (по медленной).

- При переносе на новую плату ситуация сохранится
- Рекомендация: заменить на одинаковый комплект DDR4 3200MHz
- Особенно важно для APU: встроенная графика Vega 8 использует системную RAM как видеопамять (после установки дискретной GPU это станет менее критично)

## Этап 4: Настройка ПО (Post-Build)

### BIOS:
- [ ] Обновить BIOS до последней версии (Q-Flash) для лучшей поддержки памяти и CPU
- [ ] Включить **Resizable BAR** (Above 4G Decoding) — важно для производительности LLM на картах NVIDIA 30/40 серии
- [ ] Настроить XMP/DOCP профиль для RAM (если замените на 3200MHz комплект)

### Драйверы:
- [ ] Установить драйверы чипсета AMD B550
- [ ] Установить **NVIDIA Studio Drivers** (стабильнее для AI/LLM, чем Game Ready)
- [ ] Установить CUDA Toolkit (для llama.cpp, vLLM, PyTorch)

### ОС:
- [ ] Windows 11 IoT Enterprise — проверить активацию (лицензия может быть привязана к старой плате HP)
- [ ] Возможно потребуется переустановка или исправление загрузчика

## Будущий апгрейд: 2x GPU для LLM (Roadmap 2.0)

Если в будущем понадобится запускать модели 70B+ без сильного квантования, потребуется **более 24GB VRAM** — то есть 2 видеокарты.

### Почему текущая плата НЕ подходит для 2 GPU:

1. PCIe x16 #2 работает в режиме **x4** (от чипсета) — вторая GPU будет в 4 раза медленнее по шине
2. Если оба слота заняты видеокартами — для 3-го SSD адаптера некуда
3. Ryzen 5700G имеет всего 24 линии PCIe 3.0 — мало для 2 GPU

### Варианты перехода на 2 GPU:

| Вариант | Платформа | Примечание |
| :--- | :--- | :--- |
| **A. AM4 (бюджет)** | ASRock X570 Taichi / ASUS Crosshair VIII Hero | Умеют x16/x8 split, но платформа устаревшая |
| **B. AM5 (рекомендуется)** | Ryzen 9000 + X670E/X870E | PCIe 5.0, больше линий, актуальная платформа |
| **C. Server** | EPYC / Threadripper | Много слотов x16, но дорого и шумно |

### Справка: SLI/CrossFire vs LLM multi-GPU

- **SLI** (NVIDIA) и **CrossFire** (AMD) — устаревшие технологии объединения 2 GPU для игр. Отменены производителями (2020+), игры не поддерживают
- Для **LLM inference** 2 GPU работают по другому принципу — **Tensor Parallelism**: модель разбивается на части и каждая GPU считает свой кусок
- Фреймворки llama.cpp, vLLM, Ollama, text-generation-inference умеют автоматически делить модель на несколько GPU

### Текущая стратегия:

Выжать максимум из **одной RTX 3090/4090 (24GB VRAM)**, используя квантование моделей (4-bit GGUF, AWQ, GPTQ). Это позволяет запускать:
- Модели до 30B — в полном качестве (FP16)
- Модели 70B — в 4-bit квантовании (качество ~95% от оригинала)
- Модели 8B-14B — с максимальным контекстом
