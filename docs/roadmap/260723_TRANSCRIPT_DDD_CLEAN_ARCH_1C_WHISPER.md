# Пример DDD и Чистой Архитектуры в 1С (whisper, слой B)

**Источник:** https://www.youtube.com/watch?v=FjL9sBgfGo8
**Канал:** Желтый клуб — 1С программирование
**Дата публикации:** 2026-07-23
**Длительность:** 2:24:08
**Способ получения:** локальное распознавание речи (слой B, ADR-057) —
yt-dlp (извлечение аудио) -> whisper.cpp `large-v3-turbo` на GPU (Vulkan),
`language=ru`, подсказка словаря терминов 1С/DDD, temperature=0.
Время прогона ~17 мин, объём ~31 900 слов.

**Отличие от версии слоя A** ([260723_TRANSCRIPT_DDD_CLEAN_ARCH_1C.md](260723_TRANSCRIPT_DDD_CLEAN_ARCH_1C.md)):
там - автоматические субтитры YouTube без пунктуации и с искажением терминов
(«1S», «ээнд», «Nва-риантов»). Здесь - пунктуация и термины от большой модели.
Спорные фрагменты стоит сверять между двумя версиями: ни один слой не безошибочен.
