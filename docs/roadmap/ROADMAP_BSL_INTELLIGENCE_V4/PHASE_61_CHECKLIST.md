## Метрики приёмки
- [ ] Coverage: >= 95% явных вызовов найдены и сохранены
- [ ] Precision: <= 2% ложных срабатываний
- [ ] Latency парсинга: <= 1.5s на 10,000 строк
- [ ] Latency запроса "кто вызывает X?": < 200ms
- [ ] Dead code detection: корректно исключает точки входа (обработчики событий)

## Интеграционные проверки
- [ ] "Кто вызывает?": поиск потребителей экспортной функции — полный список
- [ ] Impact Analysis: изменение метода → список зависимых модулей
- [ ] Dead Code: выявление методов с in-degree = 0 (кроме event handlers)
- [ ] Рекурсия: циклические вызовы обрабатываются без зацикливания
- [ ] Кросс-модульные ссылки: вызовы общих модулей резолвятся корректно
