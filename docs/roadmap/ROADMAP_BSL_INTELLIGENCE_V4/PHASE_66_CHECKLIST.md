# Чеклист готовности: Фаза 66 — BSL Coding Assistant

**Приоритет:** HIGH | **Срок:** 3-5 дней | **Зависимости:** Фазы 59, 61, 62

## Предусловия
- [ ] Фаза 59 (AST): символьный индекс доступен для поиска похожего кода
- [ ] Фаза 61 (Call Graph): API зависимостей доступно
- [ ] Фаза 62 (Knowledge Graph): метаданные объектов доступны
- [ ] Доступ к Claude API через Z.AI настроен и проверен
- [ ] Определён `prompt_template` для инъекции контекста проекта

## Артефакты (файлы/код)
- [ ] `src/bsl/assistant/context_aggregator.py` — сбор контекста: зависимости, соглашения, похожий код
- [ ] `src/bsl/assistant/rag_retriever.py` — поиск релевантных сниппетов (threshold > 0.75)
- [ ] `prompts/bsl_coding_v1.yaml` — шаблоны промптов с плейсхолдерами для контекста
- [ ] `src/bsl/assistant/reviewer.py` — модуль code review с структурированными замечаниями
- [ ] Тесты: `tests/test_bsl_assistant.py`

## Метрики приёмки
- [ ] Latency: время до начала ответа < 3.5s (p95)
- [ ] Context Relevance: оценка LLM-судьи >= 4.0/5.0
- [ ] Review Precision: точность замечаний >= 85%
- [ ] Token Usage: < 8000 input токенов на задачу (экономический лимит)

## Интеграционные проверки
- [ ] Инъекция зависимостей: сгенерированный код включает корректные ссылки на общие модули
- [ ] Соглашения: код соответствует стилю проекта (именование, структура запросов)
- [ ] Similar Code: при написании метода предлагается существующая реализация из другого модуля
- [ ] E2E: Запрос → Поиск контекста → Генерация → Review → Ответ без ошибок
- [ ] Graceful degradation: при недоступности Qdrant — понятная ошибка

## Блокеры для следующих фаз
- [ ] Без RAG контекста блокируется качество автодополнений
- [ ] Некорректная инъекция зависимостей блокирует безопасный рефакторинг
