## Blocker: tree-sitter-bsl Native Compilation

ast-grep requires a compiled native library (.dll / .so / .dylib)
for custom language grammars. The project has:

- `tree-sitter-bsl.wasm` (web-tree-sitter format) — NOT usable by ast-grep CLI
- `tree-sitter-bsl/prebuilds/` — only darwin/linux, no win32-x64
- Source: `tools/node_modules/tree-sitter-bsl/src/parser.c`

**Resolution options:**
1. Compile tree-sitter-bsl to .dll using `tree-sitter build-wasm` or cmake
2. Use the Node.js-based ast-grep-mcp server instead of CLI subprocess
3. Wire the multilspy (BSL LS) backend as alternative
