## Content

Анализ задачи GKSTCPLK-2536 «Разработать печатную форму ТН снятие с хранения» (1С УправлениеТранспортом, ИБTransportManagementDevelop). ANALYSIS-REPORT.md создан.

Суть: обработка-каркас Обработка.гкс_ПечатьТНСнятиеСХранения — недоведённая байт-в-байт копия гкс_ПечатьТТНСнятиеСХранения (ТТН, GKSTCPLK-2522). Эталон для реализации = ManagerModule.bsl ТТН (993 стр., полностью рабочий).

Что не доведено в ТН-каркасе:
- НЕТ ManagerModule.bsl (форма вызывает .ПолучитьДокументыРегистрации/.Печать менеджера, которых нет → форма нерабочая) — основная работа: создать его адаптацией ТТН.
- Forms/Форма/Module.bsl:139 указывает на чужой "Обработка.гкс_ПечатьТТНСнятиеСХранения" — сменить на свой.
- Forms/Форма/Module.bsl:14 дефолт макета ТТН — сменить на ТН.
- Templates/* = байт-в-байт копии ТТН-макетов (diff IDENTICAL) — перепроектировать под ТН-2 (товарная накладная, МакетПечати.png, без транспортного блока) в Конструкторе.

Ключевое отличие ТН от ТТН (load-bearing): ТТН печатает 1 лист на каждый ДокументРегистрации (шапка группируется по документу). ТН консолидирует регистрации за сутки — ключ листа = (Дата, ТочкаМаршрута/ПЛК, Собственник, ДоговорХранения), строки по Номенклатуре. Подтверждено на живых данных: за 2026-05-07 группа «БЕЛАГРОТЕРМИНАЛ ООО / Шрот соевый / ПЛК Сморгонь» = 20 документов → 1 строка.

Верифицировано execute_query (БД жива, домен @sodru.com): 15367 Убыл/Отгрузка/Авто; макс.дата 2026-05-07; ДоговорХранения=null + ВесНетто=0 + ЗалоговаяЦена=0 у всех проб (залоговые цены не заполнены — связано с in-flight GKSTCPLK-2521). Поэтому обязателен fallback количества на гкс_ПриемкаНаПЛКСервер.ПоказанияВесовПоРегистрации (как в ТТН). Собственник — составной тип (Организации/Контрагенты) → грузополучатель через ВЫРАЗИТЬ.

Wiring печати: Документ.гкс_РегистрацияНаПЛК.ManagerModule.ДобавитьКомандыПечати → гкс_ЛокализацияСервер.МодульЛокализации → гкс_РегистрацияНаПЛКЛокализация_by; обработчики команд в гкс_УправлениеПечатьюКлиент_by. Регистрация ТН-команды в списке опциональна (форма standalone, period→Сформировать→Печать, прямой ВыполнитьКомандуПечати).

Открытый вопрос №1 заказчику: точный ключ группировки листа ТН. Маршрут: implement-1c-task. Корень исходников: ИБTransportManagementDevelop/Конфигурация/src (не configuration/260304_.../docs).
