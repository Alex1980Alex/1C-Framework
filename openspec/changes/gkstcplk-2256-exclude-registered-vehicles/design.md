## Design: Исключение зарегистрированных ТС из очереди приемки

### Модифицируемый модуль

**Файл:** `InformationRegisters/гкс_СтатусыЗаписейВОчередиПриемкиПЛК/Ext/ManagerModule.bsl`

### Изменение SQL-запроса

В запросе формирования `ВТ_ЭлектроннаяОчередь` добавить LEFT JOIN на документ `гкс_РегистрацияНаПЛК`:

```bsl
ЛЕВОЕ СОЕДИНЕНИЕ Документ.гкс_РегистрацияНаПЛК КАК РегистрацияНаПЛК
ПО ОчередьПриемкиПЛК.НомерТранспортногоСредства = РегистрацияНаПЛК.ТранспортноеСредство.Наименование
    И ОчередьПриемкиПЛК.ТочкаМаршрута = РегистрацияНаПЛК.ТочкаМаршрута
    И РегистрацияНаПЛК.Проведен = ИСТИНА
```

В секцию ГДЕ добавить:
```bsl
И РегистрацияНаПЛК.Ссылка ЕСТЬ NULL
```

### Аналогичные реализации в конфигурации

Паттерн LEFT JOIN + ЕСТЬ NULL для исключения записей используется в:
- Модуль менеджера `гкс_ОчередьПриемкиПЛК` — аналогичная фильтрация по статусам
- Обработка проведения `гкс_РегистрацияНаПЛК` — проверка уникальности

### Зависимости

- Нет зависимостей от других модулей
- Изменение затрагивает только один запрос в одной процедуре

### Риски

- Производительность: LEFT JOIN на большой таблице документов. Митигация: JOIN по двум полям (НомерТС + ТочкаМаршрута) + фильтр Проведен = ИСТИНА сужает выборку
