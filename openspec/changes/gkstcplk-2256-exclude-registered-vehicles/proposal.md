## Why

Задача GKSTCPLK-2256: при формировании электронной очереди на приемку ПЛК в неё попадают транспортные средства (ТС), которые уже прошли регистрацию на ПЛК. Это приводит к дублированию — оператор видит в очереди ТС, которые уже зарегистрированы, и тратит время на их фильтрацию вручную.

## What Changes

- Исключить из электронной очереди приемки ТС, для которых уже существует проведённый документ "Регистрация на ПЛК" с совпадающим номером ТС и точкой маршрута
- Модификация запроса в модуле менеджера регистра сведений `гкс_СтатусыЗаписейВОчередиПриемкиПЛК`
- Добавление LEFT JOIN на документ `гкс_РегистрацияНаПЛК` с фильтром `Ссылка ЕСТЬ NULL`

## Capabilities

### New Capabilities
- `exclude-registered-vehicles`: Фильтрация электронной очереди приемки — исключение ТС с проведённой регистрацией на ПЛК

### Modified Capabilities
<!-- Нет изменений существующих спецификаций -->

## Impact

- **Код:** Модуль менеджера РС `гкс_СтатусыЗаписейВОчередиПриемкиПЛК` — изменение SQL-запроса формирования временной таблицы `ВТ_ЭлектроннаяОчередь`
- **Данные:** Сокращение количества записей в очереди приемки (только незарегистрированные ТС)
- **Риски:** Если у ТС несколько регистраций на разных точках маршрута — каждая должна проверяться отдельно (JOIN по НомерТС + ТочкаМаршрута)
