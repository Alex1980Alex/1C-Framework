## ADDED Requirements

### Requirement: Исключение зарегистрированных ТС из электронной очереди приемки

Запрос формирования временной таблицы `ВТ_ЭлектроннаяОчередь` в модуле менеджера РС `гкс_СтатусыЗаписейВОчередиПриемкиПЛК` MUST исключать транспортные средства, для которых существует проведённый документ `гкс_РегистрацияНаПЛК` с совпадающим номером ТС и точкой маршрута.

#### Объекты метаданных

| Объект | Тип | Роль |
|--------|-----|------|
| `РегистрСведений.гкс_ОчередьПриемкиПЛК` | Регистр сведений | Источник: записи очереди |
| `РегистрСведений.гкс_СтатусыЗаписейВОчередиПриемкиПЛК` | Регистр сведений | Модуль менеджера: содержит изменяемый запрос |
| `Документ.гкс_РегистрацияНаПЛК` | Документ | Фильтр: проведённые регистрации |

#### Поля соединения

| Поле очереди | Поле регистрации | Тип |
|-------------|-----------------|-----|
| `ОчередьПриемкиПЛК.НомерТранспортногоСредства` | `РегистрацияНаПЛК.ТранспортноеСредство.Наименование` | Строка |
| `ОчередьПриемкиПЛК.ТочкаМаршрута` | `РегистрацияНаПЛК.ТочкаМаршрута` | СправочникСсылка.гкс_ТочкиМаршрута |

#### Условие фильтрации

- `РегистрацияНаПЛК.Проведен = ИСТИНА`
- `РегистрацияНаПЛК.Ссылка ЕСТЬ NULL` (LEFT JOIN — оставляем только НЕзарегистрированные)

---

#### Scenario: ТС не зарегистрировано — попадает в очередь

- **GIVEN** ТС с номером "А123БВ" в очереди приемки на точке маршрута "Склад-1"
- **AND** нет проведённого документа `гкс_РегистрацияНаПЛК` для этого ТС на этой точке
- **WHEN** выполняется запрос формирования `ВТ_ЭлектроннаяОчередь`
- **THEN** запись с номером "А123БВ" MUST присутствовать в результате

---

#### Scenario: ТС зарегистрировано — исключается из очереди

- **GIVEN** ТС с номером "Б456ГД" в очереди приемки на точке маршрута "Склад-1"
- **AND** существует проведённый документ `гкс_РегистрацияНаПЛК` для этого ТС на точке "Склад-1"
- **WHEN** выполняется запрос формирования `ВТ_ЭлектроннаяОчередь`
- **THEN** запись с номером "Б456ГД" MUST NOT присутствовать в результате

---

#### Scenario: ТС зарегистрировано на другой точке маршрута

- **GIVEN** ТС с номером "В789ЕЖ" в очереди приемки на точке маршрута "Склад-2"
- **AND** существует проведённый документ `гкс_РегистрацияНаПЛК` для этого ТС, но на точке "Склад-1"
- **WHEN** выполняется запрос формирования `ВТ_ЭлектроннаяОчередь`
- **THEN** запись с номером "В789ЕЖ" MUST присутствовать в результате (регистрация на другой точке не считается)

---

#### Scenario: Документ регистрации не проведён

- **GIVEN** ТС с номером "Г012ЗИ" в очереди приемки
- **AND** существует документ `гкс_РегистрацияНаПЛК` для этого ТС, но он НЕ проведён
- **WHEN** выполняется запрос формирования `ВТ_ЭлектроннаяОчередь`
- **THEN** запись с номером "Г012ЗИ" MUST присутствовать в результате (непроведённая регистрация не считается)
