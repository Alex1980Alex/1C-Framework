## Architecture

### Расширение конфигурации `гкс_MCPToolkit`

```
Claude Code (.mcp.json)
  │ HTTP POST /hs/mcp/endpoint
  ▼
IIS / Веб-сервер 1С (порт 80/443)
  │ Маршрутизация → HTTP-сервис
  ▼
Расширение гкс_MCPToolkit
  ├── HTTPСервис.гкс_MCP
  │   └── Шаблон URL: /endpoint
  │       └── POST → гкс_MCPToolkitСервер.ОбработатьЗапрос()
  ├── ОбщийМодуль.гкс_MCPToolkitСервер (Сервер, Привилегированный)
  │   ├── ОбработатьЗапрос(HTTPЗапрос) → HTTPОтвет
  │   ├── МаршрутизироватьКоманду(Метод, Параметры) → Результат
  │   ├── ВыполнитьЗапрос(Текст, Параметры, Лимит)
  │   ├── ВыполнитьКод(Код)
  │   ├── ПолучитьМетаданные(Фильтр, Тип, Маска, Лимит)
  │   ├── ПолучитьЖурналРегистрации(Количество, Период)
  │   ├── ПолучитьОбъектПоСсылке(Ссылка)
  │   ├── ПолучитьСсылкуОбъекта(Описание)
  │   ├── НайтиСсылкиНаОбъект(Описание, Область)
  │   └── ПолучитьПраваДоступа(Объект)
  ├── ОбщийМодуль.гкс_MCPToolkitСериализация (Сервер)
  │   ├── ЗначениеВTOON(Значение) → Строка
  │   ├── БезопасноеЗначение(Значение, Глубина)
  │   └── СхемаРезультатаЗапроса(РезультатЗапроса)
  └── Константа.гкс_РазрешитьMCPToolkit (Булево)
```

### Протокол MCP JSON-RPC

Входящий запрос:
```json
{"jsonrpc": "2.0", "id": 1, "method": "tools/call",
 "params": {"name": "execute_query", "arguments": {"query": "..."}}}
```

Ответ:
```json
{"jsonrpc": "2.0", "id": 1, "result": {"content": [{"type": "text", "text": "..."}]}}
```

### Маршрутизация команд

| MCP method | Обработчик | Привилегированный |
|---|---|---|
| tools/list | СписокИнструментов() | Нет |
| tools/call → execute_query | ВыполнитьЗапрос() | Да |
| tools/call → execute_code | ВыполнитьКод() | Да |
| tools/call → get_metadata | ПолучитьМетаданные() | Нет |
| tools/call → get_event_log | ПолучитьЖурналРегистрации() | Нет |
| tools/call → get_object_by_link | ПолучитьОбъектПоСсылке() | Нет |
| tools/call → get_link_of_object | ПолучитьСсылкуОбъекта() | Нет |
| tools/call → find_references_to_object | НайтиСсылкиНаОбъект() | Нет |
| tools/call → get_access_rights | ПолучитьПраваДоступа() | Нет |

## Key Decisions

### 1. HTTP-сервис vs NativeAPI
**Решение:** HTTP-сервис 1С (стандартный механизм).
**Причина:** NativeAPI требует бинарную компоненту (.dll), сборку C++, и ручной запуск. HTTP-сервис работает через IIS/веб-сервер автоматически. Платформа 8.3.27 поддерживает Streamable HTTP.

### 2. Привилегированный режим
**Решение:** Общий модуль `гкс_MCPToolkitСервер` с флагом `Привилегированный = Истина`.
**Причина:** execute_query и execute_code должны иметь полный доступ к данным без ограничений RLS. Защита через константу `гкс_РазрешитьMCPToolkit` + роль `гкс_МСPToolkit`.

### 3. TOON-формат сериализации
**Решение:** Перенести логику `БезопасноеЗначениеДляПередачи()` (340 строк) в отдельный модуль `гкс_MCPToolkitСериализация`.
**Причина:** Экономия 30-60% токенов, совместимость с Claude Code клиентом.

### 4. Без анонимизации в v1
**Решение:** Анонимизация (779 правил) не переносится в расширение.
**Причина:** Сложность + низкий приоритет для тестовой базы. Добавить в v2 при необходимости.

### 5. Публикация через IIS
**Решение:** HTTP-сервис публикуется на существующем веб-сервере KOMPUTER.
**Причина:** IIS уже настроен для 1С. URL: `http://KOMPUTER/TestDB/hs/mcp/endpoint`.

## Data Model

### Объекты расширения

| Объект | Тип | Назначение |
|---|---|---|
| `гкс_MCP` | HTTPСервис | Точка входа HTTP-запросов |
| `гкс_MCPToolkitСервер` | ОбщийМодуль (Сервер, Привилегированный) | Логика обработки команд |
| `гкс_MCPToolkitСериализация` | ОбщийМодуль (Сервер) | TOON-сериализация |
| `гкс_РазрешитьMCPToolkit` | Константа (Булево) | Вкл/выкл MCP-сервис |
| `гкс_МСPToolkit` | Роль | Доступ к HTTP-сервису |

### Формат TOON (Token-Optimized Object Notation)

Компактная нотация вместо JSON:
```
[3]{Код, Наименование, Дата}:
  "001", "Пшеница 3кл", 2026-04-06
  "002", "Рапс", 2026-04-05
  "003", "Ячмень", 2026-04-04
```

## Error Handling

- HTTP 200 + `{"error": {"code": -32600, "message": "..."}}` для MCP-ошибок
- HTTP 403 если `гкс_РазрешитьMCPToolkit = Ложь`
- HTTP 500 для необработанных исключений
- Логирование в журнал регистрации (событие `гкс_MCPToolkit`)

5. Обновить `.mcp.json` с новым URL
