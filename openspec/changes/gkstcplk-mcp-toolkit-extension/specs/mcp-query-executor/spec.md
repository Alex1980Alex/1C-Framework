## ADDED Requirements

### Requirement: execute_query — выполнение запросов 1С

Инструмент `execute_query` MUST выполнять текст запроса 1С и возвращать результат в TOON.

- Принимает: `query` (текст запроса), `params` (параметры), `limit` (default 100), `include_schema` (boolean)
- Выполняет через `Новый Запрос(ТекстЗапроса)`
- Параметры с `_objectRef: true` преобразуются в ссылки 1С
- Результат в TOON-формате: `[N]{колонки}:\n  строка1\n  строка2`
- При `include_schema=true` добавляется описание типов колонок
- Ошибки запроса возвращаются как MCP error

#### Scenario: простой SELECT

- **WHEN** `query = "ВЫБРАТЬ Код, Наименование ИЗ Справочник.Валюты"`, `limit = 5`
- **THEN** возвращается TOON `[5]{Код,Наименование}` с первыми 5 строками

#### Scenario: запрос с ссылкой-параметром

- **WHEN** params содержит `{Контрагент: {_objectRef: true, id: "..."}}`
- **THEN** параметр преобразуется в ссылку 1С перед `Выполнить()`

### Requirement: execute_code — выполнение произвольного BSL

Инструмент `execute_code` MUST выполнять произвольный BSL-фрагмент и возвращать `Результат`.

- Принимает: `code` (текст BSL-кода)
- Выполняет через `Выполнить(Код)` в привилегированном режиме
- Результат записывается в переменную `Результат`
- Возвращает сериализованное значение `Результат`
- Ошибки компиляции/выполнения возвращаются как MCP error

#### Scenario: вычисление выражения

- **WHEN** `code = "Результат = 2 + 2;"`
- **THEN** возвращается `4`

#### Scenario: возврат из процедуры запрещён

- **WHEN** `code` содержит `Возврат;` вне процедуры/функции
- **THEN** возвращается MCP error с описанием parse-проблемы (известное ограничение)

### Requirement: Сериализация значений в TOON

Все возвращаемые значения MUST сериализоваться в TOON-формат по правилам:

- Примитивы: строки в кавычках, числа без, даты ISO 8601, булево `true/false`
- Ссылки: `{_objectRef: true, УникальныйИдентификатор: "uuid", ТипОбъекта: "..."}`
- Табличные части: массив объектов
- Максимальная глубина рекурсии: 5
- `null` для пустых ссылок

#### Scenario: пустая ссылка

- **WHEN** значение = `Справочники.Контрагенты.ПустаяСсылка()`
- **THEN** сериализуется как `null`

#### Scenario: глубокая структура

- **WHEN** объект имеет вложенность > 5 уровней
- **THEN** сериализация прекращается на уровне 5, дальше — `"..."`
