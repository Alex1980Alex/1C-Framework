## Requirements

### REQ-5: execute_query — выполнение запросов 1С
- Принимает: `query` (текст запроса), `params` (параметры), `limit` (лимит строк, default 100), `include_schema` (boolean)
- Выполняет запрос через `Новый Запрос(ТекстЗапроса)`
- Параметры с `_objectRef: true` преобразуются в ссылки 1С
- Результат в TOON-формате: `[N]{колонки}:\n  строка1\n  строка2`
- При `include_schema=true` добавляется описание типов колонок
- Ошибки запроса возвращаются как MCP error

### REQ-6: execute_code — выполнение произвольного BSL
- Принимает: `code` (текст BSL-кода)
- Выполняет через `Выполнить(Код)` в привилегированном режиме
- Результат записывается в переменную `Результат`
- Возвращает сериализованное значение `Результат`
- Ошибки компиляции/выполнения возвращаются как MCP error

### REQ-7: Сериализация значений в TOON
- Примитивы: строки в кавычках, числа без, даты ISO 8601, булево true/false
- Ссылки: `{_objectRef: true, УникальныйИдентификатор: "uuid", ТипОбъекта: "..."}`
- Табличные части: массив объектов
- Максимальная глубина рекурсии: 5
- null для пустых ссылок
