## ADDED Requirements

### Requirement: execute_query — выполнение запросов 1С

Инструмент `execute_query` MUST выполнять текст запроса 1С и возвращать результат в TOON.

- Принимает: `query` (текст запроса), `params` (параметры), `limit` (default 100), `include_schema` (boolean)
- Выполняет через `Новый Запрос(ТекстЗапроса)`
- Параметры с `_objectRef: true` преобразуются в ссылки 1С
- Результат в TOON-формате: `[N]{колонки}:\n  строка1\n  строка2`
- При `include_schema=true` добавляется описание типов колонок
- Ошибки запроса возвращаются как MCP error

#### Scenario: простой SELECT

- **WHEN** `query = "ВЫБРАТЬ Код, Наименование ИЗ Справочник.Валюты"`, `limit = 5`
- **THEN** возвращается TOON `[5]{Код,Наименование}` с первыми 5 строками

#### Scenario: запрос с ссылкой-параметром

- **WHEN** params содержит `{Контрагент: {_objectRef: true, id: "..."}}`
- **THEN** параметр преобразуется в ссылку 1С перед `Выполнить()`
