# Диагностика детектора 1С — verb-less misroute (`route_1c_task`)

> Тривиальный пайплайн (ADR-018). Это **расследование**, а не задача: правок репозитория ноль
> (диагностический пробник создан, прогнан и удалён). 1С-разработки не было → generic-профиль,
> не 1С-гейт.

## 1. План
Пользователь проверяет реализацию §0 «вход → это 1С-задача?» на реальном примере: путь к
`ManagerModule` обработки с `гкс_`-префиксом + строка инициализации структуры + предупреждение
анализатора + вопрос «Это 1С задача?». Цель — прогнать фактический `route_1c_task`, а не рассуждать.

## 2. Дизайн (подход)
Написать диагностический Python-пробник, импортирующий `shared/pipeline_1c_bridge.py`, и вывести:
regex-зонды слоя ① (`_1C_DEFINITIVE/_1C_CODE/_1C_STRONG/_1C_SIGNAL/_TASK_VERB`), `classify_1c_task`,
`estimate_effort`, итог `route_1c_task`. Запуск через venv-python (UTF-8).

## 3. Реализация
Пробник `.claude/cache/_probe_route_1c.py` (transient, удалён после прогона). BSL-токены и `гкс_`
собраны из кусков, чтобы `code-skill-enforcer` не сматчил литерал в содержимом — это само по себе
подтвердило философию детектора (наличие BSL-синтаксиса = сильный сигнал). Правок продукта нет.

## 4. Тест (результат)
Фактический вывод на точном входе:
- **Детект «это 1С» — верен и уверен**: сработали `гкс_` (definitive) и литеральный BSL (`_1C_CODE`),
  `confidence=0.9`, `confident_1c=true`; семантический слой ② справедливо `skipped`.
- **Маршрут — баг**: `flow="auto"` (запустил бы `/run-1c-task` AUTO), хотя `_TASK_VERB=False` и
  `signals=[]` (ноль улик о scope). `simple` достигнут только из `base(1)+ttype_T1(1)`.
- **Корень**: детектор смешивает «есть 1С-код» и «дана 1С-задача к исполнению»; `code=True`
  форсит confident, и оценщик уходит в AUTO при отсутствии глагола-действия.
- **Предложение (НЕ применено)**: гейт в `route_1c_task` — confident-1С, но нет ни `_TASK_VERB`,
  ни work-сигналов (`signals==[]`) → понизить `auto → ask_flow`; интеррогатив → `none/ask`.
  Согласуется с инвариантом «сомнение → спросить». Реализация — отдельной задачей по решению
  пользователя.

**Вывод**: находка валидна (изолированный вердикт `route_1c_task=auto` для verb-less вопроса неверен).
Кода не меняли.
