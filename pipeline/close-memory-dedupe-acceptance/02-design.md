## Почему это безопасно (сведено из инструмента)

- **Бэкап ДО мутации** — точки + векторы + рёбра в `data/memory/backups/`, откат `--restore`.
- **Link-aware** — рёбра лоузеров репойнтятся на выжившего; канон из `mirrors` побеждает
  эвристику `pick_survivor`; висячих рёбер не остаётся (иначе ABORT в `main()`).
- **Fail-closed** — если `link_registry` нечитаем ИЛИ план оставил бы висячее ребро →
  инструмент отказывается мутировать.
- **Create-before-delete** для рёбер — прерванный прогон оставляет дубль (безвреден,
  идемпотентный повтор), не дыру.
- **Слияние без потери обучения** — succ/fail/application_count суммируются в выжившего,
  confidence пересчитывается из слитых счётчиков (§22 Beta(7,3)).
