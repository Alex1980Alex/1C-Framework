# Пайплайн: Создание серверной демо-базы 1С:ERP 2.5.27.52

> **Инфраструктурная задача** (администрирование кластера 1С + MSSQL), парная к Trade 11.5.27.52. Кода конфигурации/фреймворка не писалось. Компактный артефакт по ADR-018.

## 1. Планирование
Запрос: «создай серверную базу для установки Enterprise20_2_5_27_52_setup1c» = **1С:ERP Управление предприятием 2, версия 2.5.27.52**.
Окружение известно (кластер x86 8.3.27.1936, MSSQL 2022). Проверено: ERP-шаблон уже установлен в `…\tmplts\1c\Enterprise20\2_5_27_52\` (`1cv8.cf` 1533 МБ + `1cv8.dt` 1759 МБ); на C: (MSSQL DATA) свободно 180 ГБ — демо ERP хватит с запасом.

## 2. Дизайн  (одобрено)
- Тип базы — **демонстрационная (`1cv8.dt`)** по аналогии с Trade (дефолт заявлен пользователю + дана опция переключиться на clean из `.cf`).
- Ref/DB = `Enterprise20_2_5_27_52`; отдельный SQL-логин `1c_erp` (dbcreator), алфавитно-цифровой пароль, креды вне публичного репо (`C:\1SDB\creds_1c_erp.txt`).
- Один шаг `CREATEINFOBASE …;CrSQLDB=Y;Locale=ru; /UseTemplate <…1cv8.dt> /AddInList`, бинарём x86 8.3.27.1936.

## 3. Исполнение
1. Pre-flight: БД `Enterprise20_2_5_27_52` отсутствует, Ref свободен → OK.
2. `sqlcmd -E -Q` создал логин `1c_erp` (dbcreator); пароль сохранён вне репо.
3. `CREATEINFOBASE /UseTemplate …1cv8.dt` в фоне → **exit 0**: серверная ИБ + SQL-БД + восстановление демо-дампа + запись в `ibases.v8i`.

## 4. Верификация
- `/Out`-лог: «Создание информационной базы … успешно завершено» + «… добавлена в список».
- Кластер: `1CV8Clst.lst` содержит `Enterprise20_2_5_27_52` (1 совпадение).
- Список запуска: `ibases.v8i` → `[ERP 2.5.27.52 demo]`, `Connect=Srvr="DESKTOP-TNU600C";Ref="Enterprise20_2_5_27_52";`.
- БД: **ONLINE**, collation `Cyrillic_General_CI_AS`, ~5 ГБ, **17 900 таблиц, ~1 846 202 строк** → демо-данные на месте.
