# Пайплайн: Создание серверной демо-базы УТ 11.5.27.52

> **Инфраструктурная задача** (администрирование кластера 1С + MSSQL). Кода конфигурации/фреймворка не писалось — все действия через `1cv8.exe` / `sqlcmd` / реестр кластера. Компактный артефакт по ADR-018 (trivial-путь: один файл на 4 этапа).

## 1. Планирование
Запрос: «создай серверную базу для установки конфигурации Trade_11_5_27_52_setup1c».
Разведка окружения: платформа 8.3.27 (**активный кластер — x86 8.3.27.1936**, `DESKTOP-TNU600C:1541`, ragent/rmngr/rphost живы; x64-агент остановлен), MSSQL 2022 (`MSSQLSERVER`, `sqlcmd -E` под sysadmin), дистрибутив `setup1c` уже распакован в шаблоны `…\tmplts\1c\trade\11_5_27_52\` (есть и `1cv8.cf`, и `1cv8.dt`).

## 2. Дизайн  (одобрено)
- Развилка **demo / clean** вынесена пользователю → выбрана **демонстрационная (`1cv8.dt`)**.
- Ref/DB = `Trade_11_5_27_52`; отдельный SQL-логин `1c_trade` (dbcreator), алфавитно-цифровой пароль (без `=;'"[]` — парсер строки подключения 1С), креды **вне публичного репо** (`C:\1SDB\creds_1c_trade.txt`).
- Создание одним шагом: `1cv8 CREATEINFOBASE …;CrSQLDB=Y;Locale=ru; /UseTemplate <…1cv8.dt> /AddInList`, бинарём **x86 8.3.27.1936** (совпадение с работающим кластером).

## 3. Исполнение
1. Pre-flight: БД `Trade_11_5_27_52` отсутствует, Ref в `1CV8Clst.lst` свободен → OK.
2. `sqlcmd -E -Q` создал логин `1c_trade` (роль `dbcreator`); пароль сохранён вне репо.
3. `CREATEINFOBASE /UseTemplate …1cv8.dt` в фоне → **exit 0**: серверная ИБ + SQL-БД (`CrSQLDB=Y`) + восстановление демо-дампа + запись в `ibases.v8i`.

## 4. Верификация
- `/Out`-лог: «Создание информационной базы … успешно завершено» + «… добавлена в список».
- Кластер: `1CV8Clst.lst` содержит `Trade_11_5_27_52` (1 совпадение).
- Список запуска: `ibases.v8i` → `[Trade 11.5.27.52 demo]`, `Connect=Srvr="DESKTOP-TNU600C";Ref="Trade_11_5_27_52";`.
- БД: **ONLINE**, collation `Cyrillic_General_CI_AS`, ~2.6 ГБ, **8820 таблиц, ~679 017 строк** → демо-данные на месте.
