# Pipeline (trivial) — Docs 43.5 §0.10: stateless-детектор vs непрерывность задачи

> Задача из чата: «добавь это объяснение в документацию» (про то, что детект 1С срабатывает
> на каждом промте, но активный алгоритм задачи не переключается). Trivial — 1 doc-файл, прозы,
> кода нет. 4 секции по ADR-018.

## 1. Планирование
- **Запрос:** объяснить, что проверка «это 1С?» (`onec-task-input.py`, UserPromptSubmit) стартует на
  КАЖДОМ промте, но follow-up-промты активной задачи НЕ переключают алгоритм выполнения.
- **Где:** глава [`43_ПАЙПЛАЙН_1С`](../../docs/framework%20documentation/43_ПАЙПЛАЙН_1С/), главный файл
  [`43.5_СКВОЗНАЯ_КАРТА.md`](../../docs/framework%20documentation/43_ПАЙПЛАЙН_1С/43.5_СКВОЗНАЯ_КАРТА.md).
- **Пробел:** §0 описывает первичный детект ОДНОГО промта; нет раздела про повторный детект на
  последующих промтах и почему нет «переподключения».

## 2. Дизайн
- Новая секция **§0.10** между §0.9 (заведение state machine) и §1–§4 (этапы) — естественное место:
  §0.9 вводит pipeline-state, §0.10 контрастирует stateless-детектор vs этот state machine.
- Контент = разбор «два слоя»: СЛОЙ 1 детектор (advisory, УРОВЕНЬ 1 UserPromptSubmit) vs СЛОЙ 2
  непрерывность (`.pipeline-state.json`, keyed на slug). Стиль главы: ASCII-боксы + таблица + `file:line`.
- НЕ новый файл `43.5.x` (те — поблочный разбор детектор-каскада; это сквозная клировка).
