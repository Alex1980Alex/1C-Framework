## Сверка с реализацией (`scripts/tool_usage_report.py`)
Цикл из 4 шагов реально реализован:
1. **TOOL-PLAN.md** — артефакт (этап→инструменты→заметка), ведёт оператор (Claude).
2. **Лог** — `data/hook-invocations.jsonl` авто (`invocation_logger`): tool/outcome/elapsed_ms/correlationid=run_id.
3. **Оценка** — `tool_usage_report.py --run-id` агрег по tool (calls/errors/err%/avg_ms) + вердикт ✓/⚠/✗ **авто из err%** (≥30→✗, >0→⚠, 0→✓) + слот `_заметка_`.
4. **Запись** — `TOOL-USAGE-REPORT.md` (per-task) + append `data/tool-effectiveness.jsonl` → `--rollup` cross-task.

Нюанс (честно): TOOL-PLAN + `_заметка_` — ручные; лог + метрики + базовый вердикт — авто.
