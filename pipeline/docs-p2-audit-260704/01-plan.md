показала обратное: `claude-opus-4-6` — это **фактический дефолт конфигурации** во всём коде

`research_agent.py`, `rag/middleware.py`, `cross_document_synthesizer.py`) + юнит-тесты
ассертят строку. Доки уже совпадали с кодом. Реальной модели `claude-opus-4-6` в Anthropic API
нет (актуальная — `claude-opus-4-8`, $5/$25 за 1M токенов; старые $15/$75 в cost-таблицах были
устаревшими даже для 4.6).

**Решение пользователя (2026-07-04): bump кода → `claude-opus-4-8`** + правка цен $15/75→$5/25,
затем синхронизация доков. Это code-first: исправляем источник истины (код + тесты), доки следуют.
