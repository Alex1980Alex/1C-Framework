## A. Память

| Решение | Обоснование | Отклонённая альтернатива |
|---|---|---|
| `.wslconfig`: `memory=24GB`, `swap=8GB`, `autoMemoryReclaim=gradual` | cap выбран по замеру `docker stats` = 15.9 ГБ реального потребления + запас на пиковые сканы SonarQube и загрузку моделей TEI | `memory=8GB` из первоначальной рекомендации - **ниже фактического потребления, сломало бы контейнеры**; отвергнуто после замера |
| MSSQL `max server memory` = 12288 МБ | было `2147483647` (без лимита), фактически занимал 18.07 ГБ; 12 ГБ достаточно для dev-инстанса с 1С-инфобазами | рестарт службы не нужен, буферный пул сжимается сам |
| Pagefile не трогаем | 67.5 ГБ выделено при peak 11.4 ГБ - узкое место не он, а commit charge живых процессов | увеличение pagefile лечило бы симптом |
| Стек Langfuse не останавливаем | ~3 ГБ, по ADR-052 opt-in; выходит за рамки согласованного плана | предложено пользователю как следующий шаг |

## B. Хук

Восстановить блок из `ca61a74b0` дословно, с двумя обоснованными отклонениями:

1. **`sys.path.insert(0, repo_root)` → `append`.** Приоритет корня репозитория затенил бы hooks-local `shared.*`
   ([[feedback-hook-src-shared-collision]]). На позиции 0 уже стоит `.claude/hooks`.

2. **Langfuse-span под `DELEGATION_ROUTING_SPAN=1`, по умолчанию OFF.** Замер на здоровом Langfuse:

   | Слой | Стоимость |
   |---|---|
   | `import` модуля | 147 мс |
   | `is_langfuse_enabled()` | 52 мс |
   | `_get_langfuse_client()` | **740 мс** |
   | `start+end span` | 0.4 мс |
   | `client.flush()` | **1132 мс** |

   Итого ~1.9 с из 3 с таймаута = 95% бюджета на телеметрию. `flush=False` не помогает (2016 мс против 2058 мс:
   SDK выгружает буфер на `atexit`). Амортизировать нечем - на каждый промпт стартует новый процесс.
   Канареечный A/B (`_ROUTER_CANARY_PCT`) и так OFF, поэтому при выключенном span записывать нечего кроме `method="linucb"`.

**Отвергнуто:** эмит в daemon-потоке с коротким join. При стоимости одного только клиента 740 мс span почти никогда
не успевал бы уйти - телеметрия стала бы декоративной, что хуже честного явного выключателя.
