## Ловушка, найденная при закрытии гейтов

Саботаж-скрипт писал файл через `Path.write_text()` - Python на Windows перевёл весь файл в CRLF (396 строк).
Сверка `sha256` этого **не поймала**, потому что `read_text()` конвертирует CRLF→LF при чтении, а `git diff`
молчал из-за нормализации autocrlf - расхождение видел только `git status`/`update-index` («needs update»).
Устранено записью через `write_bytes()`; файл побайтово совпал с HEAD.
