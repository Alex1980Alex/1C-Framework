# Pipeline (medium): fix-labanaliz-temp-field

Задача: убрать предупреждение **«Уберите неиспользуемое поле из временной таблицы»** на
`ЛабораторныйАнализ.Номенклатура КАК НоменклатураСсылка` в
`ИБTransportManagementDevelop/Конфигурация/src/CommonModules/гкс_ЛабораторныйАнализЛокализация_by/Module.bsl`
(функция `ДанныеДляПечатнойФормыАктВозврата`, код GKSTCPLK-2567).

## 1. План
- `НоменклатураСсылка` помещается в ВТ `ВТ_ОсновныеДанные` (запрос 1), но НЕ читается из этой ВТ
  ни одним последующим запросом пакета → EDT/АПК ругается «неиспользуемое поле ВТ».
- НО поле РЕАЛЬНО используется: результат запроса 1 (`РезультатПакетаЗапросов[0]`) возвращается
  как `РезультатПоШапке` → `ДанныеШапки.НоменклатураСсылка` → ключ для лукапа текстов граф в
  `гкс_ПечатьАктВозврата_Беларусь.ДобавитьШаблоныВДанныеШапки`.
- **Удалять поле НЕЛЬЗЯ** — это тихо сломает фичу GKSTCPLK-2567 (всегда fallback «Рапс»).

## 2. Дизайн
Сделать «шапку» отдельным финальным `ВЫБРАТЬ … ИЗ ВТ_ОсновныеДанные` (а не результатом
ПОМЕСТИТЬ-запроса). Тогда все поля ВТ (включая `НоменклатураСсылка`) читаются ИЗ ВТ → проверка
«неиспользуемое поле» снимается. Поведение сохраняется: те же 13 колонок шапки.

## 3. Реализация
- Добавлен 4-й запрос в пакет: `ВЫБРАТЬ <13 полей> ИЗ ВТ_ОсновныеДанные` (шапка).
- `Возврат`: `РезультатПоШапке = РезультатПакетаЗапросов[3]` (был `[0]`),
  `РезультатПоТабличнойЧасти = РезультатПакетаЗапросов[2]` (без изменений).
- Запросы 1–3 (ПОМЕСТИТЬ ВТ_ОсновныеДанные / ПОМЕСТИТЬ ВТ_ЛабАнализ / ИТОГИ по показателям) не тронуты.

## 4. Тест (ground truth — live на dev-ИБ)
- `update_database` (incremental) → ИБ `UPDATED`.
- `1c-mcp-crud.execute_code`: вызов `ДанныеДляПечатнойФормыАктВозврата(Массив из 5 ЛабАнализов)`:
  - `РезультатПоШапке` = Результат запроса, **13 колонок**, есть `НоменклатураСсылка`;
  - `НоменклатураСсылка` **заполнена** = «Рапс (Россия)» (фича GKSTCPLK-2567 работает сквозь весь поток);
  - `РезультатПоТабличнойЧасти` = Результат запроса; 4-й индекс пакета валиден, ошибок нет.
- `edt-mcp.revalidate_objects` + `get_project_errors`: новых ошибок по модулю нет (запрос парсится).
- Примечание: сам чек «неиспользуемое поле ВТ» в профиле edt-mcp не воспроизводится (профиль заказчика
  строже), но снят по построению: поле теперь читается ИЗ ВТ финальным ВЫБРАТЬ.
- Косметика: у добавленных строк `|` на 1 таб больше отступа, чем у соседних — на разбор запроса не влияет.
