## Покрытие инварианта (обе стороны)

| Сценарий | Ожидание |
|---|---|
| запись вне репо | не правка ⟶ пайплайн не требуется |
| запись в репо | правка ⟶ требуется |
| бита нет (старые записи) | правка (fail-closed) |
| внешняя + внутренняя | правка (внешняя не оправдывает внутреннюю) |
| внешняя + её блок + реальная правка | **правка** (осиротевший блок не гасит чужое — нота ревьюера) |
| битый `ts` вне репо / в репо | не правка / правка |
| проводка логгера | бит доезжает до `log_invocation` |
| форма записи без бита | ключа нет (бит-в-бит прежняя) |
| `start` из внешней строки | сохраняется (якорь git-fallback) |
