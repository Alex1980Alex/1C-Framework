# Pipeline (trivial): fix-shablony-struct-init

Задача: убрать предупреждение статанализа 1С:EDT на инициализации структуры `Шаблоны`
в `ИБTransportManagementDevelop/Конфигурация/src/DataProcessors/гкс_ПечатьАктВозврата_Беларусь/ManagerModule.bsl`
(процедура `ДобавитьШаблоныВДанныеШапки`, код GKSTCPLK-2567).

## 1. План
Две взаимно-конфликтующие проверки EDT на этой строке:
- **«Предыдущее значение переменной не используется»** — срабатывает на `Шаблоны = Новый Структура();`
  (пустой конструктор, который тут же заполняется → пустое значение не используется).
- **`structure-consructor-too-many-keys`** («Конструктор структуры содержит более чем 3 ключей») —
  срабатывает на параметризованном конструкторе с >3 значениями.
Структуре нужно 4 ключа (Наименование1..4) → ни «пустой+Вставить», ни «конструктор на 4» не дают 0 предупреждений.

## 2. Дизайн
Компромисс, снимающий ОБЕ проверки: **3 значения в конструкторе + 4-й ключ через `.Вставить`**.
- ≤3 значений в конструкторе → `structure-consructor-too-many-keys` молчит.
- конструктор НЕ пустой → «предыдущее значение не используется» молчит.
Поведенчески идентично: те же 4 ключа/значения; условные перезаписи из справочника и
`ОбщегоНазначенияКлиентСервер.ДополнитьСтруктуру` не трогаются.

## 3. Реализация
Файл: `…/гкс_ПечатьАктВозврата_Беларусь/ManagerModule.bsl`, процедура `ДобавитьШаблоныВДанныеШапки`.
```bsl
Шаблоны = Новый Структура("Наименование1,Наименование2,Наименование3",
    "рапс россия маслосемян рапса",
    "маслосеменам рапса",
    "Маслосемена рапса");
Шаблоны.Вставить("Наименование4", "Маслосемена рапса. Требования при заготовках и поставках. Технические условия");
```
История попыток: (а) пустой `Новый Структура()`+4×Вставить → warning #1; (б) `Новый Структура(4 ключа)` → warning #2;
(в) 3+1 (принято) → 0 структурных warning'ов.

## 4. Тест (ground truth — реальный анализатор заказчика)
Прогон через **edt-mcp** (`revalidate_objects` + `get_project_errors` на `DataProcessor.гкс_ПечатьАктВозврата_Беларусь`):
- было (форма б): `structure-consructor-too-many-keys` ПРИСУТСТВУЕТ;
- стало (форма в): структурных предупреждений НЕТ.
- осталось 2× `query-in-loop` — **предсуществующие** (запрос внутри цикла печати, дизайн GKSTCPLK-2567), вне scope этой задачи.
Поведение: 4 ключа/значения и порядок совпадают с исходными (ранее подтверждено live-прогоном 8.3.27).
