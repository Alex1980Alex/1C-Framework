# Pipeline (trivial): fix-shablony-struct-init

Задача: убрать предупреждение статанализа **«Предыдущее значение переменной не используется»**
на строке `Шаблоны = Новый Структура();` в
`ИБTransportManagementDevelop/Конфигурация/src/DataProcessors/гкс_ПечатьАктВозврата_Беларусь/ManagerModule.bsl`
(процедура `ДобавитьШаблоныВДанныеШапки`, код GKSTCPLK-2567).

## 1. План
- Это НЕ настоящий мёртвый код: `Шаблоны` используется ниже (`.Вставить`, условные
  перезаписи, `ОбщегоНазначенияКлиентСервер.ДополнитьСтруктуру`). Удалять строку нельзя — сломает процедуру.
- Анализатор ругается на анти-паттерн «создать пустую структуру → тут же заполнить»:
  пустое значение конструктора `Новый Структура()` не используется, т.к. сразу
  затирается серией `.Вставить` (введено рефакторингом GKSTCPLK-2567).
- Решение: свернуть инициализацию значений-по-умолчанию в параметризованный конструктор
  `Новый Структура(КлючиСвойств, Значение1, …)` — пустого промежуточного значения больше нет.

## 2. Дизайн
- Заменить 5 строк (пустой конструктор + 4 `.Вставить` дефолтов) одним вызовом
  `Новый Структура("Наименование1,…,Наименование4", v1, v2, v3, v4)`.
- Условные перезаписи `Шаблоны.Вставить("НаименованиеN", …)` из запроса НЕ трогаем —
  `Структура.Вставить` перезаписывает существующий ключ, поведение идентично.
- Поведенчески эквивалентно: тот же набор ключей/значений, тот же fallback «Рапс».

## 3. Реализация
Файл: `…/гкс_ПечатьАктВозврата_Беларусь/ManagerModule.bsl`, процедура `ДобавитьШаблоныВДанныеШапки`.
```bsl
Шаблоны = Новый Структура(
    "Наименование1,Наименование2,Наименование3,Наименование4",
    "рапс россия маслосемян рапса",
    "маслосеменам рапса",
    "Маслосемена рапса",
    "Маслосемена рапса. Требования при заготовках и поставках. Технические условия");
```
Stale-копия `src/bsl/DataProcessors/…/Ext/ManagerModule.bsl` (старый pre-2567 вариант с
ветвлением по `ПродуктоваяГруппа`) — НЕ трогалась: это устаревший Designer-дамп, не цель линтера.

## 4. Тест
- Эквивалентность по разбору: 4 ключа + 4 значения совпадают со старыми дефолтами.
- Конструктор `Новый Структура(КлючиСтрокой, Значения…)` — штатный идиоматический BSL.
- Skill `code-verify` (статическая верификация diff).
- EDT/Sonar повторную валидацию у себя должен прогнать заказчик (edt-mcp в этой сессии не подключён).
