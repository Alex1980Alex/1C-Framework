# 02 Дизайн — устранение smells (поведение-сохраняюще)

| Замечание | Решение |
|---|---|
| Дубль `МассивСлов.Количество()` ×4 | переменная `КоличествоСлов` (извлечь после цикла заполнения) |
| Магическое `3` (порог слов) | константа `МаксимумСловВПолномФИО = 3` |
| Магические `2`/`3` (позиции) | `ПозицияВторогоСимвола = 2`, `ПозицияПослеИнициалаСТочкой = 3` |
| Конкатенация в цикле + в возврате | `СтрШаблон`/`СтрСоединить` (0 операторов `+`) |
| Дубль `ВРег(Символ)`/`ВРег(СледующийСимвол)` | приватный предикат `ЭтоЗаглавнаяБуква(Символ)` (кэш `ВРег`, порядок `И` сохранён) |

Инвариант: публичный API `ФИОДляПечати(...) Экспорт` не меняется; новый хелпер — не Экспорт.
Соответствие каноническому bsl-language-server (MagicNumber → именованная константа, исключения
-1/0/1) подтверждено. Правка — line-index-скриптом с anchor-ассертами (UTF-8/LF/no-BOM сохранены).

Дизайн одобрен (auto): бюджетная низкорисковая механика рефакторинга, эквивалентность доказуема.
