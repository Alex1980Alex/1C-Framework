# 02 Дизайн

Решение: **заинлайнить константу**. Значение-по-умолчанию в `ЕСТЬNULL` должно быть литералом, а не
параметром (параметр-константа в ISNULL-default не валидируется статически → «значение не задано»).

- 3 места `ЕСТЬNULL(поле, &КодВалютыПоУмолчанию)` → `ЕСТЬNULL(поле, ""BYN"")` (в BSL-строке `""BYN""` = query-литерал `"BYN"`).
- Удалить `Запрос.УстановитьПараметр("КодВалютыПоУмолчанию", "BYN")` (параметр больше не нужен).

Поведение тождественно: параметр всегда был `"BYN"` (Строка); литерал `"BYN"` — та же Строка, тот же тип.
DuplicateStringLiteral не возникает: `"BYN"` — подстроки внутри ОДНОГО строкового литерала query (не отдельные литералы).

Отклонённые варианты: (а) вынести set в text-builder — невозможно (функция возвращает строку, нет объекта Запрос);
(б) оставить параметр — он и так установлен, но EDT кросс-методно не видит. Дизайн одобрен (auto): тривиальная константа-подстановка.
