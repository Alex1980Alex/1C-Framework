# Пайплайн (trivial): исключить локальный EDT-воркспейс `MFM/` из git

## Что + зачем
EDT-MCP материализовал в корне репо локальный воркспейс `MFM/` (не git-репо,
машинно-специфичный: `.metadata`, `Конфигурация/` с `.settings`/`DT-INF`/`src`).
Он попал в `git status` как `?? MFM/` → Stop-гейты (`pipeline-protocol`,
`docs-change-enforcer`) ложно сочли это «правкой кода без пайплайна/доков».
Цель — исключить воркспейс из git, чтобы устранить ложное срабатывание навсегда.

## Корень, не симптом
Симптом: гейт блокирует завершение Q&A-сессии. Корень: untracked EDT-воркспейс
в корне репо. Другие EDT-воркспейсы (`ИБTransportManagementDevelop/`,
`TransportManagementDevelop_SVETLY/`) — submodule'ы; `MFM/` — обычный локальный
checkout, поэтому правильное место исключения — `.gitignore` (а не SKIP_PATTERNS).

## Этапы
1. **Планирование** — определено: исключить `MFM/` через `.gitignore` (минимальный,
   обратимый diff; зеркалит трактовку прочих EDT-воркспейсов как не-product-кода).
2. **Дизайн** — 2 строки коммента + `MFM/` после блока «Detached subprojects».
3. **Кодирование** — правка `.gitignore` (1 значимая строка-паттерн).
4. **Тестирование** — `git status --short --ignore-submodules=all` → `MFM/` исчез,
   остался только `M .gitignore`. ✅

## Критерий готово
`git status` больше не показывает `MFM/`; будущие EDT-сессии не триггерят гейты.
