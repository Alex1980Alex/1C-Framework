# 01 — Планирование

**Задача:** GKSTCPLK-2521 — хранение залоговых цен «по протоколу». Регистр `гкс_ЗалоговыеЦены` переведён в подчинение регистратору (документ-протокол `гкс_УстановкаЗалоговыхЦен`), периодичность `Month`.

**Проблема:** у подчинённого регистратору РС при **календарной** периодичности ключ записи = `Период + Измерения`, регистратор в ключ НЕ входит ⇒ два протокола на один месяц + срез → платформенная ошибка «Запись с такими ключевыми полями существует» при проведении второго. Подтверждено Infostart 1749405 + v8.1c.ru.

**Цель:** бизнес-правило «один протокол в месяц на срез (ТочкаМаршрута + ВидЗалоговойЦены)»; второй документ — дружелюбный отказ вместо платформенной ошибки.

**Решение заказчика (`доработка.md`):** оставить `Month` (не `RecorderPosition` из ANALYSIS-REPORT §13.4.3), добавить защиту уникальности.
