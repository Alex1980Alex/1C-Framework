# 02 — Дизайн (approved)

Срез стока УТ/ERP (дампы `external/1c-reference-src`): ценовые регистры `Month` НЕ используют — `ЦеныНоменклатуры` = `Second`, `ЦеныНоменклатурыПоставщиков` = `RecorderPosition`. `Month` в стоке — только «одно значение на календарный период на срез» (`КвотыАссортимента`, `СтоимостьТоваров`).

**Эталон:** `Документ.УстановкаКвотАссортимента` → `РегистрСведений.КвотыАссортимента` (Month + RecorderSubordinate):
1. Период движений = `НачалоМесяца(дата из шапки)`.
2. Менеджер-функция `СуществуетПлан(срез, НаДату, ВызывающийДокумент)` — запрос к РС, исключая себя (`Регистратор <> ВызывающийДокумент`).
3. `Отказ` + понятное сообщение при проведении.
4. Проверка под исключительной блокировкой среза → race-safe (TOCTOU).

**Применение:** срез уникальности = `ТочкаМаршрута + ВидЗалоговойЦены`, период из `Дата` документа.
