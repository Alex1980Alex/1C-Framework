# GKSTCPLK-2567 п.3 — доступ профилей к справочнику гкс_ТекстыГрафАктаВозврата

**Тип:** 1С (права доступа, БСП). **Конфигурация:** ИБTransportManagementDevelop.
**Требование:** Настройка (справочник `гкс_ТекстыГрафАктаВозврата`) должна быть доступна профилям **Лаборант**, **Лаборант внешних проб**, **Кладовщик**.
**Уровень доступа (решение пользователя):** полный — просмотр + изменение.

## 1. Планирование
Справочник `гкс_ТекстыГрафАктаВозврата` (Графа / Номенклатура / ТекстГрафы) — настроечный, хранит гибкие тексты граф ПФ «Акт возврата» по номенклатуре (пункты 1-2 задачи — печать `гкс_ПечатьАктВозврата_Беларусь`). Права в конфигурации раздаются по БСП: **Роль → поставляемый профиль (код `гкс_УправлениеДоступом`) → группа доступа → пользователь**. Роли для справочника не было.

## 2. Дизайн (эталон GKSTCPLK-2521 «залоговые цены»)
- Создать 2 гранулярные роли по конвенции `гкс_Справочник_<Объект>_<Просмотр|ДобавлениеИзменение>`.
- Зарегистрировать обе в `Configuration.mdo` (по алфавиту).
- Провести роль `_ДобавлениеИзменение` (включает просмотр) в 3 профиля через `ОписаниеПрофиля.Роли.Добавить`.
- RLS не требуется (объект не ограничиваемый).

## 3. Кодирование (изменённые файлы, сабмодуль Конфигурация/src)
- **NEW** `Roles/гкс_Справочник_ТекстыГрафАктаВозврата_Просмотр/` (.mdo + Rights.rights: Read, View, InputByString, Read/ViewDataHistory)
- **NEW** `Roles/гкс_Справочник_ТекстыГрафАктаВозврата_ДобавлениеИзменение/` (.mdo + Rights.rights: + Insert, Update, InteractiveInsert, Edit, Interactive(Set/Clear)DeletionMark)
- **MOD** `Configuration/Configuration.mdo` — 2 записи `<roles>` (между ПоказателиАнализовНоменклатуры и ТранспортныеСредства)
- **MOD** `CommonModules/гкс_УправлениеДоступом/Module.bsl` — `Роли.Добавить("гкс_Справочник_ТекстыГрафАктаВозврата_ДобавлениеИзменение")` ×3:
  - Лаборант → `ДополнитьПрофильРолямиДляРаботыСПрочимиОбъектамиЛаборант`
  - Лаборант внешних проб → `ДополнитьПрофильРолямиДляРаботыСОбъектамиЛабораторияВнешниеПробы`
  - Кладовщик → `ДополнитьПрофильРолямиДляРаботыСПрочимиОбъектамиКладовщик`

## 4. Тестирование / верификация
- EDT `revalidate_objects` → objectsFound = 3 (обе роли + модуль распознаны).
- EDT `get_project_errors` (объекты роли/модуль/справочник) → 0 ошибок на новых ролях и справочнике; 47 pre-existing style/doc-warn на модуле (не на новых строках); 1 unrelated ERROR (`ПрочитатьJSON` в `гкс_ИнтеграцияСКверионКлиент`, web-клиент) — не связано.
- `update_database` к dev-ИБ НЕ выполнялся: в рабочем дереве есть чужие незакоммиченные правки (пункты 1-2), применение применит весь конфиг. Деплой: роли наполнят профили при обновлении вспомогательных данных БСП (запуск Предприятия) после update_database. Опционально — применить + проверить `get_access_rights`.
