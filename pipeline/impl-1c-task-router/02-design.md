## Изменения (2 файла + тесты, обратимо)

### 1. `pipeline_1c_bridge.py` — `estimate_effort` + `route_1c_task`

**`estimate_effort(prompt, ttype, is_folder, cfg) -> {complexity, points, signals}`** — эвристическая
оценка трудозатрат `[own]`. Баллы по группам сигналов текста (config `_EFFORT_CFG`, тюнится):

| Группа | Вес | Маркеры (примеры) |
|---|---|---|
| `light` | −2 | опечатк, текст сообщен, наименован, переименов, заголовок |
| `modify` | +2 | доработать, добавить реквизит/колонк/форм, новый реквизит |
| `heavy_obj` | +5 | новый документ/справочник/регистр/отчёт/обработк, план обмена, регистр накоплен |
| `cross` | +3 | обмен данны, интеграц, rls, права доступ, роль, подсистем, рефакторинг |
| `multi` | +2 | несколько, массов, по всем, пакетн |
| `folder` | +2 | вход = готовая ТЗ-папка (формальный spec → крупнее) |
| `ttype_T1/T3` | +1 | новое / found-in-testing |

База = 1 (любая 1С-задача нетривиальна). Банды: **simple ≤2, medium 3–5, complex ≥6**.
Это ЭВРИСТИКА (грубый оценщик, не замена ревью) — честно отражено в docstring.

**`route_1c_task(prompt, is_folder, cfg) -> {is_1c, jira, ttype, complexity, points, signals, flow, reason, confident_1c}`**:
1. `classify_1c_task`. `is_1c=False` → `flow="none"` (молча, не наш маршрут).
2. `confident_1c` = есть JIRA ИЛИ сильный маркер (`_1C_STRONG`: гкс_ / объект-точка / CamelCase-кириллица).
   Не уверен → `flow="ask_1c"` (подтвердить 1С + V.6-дизамбигуация). **(«сомнение в 1С → спросить»)**
3. Иначе по `estimate_effort`: **simple→`auto`**, **complex→`gated`**, **medium→`ask_flow`**.

### 2. `onec-task-input.py` — сурфейсить маршрут
Заменить вызов `classify_1c_task` на `route_1c_task`; собрать system_message по `flow`:
- `none` → None (не инъектим).
- `ask_1c` → «похоже на 1С, не уверен/нет JIRA → ПОДТВЕРДИ (1С ли) + новая/доработка + папка» (+ V.6).
- `auto` → «1С простая (≈N трудозатрат) → рекомендую `/run-1c-task` (AUTO)».
- `ask_flow` → «1С средней сложности (≈N) → СПРОСИ: `/run-1c-task` (AUTO) или гейтованный `/analyze`+`/implement`?».
- `gated` → «1С сложная (≈N) → рекомендую гейтованный `/analyze-1c-task` → ревью → `/implement-1c-task`».
- Хвост всегда: «сомневаешься в 1С/потоке → спроси пользователя» (правило пользователя — поверх эвристики).
