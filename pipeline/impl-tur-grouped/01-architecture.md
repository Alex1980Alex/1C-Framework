# 01 — Планирование

## Задача (пользователь)
TOOL-USAGE-REPORT.md информативнее: (1) саммари по каждому инструменту, (2) группировка по artifact (этапу),
(3) расширить обязательные инструменты — память, скилы, анализ конфигурации (+ внешний анализ).

## Ключевой факт
События `hook-invocations.jsonl` несут `ts`/`time`, НО отчёт агрегируется ПО СЕССИИ (whole-session, не per-task).
Time-bucketing по этапам одной задачи покрыл бы лишь окно задачи → выбрана **группировка по функциональной
категории**, где каждая категория ассоциирована с artifact/этапом. Это же даёт обязательные категории-петли.
