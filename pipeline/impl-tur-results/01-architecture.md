# 01 — Планирование

## Задача (пользователь)
Под каждым инструментом в TOOL-USAGE-REPORT.md — саммари **результата работы** (не только назначение).

## Ключевое ограничение
Лог `hook-invocations.jsonl` несёт только **метрики** (calls/errors/ms), **не результаты**. Значит результат
нельзя вывести автоматически — он **курируется** Claude по факту задачи. Источник — сайдкар `TOOL-RESULTS.json`.

## Формат (выбор пользователя, AskUserQuestion)
**Блок на инструмент**: строка метрик + `· назначение:` + `· результат:` под каждым (таблица убрана).
