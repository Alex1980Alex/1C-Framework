# 01 — Планирование

## Задача
`TOOL-USAGE-REPORT.md` резолвить через `pipeline_state.state_dir(slug)` (реестр), а не только из `--task-dir`.
Цель пользователя: ВСЕ файлы задачи — в папке задачи, единый источник (реестр), как `.pipeline-state.json`/`LOOPS.md`.

## Контекст
До: `tool_usage_report.py --task-dir <D>` писал отчёт в `D` (передаётся извне, по соглашению). Не привязан к реестру.
После: путь = реестр (state_dir) — жёсткая привязка, консистентно с остальными файлами задачи.
