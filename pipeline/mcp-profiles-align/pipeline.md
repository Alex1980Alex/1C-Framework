# mcp-profiles-align (trivial, компактная форма ADR-018)

**Задача:** выровнять дрейф MCP-конфигов, найденный сканом бэкслэшей 2026-07-04.

## Что сделано

1. **`.mcp.json` → `bsl-platform-context`**: `--platform-path` переведён с
   `C:\Program Files (x86)\1cv8\8.3.27.1936` на `C:\Program Files\1cv8\8.3.27.2214`
   (актуальная установленная 64-битная платформа; профили `.mcp/bsl.json` и
   `.mcp/full.json` уже указывали на 2214 — отставал именно корень).
   Файлы синтакс-контекста `shcntx_*.hbk`/`shlang_*.hbk` в 2214 проверены — на месте.
2. **`.mcp/lazy-mcp.json`**: блок `lazy-mcp` приведён к зеркалу живого корневого
   (`.venv\Scripts\python.exe` + `-u` + `PYTHONUNBUFFERED=1` + timeout 60000)
   вместо отдельного `infra\lazy-mcp\.venv` → один venv на оба конфига.
   Каталог `infra/lazy-mcp/.venv` остался на диске, но конфигами больше не
   используется — можно удалить при желании.

## Верификация

- Все 5 конфигов (`.mcp.json`, `.mcp/{bsl,full,lazy-mcp,pdf}.json`) парсятся как JSON.
- `grep 8.3.27.1936` по конфигам → 0 вхождений.
- Активация корневой правки — после `/mcp reconnect` (текущая сессия
  bsl-platform-context продолжает работать на 1936 до реконнекта).
