# Тривиальная задача: сохранить справку по расчёту КПЭ/бонуса в память

**Тип:** trivial (не код, memory-save).

**Что сделано:** по 3 скриншотам документа КПЭ (ООО «Содружество-Инфо», сотрудник Терлецкий А.В.) выведена формула расчёта % премии к начислению (`вес/100 × 30% × %вып`), пересчитана таблица, справка сохранена в память для повторных обращений.

**Артефакты:**
- `.claude/projects/C--1--Framework/memory/reference_kpe_bonus_calculation.md`
- пойнтер в `MEMORY.md`

**Верификация:** формула проверена на двух примерах (вес 20→премия 6, вес 80→премия 24, итого 30%). Продуктовый код не затрагивался — ADR-018 pipeline применён формально (гейт над memory-Write).
