# Research: точки добавления шаблонов выбора без изменения БСП (GKSTCPLK-2692)

Trivial-задача (консультация, ADR-018 компактный формат). Код конфигурации не менялся - только кеш знаний.

## Вопрос

Из какого места можно добавлять шаблоны для выбора (механизм рассылки, БСП «Шаблоны сообщений»), не дорабатывая объекты БСП - взамен «сомнительного решения» GKSTCPLK-2574 (правка типового `ШаблоныСообщенийСлужебный`).

## Результат (verified по исходникам ИБTransportManagementDevelop)

- Чокпоинт списка: `ШаблоныСообщенийСлужебный.ПодготовитьЗапросДляПолученияСпискаШаблонов` :997; отбор :1052-1062 (тип предмета ИЛИ общий шаблон).
- Штатные места добавления: (1) элемент справочника ШаблоныСообщений «для ввода на основании» нужного типа - данные; (2) общий шаблон; (3) состав `ОпределяемыйТип.ПредметШаблонаСообщения` (уже содержит гкс_Взвешивание/гкс_РегистрацияНаПЛК/гкс_НаправлениеНаРазгрузку) + опц. СКД-макет `ДанныеШаблонаСообщений` в СВОЁМ документе; (4) `ШаблоныСообщенийПереопределяемый.ПриОпределенииНастроек` для произвольных предметов.
- Хука на сам запрос списка в БСП НЕТ (8 процедур переопределяемого проверены) - при реальной нужде только расширение `&Вместо` + `ПродолжитьВызов`, для 2692 не требуется.
- Под откат по 2692: вызов `гкс_РассылкиИОповещения.ДополнитьОтборШаблоновТипомПредмета` (база bat33566), инлайн `ИЛИ ТипПредметаОповещения` :1056 + нетиповой реквизит `ТипПредметаОповещения` (mdo :566, воркспейс).
