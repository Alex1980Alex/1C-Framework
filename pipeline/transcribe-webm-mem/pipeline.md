# Пайплайн (trivial): Транскрипция встречи + компактизация MEMORY.md

Тривиальная задача (не код-задача в продуктовом смысле): локальная транскрипция видео
через whisper MCP + обслуживание индекса памяти. Правки — только memory-`.md` файлы
(вне репо) + один pipeline-артефакт. Оформлено компактным `pipeline.md` по ADR-018.

## 1. Планирование
Вход: `file:///…/Запись встречи 10.07.2026 11_33_36.webm` (webm, 2:48, opus, русская речь).
Цель: расшифровать в текст. Инструмент: skill `whisper-transcription` + MCP `whisper`.
Побочно (по запросу Stop-хука): компактизировать `MEMORY.md` (161 → <140 строк).

## 2. Дизайн
- Путь с неразрывным пробелом U+00A0 в имени папки нормализуется MCP-транспортом →
  передавать DOS 8.3 short path (`FSO GetFile().ShortPath`). Зафиксировано в память.
- Приватность: встреча потенциально конфиденциальна → спросить пользователя.
  Выбран `privacy_mode=true` — текст остаётся локально, в API не уходит.
- Компактизация: одна строка/кластер, тесно связанные записи объединить попарно
  (оба wikilink'а на строке), один исторический пункт убрать. Заголовки секций сохранить.

## 3. Реализация
- `analyze_media` (short path) → 2:48/opus. `transcribe_audio` ru + `privacy_mode=true`,
  large-v3-turbo (Vulkan GPU) → `Запись встречи 10.07.2026 11_33_36.txt` (~402 слова, 4876 б).
- Память: создан `reference_mcp_file_arg_nbsp_short_path.md` + указатель в `MEMORY.md`.
- Компактизация `MEMORY.md`: 162 → 128 строк (119 записей); все указатели сохранены,
  убран 1 исторический (roadmap 260518 Phase 5 DONE).
