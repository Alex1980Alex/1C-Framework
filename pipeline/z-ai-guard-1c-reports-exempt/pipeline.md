# Trivial: исключение отчётов 1С-пайплайна из z-ai-write-guard

**Дата:** 2026-07-22
**Класс:** trivial (1 хук + 1 тест-файл)
**Решение пользователя:** вариант «Исключить отчёты 1С-пайплайна» (AskUserQuestion)

## Задача

`z-ai-write-guard` блокировал запись `ANALYSIS-REPORT.md` (правило «длинная .md-проза делегируема»,
порог 50 строк). Конфликт двойной:

1. **Содержательный** - отчёт несёт выверенные факты: номера строк модулей, UUID реальных
   объектов 1С, дословные выдержки стандартов ИТС. Делегирование переписывает именно эти
   позиции и тихо искажает то, на что затем опирается `/implement-1c-task`. Прямая аналогия
   с BSL-исключением из `_CODE_EXTENSIONS`.
2. **Конфликт энфорсеров** - `onec-task-completion-stop` и `pipeline-1c-advance` ТРЕБУЮТ этот
   файл, а гард его запрещал. Тот же класс, что уже закрыт для `pipeline/`.

Обходы были хуже правки: делегировать нельзя (искажение фактов), резать на куски <50 строк -
обход правила без фиксации решения, `llm_complete` не вмещает ~500 строк (лимит 4096 токенов).

## Решение

[.claude/hooks/z-ai-write-guard.py](../../.claude/hooks/z-ai-write-guard.py):
`_MD_EXEMPT_BASENAMES = ["analysis-report.md", "implementation-progress.md"]` +
`_MD_EXEMPT_BASENAME_SCOPE = "configuration/"`, условие вплетено в `is_large_md`.
Скоуп якорится на границу сегмента (`startswith` / `"/configuration/" in fp`) - каталог
`my_configuration/` исключения НЕ получает.

## Верификация

- Регресс [tests/unit/test_z_ai_guard_1c_reports_exempt.py](../../tests/unit/test_z_ai_guard_1c_reports_exempt.py):
  6 тестов, обе стороны инварианта (освобождение работает / другое имя блокируется /
  вне `configuration/` блокируется / lookalike-каталог блокируется / порог 50 цел).
- 22 теста трёх гард-наборов зелёные (новый + BSL + scope).
- Саботаж: с пустым `_MD_EXEMPT_BASENAMES` гард снова блокирует - тесты не зелёные по ложной причине.
- `code-verify` (субагент, read-only) → PARTIAL → 4 замечания исправлены → перепроверено:
  главное - тесты не глушили `shared.llm_health`/`shared.session_state`, из-за чего зависели
  от состояния машины (живое окно делегирования дало бы ложно-зелёные позитивы).
