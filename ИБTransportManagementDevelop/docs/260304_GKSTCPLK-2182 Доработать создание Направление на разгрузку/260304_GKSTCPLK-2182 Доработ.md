GKSTCPLK-2182 Доработать создание Направление на разгрузку для заблокированных ТС
Описание
Как сейчас При проведении Лаб. анализа, если качество принято, то создается Направление на разгрузку.БЕЗ включенной ФО Заблокированных ТС принцип создания Направления на разгрузку должен оставаться тот же.
При включенной ФО Направление на разгрузку формируется, когда
1. При проведении ЛА приемка на ТС, если регистрация не заблокировалась по правилу Первого ТС или Группы ТС, то автоматом создаем направление на разгрузку
2. При проведении ЛА промежуточного композита на группу или ЛА приемка первого ТС(по УК), если Качество принято по УК по для всех заблокированных ТС у которых итоговое качество принято формируем Направление на разгрузку, если оно еще не создано.
3. При проведении ЛА единичный/ промежуточной композит по УК , если Регистрация разблокирована и итоговое Качество принято

ОБРАТИТЬ ВНЕМАНИЕ !!!
Для отработки вычисления в ЛА заблокированных ТС при проведении ЛА создана процедура СформироватьСостоянияРегистацииДляЗаблокированныхТС();
Опираться на нее для дальнейших доработок.
