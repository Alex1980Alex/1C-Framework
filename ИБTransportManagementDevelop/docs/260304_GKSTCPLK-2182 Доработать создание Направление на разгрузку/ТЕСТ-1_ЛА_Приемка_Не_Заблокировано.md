# ТЕСТ-1: ЛА Приёмка — регистрация НЕ заблокирована

**Дата:** 2026-03-12
**База:** Srvr="KOMPUTER";Ref="TestDB"
**Требование п.1:** При проведении ЛА приемка на ТС, если регистрация не заблокировалась по правилу Первого ТС или Группы ТС, то автоматом создаем направление на разгрузку.

---

## Предусловия

| Параметр | Значение |
|---|---|
| ФО `гкс_ИспользоватьЗаблокированныеТС` | Должна быть **ВКЛЮЧЕНА** |
| ФО `гкс_ИспользоватьУсиленныйКонтрольКачества` | Должна быть **ВКЛЮЧЕНА** |
| Текущее значение ФО в базе | **ВЫКЛЮЧЕНА** (`false`) — для теста нужно включить |

## Логика (из кода)

```
ОбработкаПроведения
  → ОбновитьНаправлениеНаРазгрузку(Отказ) = Истина (Статус=Выполнен)
    → СформироватьНаправлениеНаРазгрузкуПриНеобходимости(гкс_ДокументРегистрации, ...)
      → Guard 1: НаправлятьНаРазгрузкуРазрешение() — проверка разрешения
      → Guard 2: РегистрацияЗаблокированаДляРазгрузки()
        → ТребуетсяЗаблокированныеТСЛабАнализа() = Истина (ФО включена + УК)
        → ПроверитьБлокированиеТранспортногоСредстваДляРазгрузки(гкс_ДокументРегистрации)
          → Если регистрация НЕ в таблице заблокированных → Ложь → проходим дальше
      → Guard 3: РегистрацияРазблокированаБезПринятогоКачества() — новая проверка
      → СформироватьНаправлениеНаРазгрузку() — СОЗДАНИЕ НР
```

## Цепочка тестирования

### Шаг 1: Включить ФО
- [ ] Установить `гкс_ИспользоватьЗаблокированныеТС` = `Истина`
- [ ] Установить `гкс_ИспользоватьУсиленныйКонтрольКачества` = `Истина` (если ещё не включена)

### Шаг 2: Найти ЛА Приёмка с регистрацией НЕ в таблице заблокированных

**Тестовый документ:** ЛА СоУТ-000039

```
Запрос проверки:
```

- [ ] Перепровести ЛА СоУТ-000039
- [ ] Проверить: НР СоУТ-000019 всё ещё проведён / или создан новый (защита от дублей в `ПолучитьПоРегистрации`)

### Шаг 3: Создать новый тестовый ЛА Приёмка

- [ ] Установить Статус = Выполнен
