# GKSTCPLK-2257 Доработать создание Направление на разгрузку для заблокированных ТС

## Описание

**Как сейчас:** При проведении Лаб. анализа, если качество принято, то создается Направление на разгрузку.

**БЕЗ включенной ФО** Заблокированных ТС принцип создания Направления на разгрузку должен оставаться тот же.

**При включенной ФО** Направление на разгрузку формируется, когда:

### Пункт 1: ЛА Приемка на ТС — регистрация НЕ заблокировалась

**Условие:** При проведении ЛА приемка на ТС, если регистрация не заблокировалась по правилу Первого ТС или Группы ТС — автоматом создаём НнР.

**Flow:**
```
гкс_ЛабораторныйАнализ.ОбработкаПроведения()
│
├─ ЗаполнитьРегистрЗаблокированныеРегистрацииПЛК(Отказ)          // стр. 150
│   └─ Записывает блокировку в гкс_ЗаблокированныеРегистрацииУсиленныйКонтроль
│      (если правило УК подобралось)
│
├─ СформироватьВспомогательныеДанныеДляЗаблокированныхТС(Отказ)   // стр. 153
│   └─ Пропускается (ЭтоЛабАнализДляЗаблокированныхТС = Ложь,
│      т.к. это обычная приемка, не первое ТС)
│
└─ ОбновитьНаправлениеНаРазгрузку(Отказ) = Истина                 // стр. 155
   └─ СформироватьНаправлениеНаРазгрузкуПриНеобходимости()        // стр. 630
      ├─ НазначатьНаСкладыПоПараметрам() → ОК
      ├─ НаправлятьНаРазгрузкуРазрешение() → ОК
      ├─ РегистрацияЗаблокированаДляРазгрузки() → Ложь            // стр. 637
      │   (нет записи в гкс_ЗаблокированныеРегистрацииУсиленныйКонтроль)
      └─ гкс_ПриемкаТранспорта.СформироватьНаправлениеНаРазгрузку() // стр. 652
         ├─ ПолучитьПоРегистрации() → пусто (НнР нет)
         ├─ Определяет СлужебнуюНоменклатуру, ЯмаСилос
         └─ Создаёт документ НаправлениеНаРазгрузку
```

#### Цепочка 1.1 — Первое ТС (не заблокировано само, является блокирующим для последующих)

Первое ТС не блокируется само — оно создаёт правило УК и блокирует последующие.
НнР для первого ТС создаётся штатно через `ОбновитьНаправлениеНаРазгрузку`.

| 2 | ФормированиеНомераПробы | УТ-00000017 | 11.03.2026 9:25:22 | Единичная, проба 202611030001 |

### Пункт 2: ЛА промежуточного композита / ЛА приемка первого ТС (по УК) — качество принято для заблокированных

**Условие:** При проведении ЛА промежуточного композита на группу или ЛА приемка первого ТС (по УК), если качество принято по УК для всех заблокированных ТС у которых итоговое качество принято — формируем НнР (если ещё не создано).

**Flow:**
```
гкс_ЛабораторныйАнализ.ОбработкаПроведения()
│
├─ ЗаполнитьРегистрЗаблокированныеРегистрацииПЛК(Отказ)          // стр. 150
│
├─ СформироватьВспомогательныеДанныеДляЗаблокированныхТС(Отказ)   // стр. 153
│   ├─ ТребуетсяЗаблокированныеТСЛабАнализа() → Истина            // стр. 685
│   │   (ФО включена + Статус=Выполнен + ЭтоПриемкаПромежуточныйКомпозит)
│   ├─ ЭтоЛабАнализДляЗаблокированныхТС() → Истина               // стр. 737
│   │   (ЭтоПриемка + ЭтоПерваяРегистрацияТС ИЛИ ЭтоПромежуточныйКомпозит + ЭтоФНП)
│   │
│   ├─ гкс_ВходнойКонтрольКачества.ЗаписатьСостоянияРегистрацииЗаблокированныхТС()
│   │   // стр. 667 — пакетный запрос:
│   │   ├─ ЗаблокированныеТС — находит все заблокированные ТС
│   │   │   (по БлокирующаяРегистрация или БлокирующаяГруппаТС)
│   │   ├─ ПоказателиЗаблокированныхТС — фактические показатели качества
│   │   ├─ КачествоПоЗаблокированнымТС — агрегация: МИНИМУМ(СоответствуетНормативу)
│   │   ├─ СостоянияРегистрацииПоЗаблокированнымТС — определяет новое состояние:
│   │   │   ОтклонятьКачество → КачествоНеПринято
│   │   │   НеСоответствуетНормативу → РезультатыПробПолучены
│   │   │   Иначе → КачествоПринято
│   │   ├─ СостоянияРегистрацииИтог → записывает состояния в РС
│   │   └─ ЗаблокированныеТСКачествоПринято → выбирает ТС с:
│   │       СостояниеРегистрации = КачествоПринято
│   │       И НаправлениеНаРазгрузку.Ссылка ЕСТЬ NULL (нет НнР)
│   │   Возвращает: ДанныеДляРазгрузкиРазблокированныхТС
│   │   (ДокументРегистрации, ЛабораторныйАнализ, Дата)
│   │
│   ├─ СформироватьНаправленияНаРазгрузкуДляРазблокированныхТС()   // стр. 725
│   │   └─ Цикл по ДанныеДляРазгрузкиРазблокированныхТС:
│   │      └─ СформироватьНаправлениеНаРазгрузкуПриНеобходимости() // стр. 630
│   │         ├─ РегистрацияЗаблокированаДляРазгрузки() → Истина
│   │         │   (запись Разблокировано=Ложь ещё в регистре!)
│   │         └─ 🐛 Возврат — НнР НЕ создаётся ← ЗДЕСЬ БАГ
│   │
│   └─ ЗаполнитьЗаблокированныеРегистрацииУсиленныйКонтроль()    // стр. 720
│       └─ 🐛 Записывает Разблокировано=Истина (но уже ПОЗДНО)
│
└─ ОбновитьНаправлениеНаРазгрузку(Отказ)                          // стр. 155
   └─ СформироватьНаправлениеНаРазгрузкуПриНеобходимости()
      └─ РегистрацияЗаблокированаДляРазгрузки() → зависит от текущего ТС
         (для текущего ТС — первого/композита — может быть не заблокирован)
```

🐛 **Проблема:** `СформироватьНаправленияНаРазгрузкуДляРазблокированныхТС` вызывает `СформироватьНаправлениеНаРазгрузкуПриНеобходимости`, которая проверяет `РегистрацияЗаблокированаДляРазгрузки()`. Но разблокировка в регистре (`Разблокировано=Истина`) записывается **позже** в `ЗаполнитьЗаблокированныеРегистрацииУсиленныйКонтроль` (стр. 720).

### Пункт 3: ЛА единичный / промежуточный композит по УК — регистрация разблокирована

**Условие:** При проведении ЛА единичный / промежуточный композит по УК, если регистрация разблокирована и итоговое качество принято — формируем НнР.

**Flow:**
```
гкс_ЛабораторныйАнализ.ОбработкаПроведения()
│
├─ ЗаполнитьРегистрЗаблокированныеРегистрацииПЛК(Отказ)          // стр. 150
│
├─ СформироватьВспомогательныеДанныеДляЗаблокированныхТС(Отказ)   // стр. 153
│   └─ ТребуетсяЗаблокированныеТСЛабАнализа() → зависит от типа ЛА
│      Если единичный ЛА по УК — может не попасть в ЭтоПриемкаПромежуточныйКомпозит
│
└─ ОбновитьНаправлениеНаРазгрузку(Отказ) = Истина                 // стр. 155
   └─ СформироватьНаправлениеНаРазгрузкуПриНеобходимости()        // стр. 630
      ├─ НаправлятьНаРазгрузкуРазрешение() → ОК
      ├─ РегистрацияЗаблокированаДляРазгрузки() → ?
      │   ├─ Если Разблокировано=Истина в регистре → Ложь → идём дальше
      │   └─ Если Разблокировано=Ложь → Истина → ⛔ Возврат, НнР НЕ создаётся
      │
      └─ (если прошла проверку)
         гкс_ПриемкаТранспорта.СформироватьНаправлениеНаРазгрузку() // стр. 652
         └─ Создаёт документ НаправлениеНаРазгрузку
```

**Ключевое:** для пункта 3 необходимо, чтобы регистрация была **заранее** разблокирована (из предыдущего проведения ЛА по группе/первому ТС). Если разблокировка произошла ранее — `РегистрацияЗаблокированаДляРазгрузки() = Ложь` — НнР создаётся корректно.
