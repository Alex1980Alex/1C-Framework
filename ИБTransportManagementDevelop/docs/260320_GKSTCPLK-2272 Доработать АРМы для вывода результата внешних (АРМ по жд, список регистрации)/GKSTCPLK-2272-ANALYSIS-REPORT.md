# GKSTCPLK-2272 Доработать АРМы для вывода результата внешних (АРМ по жд, список регистрации)

## 1. Описание задачи

### 1.1 Требования

1. **Создать ресурс ЭтоЗначениеВнешнейПробы** в регистре сведений гкс_ФактическиеПоказателиКачества
2. **Заполнять ресурс при проведении** документа гкс_ЛабораторныйАнализ из реквизита табличной части ЭтоЗначениеВнешнейПробы
3. **Изменить АРМ гкс_ПриемкаТранспорта** — заполнять КачественныеПоказатели из единого регистра гкс_ФактическиеПоказателиКачества (вместо табличной части документа)

### 1.2 Суть проблемы

В табличной части КачественныеПоказатели документа гкс_ЛабораторныйАнализ есть реквизит **ЭтоЗначениеВнешнейПробы**, который не попадает в регистр гкс_ФактическиеПоказателиКачества при проведении. АРМ гкс_ПриемкаТранспорта читает данные напрямую из табличной части документа, а не из единого регистра. Нужно унифицировать источник данных.

## 7. Тест-план

### 7.1 Проверка проведения

1. Создать документ гкс_ЛабораторныйАнализ с заполненным ЭтоЗначениеВнешнейПробы = Истина

1. Открыть АРМ гкс_ПриемкаТранспорта

3. Проверить отображение качественных показателей
4. Проверить признак внешней пробы в детальной информации
