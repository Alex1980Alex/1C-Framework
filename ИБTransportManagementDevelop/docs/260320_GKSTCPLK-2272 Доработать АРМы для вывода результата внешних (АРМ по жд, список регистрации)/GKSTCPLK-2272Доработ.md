GKSTCPLK-2272 Доработать АРМы для вывода результата внешних (АРМ по жд, список регистрации)

Описание задания

В документе Лабараторный анализ в табличной части вынесен реквизит Внешняя проба

1. Создать ресурс ЭтоЗначениеВнешнейПробы в РС гкс_ФактическиеПоказателиКачества. Из документа гкс_ЛабораторныйАнализ при проведении заполнять данные из реквизита табличной части ЭтоЗначениеВнешнейПробы в ресурс ЭтоЗначениеВнешнейПробы  РС гкс_ФактическиеПоказателиКачества

2. В АРМ гкс_ПриемкаТранспорта , заполнять КачественныеПоказатели из на РегистрСведений.гкс_ФактическиеПоказателиКачества так как для удобства мы теперь данные можем брать из единого регистра (входной контроль, промежуточный композит)

---

## Комментарий к коммиту (GKSTCPLK-2272)

feat(качество): вывод результата внешних проб в АРМ приёмки

### Как было

- АРМ гкс_ПриемкаТранспорта получал качественные показатели напрямую из ТЧ КачественныеПоказатели документа гкс_ЛабораторныйАнализ
- В РС гкс_ФактическиеПоказателиКачества не было признака внешней пробы — нельзя было отличить внешнюю пробу от обычной
- В форме АРМ не было колонки для отображения признака внешней пробы

### Как стало

1. **РС гкс_ФактическиеПоказателиКачества** — добавлен ресурс `ЭтоЗначениеВнешнейПробы` (Булево)

2. **Документ гкс_ЛабораторныйАнализ, МодульМенеджера** — в запрос `ТекстЗапросаТаблицаФактическиеПоказателиКачества()` добавлено поле `ЭтоЗначениеВнешнейПробы` из ТЧ. При проведении значение автоматически попадает в регистр через механизм `Движения[Регистр].Загрузить()`

3. **Обработка гкс_ПриемкаТранспорта, МодульОбъекта** — запрос `ТекстЗапросаДанныеДляДетальныхЗаписей()` переписан: качественные показатели теперь берутся из РС гкс_ФактическиеПоказателиКачества (единый источник для входного контроля и промежуточного композита). Поля `ОтклонениеОтБазиса` и `Примечание` получаются через ЛЕВОЕ СОЕДИНЕНИЕ с ТЧ документа. В условие соединения добавлен `ЭтоЗначениеВнешнейПробы` для исключения дублей при совпадении показателей. Фильтр по конкретному документу-регистратору через `Регистратор = &СсылкаАнализов`

4. **Форма ОсновнаяФорма обработки гкс_ПриемкаТранспорта** — в реквизит `КачественныеПоказатели` добавлена колонка `ЭтоЗначениеВнешнейПробы` (Булево), на форму добавлен элемент ФлажокПоля «Внешняя проба»
