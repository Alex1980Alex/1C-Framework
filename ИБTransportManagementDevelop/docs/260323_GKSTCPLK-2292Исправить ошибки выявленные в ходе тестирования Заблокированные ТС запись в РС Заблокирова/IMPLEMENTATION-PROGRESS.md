### TM-2: Исправление дедупликации в `ДобавитьЗаблокированноеВГруппыРегистрации` (CommonModule)

**Файл:** `CommonModules/гкс_ВходнойКонтрольКачества/Module.bsl`  
**Строки:** ~1751-1773

Два подбага:
1. При создании нового массива — первый элемент добавлялся дважды (один раз в `Если`, ещё раз в цикле)
2. Условие в цикле было `<>` (добавлять при несовпадении) вместо `=` (выйти при совпадении — защита от дублей)

```bsl
// СТАЛО — создаём пустой массив, ранний выход при дубликате, добавляем один раз после цикла:
Если БлокируюшааяГруппы = Неопределено Тогда
    БлокируюшааяГруппы = Новый Массив;
    Результат.ГруппыПоРегистрациям.Вставить(Регистрация, БлокируюшааяГруппы);
КонецЕсли;
Для Каждого БлокируюшаяГруппы Из БлокируюшааяГруппы Цикл
    Если БлокируюшаяГруппы["БлокирующаяГруппаТС"] = БлокирующаяГруппаТС
        И БлокируюшаяГруппы["ЗаблокированноеТС"] = ЗаблокированноеТС Тогда
        Возврат;
    КонецЕсли;
КонецЦикла;
БлокируюшааяГруппы.Добавить(ЗаполнитьЗаблокированное(...));
```
