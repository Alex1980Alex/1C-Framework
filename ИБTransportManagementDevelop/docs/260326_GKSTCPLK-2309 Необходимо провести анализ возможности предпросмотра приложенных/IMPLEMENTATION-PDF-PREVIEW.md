# GKSTCPLK-2309: Реализация предпросмотра PDF в формах присоединённых файлов

## 1. Суть доработки

В формы присоединённых файлов добавлен встроенный предпросмотр PDF-документов с использованием нативного элемента платформы `ПолеPDFДокумента` (доступен с версии 8.3.21+). Ранее при выборе PDF-файла отображалось сообщение "Предпросмотр файлов этого типа не поддерживается."

## 2. Модифицированные объекты

| Объект | Модуль | Тип изменений |
|--------|--------|---------------|
| `Обработка.ИнтеграцияС1СДокументооборот.Форма.ПрисоединенныеФайлы` | Модуль формы | Модификация процедуры `ОбновитьПредпросмотр`, добавление элемента `ПолеПредпросмотраPDF` на форму |
| `Обработка.РаботаСФайлами.Форма.ПрисоединенныеФайлы` | Модуль формы | Модификация процедур `ОбновитьПредпросмотр`, `УстановитьВидимостьПредпросмотра`, добавление серверной процедуры `ЗагрузитьPDFПредпросмотрНаСервере`, добавление элемента `ПолеПредпросмотраPDF` на форму |

## 3. Описание изменений по объектам

### 3.1 Обработка.ИнтеграцияС1СДокументооборот.Форма.ПрисоединенныеФайлы

Форма предпросмотра файлов, получаемых из 1С:Документооборота через web-сервис DMService.

**Изменения в Form.xml:**
- Добавлен элемент формы `ПолеПредпросмотраPDF` типа `ПолеPDFДокумента`
- Элемент размещён в той же группе, что и `КартинкаПредпросмотра`
- По умолчанию `Видимость = Ложь` — становится видимым только при выборе PDF-файла

**Изменения в Module.bsl — процедура `ОбновитьПредпросмотр()` (строки 1048–1108):**

Добавлена ветка обработки PDF перед штатной логикой предпросмотра изображений:

```bsl
// GKSTCPLK-2309 Начало — предпросмотр PDF через ПолеPDFДокумента
Если НРег(ТекущиеДанные.Расширение) = "pdf" Тогда

    // 1. Получаем двоичные данные файла из ДО (если ещё не получены)
    Если Не ЗначениеЗаполнено(ТекущиеДанные.АдресДанныхФайла) Тогда
        ТекущиеДанные.АдресДанныхФайла =
            ИнтеграцияС1СДокументооборотВызовСервера.ПолучитьФайлИПоместитьВХранилище(
                ТекущиеДанные.ID, УникальныйИдентификатор);
    КонецЕсли;

    // 2. Загружаем PDF во временный файл и читаем в ДокументPDF
    Если ЗначениеЗаполнено(ТекущиеДанные.АдресДанныхФайла) Тогда
        ДвоичныеДанные = ПолучитьИзВременногоХранилища(ТекущиеДанные.АдресДанныхФайла);
        ИмяВременногоФайла = ПолучитьИмяВременногоФайла("pdf");
        ДвоичныеДанные.Записать(ИмяВременногоФайла);

        ДокументPDFПредпросмотр = Новый ДокументPDF;
        ДокументPDFПредпросмотр.Прочитать(ИмяВременногоФайла);

        Попытка
            УдалитьФайлы(ИмяВременногоФайла);
        Исключение
        КонецПопытки;
    КонецЕсли;

    // 3. Переключаем видимость: скрываем картинку, показываем PDF-поле
    АдресДанныхФайла = "";
    Элементы.КартинкаПредпросмотра.Видимость = Ложь;
    Элементы.ПолеПредпросмотраPDF.Видимость = Истина;
    Возврат;
КонецЕсли;
// GKSTCPLK-2309 Конец
```

**Логика переключения видимости:**
- При выборе PDF: `КартинкаПредпросмотра` скрывается, `ПолеПредпросмотраPDF` показывается
- При выборе изображения (jpg, png и т.д.): `КартинкаПредпросмотра` показывается, `ПолеПредпросмотраPDF` скрывается
- При отключении предпросмотра или пустом выборе: `КартинкаПредпросмотра` видима (пустая), `ПолеПредпросмотраPDF` скрыто

### 3.2 Обработка.РаботаСФайлами.Форма.ПрисоединенныеФайлы

Стандартная форма БСП для просмотра присоединённых файлов (работает с файлами из локального хранилища, без ДО).

**Изменения в Form.xml:**
- Добавлен элемент формы `ПолеПредпросмотраPDF` типа `ПолеPDFДокумента`
- Добавлен реквизит формы `ДокументPDFПредпросмотр` типа `ДокументPDF`

**Изменения в Module.bsl:**

1. **Процедура `УстановитьВидимостьПредпросмотра()` (строки 1772–1780):**
   При переключении предпросмотра PDF-поле всегда скрывается — оно станет видимым только когда пользователь выберет PDF-файл.

2. **Процедура `ОбновитьПредпросмотр()` (строки 1782–1834):**
   Аналогичная ветка для PDF, но с отличиями:
   - Процедура клиентская (`&НаКлиенте`), а не серверная
   - Данные файла получаются через `РаботаСФайламиСлужебныйВызовСервера.ДанныеФайлаДляОткрытия()`
   - Загрузка PDF вынесена в отдельную серверную процедуру `ЗагрузитьPDFПредпросмотрНаСервере()`

3. **Новая процедура `ЗагрузитьPDFПредпросмотрНаСервере()` (строки 1836–1856):**
   ```bsl
   &НаСервере
   Процедура ЗагрузитьPDFПредпросмотрНаСервере(АдресДвоичныхДанных)
       // 1. Получаем двоичные данные из временного хранилища
       // 2. Записываем во временный файл .pdf
       // 3. Читаем в реквизит формы ДокументPDFПредпросмотр
       // 4. Удаляем временный файл
   КонецПроцедуры
   ```

## 4. Ключевые технические решения

### 4.1 Использование ДокументPDF (нативный элемент платформы)

Начиная с версии 8.3.21, платформа 1С:Предприятие поддерживает элемент управления `ПолеPDFДокумента`, который отображает PDF-файлы непосредственно на форме без внешних библиотек.

**Цепочка работы:**
1. Двоичные данные PDF → временный файл на сервере
2. `Новый ДокументPDF` → `.Прочитать(путь)` загружает файл
3. Реквизит формы типа `ДокументPDF` связан с элементом `ПолеПредпросмотраPDF`
4. Временный файл удаляется после загрузки

### 4.2 Взаимоисключающая видимость

На форме одновременно присутствуют два элемента предпросмотра:
- `КартинкаПредпросмотра` (`ПолеКартинки`) — для изображений (bmp, jpg, png и др.)
- `ПолеПредпросмотраPDF` (`ПолеPDFДокумента`) — для PDF

В каждый момент времени виден только один из них. Переключение происходит по расширению файла.

### 4.3 Различия между двумя формами

| Аспект | ИнтеграцияС1СДокументооборот | РаботаСФайлами |
|--------|------------------------------|----------------|
| Источник файлов | Web-сервис DMService (1С:Документооборот) | Локальное хранилище БСП |
| Контекст процедуры `ОбновитьПредпросмотр` | `&НаСервере` | `&НаКлиенте` |
| Загрузка PDF | Прямо в теле процедуры | Через отдельную серверную процедуру `ЗагрузитьPDFПредпросмотрНаСервере()` |
| Получение данных файла | `ИнтеграцияС1СДокументооборотВызовСервера.ПолучитьФайлИПоместитьВХранилище()` | `РаботаСФайламиСлужебныйВызовСервера.ДанныеФайлаДляОткрытия()` |

## Итого

Добавили на формы `ПрисоединенныеФайлы` двух обработок (`ИнтеграцияС1СДокументооборот` и `РаботаСФайлами`) элемент `ПолеPDFДокумента`. В процедуре `ОбновитьПредпросмотр` перед штатной веткой изображений вставили проверку расширения `"pdf"`. Если PDF — получаем двоичные данные файла, пишем во временный файл, читаем через `Новый ДокументPDF` → `.Прочитать()`, удаляем временный файл, переключаем видимость: `КартинкаПредпросмотра` скрыта, `ПолеПредпросмотраPDF` видимо. Для не-PDF — обратно. Конвертация не нужна, Ghostscript не нужен, всё нативно через платформу 8.3.21+. Доработка затронула только модули форм, метаданные конфигурации (справочники, регистры, документы) не изменены.
