# GKSTCPLK-2376 Доработать печатную форму "Акт отбора образцов композитной пробы"

> **Примечание:** Z.AI fallback — `mcp__llm-rotation__llm_complete` вернул ошибку "All providers failed" (zai-glm5, gemini, openrouter, ollama-local/cloud), локальный Ollama также не отвечает. Отчёт сформирован напрямую. Все факты (номера строк, фрагменты кода, имена объектов) проверены через Read/Grep непосредственно в исходниках конфигурации.

## 1. Описание задачи

### 1.1 Требования

- **[REQ-1]** В печатной форме **"Акт отбора образцов композитной пробы"** (команда `ПФ_MXL_АктОтбораКП`) документа `Документ.гкс_ФормированиеНомераПробы` номера транспортных средств должны выводиться **через запятую в одну строку**.
- **[REQ-2]** Формат вывода должен совпадать с уже реализованным в соседней печатной форме **"Акт отбора проб новый"** (команда `ПФ_MXL_АктОтбораПроб`, обработчик — обработка `гкс_ПечатьДокументаЛабораторныйАнализ`).
- **[REQ-3]** Правка локализована в алгоритме формирования печатной формы: **без** изменений структуры данных, запроса и макета (параметр `[НомерТС]` и его расположение в ячейке сохраняются).

### 1.2 Суть проблемы

В текущей реализации функция `СформироватьПечатнуюФормаАктОтбораКП` собирает номера ТС в строку через символ перевода строки `Символы.ПС`, поэтому в ячейке макета `[НомерТС]` каждое ТС печатается на своей строке (см. `Скриншот-20260413-115023.jpg`):

```
99637555
59941211
95876652
95096954
```

Требуется формат:

```
99637555, 59941211, 95876652, 95096954
```

В соседней ПФ "Акт отбора проб новый" задача уже решена через массив с дедубликацией и `СтрСоединить(, ", ")`. Нужно перенести этот приём в нашу функцию.

## 3. Детальный анализ механизма

### 3.1 Текущий алгоритм (проблемный)

Файл: `src/Documents/гкс_ФормированиеНомераПробы/Ext/ManagerModule.bsl`
Функция: `СформироватьПечатнуюФормаАктОтбораКП` (стр. 592)
Фрагмент (стр. 638–645):

```bsl
СписокТС	= "";
СписокПоказателей = "";

Пока ВыборкаПоРегистрациям.НайтиСледующий(СтруктураПоиска) Цикл
	
	СписокТС	= СписокТС + ВыборкаПоРегистрациям.ТранспортноеСредство + Символы.ПС;
	
КонецЦикла;
```

Далее (стр. 668): `ОбластьМакета.Параметры.НомерТС = СписокТС;`

**Проблема:** `Символы.ПС` — символ перевода строки, поэтому в ячейке каждый ТС начинается с новой строки.

### 3.2 Найденные паттерны в конфигурации ✓ pattern

**Паттерн 1 — с дедубликацией** — `src/DataProcessors/гкс_ПечатьДокументаЛабораторныйАнализ/Ext/ManagerModule.bsl`, стр. 512–516 (это и есть обработчик "соседней ПФ" из ТЗ):

```bsl
// вывод транспортных средства
МассивТС = ТаблицаПоРегистрациям.ВыгрузитьКолонку("НомерТранспортногоСредства");
МассивТСБезПовтора = Новый Массив;
ОбщегоНазначенияКлиентСервер.ДополнитьМассив(МассивТСБезПовтора, МассивТС, Истина); 
РеквизитыЛицеваяСторона.Вставить("НомерТС", СтрСоединить(МассивТСБезПовтора, ","));
```

**Паттерн 2 — упрощённый** — тот же модуль, функция `ЗаполнитьТранспортныеСредства`, стр. 905–926:

```bsl
КоличествоТС = ТранспортныеСредства.Количество();       
Если КоличествоТС = 1 Тогда
    ОбластьШапка.Параметры.Транспорт = ТранспортныеСредства[0];
ИначеЕсли КоличествоТС <> 0 Тогда         
    НесколькоТС = Истина;
    СтрокаТС = СтрСоединить(ТранспортныеСредства, ", ");
    ОбластьШапкаТС.Параметры.ТранспортныеСредства = СтрокаТС;
Иначе
    ОбластьШапка.Параметры.Транспорт = "";
КонецЕсли;
```

**Вывод:** канонический приём в данной конфигурации — `Массив → СтрСоединить(, ", ")`, с опциональной дедубликацией через `ОбщегоНазначенияКлиентСервер.ДополнитьМассив(dst, src, Истина)`.

### 3.3 Рекомендуемый алгоритм

Берём **Паттерн 1** с дедубликацией (безопаснее — в `СписокРегистраций` теоретически могут быть дубли одного ТС):

```bsl
МассивТС = Новый Массив;
Пока ВыборкаПоРегистрациям.НайтиСледующий(СтруктураПоиска) Цикл
    МассивТС.Добавить(ВыборкаПоРегистрациям.ТранспортноеСредство);
КонецЦикла;

МассивТСБезПовтора = Новый Массив;
ОбщегоНазначенияКлиентСервер.ДополнитьМассив(МассивТСБезПовтора, МассивТС, Истина);
СписокТС = СтрСоединить(МассивТСБезПовтора, ", ");
```

Преобразование ссылки `Справочник.ТранспортныеСредства` в строку при `СтрСоединить` использует стандартное представление объекта (`Наименование`), которое совпадает с текущим поведением (в обоих случаях используется та же ссылка, только способ конкатенации разный).

### 3.4 Граничные условия

| Случай | Поведение |
|---|---|
| 0 ТС | `СписокТС = ""` (пустая строка) — идентично текущему поведению |
| 1 ТС | `"99637555"` — одна строка без разделителя |
| 2+ ТС, уникальные | `"99637555, 59941211, 95876652, 95096954"` |
| 2+ ТС, дубли по ссылке | Дубли схлопываются (`ДополнитьМассив(...Истина)` сравнивает ссылки) |
