## Открытые вопросы / риски

1. **Синтаксис-проверка через Designer/EDT** не запускалась в рамках этой сессии — у пользователя сейчас Designer/EDT не прикреплён к MCP серверу, либо запуск нежелателен. Ручной запуск `Конфигуратор → Конфигурация → Проверить модули` перед тестированием обязателен.
