GKSTCPLK-2399  Разработать механизм приемки авто с другим порядком операции для ООО Инфида
Описание
Как сейчас:по процессу приемки авто существует следующий алгоритм в программе:
1. Регистрация транспорта
2. Взвешивание
3. Лабораторный анализ
4. Распределение сырья по силосам
5. взвешивание тары

Необходимо:
1. Регистрация транспорта
2. Лабораторный анализ
3. Взвешивание
4. Распределение сырья по силосам
5.  взвешивание тары

Аналогичный механизм включается в общих настройках функциональной опцией для ЖД:

Необходимо: Разработать функциональную опцию "Разрешить входной контроль до взвешивания авто транспорт", добавить в "Основные настройки" , реализовать вышеуказанный механизм по данной функциональной опции.
