# GKSTCPLK-2400 Разработать печатную форму "Ярлык пробы"

## 1. Описание задачи

### 1.1 Требования

- **[REQ-1]** Создать печатную форму "Ярлык пробы" на основании документа `Документ.гкс_ЛабораторныйАнализ`
- **[REQ-2]** Поля ярлыка:
  - Организация (из ЛабАнализ.Организация) [REQ-2.1]
  - Дата отбора (дата ЛабАнализа) [REQ-2.2]
  - Накладная № (номер ТН из РегистрацияНаПЛК) [REQ-2.3]
  - Образец номер (НомерПробы из ЛабАнализа) [REQ-2.4]
  - Сырье (Номенклатура + ГодУрожая) [REQ-2.5]
  - Поставщик (из РегистрацияНаПЛК) [REQ-2.6]
  - № тр. средства (из РегистрацияНаПЛК) [REQ-2.7]
  - Комментарий [REQ-2.8]
  - Масса партии (груза) [REQ-2.9]
  - Подпись лица, отобравшего пробу [REQ-2.10]
- **[REQ-3]** Настройки ПФ по аналогии с "Акт отбора проб" — возможность выбора фамилии лаборанта
- **[REQ-4]** Печать из обработки "Приемка/отгрузка" (`Обработка.гкс_ПриемкаТранспорта`)

### 1.2 Суть задачи

Добавить новую печатную форму "Ярлык пробы" в существующую обработку `гкс_ПечатьДокументаЛабораторныйАнализ`, которая уже содержит 6 печатных форм (Акт отбора проб, Акт забраковки партии/товара, ЗПП-47, ЗПП-47 АЛЦ, ЗПП-42). Форма представляет собой компактный ярлык для маркировки отобранной пробы с основными идентификационными данными.
