## Бизнес-логика причин блокировки

### Контекст

На ПЛК действует механизм усиленного контроля качества. Когда приезжает новое ТС, система проверяет — нужно ли его заблокировать и подождать результатов по другим ТС. Блокировка работает по двум правилам: **Первое ТС** и **Группа ТС**.

### 1. Заблокировано, т.к. ждём результата по входному контролю

Текущее ТС заблокировано по правилу **Первого ТС**. Первое ТС в партии (блокирующая регистрация) уже зарегистрировано, но проба ещё **даже не отобрана** или ФНП ещё не проведён.

**На площадке:** Первое ТС стоит на разгрузке или в очереди, лаборант ещё не отобрал пробу. Все последующие ТС с таким же товаром ждут — разгружать их нельзя, пока не узнаем качество первого.

Ссылки на ЛА нет — его ещё не существует.

### 2. Заблокировано, потому что ждём результат по первому ТС (ссылка на ЛА)

Первое ТС уже **прошло отбор пробы**, ФНП проведён и сопоставлен с Лабораторным Анализом (назначение — Приемка). Но ЛА ещё **не завершён** — лаборатория работает, результата пока нет.

**На площадке:** Проба от первого ТС уже в лаборатории, идёт анализ. Остальные ТС ждут результат. Как только ЛА по первому ТС будет проведён и качество принято — блокировка снимется, и для всех ожидающих ТС автоматически создадутся Направления на разгрузку.

Ссылка на ЛА есть — пользователь может открыть и посмотреть статус.

### 3. Заблокировано, потому что анализ по первому ТС не прошёл (ссылка на ЛА), ждём усиленный контроль

Первое ТС **не прошло** входной контроль — качество по ЛА Приемки не принято. Система перевела ситуацию в режим **усиленного контроля**: теперь для текущего заблокированного ТС нужен отдельный ЛА (единичный анализ или УК), чтобы определить, можно ли его разгрузить.

**На площадке:** Первое ТС оказалось плохого качества. Теперь каждое заблокированное ТС проверяется **индивидуально** — лаборант отбирает пробу конкретно от этого ТС и проводит анализ на усиленный контроль. Пока результат не готов — ТС продолжает ждать.

Ссылка на ЛА есть — это ЛА первого ТС, который не прошёл.

### 4. Заблокировано, потому что ждём результат на промежуточный композит предыдущей группы

Текущее ТС заблокировано по правилу **Группы ТС**. Предыдущая группа ТС (несколько машин, объединённых в группу) ещё не прошла анализ на **промежуточный композит** — усреднённую пробу по всей группе.

**На площадке:** Несколько ТС из предыдущей партии объединены в группу. По этой группе формируется ФНП с назначением "Промежуточный композит" — смесь проб от всех ТС группы. Этот композит ещё не прошёл лабораторию. Текущее ТС ждёт, пока группа не получит результат.

Ссылки на ЛА нет — его ещё не существует.

### 5. Заблокировано, потому что не прошёл анализ на промежуточный композит предыдущей группы (ссылка на ЛА), ждём усиленный контроль

Промежуточный композит предыдущей группы **не прошёл** — качество по группе не принято. Теперь текущее ТС должно пройти индивидуальную проверку на усиленный контроль.

**На площадке:** Усреднённая проба предыдущей группы показала плохое качество. Все ТС, которые были заблокированы по этой группе, теперь проверяются **поштучно** — каждому нужен свой ЛА по усиленному контролю. Пока этот ЛА не готов, ТС ждёт.

Ссылка на ЛА есть — это ЛА промежуточного композита группы, который не прошёл.
