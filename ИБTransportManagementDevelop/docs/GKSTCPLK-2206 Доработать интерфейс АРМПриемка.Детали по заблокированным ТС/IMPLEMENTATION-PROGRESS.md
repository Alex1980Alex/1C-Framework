## Архитектурные решения

1. **Программное создание элементов вместо XML** — проще, не требует редактирования Form.xml, защита через `Элементы.Найти()` от ошибок при отключённой ФО
2. **Отдельная область `#Область ИнформацияОБлокировке`** — изоляция нового кода от существующего
3. **Префикс `Подключаемый_`** — для корректной работы `УстановитьДействие("Нажатие", ...)`
4. **Защита от отсутствия элементов** — все процедуры проверяют `Элементы.Найти("ГруппаИнформацияОБлокировке") <> Неопределено` перед обращением

## Чек-лист тестирования

- [ ] Открыть АРМ Приемки с ФО `гкс_ИспользоватьЗаблокированныеТС` = Истина
- [ ] Выбрать заблокированную регистрацию (причина 2: первое ТС) → красный текст + ссылка на ЛА
- [ ] Выбрать заблокированную регистрацию (причина 3: первое ТС не прошло) → красный текст + ссылка на ЛА
- [ ] Выбрать заблокированную регистрацию (причина 4: группа ТС) → красный текст, без ссылки
- [ ] Кликнуть по ссылке ЛА → открывается форма ЛА
- [ ] Переключиться на незаблокированную регистрацию → группа блокировки скрыта
- [ ] Выключить ФО → элементы не создаются, ошибок нет
- [ ] Режим Отгрузка → секция Анализы скрыта → блокировка тоже не видна
