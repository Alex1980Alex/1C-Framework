## Сообщение коммита:

```
feat: Доработано проведение ЛА по УК — блокировка создания записей для ТС с непройденным входным контролем

Как было:
При проведении ЛА первого ТС или группы — для заблокированных ТС всегда создавались записи
в РС Показатели УК по регистрации (тип Единичная, назначение Промежуточный композит) и ставился
статус "Не требуется" для Композитных. Не учитывалось, прошёл ли заблокированный ТС входной контроль.

Как стало:
В пакетный запрос ПолучитьДанныеБлокировкиДляРегистраций добавил ещё один пакет —
он джойнит заблокированные ТС с их ЛА через гкс_ДокументРегистрации и проверяет
табличную часть КачественныеПоказатели: если есть строка где УсиленныйКонтроль = Ложь
и СоответствуетНормативу = Ложь, значит входной контроль не пройден.
Список таких ТС возвращается в поле ТСНеПрошедшиеВходнойКонтроль.

Дальше в ОбновитьБлокировкуДляТС и ОбновитьБлокировкуГруппаТС перед вызовом
ДобавитьПоказателиУКДляЗаблокированногоТС проверяю — если ТС в этом списке,
то не создаю для него новые записи Единичная/ПромежуточныйКомпозит
и не ставлю "Не требуется" для Композитных. Обновление состояний блокировки (Сценарий А)
работает по-прежнему для всех ТС.

МЕТАДАННЫЕ: GKSTCPLK-2210
```
