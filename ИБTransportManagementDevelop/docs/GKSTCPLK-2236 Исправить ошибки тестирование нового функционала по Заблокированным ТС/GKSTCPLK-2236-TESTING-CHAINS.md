# GKSTCPLK-2236 Цепочки тестирования заблокированных ТС

**Дата:** 2026-03-06
**Источник:** Расшифровка диалога «Настройка алгоритмов усиленного контроля качества при приемке ТС»

---

## Общая схема усиленного контроля

```
Первое ТС (единичная приёмка)
│
├─ Качество ПРИНЯТО → последующие группы проверяем через ПРОМЕЖУТОЧНЫЙ КОМПОЗИТ
│
└─ Качество НЕ ПРИНЯТО → последующие ТС ЗАБЛОКИРОВАНЫ
   └─ Проверяем КАЖДОЕ ТС индивидуально (единичная проба)
   └─ Композитная проба по группе → "Не требуется"

Группа 1 (промежуточный композит)
│
├─ Качество ПРИНЯТО → Группа 2 проверяем через ПРОМЕЖУТОЧНЫЙ КОМПОЗИТ
│
└─ Качество НЕ ПРИНЯТО → Группа 2 композит "Не требуется"
   └─ Каждое ТС из группы 2 проверяем ЕДИНИЧНОЙ пробой
```

**Ключевое правило:** Если усиленный контроль не пройден — проверяем каждое ТС.
Входной контроль уже пройден → остаётся проверить только «промежуточный композит единичная».

---

## Цепочка 1: Первое ТС — качество ПРИНЯТО

### Сценарий
Первое транспортное средство проходит усиленный контроль. Последующие группы проверяются через промежуточный композит (штатный режим).

### Шаги в 1С:Предприятие

| Шаг | Действие | Документ / Объект | Что проверить |
|-----|----------|-------------------|---------------|
| 1 | Создать регистрацию первого ТС | **Документ `гкс_РегистрацияНаПЛК`** | Тип регистрации = Приёмка, единичная |
| 2 | Сформировать номер пробы (приёмка единичная) | **Документ `гкс_ФормированиеНомераПробы`** | Создан ЛА типа «Приёмка единичная» |
| 3 | Провести Лабораторный анализ — **качество принято** | **Документ `гкс_ЛабораторныйАнализ`** | Статус = Выполнен, СостояниеКачества = КачествоПринято |
| 4 | Проверить: первое ТС разблокировано | **РС `гкс_ЗаблокированныеРегистрацииУсиленныйКонтроль`** | Нет записей с Разблокировано = Ложь для этого ТС |
| 5 | Создать НнР для первого ТС | **Документ `гкс_НаправлениеНаРазгрузку`** | Документ создаётся успешно |
| 6 | Зарегистрировать вторую группу ТС (2-3 машины) | **Документ `гкс_РегистрацияНаПЛК`** | Создаются регистрации, правило = группа |
| 7 | Проверить: группе назначен промежуточный композит | **РС `гкс_ПоказателиУсиленногоКонтроляПоРегистрации`** | Есть записи с типом «Промежуточный композит» |
| 8 | Сформировать композитную пробу через АРМ | **Обработка `гкс_АРМПромежуточныйКомпозит`** | Проба создана, тип = Композитная |

## Цепочка 2: Первое ТС — качество НЕ ПРИНЯТО → блокировка последующих

### Сценарий
Первое ТС не прошло усиленный контроль. Все последующие ТС блокируются. НнР не создаётся до разблокировки.

### Шаги в 1С:Предприятие

| Шаг | Действие | Документ / Объект | Что проверить |
|-----|----------|-------------------|---------------|
| 1 | Создать регистрацию первого ТС | **Документ `гкс_РегистрацияНаПЛК`** | Тип = Приёмка единичная |
| 2 | Сформировать номер пробы | **Документ `гкс_ФормированиеНомераПробы`** | ЛА создан |
| 3 | Провести ЛА — **качество НЕ принято** | **Документ `гкс_ЛабораторныйАнализ`** | Статус = Выполнен, СостояниеКачества = КачествоНеПринято |
| 4 | **Проверить: блокировка записана** | **РС `гкс_ЗаблокированныеРегистрацииУсиленныйКонтроль`** | Появились записи: Разблокировано = Ложь, БлокирующаяРегистрация = первое ТС |
| 5 | Зарегистрировать второе ТС (группа 1) | **Документ `гкс_РегистрацияНаПЛК`** | Регистрация создана |
| 6 | **Проверить: второе ТС заблокировано** | **РС `гкс_ЗаблокированныеРегистрацииУсиленныйКонтроль`** | Есть запись с ДокументРегистрации = второе ТС, Разблокировано = Ложь |
| 7 | Попытаться создать НнР для второго ТС | **Документ `гкс_НаправлениеНаРазгрузку`** | **НнР НЕ создаётся** или показывает предупреждение о блокировке |
| 8 | Открыть форму НнР, проверить флаг | Форма `гкс_НаправлениеНаРазгрузку` | Видна кнопка «Принять качество», комментарий обязателен |

## Цепочка 3: Первая группа — промежуточный композит НЕ ПРИНЯТ → вторая группа «Не требуется»

### Сценарий
Первое ТС прошло. Группа 1 собрана, промежуточный композит проведён — качество не принято. Для группы 2 композитная проба ставится «Не требуется», но единичные пробы остаются.

### Шаги в 1С:Предприятие

| Шаг | Действие | Документ / Объект | Что проверить |
|-----|----------|-------------------|---------------|
| 1 | Первое ТС — приёмка, ЛА принят | (см. Цепочку 1, шаги 1-5) | Качество принято |
| 2 | Зарегистрировать группу 1 (2-3 ТС) | **Документ `гкс_РегистрацияНаПЛК`** | Создаются регистрации |
| 3 | Сформировать промежуточный композит группы 1 | **Обработка `гкс_АРМПромежуточныйКомпозит`** | Композитная проба создана |
| 4 | Провести ЛА промежуточного композита — **качество НЕ принято** | **Документ `гкс_ЛабораторныйАнализ`** | СостояниеКачества = КачествоНеПринято |
| 5 | **Проверить: ТС группы 1 заблокированы** | **РС `гкс_ЗаблокированныеРегистрацииУсиленныйКонтроль`** | Записи по каждому ТС группы 1, БлокирующаяГруппаТС заполнена |
| 6 | Зарегистрировать группу 2 (новые ТС) | **Документ `гкс_РегистрацияНаПЛК`** | Регистрации созданы |
| 7 | **Проверить: композит группы 2 = «Не требуется»** | **РС `гкс_ПоказателиУсиленногоКонтроляПоРегистрации`** | По показателям типа «Промежуточный композит» → СостояниеКачества = «Не требуется» |
| 8 | **Проверить: единичные пробы группы 2 НУЖНЫ** | **РС `гкс_ПоказателиУсиленногоКонтроляПоРегистрации`** | По показателям типа «Промежуточный композит единичная» → статус пустой (требуется проверка) |

## Цепочка 4: Разблокировка ТС после принятия качества

### Сценарий
ТС было заблокировано (цепочка 2 или 3). После повторной проверки (единичная проба) качество принято → ТС разблокируется → создаётся НнР.

### Шаги в 1С:Предприятие

| Шаг | Действие | Документ / Объект | Что проверить |
|-----|----------|-------------------|---------------|
| 1 | Начальное состояние: ТС заблокировано | **РС `гкс_ЗаблокированныеРегистрацииУсиленныйКонтроль`** | Разблокировано = Ложь |
| 2 | Сформировать единичную пробу для заблокированного ТС | **Документ `гкс_ФормированиеНомераПробы`** | ЛА создан, тип = Промежуточный композит единичная |
| 3 | Провести ЛА — **качество ПРИНЯТО** | **Документ `гкс_ЛабораторныйАнализ`** | СостояниеКачества = КачествоПринято |
| 4 | **Проверить: ТС разблокировано** | **РС `гкс_ЗаблокированныеРегистрацииУсиленныйКонтроль`** | Разблокировано = Истина |
| 5 | **Проверить: НнР создан автоматически** | **Документ `гкс_НаправлениеНаРазгрузку`** | Документ существует по регистрации |
| 6 | Если НнР не создан автоматически — создать вручную | Форма `гкс_НаправлениеНаРазгрузку` | Кнопка «Принять качество» НЕ видна (качество уже принято) |

## Куда смотреть при отладке

### Регистр `гкс_ЗаблокированныеРегистрацииУсиленныйКонтроль`

Открыть через: Все функции → Регистры сведений → гкс_ЗаблокированныеРегистрацииУсиленныйКонтроль

| Измерение | Что показывает |
|-----------|----------------|
| ДокументРегистрации | Какое ТС заблокировано |
| Показатель | По какому показателю |
| БлокирующаяРегистрация | Какое ТС вызвало блокировку (правило «Первое ТС») |
| БлокирующаяГруппаТС | Какая группа вызвала блокировку (правило «Группа ТС») |

| Ресурс | Что показывает |
|--------|----------------|
| БлокирующееСостояниеКачества | Пусто = ждём результат; КачествоНеПринято = не прошёл |
| Разблокировано | Ложь = заблокировано; Истина = разблокировано |

### Регистр `гкс_ПоказателиУсиленногоКонтроляПоРегистрации`

Смотреть записи с типом показателя «Промежуточный композит» / «Промежуточный композит единичная».
Если СостояниеКачества = «Не требуется» — композитная проба по группе отменена.
