GKSTCPLK-2340 Доработать существующий механизм отправки сообщений на электронные табло

Описание
На электронное табло отправляться сообщения, нужно разработать механизм (или доработать существующий) который фиксирует отправление сообщения по записям в регистре гкс_НастройкаЭлектронногоТабло.

P.S. Отправляются пустые сообщения которые обозначают что машина уже уехала, есть ли смысл их вообще отправлять? Анализировать отправку сообщений
