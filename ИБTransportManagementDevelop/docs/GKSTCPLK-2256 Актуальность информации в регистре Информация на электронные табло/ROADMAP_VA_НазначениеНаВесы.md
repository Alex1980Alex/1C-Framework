# Дорожная карта VA BDD: НазначениеНаВесы

> Вид табло: `гкс_ВидыЭлектронныхТабло.НазначениеНаВесы`
> Путь: **А (событийный)** — триггер `ПриЗаписи` при смене состояния через АРМ
> Записей в TestDB: **64**
> Настройка: ПЛК Светлый (без фильтра номенклатуры)

## Точки модификации

| ТМ | Баг | Что делает | Код |
|----|-----|-----------|-----|
| **ТМ-1** | RC-2 | Фильтр по состояниям: только Прибыл | `гкс_ИнтеграцияСЭлектроннымТаблоСервер.ПолучитьСписокРегистрацийДляТабло()` |
| **ТМ-4** | RC-3, RC-6 | Фильтр по номенклатуре при записи | то же (Пакет 2) |

## Цепочка объектов конфигурации

```
[1] РС.гкс_НастройкаЭлектронногоТабло   <- настройка (ПЛК Светлый / НазначениеНаВесы)
[2] Документ.гкс_РегистрацияНаПЛК        <- создание через UI
[3] РС.гкс_СостоянияРегистрации          <- автодвижение: Прибыл
[4] АРМ гкс_ПриемкаТранспорта            <- кнопка Въезд (РедактироватьВесНаВъезде)
[5] Документ.гкс_Взвешивание             <- подчинённый документ
[6] РС.гкс_СостоянияРегистрации.ПриЗаписи <- триггер -> ОбновитьТабло()
[7] ОбщийМодуль: ТМ-1 фильтр состояний + ТМ-4 фильтр номенклатуры
[8] РС.гкс_ЭлектронныеТабло             <- результат
```
