# Дорожная карта VA BDD: НазначениеНаВыгрузку

> Вид табло: `гкс_ВидыЭлектронныхТабло.НазначениеНаВыгрузку`
> Путь: **А (событийный)** — триггер `ПриЗаписи` при ВыгрузкаРазрешена
> Записей в TestDB: **29** (ПЛК Светлый)
> Настройка: **НЕТ для Светлый** (КАТ -- 4 записи)

## Точки модификации

| ТМ | Баг | Что делает |
|----|-----|----------|
| M-1 | RC-1 | Проверка настроек ДО записи |
| (нет ТМ) | -- | Запись при ВыгрузкаРазрешена |

## Цепочка объектов конфигурации

```
[1] РС.гкс_НастройкаЭлектронногоТабло   <- КАТ / НазначениеНаВыгрузку (4 шт)
[2] Документ.гкс_РегистрацияНаПЛК        <- создание
[3] РС.гкс_СостоянияРегистрации          <- Прибыл
[4] АРМ: Въезд -> ... -> КачествоПринято ->
    **НаРазгрузку (РедактироватьНаправлениеНаРазгрузку) -> ВыгрузкаРазрешена**
[5] Документ.гкс_НаправлениеНаРазгрузку   <- подчиненный документ
[6] ПриЗаписи -> ОбновитьТабло()
[7] ОбщийМодуль: M-1 проверка настройки
[8] РС.гкс_ЭлектронныеТабло             <- ТС на табло
```

## Покрытие через 06_arm_workflow.feature

Отдельный feature НЕ нужен. Покрытие обеспечивается ARM-FULL:

| Шаг ARM | Состояние | SQL CHECK | Строка |
|---------|-----------|-----------|--------|
| 5 (НаРазгрузку) | ВыгрузкаРазрешена | НазначениеНаВыгрузку Кол >= 1 | ~357 |
| 8 (Убыл) | Убыл | ВСЕ табло = 0 | ~430 |

## Ограничение: Светлый vs КАТ

ARM-FULL работает на Светлом. У Светлого **НЕТ настройки** НазначениеНаВыгрузку.
M-1 блокирует запись -> SQL CHECK вернет Кол = 0. Это **корректное поведение M-1**.

Для полного E2E теста нужна площадка КАТ -> `07_kat_dispatch.feature`.
