## Ограничения VA (критично)

| Ограничение | Следствие | Workaround |
|-------------|-----------|------------|
| VA не умеет `assertRowNotExists` для DynamicList | Negative-сценарии (FN-1.3.1, EC-1.3.1) **не могут** доказать исчезновение через UI | **Обязательный SQL-якорь** через `execute_query` после прогона |
| `перехожу к строке` по reference-колонке в DynamicList не работает | Поиск по `ТранспортноеСредство` падает | Использовать строковую колонку `Авто` (НомерТранспортногоСредства = строка) |
| Регламент Пути Б асинхронный | Между шагами нужна Пауза + явный trigger | `trigger-reglament.ps1` + `Пауза 2` |

**Правило:** все negative-assertion-сценарии этого пути **обязаны** заканчиваться SQL-CHECK через MCP. Без SQL-якоря тест статуса фикса RC-5 не доказывает.
