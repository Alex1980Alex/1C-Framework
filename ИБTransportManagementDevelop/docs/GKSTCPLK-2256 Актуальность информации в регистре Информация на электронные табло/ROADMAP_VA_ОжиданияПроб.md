# Дорожная карта VA BDD: ОжиданияПроб

> Вид табло: `гкс_ВидыЭлектронныхТабло.ОжиданияПроб`
> Путь: **А (событийный)** — триггер `ПриЗаписи` при ВзятыПробы/ПринятыПробы
> Записей в TestDB: **5** (ПЛК Светлый)
> Настройка: ПЛК Светлый (без фильтра)

## Точки модификации

| ТМ | Баг | Что делает |
|----|-----|----------|
| M-1 | RC-1 | Проверка настроек ДО записи |
| (нет ТМ) | -- | Запись при ВзятыПробы/ПринятыПробы |

## Цепочка объектов конфигурации

```
[1] РС.гкс_НастройкаЭлектронногоТабло   <- ПЛК Светлый / ОжиданияПроб
[2] Документ.гкс_РегистрацияНаПЛК        <- создание
[3] РС.гкс_СостоянияРегистрации          <- Прибыл
[4] АРМ: Въезд -> ВзвешенБрутто ->
    **НомерПробы (РедактироватьНомерПробы) -> ВзятыПробы**
    **ПринятьПробы (КомандаПробыПриняты) -> ПринятыПробы**
[5] Документ.гкс_ФормированиеНомераПробы  <- custom post button!
[6] ПриЗаписи -> ОбновитьТабло()
[7] ОбщийМодуль: M-1 проверка настройки
[8] РС.гкс_ЭлектронныеТабло             <- ТС на табло ОжиданияПроб
```
