## 3. БАГ #1 ПОДТВЕРЖДЁН: Зависшие записи НазначениеНаВесы

**Запрос**: записи НазначениеНаВесы, у которых текущее состояние != Прибыл

**Результат: 30 записей — ВСЕ записи на табло НазначениеНаВесы имеют состояние, отличное от "Прибыл"**

| Состояние | Кол-во | Примеры ТС |
|-----------|--------|-----------|
| КачествоПринято | 3 | К034ЕМ46RUS (24.11.2025), 196AGM01 (04.03.2026), Х998СУ31ВА858031 (13.03.2026) |
| ГотовКОтборуПроб | 2 | А002ВК36RUS (20.11.2025), Х995КК57RUS (13.03.2026) |
| ПринятыПробы | 1 | Х998СУ31ВА858031 (13.03.2026) |
| КачествоНеПринято | 3 | Х995КК57RUS, Х987ВТ193RUS, Х985ХМ36RUS (13.03.2026) |
| НеПринято | 6 | М827ТС (20.11.2025), Н006АЕ46 (26.03.2025!), Р007РТ58RUS (26.03.2025!), О080УН, О412ТХ, О263ОЕ (12.09.2025) |
| ВзвешенТара | 5 | К034РУ48RUS, Е500ТР48RUS (25.11.2025), Е047ВК136RUS (26.11.2025), А081ОМ01RUS, А088ЕА62RUS (27.11.2025) |
| ВыгрузкаРазрешена | 5 | А255ОС761, А117СО62RUS (20.11.2025), А088ЕА62RUS, А081ОМ01RUS (26.11.2025) |
| Выгружен | 2 | В008АН136RUS (10.03.2026) — 2 записи |
| Убыл | 3 | ТЕСТОВЫЙАВТОМОБИЛЬ1 (11.11.2025, 17.09.2025), О909РУ (14.05.2025) |

### Критичные находки:
- **Н006АЕ46** и **Р007РТ58RUS** висят с **26 марта 2025** — почти год!
- **О909РУ** висит с **14 мая 2025** со статусом "Убыл" — ТС давно уехало
- Ни одной записи со статусом "Прибыл" — это означает, что ВСЕ записи на табло "НазначениеНаВесы" являются мусором

### Корневая причина:
Запрос `ПолучитьСписокРегистрацийДляТабло` (строки 278-305 `гкс_ИнтеграцияСЭлектроннымТаблоСервер`) НЕ содержит `ГДЕ Состояние В(&СписокСостояний)` для ветки НазначениеНаВесы.

## 5. БАГ #2 (косвенно): НеПрошедшиеРегистрацию — дубли и отсутствие фильтра

**Наблюдения**:
- Авто `С111СС39` встречается **6 раз** подряд с одинаковой номенклатурой "Рапс (Россия)" — явные дубликаты из электронной очереди
- Все записи НеПрошедшиеРегистрацию имеют `ДокументРегистрации = null` — это записи электронной очереди (Путь Б)
- Номенклатура заполнена ("Рапс (Россия)"), но фильтр по ней в запросе отображения отсутствует

### Корневая причина:
1. Запрос отображения НеПрошедшиеРегистрацию не фильтрует по `Номенклатура` (Точка модификации 2)
2. Запрос электронной очереди не проверяет факт прохождения регистрации (Точка модификации 3)

## 7. SQL-запросы использованные для baseline

### Запрос 1: Настройки табло
```sql
ВЫБРАТЬ ПЕРВЫЕ 10
    НастройкаТабло.ТочкаМаршрута.Наименование КАК ТочкаМаршрута,
    НастройкаТабло.ВидТабло,
    НастройкаТабло.Номенклатура.Наименование КАК Номенклатура
ИЗ
    РегистрСведений.гкс_НастройкаЭлектронногоТабло КАК НастройкаТабло
```

### Запрос 2: Содержимое регистра табло
```sql
ВЫБРАТЬ
    Табло.ТочкаМаршрута.Наименование КАК ТочкаМаршрута,
    Табло.ВидТабло,
    Табло.Авто,
    Табло.Номенклатура.Наименование КАК Номенклатура,
    Табло.ВидЗерна,
    Табло.ДокументРегистрации
ИЗ
    РегистрСведений.гкс_ЭлектронныеТабло КАК Табло
```

### Запрос 3: Зависшие записи НазначениеНаВесы (Состояние != Прибыл)
```sql
ВЫБРАТЬ
    Табло.Авто,
    Табло.ДокументРегистрации,
    Табло.ВидТабло,
    Состояния.Состояние
ИЗ
    РегистрСведений.гкс_ЭлектронныеТабло КАК Табло
        ЛЕВОЕ СОЕДИНЕНИЕ РегистрСведений.гкс_СостоянияРегистрации.СрезПоследних КАК Состояния
        ПО Табло.ДокументРегистрации = Состояния.ДокументРегистрации
ГДЕ
    Табло.ВидТабло = ЗНАЧЕНИЕ(Перечисление.гкс_ВидыЭлектронныхТабло.НазначениеНаВесы)
    И Состояния.Состояние <> ЗНАЧЕНИЕ(Перечисление.гкс_СостоянияРегистрации.Прибыл)
```

### Запрос 4: Дубликаты (одно ТС, разные номенклатуры)
```sql
ВЫБРАТЬ
    Табло.Авто,
    Табло.ДокументРегистрации,
    Табло.ВидТабло,
    КОЛИЧЕСТВО(РАЗЛИЧНЫЕ Табло.Номенклатура) КАК КолНоменклатур
ИЗ
    РегистрСведений.гкс_ЭлектронныеТабло КАК Табло
СГРУППИРОВАТЬ ПО
    Табло.Авто, Табло.ДокументРегистрации, Табло.ВидТабло
ИМЕЮЩИЕ
    КОЛИЧЕСТВО(РАЗЛИЧНЫЕ Табло.Номенклатура) > 1
```
