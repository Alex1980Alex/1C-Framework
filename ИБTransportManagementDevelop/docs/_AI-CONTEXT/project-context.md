# Project Context — ИБTransportManagementDevelop

## Что это

EDT-проект 1С:Предприятие 8.3.27 для разработки и сопровождения функционала
**управления транспортом на ПЛК** (Промышленно-логистический комплекс).

Основная тематика: транспортная логистика — приёмка, разгрузка, отгрузка ТС
(транспортных средств), направления на разгрузку, заблокированные ТС, АРМ
(автоматизированные рабочие места) операторов и логистов.

## Структура

- `Конфигурация/` — EDT project (Eclipse Xtext, BSL/XML файлы 1С)
  - `Конфигурация/src/` — выгруженная конфигурация 1С (Catalogs, Documents,
    CommonModules, AccumulationRegisters и т. д.)
- `docs/` — ТЗ, ANALYSIS-REPORT, IMPLEMENTATION-PROGRESS, тесты, скриншоты
  по каждой Jira-подзадаче (формат `YYMMDD_GKSTCPLK-NNNN_описание/`)
  - `docs/_AI-CONTEXT/` — этот каталог: контекст проекта для AI-агентов
    (project-context, tooling, coding-conventions, lifecycle)
  - `docs/_HISTORY/` — архив рабочих заметок прошлых сессий
  - `docs/_TEMPLATE/` — шаблон новой Jira-задачи
- `features/` — Vanessa BDD `.feature` тесты
- `scripts/` — вспомогательные скрипты (Python, OneScript)
- `.vscode/` — настройки VS Code workspace
- `.bsl-language-server.json` — маркер BSL-проекта (`configurationRoot: "Конфигурация/src"`)

## Ключевые подсистемы 1С (по результатам анализов)

- **Заблокированные ТС** — управление списком ТС с ограничениями на работу
- **Направление на разгрузку** — документ-распоряжение оператору погрузки
- **АРМ оператора ПЛК** — формы для приёмки/отгрузки/композиции
- **Регистр сведений «РегистрацияНаПЛК»** — журнал событий по ТС
- **Композитные пробы** — отбор образцов для контроля качества
- **Статусная модель** — управление состояниями ТС, проб, документов
