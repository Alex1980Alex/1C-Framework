## Корневая причина (баг)
Функция `РегистрацияЗаблокированаДляРазгрузки()` (строки 717-722) использует модульную переменную `гкс_ДокументРегистрации` вместо параметра `ДокументРегистрации`, переданного в `СформироватьНаправлениеНаРазгрузкуПриНеобходимости`.

## 4 точки модификации
1. Добавить параметр `ПропуститьПроверкуБлокировки = Ложь` в `СформироватьНаправлениеНаРазгрузкуПриНеобходимости` (строка 598)
2. Передавать `Истина` при вызове из `СформироватьНаправленияНаРазгрузкуДляРазблокированныхТС` (строка 700)
3. Расширить `ЭтоЛабАнализДляЗаблокированныхТС` для покрытия "единичных" ЛА (строки 705-711)
4. Обратная совместимость вызовов из гкс_Взвешивание и гкс_СРПВРегистрацияОперацииСВагоном
