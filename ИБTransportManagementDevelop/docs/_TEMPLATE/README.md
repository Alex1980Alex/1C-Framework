# Шаблон папки задачи

Скопируй эту папку и переименуй в `<YYMMDD>_<JIRA-TICKET> <короткое описание>/`.

Пример: `260502_GKSTCPLK-2400 Добавить отчёт по простоям ТС/`

## Файлы шаблона

| Файл | Когда заполняется | Кем |
|---|---|---|
| `<тикет>.md` | На входе | Скопировать ТЗ от заказчика |
| `ANALYSIS-REPORT.md` | После Phase 1 | `/analyze-1c-task` |
| `IMPLEMENTATION-PROGRESS.md` | После Phase 3 | `/implement-1c-task` (чек-лист) |
| `test-plan.md` | После Phase 4 | `/write-1c-tests` |
| `REVIEW.md` | После Phase 5 (опц.) | code-verify subagent |
| `DEPLOYMENT.md` | Перед накаткой на прод | вручную |
| `CHANGELOG.md` | После релиза | вручную |

## Удалить файлы которые не нужны

После копирования удалить нерелевантные шаблоны (например, `DEPLOYMENT.md`
для мелкой правки баг-фикса).
